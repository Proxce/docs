## Introduction

Bluetooth ID is generated for the M-Tag application to function.

## Pre-requisite

Badge ID should be assigned to the User.

Steps to assign Badge ID and create Bluetooth credentials:

1. Log in to the **Supervisor Portal.**
   The **Users** page is displayed.
2. Click the **username** to edit.

   ![Click the username to edit.](/images/intercom/9716833/7046f59b-7e08-4971-9372-8bd19055bc69-aea17ab3.png)

   The user details page is displayed.

   ![The user details page is displayed.](/images/intercom/9716833/image-c720c4c1.png)

3. Do any of the following:
   1. Go to **Credentials** > **Bluetooth** tab> + **Create Bluetooth**.

      ![Go to Credentials &gt; Bluetooth tab&gt; + Create Bluetooth.](/images/intercom/9716833/image-799c3c07.png)

   2. Go to **Assign Credential** > **Create Bluetooth**.

      ![Go to Assign Credential &gt; Create Bluetooth.](/images/intercom/9716833/image-23d25799.png)

      The **Assign Bluetooth Credential** pop-up box is displayed.

      ![The Assign Bluetooth Credential pop-up box is displayed.](/images/intercom/9716833/image-b7af9de7.png)

4. On the pop-up box do the following:
   1. Enter **Badge ID** / **Secondary ID**.
   2. Select weigand format from **Wiegand Format** drop-down list.
   3. Click **Next**.
      The **Add Credential Validity** screen is displayed.

      ![The Add Credential Validity screen is displayed.](/images/intercom/9716833/image-31ab5ed2.png)

   4. Select **Start Date / Time** and **End Date/Time** from the calendar.

      <Note>
        **Note:** You can click **Now** to set the current date and time. The end date is automatically set to 1 year from the current date.
      </Note>

      You can also click **10 years from Now** to set the **End Date/Time** to 10 years from the current date/time.
   5. Click **Assign**.
      The Bluetooth ID is created and listed on the **Bluetooth** tab.

      ![The Bluetooth ID is created and listed on the Bluetooth tab.](/images/intercom/9716833/image-3f34653c.png)

      <Note>
        **Note:** The Badge ID is also assigned and listed on the **Badge** tab.
      </Note>

      ![The Bluetooth ID is created and listed on the Bluetooth tab. (2)](/images/intercom/9716833/image-3b479727.png)
