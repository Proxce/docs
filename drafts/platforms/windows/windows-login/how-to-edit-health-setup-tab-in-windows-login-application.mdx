**Pre-requisite:**

You must create a Passwordless application of type Windows Login. For further details, refer [How to create a Windows Login Application](/platforms/windows/windows-login/windows-login-how-to-create-and-configure-windows-login-application)

Steps to edit Health setup tab:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, click on an Windows application to edit.

   ![On the Applications page, click on an Windows application to edit.](/images/intercom/10796695/image-6eeaf72f.png)

   The application page is displayed.

   ![The application page is displayed.](/images/intercom/10796695/a6fe6366-1db5-41f4-a0af-130beb3c138d-7aa14f86.png)

3. Go to **Health Setup** tab.

   ![Go to Health Setup tab.](/images/intercom/10796695/7427cf3f-51ca-48a8-a72f-1032c4f3afe6-d725a90e.png)

   The **Health Setup** tab is displayed.
4. Do the following:
   1. Enter **Server Name**.
   2. Enter URL in **Add URL that needs to be monitored** field.
   3. Click **Add**.
      The Server Name is added and the Health Setup tab is configured successfully.
