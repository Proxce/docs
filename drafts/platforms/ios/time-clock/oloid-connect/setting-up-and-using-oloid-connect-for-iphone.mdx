**Oloid Connect** is a secure, contactless authentication solution. It enables seamless access, attendance tracking, and identity verification using face recognition, PINs, QR codes.

## Installation and Configuration

The Oloid Connect app is installed and configured on the iPhone.

- Download and Install the Oloid Connect App
- Configure the Oloid Connect App

For more details, see [How to Download and Install the Oloid Connect App on iPhone](/platforms/ios/time-clock/oloid-connect/oloid-connect-how-to-download-and-install-on-iphone)

For more details, see [Oloid Connect - Admin Setup on iPhone](/platforms/ios/time-clock/oloid-connect/oloid-connect-admin-setup-on-iphone)

## Configuration

### Platform

For an end-user to use the Oloid Connect for Passwordless app, the Tenant admin must perform the following configuration in the Oloid Platform.

- Set up Application and Connection
  For more details, see [How to create and configure Oloid Connect for Passwordless application](/platforms/ios/connect-passwordless/how-to-create-and-configure-oloid-connect-passwordless-application-in)
- Create User and assign to Connection
  For creating user assigning them to Connection, see [How to add user](/platform/tenant-admin-portal/tenant-admin-portal-how-to-create-user) guide
- Assign Credentials to users
  For assigning credential to users, see [User Onboarding](/reference/supporting-documents/user-onboarding-for-oloid-portal) guide
- Configure Oloid Connect Endpoint

  <Note>
    **Note:** Oloid Connect Endpoint is created in the Oloid Connect app.
  </Note>

  For more details, see [How to configure Oloid Connect Endpoint](/platforms/ios/time-clock/oloid-connect/oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal)
- Create and Configure Endpoint Template
  For more details, see [How to create and configure Oloid Connect endpoint template](/platforms/ios/time-clock/oloid-connect/oloid-connect-how-to-create-and-configure-endpoint-template-in-the)
- Grant Supervisor privileges to perform the assigned activities
  - Grant Supervisor permission to pair the endpoint in Oloid Connect app
    For more details, [How to activate Endpoint Pairing action in Oloid Portal](/platform/tenant-admin-portal/how-to-activate-endpoint-pairing-action-for-supervisor-in-tenant)

## Oloid Connect App

1. After installing the Oloid Connect app, the Tenant Admin or Supervisor can log in to pair the endpoint.
   For details, see [Oloid Connect - Admin Setup on iPhone](/platforms/ios/time-clock/oloid-connect/oloid-connect-admin-setup-on-iphone)

   <Note>
     **Note:** Endpoint pairing in Oloid Connect generates an endpoint ID with endpoint details in the Oloid Portal.
   </Note>

2. Once the endpoint is paired successfully, log in using:
   1. Face Recognition
   2. Single Sign-On
      For details, see [Oloid Connect - Admin Setup on iPhone](/platforms/ios/time-clock/oloid-connect/oloid-connect-admin-setup-on-iphone)
