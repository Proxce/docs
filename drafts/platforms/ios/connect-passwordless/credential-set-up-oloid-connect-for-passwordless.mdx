This is based on client requirement. Oloid's Windows login functions with a single factor (like Face, Badge , NFC tags and Pin) or combination of factors ( **Badge +Pin** and **NFC +Pin**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](/more/passwordless-authenticator/face-onboarding) guide. For onboarding User Faces through the device, see [Oloid Connect: Add Faces](/platforms/ios/time-clock/oloid-connect/oloid-connect-how-to-add-face-for-a-user) guide.
- Create Badges and assign it to users. Refer [Badge Onboarding](/more/passwordless-authenticator/badge-onboarding) guide.
- Create NFC and assign to users. Refer [NFC Onboarding](/more/passwordless-authenticator/nfc-onboarding) guide.
- Create Pin and assign to users. Refer [Pin Onboarding](/more/passwordless-authenticator/pin-onboarding) guide.
