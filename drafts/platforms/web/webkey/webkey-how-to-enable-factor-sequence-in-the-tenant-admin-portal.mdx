## Introduction

Factor Sequence enables adaptive Multi-Factor Authentication (MFA) for the Webkey application. A factor sequence defines the order of authentication factors (for example, Face followed by PIN) that a user must complete to access the application's endpoints.

## Prerequisites

- You have administrator access to the Tenant Admin Portal.
- The Webkey application is created in the Tenant Admin Portal.
- The factor sequence that you want to apply is configured in the Tenant Admin Portal.

## Steps to Enable Factor Sequence

1. Log in to the Tenant Admin Portal.
2. From the left navigation panel, click **Applications**.
   The Applications page is displayed.
3. From the list of applications, select the **Webkey application**.
   The Application Details page is displayed.
4. Click **Authenticator** tab.
5. In the left panel, click **Factor Sequence**.
   The Factor Sequence panel is displayed.
6. Do the following:
   1. Turn on the **Factor Sequence** toggle.
   2. From the **Factor Sequence drop-down list**, select the **factor sequence** that you want to apply to the application.
   3. Click **Save**.

<Note>
  **Note:** Factor Sequence is a mandatory field. If no factor sequence is listed, configure a factor sequence in the Tenant Admin Portal first, and then return to this step.
</Note>

Factor Sequence is enabled successfully for the Webkey application.
