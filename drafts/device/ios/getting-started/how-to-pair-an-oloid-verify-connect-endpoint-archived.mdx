To pair an endpoint:

1. Log in as Admin to Oloid **Verify**/**Connect**.

   <Note>
     **Note:** For more information on logging in to admin mode, see **[How to log into the admin mode of Oloid Verify/Connect App as a Supervisor](https://oloid.help/en/articles/8464035-how-to-log-into-the-admin-mode-of-oloid-verify-connect-app-as-a-supervisor)**.
   </Note>

   The **Settings** page is displayed on successful login.
   ![How to pair an Oloid Verify/Connect... - screenshot 1](/images/intercom/8181293/image-00ef5ccf.png)
2. Do the following:
   1. Add **Template (**optional**)**.

      <Note>
        **Note:** Templates allow Admins to configure Endpoints at scale. A template has to be created in Tenant Admin Portal.
      </Note>

   2. Enter **Endpoint Name**.
   3. Select **Application Name** from **Application Name** dropdown.
   4. Click **Pair**.
      ![How to pair an Oloid Verify/Connect... - screenshot 2](/images/intercom/8181293/image-00ef5ccf.png)
      The settings are saved.
      ![How to pair an Oloid Verify/Connect... - screenshot 3](/images/intercom/8181293/image-ea5cd604.png)
      The endpoint is successfully paired.

![How to pair an Oloid Verify/Connect... - screenshot 4](/images/intercom/8181293/image-3c29f112.png)
