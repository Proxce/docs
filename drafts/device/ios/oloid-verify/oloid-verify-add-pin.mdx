## Introduction

This feature of the Oloid Verify app allows Tenant Admins and Supervisors to add PIN credentials for users.

### Pre-requisite

- User should be added to the connection.
- Ensure that the endpoint is properly paired. For more, refer to [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)

#### Steps to Add PIN

1. Log in to **Oloid Verify App**. For more, refer to [How to log in to the admin mode of Oloid Verify App as a Supervisor/Admin](https://oloid.help/en/articles/8671139-how-to-log-into-the-admin-mode-of-oloid-verify-app-as-a-supervisor-admin).
   The **Settings** page is displayed.
2. Tap **Users** on the menu at the bottom of the screen.
   ![Oloid Verify: Add PIN - screenshot 1](/images/intercom/9571329/9377fe2b-a615-4249-8523-c2c160df351b-7124fb23.png)
   The **Users** page is displayed with the list of users.
   ![Oloid Verify: Add PIN - screenshot 2](/images/intercom/9571329/image-93ba82a2.png)
3. Select user to add QR code from **Users** list.
   ![Oloid Verify: Add PIN - screenshot 3](/images/intercom/9571329/5fcf05cb-e154-401d-afb5-439de0ab2476-f82645cc.png)
   The user details page is displayed.
   ![Oloid Verify: Add PIN - screenshot 4](/images/intercom/9571329/f908dcbc-1529-4add-954b-ce7d1b45bb85-e416e83a.png)
4. Tap **PIN** tab, then tap![Oloid Verify: Add PIN - screenshot 5](/images/intercom/9571329/image-1ef1d34a.png)**Add** button next to **Set PIN**.
   ![Oloid Verify: Add PIN - screenshot 6](/images/intercom/9571329/c578eaf5-c988-4e12-82c8-c2900510300a-3434624d.png)
   The **Create PIN** pop-up box is displayed.
   ![Oloid Verify: Add PIN - screenshot 7](/images/intercom/9571329/image-7c96ae88.png)
5. On the pop-up box, do the following:
   1. Enter new PIN.
   2. Re-enter new PIN.

      <Note>
        **Note:** You can also share PIN with respective email IDs.
      </Note>

      The PIN is created and displayed under the **PIN** tab.
