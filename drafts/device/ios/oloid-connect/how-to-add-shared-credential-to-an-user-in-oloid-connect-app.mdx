Steps to add Shared Credential:

1. Login to **Admin Mode** in **Oloid Connect App**.

   <Note>
     **Note:** For knowing more about logging in to Admin Mode, see [How to login to Admin More in Oloid Connect as A Supervisor/Admin](https://oloid.help/en/articles/8671144-how-to-log-into-the-admin-mode-of-oloid-connect-app-as-a-supervisor-admin).
   </Note>

   The **Users** screen is displayed.
2. Select **User**.
   ![How to add Shared Credential to an User... - screenshot 1](/images/intercom/10410135/ecb1ec9b-e635-4105-923a-811c264048e2-1f33db3e.png)
   The **Details** screen is displayed.
3. Go to **Password** > tap **Add Shared Credentials**.
   ![How to add Shared Credential to an User... - screenshot 2](/images/intercom/10410135/e1a9a0ed-e859-4f6f-a3d1-987ed8b9b433-5043a604.png)
   The list of shared credential is displayed.
4. Select **Credential**(s) > tap **Assign**.
   ![How to add Shared Credential to an User... - screenshot 3](/images/intercom/10410135/image-fbc41af3.png)
   The **Shared Credentials** are added and listed under Password tab.
   ![How to add Shared Credential to an User... - screenshot 4](/images/intercom/10410135/image-553cad1b.png)
