Incorporating Single Sign-On (SSO) into the Oloid Connect App streamlines user access and enhances security. This document provides a step-by-step guide on configuring the Oloid Connect App for SSO login.

## Understanding the Basics

### Endpoints and Applications

Endpoints are the devices that facilitate specific functionalities within an application.

Each endpoint is associated with the application, and this association is commonly referred to as "pairing an endpoint."

### Connections

Connections, on the other hand, are groups or collections of users who utilize a specific application. Connections help organize and manage user access to the functionalities provided by the paired endpoints. It is crucial to establish connections to ensure the right users have access to the right resources within the application.

## Step-by-Step Configuration

Follow these steps to configure supervisor tablets :

### 1. Create Applications

Begin by creating the Passwordless application that your supervisor tablets will interact with. Refer to [Setting up applications and connections for Passwordless in Oloid Connect App](https://oloid.help/en/articles/8408159-setting-up-applications-and-connections-for-passwordless-in-oloid-connect-app)

### **2.** Create Connections

After creating the applications, it's time to organize users into connections. Connections are groups of users who will interact with the application functionalities provided by the paired endpoints.

Refer to [Setting up applications and connections for Passwordless in Oloid Connect App](https://oloid.help/en/articles/8408159-setting-up-applications-and-connections-for-passwordless-in-oloid-connect-app) guide.

### **3.** Map Connections to Applications

Now that you have both application and connections in place, it's time to establish the link between them. This step ensures that users within the connections can access the functionalities provided by the associated endpoints within the designated application.

This is done in the Oloid Portal. See, [Map Connections to Applications](https://oloid.help/en/articles/8304594-how-to-map-connection-to-application)

### **4.** Pair Endpoints

The final step involves pairing the endpoints to work in conjunction with the applications and connections. Endpoints should be set up to provide the specific functionalities required by the users within the mapped connections.

This is done on the device. See , [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)

### 5. Configure Third-Party Application URL

You need to configure the third-party url to interact with Okta application.

You need to share the url with Oloid Team.

### 6. Enable Integration

You need to enable **HTTP Request** under Enable Integrations in the Oloid Portal.

This is done by Oloid Admin.

### 7. Selecting credential for authentication.

Select the authentication method to login to your Okta system. You can either user Face, Badge or Pin depending on your requirement.

This is done by Oloid Admin.

The Oloid Connect App is configured for SSO Login.

You can now use your Oloid Connect App. See How to log into OKTA using Oloid Connect.
