**Pre-requisite**

The Windows Login endpoint must be created from Oloid Portal. For further details, see [How to add Windows Login endpoint](https://oloid.help/en/articles/8555476-how-to-add-windows-login-endpoint)

To download endpoint config file:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **Endpoints** on the left menu panel.
   ![How to download endpoint config file... - screenshot 1](/images/intercom/8778331/image-ba04d6ea.png)
   The Endpoints page is displayed.
3. Click **Endpoint Name** (endpoint created from portal) to edit.
   ![How to download endpoint config file... - screenshot 2](/images/intercom/8778331/image-a76d4621.png)
   The Endpoint detail page is displayed.
4. Click **Download** to download the config file for endpoint pairing.
   ![How to download endpoint config file... - screenshot 3](/images/intercom/8778331/image-236dcc64.png)
   The Config File is saved to the local device.
