## Introduction

An endpoint is added to the Oloid Platform for Oloid Verify/Connect app using the device.

Once the endpoint is paired, it gets automatically registered in the Oloid Platform.

Please refer to the instructions to learn **[how to pair an endpoint in Oloid Verify/Connect](https://oloid.help/en/articles/8181293-how-to-pair-an-oloid-verify-connect-endpoint)**.

Once the pairing process is completed on your device, you can check the added endpoint in the Oloid platform.

To check the added endpoint:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **Endpoints** on the left menu panel.
   ![How to add an endpoint for Oloid... - screenshot 1](/images/intercom/8320322/image-ba04d6ea.png)
   The Endpoints page is displayed.
3. On the Endpoints page, review the **Endpoint Name** and **Endpoint Type**.
   ![How to add an endpoint for Oloid... - screenshot 2](/images/intercom/8320322/image-392e2db7.png)
   The endpoint is successfully added to the portal.
   To edit and configure the Endpoint, see **[How to configure Endpoint](https://oloid.help/en/articles/8332796-how-to-configure-endpoint-for-verify-connect)**[.](https://oloid.help/en/articles/8332796-how-to-configure-endpoint-for-verify-connect)
