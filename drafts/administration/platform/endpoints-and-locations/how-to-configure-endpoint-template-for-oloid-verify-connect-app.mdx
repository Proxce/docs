Steps to configure Verify Endpoint Template:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to configure endpoint template for... - screenshot 1](/images/intercom/8472410/image-86b2831e.png)
   The Endpoints page is displayed.
3. On the top right, click **Endpoint Templates**.
   ![How to configure endpoint template for... - screenshot 2](/images/intercom/8472410/image-2ca52023.png)
   The **Endpoint Templates** page is displayed.
4. Click the endpoint template to be configured from the listed templates .
   ![How to configure endpoint template for... - screenshot 3](/images/intercom/8472410/image-91c9cf6b.png)
   The endpoint template details page is displayed.
   ![How to configure endpoint template for... - screenshot 4](/images/intercom/8472410/image-fad17d3f.png)
5. Do the following:
   1. **Settings** tab:
      1. Edit **Template Name.**

         <Note>
           **Note:** Template name is auto populated. You may edit it if required.
         </Note>

      2. Enter **Template Description** (Optional).
      3. Select time from **Timezone** dropdown list (Optional).
      4. Select Location from **Location** dropdown list (Optional).
      5. Select Building from **Building** dropdown list (Optional).

         <Note>
           **Note:** The Building field is enabled on selecting location.
         </Note>

      6. Select Area from **Area** dropdown list (Optional).

         <Note>
           **Note:** The Area field is enabled on selecting Building.
         </Note>

      7. Enter Endpoint Name in the **Name Endpoint As** field.
      8. Click **Save**.
   2. **Integration** tab: Enable Integrations to perform cloud-based actions.
   3. **Web Button** tab: Turn on **Enable Web Button** toggle button to view transactions.
   4. **Configure** tab:
      1. Turn on **Enable Heath Alerts** toggle button to receive health alerts of the endpoint at your configured email.
      2. Enter integration in the **Integration Name** field and enter URL in the **Add URLs that needs to be monitored** field.
   5. **Groups** tab: Add Group to Endpoint Template.
      The Verify endpoint template is configured.
