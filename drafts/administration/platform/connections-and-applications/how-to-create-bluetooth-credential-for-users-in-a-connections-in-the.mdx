## Introduction

The Tenant Admin Portal allows administrators to create Bluetooth credentials for users within a specific connection or across all connections. These credentials enable secure and seamless authentication using Bluetooth-enabled devices. By assigning Bluetooth credentials with defined start and end dates, administrators can effectively manage access duration and ensure controlled user authentication.

## Prerequisite

You must create a Connection in the Tenant Admin Portal. To create connections refer [How to create Connections in the Tenant Admin Portal](https://oloid.help/en/articles/8294297-how-to-create-connections-in-the-tenant-admin-portal).

## Steps to create Bluetooth credential for connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to create Bluetooth credential for... - screenshot 1](/images/intercom/8730917/image-023f2757.png)
   The **Users** page is displayed.
3. Go to **Action > Create Bluetooth Credential**.
   ![How to create Bluetooth credential for... - screenshot 2](/images/intercom/8730917/image-185ce09a.png)
   The **Create Bluetooth** pop-up box is displayed.
4. On the pop-up box, do the following:
   1. Select the connection(s) from the **Connections** dropdown list.
   2. For **Start Date / Time** do one of the following:
      1. Select **Start Date/Time**.
         or
      2. Select **Now** to set the current date and time.

         <Note>
           **Note:** The end date is automatically set to 1 year in default from the current date.
         </Note>

   3. For **End Date/Time** do one of the following:
      1. Select **End Date/Time.**
         or
      2. Select **10 years from Now** to set the **End Date/Time** to 10 years from the current date/time.
   4. Click **Assign**.

      <Note>
        **Note:** Credentials can only be assigned to users who have a badge associated with their profile.
      </Note>

      ![How to create Bluetooth credential for... - screenshot 3](/images/intercom/8730917/image-b77837a4.png)
      The Bluetooth credential is successfully created for all the users for the selected connection.
      ![How to create Bluetooth credential for... - screenshot 4](/images/intercom/8730917/image-2c1e6830.png)
