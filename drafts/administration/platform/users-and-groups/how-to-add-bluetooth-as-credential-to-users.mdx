## Introduction

Bluetooth ID is generated for the M-Tag app to function.

This document provides step-by-step instructions to create Bluetooth ID in the Oloid Portal.

## Pre-requisite

Badge ID should be assigned to the User. In case a Badge ID is not assigned to the User, see [How to assign Badge ID and create Bluetooth credentials](https://oloid.help/en/articles/8290168-how-to-assign-badge-id-and-create-bluetooth-credentials).

## Steps to Create Bluetooth ID

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left panel menu.
   ![How to add Bluetooth as credential to... - screenshot 1](/images/intercom/8290028/image-8a2530d0.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![Image](/images/intercom/8290028/6fdddeff-6161-4338-8bd9-0bba14bd0852-c2652008.png)
   The **user details** page is displayed.
   ![How to add Bluetooth as credential to... - screenshot 2](/images/intercom/8290028/image-825650f9.png)
4. Do one of the following:
   1. Go to **Credentials** tab> **Bluetooth** > + **Create Bluetooth**.
      ![How to add Bluetooth as credential to... - screenshot 3](/images/intercom/8290028/image-2ceeec8d.png)
   2. Go to **Assign Credential** > **Create Bluetooth**.
      ![How to add Bluetooth as credential to... - screenshot 4](/images/intercom/8290028/image-3b0521a5.png)
      The **Create Bluetooth** pop-up box is displayed.
      ![How to add Bluetooth as credential to... - screenshot 5](/images/intercom/8290028/image-ea3927af.png)
5. Select **Start Date / Time** and **End Date/Time** from the calendar.

   <Note>
     **Note:**

        You can click **Now** to set the current date and time. The end date is automatically set to 1 year from the current date.
        You can click **10 years from Now** to set the **End Date/Time** to 10 years from the current date/time.
     6. Click **Save**.
        The Bluetooth ID is created and listed on the **Bluetooth** tab.
        ![Image](/images/intercom/8290028/df748e44-883b-46f5-ab50-cc7ade501ae3-d77a65af.png)
   </Note>
