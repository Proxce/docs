You can enable new user creation button in Oloid Verify/Connect in the Oloid Portal.

To set up OLOID Verify/Connect:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to enable new user creation button... - screenshot 1](/images/intercom/8811118/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Click **Settings**.
   ![How to enable new user creation button... - screenshot 2](/images/intercom/8811118/image-af4f10b3.png)
   The **Tenant Settings** page is displayed.
   ![How to enable new user creation button... - screenshot 3](/images/intercom/8811118/image-539cb5ba.png)
4. Go to **Advanced** tab .
   ![How to enable new user creation button... - screenshot 4](/images/intercom/8811118/image-2dd5eb0e.png)
5. Under **Apps** section, select **OLOID Verify/Connect**.
   ![How to enable new user creation button... - screenshot 5](/images/intercom/8811118/image-d2e968e2.png)
   The **App Settings** page is displayed.
6. Enable **Show New User Creation** to add user on the Verify/Connect app.
7. Click **Save**.
   The setting is saved successfully.
