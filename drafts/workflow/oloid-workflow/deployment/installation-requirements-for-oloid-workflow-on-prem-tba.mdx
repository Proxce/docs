## Oloid Workflow (On-Prem) instance runs on the following systems

- Windows 7, 8, 8.1, 10 (32-bit & 64-bit) (Professional Edition or Higher)
- Windows Server 2012/2012R2, 2016, 2019 (Enterprise & Standard Edition) (32-bit & 64-bit)

## Minimum HW requirements

- 8 GB of RAM or above
- 100 GB disk Space (install size + log size)

You will need admin access to setup Oloid Workflow instance on the host machine.
