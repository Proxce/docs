## Applications to be installed

1. Python 3.10.x (prerequisite)

2. Node JS 14.x (prerequisite)

3. Oloid Workflow application

## Installation Procedure

1. Copy and paste the installer files from the local desktop to the destination machine.

![Instruction for Workflow Instance Setup... - screenshot 1](/images/intercom/6950909/image-bf0cc11d.png)

2. Always verify files have been installed in the Start → Services or Command prompt or Control panel → uninstall a program.

### Steps to Install Node JS

1. Double click on **node-v14.x** and click **Next** on the pop-up screen to continue with the installation.

![Instruction for Workflow Instance Setup... - screenshot 4](/images/intercom/6950909/image-b10708db.png)

2. Accept the license agreement and click **Next**.

![Instruction for Workflow Instance Setup... - screenshot 5](/images/intercom/6950909/image-657ba48e.png)

3. Click **Next** on **Destination Folder** screen.

4. Click **Next** on **Custom Setup** screen.

![Instruction for Workflow Instance Setup... - screenshot 6](/images/intercom/6950909/image-9c0feaa8.png)

5. Check the **Automatically install the necessary tools** and click **Next**.

![Instruction for Workflow Instance Setup... - screenshot 7](/images/intercom/6950909/image-f76a4d43.png)

6. Click **Install**.

![Instruction for Workflow Instance Setup... - screenshot 8](/images/intercom/6950909/image-551e0a33.png)

**7.** Click **Finish.**

![Instruction for Workflow Instance Setup... - screenshot 9](/images/intercom/6950909/image-27d99313.png)

The Command line screen opens.

![Instruction for Workflow Instance Setup... - screenshot 10](/images/intercom/6950909/image-e529b979.png)

8. Press **Enter**.

Wait until Windows starts PowerShell and successfully complete installation.

9. Press **Enter** to exit.

![Instruction for Workflow Instance Setup... - screenshot 11](/images/intercom/6950909/image-58d32c59.png)

### Steps to Install Python

1. Double click on **Python-3.10.x** → Select **Add Python checkbox** → Choose **Customize installation** → Click **Next.**

![Instruction for Workflow Instance Setup... - screenshot 12](/images/intercom/6950909/image-9dd5cb52.png)

![Instruction for Workflow Instance Setup... - screenshot 13](/images/intercom/6950909/image-6e46cea5.png)

**2.** Select **Install for all users** checkbox and click **Install**.

![Instruction for Workflow Instance Setup... - screenshot 14](/images/intercom/6950909/image-bd7c1c71.png)

3. Wait till Setup progress is successful.

![Instruction for Workflow Instance Setup... - screenshot 15](/images/intercom/6950909/image-6db5714b.png)

### Steps to Install Oloid-Workflow

1. Double click on Oloid-Workflow.

**The OloidWorkflow Setup Wizard is displayed.**

**2. Click Next on the OloidWorkflow Setup Wizard welcome screen.**

![Instruction for Workflow Instance Setup... - screenshot 16](/images/intercom/6950909/image-3e4a0f0f.png)

**3. Click Next on the Select Installation Folder screen.**

![Instruction for Workflow Instance Setup... - screenshot 17](/images/intercom/6950909/image-693c9828.png)

**4. Click Next on the Confirm Installation screen.**

![Instruction for Workflow Instance Setup... - screenshot 18](/images/intercom/6950909/image-4c8c97ed.png)

5. Wait till the Oloid Workflow installation is complete.

![Instruction for Workflow Instance Setup... - screenshot 19](/images/intercom/6950909/image-817ca001.png)

![Instruction for Workflow Instance Setup... - screenshot 20](/images/intercom/6950909/image-84074920.png)

6. Open **Microsoft Services** in the instance and see that **Oloid Workflow service** is up and running.

![Instruction for Workflow Instance Setup... - screenshot 21](/images/intercom/6950909/image-4706a583.png)

7. To verify Workflow is installed→ Enter **localhost: 3000** in your browser.

The **Login** page is displayed.

![Instruction for Workflow Instance Setup... - screenshot 22](/images/intercom/6950909/image-30be366c.png)

**8.** Enter **username** and **password** → Click **Login.**

The Oloid Workflow application page is displayed.

![Instruction for Workflow Instance Setup... - screenshot 23](/images/intercom/6950909/image-a4aa4e76.png)
