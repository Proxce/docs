## Introduction

A Scheduled report is a document generated and delivered automatically at set intervals to customers through email. Scheduled Reports are of two types:

- [Transaction Report](#transaction-report)
- [Onboarding Report](#onboarding-report)

## Pre-Requisite

You must have a Tenant Admin account.

### Transaction Report

Transaction Report contains the records of the last 24 hours of successful transactions performed across the site.

Create a Transaction Report:

1. Open the Oloid Portal.
2. Navigate to the "**Reports**" section.
3. Click "**Create Report**."
4. Follow the on-screen instructions to create Transaction Report.
   For detailed instructions, see [How to create transaction report.](https://oloid.help/en/articles/8446424-how-to-create-a-scheduled-transaction-report)

Configure a Transaction Report:

1. Open the Oloid Portal.
2. Navigate to the "**Reports**" section.
3. Click report name of "**Report Type**" as Transaction.
4. Follow the on-screen instructions to configure the Transaction Report.
   For detailed instructions, see [How to configure transaction report](https://oloid.help/en/articles/8455213-how-to-configure-a-scheduled-transaction-report).

### Onboarding Report

The Onboarding Report contains the record of all users onboarded onto the Oloid Platform. It can be configured to schedule the report generation frequency and send it to the customers through email.

Create an Onboarding Report:

1. Open the Oloid Portal.
2. Navigate to the "**Reports**" section.
3. Click "**Create Report**."
4. Follow the on-screen instructions to create Onboarding Report.
   For detailed instructions, see [How to create onboarding report.](https://oloid.help/en/articles/8450096-how-to-create-onboarding-report)

Configure an Onboarding Report:

1. Open the Oloid Portal.
2. Navigate to the "**Reports**" section.
3. Click report name of "**Report Type**" as Onboarding.
4. Follow the on-screen instructions to configure Onboarding Report.
   For detailed instructions, see [How to configure onboarding report](https://oloid.help/en/articles/8455465-how-to-configure-onboarding-report).
