This article outlines the steps for setting up Oloid Passwordless for Epic using the **Oloid RPA Add-On** and the **RPA Runtime** program. In this method, the Oloid RPA Add-On automates the Epic login process without changing the Windows login experience. Users will continue to log in to Windows as usual, while Oloid’s RPA handles seamless, passwordless authentication for Epic.

**Prerequisites**

Before starting the installation, ensure the following:

• **Administrator Access**: Admin rights are required to install both the Oloid RPA Add-On and the RPA Runtime program.

• **Oloid RPA Add-On Installer**: Available from the **Files** section of the **Oloid Tenant Admin Portal**.

• **RPA Runtime Installer**: Also available from the **Oloid Tenant Admin Portal**.

• **Host PC for Installation**: This method requires installation on the host PC, which is used to access Epic.

**Step-by-Step Installation Guide**

**Step 1: Download Oloid RPA Add-On and RPA Runtime Installers**

1. **Log in to the Oloid Tenant Admin Portal** using your admin credentials.

2. Navigate to the **Files** section.

3. **Download the Oloid RPA Add-On Installer** and **RPA Runtime Installer**. Both installers are pre-configured for your specific tenant, ensuring compatibility with your Oloid setup.

**Step 2: Install Oloid RPA Add-On**

The Oloid RPA Add-On will be installed on the host PC, providing the necessary extension to automate passwordless login into Epic.

1. **Run the Oloid RPA Add-On Installer as Administrator**:

• Right-click the installer and select **“Run as Administrator.”**

2. **Follow the Installation Prompts**:

• The installer will guide you through the setup process. Make sure to follow all prompts to complete the installation.

• The RPA Add-On will be installed as an extension, designed to interface with Epic and automate the login process without altering the Windows login experience.

**Step 3: Install RPA Runtime Program (for EPIC Login)**

The RPA Runtime will automate the Epic login process, ensuring a seamless and passwordless experience for users.

1. **Run the RPA Runtime Installer as Administrator**:

• Right-click the installer and select **“Run as Administrator.”**

2. **Follow the Installation Prompts**:

• The RPA Runtime installer will guide you through the setup, ensuring that the program is properly configured to detect Epic and manage passwordless login.

• Once installed, the RPA Runtime will be responsible for automating the EPIC login process, allowing for seamless integration, whether Epic is running on the host PC or through a Citrix session.

**Step 4: Verify in Citrix (If Applicable)**

If EPIC is accessed through a Citrix environment, ensure the following Citrix-specific configurations are completed:

**Verify RPA Integration in Citrix**:

• Open a Citrix session and confirm that the RPA Runtime is correctly detecting Epic and automating the login process.

• The RPA Runtime will work within the Citrix environment, ensuring passwordless login without requiring any manual input.

**Step 5: Test EPIC Passwordless Authentication with Oloid RPA**

1. **Test Epic Login**:

• Launch Epic on the host PC or within the Citrix session.

• The RPA Runtime will automatically handle the login process. Users do not need to enter a username or password; the Oloid RPA system will automate the authentication.

2. **Windows Login Experience Remains Unchanged**:

• Users will continue to log in to Windows as they currently do. This method does not modify the Windows login screen or require any changes to how users authenticate to the host PC.

**Troubleshooting Tips**

• **RPA Runtime Not Detecting Epic**: Ensure that the RPA Runtime is installed correctly and running. Restart the RPA service if necessary, which can be done via the Windows Services panel.

• **Citrix Integration Issues**: If Epic is running in Citrix and the RPA is not functioning correctly, verify that USB passthrough is enabled (if using a badge reader) and that the RPA Runtime is working inside the Citrix session.

• **Admin Privileges**: Always ensure you are running the installers with administrator rights to avoid permission or access issues during installation.
