## Pre-requisite

You should be a Tenant Admin in the Oloid Platform.

## To move user from one location to another

1. Log in to the **Oloid Platform**.
   Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.
   Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu.
   In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Migrate User"**.
   In the "**Users**" page select the user to whom you want to migrate it to another connection. Then, follow the on-screen instructions to complete the process.
   For a detailed guide on moving user from one location to another, refer[**How to migrate user to a different connection**](https://oloid.help/en/articles/8379283-how-to-migrate-user-to-a-different-connection)**.**
