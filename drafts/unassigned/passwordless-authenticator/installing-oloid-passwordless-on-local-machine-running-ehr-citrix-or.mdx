In this guide, we will walk you through the process of installing Oloid Passwordless on a machine running Epic, with specific instructions for setups where a USB badge reader is connected to a host PC, such as in a Citrix environment. This method ensures that the badge reader connected to the host PC is accessible within the Citrix session using USB passthrough technology, enabling seamless, passwordless authentication.

**Prerequisites**

Before proceeding with the installation, ensure the following:

• **Administrator Access**: You will need admin privileges on the machine (local or Citrix) where Epic is running.

• **Oloid Login Device Installer**: Downloadable from the **Files** section of the **Oloid Tenant Admin Portal**.

• **USB Badge Reader**: Connected to the host PC and configured for use with the Oloid Passwordless solution.

• **USB Passthrough Enabled**: In Citrix environments, ensure that USB passthrough is enabled to allow the virtual machine to access the badge reader connected to the host PC.

**Step-by-Step Installation Guide**

**Step 1: Access Oloid Tenant Admin Portal**

1. **Login to the Oloid Tenant Admin Portal** using your admin credentials.

2. Navigate to the **Files** section within the portal.

3. **Download the Oloid Login Device Installer** that is pre-configured for your tenant. This installer ensures that the Oloid system integrates correctly with your setup.

**Step 2: Enable USB Passthrough for Badge Reader in Citrix Environment**

For environments where Epic is running on a Citrix machine, follow these steps to ensure that the badge reader connected to the host PC is accessible to the Citrix session:

1. **Configure USB Passthrough in Citrix**:

• **On the Host PC**, ensure that USB redirection or passthrough is enabled. This allows devices like badge readers connected to the host to be recognized within the Citrix virtual machine.

• **Citrix Workspace/Receiver Configuration**:

• Go to **Citrix Workspace Settings** on the host PC.

• Enable **USB Device Redirection** and ensure the connected badge reader is listed and available for redirection.

• Once USB passthrough is enabled, the Citrix session will recognize the badge reader and make it accessible within the virtual environment.

**Step 3: Install Oloid Login Device on Local or Citrix Machine**

Once the USB passthrough is configured, proceed with the Oloid installation:

1. **Run the Installer as Administrator**:

• If Epic is running on a **local machine**, right-click the installer file and select **“Run as Administrator.”**

• If Epic is running on a **Citrix environment**, log in to the Citrix server or machine as an administrator, and right-click the installer file to run it as admin.

2. **Follow the On-Screen Prompts**:

• The installer will guide you through the installation process.

• Ensure that Citrix is properly configured and that the USB badge reader is accessible during installation.

**Step 4: Verify Badge Reader Connection**

After the installation, confirm that the badge reader connected to the host PC is accessible from within the Citrix session:

1. **Test USB Passthrough**:

• Open the Citrix session and verify that the badge reader is detected by the virtual machine.

• You can check the device list within the Citrix session to confirm that the badge reader is accessible.

2. **Epic Badge Authentication**:

• Attempt to log in to Epic using your badge. The Oloid Login Device will now handle the passwordless authentication by reading the badge data and passing it to Epic for user verification.

**Step 5: Installation Completion and Success Message**

• After the installation is complete, you will see a **Success Message** indicating that the Oloid Login Device has been successfully installed and configured.

• **No further configuration** is required on the machine running Epic. Once installed, Epic will automatically detect the Oloid Login Device, and the badge reader will be utilized for authentication via USB passthrough in Citrix environments.

**Step 6: Verify Installation and Test EPIC Login**

1. **Restart the Machine** (if required):

• In some cases, a restart may be necessary for the changes to take effect, especially in Citrix environments.

2. **Login to EPIC**:

• Open Epic and attempt to log in using your badge. The Oloid system will now recognize the badge reader and allow passwordless login.

**Troubleshooting Tips**

• **USB Passthrough Issues**: If the badge reader is not detected within the Citrix session, double-check that USB redirection is enabled in Citrix Workspace settings and that the badge reader is listed under USB devices on the host PC.

• **Admin Privileges**: Ensure that the installer is run with administrator rights to avoid permission issues, especially in Citrix environments.

• **Badge Reader Compatibility**: Make sure the badge reader is compatible with Oloid’s system and properly connected to the host PC.
