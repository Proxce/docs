1. A **Supervisor** will be able to login to the admin mode of **Oloid Verify / Oloid Connect** using username and password or using face.
2. Once logged into the admin mode of **Oloid Verify / Oloid Connect** using username and password, the **Supervisor** can pair an endpoint.
3. Once logged into the admin mode, **Supervisor** can access the following:
   1. View a list of users that fulfils any of the below conditions-
      1. The connection which the **Supervisor** is part of is enabled for the application that the endpoint is paired with on that iPad.
      2. The application which the endpoint is paired with is assigned to the **Supervisor** who is logged in that iPad
   2. No users will show if
      1. The connection that the **Supervisor** is part of is not enabled for the application that the endpoint is paired with on that iPad.
      2. The Application that is paired with the endpoint that the Supervisor is logged into is not assigned to that **Supervisor**.
4. Add face to the users listed in the Admin mode
5. Add users to the connections that are enabled for the application that is paired with the endpoint that the **Supervisor** has logged into.
6. Delete faces for any user that is listed in the Admin mode.
