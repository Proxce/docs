To utilize the **Oloid's** Passwordless Login, you must configure **Applications** and **Connections** within the Oloid Portal.

## Understanding the Basics

### Application

An application is a set of configurations to enable Passwordless feature for the endpoint.

An application is created from the Oloid Portal and then mapped with the end user device (also known as Endpoint).

### Connection

Connections are a collection of users of the application.

Once both application and connection are created, map the connection to the application.

This step ensures that users within the connections can access the functionalities provided by the associated endpoints within the designated application.

## Step-by-Step Configuration

Follow these steps to configure supervisor tablets :

### 1. Create Applications

Begin by creating the Passwordless Application that your endpoint will interact with.

This is done in the Oloid Portal.

See, **How to create Application** and **[How to Configure Application Type - Passwordless](https://oloid.help/en/articles/8300330-how-to-configure-application-type-passwordless)**

### **2.** Create Connections

After creating the applications, it's time to organize users into connections. Connections are groups of users who will interact with the application functionalities provided by the endpoints.

This is done in the Oloid Portal. See, [How to create Connections](https://oloid.help/en/articles/8294297-how-to-create-connection)

### **3.** Map Connections to Applications

Now that you have both application and connections in place, it's time to establish the link between them. This step ensures that users within the connections can access the functionalities provided by the associated endpoints within the designated application.

This is done in the Oloid Portal. See, **[Map Connections to Applications](https://oloid.help/en/articles/8304594-how-to-map-connection-to-application-in-oloid-portal)**
