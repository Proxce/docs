## Introduction

Oloid Passkey enables secure, passwordless access to the Tenant Admin Portal using device-based authentication.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure Passkey is enabled for the User from the Tenant Admin Portal. For more, refer: [Webkey - How to Enable Oloid (Webkey) SSO login](https://oloid.help/en/articles/13597272-webkey-how-to-enable-oloid-webkey-sso-login)

## Steps to log into Tenant Admin Portal using Oloid Passkey

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**.
   The **Oloid Login** page is displayed.
3. Click **Login with SSO**.
   ![How to Log in to the Tenant Admin... - screenshot 1](/images/intercom/13884713/image-6048ac34.png)
   The configured login options are displayed.
4. Click **Continue with OloID**.
   ![How to Log in to the Tenant Admin... - screenshot 2](/images/intercom/13884713/image-46fa6de8.png)
   The Oloid Authentication page is displayed.
5. Select the preferred credential to login. (Example face, Badge, NFC etc)

   <Note>
     **Note:** The Login options are displayed based on the authentication methods configured in the Webkey application.
   </Note>

   ![How to Log in to the Tenant Admin... - screenshot 3](/images/intercom/13884713/image-9e648734.png)

Complete the Authentication process for the preferred credential.

The user is successfully authenticated.
