## Introduction

A Personal Passkey allows Tenant Admin to set up secure, passwordless authentication through passkeys. Tenant Admins can generate a passkey from the user profile in the Tenant Admin Portal.

## Prerequisite

- You must have access to Tenant Admin account.
- Personal Passkey must be enabled in the Tenant Admin portal. Refer: [How to Enable Passkey SSO in Tenant Admin Portal](https://oloid.help/en/articles/13856829-how-to-enable-passkey-sso-in-tenant-admin-portal)

## Steps to Generate Personal Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Profile icon** on the bottom left corner of the menu panel.
   ![How to Generate Personal Passkey - screenshot 1](/images/intercom/13856872/image-6aab28d0.png)
   The user profile menu is displayed.
3. Click **Username**.
   ![How to Generate Personal Passkey - screenshot 2](/images/intercom/13856872/1d798efb-86a0-49ec-8e55-2630d1b4dbf7-6e7a43b8.png)
   The **User Profile** page is displayed.
4. Do the following:
   1. Edit **Full Name**. (Optional)
      1. Click **Save.**

         <Note>
           **Note:** Click **Save** if Full Name field is changed.
         </Note>

   2. Click **Generate**.
   3. Enter **Phone** number. (Optional)
      ![How to Generate Personal Passkey - screenshot 3](/images/intercom/13856872/image-efa979db.png)
      The Passkey registration screen is displayed.
      ![How to Generate Personal Passkey - screenshot 4](/images/intercom/13856872/image-be00c068.png)
      The Passkey is successfully generated.
      ![How to Generate Personal Passkey - screenshot 5](/images/intercom/13856872/image-cbc3df51.png)

      <Note>
        **Note:** The Passkey will be saved to Oloid Vault, Windows Login, Google Password manager or Windows Hello.
      </Note>

The Personal Passkey will be displayed on the User's profile under the Credentials tab.

![How to Generate Personal Passkey - screenshot 6](/images/intercom/13856872/image-7515582a.png)
