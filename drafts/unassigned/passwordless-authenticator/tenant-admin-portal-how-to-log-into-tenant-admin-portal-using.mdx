## Introduction

Personal Passkey enables secure, passwordless access to the Tenant Admin Portal using a passkey associated with an individual user account.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Passkey is enabled for the user. Refer: [How to Enable Passkey SSO in Tenant Admin Portal](https://oloid.help/en/articles/13856829-how-to-enable-passkey-sso-in-tenant-admin-portal)
- Personal Passkey is **enabled for your account**. Refer: [How to Generate Personal Passkey in the Tenant Admin Portal](https://oloid.help/en/articles/13856872-how-to-generate-oloid-passkey-in-the-tenant-admin-portal)

## Steps to log into Tenant Admin Portal using Personal Passkey

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**.
   The **Oloid Login** page is displayed.
3. Click **Login with SSO**.
   ![How to log into Tenant Admin Portal... - screenshot 1](/images/intercom/15531507/image-6048ac34.png)
   The configured login options are displayed.
4. Click **Login with Passkey**.
   ![How to log into Tenant Admin Portal... - screenshot 2](/images/intercom/15531507/image-58b91b64.png)
   The Oloid login page is displayed.

Enter **Email ID** > click **Next**.

![How to log into Tenant Admin Portal... - screenshot 3](/images/intercom/15531507/image-8534556b.png)

The user is authenticated using passkey.

![How to log into Tenant Admin Portal... - screenshot 4](/images/intercom/15531507/image-42e1e253.png)

The User is logged into the Tenant Admin Portal.
