This article details how to set up Oloid Passwordless for Epic login using the **Oloid Agent** and **RPA Runtime** program. In this method, the Oloid Agent integrates with Windows as a Credential Provider to enable passwordless login at the Windows login screen. Additionally, the RPA (Robotic Process Automation) Runtime handles seamless passwordless login into Epic, even when accessed through Citrix.

**Prerequisites**

Before starting the installation process, ensure the following:

• **Administrator Access**: You will need admin rights to install both the Oloid Agent and the RPA Runtime program.

• **Oloid Agent Installer**: This installer is available from the **Files** section of your **Oloid Tenant Admin Portal**.

• **RPA Runtime Installer**: Also available from the **Oloid Tenant Admin Portal**.

• **Host PC for Installation**: This method requires installation on the host PC that is being used to access Epic.

**Step-by-Step Installation Guide**

**Step 1: Download Oloid Agent and RPA Runtime Installers**

1. **Log in to the Oloid Tenant Admin Portal** using your admin credentials.

2. Navigate to the **Files** section.

3. **Download the Oloid Agent Installer** and **RPA Runtime Installer**. Both files are pre-configured for your specific tenant and are required to enable passwordless login for Epic.

**Step 2: Install Oloid Agent (Credential Provider)**

The Oloid Agent will be installed on the host PC as a Credential Provider, allowing users to authenticate without a password at the Windows login screen.

1. **Run the Oloid Agent Installer as Administrator**:

• Right-click the installer and select **“Run as Administrator.”**

2. **Follow the Installation Prompts**:

• The installer will guide you through the setup. Accept the default installation directory unless your setup requires a different location.

• After installation, the Oloid Agent will be registered as a Windows Credential Provider.

3. **Windows Login Screen Integration**:

• Once the installation is complete, the Windows login screen will now display the Oloid passwordless login option. Users will be able to authenticate using Oloid, bypassing the need for a traditional username and password.

**Step 3: Install RPA Runtime Program (for Epic Login)**

The RPA Runtime handles automated, passwordless authentication for Epic. Follow these steps to install it on the host PC:

1. **Run the RPA Runtime Installer as Administrator**:

• Right-click the installer and select **“Run as Administrator.”**

2. **Follow the Installation Prompts**:

• The installer will guide you through the RPA Runtime setup. The program will be installed to automate Epic login without user interaction.

3. **RPA Configuration**:

• The RPA Runtime will be configured to detect when Epic is running (whether locally or in a Citrix session) and automatically handle the login process using stored credentials.

**Step 4: Verifying with Citrix (If Applicable)**

If you are using Epic in a Citrix environment, ensure the following configuration steps are completed:

**Verify RPA Functionality in Citrix**:

• Open a Citrix session and check that the RPA Runtime is correctly detecting EPIC and automating the login process. The RPA should handle the login seamlessly, bypassing the need for user interaction.

**Step 5: Test Oloid Passwordless Windows Login and Epic Authentication**

1. **Test Windows Login**:

• Restart the host PC to apply the Credential Provider changes.

• On the Windows login screen, select the **Oloid passwordless login option**.

• Authenticate using Oloid’s passwordless method (e.g., facial recognition or badge).

2. **Test EPIC Login**:

• Launch Epic on the host PC or through Citrix.

• The RPA Runtime should automatically log you into Epic without requiring a password. The process is fully automated.

**Troubleshooting Tips**

• **Windows Login Issues**: If the Oloid passwordless option does not appear on the Windows login screen, verify that the Oloid Agent was installed correctly with administrator privileges.

• **RPA Runtime Not Detecting Epic**: Ensure that the RPA Runtime is running and configured to detect Epic. You can restart the RPA service from the Windows Services panel if needed.

• **Citrix Integration Issues**: Double-check that USB passthrough is enabled in Citrix if a badge reader is being used, and verify that the RPA Runtime is working within the Citrix session.
