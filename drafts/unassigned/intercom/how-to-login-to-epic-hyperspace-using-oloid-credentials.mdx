## Introduction

Logging into **Epic Hyperspace using Badge and PIN** allows users to scan their assigned badge and verify their identity using a PIN before gaining access to Epic Hyperspace.

## Prerequisites

In the Oloid Portal, you must do the following:

- Assign Badge ID to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
- Enable Badge as an authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_9366168092:~:text=by%20Oloid%20admin.-,Badge%20ID,-To%20use%20Badge)
- Add PIN access to the user. For more details, refer [How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
- Enable PIN as an authenticator in the Windows application. For more details, refer [How to enable PIN in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_0412e471e4:~:text=multi%2Dfactor%20authentication.-,PIN,-To%20use%20PIN)
- Epic Vault Password must be created for the user.

  <Note>
    **Note:** Vault Password is required for Username/ Password flow. For more information, refer: [How to create Vault Password for a user](https://oloid.help/en/articles/9936961-chrome-vault-how-to-create-vault-password-for-a-user)
  </Note>

1. Launch the Epic Hyperspace application on your Windows machine.

### Login using Username & Password

If Username / Email have been configured as first factor, users must do the following:

<Note>
  **Note:** To login using Email/ Employee ID, Face must be enabled as a credential in the Tenant admin portal.
</Note>

1. The Windows login app opens and the Welcome page is displayed, Enter **Email ID / Employee ID.**
2. Click **Continue**.

The camera turns on and users must authenticate using [Face](#login-using-face) to authenticate.

![How to Login to Epic Hyperspace using... - screenshot 3](/images/intercom/13903766/image-243f99b6.png)

### Login using Face

1. The Windows login app opens and the Welcome page is displayed, Click **Face.**
2. The camera turns on. Place your face in front of the camera for facial authentication.
   The camera auto-captures the user's face.
   If manual capture is enabled, press **Enter or Spacebar,** or click on the camera icon.
   On successful facial authentication, you are signed in to the Windows system.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully.
   </Note>

### Login using Badge

The **Scan Badge** pop-up box is displayed.

1. Tap the **Badge** on the **Badge Reader** to scan it.
   ![How to Login to Epic Hyperspace using... - screenshot 4](/images/intercom/13903766/image-9cd74bd6.png)
   The **Enter PIN** pop-up box is displayed.

Enter the **PIN** then click **Submit**. Check

### Login using QR code.

1. The Windows login app opens and the camera turns on.
2. Show your QR Code in front of the camera for QR Code authentication.

![How to Login to Epic Hyperspace using... - screenshot 6](/images/intercom/13903766/image-a95606cc.png)

The QR is successfully authenticated.

### Login using NFC ID

1. The Windows login app opens and the **Tap NFC Tag at the device** screen is displayed.
2. Tap the **NFC Tag** on the **Reader** to scan it.
   The NFC ID is successfully authenticated.

The **Choose Your Account** pop-up box is displayed.

<Note>
  **Note:** If the user has multiple passwords configured in the Oloid Portal, they can select a specific account to sign in. If the user has only one account configured, **Choose Your Account** pop-up box will not be displayed.
</Note>

1. Select the account to sign in.
2. The **Duo Security** pop-up box is displayed.
3. Select the user’s phone number from the **Device** dropdown in the **User Details** section.

   <Note>
     **Note:** The **Device** dropdown displays multiple phone numbers only if the user has more than one phone number configured in the system.
   </Note>

4. Do one of the following:
   1. **Duo Push**:
      1. Select **Send push** to send a notification to the registered mobile number.
         The Push notification is displayed in your registered device.
      2. Tap **Approve**.
   2. **Passcode:**
      1. Select **Enter a Passcode** to send a Passcode to the registered mobile number.
         A Passcode is displayed on the Duo mobile application.
      2. Enter the passcode in the passcode field and click **Log In**.
         OR
      3. Click **Text me New Codes.**
         You will receive a SMS with a verification code.
      4. Enter the code in the Passcode Login field and then click **Login.**
