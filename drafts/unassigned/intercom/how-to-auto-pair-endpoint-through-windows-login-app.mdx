**Introduction**

This document provides step-by-step instructions for auto pairing the endpoint through Windows Login app.

**Pre-requisite**

- Enable preferred authenticator in the Oloid Portal. For more details, see How to create and configure Windows Login application >[How to configure authenticator tab](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_d3f5dd6c43)

  <Note>
    **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
  </Note>

Steps to sign in to Windows device:

1. On the Windows lock screen, click **Login with OLOID**.
   ![How to auto pair endpoint through... - screenshot 1](/images/intercom/10448856/image-2b9913e8.png)
   The Windows login app opens.
2. Select **Yes, pair my device** to auto-pair the device.
   ![How to auto pair endpoint through... - screenshot 2](/images/intercom/10448856/36ba5c1c-da02-44b6-a6da-a1ce9cc3ef00-786a18de.png)
   The device is paired successfully.
3. Click **Login**.
   ![How to auto pair endpoint through... - screenshot 3](/images/intercom/10448856/27df5e54-1312-4f82-9e65-70f0ea701e0e-f3d2a930.png)
4. Enter **Employee / Email ID**, then click **Continue**.
   ![How to auto pair endpoint through... - screenshot 4](/images/intercom/10448856/a98c048d-8d81-4629-95f1-4f3cac62bb23-5fdf17c5.png)
   The camera turns on.
5. Place your face in front of the camera for facial authentication.
   ![How to auto pair endpoint through... - screenshot 5](/images/intercom/10448856/image-762fc0b7.png)
   On successful facial authentication, you are signed in to the Windows device.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully.
   </Note>

   ![How to auto pair endpoint through... - screenshot 6](/images/intercom/10448856/image-751ec873.png)
