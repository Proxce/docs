**Steps to set logout URL:**

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click the preferred application from the application list.
   ![How to set logout URL in Passwordless... - screenshot 1](/images/intercom/11537542/image-3c3c4a2e.png)
3. Go to **Configure** tab > click **Configure Passwordless** from the left menu panel.
   ![How to set logout URL in Passwordless... - screenshot 2](/images/intercom/11537542/image-d03d05d1.png)
4. Turn on **Enable Passwordless Config** toggle > select **Passwordless Login**

   <Note>
     **Note:** Turning on this toggle will disable **Clock In / Clock Out** mode.
   </Note>

   ![How to set logout URL in Passwordless... - screenshot 3](/images/intercom/11537542/image-5c423b92.png)
5. Turn on **Passwordless SSO URL** toggle > enter Logout URL in the text field > click **Save**.
   ![How to set logout URL in Passwordless... - screenshot 4](/images/intercom/11537542/image-870f37d5.png)
   The logout URL is set successfully.
   ![How to set logout URL in Passwordless... - screenshot 5](/images/intercom/11537542/image-de46183c.png)
