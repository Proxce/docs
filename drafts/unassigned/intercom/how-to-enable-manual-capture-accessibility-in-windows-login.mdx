## **Introduc**tion

In Oloid portal, enabling Manual Capture Accessibility feature in Windows Login application allows users to manually capture the face when using the Windows Login app.

## Steps to Enable Manual Capture Accessibility

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to enable Manual Capture... - screenshot 1](/images/intercom/11016632/image-6eeaf72f.png)
   The application page is displayed.
   ![How to enable Manual Capture... - screenshot 2](/images/intercom/11016632/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to enable Manual Capture... - screenshot 3](/images/intercom/11016632/d6ac5f50-d13c-4c30-8c82-f1ccbdbe53e2-aaefe3f2.png)
4. Turn on **Enable Manual Capture Accessibility** toggle button to manually capture face for sign-in Windows Login app.
   ![How to enable Manual Capture... - screenshot 4](/images/intercom/11016632/6556cd3f-82ad-4635-bb49-3aed1a823337-2f2dbe99.png)

Click **Save**.

![How to enable Manual Capture... - screenshot 5](/images/intercom/11016632/a39585fa-1a29-408d-ad0c-5b5253be315a-20b990a0.png)

The configuration is saved successfully. See, [Sample screen for Manual Capture Accessibility](#sample-screen-for-manual-capture-accessibility)

<Note>
  **Note:** In **Windows Authenticator** app, you must sync the configuration to enable Manual Capture Accessibility. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
</Note>
