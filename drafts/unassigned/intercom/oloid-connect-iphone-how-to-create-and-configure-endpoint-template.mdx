## **Intro**duction

This document provides instructions for creating and configuring the Oloid Connect Endpoint Template. Tenant Admins and Supervisors in the Oloid Connect application can apply the template to configure endpoint-specific settings.

## Prerequisite

You must have a Tenant Admin Account.

## Steps to create Endpoint Template

1. Log in to the **Tenant Admin Portal**.
   The **Application** page is displayed.
2. Select **Endpoint** from the left menu panel.
   ![How to Create and Configure Endpoint... - screenshot 1](/images/intercom/13700997/2e77e818-0456-4972-8080-8c6befda4a89-97cd9706.png)
   The **Endpoint** page is displayed.
3. On the top right click **Endpoint Template**.
   ![How to Create and Configure Endpoint... - screenshot 2](/images/intercom/13700997/image-601749e2.png)
   The **Endpoint Template** page is displayed.
4. On the top right, click **Create Template**.
   ![How to Create and Configure Endpoint... - screenshot 3](/images/intercom/13700997/d72bb8de-d95f-4e11-bd37-3e550baa4659-a0850d12.png)
   The **Create New Template** pop-up is displayed.
   ![How to Create and Configure Endpoint... - screenshot 4](/images/intercom/13700997/image-1265c418.png)
5. Do the following:
   1. Enter **Template Name**.
   2. Select **Application Type** as **Oloid Verify** from the dropdown list.
   3. Select **Endpoint Type** as **Oloid Connect** from the dropdown list.
   4. Click **Create**.
      The Endpoint is created and listed successfully on Endpoint Template page.
      ![How to Create and Configure Endpoint... - screenshot 5](/images/intercom/13700997/e9da5bdc-211f-48ab-8d5b-1161af6af90c-c89b83c6.png)
6. Click **Endpoint Template** to be configured from the listed templates.
7. Configure the following:
   1. [Details tab](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template#h_31a43aea7f)
   2. [Configure tab](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template#h_6b85c4579c)
      The Endpoint Template is configured successfully.

### Configure Details Tab

![How to Create and Configure Endpoint... - screenshot 6](/images/intercom/13700997/image-017d0cd5.png)

1. Edit **Template Name** (If required).
2. Enter **Template Description**. (Optional)
3. Select **Endpoint Type** from the dropdown list.
4. Select **Timezone** from the dropdown list. (Optional)
5. Enter name in **Name Endpoint As** text field. (Optional)
6. Select **Location** from the dropdown list. Once selected, this activates the **Building** field. (Optional) For more information on creating a location, refer [How to create a new location and add location details](https://oloid.help/en/articles/8227103-how-to-create-a-new-location-and-add-location-details?q=for+more+information)
7. Select **Building** associated with the chosen locationfrom the dropdown list. Once selected, this activates the **area** field. (Optional)
8. Select **area** within the building from the dropdown list. (Optional)
9. Click **Save**.

   <Note>
     **Note:** The **Building** and **Area** fields remain disabled until a valid **Location** is selected.
   </Note>

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

   The **Details tab** is configured successfully.
   ![How to Create and Configure Endpoint... - screenshot 7](/images/intercom/13700997/image-1a9c956b.png)

### Configure Endpoint Setting Tab

![How to Create and Configure Endpoint... - screenshot 8](/images/intercom/13700997/dd95c168-92b7-48d1-acc9-9d013c19ede3-5242cfaa.png)

1. **Use Endpoint in Admin Mode Only**: Enable this toggle to restrict the endpoint device to admin mode and discard user's access control.
2. **Capture Location:** Enable this toggle to capture location on the endpoint for each transaction.
   **Note: Location Permission** on the Endpoint device must be enabled to Capture Location.
3. **Generate Debug Logs:** Enable this toggle to generate debug logs for the endpoint. Logs are saved locally on the device.
4. **Enable Landscape Mode for Preview Screen:** Enable this toggle to allow the user preview screen to switch from portrait to landscape orientation.
5. Click **Save**.
   The **Endpoint Settings tab** is configured successfully.

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

### Groups Tab

![How to Create and Configure Endpoint... - screenshot 9](/images/intercom/13700997/689a1ecc-83ec-44e1-ad68-2ff9f4312467-2ce70919.png)

1. Click **+Add Group**.
   The **Add Group** pop-up is displayed.
   ![How to Create and Configure Endpoint... - screenshot 10](/images/intercom/13700997/image-9ae0067a.png)
2. Select **Group(s)** from the dropdown list.
3. Click **Add**.
   The group is added and listed in the Group Name section.

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

### Configure Web Button Tab

![How to Create and Configure Endpoint... - screenshot 11](/images/intercom/13700997/fd4b8e31-1af1-4ad5-8707-51161e2d5a7e-862877ef.png)

1. **Enable Web Button** toggle to activate the web button on the endpoint preview screen to view transaction.
   1. Enter **URL**.

      <Note>
        **Note:** You have to enter the URL of the website where the user will review the punches.
      </Note>

   2. Enter **Timeout** duration.
2. Enable **Show only on Auth** to allow the web button to appear only after successful authorization.
3. Enable **Auto Launch** to automatically launch the web button and view transaction.
4. Click **Save**.
   The **Web Button tab** is configured successfully.

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

### Configure Integration Tab

![How to Create and Configure Endpoint... - screenshot 12](/images/intercom/13700997/fc2134ff-b26f-4651-9f8c-a5df03f9d180-93335142.png)

The Integration section allows the Oloid Admin to configure post-authentication actions for the template. These actions can include API calls, relay triggers, or updates to external systems, triggered after user authentication. (Optional)

### Configure Health Setup Tab

![How to Create and Configure Endpoint... - screenshot 13](/images/intercom/13700997/7b2c2996-111f-4100-b022-3187c4e19b33-c69f53f5.png)

**Enable Health Alerts**

Do the following:

1. Turn on **Enable Health Alerts** toggle to monitor the health of the paired endpoints. (Optional)
2. Enter email ID(s) in **Add recipients for Endpoint Health Alerts** whom you want to share the health alert notifications. (Optional)
3. Set **Email frequency** in Hours and Mins to adjust the frequency of email notifications.
4. Click **Save** to apply your changes.
   The Health Alert is configured for the endpoint.

**Add URLs to Monitor**

Do the following:

1. Enter **Server Name**.
2. Enter URL in **Add URL that needs to be monitored** field.
3. Click **Add**.

![How to Create and Configure Endpoint... - screenshot 14](/images/intercom/13700997/image-e47310f3.png)

The Endpoint Template is created and configured successfully.
