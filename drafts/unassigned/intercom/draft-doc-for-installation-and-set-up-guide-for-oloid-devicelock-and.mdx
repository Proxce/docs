## Introduction

This guide provides detailed instructions to install and set up the Oloid Device Lock and Oloid Vault applications on Android devices through SOTI MobiControl. It also includes a set of basic regression test cases with expected outcomes to ensure that, with every new build release, all core use cases function as intended and no regressions occur.

## Prerequisites

- The device is already enrolled in **SOTI MobiControl**.
- A stable internet connection is available.
- A valid **Microsoft account** is available for the user.

### Enroll User credentials

1. Enroll Face. To enroll face refer [How to enroll face for users in the DeviceLock App](https://oloid.help/en/articles/12156735-how-to-enroll-face-for-users-in-the-devicelock-app).
2. Enroll PIN. To enroll PIN refer [How to enroll PIN for users in the DeviceLock App](https://oloid.help/en/articles/12157257-how-to-enroll-pin-for-users-in-the-devicelock-app).
3. Enroll NFC/ID. To enroll NFC/ID refer [How to enroll NFC/ID for users in the DeviceLock App](https://oloid.help/en/articles/12157546-how-to-enroll-nfc-id-for-users-in-the-devicelock-app).

   <Note>
     **Note:** Once the Credentials are enrolled for the user, Log out of Admin Mode and Initial Screen of device lock with configured Auth methods will be displayed
   </Note>

### Authentication Flow

1. Authenticate using **Device Lock** (Face + PIN or NFC + PIN).
   ![Draft Doc for-Installation and set-up... - screenshot 37](/images/intercom/12148494/image-d048c852.png)
   The **web view** screen is displayed.
2. Enter your Microsoft account **password** > Tap **sign-in.**

   <Note>
     **Note:** If it is first-time login, you need to manually enter your credentials.
   </Note>

   ![Draft Doc for-Installation and set-up... - screenshot 38](/images/intercom/12148494/image-c42e6246.png)
   The Username and Password prompt box is displayed.
3. Select **Save**.
   ![Draft Doc for-Installation and set-up... - screenshot 39](/images/intercom/12148494/cc148b33-65cf-4847-8cd8-66f89db93e3d-f5578166.png)
   .
   The **pre-login screen** is displayed.
   ![Draft Doc for-Installation and set-up... - screenshot 40](/images/intercom/12148494/image-9b9213bb.png)

   <Note>
     **Note:** Using Accessibility, **auto-login** is attempted into SOTI.
   </Note>

4. If auto-login does not occur, tap the **Login button** manually.
   The SOTI dash board screen is appeared.
   ![Draft Doc for-Installation and set-up... - screenshot 41](/images/intercom/12148494/image-7f3a70d6.png)
5. Once logged in, you can access the customer **apps** like - Blank slate, Spring shot, Aero, etc.
6. For all future app logins, **auto-login will occur automatically**.

## Summary

By following the above steps, the **Oloid Device Lock** and **Oloid Vault** applications will be fully installed, configured, and ready for use.

- Administrators can log in using **Microsoft SSO for** enrolling with **Face, NFC, and PIN** credentials
- **Oloid Vault** enables **Autofill**, allowing seamless access and auto-login to Microsoft and non-Microsoft applications.
