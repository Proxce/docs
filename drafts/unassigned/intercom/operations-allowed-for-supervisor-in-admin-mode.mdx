A **Supervisor** has limited access to the Oloid Portal and connected devices.

Supervisors can create, update, and delete data only if granted privileges by an Admin.

1. The Supervisor first logs in to the Supervisor portal using credentials. See [Supervisor Portal - How to log in to Supervisor Portal](https://oloid.help/en/articles/9690901-supervisor-portal-how-to-log-in-to-supervisor-portal) to know more.
2. Once logged in the Supervisor can perform the following actions:
   1. [Download file using file sharing option](https://oloid.help/en/articles/9690938-supervisor-portal-how-to-download-file-using-file-sharing-option).
   2. [Create and Manage User](https://oloid.help/en/collections/10092607-supervisor-portal-create-manage-users).
   3. [Create and manage Shared Credentials](https://oloid.help/en/collections/10092608-supervisor-portal-create-manage-shared-credentials).
