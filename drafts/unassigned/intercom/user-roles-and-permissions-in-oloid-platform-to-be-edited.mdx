Permissions are set using roles, which define the level of access for users and groups have to devices and settings within an organization and its sites/subsites.

## Oloid Admin

An Oloid Admin is a user with the predefined role of Platform Administrator, and does these tasks:

- managing users,
- access control
- tenant configuration.

## Tenant Admin

A Tenant Admin is a user who has complete access to Oloid platform and all the Oloid connected devices. You must be an Oloid user to be a Tenant Admin.

## Supervisor

A Supervisor is a user with onboarding rights on the app. They have admin mode access on Oloid Verify/Connect app. A supervisor cannot access the Oloid Platform.

## Oloid End User

All users added to Oloid Platform are *Oloid Users*. A user added to the platform who has not been made an Admin or Supervisor has the minimum level of access rights.

Oloid End User access allows you to:

- Sign and set password in Oloid App.
- Use Oloid Verify/Connect App for Access Control.
- Use Passwordless App for Okta Login.
