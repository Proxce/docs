## Introduction

Connections are collections of users associated with an application. Adding connections allows administrators to define which users can access the application using passwordless login.

## Prerequisites

- A **Passwordless application** of type **Windows Login** has been created. For further details, refer [How to create a Windows Login Application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#:~:text=2%20weeks%20ago-,Steps%20to%20create%20and%20configure%20Windows%20Login%20application%3A,-Log%20in%20to).
- At least one connection is created. For further details, refer [How to Create a Connection.](https://oloid.help/en/articles/8294297-how-to-create-connections-in-the-tenant-admin-portal)

## Steps to add Connections

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click the **Windows Login application** you want to edit.
   ![How to add Connections in Windows Login... - screenshot 1](/images/intercom/10756940/image-272a5aa5.png)
   The application details page is displayed.
3. Go to **Connections** tab > select **+Add Connections**.
   ![How to add Connections in Windows Login... - screenshot 2](/images/intercom/10756940/4fd97409-fe11-4542-99a6-f7c94eb1c765-53a31fa8.png)
   The **Add Connections** pop-up box is displayed.
4. Do the following:
   1. Select **Connection**(s) from Connection drop-down list.
   2. Click **Add**.

      <Note>
        **Note:** An application can have up to 5 connections, all of which must be either PC/SC-enabled or none at all-mixing connection types is not allowed.
      </Note>

      ![How to add Connections in Windows Login... - screenshot 3](/images/intercom/10756940/image-fa2a5486.png)
      The Connection is successfully added to the application and listed in the connections list.
      ![How to add Connections in Windows Login... - screenshot 4](/images/intercom/10756940/b4a96eb4-588e-4718-a6fa-e65fa055545e-2031dfb8.png)
