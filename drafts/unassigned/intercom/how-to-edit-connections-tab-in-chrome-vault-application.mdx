**Pre-requisite:**

You must create a Passwordless application of type Chrome Vault. For further details, refer How to create [How to create and configure Chrome Vault application](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application)

Steps to edit Connections tab:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, click on the Chrome Vault application to edit.
   ![How to edit Connections tab in Chrome... - screenshot 1](/images/intercom/10832713/image-6525c9a9.png)
   The application page is displayed.
   ![How to edit Connections tab in Chrome... - screenshot 2](/images/intercom/10832713/60d8d1ba-ab28-4af7-92f8-9ca7013f14b4-a10bdde4.png)
3. Go to **Connections** tab > Select **+ Add Connections**.
   ![How to edit Connections tab in Chrome... - screenshot 3](/images/intercom/10832713/12661c8a-dc7c-4322-ac00-61ed16b6d7ee-d1182d5e.png)
4. On the **Add Connections** pop-up box, select connection name(s) from the **Select Connection** dropdown list and click **Add**.
   ![How to edit Connections tab in Chrome... - screenshot 4](/images/intercom/10832713/image-6d467d31.png)
