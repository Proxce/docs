Follow the below steps to configure CloudKey .

1. Login to the Oloid Platform using your credentials.
2. Go to Settings> Advanced> CloudKey and configure CloudKey for the tenant. For detailed instructions, see [How to configure CloudKey](https://oloid.help/en/articles/8803628-how-to-configure-cloudkey) guide.
3. Create a CloudKey endpoint after Tenant CloudKey configuration. For detailed instructions, see [How to add a CloudKey endpoint](https://oloid.help/en/articles/8263138-how-to-add-a-cloudkey-endpoint) guide.

   <Note>
     **Note:** Once Endpoint is created successfully , add location to the endpoint. Refer to [How to add location to the endpoint](https://oloid.help/en/articles/8223212-how-to-add-location-to-the-endpoint) guide. For additional guides on location , refer to **[Create and Manage Locations](https://oloid.help/en/collections/6445616-create-and-manage-locations) .**This is important to ensure that the proximity settings work to display the nearest CloudKey.
   </Note>

   Also, Workflow instance needs to be deployed and running where this CloudKey endpoint is mapped and use the same door ID from workflow while creating the endpoint.
4. Assign the CloudKey to the user. For detailed instructions, see [How to add Cloudkey as credential to users](https://oloid.help/en/articles/8290091-how-to-add-cloudkey-as-credential-to-users) guide.
   The CloudKey is configured and ready to use.
