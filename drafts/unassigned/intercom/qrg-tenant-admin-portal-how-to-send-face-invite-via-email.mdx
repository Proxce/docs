## Steps to Send Face Invite via SMS

1. Log in to the **Tenant Admin Portal**.
2. Go to **Directory > Users >** click **Action.**
   ![How to Send Face Invite via Email - screenshot 1](/images/intercom/13339835/image-6f2000f6.png)
   The action drop-down list is displayed.
3. Click **Send Invite > Invite to add Face > Send invitation via Email**.
   ![How to Send Face Invite via Email - screenshot 2](/images/intercom/13339835/image-54f77004.png)
   The SMS Invitation Preview pop-up box is displayed.
4. Do the following:
   1. Select either Connection or Group.
   2. Choose applicable connection/group from the drop-down list.
   3. Click Next.
   4. Update the SMS (if needed).
   5. Click **Send**.
      ![How to Send Face Invite via Email - screenshot 3](/images/intercom/13339835/b5e81aa2-b166-443b-9e64-bab030c34bd8-07c50c72.png)
      The QR code is created successfully.
