**Pre-requisite:**

You must create a Passwordless application of type WebKey. For further details, refer [How to create a WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)

Steps to edit Connections tab:

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Webkey application to edit.
   ![How to edit Connections tab in WebKey... - screenshot 1](/images/intercom/10801745/image-d74a8c32.png)
   The application page is displayed.
   ![How to edit Connections tab in WebKey... - screenshot 2](/images/intercom/10801745/image-689e0220.png)
3. Go to **Connections** tab > Click **Add Connections**.
   ![How to edit Connections tab in WebKey... - screenshot 3](/images/intercom/10801745/image-c031deb4.png)
   The Connections page is displayed.
4. Do the following:
   1. Select **+ Add Connections** to map a connection to the application.
   2. On the **Add Connections** pop-up box, select connection name(s) from the **Select Connection** dropdown list and click **Add**.
      ![How to edit Connections tab in WebKey... - screenshot 4](/images/intercom/10801745/image-c3fef77f.png)
      A connection is created successfully and listed on the **Connections** page.
