## Add and configure Rule

Steps to add and configure rule in MFA:

1. Login to **Oloid Portal.**
   The homepage is displayed
2. Click **Auth Policies** > **Factor Sequencing.**
   The **Factor Sequence for MFA App** page is displayed.
3. Select **Factor Sequence Name** to edit.
   The details page is displayed.
4. Click **Policy Rules** > **Add Rule.**

   <Note>
     **Note:** You can add multiple rules for MFA.
   </Note>

5. Select Credentials for **Factor 1** and **Factor 2.**

   <Note>
     **Note:** You cannot select the same credential for Factor 1 and Factor 2.
   </Note>

   1. Click **Save.**
      The Rule is saved successfully.
   2. Click ![How to add rule for Multifactor... - screenshot 1](/images/intercom/9738953/image-b54b21a9.png) icon to **Drag and change the priority sequence.**

      <Note>
        **Note:** The system will read the rules following the priority sequence.
      </Note>

## MFA Workflow

MFA Rule is set as :

Factor 1: Badge and Factor 2: PIN

<Note>
  **Note:** The user has to select the factors that are set in the Policy Rules.
</Note>

Steps to Check-in with MFA:

1. Login to **HRMS Portal.**
   The login page is displayed.
2. Select **Badge.**
3. Scan the **Badge at the Reader.**
   The Identify is verified.
4. The Welcome page for Factor 2 authentication is displayed.
5. Select **PIN.**
6. Enter **PIN.**
   The confirmation pop-up page is displayed.
   You are logged in successfully.
