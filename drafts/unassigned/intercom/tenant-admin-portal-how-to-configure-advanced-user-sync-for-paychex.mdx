## Introduction

This document describes how to configure Advanced User Sync for Paychex - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- An **Advanced User Sync profile for Paychex - Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for Paychex - Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.
   ![How to Configure Advanced User Sync for... - screenshot 1](/images/intercom/15886736/image-0b56f77e.png)
   The **Advanced User Sync** page is displayed.
3. Select the preferred Paychex - Inbound Advanced User Sync.
   ![How to Configure Advanced User Sync for... - screenshot 2](/images/intercom/15886736/image-880493a0.png)
   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
5. Click **Activate**.
   ![How to Configure Advanced User Sync for... - screenshot 3](/images/intercom/15886736/image-ef8b6669.png)
   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 4](/images/intercom/15886736/image-81ce9ca9.png)
   The Advanced User Sync is configured and activated successfully.
7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![How to Configure Advanced User Sync for... - screenshot 5](/images/intercom/15886736/image-0e07c558.png)
   The **Sync Now?** pop-up box is displayed.
8. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 6](/images/intercom/15886736/image-2e197d43.png)
   The **Success** pop-up box is displayed.
   ![How to Configure Advanced User Sync for... - screenshot 7](/images/intercom/15886736/image-84a08d11.png)
   The Advanced User Sync for Okta - Inbound is configured successfully.
   ![How to Configure Advanced User Sync for... - screenshot 8](/images/intercom/15886736/image-2abfa483.png)

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (if required).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 9](/images/intercom/15886736/image-dd0d7973.png)
   The Details tab is configured successfully.

### Setup Configuration Tab

This tab is used to map user data from **Paychex** to **Oloid** and select the Oloid connection where users are added during the inbound user sync.

Do the following:

1. Select the data mapper table from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. On **Add Users to Selected Connection**, do one of the following:
   1. Select the **Connection** option, and then select the required **Connection** from the drop-down list.
      **Note: (Optional)** Select **Group** from the Groups drop-down to add users only to the selected groups.
      OR
   2. Select the **Data Filter Table** option, and then select the required **Data Filter Table** from the drop-down list.

      <Note>
        **Note:** Click **View Tables** to review or create a data filter table, if required.
      </Note>

3. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 10](/images/intercom/15886736/image-83168143.png)
   The Configuration tab is configured successfully.

### Configure Account Tab

This tab is used to add and configure the **Okta** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**.
2. Enter **Token Endpoint**.
3. Enter **API URL**.

   <Note>
     **Note:** Enter the API URL https://api.n1.paychex.com/companies.
   </Note>

4. Enter **Company ID**.
5. Enter **Client ID**.
6. Enter **Client Secret**.

   <Note>
     **Note:** Contact Oloid support for **Token Endpoint, Organization ID**, Company ID **Client ID** and **Client Secret**.
   </Note>

7. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 11](/images/intercom/15886736/image-b5519493.png)
   The Account tab is configured successfully.
8. Click **Test**.
   ![How to Configure Advanced User Sync for... - screenshot 12](/images/intercom/15886736/image-ef9ae021.png)
   The **Success** pop-up box is displayed.

   ![How to Configure Advanced User Sync for... - screenshot 13](/images/intercom/15886736/image-781687ab.png)

### Configure Schedule Tab

This tab is used to define when the **Okta – Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![How to Configure Advanced User Sync for... - screenshot 14](/images/intercom/15886736/image-e40c53b0.png)

The Schedule tab is configured successfully.

#### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 15](/images/intercom/15886736/image-8170ea1f.png)
   The **Repeat Every** section is configured successfully.

### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![How to Configure Advanced User Sync for... - screenshot 16](/images/intercom/15886736/image-7731a9dd.png)

The **Run Once When Activated** section is configured successfully.
