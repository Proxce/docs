Introduction

The Web Button is used to review punches in Oloid Verify and Oloid Connect.

Steps to configure Web Button:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![Supervisor Portal- How to configure Web... - screenshot 1](/images/intercom/10363804/72aa84db-f3e8-4d3a-93b6-8b2b88cafede-60f1902f.png)
   The Endpoints page is displayed.
3. Click on an endpoint name (Verify endpoint/ Connect endpoint) to edit from the listed endpoints.
   ![Supervisor Portal- How to configure Web... - screenshot 2](/images/intercom/10363804/55bb6400-9dda-4350-9eec-95e5700b4311-6379de7e.png)
   The Endpoint details page is displayed.
4. Go to **Settings** tab **> Web Button**.
   ![Supervisor Portal- How to configure Web... - screenshot 3](/images/intercom/10363804/c295af27-a3cc-4207-852a-e992248a1fbb-2269f469.png)
5. On the Web Button tab, do the following:
   1. Turn on the **Enable Web Button**.
   2. Enter URL in the **URL** text field.

      <Note>
        **Note:** The URL leads you to the website where you can review the punches.
      </Note>

   3. Enter **Timeout**.
   4. Show only on Auth- *Coming soon.*
   5. Enable **Auto Launch** to automatically launch the web button and view transaction.
6. Click **Save**.
   **Sample screen for Web Button**
   ![Supervisor Portal- How to configure Web... - screenshot 4](/images/intercom/10363804/a12b9c2a-40da-4f5b-aeaa-83f54c6a055a-10fab320.png)

The Web Button is configured.
