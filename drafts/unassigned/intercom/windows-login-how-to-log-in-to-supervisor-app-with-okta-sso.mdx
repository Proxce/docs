## Introduction

This document provides step-by-step instructions for logging in to the Supervisor App using Okta SSO. When SSO is enabled, users can authenticate using their Okta account credentials to securely access the Supervisor App.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- You must have a valid **Okta account**.
- Ensure SSO is enabled in the Tenant Admin Portal. For more information, refer: [Windows Login - How to Enable OKTA Multi-Factor Authentication (MFA) Credential for Windows Login in the Tenant Admin Portal](https://oloid.help/en/articles/12888385-windows-login-how-to-enable-okta-multi-factor-authentication-mfa-credential-for-windows-login-in-the-tenant-admin-portal)

## Steps to login with Okta SSO

1. Double-click on the **Supervisor App** to start.
   ![How to log in to Supervisor App with... - screenshot 1](/images/intercom/9555730/image-78170438.png)
   The Login screen is displayed.
2. Click **Login with SSO.**
   ![How to log in to Supervisor App with... - screenshot 2](/images/intercom/9555730/image-765f07e5.png)
   The configured Login options are displayed.
3. Select **Login with Okta** to log into Supervisor app.
   ![How to log in to Supervisor App with... - screenshot 3](/images/intercom/9555730/image-5377f573.png)
   The **Sign in** page is displayed.
4. Enter **Username.**
5. Click **Next.**
   The **Welcome** page is displayed.
   ![How to log in to Supervisor App with... - screenshot 4](/images/intercom/9555730/image-1bbf51d2.png)
6. Enter **Password.**
7. Click **Sign in.**
   ![How to log in to Supervisor App with... - screenshot 5](/images/intercom/9555730/image-727b8f46.png)
   You are logged into the Supervisor app.
   ![How to log in to Supervisor App with... - screenshot 6](/images/intercom/9555730/image-6e846f4d.png)
