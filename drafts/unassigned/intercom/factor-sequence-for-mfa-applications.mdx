Multifactor authentication (MFA) means that users must verify their identity in two or

more ways to gain access to their account. MFA is used to add a security layer to the

authentication process.

Adding authenticators with different factor types and method characteristics strengthens

your MFA strategy. You may be required to define different behaviors for different sets

of users while doing the authentication. These can be configured by creating a Factor

Sequence with Policies and Rules for an Application.

## Steps to create a factor sequence

1. Login to Admin Portal.
2. Click **Home** > **Factor Sequence.**
   ![Factor Sequence for MFA Applications - screenshot 1](/images/intercom/8794094/image-a708d666.png)
3. Click **Create Factor Sequence** and fill in the details in the Pop-up that appears.
   All the fields here are mandatory and cannot be modified (except for the name),
   once the Factor Sequence is created.
   ![Factor Sequence for MFA Applications - screenshot 2](/images/intercom/8794094/image-3360c218.png)
   ![Factor Sequence for MFA Applications - screenshot 3](/images/intercom/8794094/image-38055df2.png)
4. Once the sequence is created, you may choose to add a description. Move to the
   next tab, i.e., **Policy**. Oloid supports Connection based Policy creation. Create
   policies based on user sets on which similar rules must be applied during
   authentication.
   ![Factor Sequence for MFA Applications - screenshot 4](/images/intercom/8794094/image-1e417fba.png)
   ![Factor Sequence for MFA Applications - screenshot 5](/images/intercom/8794094/h-evg9bwXSzbHwMyVNI9SFjGEzRyJffTc1FOVwUKmBqWc3zc-eb184221.png)
5. Move on to the **Rules** tab.
   **Add rule**, select at least one 1st factor, select a connection policy, and define the
   outcome, which could be user set going to 2nd factor or direct login. There is no
   limit on the number of policies that you can create.
   ![Factor Sequence for MFA Applications - screenshot 6](/images/intercom/8794094/b1zjjfeWJwtu70CvavNcggL-9fZjAFcmVRSqNcqaBW4vNnjQ-3a6a36ca.png)
6. Click on **Save**.
   You have successfully created a Factor Sequence Attached to the selected MFA
   Application. All the Endpoints run by the attached Application will now follow the
   Factor Sequence Policies and Rules.
   Please note that if a Factor Sequence is deleted, the Application can no longer
   perform any MFA actions on its Endpoints.
