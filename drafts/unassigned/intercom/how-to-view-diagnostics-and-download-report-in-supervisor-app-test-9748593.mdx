You can view and download diagnostics report from Supervisor app in the following ways

- Using Network Diagnostics
- Using Settings Feature

## How to view diagnostics and download report from Network Diagnostics

### To view diagnostics and download report

1. Double-click on Supervisor app.
   The app opens.
2. Click on **More Options** > **Network Diagnostics**.
   ![How to view diagnostics and download... - screenshot 1](/images/intercom/9748593/image-6637cbfe.png)
   The **Diagnostics** screen opens.
   You can view all the active URLs.
3. Type **Custom URL** in the text field and press **Enter**. (Optional)
   ![How to view diagnostics and download... - screenshot 2](/images/intercom/9748593/image-e7ece93f.png)
4. Do the following:
   1. Click **Diagnose** to refresh the URLs.
      ![How to view diagnostics and download... - screenshot 3](/images/intercom/9748593/image-ea9b7f7f.png)
      The URLs get refreshed with status.
   2. Click **Download Report** to download the diagnostic report.
      ![How to view diagnostics and download... - screenshot 4](/images/intercom/9748593/image-1623a36c.png)
      The diagnostic report is successfully downloaded to the local device.

## How to view diagnostics and download report from Settings

### To view diagnostics and download report

1. Double-click on Supervisor app.
   The app opens.
2. Log in to **Supervisor App**.
   The **Admin Home** screen opens.
3. Click **Settings**.
   ![How to view diagnostics and download... - screenshot 5](/images/intercom/9748593/image-d884431e.png)
   The **Settings** screen opens.
4. Click **Diagnostics**.
   ![How to view diagnostics and download... - screenshot 6](/images/intercom/9748593/image-e84e60cd.png)
5. The **Diagnostics** screen opens.
   You can view all the active URLs.
6. Type **Custom URL** in the text field and press **Enter**. (Optional)
   ![How to view diagnostics and download... - screenshot 7](/images/intercom/9748593/image-e7ece93f.png)
7. Do the following:
   1. Click **Diagnose** to refresh the URLs.
      ![How to view diagnostics and download... - screenshot 8](/images/intercom/9748593/image-ea9b7f7f.png)
      The URLs get refreshed with status.
   2. Click **Download Report** to download the diagnostic report.
      ![How to view diagnostics and download... - screenshot 9](/images/intercom/9748593/image-1623a36c.png)
      The diagnostic report is successfully downloaded to the local device.
