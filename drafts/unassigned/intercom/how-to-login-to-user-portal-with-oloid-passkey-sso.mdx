## Introduction

With Oloid Passkey SSO, users can access the Oloid User portal without entering traditional credentials, ensuring a faster and more secure login process.

## Prerequisites

Ensure the following prerequisites are met before logging in to the User Portal using Oloid Passkey SSO:

- You have the **login URL** provided to access the User portal.
- Ensure Oloid Passkey is created for the user. For more, refer: [How to Generate Oloid Passkey in the User Portal](https://oloid.help/en/articles/13884380-oloid-user-portal-how-to-generate-oloid-passkey-in-the-user-portal)
- Ensure Passkey is enabled for the User from the Tenant Admin Portal. For more, refer: [How to Enable Passkey SSO in Tenant Admin Portal](https://oloid.help/en/articles/13856829-how-to-enable-passkey-sso-in-tenant-admin-portal)

## Steps to log into User Portal using Oloid Passkey SSO

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**.
   The configured Log in options are displayed.
3. Click **Login with SSO**.
   ![How to Login to User Portal with Oloid... - screenshot 1](/images/intercom/13884773/image-1d357b1a.png)
   The Authentication screen is displayed.
4. Click **Continue with Passkey.**
   ![How to Login to User Portal with Oloid... - screenshot 2](/images/intercom/13884773/image-d5a08e98.png)
   The Oloid Passkey login page is displayed.

Enter **Email ID** > click **Next**.

![How to Login to User Portal with Oloid... - screenshot 3](/images/intercom/13884773/image-9acadbb9.png)

The user is authenticated using passkey.

![How to Login to User Portal with Oloid... - screenshot 4](/images/intercom/13884773/image-c018d1ad.png)

User is logged into User Portal.
