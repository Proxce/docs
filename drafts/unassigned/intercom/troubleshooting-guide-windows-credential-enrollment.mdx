## Introduction

This guide helps resolve authentication issues encountered while:

- Logging into a Windows machine using Oloid
- Performing self-enrollment

Follow the steps based on the specific error message displayed.

## Error 1: Invalid or Missing Windows Credential

Error Message: **“Invalid or Missing Windows Credential”**

### Description

This error occurs when the system is unable to validate the stored Windows credentials for the user.

---

#### Resolution Steps

##### Step 1: Check for Recent Password Change

- Ask the user or supervisor/admin:
  - Has the user **recently changed their Windows password**?

---

##### If YES (Password Changed Recently)

- Instruct the user to:
  1. Click the **Edit** option displayed next to their name (below the error message)
  2. Update the **new Windows password**
  3. Retry login

---

##### If NO (Password Not Changed)

Proceed with the following checks:

---

#### Step 2: Verify Windows Login Manually

- Ask the supervisor/admin to check:
  - Can the user log into the Windows machine using their password?

---

##### If NO (Login Fails)

- Action:
  - Contact IT team to **reset the user’s password**
  - After reset:
    - Update credentials using the **Edit** option
    - Retry login

---

##### If YES (Login Successful)

- Action:
  1. Log in to the Tenant Admin Portal
  2. Delete the user’s stored credentials
  3. Ask the user to:
     - Re-enter credentials using the **Edit** option
     - Retry login
