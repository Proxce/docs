**Pre-requisite:**

You must create a Passwordless application of type Windows Login. For further details, refer [How to create a Windows Login Application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#:~:text=2%20weeks%20ago-,Steps%20to%20create%20and%20configure%20Windows%20Login%20application%3A,-Log%20in%20to)

Steps to edit Health Setup tab:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, click on an Windows application to edit.
   ![How to edit Health Setup tab in Windows... - screenshot 1](/images/intercom/10796420/image-de61b09c.png)
   The application page is displayed.
   ![How to edit Health Setup tab in Windows... - screenshot 2](/images/intercom/10796420/a245efc8-2132-4bca-848f-0c07447f2c4c-faea0bc2.png)
   Do the following:
3. Click > **Health Setup** tab.
   1. Enter **Server Name**.
   2. Enter URL in **Add URL that needs to be monitored** field. > click **Add**.
      The Server Name is added and the Health Setup tab is configured successfully.
