**Multimodal Multi-Modal Authentication** refers to an authentication approach that combines multiple modalities or methods to verify a user's identity. Each modality serves as an independent layer of verification, enhancing security and user convenience. Multimodal authentication in Oloid platform enables users to choose from various available methods or use multiple methods in combination.

## Available Onboarding Methods in Oloid

Oloid supports a range of onboarding methods for authentication and identity management. These include:

1. **Face Recognition**:
   - Uses facial biometrics to verify the user's identity.
   - Requires the user to enroll their facial data during onboarding.
   - Provides a seamless, contactless authentication experience.
2. **Badge Authentication**:
   - Leverages existing employee ID badges.
   - Compatible with RFID and other smart badge technologies.
   - Users can scan their badge for authentication.
3. **NFC (Near Field Communication)**:
   - Uses NFC-enabled devices or badges for secure authentication.
   - Typically involves tapping an NFC-enabled badge or smartphone on a reader.
4. **QR Code Authentication**:
   - Users are issued unique QR codes for identification.
   - Scanning the QR code allows access or authentication.
   - Convenient for users without badges or biometric registration.
5. **Windows Password Authentication**:
   - Integrates with Windows credentials.
   - Users can authenticate using their domain password.
   - Useful for secure access to workplace systems and networks.
6. **Vault Passwords**:
   - Centralized password management for secure credentials storage.
   - Users can authenticate by retrieving and using credentials stored in a vault.
   - Typically used for accessing shared or sensitive resources.

## Benefits of Multimodal Authentication in Oloid

- **Flexible Options**: Users can select a modality that best suits their preferences or circumstances.
- **Enhanced Security**: Combines multiple factors (e.g., biometric + possession-based methods) for robust identity verification.
- **Streamlined Onboarding**: Multiple methods ensure users with varying technology access levels can onboard easily.
- **Contactless and Hygienic**: Face recognition, NFC, and QR codes enable touch-free authentication, promoting hygiene in shared spaces.
