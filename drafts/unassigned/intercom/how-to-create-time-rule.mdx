## Introduction

The Time Rule feature allows the Admin to create custom work schedule for the user. Once the Time Rule is added to a user, it overrides the regular time clocking logic set in the backend.

## Steps to create Time Rule

1. Log in to the **Oloid Portal**.
2. On the homepage, select **Time Interpretation** from the left menu panel.
   ![How to create Time Rule - screenshot 1](/images/intercom/10741035/8607edd8-97ec-4016-b65a-6e06ae598c50-dce85962.png)
   The **Time Interpretation** page is displayed.
3. Click **Create Time Rule** from the top right.
   ![How to create Time Rule - screenshot 2](/images/intercom/10741035/56f6127c-0f62-4520-bd55-2bff0e0674b3-758956b6.png)
   The **Create a new Time Rule** pop-up box is displayed.
4. Do the following:
   ![How to create Time Rule - screenshot 3](/images/intercom/10741035/image-20e0f8bf.png)
   1. Enter name in **Rule Name** field.
   2. Select type from the **Rule Type** dropdown list.
   3. Select location from the **Location** dropdown list.

      <Note>
        **Note:** To add location in the list, see How to add Location for the Time Rule. (Link to be added)
      </Note>

   4. Click **Create**.
      The Time Rule is created and listed in Time Interpretation page.
      ![How to create Time Rule - screenshot 4](/images/intercom/10741035/image-0e0e4774.png)

      <Note>
        **Note:** All punches must be within the time frame set in the Time Rule to work as per the condition applied in the backend. If the user tries to punch for any activity (Punch in, Lunch in, Lunch out, Punch out etc) outside the timeline, in that case the punches will not be registered and an error transaction will be lodged.
      </Note>

      To know more about configuring time rule, see How to configure Time Rule.
