## Steps to create transaction Ad-Hoc Report

1. Log in to the Tenant Admin Portal.
2. Click **Report** from the left menu panel > click **Ad-Hoc** report.
   ![How to create transaction Ad-Hoc report - screenshot 2](/images/intercom/13333813/image-a13e576e.png)
3. Click **transaction report** > click **create report**.
   ![How to create transaction Ad-Hoc report - screenshot 3](/images/intercom/13333813/image-da428c6c.png)
   The create transaction report pop-up box is displayed.
4. Do the following on the pop-up box:
   1. Select the date and time from the calendar for **From Date & Time** and **To Date Time.** (optional)
   2. Select time-zone from **Time-zone** drop-down list.(optional)
   3. Select transaction status from **Transaction Status** drop-down list.(optional)
   4. Select application names from **Application Names** drop-down list.(optional)

      <Note>
        **Note:** Click the **Use Application Time** checkbox to show transactions based on the time-zone set in the application.
      </Note>

   5. Select endpoint names from **Endpoint Names** drop-down list.(optional)
   6. Enter **Primary ID**.(optional)
   7. Select Mode from **Mode** drop-down list.(optional)
   8. Select face match status from **Face Match Status** drop-down list.(optional)
   9. Click **Download**.
      ![How to create transaction Ad-Hoc report - screenshot 4](/images/intercom/13333813/image-96aa53a1.png)

The **transaction report** is saved to the local device and listed on the **Ad-Hoc Reports** page.
