**Pre-requisite:**

You must create a Passwordless application of type Chrome Vault. For further details, refer How to create [How to create and configure Chrome Vault application](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application)

Steps to edit Configure tab:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, click on the Chrome Vault application to edit.
   ![How to edit Configure tab in Chrome... - screenshot 1](/images/intercom/10832515/image-6525c9a9.png)
   The application page is displayed.
   ![How to edit Configure tab in Chrome... - screenshot 2](/images/intercom/10832515/712f3912-141f-4123-96dc-d85cf6d3e26a-fe80a89b.png)
3. Go to **Configure** tab > Click **Settings**.
   ![How to edit Configure tab in Chrome... - screenshot 3](/images/intercom/10832515/7985d441-eebc-4d7d-93b2-a0fd55c27242-156a8b96.png)

Do the following:

## Configure Settings Tab

## Vault Behavior

- **Enable Auto-Submit:** Select this option to allow automatic login using saved passwords from Chrome Vault without clicking Submit.
  ![How to edit Configure tab in Chrome... - screenshot 4](/images/intercom/10832515/1a39da5f-b337-4567-a553-5ffed532c31f-6e9f3260.png)
- **Enable Copy Password:** Select this option to allow users to copy passwords from the Chrome Vault home page after logging in.
  ![How to edit Configure tab in Chrome... - screenshot 5](/images/intercom/10832515/a9a6a05d-cfe6-4519-a55b-bc29a5f94607-0d009a7a.png)

**Enable Face Camera to open in a new Tab:** Select this option to open the face camera in a new tab for Chrome Vault users.

![How to edit Configure tab in Chrome... - screenshot 6](/images/intercom/10832515/64fb8b50-4faa-46dc-8ee3-3387e9ae7414-f81e66af.png)

## Set Time-out durations for Re-authentication

- ![How to edit Configure tab in Chrome... - screenshot 7](/images/intercom/10832515/image-74e28bcd.png)
  - **Session Limit:** Set the maximum duration a user can remain signed into the Chrome Vault per session, up to a max of 55 mins.

**Inactivity Timer:** Enable this option to protect user sessions from unauthorized access. Set the timer to automatically log off the user after a specified period of inactivity.

## Apply Endpoint Template**:**

- ![How to edit Configure tab in Chrome... - screenshot 8](/images/intercom/10832515/image-75570d5d.png)

Select an endpoint template from the dropdown list to ensure the template is applied during endpoint pairing.
