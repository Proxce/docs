## Pre-requisite

- In Oloid Portal, you must enable **Allow Credential Updates and Enrollment** to enroll credentials in Windows Login app. For more details, refer to [How to enable Allow Credential Updates and Enrollment in Windows Login application](https://oloid.help/en/articles/10912821-oloid-portal-how-to-enable-credential-updates-and-enrollment-in-windows-login-application)
- Make sure either the user's Primary ID or email ID matches your System Account Name.

## Enroll Face

Steps to enroll face through Windows Login app:

1. On the Windows lock screen, click **Login with OLOID**.
   ![Windows Login app- How to enroll... - screenshot 1](/images/intercom/11424173/image-1863c32e.png)
   The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with Face**.
   ![Windows Login app- How to enroll... - screenshot 2](/images/intercom/11424173/image-59096d44.png)
   The Windows login app opens and the camera turns on.
3. Place your face in front of the camera for facial authentication.
   ![Windows Login app- How to enroll... - screenshot 3](/images/intercom/11424173/image-0c3d9755.png)
   The Face authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed** screen, select **Enroll Credential**.
   ![Windows Login app- How to enroll... - screenshot 4](/images/intercom/11424173/image-92e636fe.png)
   The **Verify using Windows Credential** screen is displayed.
5. Do the following:
   1. Enter **Domain\Username**.
      Enter your Windows domain and username in the format `Domain\Username`.
   2. Enter **Password**.
      Use your Windows account password.
   3. Select **Enroll Windows credential to your account**. (Optional)
   4. Click **Continue**.
      ![Windows Login app- How to enroll... - screenshot 5](/images/intercom/11424173/image-a7a45254.png)
      The **Select Credential to Enroll or Update** screen is displayed.
6. Select **Face**.

   <Note>
     **Note:** If connection is enabled, user consent is requested before uploading the picture.
   </Note>

   ![Windows Login app- How to enroll... - screenshot 6](/images/intercom/11424173/image-18f1f11e.png)
   The camera turns on.
7. Place your face in front of the camera for face authentication.
   ![Windows Login app- How to enroll... - screenshot 7](/images/intercom/11424173/image-0ac91c1d.png)
   Your face is automatically captured and it is enrolled successfully.
   ![Windows Login app- How to enroll... - screenshot 8](/images/intercom/11424173/image-672be44f.png)

## Enroll Badge

Steps to enroll badge through Windows Login app:

1. On the Windows lock screen, click **Login with OLOID**.
   ![Windows Login app- How to enroll... - screenshot 9](/images/intercom/11424173/image-1863c32e.png)
   The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with Badge**.
   ![Windows Login app- How to enroll... - screenshot 10](/images/intercom/11424173/image-35bf79b7.png)
3. Tap the **Badge** on the **Badge Reader** to scan it.

   <Note>
     **Note:** The badge reader must be connected to the computer.
   </Note>

   ![Windows Login app- How to enroll... - screenshot 11](/images/intercom/11424173/image-40fa50b7.png)
   The badge authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed** screen, select **Enroll Credential**.
   ![Windows Login app- How to enroll... - screenshot 12](/images/intercom/11424173/image-d1a02978.png)
   The **Verify using Windows Credential** screen is displayed.
5. Do the following:
   1. Enter **Domain\Username**.
      Enter your Windows domain and username in the format `Domain\Username`.
   2. Enter **Password**.
      Use your Windows account password.
   3. Select **Enroll Windows credential to your account**. (Optional)
   4. Click **Continue**.
      ![Windows Login app- How to enroll... - screenshot 13](/images/intercom/11424173/image-a7a45254.png)
      The **Select Credential to Enroll or Update** screen is displayed.
6. Select **Badge**.

   <Note>
     **Note:** You can also update the badge credential.
   </Note>

   ![Windows Login app- How to enroll... - screenshot 14](/images/intercom/11424173/image-36cc5289.png)
   The **Scan your Badge to Enroll** screen is displayed.
7. Scan your badge in the Badge Reader.
   ![Windows Login app- How to enroll... - screenshot 15](/images/intercom/11424173/image-3ddc77f0.png)
8. Click **Submit**.
   The badge is enrolled successfully.
   ![Windows Login app- How to enroll... - screenshot 16](/images/intercom/11424173/image-468c0a99.png)
