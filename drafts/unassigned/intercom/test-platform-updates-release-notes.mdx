## RELEASE UPDATE – September 2025

**Version 2**

## New / Updated Features

- **Connections Management in Tenant Admin Portal**
  Tenant Admins can now create and manage **Connections** to group users and control application access. This feature simplifies user-grouping and enhances access management.
  [Read the full guide ›](https://oloid.help/en/articles/8294297-how-to-create-connections-in-the-tenant-admin-portal?utm_source=chatgpt.com)
- **Add Users Directly from the Portal**
  Admins can add individual users through the **Directory → Create User** workflow. Optionally, set OloID as the primary ID or rely on ADP auto-sync for automatic user onboarding.
  [Read the full guide ›](https://oloid.help/en/articles/8185048-how-to-add-users-in-the-tenant-admin-portal?utm_source=chatgpt.com)
- **Deactivate Users with a Single Click**
  Quickly deactivate a user from the **Directory → Users** list using the **Action → Deactivate** option. Once confirmed, the user immediately loses active access.
  [Read the full guide ›](https://oloid.help/en/articles/8424258-how-to-deactivate-user-in-the-tenant-admin-portal?utm_source=chatgpt.com)
- **Endpoint Deactivation Made Easy**
  Admins can now deactivate endpoints from the **Endpoints** tab. After confirmation, the endpoint is archived and disabled.
  [Read the full guide ›](https://oloid.help/en/articles/8463355-how-to-deactivate-endpoint-in-the-tenant-admin-portal?utm_source=chatgpt.com)
