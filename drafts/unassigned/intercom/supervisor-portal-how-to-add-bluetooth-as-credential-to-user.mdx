## Introduction

Bluetooth ID is generated for the M-Tag application to function.

**Pre-requisite**

Badge ID should be assigned to the User. If a Badge ID is not assigned to the User, see **[How to assign Badge ID and create Bluetooth credentials](https://oloid.help/en/articles/9716833-supervisor-portal-how-to-assign-badge-id-and-create-bluetooth-credentials)**[.](https://oloid.help/en/articles/9716833-supervisor-portal-how-to-assign-badge-id-and-create-bluetooth-credentials)

Steps to add Bluetooth as credential:

1. Log in to the **Supervisor Portal.**
   The **Users** page is displayed.
2. Click the **username** to edit.
   ![Image](/images/intercom/9669712/7046f59b-7e08-4971-9372-8bd19055bc69-aea17ab3.png)
   The user details page is displayed.
   ![How to add Bluetooth as credential to... - screenshot 1](/images/intercom/9669712/image-c720c4c1.png)
3. Do one of the following:
   1. Go to **Credentials** > **Bluetooth** tab> + **Create Bluetooth**.
      ![How to add Bluetooth as credential to... - screenshot 2](/images/intercom/9669712/image-62a3dd15.png)
   2. Go to **Assign Credential** > **Create Bluetooth**.
      ![Image](/images/intercom/9669712/73f76c6c-f886-4730-8476-5994d571ebf4-de65174a.png)
      The **Create Bluetooth** pop-up box is displayed.
      ![How to add Bluetooth as credential to... - screenshot 3](/images/intercom/9669712/image-ea3927af.png)
4. Do the following:
   1. Select **Start Date / Time** and **End Date/Time** from the calendar.

      <Note>
        **Note:**

           You can click **Now** to set the current date and time. The end date is automatically set to 1 year from the current date.
           You can click **10 years from Now** to set the **End Date/Time** to 10 years from the current date/time.
        2. Click **Save**.
           The Bluetooth ID is created and listed on the **Bluetooth** tab.
           ![Image](/images/intercom/9669712/57f6813d-800a-41bb-a2bc-ff8fad5b8c80-968dfc80.png)
      </Note>
