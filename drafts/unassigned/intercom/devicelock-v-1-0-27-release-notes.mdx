## New Features

**Admin Module Enhancements**

- View and search users with improved list functionality, now including user images.
- Manage user faces: easily add or delete facial data.
- Display and update user consent with dynamic, real-time values for better compliance.

**Unified FR/QR Preview**

- Experience a single, streamlined preview screen for both Face Recognition (FR) and QR scanning for faster verification.

**Transaction Monitoring**

- Added `AllEndpointActionStatus` implementation for comprehensive transaction tracking and better diagnostics.

**Enhanced Background Operations**

- Introduced an Android service-backed queue system for efficient background processing.
- Improved background user management for smoother operation and better system responsiveness.

## Bug Fixes

- **Kiosk Mode**: Automatically exits kiosk mode after device unpairing.
- **Status Display**: Corrected overall status values for accurate reporting.
- **Transaction UI**: Fixed display of mode, device info, and connection name.
- **Kronos Integration**: Resolved QR code visibility issues and corrected employee ID and job code mapping.
- **Admin Interface**: Adjusted dimensions and margins for a cleaner, more consistent UI.
