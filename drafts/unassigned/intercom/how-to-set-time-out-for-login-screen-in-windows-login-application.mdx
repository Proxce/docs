## Introduction

In Oloid Portal, Set Time-out for Login Screen feature allows the Tenant Admin to set how long the Windows Login screen remains visible when there is no user response in the Windows Login app.

## Steps to set Time-out for Login Screen

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to Set Time-out for Login Screen in... - screenshot 1](/images/intercom/11059154/image-6eeaf72f.png)
   The application page is displayed.
   ![How to Set Time-out for Login Screen in... - screenshot 2](/images/intercom/11059154/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to Set Time-out for Login Screen in... - screenshot 3](/images/intercom/11059154/410243bb-dc49-47d9-9e5d-4aed95ebe6e5-32fa16eb.png)
4. **Set Time-out for login screen** in Hours, Mins, and sec for the Windows Login app. If there is no user activity, the login screen in the Windows Login application will time out and close automatically after the set time.
   ![How to Set Time-out for Login Screen in... - screenshot 4](/images/intercom/11059154/image-63a06fba.png)

5. Click **Save**.
   ![How to Set Time-out for Login Screen in... - screenshot 5](/images/intercom/11059154/fc3cb9cc-1726-4d48-8b91-4c79106cae19-d33f11fa.png)
   The configuration is saved successfully.

   <Note>
     **Note:** In **Windows Authenticator** app, you must sync the configuration to enable Set Time-out for Login Screen. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
   </Note>
