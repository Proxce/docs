### Introduction

The Online Intent Screen in Device Lock allows users to select predefined actions during authentication. It supports multi-button configuration, enabling organizations to capture user inputs such as department selection and activity type based on business requirements.

### Prerequisites

- You must have access to the Tenant Admin account.
- The **Device Lock** application must be created and configured in the Tenant Admin Portal. For more information, refer [How to Create and Configure DeviceLock Application in the Tenant Admin Portal](https://oloid.help/en/articles/8698213-how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal)

## Steps to Configure Online Intent Screen

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the DeviceLock application.
   ![How to Configure Online Intent Screen... - screenshot 1](/images/intercom/10419910/image-34fbe85a.png)
   The Application Details page is displayed
   ![How to Configure Online Intent Screen... - screenshot 2](/images/intercom/10419910/image-5eb04234.png)
3. Go to **Configure** tab > select **Online Intent Screen** from the left panel menu.
4. Turn on **Show Intent Screen** toggle.
   ![How to Configure Online Intent Screen... - screenshot 3](/images/intercom/10419910/image-38aeac4e.png)
   The show intent screen enabled successfully.
5. Select **Multi-button** option and do the following:
   1. Select **Choose Departments** to enable users to select a department.
   2. Select **Process data locally** to handle data processing locally.
      ![How to Configure Online Intent Screen... - screenshot 4](/images/intercom/10419910/image-fdfddac4.png)
6. Do the following:
   1. [Configure Intent Screen](#configure-intent-screen)
   2. Setup Departments
7. Click **Save**.
   The intent screen is configured successfully.

### Configure Intent Screen

1. Enter the intent screen title in the **Intent Screen Heading** field. This title appears at the top of the intent screen.
2. Enter a short and clear description in the Intent Screen Description field.

   2. [Configure Minimum Lunch Break Config](#configure-minimum-lunch-break-config)

#### Configure Minimum Lunch Break Config

You can configure the minimum lunch break requirements for the user.

<Note>
  **Note:** You must add Start Lunch and End Lunch button type in **Intent Screen Buttons** section before you configure minimum lunch break.
</Note>

1. **Lunch Break Validation Message**: Enter the message that will be displayed if the minimum lunch break requirement is not met. (See [Sample Screen](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen#h_2790fbae98) below)
2. **Minimum Lunch Break**: Set the minimum time for a lunch break, specifying hours and minutes. (See [Sample Screen](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen#h_2790fbae98) below)
3. Click **Save** to apply your changes.

### Configure Departments

You can configure a department section for users during the clock-in and clock-out process.

<Note>
  **Note:** Ensure that the Choose Departments is selected in the Multi-button section.
</Note>

1. Click **+Add Department** to create a new department.
   ![How to Configure Online Intent Screen... - screenshot 11](/images/intercom/10419910/ba85e7ea-740d-483b-9795-41a06a29a320-867635d1.png)
   The department detail is displayed.
2. Configure the following details:
   1. **Department Name**: Enter the department name.
   2. **Department Code**: Enter a department code.
   3. **Clock ID**: Enter the unique clock ID for the sub-department. (Optional)
   4. Click **Save** to apply your changes.

      <Note>
        **Note:** Repeat steps 1–2 for each department you want to add.
      </Note>

      ![How to Configure Online Intent Screen... - screenshot 12](/images/intercom/10419910/a553a303-7f3d-45b8-80a0-595039055ded-5ec0fa83.png)
