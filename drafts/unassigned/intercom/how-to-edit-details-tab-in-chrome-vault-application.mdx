**Pre-requisite:**

You must create a Passwordless application of type Chrome Vault. For further details, refer How to create [How to create and configure Chrome Vault application](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application)

Steps to edit Details tab:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, click on the Chrome Vault application to edit.
   ![How to edit Details tab in Chrome Vault... - screenshot 1](/images/intercom/10814228/image-6525c9a9.png)
   The application page is displayed.

![How to edit Details tab in Chrome Vault... - screenshot 2](/images/intercom/10814228/6e2e8ec5-540b-4414-b61d-ce4172aac2e5-2fe72ee9.png)

3. Do the following:

a. Edit **Application Name** if required.

b. Add **Description**. (Optional)

c. Select **Factor Sequence**. (Coming Soon)

d. Select **Time Zone** from the dropdown list. (Optional)

<Note>
  **Note:** These are one-time settings and all the default settings are recommended.
</Note>
