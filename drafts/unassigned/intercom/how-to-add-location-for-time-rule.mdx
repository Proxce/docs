Steps to add location for Time Rule:

1. Log in to the **Oloid Portal**.
2. On the homepage, select **Transactions**.
   ![How to add Location for Time Rule - screenshot 1](/images/intercom/10748160/154da87c-b2f8-421b-a452-b55ff21ba469-ce1c45b7.png)
   The **User Transactions** page is displayed.
3. Click **Location Settings** from the bottom left.
   ![Image](/images/intercom/10748160/b51e7faa-6dc2-47d2-8cdc-79c013533484-9def7612.png)
   The **Location Settings** page is displayed.
4. Click **Create Location** from the top right.
   ![How to add Location for Time Rule - screenshot 2](/images/intercom/10748160/image-e7f1d665.png)
   The **Create Location** pop-up box is displayed.
   ![How to add Location for Time Rule - screenshot 3](/images/intercom/10748160/image-99f95097.png)
5. Enter **Location Name**.
6. Click **Create**.
   The Location is created and listed in the page successfully.
