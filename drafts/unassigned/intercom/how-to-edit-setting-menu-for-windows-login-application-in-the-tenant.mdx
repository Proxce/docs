## Introduction

The Settings menu in the Windows Login application allows Tenant Admins to configure features that control the authentication process and user interaction with Windows devices. It provides options to manage login methods, credential handling, user activity capture, and recovery mechanisms, ensuring a secure and seamless login experience.

## Prerequisites

You must create a Windows Login application. For further details, refer [How to create a Windows Login Application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#:~:text=2%20weeks%20ago-,Steps%20to%20create%20and%20configure%20Windows%20Login%20application%3A,-Log%20in%20to).

## Steps to edit setting menu

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on a Windows Login application to edit.
   ![How to Edit setting menu for Windows... - screenshot 1](/images/intercom/12096020/image-6eeaf72f.png)
   The application page is displayed.
3. Go to **Configure** tab.
   ![How to Edit setting menu for Windows... - screenshot 2](/images/intercom/12096020/8f9f1b20-1a45-45d8-9a9b-5a1c41a72f16-91417975.png)
4. Enable **Auto Launch Mode** toggle to auto-launch the Windows Login app in the login screen.
   ![How to Edit setting menu for Windows... - screenshot 3](/images/intercom/12096020/image-d1adbcb4.png)
5. Enable **Use Groups for Authorization** toggleto allow authentication using only groups.
   ![How to Edit setting menu for Windows... - screenshot 4](/images/intercom/12096020/image-6c5f413d.png)
6. Enable **Validate Windows Credential** toggle to allow the Oloid Agent to validate, update or create Windows credentials before logging in.
   ![How to Edit setting menu for Windows... - screenshot 5](/images/intercom/12096020/image-0135b04b.png)
7. Enable **Passkeys** toggle to allow users to log in with a Passkey credential.
   ![How to Edit setting menu for Windows... - screenshot 6](/images/intercom/12096020/image-a3701825.png)
8. Enable **Allow Credential Updates and Enrolment** toggle to allow users to update or enrol credentials using Windows credentials.
   1. Enable **Hide option to save Windows credentials** toggle to remove the checkbox for saving Windows domain credentials to the Oloid account during enrolment.
   2. Select **Auto-save credentials on successful validation** checkbox to automatically save credentials when the Save option is hidden.
   3. Enable **Allow Login Through Local Credentials** toggle to allow users to log in to Windows using their local Windows credentials.
      ![How to Edit setting menu for Windows... - screenshot 7](/images/intercom/12096020/image-33ec2d76.png)
9. Enable **Capture Windows User Events** toggle to capture Windows events for user logins, logouts, locks, unlocks, and credential provider details. All captured data is stored in the transaction tab.
   ![How to Edit setting menu for Windows... - screenshot 8](/images/intercom/12096020/image-4646f247.png)
10. Enable **Auto-recover Endpoint toggle** to check the Endpoint configuration and automatically sync it when the Login module launches.
    ![How to Edit setting menu for Windows... - screenshot 9](/images/intercom/12096020/image-de749e82.png)
11. Enable **Manual Capture Accessibility** to allow users to manually capture their face during face authentication.
    ![How to Edit setting menu for Windows... - screenshot 10](/images/intercom/12096020/image-cea27b4f.png)
12. Enable **Auto Authentication of Webkey using Local Transaction** toggle to automatically authenticate the user into Webkey after device login.
    ![How to Edit setting menu for Windows... - screenshot 11](/images/intercom/12096020/image-e344c581.png)
13. Enable **Badge Out** toggle to allow users to lock or sign out of Windows using badge scan. For details, refer to [Windows Login - How to configure Enable Badge Out option](https://oloid.help/en/articles/10616183-windows-login-how-to-enable-badge-out-option).
    ![How to Edit setting menu for Windows... - screenshot 12](/images/intercom/12096020/image-257e87d9.png)
14. Set **Time-out for Login Screen** to define the maximum duration the system will wait on the login screen before timing out.
    ![How to Edit setting menu for Windows... - screenshot 13](/images/intercom/12096020/image-756e427c.png)
15. **Master Admin override passcode:** Follow the onscreen instruction to create master admin override passcode. For details, refer [How to create device-admin passcode for Supervisor App](https://oloid.help/en/articles/9244629-how-to-create-device-admin-passcode-for-supervisor-app).
    ![How to Edit setting menu for Windows... - screenshot 14](/images/intercom/12096020/image-410f3bf9.png)
16. **Apply Endpoint Template**: Select a Windows Login endpoint template that is applied during the endpoint pairing process.
    ![How to Edit setting menu for Windows... - screenshot 15](/images/intercom/12096020/image-d0974a45.png)
