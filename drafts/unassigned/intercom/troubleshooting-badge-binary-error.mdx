## Problem

Badge binary error while assigning badge to the user.

## Probable Cause

- Incorrect bit lengths
- Mismatched facility codes
- Invalid card data

## Solution

To troubleshoot the issue:

Go to Oloid Portal > users > credentials > Assign Badge.
Badge ID/ Secondary ID check as per the standard norms for the weigand format

Check if the weigand format selected is correct

Once it matches it will succesfully generate the badge binary.

**Solution:**
To troubleshoot the issue, follow these steps:

1. **Navigate to Badge Assignment Section**
   - Go to **Oloid Portal** > **Users** > **Credentials** > **Assign Badge**.
2. **Verify Badge Details**
   - Check the **Badge ID/Secondary ID** to ensure it complies with the standard norms for the Wiegand format.
3. **Validate Wiegand Format**
   - Confirm that the correct Wiegand format is selected.
4. **Generate Badge Binary**
   - Once all details match, the badge binary will successfully generate.
