**Pre-requisite**

You need to download the config file of the preferred endpoint from the Oloid Portal. For details, refer How to download endpoint config file for Chrome Vault application?

To pair an endpoint:

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar.
   ![How to pair using config file in admin... - screenshot 1](/images/intercom/9611988/4873aa59-1f6a-4da8-ae2b-aff94b3fb268-c678573c.png)
   The Chrome Vault home page is displayed.
   ![How to pair using config file in admin... - screenshot 2](/images/intercom/9611988/image-761644e3.png)
2. Go to **More** ![How to pair using config file in admin... - screenshot 3](/images/intercom/9611988/image-416117ef.png) option icon > **Admin Mode**.
   ![How to pair using config file in admin... - screenshot 4](/images/intercom/9611988/4ef84be2-075a-4b26-8212-a58ba0dfc030-97971ea7.png)
   The Chrome Vault login screen is displayed on a new tab.
3. Enter your credentials to log in to admin mode.
   ![How to pair using config file in admin... - screenshot 5](/images/intercom/9611988/7429704c-cd41-43f5-91ab-621dbeff88c8-073b522a.png)
   The Welcome screen is displayed.
4. Select **Pair Using Config File**.
5. Select the json file you want to upload and click **Open**.
   The device is paired successfully.
   ![How to pair using config file in admin... - screenshot 6](/images/intercom/9611988/image-651d0d61.png)
