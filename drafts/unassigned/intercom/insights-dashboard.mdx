## Introduction

The **Insights Dashboard** provides a unified view of user onboarding, endpoint performance, transaction activity, credential adoption, and scheduled reporting across your organization.

## Prerequisites

1. You must have a Tenant Admin account
2. Insights Dashboard flag must be enabled.

## Insights Dashboard Overview

The Insights Dashboard includes the following tabs:

1. **User Matrix**
2. **Endpoint Activity**
3. **Transaction Insights**
4. **Credentials**
5. **Reports**

Each tab includes dedicated analytics, visual charts, and export options designed to help administrators understand system usage and performance.

## 1. User Matrix

The **User Matrix** provides a complete overview of user onboarding, enrollment, and growth trends.

### Key Components

- **Onboarding Overview** – Tracks total users, credential enrollment, and enrollment percentages.
- **Onboarding Growth** – Shows user onboarding trends over selectable time periods.
- **Users Growth** – Displays how many users were added over time.

### Purpose

Use this section to monitor adoption, identify onboarding delays, and generate onboarding-related reports.

For detailed documentation, see: “Understanding the User Matrix in Insights”

---

## 2. Endpoint Activity

The **Endpoint Activity** tab provides real-time visibility into endpoint health, performance, and growth patterns.

### Key Components

- **Active Endpoint Health** – Displays endpoint health categories (Healthy, Critical, Unknown, Offline, etc.).
- **Endpoint Growth** – Tracks how many endpoints were added over a selected timeframe.
- **Endpoint Status** – Shows the count of active vs. inactive endpoints.

### Purpose

Use this tab to monitor operational devices, troubleshoot issues, and export endpoint health data.

For detailed documentation, see: “Endpoint Activity in Insights”

---

## 3. Transaction Insights

The **Transaction Insights** tab provides analytics on system transactions such as access attempts, authentication events, and other recorded activity.

### Key Components

- **Total Transactions** – All logged transactions over the selected timeline.
- **Successful vs. Failed Transactions** – Tracks access and authentication outcomes.
- **Transaction Trend Charts** – Visual timeline of activity.
- **Filters** – Filter by date range, location, endpoint, or transaction type.

### Purpose

Use this tab to audit usage behavior, identify anomalies, and understand authentication patterns.

For detailed documentation, see: “Transaction Insights Overview”

---

## 4. Credentials

The **Credentials** tab provides insights into how users are enrolling and using credentials.

### Key Components

- **Total Credentials** – All credentials created or active.
- **Credential Types** – Breakdown by Face, Passkey, Badge, or other supported types.
- **Enrollment Trends** – Charts showing growth in credential adoption.
- **Status Overview** – Active, expired, or unused credentials.

### Purpose

Use this tab to monitor credential adoption, manage user readiness, and export credential analytics.

For detailed documentation, see: “Credential Analytics in Insights”

---

## 5. Reports

The **Reports** tab includes tools for generating, scheduling, and downloading reports.

### Key Components

- **Scheduled Reports** – Automatically generated at set intervals.
- **Generated Reports** – Previously created reports available for download.
- **Report Filters and Schedules** – Configure frequency, recipients, and report details.

### Purpose

Use this tab to automate reporting and provide data summaries for compliance, audits, and leadership review.

For detailed documentation, see: “Reports in Insights”

## How the Tabs Work Together

These tabs provide a complete analytics ecosystem:

- **User Matrix** shows who is onboarded.
- **Credentials** shows what credentials they use.
- **Transaction Insights** shows how they interact with your system.
- **Endpoint Activity** shows the health of devices they use.
- **Reports** lets you export and automate all this data.

Together, they create a holistic view of your organization’s operational and security status.
