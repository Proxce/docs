The Oloid Supervisor Portal is a restricted-access section of the Tenant Admin Portal, granting supervisors limited privileges managed within the Tenant Admin Portal.

## Setting Up the Supervisor Role

Only users with **Tenant Admin** privileges can create and assign Supervisor roles. The process includes:

1. Logging in to the Oloid Portal as a Tenant Admin.
2. Navigating to **Tenant Settings** via the profile icon.
3. Opening the **Admin Controls** tab and selecting **Supervisors**.
4. Clicking **“Invite Supervisor”** to begin creating a new Supervisor profile.
5. Entering the required details and confirming the invitation.

After setup, Supervisors can log into the portal using supported Single Sign-On (SSO) providers like Google, Microsoft, or Okta, or with their registered email address.

Operations allowed for a Supervisor in the Supervisor Portal.

## 1. Accessing the Supervisor Portal

Supervisors can log in to the portal using Single Sign-On (SSO) methods, including Google, Microsoft, Okta, or their email account.

## 2. User Management

Supervisors have the ability to manage user accounts:

- **Add New Users**
- **Remove Users**
- **Activate or Deactivate Users**
- **Extend QR Code Expiry Dates**
- **Migrate Users to Different Connections**
- **Invite Users to Add Facial Recognition Data**
- **Onboard Facial Recognition for Single Users**
- **Find and View User Facial Data**
- **View and Download User Transactions**

## 3. Credential Management

Supervisors can manage various user credentials:

- **Generate and Delete QR Codes**
- **Assign or Remove Bluetooth Credentials**
- **Assign Badge ID, NFC/ID, or PIN Credentials**
- **Add CloudKey as Credential**
- **Assign Windows Shared Credentials to Multiple Users**
- **Create Vault Passwords**

## 4. Shared Credential Management

Supervisors can handle shared credentials:

- **Associate Users with Shared Credentials**
- **Assign Shared Credentials to Users or Multiple Users**
- **Create Passwords for Windows Login**
- **Add Credential Owners**
- **Create Shared Credentials for Windows Login**

## 5. Account Management

Supervisors are permitted to:

- **Create Oloid Accounts for Multiple Users**
- **Deactivate Oloid Accounts for Single or Multiple Users**
