## Steps to Create Users

1. Log in to the **Tenant Admin Portal**.
2. Go to **Directory > Users >** click **Create User**.
   ![How to Create Users - screenshot 1](/images/intercom/13333139/image-58cccb77.png)
   **Create User** Pop box is displayed.
3. Do the following:
   1. Enter **Full Name**.
   2. Enter **Primary ID**.

      <Note>
        **Note:** Select the checkbox, to use Oloid as Primary ID.
      </Note>

   3. Select **Connection** from the drop-down list.
   4. Click **Create**.
      ![How to Create Users - screenshot 2](/images/intercom/13333139/image-4c441b3c.png)
      The User is created successfully.
