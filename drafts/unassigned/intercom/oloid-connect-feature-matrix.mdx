## 🔍 Feature Details (Context)

Here’s what these capabilities mean in Oloid Connect terms:

- **Contactless authentication:** Enables users to clock in/out or log in using **Face, Badge, NFC, QR, or PIN** without traditional passwords. ([Oloid Help Center](https://oloid.help/en/articles/6903800-what-is-oloid-connect?utm_source=chatgpt.com))
- **Multi-factor authentication (MFA):** More secure workflows combining multiple factors (e.g., face + PIN). ([App Store](https://apps.apple.com/us/app/oloid-connect/id1507400421?utm_source=chatgpt.com))
- **Intent screen:** UI prompts for workforce actions like *Punch-In/Out, Start Shift*, etc. ([Oloid Help Center](https://oloid.help/en/articles/6903800-what-is-oloid-connect?utm_source=chatgpt.com))
- **Auto Pair:** Simplifies pairing devices/endpoints with the Connect application. ([App Store](https://apps.apple.com/us/app/oloid-connect/id1507400421?utm_source=chatgpt.com))
- **SSO for Admin/Supervisor:** Admins can log in via identity providers without pairing first. ([App Store](https://apps.apple.com/us/app/oloid-connect/id1507400421?utm_source=chatgpt.com))
- **Job Code Intent:** Supports tagging of clock events with job codes (useful in attendance and payroll workflows). ([App Store](https://apps.apple.com/us/app/oloid-connect/id1507400421?utm_source=chatgpt.com))
- **Security & stability:** Ongoing fixes for spoof protection, platform compatibility (e.g., iOS 26). ([App Store](https://apps.apple.com/us/app/oloid-connect/id1507400421?utm_source=chatgpt.com))
