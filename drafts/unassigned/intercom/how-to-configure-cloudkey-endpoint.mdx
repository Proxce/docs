## Steps to configure CloudKey Endpoint

1. Login to the **Oloid Portal**.
2. On the homepage, click **Endpoints** from the left menu panel.
   ![Image](/images/intercom/9847706/b81c4178-4ccf-481c-bba3-eb6696305376-cd1bef6e.png)
   The **Endpoints** page is displayed.
3. Click **CloudKey** endpoint name to edit.
   ![How to Configure CloudKey Endpoint - screenshot 1](/images/intercom/9847706/image-bd5da596.png)
   The **Endpoint details** page is displayed.
   ![How to Configure CloudKey Endpoint - screenshot 2](/images/intercom/9847706/image-6b05c144.png)
4. Configure the following:
   - **[Details](#configure-details-tab)**[Tab](#configure-details-tab)
   - **[Configure](#steps-to-configure-cloudkey-endpoint)**[Tab](#configure-details-tab)
   - **Transactions**[Tab](#configure-details-tab)
5. **Add Endpoint Location**

![How to Configure CloudKey Endpoint - screenshot 3](/images/intercom/9847706/image-edf60b2f.png)

Add the Endpoint Location. For more information on adding location, see **How to add location to the endpoint**.

The Endpoint is configured.

## Configure Details Tab

![Image](/images/intercom/9847706/21cba365-1017-49ce-a2f6-d62deae704e8-36f7c22a.png)

1. Edit **Endpoint Name**.
2. Enter **Endpoint Description**. (optional)
3. Select **Timezone** from the timezone dropdown list. (optional)
4. Click **Save**.

The Details tab is configured.

## Design Configure Tab

![How to Configure CloudKey Endpoint - screenshot 4](/images/intercom/9847706/image-a64625fd.png)

Do the following:

1. **[Endpoint Settings](#configure-endpoint-settings)**
2. **[Groups](#add-groups)**
3. **[Integration](#integration)**
   The Configure tab is designed.

### Configure Endpoint Settings

![How to Configure CloudKey Endpoint - screenshot 5](/images/intercom/9847706/image-45bf5bd4.png)

1. Edit **Door ID**.
2. Edit **Cloud Key UR**L.
3. Enable **Wait for Response** to allow the system wait for api response after CloudKey is triggered.
4. Click **Save**.
   The Endpoint Settings is successfully configured.

### Add Groups

![How to Configure CloudKey Endpoint - screenshot 6](/images/intercom/9847706/image-c79c3a29.png)

1. Click **+Add Group**.
   ![How to Configure CloudKey Endpoint - screenshot 7](/images/intercom/9847706/image-eb5aa9f6.png)
   The **Add Group** pop-up box is displayed.
2. Select **Group** from the dropdown list.
3. Click **Save**.
   The Group is added and listed in the Groups tab.
   ![Image](/images/intercom/9847706/3548f565-dd80-4040-bc9f-11c8d995dcbc-715d57c8.png)
