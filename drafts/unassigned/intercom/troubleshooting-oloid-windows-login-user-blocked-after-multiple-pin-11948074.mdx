**Introduction**

This document contains detailed troubleshooting steps for resolving the "User Blocked" issue encountered during login with PIN via the Oloid Windows Login application. It explains the causes of PIN lockout, outlines methods to unlock or reset the PIN, via **Tenant Admin portal** to regain access.

**Issue:**

The Oloid Windows Login application displays a “User Blocked” message after multiple incorrect PIN attempts, preventing the user from logging in using the PIN credential.

**Applies to:**

- Tenant Admin

**Cause:**

The PIN lockout issue may occur due to the following reason:

- The user has entered an incorrect PIN multiple times consecutively.

**Solution:**

Once the user exceeds the maximum allowed PIN attempts, the system will block further login attempts for the configured lockout duration. If you know the correct PIN, wait for the defined time period before trying again. Otherwise, proceed to reset the PIN. Follow the steps below to reset the PIN or assist the user in regaining access:
