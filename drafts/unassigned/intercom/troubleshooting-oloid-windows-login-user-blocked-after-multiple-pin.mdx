**Introduction**

This document contains detailed troubleshooting steps for resolving the "User Blocked" issue encountered during login with PIN via the Oloid Windows Login application. It explains the causes of PIN lockout, outlines methods to unlock or reset the PIN, and provides guidance for users and administrators to regain access.

**Issue:**

The Oloid Windows Login application displays a “User Blocked” message after multiple incorrect PIN attempts, preventing the user from logging in using the PIN credential.

**Applies to:**

- Oloid Windows Login users authenticating with **PIN** credential.
- Users receiving the **User Blocked** screen on the Windows login app.
- Devices running the **Oloid Windows Login** application.

**Cause:**

The PIN lockout issue may occur due to the following reason:

- The user has entered an incorrect PIN multiple times consecutively.

**Solution:**

Once the user exceeds the maximum allowed PIN attempts, the system will block further login attempts for the configured lockout duration. If you know the correct PIN, wait for the defined time period before trying again. Otherwise, proceed to reset the PIN. Follow the steps below to reset the PIN or assist the user in regaining access:

1. **Reset PIN in the Tenant Admin Portal:**
   To reset PIN in Tenant Admin portal refer [How to reset PIN for Users in the Tenant Admin Portal](https://oloid.help/en/articles/11928944-how-to-reset-pin-for-users-in-the-tenant-admin-portal).
2. **Reset PIN in the Oloid User Portal:**
   To reset PIN in the Oloid User portal refer [How to edit PIN in Oloid User Portal](https://oloid.help/en/articles/9448187-how-to-edit-pin-in-oloid-user-portal).
3. **Reset PIN in the Supervisor App:**
   To reset PIN in the Supervisor app refer [Edit/update PIN using Supervisor App](https://oloid.help/en/articles/9116073-supervisor-app-view-and-edit-pin).

**Escalation**

If the issue persists:

- Capture a screenshot of the locked PIN message (if possible).
- Reach out to **Oloid Support** for further assistance.
