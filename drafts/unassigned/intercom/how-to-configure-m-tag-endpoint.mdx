Steps to configure M-Tag Endpoint:

1. Login to the **Oloid Portal**.
2. On the homepage, click **Endpoints** from the left menu panel.
   ![Image](/images/intercom/9840882/02c308e8-9e0e-4c62-a5a6-9c0f25e576eb-99823083.png)
   The **Endpoints** page is displayed.
3. Click **M-Tag endpoint** name to edit.
   ![Image](/images/intercom/9840882/004c91a4-fd0c-47d2-98af-1325b771c096-2fbe6ac4.png)
   The **Endpoint details** page is displayed.
   ![How to configure M-Tag Endpoint - screenshot 1](/images/intercom/9840882/image-681f884b.png)
4. The configuration comprises the following:
   - **[Details](#details-tab)**[Tab](#details-tab)
   - **[Configure](#configure-tab)**[Tab](#details-tab)
   - **[Transactions](#transactions-tab)**[tab](#details-tab)
   - **[Auto Unlock](#auto-unlock-tab)**[Tab](#details-tab)

## Details Tab

![Image](/images/intercom/9840882/bb771675-9525-408a-b2eb-3e85fd297f24-4596a160.png)

1. Edit **Endpoint Name.**
2. Enter **Endpoint Description**. (optional)
3. Select **Timezone** from the dropdown list. (optional)
4. Click **Save**.

## Configure Tab

This Tab comprises two sub-tabs:

- **Device Information**: The values are auto populated from the values entered while creating the **Endpoint.**
  ![Image](/images/intercom/9840882/a44cd662-7122-400e-b752-50297bb5155a-74723645.png)
- **Device Characteristics**: The fields are related to a set of **upcoming features** and the values will be auto-populated.
  ![Image](/images/intercom/9840882/c6d1fdf9-15ef-4ea2-a93a-aaea710b68cb-ca2d377b.png)

## Transactions Tab

![How to configure M-Tag Endpoint - screenshot 2](/images/intercom/9840882/image-ccf670c9.png)

You can view all the transactions under **Transactions** Tab.

## Auto Unlock Tab

![Image](/images/intercom/9840882/51804487-4b7c-4f23-8c0a-3c27edbc8dc9-4074324b.png)

1. Enable **Background Unlock** to auto unlock the door if the user is within RSSI threshold.
2. Enable **Push Notification Unlock** to get notification for nearby door and unlock it.
3. Enable **Hold to Unlock** to unlock the gate by holding the phone near the reader.
4. Select **RSSI Threshold**.

   <Note>
     **Note:** The value is set 0 by default for **RSSI Threshold.**
   </Note>

5. Click **Save**.
