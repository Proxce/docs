## Overview

Enterprise Endpoint Detection and Response (EDR), antivirus, and endpoint protection solutions may block Windows Login v2.0 components during installation or authentication. To ensure successful deployment and uninterrupted passwordless authentication, configure the required allowlisting (whitelisting) policies in your endpoint security solution.

The recommendations in this document apply to commonly used endpoint security products such as Microsoft Defender for Endpoint, CrowdStrike Falcon, SentinelOne, VMware Carbon Black, Trellix (McAfee), Sophos Intercept X, Trend Micro Apex One, Cortex XDR, and Cisco Secure Endpoint.

## Recommended Allowlisting

Category

Item

Recommendation

Installation Folder

Oloid installation directory

Allow the complete installation folder from scanning and behavioral analysis.

Executables

Windows Login application binaries

Allow all Oloid executable files.

Windows Services

Oloid Windows services

Allow service execution and startup.

Credential Provider

Oloid Credential Provider

Do not block or quarantine the Windows Credential Provider.

DLL Files

Oloid DLLs

Allow all DLLs installed with Windows Login v2.

Registry

Oloid registry entries

Allow read/write access required by the application.

Local Communication

Named Pipes / IPC / Localhost

Do not block communication between Oloid components.

Network

HTTPS (TCP 443)

Allow outbound communication to required Oloid endpoints. Refer to the Windows Login v2 Network URL Whitelisting guide. ([oloid.help](https://oloid.help/en/collections/7487490-oloid-windows-passwordless-authenticator-windows-login?utm_source=chatgpt.com))

## Troubleshooting

Issue

Recommendation

Application fails to launch

Verify executable allowlisting.

Windows Credential Provider is missing

Verify the Credential Provider DLL is not blocked by endpoint security.

Authentication fails

Review EDR logs for blocked processes or services.

Installation is blocked

Verify the installation folder and executable exclusions.

Services do not start

Verify service execution is permitted by the endpoint security policy.
