**Introduction:**

The NFC/ID credential feature in the Tenant Admin Portal allows admin to enable NFC-based authentication for the WebKey application. Once enabled, Users can authenticate to the Webkey application by scanning an NFC card or tag.

## Steps to configure NFC/ID credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit.
   ![How to configure NFC/ID credential for... - screenshot 1](/images/intercom/11501934/image-d74a8c32.png)
   The application page is displayed.
   ![How to configure NFC/ID credential for... - screenshot 2](/images/intercom/11501934/image-8d7449fb.png)
3. Go to **Authenticator tab.**
4. Turn on **NFC/ID** toggle.
   ![How to configure NFC/ID credential for... - screenshot 3](/images/intercom/11501934/0774f74e-70e2-4c26-a765-d9ff4b881b6e-5a12457a.png)
5. Turn on **Use Web-NFC** toggleto allow NFC Login from the Mobile Phone and Tablet browser that supports NFC. (such as Google Chrome on Android)
   ![How to configure NFC/ID credential for... - screenshot 4](/images/intercom/11501934/0ec1c067-d1a4-4961-8d77-979541ede66d-3e8c2f6e.png)
6. Enable **Replace the Credential Label - NFC Tag** to replace the default **"NFC"** or **"NFC Tag"** label with a custom name.
   1. Enter the new label in the **Replace label with** field. Example: Replace **NFC Tag** with **RFID**.
   2. Provide **NFC Scan Instruction** to guide users on scanning their NFC badge for login.
      ![How to configure NFC/ID credential for... - screenshot 5](/images/intercom/11501934/97942430-1e6f-463a-84ad-3711095261e3-c554fa20.png)
7. **Authentication Success Message**: Enter a message to display when authentication is successful.
8. **Authentication Failure Message**: Enter a message to display when authentication fails.
9. Click **Save**.
   ![How to configure NFC/ID credential for... - screenshot 6](/images/intercom/11501934/275ecac4-1c19-45eb-ac11-11c10fabb98e-f153fd2b.png)
   The NFC/ID authenticator for WebKey application is configured successfully.
