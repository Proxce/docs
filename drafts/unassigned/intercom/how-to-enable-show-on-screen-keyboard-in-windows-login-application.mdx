## Introduction

In Oloid Portal, enabling Show on-screen keyboard feature display an on-screen keyboard during Windows login. This option is useful for devices without a physical keyboard, such as tablets.

## Steps to enable Show on-screen keyboard

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to enable Show on-screen keyboard... - screenshot 1](/images/intercom/11098727/2384b68f-77d9-4ed6-a6c3-515e79034b09-ce9caff2.png)
   The **Endpoints** page is displayed.
3. Select the paired Windows Login Endpoint.
   ![How to enable Show on-screen keyboard... - screenshot 2](/images/intercom/11098727/8cbc4dfd-c155-44b8-99eb-c3413e16fec1-4a2e2014.png)
   The **Endpoint Details** page is displayed.
   ![How to enable Show on-screen keyboard... - screenshot 3](/images/intercom/11098727/image-dfd08c2d.png)
4. Go to **Configure** > **Endpoint Settings** tab.
   ![How to enable Show on-screen keyboard... - screenshot 4](/images/intercom/11098727/21dd6422-2064-4fe7-8740-6a58d39013b9-d1e0bf48.png)
5. Turn on **Show on-screen keyboard** toggle button to display an on-screen keyboard during Windows login. This option is useful for devices without a physical keyboard, such as tablets.
   ![How to enable Show on-screen keyboard... - screenshot 5](/images/intercom/11098727/40544c54-69e6-4bba-a6f7-b03f8cc38b05-fb3e3c54.png)
6. Click **Save**.
   ![How to enable Show on-screen keyboard... - screenshot 6](/images/intercom/11098727/2244342e-a4cb-40b3-92b4-dce47bbd3de2-99ea0430.png)
   The configuration is saved successfully.

   <Note>
     **Note:** In **Windows Authenticator** app, you must sync the configuration to allow on-screen keyboard work properly. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
   </Note>
