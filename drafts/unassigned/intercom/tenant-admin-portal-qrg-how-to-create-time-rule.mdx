## Steps toCreate Time Rule

1. Log in to the **Tenant Admin Portal**.
2. Click **Time Interpretation** from the left panel menu > Click **Create Time Rule**.
   **Create a new Time Rule** Pop box is displayed.
   ![How to Create Time Rule - screenshot 2](/images/intercom/13305012/ce0254e8-9392-46c7-bf5a-b13ff7a3c727-80f79816.png)
3. On the pop-up box, do the following:
   1. Enter a name in the **Type Rule Name here** field.
   2. Select a rule type from the **Select Rule Type** dropdown.
   3. Select a location from the **Select Location** dropdown.
   4. Click **Create** to save the time rule.

The time rule is created successfully.
