## How to download Windows Device Login installer files

To install Windows Device Login you need to download and install the following from the Oloid portal:

1. .Net SDK
2. C++ Redistributable
3. Oloid Windows Device Login

Steps to download the files:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **User profile icon** on the bottom left corner of the menu panel.
   ![How to install and configure Windows... - screenshot 1](/images/intercom/8860264/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Select **File Sharing**.
   ![How to install and configure Windows... - screenshot 2](/images/intercom/8860264/image-706ddd0c.png)
   The **File Sharing** page is displayed.
4. Do the following:
   1. Select **.Net SDK file** to download.
      ![How to install and configure Windows... - screenshot 3](/images/intercom/8860264/image-79018aad.png)
   2. Select **Microsoft Visual C++ redistributable** file to download.
      ![How to install and configure Windows... - screenshot 4](/images/intercom/8860264/image-b2768f59.png)
   3. Select **WindowsDeviceLogin.zip** to download.
      ![How to install and configure Windows... - screenshot 5](/images/intercom/8860264/image-96224996.png)
      All the files are downloaded to the system.

## Installation Procedure

### Steps to install .Net SDK

1. Download the **dotnet-sdk-6.0.416-win-x64** file on your system.
2. Click **dotnet-sdk-6.0.416-win-x64** file to open.
3. Click **Install**.
   ![How to install and configure Windows... - screenshot 6](/images/intercom/8860264/image-4ed3505f.png)
   The installation process begins.
   ![How to install and configure Windows... - screenshot 7](/images/intercom/8860264/image-4779e395.png)
4. On successful installation, click **Close**.
   ![How to install and configure Windows... - screenshot 8](/images/intercom/8860264/image-b00b8150.png)

### Steps to install Microsoft Visual C++ Redistributable

1. Download the **VC_redist.x64** file on your system.
2. Click **VC_redist.x64** file to open.
3. Select the license agreement checkbox and click **Install**.
   The installation begins.
   ![How to install and configure Windows... - screenshot 9](/images/intercom/8860264/image-8896640e.png)
4. On successful installation, restart your system.
   ![How to install and configure Windows... - screenshot 10](/images/intercom/8860264/image-99b8e30d.png)

   <Note>
     **Note:** You must install the Windows installer file before restarting your system.
   </Note>

### Steps to install Windows Installer file

1. Download the **WindowsDeviceLogin.zip** file on your system.
2. After the download is complete, unzip the **WindowsDeviceLogin** folder, and right-click to select **Extract All**.
3. Select **OloidPasswordlessAdmin.Setup** and run it to install the application.
4. On the **OloidPasswordlessAdmin** Setup wizard, click **Next**.
   ![How to install and configure Windows... - screenshot 11](/images/intercom/8860264/image-0f9cac25.png)
5. Use the default path to install the application and click **Next**.
   ![How to install and configure Windows... - screenshot 12](/images/intercom/8860264/image-0bd2411e.png)
6. Click **Next** to confirm the installation.
   ![How to install and configure Windows... - screenshot 13](/images/intercom/8860264/image-fde92738.png)
7. Click **Close** after the installation is complete.
   ![How to install and configure Windows... - screenshot 14](/images/intercom/8860264/image-d3c87525.png)
   You can find the app icon on your desktop.

Now, restart your system to use Windows Device Login app.

## Configuring Windows Device app with Tenant

## Steps to configure Windows Device app

1. Double-click on the **Windows Device** app to open.
   The **Welcome** page is displayed.
   ![How to install and configure Windows... - screenshot 15](/images/intercom/8860264/image-110e0ec0.png)
2. Enter tenant name in the **Tenant Name / Customer Code** field.
   ![How to install and configure Windows... - screenshot 16](/images/intercom/8860264/image-b7dd0cd3.png)
3. Click **Next**.
   If the tenant name is available in different environments then **Select Environment** page is displayed.
   ![How to install and configure Windows... - screenshot 17](/images/intercom/8860264/image-1653bb34.png)
4. Select an environment and click **Next**.

The Windows device is configured with the tenant. You can now activate the endpoint to use the app.

## Pair device using Config file

### Pre-requisite

You must download the config file of the preferred endpoint from the Oloid Portal. For details, refer [How to download endpoint config file for Windows Login?](https://oloid.help/en/articles/8778331-how-to-download-endpoint-config-file-for-windows-login)

### To pair an endpoint

1. Double-click on the **Oloid Windows Device Login** App to start.
   The Pair Endpoint page is displayed.
2. Select **Pair Device Using Config File**.
   ![How to install and configure Windows... - screenshot 19](/images/intercom/8860264/image-f8718af4.png)
   The **Active Endpoint** page is displayed.
   ![How to install and configure Windows... - screenshot 20](/images/intercom/8860264/image-afe48b89.png)
3. Click to upload the endpoint json file.
4. Select the json file you want to upload and click **Open**.
   ![How to install and configure Windows... - screenshot 21](/images/intercom/8860264/image-299a89ac.png)
5. Select **Proceed**.
   ![How to install and configure Windows... - screenshot 22](/images/intercom/8860264/image-35dcf4f1.png)
   The **Endpoint Paired** page is displayed.
6. The **Endpoint Name** is auto-populated.
   ![How to install and configure Windows... - screenshot 23](/images/intercom/8860264/image-cf2d96fe.png)
7. Select **Publish**.
   The endpoint is paired successfully.
   ![How to install and configure Windows... - screenshot 24](/images/intercom/8860264/image-abc4a0c1.png)
   Now, you can log in to admin mode.
   ![How to install and configure Windows... - screenshot 25](/images/intercom/8860264/image-ca74a49a.png)

## Pair as Supervisor

### To pair an endpoint

1. Double-click on the **Oloid Windows Device** App to start.
   The Pair Endpoint page is displayed.
2. Select **Pair as Supervisor**.
   ![How to install and configure Windows... - screenshot 26](/images/intercom/8860264/image-b69d4ce9.png)
   The **Activate as Supervisor** page is displayed.
   ![How to install and configure Windows... - screenshot 27](/images/intercom/8860264/image-7f08856a.png)
3. Log in with admin / supervisor credentials.
   The **Activate This Device** page is displayed.
   ![How to install and configure Windows... - screenshot 28](/images/intercom/8860264/image-26969a63.png)
4. Do the following:
   1. Enter **Template** name. (Optional)
   2. Enter **Endpoint Name**.
   3. Select **Application Name** from the dropdown list.
   4. Select **Activate Device**.
      The Windows Device app is configured as an endpoint and ready for use.

## How to enroll badge as credential using Windows Device Login App?

### Pre-requisite

- The user should be added in the Oloid portal.
- Endpoint should be configured.

To enroll badge follow the below steps:

1. Launch the **Windows Device** app.
2. On the **Login To Admin Mode** page of the app, enter the admin/supervisor login credentials.
   ![How to install and configure Windows... - screenshot 29](/images/intercom/8860264/image-f13cf9df.png)
3. Click **Login**.
   The paired endpoint details are displayed.
4. Select **Enroll Badge**.
   ![How to install and configure Windows... - screenshot 30](/images/intercom/8860264/image-3c11b82c.png)
   The **Enroll for Badge Login** page is displayed.
5. Enter the **Employee ID** and click **Continue**.

   <Note>
     **Note:** Employee ID is the Primary ID of the user in the Oloid Portal.
   </Note>

   ![How to install and configure Windows... - screenshot 31](/images/intercom/8860264/image-16b79999.png)
   The **Scan your Badge** page is displayed.
   ![How to install and configure Windows... - screenshot 32](/images/intercom/8860264/image-5b3d764a.png)
6. Scan your badge in the Badge Reader.
   The scanned badge number is auto-populated on the **Scan Badge** field.
   ![How to install and configure Windows... - screenshot 33](/images/intercom/8860264/image-ea3483b9.png)
7. Click **Submit**.
   The badge is enrolled successfully.
   ![How to install and configure Windows... - screenshot 34](/images/intercom/8860264/image-d105bc5f.png)
