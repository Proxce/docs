## Introduction

In Oloid Portal, enabling Allow any individual with Domain Credentials feature allows

individuals to log in to the machine using domain credential.

## Steps to Allow any individual with Domain Credentials

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Allow any individual with Domain... - screenshot 1](/images/intercom/11085787/2384b68f-77d9-4ed6-a6c3-515e79034b09-ce9caff2.png)
   The **Endpoints** page is displayed.
3. Select the paired Windows Login Endpoint.
   ![How to Allow any individual with Domain... - screenshot 2](/images/intercom/11085787/8cbc4dfd-c155-44b8-99eb-c3413e16fec1-4a2e2014.png)
   The **Endpoint Details** page is displayed.
   ![How to Allow any individual with Domain... - screenshot 3](/images/intercom/11085787/image-dfd08c2d.png)
4. Go to **Configure** > **Endpoint Settings** tab.
   ![How to Allow any individual with Domain... - screenshot 4](/images/intercom/11085787/21dd6422-2064-4fe7-8740-6a58d39013b9-67bec4e9.png)
5. Turn on **Allow any individual with Domain Credentials** toggle button to allow individuals to log in to the machine using domain credential.
   ![How to Allow any individual with Domain... - screenshot 5](/images/intercom/11085787/da43dcb9-e7ef-4666-8ec2-3f9956faf2ff-3984c348.png)
6. Click **Save**.
   ![How to Allow any individual with Domain... - screenshot 6](/images/intercom/11085787/e6eaf3f5-b218-449a-ab1b-4da39b07e880-31aa36cd.png)
   The configuration is saved successfully.

   <Note>
     **Note:** In **Windows Authenticator** app, you must sync the configuration to allow any individual with Domain Credentials. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
   </Note>
