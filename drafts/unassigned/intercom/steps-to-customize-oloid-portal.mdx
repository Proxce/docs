1. Log in to the Oloid Portal
2. Go to Tenant Settings>App Settings> User Portal
3. Select Login options.
   1. Face
   2. Email
   3. Phone
      The selected login options are displayed in your login screen. You can see the changes in the preview screen on the right side of the page.

      <Note>
        **Note:** You can select one or more login options as per your requirement.
      </Note>

4. Enter the label for user's unique ID.
   You can use Employee ID, Primary ID, Username, Email etc.

   <Note>
     **Note:** This field is enabled only if you select Face as one of the login options.
   </Note>

5. Select SSO options to log in to your User Portal using Single Sign-On.
   1. Google
   2. Azure
   3. Ping
   4. Okta
   5. Custom Button.
      You can use this option to add any specific url to log into the portal.
      Enter the custom label and redirect url in the respective fields.
