## Introduction

Oloid’s **Windows Login – Healthcare** application enables secure, fast, and passwordless access to shared clinical systems using physical identity factors such as **Face, Badge, NFC, and PIN**.

This solution is purpose-built for **healthcare environments** such as hospitals, clinics, pharmacies, and labs where:

- Multiple clinicians share workstations (e.g., nursing stations, EHR terminals)
- Fast access to systems like EHR is critical
- Compliance and auditability (HIPAA, etc.) are required

With Oloid’s passwordless authentication:

- Users **do not need to remember or enter passwords**
- Access is **instantly revoked** when a user leaves
- Clinicians can **quickly log in/out**, reducing delays in patient care
- Shared credentials are **secured and controlled centrally**

## Prerequisites

Before setting up Windows Login (Healthcare), ensure:

- You have access to the **Tenant Admin Portal**
- Supervisor App is installed on the target device
- Device meets Windows Login system requirements
- Healthcare workflows (e.g., shared workstation, EHR access) are defined
- Users are created in the system and mapped to roles/departments

### Credential Setup

Credential configuration depends on clinical workflow and security requirements.

Windows Login supports:

- **Single-factor authentication**
  - Face
  - Badge
  - NFC
  - PIN
- **Multi-factor authentication**
  - Badge + PIN
  - NFC + PIN
  - Face + PIN (for higher security areas)

Refer to [Credential set up using Oloid Platform - Windows Login](https://oloid.help/en/articles/9446862-credential-set-up-using-oloid-platform-windows-device-login) guide.

The credential setup is also done using the Supervisor App. Refer to [Credential Management - Supervisor App](https://oloid.help/en/collections/8743863-credential-management-supervisor-app)
