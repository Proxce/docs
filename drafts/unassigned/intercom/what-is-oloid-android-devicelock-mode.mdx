In **DeviceLock mode**, the Oloid Android app acts as a **secure screen locker**, where the **user is authenticated using various methods** such as Face Recognition, PIN, Password, Badge, or NFC. This mode enables **shared device usage**, allowing multiple users to securely access the same Android device while ensuring individual accountability and access control.
