**Oloid Verify** is a comprehensive identity verification solution that enhances security and streamline access management by integrating advanced biometric authentication methods, such as facial recognition, with traditional credentials like PINs and QR codes, Oloid Verify ensures seamless and secure user authentication.

## Download and Installation

You must download and install the Oloid Verify app on your iPad.

- Download and Install the Oloid Verify App
- Configure the Oloid Verify App

For instructions to download and install the app, refer to [How to download Oloid Verify App](https://oloid.help/en/articles/8592228-how-to-download-oloid-verify-app) & [Oloid Verify: App Installation and Admin Setup](https://oloid.help/en/articles/8601056-oloid-verify-app-installation-and-admin-setup).

## Configuration

### Platform

To use Oloid Verify app on iPad, the Tenant Admin must perform the following configuration in the Oloid Platform.

- Set up Application and Connection.
  For detailed instructions, refer [How to create and configure Application Type - Oloid Verify](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify)
- Create users.
  For more information, see[How to add User](https://oloid.help/en/articles/8185048-how-to-add-user).
- Assign credential to users.
  For more information, see [Create and Manage Users](https://oloid.help/en/collections/6457268-create-and-manage-users).
- Create Endpoint Template.
  For detailed instructions, see [How to create and configure Oloid Verify Endpoint Template](https://oloid.help/en/articles/10506225-how-to-create-and-configure-oloid-verify-endpoint-template).
- Configure the endpoint that you paired with the app.
  For more information, refer [How to configure Endpoint for Oloid Verify](https://oloid.help/en/articles/10511068-how-to-configure-endpoint-for-oloid-verify)

### Oloid Verify App

To use Oloid Verify app the Admin/Supervisor must perform the following configuration in the Oloid Verify App.

- Add location.
  For more information, refer [How to add location to an endpoint using the Oloid Verify App](https://oloid.help/en/articles/8601170-how-to-add-location-to-an-endpoint-using-the-oloid-verify-app) and to update location, see [How to update location in Oloid Verify](https://oloid.help/en/articles/10204617-how-to-update-location-in-oloid-verify)
- Pair/create endpoint.
  For detailed information, see [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint).
- To Log in to the app as Admin or supervisor, see [How to log into the admin mode of Oloid Verify App as a Supervisor/Admin](https://oloid.help/en/articles/8671139-how-to-log-into-the-admin-mode-of-oloid-verify-app-as-a-supervisor-admin). You can also log in to Admin mode using Single Sign-On. To know more, see the following guide:
  [How to login with Google SSO in Oloid Verify](https://oloid.help/en/articles/10247971-how-to-login-with-google-sso-in-oloid-verify)
  [How to login with Microsoft SSO in Oloid Verify App](https://oloid.help/en/articles/10255679-how-to-login-with-microsoft-sso-in-oloid-verify-app)
  [How to Login with Okta SSO in Oloid Verify](https://oloid.help/en/articles/10367862-how-to-login-with-okta-sso-in-oloid-verify)
