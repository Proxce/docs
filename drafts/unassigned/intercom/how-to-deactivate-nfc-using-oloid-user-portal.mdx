Steps to deactivate NFC:

1. Login to the **Oloid User Portal**.
2. On the homepage, click **NFC**.
   ![Image](/images/intercom/9895839/9eedc0b2-8b68-4300-b5b2-eeb77d611cb2-a7d251a1.png)
   The **NFC Credential** page is displayed.
3. Click **Deactivate NFC**.
   ![Image](/images/intercom/9895839/898000bc-a95a-4026-a2c9-9fe697168f4b-83590182.png)
   The confirmation pop-up screen is displayed.
   ![How to deactivate NFC using Oloid User... - screenshot 1](/images/intercom/9895839/image-99c31e0b.png)
4. On the screen, do the following.
   1. Select reason. (optional)
   2. Click **Deactivate**.
      The NFC is deactivated successfully.
      ![How to deactivate NFC using Oloid User... - screenshot 2](/images/intercom/9895839/image-ad390573.png)
