## Introduction

## Prerequisite

Your face must be registered.

<Note>
  **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
</Note>

## Steps to sign in to Windows Device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to Login to Windows Device using... - screenshot 1](/images/intercom/13396684/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to Login to Windows Device using... - screenshot 2](/images/intercom/13396684/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to Login to Windows Device using... - screenshot 3](/images/intercom/13396684/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The **camera** turns on.
2. Show your Face in front of the camera to capture the face.
   ![How to Login to Windows Device using... - screenshot 4](/images/intercom/13396684/image-ea274e47.png)
   The **Choose Your Account** pop-up box is displayed.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, they can select a specific account to sign in. If the user has only one account configured, **Choose Your Account** pop-up box will not be displayed.
   </Note>

3. Select the account to sign in.
   ![How to Login to Windows Device using... - screenshot 5](/images/intercom/13396684/image-87004acc.png)
4. The **OKTA Security** pop-up box is displayed.
   ![How to Login to Windows Device using... - screenshot 6](/images/intercom/13396684/image-2487cd61.png)
   The Push notification is displayed in your registered device.
5. Tap **Yes, It's me**.
   The **Authentication Approved** screen is displayed.
   ![How to Login to Windows Device using... - screenshot 7](/images/intercom/13396684/image-03948d4c.png)
   You are signed in to the Windows device successfully.
