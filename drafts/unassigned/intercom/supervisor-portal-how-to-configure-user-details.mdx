Steps to configure user details:

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
2. Click username to edit.
   ![How to configure user details - screenshot 1](/images/intercom/9673790/image-3edf8d26.png)
   The User details page is displayed.
   ![How to configure user details - screenshot 2](/images/intercom/9673790/image-39d19911.png)
3. Do the following:
   1. **Details** tab: Enter user details and click **Save**.
      ![How to configure user details - screenshot 3](/images/intercom/9673790/image-1f1874b8.png)
   2. **Credentials** tab: Add Face, Set QR code, Assign Badge, Configure Bluetooth settings, Add Windows Password, Vault Passwords, Add PIN, Assign NFC/ID, and Add CloudKey in the respective tabs.
      ![How to configure user details - screenshot 4](/images/intercom/9673790/image-3bde3301.png)
   3. **Transactions** tab: View transactions.
      ![How to configure user details - screenshot 5](/images/intercom/9673790/image-5eca566c.png)
   4. **Time Rules** tab: View time rules.
   5. **Consent** tab: View user consent.
      ![How to configure user details - screenshot 6](/images/intercom/9673790/image-2736f4b1.png)
   6. **Custom fields** tab: Edit badge binary (Optional).
      The User details are configured.
