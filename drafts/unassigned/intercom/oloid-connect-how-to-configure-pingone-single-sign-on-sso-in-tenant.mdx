## Introduction

This document provides instructions to configure **PingOne Single Sign-On (SSO)** for the Oloid Connect App in the Tenant Admin Portal.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- You must configure PingOne and generate the required SSO configuration details in the **PingOne Administrator Console**. For instructions, see [How to Configure PingOne Single Sign-On (SSO) for the Oloid Connect in the PingOne Admin Console](https://oloid.help/en/articles/16779341-how-to-configure-pingone-single-sign-on-sso-for-the-oloid-connect-in-the-pingone-admin-console)

## Steps to Configure PingOne SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **user profile icon** on the bottom-left of the menu panel.
   ![How to Configure PingOne Single Sign-On... - screenshot 1](/images/intercom/16780855/image-f96a0790.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Configure PingOne Single Sign-On... - screenshot 2](/images/intercom/16780855/image-6835c36d.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** > **PingOne**.
   The PingOne configuration section is displayed.
   ![How to Configure PingOne Single Sign-On... - screenshot 3](/images/intercom/16780855/image-61133ce8.png)
5. Turn on **Enable PingOne SSO** toggle.
   ![How to Configure PingOne Single Sign-On... - screenshot 4](/images/intercom/16780855/acbec1de-099c-4412-ae4c-17a77e175e24-8cca301c.png)
6. Do the following:
   1. Enter the **Environment ID** (Optional).
      ![How to Configure PingOne Single Sign-On... - screenshot 5](/images/intercom/16780855/3f507c3a-b8e0-414b-99f5-99f7001396df-94deb9e4.png)
   2. Enter the **Native Client ID**.
      ![How to Configure PingOne Single Sign-On... - screenshot 6](/images/intercom/16780855/image-255dec35.png)

      <Note>
        **Note:** You can find the **Environment ID** and **Native Client ID** in the **PingOne Administrator Console**. To get these details, go to **Applications > Overview > General**, and copy the required information.
      </Note>

      ![How to Configure PingOne Single Sign-On... - screenshot 7](/images/intercom/16780855/image-9c0b5694.png)
   3. Enter the **Discovery URL**.
      ![How to Configure PingOne Single Sign-On... - screenshot 8](/images/intercom/16780855/image-fc3eadd3.png)
   4. Enter the **User Info URL**.
      ![How to Configure PingOne Single Sign-On... - screenshot 9](/images/intercom/16780855/image-5168df6e.png)

      <Note>
        **Note:** You can find the **Discovery URL** and **User Info URL** in the **PingOne Administrator Console**. To get the URL, go to **Applications > Overview > Connection Details**, and copy the **User Info Endpoint** and **OIDC Discovery Endpoint URL**.
      </Note>

      ![How to Configure PingOne Single Sign-On... - screenshot 10](/images/intercom/16780855/4dbf4f6d-775b-4188-9b65-2aa0ecf0528e-ad1f4582.png)
7. Click **Save**.
   ![How to Configure PingOne Single Sign-On... - screenshot 11](/images/intercom/16780855/image-21f52b60.png)
   The PingOne SSO is configured successfully.
   ![How to Configure PingOne Single Sign-On... - screenshot 12](/images/intercom/16780855/image-6806811a.png)
