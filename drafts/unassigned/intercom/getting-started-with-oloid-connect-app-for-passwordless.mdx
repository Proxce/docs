Oloid Connect is a contactless authentication application which can be installed on your iPad. You can log into Workforce/ HRMS platforms through this application using Face, Badge or Pin depending on your device configuration.

## Installation

- Download and Install Oloid Connect App.
  For instructions to download the app, see [How to download Oloid Connect application](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application)

##### Pairing Endpoint (Endpoint Creation)

Endpoints are the devices that facilitate specific functionalities within an application.

Each endpoint is associated with the application, and this association is commonly referred to as "pairing an endpoint."

Pairing Windows Device involves associating endpoints with Passwordless application.

An application is mapped to connections in the Oloid Platform. Pairing devices ensures that the right users within the mapped connections can effectively utilize the associated endpoint and application.

Pairing an endpoint automatically creates endpoint ID in the Oloid portal and the endpoint details are added to the Endpoint section of Oloid Portal.

For details see ,[Pairing Supervisor tablets to Passwordless Application](https://oloid.help/en/articles/8403824-pairing-supervisor-tablets-to-passwordless-application)

### Credential Set up

This is based on client requirement. Oloid's Windows login functions with a single factor (like Face, Badge , NFC tags and Pin) or combination of factors ( **Badge +Pin** and **NFC +Pin**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](https://oloid.help/en/articles/8413861-face-onboarding) guide. For onboarding User Faces through the device, see [Oloid Connect: Add Faces](https://oloid.help/en/articles/8536726-oloid-connect-add-faces) guide.
- Create Badges and assign it to users. Refer [Badge Onboarding](https://oloid.help/en/articles/8402155-badge-onboarding) guide.
- Create NFC and assign to users. Refer [NFC Onboarding](https://oloid.help/en/articles/8600311-nfc-onboarding) guide.
- Create Pin and assign to users. Refer [Pin Onboarding](https://oloid.help/en/articles/8408444-pin-onboarding) guide.
