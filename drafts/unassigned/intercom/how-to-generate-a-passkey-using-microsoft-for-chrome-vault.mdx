## Introduction

This document explains how to generate and test a **passkey** using **Microsoft**.

## Prerequisite

Works best on Chrome, Edge, Safari, or Firefox (latest versions)

## Steps to Generate Passkey

1. Open a web browser (like Edge or Chrome) and visit account.live.com/proofs/manage.
2. **Sign in**: Log into your Microsoft account if you aren't already signed in.
3. **Add Sign-in Method**: Under "Advanced security options," select Add a new way to sign in or verify.
4. **Choose Passkey**: Select Face, Fingerprint, PIN, or Security Key.
5. Authenticate using Chrome Vault Credentials.
6. **Confirm**: Follow the on-screen instructions, which may involve a PIN, fingerprint scan, or face scan, and then select OK or Done to save the passkey
