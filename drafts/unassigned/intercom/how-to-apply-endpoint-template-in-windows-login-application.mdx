## Introduction

In Oloid Portal, enabling the Apply Endpoint Template feature allows Supervisors to view and select endpoint templates during the endpoint pairing process in the supervisor app.

## Steps to Apply Endpoint Template

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to Apply Endpoint Template in... - screenshot 1](/images/intercom/11069235/image-6eeaf72f.png)
   The application page is displayed.
   ![How to Apply Endpoint Template in... - screenshot 2](/images/intercom/11069235/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to Apply Endpoint Template in... - screenshot 3](/images/intercom/11069235/522f7b89-ae95-4b20-a209-6ab02df6994e-24a5a28e.png)
4. Click **Select Endpoint Template** field to select an endpoint template from the dropdown menu.

   <Note>
     **Note:** You must create an Endpoint Template. For more, refer to [How to create and configure Windows Login Endpoint Template](https://oloid.help/en/articles/10501612-how-to-create-and-configure-windows-login-endpoint-template)
   </Note>

   ![How to Apply Endpoint Template in... - screenshot 4](/images/intercom/11069235/image-75e7c353.png)

Click **Save**.

![How to Apply Endpoint Template in... - screenshot 5](/images/intercom/11069235/7341dd9d-903f-4244-9281-bd1cdf7a8239-80e8195c.png)

The configuration is saved successfully. See,[Sample screen for Apply Endpoint Template](#sample-screen-for-apply-endpoint-template)

<Note>
  **Note:** In **Windows Authenticator** app, you must sync the configuration to Apply Endpoint Template. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
</Note>
