This is based on client requirement. Oloid's Windows login functions with a single factor (like Face, Badge , NFC tags and Pin) or combination of factors ( **Badge +Pin** and **NFC +Pin**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](https://oloid.help/en/articles/8413861-face-onboarding) guide. For onboarding User Faces through the device, see [Oloid Connect: Add Faces](https://oloid.help/en/articles/8536726-oloid-connect-add-faces) guide.
- Create Badges and assign it to users. Refer [Badge Onboarding](https://oloid.help/en/articles/8402155-badge-onboarding) guide.
- Create NFC and assign to users. Refer [NFC Onboarding](https://oloid.help/en/articles/8600311-nfc-onboarding) guide.
- Create Pin and assign to users. Refer [Pin Onboarding](https://oloid.help/en/articles/8408444-pin-onboarding) guide.
