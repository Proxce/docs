**Introduction**

To support multi-WebKey configurations, you must set one Identity Provider (IDP) profile as the default. Each WebKey application is mapped to a single IDP profile in a one-to-one relationship. While you can create multiple WebKey applications, each must be tied to a unique IDP profile.

If multiple IDP profiles are available, you must explicitly mark one as the default. During sign-in, users are redirected to the HRMS platform associated with the default IDP and its linked WebKey application.

This document comprises the following:

- Assign webkey app to IDP
- Un-assign webkey from IDP
- Make an IDP as default

**Steps to Assign WebKey application with IDP**

1. Log in to Tenant Admin Portal.
2. On the home page of the portal, select **Auth Policies** > **Identity Provider**.
   ![Untitled public article - screenshot 1](/images/intercom/11550216/f9e594d5-1ae8-4a95-bc16-e1a209077779-b8b16cd0.png)
   The **Identity Provider Profiles** page is displayed.
3. Select an IDP Profile Name to edit.
   ![Untitled public article - screenshot 2](/images/intercom/11550216/09500f7c-5fe9-4662-ab81-e284bbb7a18a-c39b5ca4.png)
   The details page is displayed.
4. Go to **Details** tab.
5. Select the required WebKey application from the **Select WebKey Application** dropdown list.
6. Click **Save**.
   The IDP is configured successfully.
   ![Untitled public article - screenshot 3](/images/intercom/11550216/30308cbc-f0af-457e-ade7-a55156a47173-9b094c9b.png)
7. Click **Make Default** to set this IDP as the default. (Optional)

   <Note>
     **Note:** If another IDP is currently set as default, it will be replaced upon confirmation.
   </Note>

   ![Untitled public article - screenshot 4](/images/intercom/11550216/90c64265-5ba6-4b55-9f7a-194416efbfb2-392c40bf.png)
   The confirmation box is displayed.
8. Click **Set as Default** to designate the preferred IDP as default.
   ![Untitled public article - screenshot 5](/images/intercom/11550216/fd786cd3-9105-4326-b0c0-d84a80db1990-cb7fd744.png)
   The IDP is configured successfully.
   ![Untitled public article - screenshot 6](/images/intercom/11550216/image-6eb24629.png)

   <Note>
     **Note:** Each WebKey application can only be associated with one IDP profile. If you attempt to configure the same application ID with another profile, an error will be displayed.
   </Note>
