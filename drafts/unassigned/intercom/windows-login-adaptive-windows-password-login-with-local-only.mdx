## Overview

This document describes the Adaptive of the **OLOID Windows Login v2.0** password authentication flow. This feature allows Users to authenticate with their Windows password once and continue accessing the Windows device without repeatedly entering the password for a configurable period.

The purpose of this functionality is to provide a convenient authentication experience while ensuring that the user's Windows password remains securely stored **only on the Windows device** and is not synchronized with or uploaded to the OLOID Cloud.

### Local Password Interval Configuration

OLOID Windows Login v2.0 allows the password authentication interval to be configured for a defined period of time. This interval determines how long a user's successfully authenticated Windows password can be used locally without requiring the user to enter the password again.

The interval can be configured according to the customer's required authentication policy, such as a specific number of minutes or hours.

**To configure Local Password Interval, refer:** [Windows Login - How to configure Password credential for Windows Login](https://oloid.help/en/articles/11507597-windows-login-how-to-configure-password-credential-for-windows-login)

### 2. Local Password Protection and Lifecycle

The Windows password used for this authentication flow is intended to remain within the Windows device environment.

After the user successfully authenticates with their Windows password, OLOID Windows 2.0 securely retains the credential locally so that it can support subsequent authentication during the configured interval.

### Local Credential Lifecycle

The credential lifecycle follows this sequence:

**Initial Authentication → Secure Local Retention → Local Use During Interval → Expiration → Password Reauthentication**

### 3. Expiration Behavior

The configured interval determines how long the stored credential can be used without entering the password again.
