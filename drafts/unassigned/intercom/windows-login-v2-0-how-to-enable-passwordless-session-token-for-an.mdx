## Introduction

When the Passwordless Session Token is enabled, the endpoint can generate a passwordless session token after successful authentication, which can be used to establish a secure user session without requiring a password.

## Prerequisites

- You must have a **Tenant Admin** account.
- Ensure the Windows Login application is created and configured. For more information, refer: [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)

## Steps to Enable Passwordless Session Token

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Enable Passwordless Session... - screenshot 1](/images/intercom/16769146/image-4410c43e.png)
   The Endpoints page is displayed.
3. Click an endpoint name to edit from the listed endpoints.
   ![How to Enable Passwordless Session... - screenshot 2](/images/intercom/16769146/image-1116ba6d.png)
   The Endpoint details page is displayed.
   ![How to Enable Passwordless Session... - screenshot 3](/images/intercom/16769146/image-d9741b28.png)
4. Click **Configure Tab** > Click **Integrations**.
   The Integrations tab is displayed.
   ![How to Enable Passwordless Session... - screenshot 4](/images/intercom/16769146/image-693198ce.png)
5. Enable the **Passwordless Session Token** toggle.
   1. Enable the **Include User Token in response** toggle. (Optional)
      ![How to Enable Passwordless Session... - screenshot 5](/images/intercom/16769146/image-b16ede99.png)
      The Passwordless Session Token is enabled for the Windows Login Endpoint.
