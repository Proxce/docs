## Introduction

Oloid's DeviceLock is an Android-based application to log into your Workforce/HRMS platforms and Android Device using physical identity factors (like Face, Badge, NFC tags and Pin). The Physical Identity factors can be combined in any order using factor sequencing for Multi-factor Authentication.

### Configuration

To configure the DeviceLock perform the below steps:

1. Create "**Application**".

   <Note>
     **Note:** You must create an application of "**Passwordless**" type.
   </Note>

2. Create "**User**".
3. Add "**Connection**" to the "**Application**".

   <Note>
     **Note:** Add the same Connection to the Application in which the User is present.
   </Note>

4. Assign "**Badge**".
5. Add "**Pin**".

   <Note>
     **Note:** By default, the Pin is set to 4 Digit Numeric Pin. You can configure the Pin length. For Pin configuration, see [How to configure the Pin](https://oloid.help/en/articles/8407872-how-to-configure-the-pin).
   </Note>

6. Onboard "**Face**".
7. Assign "**NFC**".

The DeviceLock is now configured and ready for use.
