## Introduction

This document provides step-by-step instructions to activate Wallet Pass for a user in the Tenant Admin Portal. Activating Wallet Pass enables users to add and access badge credential in supported mobile wallet applications.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- You must enable wallet pass. For more, refer to [Tenant Admin Portal - How to Enable Wallet Pass](https://oloid.help/en/articles/14885173-tenant-admin-portal-how-to-enable-wallet-pass)

## Steps toActivate and Send Wallet Pass

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Directory** on the left menu panel.
   ![How to Activate and Send Wallet Pass to... - screenshot 1](/images/intercom/15174017/image-fee2cfec.png)
   The **Users** page is displayed.
3. Click **user name** to Activate Wallet Pass for User.
   ![How to Activate and Send Wallet Pass to... - screenshot 2](/images/intercom/15174017/image-8a860ed0.png)
   The user details page is displayed.
4. Go to **Credentials > Badge.**
   ![How to Activate and Send Wallet Pass to... - screenshot 3](/images/intercom/15174017/image-62e27a9c.png)
   The Badge credential page is displayed.
5. Click **Activate Wallet Pass**.
   ![How to Activate and Send Wallet Pass to... - screenshot 4](/images/intercom/15174017/image-14d2e179.png)
   The **Activate Wallet Pass** pop-up box is displayed.
6. Click **Activate**.
   ![How to Activate and Send Wallet Pass to... - screenshot 5](/images/intercom/15174017/image-c7fed486.png)
   The Wallet Pass activated successfully.
   ![How to Activate and Send Wallet Pass to... - screenshot 6](/images/intercom/15174017/image-d4d10101.png)

Click **Send Invite to Add Pass to Wallet**.

<Note>
  **Note:** Ensure that a valid email address is configured for the user before sending the wallet pass invitation.
</Note>

![How to Activate and Send Wallet Pass to... - screenshot 7](/images/intercom/15174017/image-b026a3ed.png)

The wallet pass invitation email is sent to the user's configured email address, and the badge details are displayed successfully.
