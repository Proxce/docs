## Prerequisite

- In the Tenant Admin Portal, admin must do the following:
  - Add PIN for the user. For more details, refer [How to add PIN as credential to users.](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Assign a face credential to the user. For more details, refer [Face Onboarding](https://oloid.help/en/articles/8413861-face-onboarding)
  - Enable PIN option under the Oloid Connect application in Authentication tab. For more details, refer [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal#h_f5cb6be542)

## Steps to log in using PIN and Face

1. Launch the **Oloid Connect App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the Auth selection screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to authenticate using Oloid Connect... - screenshot 1](/images/intercom/12146294/image-64bf3a75.png)
   The Auth selection screen is displayed.
2. Tap **Login with PIN.**
   ![How to authenticate using Oloid Connect... - screenshot 2](/images/intercom/12146294/e7ffa51d-f8b4-48ff-b1c7-bd6e541fc1f0-c2617862.png)
   The **Enter PIN to Login** screen is displayed.
3. Enter PIN.
   ![How to authenticate using Oloid Connect... - screenshot 3](/images/intercom/12146294/image-c9b405a7.png)
   After successful authentication, the Camera opens to capture the user's face.

Place your Face inside the ovel shape in the screen.

![How to authenticate using Oloid Connect... - screenshot 4](/images/intercom/12146294/image-d47044ee.png)

After successful authentication user details are appeared on the top of the screen.

![How to authenticate using Oloid Connect... - screenshot 5](/images/intercom/12146294/image-6d721999.png)

On Face authentication, you are directed to User Portal for selecting the intent.
