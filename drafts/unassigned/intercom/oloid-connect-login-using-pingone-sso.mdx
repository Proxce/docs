## Introduction

The PingOne SSO Login feature in the Oloid Connect App allows Tenant Admin and Supervisor to securely access Admin Mode using PingOne SSO credentials.

## Prerequisites

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must download the Oloid Connect app from App Store. For more details, refer [How to download Oloid Connect app](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application).

## Steps to log in with PingOne SSO

1. Launch the **Oloid Connect** ![Login using PingOne SSO - screenshot 1](/images/intercom/14483914/image-6def886f.png) app.
   ![Login using PingOne SSO - screenshot 2](/images/intercom/14483914/image-8023bdfb.png)
2. Tap **Pair as Supervisor.**
   ![Login using PingOne SSO - screenshot 3](/images/intercom/14483914/ecc40269-285d-4f4e-88e2-f9771a362fd6-2acb4e46.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name,** then tap **Next**.
   ![Login using PingOne SSO - screenshot 4](/images/intercom/14483914/image-68b311a7.png)
   The **Login** page is displayed.
4. Tap **Login with SSO**.
   ![Login using PingOne SSO - screenshot 5](/images/intercom/14483914/bccab0d0-afda-4533-91d6-7bbcb81148ee-1bd8f66b.png)
   The screen with **SSO options** is displayed.
5. Tap **Continue with Ping**.
   ![Login using PingOne SSO - screenshot 6](/images/intercom/14483914/image-cd93cc31.png)
   The PingOne sign-in pop up box is displayed.
6. Do the following:
   1. Enter **Username.**
   2. Enter **Password**.
   3. Click **Sign in**.
      ![Login using PingOne SSO - screenshot 7](/images/intercom/14483914/image-9041b1c8.png)
      You are successfully logged in to Oloid Connect Admin Mode.
