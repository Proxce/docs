This document provides an overview of the user roles—**Admin,** and **Read-only Admin,** —along with their operations in Oloid Tenant Admin Portal.

The Tenant Admin performs various operations or actions to manage and maintain the Oloid Portal.

[Operations for Tenant Admin](#operations-for-tenant-admin)

[Operations for Read-only Tenant Admin](#operations-for-read-only-tenant-admin)

## Operations for Tenant Admin

An **Admin** has full access to the Oloid platform and all connected devices. Admins can create, update, and delete data.

To become a Tenant Admin, you must be an Oloid user.

1. The Admin configures and manages the system to login to the Oloid portal using various login options. See [Getting Started](https://oloid.help/en/collections/6445591-getting-started) to know more.
2. Once logged in the Admin can manage [Accounts and Settings](https://oloid.help/en/collections/6458318-accounts-and-settings) for Admins, Supervisors and User.
3. Then the Admin [Create and Manage Applications](https://oloid.help/en/collections/6445617-create-and-manage-applications) for the array of products.
4. Oloid acts as IDP for Passwordless SSO use cases and the Admin can [Create and Manage IdP Provider](https://oloid.help/en/collections/9401352-create-and-mange-idp-provider).
5. The Admin [Creates and Manages Factor Sequence](https://oloid.help/en/articles/9699393-how-to-create-and-configure-factor-sequence) for MFA.
6. Once Application is created the Admin [Creates and Manages Connections](https://oloid.help/en/collections/6445618-create-and-manage-connections).
7. Now the Admin adds Users and manages them as required. See, **[Create and Manage Users](https://oloid.help/en/collections/6457268-create-and-manage-users)** to know more.
8. To assign Badge Id credentials the Admin needs to **[Create and Manage Wiegand Access](https://oloid.help/en/collections/6561738-create-and-manage-wiegand-access).**
9. Once the User is added the Admin can assign shared credentials to user. See **[Create and Manage Shared Credentials](https://oloid.help/en/collections/6646524-create-and-manage-shared-credentials)** to know more.
10. The Admin can create Groups primarily used for On-Device Transactions. See **[Create and Manage Groups](https://oloid.help/en/collections/6457224-create-and-manage-groups)** to know more.
11. Once the user is added to connection and application is configured the Admin create Endpoints. See, **[Create and Manage Endpoints](https://oloid.help/en/collections/6445619-create-and-manage-endpoints)** to know more about creating and configuring endpoints.
12. Once the Endpoint is create the Admin [Adds and Manages Location](https://oloid.help/en/collections/6445616-create-and-manage-locations) in the Endpoint
13. The Admin [Creates and Manage Consent Document](https://oloid.help/en/collections/6458393-create-and-manage-consent-documents) for the users to provide consent to store and use their face for different applications within the workplace during face onboarding.
14. The Admin also [Creates and Manages Reports](https://oloid.help/en/collections/6445604-create-and-manage-reports) for all kind of activity on the Oloid Portal.

## Operations for Read-only Tenant Admin

Read-only access restricts the Admin to create, update, and delete data . However, they have full read-only access to all the data .
