**Pre-requisite:**

You must create a Passwordless application of type WebKey. For further details, refer [How to create a WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)

Steps to edit Details tab:

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Webkey application to edit.
   ![How to edit Details tab in WebKey... - screenshot 1](/images/intercom/10799157/image-d74a8c32.png)
   The application page is displayed.
   ![How to edit Details tab in WebKey... - screenshot 2](/images/intercom/10799157/442c93ac-d723-4e6c-b867-d6b8adfce7cf-391da2c6.png)
3. Do the following:
   1. Edit **Application Name** if required.
   2. Add **Description**. (Optional)
   3. Select **Factor Sequence**. (Coming Soon)
   4. Select IDP Profile from **IDP Profile** dropdown list. (Optional)
   5. Select **Time Zone** from the dropdown list. (Optional)
   6. Copy **Login URL Path** to sign in to WebKey app.

      <Note>
        **Note:** These are one-time settings and all the default settings are recommended.
      </Note>
