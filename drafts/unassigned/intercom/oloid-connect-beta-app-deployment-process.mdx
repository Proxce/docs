## Introduction

This document provides a step-by-step process for deploying the **Oloid Connect Beta App** using [Microsoft Intune](https://learn.microsoft.com/mem/intune/fundamentals/what-is-intune) Mobile Device Management (MDM) system. It covers the required XML configuration from the Oloid Admin Portal, uploading the .ipa (iOS App Store Package) file, and assigning it as a Line-of-Business (LOB) app. Additionally, it outlines the process for setting up a Managed Device Configuration policy to enable auto-pairing on enrolled iOS devices.

## Deployment Steps

Step 1: Create the XML configuration file from the Oloid Tenant Admin Portal.

Step 2: Share the .ipa file with the IT team via MDM.

Step 3: Deploy the app in Intune.

Step 4: [Create the Configuration policy for the app.](#steps-to-create-the-configuration-policy-for-the-app)

Once all the steps are performed correctly, the app appears in the enrolled iOS devices. Launch the app and pair the devices using auto-pair option to successfully install the app.

<Note>
  **Note:** If you are using the UAT environment, you must manually switch the Oloid Environment configuration within the iOS settings before launching the app. This step is not required when configuring the Production environment.
</Note>

If you are using the UAT environment, you must manually switch the Oloid Environment configuration within the iOS settings before launching the app.

To set the runtime environment:

1. Open the **Settings** app on your iOS device.
2. Scroll down and select **OloidConnect**.
3. Tap **Environment**, and then select **UAT**.

This step is required only for the UAT environment. You do not need to perform this step for the Production environment.

## Steps to create the Configuration policy for the app.

Create and assign a configuration policy to apply the necessary settings for the Oloid iOS app. Follow the steps below to configure iOS managed app deployment for automatic device pairing:

   ![Oloid Connect Beta App Deployment... - screenshot 13](/images/intercom/11091553/image-bc412b5c.png)

   ![Oloid Connect Beta App Deployment... - screenshot 14](/images/intercom/11091553/image-0de9d6b5.png)

   ![Oloid Connect Beta App Deployment... - screenshot 15](/images/intercom/11091553/image-5b8af895.png)
7. Assign the required **Groups** on the next screen >create the **configuration**.

## ⚠️ Developer Mode Requirement for Ad Hoc iOS Builds

Starting with **iOS 16**, Apple requires **Developer Mode** to be enabled on devices for running apps installed via Ad Hoc, Enterprise, or other direct distribution methods (outside of TestFlight or the App Store).

<Warning>
  **Important:** Developer Mode must be enabled for any app installed using Ad Hoc provisioning profiles. This requirement is enforced by Apple and applies to all devices running **iOS 16 or later**.
</Warning>

✅ **What to Expect**

- If the app is distributed via Ad Hoc builds for development or testing, users **must enable Developer Mode** on their iPhone or iPad to launch the app.
- Once the app is published and installed via the **App Store**, **Developer Mode is no longer required** and can be safely turned off.

**Reference**

Apple Developer Documentation – [Enable Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)
*“On devices running iOS 16 or later, you must enable Developer Mode to install and launch apps using development provisioning profiles, ad hoc distribution, or enterprise distribution.”*

## Enabling Developer Mode via MDM

If you're managing iOS devices using MDM solution, such as **Microsoft Intune**, and the devices are **supervised**, you can enable Developer Mode remotely.

Use a configuration profile to set up Developer Mode, so it can be turned off remotely once the app is installed from the App Store.

```
<dict>
    <key>PayloadType</key>
    <string>com.apple.configuration.profile</string>
    <key>PayloadVersion</key>
    <integer>1</integer>
    <key>PayloadIdentifier</key>
    <string>com.connect.oloid</string>
    <key>PayloadUUID</key>
    <string>01234567-89AB-CDEF-0123-456789ABCDEF</string>
    <key>PayloadDisplayName</key>
    <string>Oloid Developer Mode Config</string>
    <key>PayloadContent</key>
    <array>
       <dict>
          <key>PayloadType</key>
          <string>com.apple.developer</string>
          <key>PayloadVersion</key>
          <integer>1</integer>
          <key>DeveloperMode</key>
          <true/>
        </dict>
   </array>
</dict>
```
