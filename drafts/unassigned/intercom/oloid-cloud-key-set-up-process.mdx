Oloid Cloud Key setup process involves configuring the Oloid Cloud Key in Oloid Platform which involves the following:

1. Creating Application for CloudKey
2. CloudKey Endpoint Creation
3. Configuring Cloudkey in Tenant Settings
4. Assigning Cloudkey to User
1. Login to the Oloid Platform using your credentials.
2. Create an application. Select application type as **Generic** . For detailed instructions, see [How to create and configure Application Type – Generic](https://oloid.help/en/articles/8300397-how-to-create-and-configure-application-type-generic) guide.
3. Create a connection and enable it for the application created in the previous step.
   [How to Map Connection to Application](https://oloid.help/en/articles/8304594-how-to-map-connection-to-application) guide.
4. Add users to the connection created in the previous step. For detailed instructions, see [How to add user](https://oloid.help/en/articles/8185048-how-to-add-user) guide.
5. Create Cloud Key Endpoints. [How to add a CloudKey endpoint](https://oloid.help/en/articles/8263138-how-to-add-a-cloudkey-endpoint)

   <Note>
     **Note:** Once Endpoint is created successfully , add location to the endpoint. (optional). Refer to [How to add location to the endpoint](https://oloid.help/en/articles/8223212-how-to-add-location-to-the-endpoint) guide. For additional guides on location , refer to **[Create and Manage Locations](https://oloid.help/en/collections/6445616-create-and-manage-locations) .**This is important to ensure that the proximity settings work to display the nearest CloudKey.
   </Note>

6. Go to **Settings> Advanced> CloudKey** and configure CloudKey for the tenant. For detailed instructions, see [How to configure CloudKey](https://oloid.help/en/articles/8803628-how-to-configure-cloudkey) guide.
7. Assign the CloudKey to the user. For detailed instructions, see [How to add Cloudkey as credential to users](https://oloid.help/en/articles/8290091-how-to-add-cloudkey-as-credential-to-users) guide.
   The CloudKey is configured and ready to use.
