**Pre-requisite:**

QR Code must be created for selected users. For more details, refer here [Supervisor Portal- How to generate QR Code for multiple users](https://oloid.help/en/articles/9673768-supervisor-portal-how-to-generate-qr-code-for-multiple-users)

Oloid account should be created(add link)

Steps to send QR Code link:

1. Log in to **Supervisor Portal**.
   The Users page is displayed.
   ![How to send QR code link for multiple... - screenshot 1](/images/intercom/9711988/image-0d67180d.png)
2. Select user(s) to send QR code link.
   ![How to send QR code link for multiple... - screenshot 2](/images/intercom/9711988/image-a70ed3ee.png)
3. Click **Action** > **Send Email** > **Send QR code link**.
   ![How to send QR code link for multiple... - screenshot 3](/images/intercom/9711988/image-50df95b8.png)
   The QR code link is sent to selected users successfully.
