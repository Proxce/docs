## Introduction

This document provides detailed instructions to install, configure, and enroll Android devices with the **Oloid DeviceLock** and **Oloid Vault** applications using **SOTI MobiControl**. Additionally, this document outlines essential steps for enabling accessibility services, autofill configurations, and restricted settings required for full app functionality.

It also includes a set of basic regression test cases with expected outcomes to ensure that, with every new build release, all core use cases function as intended and no regressions occur.

## Prerequisites

- The device is enrolled in **SOTI MobiControl**.
- The device has a stable internet connection.
- A valid **Microsoft account** is available for the user.
- User(s) have access to **Admin or Supervisor credentials** for the DeviceLock app.

## Installation Setup

### Install Oloid DeviceLock and Oloid Vault

1. Launch the **SOTI MobiControl** app on the device.
   ![Installation and Setup Guide for Oloid... - screenshot 1](/images/intercom/12066142/image-4121fa89.png)
   The app opens successfully.
2. Tap the **Menu** icon on the top-left side of the screen.
   ![Installation and Setup Guide for Oloid... - screenshot 2](/images/intercom/12066142/5ab18002-32a6-4b44-b941-9dad83a3f5fe-b9c93f6a.png)
   Menu list is displayed.
3. Tap **App Catalog**.
   ![Installation and Setup Guide for Oloid... - screenshot 3](/images/intercom/12066142/image-4c31a9cd.png)
   The App catalog screen is displayed.
4. Tap **IN-HOUSE** tab, the IN-HOUSE app(s) is(are) displayed.
   ![Installation and Setup Guide for Oloid... - screenshot 4](/images/intercom/12066142/image-c358eb37.png)

### Enroll User credentials

1. Enroll Face. To enroll face refer [How to enroll face for users in the DeviceLock App](https://oloid.help/en/articles/12156735-how-to-enroll-face-for-users-in-the-devicelock-app).
2. Enroll PIN. To enroll PIN refer [How to enroll PIN for users in the DeviceLock App](https://oloid.help/en/articles/12157257-how-to-enroll-pin-for-users-in-the-devicelock-app).
3. Enroll NFC/ID. To enroll NFC/ID refer [How to enroll NFC/ID for users in the DeviceLock App](https://oloid.help/en/articles/12157546-how-to-enroll-nfc-id-for-users-in-the-devicelock-app).

<Note>
  **Note:** Once the Credentials are enrolled for the user, Log out of Admin Mode and Initial Screen of devicelock with configured Auth methods will be displayed.
</Note>

## Summary

By following the above steps, the **Oloid DeviceLock** and **Oloid Vault** applications will be fully installed, configured, and ready for use.

- Administrators can log in using **Microsoft SSO for** enrolling with **Face, NFC, and PIN** credentials
- **Oloid Vault** enables **Autofill**, allowing seamless access and auto-login to Microsoft and non-Microsoft applications.
