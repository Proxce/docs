## Introduction

You can configure the biometric policy (also known as the consent form) from the Connection Details page in the Tenant Admin Portal. When enabled, this feature prompts users to accept the biometric policy before they can add their face in the Oloid User Portal.

This document comprises the following:

- [To configure biometric policy in the Tenant Admin Portal](#to-configure-biometric-policy-in-the-tenant-admin-portal)
- [To test biometric policy in the Oloid User Portal](#to-test-biometric-policy-in-the-oloid-user-portal)

## Prerequisites

- You must have a tenant admin account.
- User must be part of the connection.

### To configure biometric policy in the Tenant Admin Portal

Steps to configure biometric policy:

1. Log in to Tenant Admin Portal.
2. On the home page of the portal, click **Connections** on the left menu panel.
   ![How to configure and test Biometric... - screenshot 1](/images/intercom/11324573/image-e24ab25f.png)
   The **Connections** page is displayed.
3. Click connection name to be configured from the listed connections.
   ![How to configure and test Biometric... - screenshot 2](/images/intercom/11324573/92366820-7bd7-46dc-af65-34900c9dc550-d90da62a.png)
   The Connection detail page is displayed.
   ![How to configure and test Biometric... - screenshot 3](/images/intercom/11324573/image-3cc1efe7.png)
4. Go to **Settings** tab.
5. Turn on **User Consent Required** toggle > Select a Template from the **User Consent Required** dropdown list.

   <Note>
     **Note:** Enabling this toggle will prompt users to provide consent to store and use their face for different applications within the workplace during face-onboarding.
   </Note>

   <Note>
     **Note:** To create a consent template, refer [How to create a Consent Template](https://oloid.help/en/articles/8254979-how-to-create-a-consent-template).
   </Note>

   ![How to configure and test Biometric... - screenshot 4](/images/intercom/11324573/33478e5a-8351-40e2-af21-6035f3590bd5-e15ff576.png)
6. Click **Save**.
   The connection is successfully configured.

### To test biometric policy in the Oloid User Portal

**Pre-requisite:**

- A user must be created in the Tenant Admin Portal.
- In the paired connection, enable the **User Consent Required** toggle button.

Steps to test biometric policy:

1. Log in to the **Oloid User Portal**.
   The Oloid User Portal login page is displayed.
   ![Image](/images/intercom/11324573/c97a8154-ba2a-4726-ab5b-1e93af9e52cc-d0562d77.png)
2. Select **Login with Email**.
   The **Login with Email** page is displayed.
   ![How to configure and test Biometric... - screenshot 5](/images/intercom/11324573/image-ae3c2a11.png)
3. Do the following:
   1. Enter your email address in the **Email ID** field.
   2. Click **Get Verification Code**.
      A verification code is sent to your registered email ID.
   3. Enter the Verification code.

      <Note>
        **Note:** The One Time Verification Code expires after 60 seconds.
      </Note>

   4. Click **Login**.
      ![How to configure and test Biometric... - screenshot 6](/images/intercom/11324573/image-8784c1a4.png)
      The Oloid User Portal is displayed.
4. On the homepage, click **Face**.
   ![Image](/images/intercom/11324573/b8962e99-3ef5-4dfb-94fa-cd9d48db7998-9fb95aa4.png)
   The **Face Credential** page is displayed.

   <Note>
     **Note:** The user must provide their consent to proceed to the next steps if consent is enabled in the Tenant Admin Portal.
   </Note>

   ![How to configure and test Biometric... - screenshot 7](/images/intercom/11324573/image-9d83fd12.png)
5. Select **Add Face** to complete facial enrollment.

![How to configure and test Biometric... - screenshot 8](/images/intercom/11324573/3acf42f1-b51e-499a-a040-bd9ab28b3198-d90c1287.png)
