Shared Credentials are passwords that can be used to access a local windows machine or a domain. It is shared among users to which they are assigned to.

Follow below steps to create and assign shared credentials to users

## Step 1: Create Shared Credential – Domain, Local

A local logon grants a user permission to access resources on the local computer or resources on networked computers.

A domain account, on the other hand, is used to log in to a network domain and access the resources and services available on that domain.

To create local and domain shared credentials for Oloid's Windows Device Login, refer [How to create shared credentials for Windows login](https://oloid.help/en/articles/8472794-how-to-create-shared-credentials-for-windows-login) guide.

## Step 2 : Assign Shared Credentials

Do one of the following to assign credentials to users:

- Assign credential to users. For detailed instructions, see [How to assign shared credential to user](https://oloid.help/en/articles/8504427-how-to-assign-shared-credential-to-user)
- Associate users with credentials. For detailed instructions, see [How to associate users with shared credentials](https://oloid.help/en/articles/8543917-how-to-associate-users-with-shared-credentials)

## Step 3: Assign credentials to multiple users.

You can assign shared credentials to multiple users. For detailed instructions, see [How to assign shared credential with multiple users](https://oloid.help/en/articles/8504762-how-to-assign-shared-credential-with-multiple-users)
