## Introduction

Screen timeout duration refers to the idle time after which the device screen automatically times out. Configuring this setting help ensures efficient device usage in DeviceLock mode.

## Prerequisite

You must have an active tenant and access to the Tenant Admin Portal. For more details refer [How to log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).

## Steps to set screen timeout duration

1. Log in to the **Tenant Admin Portal**. For more details refer [How to log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).
2. On the homepage of the portal, click the preferred application from the application list.
   ![How to set Screen Timeout Duration for... - screenshot 1](/images/intercom/11560127/image-3c3c4a2e.png)
   The application detail page is displayed.
   (Add Screenshot here)
3. Go to **Configure** tab > click **Configure Passwordless** from the left menu panel.
   ![How to set Screen Timeout Duration for... - screenshot 2](/images/intercom/11560127/image-d03d05d1.png)
   The configure passwordless screen is displayed.,
   (Add screenshot here)
4. Do the following:
   1. Turn on **Enable Passwordless Config** toggle.
   2. Select **Passwordless Login**.
      ![How to set Screen Timeout Duration for... - screenshot 3](/images/intercom/11560127/image-d2b361e3.png)
5. Scroll down and select the duration in **minutes** and **seconds** from the drop-down list or manually enter the value in the field to define the duration the screen should remain active before it times out.
6. Click **Save**.
   ![How to set Screen Timeout Duration for... - screenshot 4](/images/intercom/11560127/image-5d32a577.png)
   The screen timeout duration is set successfully.
   ![How to set Screen Timeout Duration for... - screenshot 5](/images/intercom/11560127/image-de46183c.png)
