## Introduction

Guided Access Mode on iPhone allows you to lock the device to a single app. This is useful when the iPhone is used as a dedicated endpoint, ensuring users stay within the Oloid Connect app.

### The following topics are covered in this document.

- How to set up Guided Access in iPhone
- How to enable Guided Access Mode in iPhone
- How to disable Guided Access Mode in iPhone

## Steps to Set up Guided Access Mode

1. Open your iPhone.
2. Go to **Settings > Accessibility.**
   ![Set up iPhone in Guided Access Mode - screenshot 1](/images/intercom/13428004/image-73012448.png)
3. Scroll down the list to the bottom and tap **Guided Access.**
   ![Set up iPhone in Guided Access Mode - screenshot 2](/images/intercom/13428004/image-5b478842.png)
4. Tap the toggle to switch on Guided Access.
   ![Set up iPhone in Guided Access Mode - screenshot 3](/images/intercom/13428004/image-eed8280a.png)
5. Tap **Passcode Settings**.
   ![Set up iPhone in Guided Access Mode - screenshot 4](/images/intercom/13428004/image-f196126b.png)
6. Tap **Set Guided Access Passcode.**
   ![Set up iPhone in Guided Access Mode - screenshot 5](/images/intercom/13428004/image-2e2ffc29.png)
7. Enter a passcode, then re-enter it to confirm.

![Set up iPhone in Guided Access Mode - screenshot 6](/images/intercom/13428004/image-91c66f67.png)
