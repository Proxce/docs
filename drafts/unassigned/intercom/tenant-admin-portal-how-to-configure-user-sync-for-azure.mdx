## Introduction

This document provides instructions to set up user sync between Microsoft Entra ID (Azure) and Oloid using the Tenant Admin Portal. This configuration enables user data to synchronize with Oloid.

## Prerequisite

You must have **Admin access** to the Tenant Admin Portal.

## Steps to Configure User Sync for Azure

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **User Sync**.
   ![How to Configure User Sync for Azure - screenshot 1](/images/intercom/16107870/image-95b6dad0.png)
   The Agents page is displayed.
3. Click **Install** on **Active Directory**.
   ![How to Configure User Sync for Azure - screenshot 2](/images/intercom/16107870/image-10435c54.png)
   The **Active Directory** pop-up box is displayed.
4. Do the following:
   1. **Client ID**: Enter the Client ID of the Microsoft Entra application.
      ![How to Configure User Sync for Azure - screenshot 3](/images/intercom/16107870/image-4d25593e.png)
   2. **Client Secret Key**: Enter the client secret for the Microsoft Entra application.
      ![How to Configure User Sync for Azure - screenshot 4](/images/intercom/16107870/image-d4d06327.png)

      <Note>
        **Note:** You can find this in the Entra ID Admin Console under **Manage > Certificates and Secrets > Client secrets**.
      </Note>

      ![How to Configure User Sync for Azure - screenshot 5](/images/intercom/16107870/image-6779ea93.png)
   3. **Unit**: Select the time unit for the synchronization interval (**Seconds**, **Minutes**, or **Hours**).
      ![How to Configure User Sync for Azure - screenshot 6](/images/intercom/16107870/image-82be6331.png)
   4. **Rate**: Enter the synchronization frequency for the selected time unit.
      ![How to Configure User Sync for Azure - screenshot 7](/images/intercom/16107870/image-e30ef7c6.png)
   5. **Connection**: Select the Oloid connection from the drop-down where synchronized users are added.
      ![How to Configure User Sync for Azure - screenshot 8](/images/intercom/16107870/image-e4b1387b.png)
   6. **Azure Tenant ID**: Enter the Tenant ID of your Microsoft Entra tenant.
      ![How to Configure User Sync for Azure - screenshot 9](/images/intercom/16107870/image-fa1b8160.png)

      <Note>
        **Note:** You can find the **Client ID** and **Tenant ID** in the Microsoft Entra admin center on the application **Overview** tab.
      </Note>

      ![How to Configure User Sync for Azure - screenshot 10](/images/intercom/16107870/image-a25560a2.png)
5. Click **Create**.
   ![How to Configure User Sync for Azure - screenshot 11](/images/intercom/16107870/43ad0760-f223-4d2a-90f6-ef7866515a2d-1c39ad5b.png)
   The User Sync configuration is configured successfully.
   ![How to Configure User Sync for Azure - screenshot 12](/images/intercom/16107870/image-a3d62eeb.png)
