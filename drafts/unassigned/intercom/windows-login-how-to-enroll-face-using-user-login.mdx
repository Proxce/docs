## Steps to Enroll Face using User Login in Supervisor App

1. Launch the Oloid Passwordless Application.
   The Login screen is displayed.
2. Click **User Login**.
3. The Welcome screen is displayed.
4. Click **Login with Windows Credential**.
5. The Verify using Windows Credential screen is displayed.
6. Do the following:
   1. Enter **Domain Name**.
   2. Enter **Username/Primary ID**
   3. Enter **Password.**
   4. Click **Login.**
