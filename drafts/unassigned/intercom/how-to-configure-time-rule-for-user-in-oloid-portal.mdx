**Introduction**

A Time Rule defines the working schedule for users, including start time and end time that includes applicable working days, time zones, and punch directions. While configuring a time rule, these values are set to ensure the system accurately interprets attendance-based data on the user’s work schedule.

**Pre-requisite**

You must create the Time Rule in the Oloid Portal. Refer here for more details, How to create Time Rule.

**Steps to configure Time Rule:**

1. Log in to the **Oloid Portal**.
2. On the homepage, select **Time Interpretation** from the left menu panel.
   ![How to configure Time Rule for user in... - screenshot 1](/images/intercom/10741199/1_jhbfjvhb-1e82bddc.png)
   The **Time Interpretation** page is displayed.
   ![How to configure Time Rule for user in... - screenshot 2](/images/intercom/10741199/1fc11a6b-e26d-491d-ab17-decdb09838e6-465ca45f.png)
3. Select the **Time Rule** to configure.
   The Time Rule page is displayed.
   ![How to configure Time Rule for user in... - screenshot 3](/images/intercom/10741199/image-cda78161.png)
4. Do the following:
   1. Select **Day(s)** of the week you want the time rule to applicable to.
   2. Select **Time Zone** from the dropdown list.
   3. Enter a label in **Default Label** field. (for what)
   4. Click **+Add Time Slot**.
      The **Add Time Slot** pop-up box is displayed.
      ![How to configure Time Rule for user in... - screenshot 4](/images/intercom/10741199/image-e871d58c.png)
   5. Do the following on the pop-up box:
      1. Set start time in **Time Slot Start** field. (calendar option)
      2. Set end time in **Time Slot End** field.
      3. Select **Direction** from the dropdown as per the requirement.
      4. Select **Label** from the dropdown.
      5. Click **Add**.
         ![How to configure Time Rule for user in... - screenshot 5](/images/intercom/10741199/9626f06c-93fa-40f4-9359-c2e5eba26711-eee94618.png)
   6. Click **Save**.
      ![How to configure Time Rule for user in... - screenshot 6](/images/intercom/10741199/734e50f6-9e01-4dbe-a9d0-880ef814d2fa-e594aa3b.png)
      The Time Rule is configured successfully.
