## Introduction

This document explains how to auto-pair the Windows Login (Authenticator) app directly from the Windows lock screen using the Auto-Pair Config File.

## Prerequisites

- You must have Admin or Supervisor credentials to perform endpoint pairing.
- You must have the Auto-Pair Config File in JSON format. To download the Auto-Pair Config File, refer to [Windows Login - How to Generate and Download Auto-Pair config file for Windows Login in Tenant Admin Portal](https://oloid.help/en/articles/10441578-windows-login-how-to-generate-and-download-auto-pair-config-file-for-windows-login-in-tenant-admin-portal#h_92d9e3460c).

## Steps to Auto-Pair Windows Login App from the Lock Screen

1. On the Windows lock screen, click **Sign-in options**.
   The Windows Login app option is displayed.
2. Select the **Windows Login app**.
3. Select **Login with OLOID**.
   The Windows Login pairing screen is displayed.
4. Select **Yes, pair my device** to auto-pair the endpoint.
   The Windows machine is paired successfully and ready for sign-in with Oloid.

<Note>
  **Note:** If auto-pair doesn't appear or fails at this step, the device can also be paired manually. Refer: [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
</Note>
