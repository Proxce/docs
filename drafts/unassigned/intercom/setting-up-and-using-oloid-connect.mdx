**Oloid Connect** is an identity verification and time locking solution that enhances security and streamline access management by integrating biometric authentication methods, such as facial recognition, with traditional credentials like PINs, and QR Codes.

## Installation and Configuration

The Oloid Connect app is installed and configured on the iPad.

- Download and Install the Oloid Connect App
- Configure the Oloid Connect App

For more details, see [How to download Oloid Connect application](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application)

For more details, see [Oloid Connect: App Installation and Admin Setup](https://oloid.help/en/articles/8592262-oloid-connect-app-installation-and-admin-setup)

## Configuration

### Platform

For an end-user to use the Oloid Connect for app, the Tenant admin must perform the following configuration in the Oloid Platform.

- Set up Oloid Connect Application and Connection (tenant admin)
  For more details, see [Oloid Platform Configuration for Oloid Connect App](https://oloid.help/en/articles/8655943-oloid-platform-configuration-for-oloid-connect-app). To enable and configure Intent Screen, see [How to configure intent screen](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen)
- Create user and assign user to connection (supervisor can do in supervisor portal). For creating users and assign credential to users, see [User Onboarding](https://oloid.help/en/articles/8463554-user-onboarding) guide
- Configure Oloid Connect Endpoint

  <Note>
    **Note:** Oloid Connect Endpoint is created in the Oloid Connect app.
  </Note>

  For more details, see [How to configure Oloid Connect Endpoint](https://oloid.help/en/articles/10550185-how-to-configure-oloid-connect-endpoint)
- Create and Configure Endpoint Template (both)
  For more details, see [How to create and configure Oloid Connect endpoint template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template#h_f874845dd7)
- Grant Supervisor permission to add or delete users in the Oloid Connect app
  For more details, [How to Activate Add User Action on the App for Supervisor](https://oloid.help/en/articles/9127132-how-to-activate-add-user-action-on-the-app-for-supervisor)
- Grant Supervisor permission to pair the endpoint in Oloid Connect app

### Oloid Connect App

Endpoint pairing in Oloid Connect generates an endpoint ID with endpoint details in the Oloid Portal. For details, see [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint?q=endpoint+template)

Once the endpoint is paired successfully, you can log into the Oloid Connect App. For details, see [How to log into the admin mode of Oloid Connect App as a Supervisor/Admin](https://oloid.help/en/articles/8671144-how-to-log-into-the-admin-mode-of-oloid-connect-app-as-a-supervisor-admin).
