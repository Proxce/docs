**Prerequisite:**

Windows Passkey must be enabled in the Tenant Admin Portal.

**Steps to add Passkey:**

1. Log in to the **Supervisor App**.
2. On the Admin Home screen, select **User Management**.
   ![Supervisor App: Assign Passkey - screenshot 1](/images/intercom/11829502/image-a1f6782b.png)
   The **Home** screen is displayed.
3. Select the preferred user to view details.
   ![Supervisor App: Assign Passkey - screenshot 2](/images/intercom/11829502/image-8ac124ae.png)
4. Go to **Passkey** tab > select +**Passkey**.

   ![Supervisor App: Assign Passkey - screenshot 3](/images/intercom/11829502/image-30bb22d6.png)
   The **Create Passkey** pop-up box is displayed
5. On the pop-up box, do the following:
   1. Enter **Display Name**.
   2. Enter **Domain Name**.
   3. Enter **Username**.
   4. Select **Preferred Machine**.
   5. Click **Generate**.
      ![Supervisor App: Assign Passkey - screenshot 4](/images/intercom/11829502/image-9057d398.png)
      The Passkey is successfully assigned.
      ![Supervisor App: Assign Passkey - screenshot 5](/images/intercom/11829502/image-e478a836.png)
