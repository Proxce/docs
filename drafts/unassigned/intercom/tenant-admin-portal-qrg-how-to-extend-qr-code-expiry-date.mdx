## Steps to Extend QR Code Expiry Date

1. Log in to the **Tenant Admin Portal**.
2. Go to **Directory > Users >** click **preferred user.**
   ![How to Extend QR Code Expiry Date - screenshot 2](/images/intercom/13333301/image-cdcf4843.png)
   The user detail page is displayed.
3. Click **Credentials > QR Code > Extend Expiry.**
   ![How to Extend QR Code Expiry Date - screenshot 3](/images/intercom/13333301/75131c30-5257-46c5-a39a-cc292c40be8e-9b9faafb.png)
   The QR code page is displayed.
4. Do the following:
   1. Select **QR Code Validity**.
   2. Click **Save.**
      ![How to Extend QR Code Expiry Date - screenshot 4](/images/intercom/13333301/image-b4f7afd1.png)
      The **QR code validity** is extended successfully.
