You can use the following authentication ways

Badge+Face
QR+Face
PIN+

### Prerequisite

- In the Tenant Admin Portal, Admin must do the following:
  - Assign badge to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
  - Add PIN for the user. For more details, refer [How to add PIN as credential to users.](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Assign QR Code to the user. For more details, refer [How to create QR code as credential for User.](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-for-user)
  - Assign a face credential to the user. For more details, refer [Face Onboarding](https://oloid.help/en/articles/8413861-face-onboarding)
  - Enable Badge, PIN, QR and Face option under the Oloid Connect application in Authentication tab. For more details, refer [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal#h_f5cb6be542)

## Steps to log in using badge and Face

## Prerequisite

1. Launch the **Oloid Connect App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the Auth selection screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to Authenticate using Oloid Connect... - screenshot 1](/images/intercom/12136059/image-64bf3a75.png)
   The Auth selection screen is displayed.
2. Tap **Login with Badge.**
   ![How to Authenticate using Oloid Connect... - screenshot 2](/images/intercom/12136059/913438c7-537f-4756-a23d-f9366dd9934f-f9d2fc23.png)
   The **Scan Badge at the Reader** screen is displayed.
   ![How to Authenticate using Oloid Connect... - screenshot 3](/images/intercom/12136059/image-422f6dee.png)
3. Tap the **Badge** on the **Reader** to scan it.

   <Note>
     **Note:** The Card Reader should be connected to your iPad.
   </Note>

   ![How to Authenticate using Oloid Connect... - screenshot 4](/images/intercom/12136059/image-b04b7a98.png)
   On Badge authentication, The Camera opens to capture the user's face.
4. Place your Face inside the ovel shape in the screen.

![How to Authenticate using Oloid Connect... - screenshot 5](/images/intercom/12136059/image-d47044ee.png)

After successful authentication user details are appeared on the top of the screen.

![How to Authenticate using Oloid Connect... - screenshot 6](/images/intercom/12136059/image-6d721999.png)

On Face authentication, you are logged in to the **HRIS** platform successfully.
