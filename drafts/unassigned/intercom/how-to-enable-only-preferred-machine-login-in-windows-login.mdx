## Introduction

In Oloid Portal, enabling Only Preferred Machine Login feature allow domain credentials to be used only in preferred machine to log in to windows system.

## Steps to Enable Only Preferred Machine Login

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Enable Only Preferred Machine... - screenshot 1](/images/intercom/11079846/2384b68f-77d9-4ed6-a6c3-515e79034b09-ce9caff2.png)
   The **Endpoints** page is displayed.
3. Select the paired Windows Login Endpoint.
   ![How to Enable Only Preferred Machine... - screenshot 2](/images/intercom/11079846/8cbc4dfd-c155-44b8-99eb-c3413e16fec1-4a2e2014.png)
   The **Endpoint Details** page is displayed.
   ![How to Enable Only Preferred Machine... - screenshot 3](/images/intercom/11079846/image-dfd08c2d.png)
4. Go to **Configure** > **Endpoint Settings** tab.
   ![How to Enable Only Preferred Machine... - screenshot 4](/images/intercom/11079846/21dd6422-2064-4fe7-8740-6a58d39013b9-67bec4e9.png)
5. **Enable Only Preferred Machine Login** toggle button to allow domain credentials to be used only in preferred machine to log in to windows system.
   ![How to Enable Only Preferred Machine... - screenshot 5](/images/intercom/11079846/d6c85dd7-f99b-4898-af23-2db9fb981c91-d8f85555.png)
6. Click **Save**.
   ![How to Enable Only Preferred Machine... - screenshot 6](/images/intercom/11079846/330d7b21-7b4f-46d9-8f2e-6458e0659007-35dfc04f.png)
   The configuration is saved successfully.
   For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
