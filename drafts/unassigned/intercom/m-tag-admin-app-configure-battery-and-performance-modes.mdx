Configure Battery and Performance Modes

To configure battery,

1. Launch the M-Tag admin app.

2. Sign in to the app.

The details screen displays a list of MAC Ids of the available M-Tags.

3. Select a registered M-Tag.

4. In device details screen, Battery settings is at the bottom of the page.

5. Battery Setting:

a) Displays Normal, when battery percentage is 100%

b) Displays Low, when battery percentage is less than 20%

c) Voltage remains constant 2.92V

To configure performance modes,

1. Launch the M-Tag admin app.

2. Sign in to the app.

The details screen displays a list of MAC Ids of the available M-Tags.

3. Select an unregistered M-Tag.

4. Do the following, in the M-Tag Registration screen:

a) Enter name of the M-Tag

b) Select one from the following performance modes at the bottom of the screen:

i. High Performance

ii. Optimal Performance

iii. Battery Saving

iv. Custom

<Note>
  **Note:** High Performance, Optimal Performance, Battery Saving mode the setting is pre-defined.
</Note>

5. Select Custom to configure performance mode on your own.

a) Toggle on IR Sensor to hold to unlock

<Note>
  **Note:** For push notification, background, and foreground unlock modes IR Sensor is not required.
</Note>

b) Select IR Sensor Distance to change the distance of the hand gesture:

i. Immediate

ii. Near

iii. Far

c) Select Advertising Interval Mode to change the signal strength:

i. Low

ii. Medium

iii. High

d) Select Bluetooth Distance to change the distance from the app to M-Tag:

i. Low

ii. Medium

iii. High

After customizing the performance mode, next tap Register

6. The M-Tag is successfully updated and registered.
