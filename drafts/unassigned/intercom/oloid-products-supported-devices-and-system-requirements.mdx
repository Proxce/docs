## Introduction

Oloid provides Passwordless authentication for frontline and shared devices across Windows, macOS, Android and iOS. Before you install an Oloid application, make sure your devices are supported and meet the minimum hardware and software requirements for that product.

Use the table below to find the devices supported by each Oloid product. For detailed requirements, such as operating system version, memory, storage and camera specifications, open the requirements document linked for that product.

## Badge Readers and Card Types

To sign in with an employee badge or NFC tag, connect a badge reader that supports your card type. Oloid supports rf IDEAS WAVE ID Plus, WAVE ID Lite and WAVE ID SP Plus readers. Supported card formats vary by reader model.

For the full list of supported card types and readers, see [Oloid Supported Card Types](/more/passwordless-authenticator/oloid-supported-card-types).
