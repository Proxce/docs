## Introduction

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user.
- Ensure that Epic SSO is enabled.
- Ensure the Tray application is running in the background.
- The badge reader must be connected to the Windows system.
- Badge Out options must be configured. Refer: [Windows Login - How to Configure Badge Out option](https://oloid.help/en/articles/10616183-windows-login-how-to-configure-badge-out-option)

## Steps to Sign Out using Badge ID

1. On the Lock screen, select **Login with OLOID**.
   ![How to Sign Out using Badge - Epic... - screenshot 1](/images/intercom/14796418/image-dc9b6bb9.png)
   The **Scan Badge** screen is displayed.

   <Note>
     **Note:**

     2. Tap the **Badge** on the **Badge Reader** to scan it.
        ![How to Sign Out using Badge - Epic... - screenshot 2](/images/intercom/14796418/image-3a908d43.png)
        The **Enter PIN** screen is displayed.
     3. Enter the **PIN**.
        ![How to Sign Out using Badge - Epic... - screenshot 3](/images/intercom/14796418/image-a6aa3d47.png)
        The Windows homepage is displayed.
        ![How to Sign Out using Badge - Epic... - screenshot 4](/images/intercom/14796418/image-14c0007f.png)
     4. Log in to **Epic Hyperspace** refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](https://oloid.help/en/articles/14780782-how-to-log-in-to-epic-hyperspace-using-badge-id-pin)**
        User is successfully logged in to **Epic Hyperspace.**
     5. Sign Out using badge out:
        - [When SSO is not enabled](#when-sso-is-not-enabled).
        - [When SSO is enabled](#when-sso-is-enabled)
          ![How to Sign Out using Badge - Epic... - screenshot 5](/images/intercom/14796418/image-0331ce57.png)
   </Note>

### When SSO is not enabled

Tap the **Badge** on the **Badge Reader** to scan it.

![How to Sign Out using Badge - Epic... - screenshot 6](/images/intercom/14796418/image-3398a354.png)

User is signed out of Epic Hyperspace.

![How to Sign Out using Badge - Epic... - screenshot 7](/images/intercom/14796418/image-42931c98.png)

### When SSO is enabled

Tap the **Badge** on the **Badge Reader** to scan it.

![How to Sign Out using Badge - Epic... - screenshot 8](/images/intercom/14796418/image-2362c786.png)

Your Windows system is successfully locked, and the **Lock** screen appears.

<Note>
  **Note:** If the Windows Login application is configured with the **Sign out of Windows** option, all open applications in the system will close, and the **Lock** screen will appear.
</Note>

![How to Sign Out using Badge - Epic... - screenshot 9](/images/intercom/14796418/image-bbae8b52.png)

The user is signed out.
