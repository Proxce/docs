## Introduction

In Oloid Portal, enabling Auto recover Endpoint feature in Windows Login application allows you to recover the existing endpoint configuration in the Windows Authenticator App. Then, you must sync the application to pair the endpoint if required.

## Steps to enable Auto-recover Endpoint

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to enable Auto-recover Endpoint in... - screenshot 1](/images/intercom/11008747/image-6eeaf72f.png)
   The application page is displayed.
   ![How to enable Auto-recover Endpoint in... - screenshot 2](/images/intercom/11008747/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to enable Auto-recover Endpoint in... - screenshot 3](/images/intercom/11008747/d6ac5f50-d13c-4c30-8c82-f1ccbdbe53e2-c76e4361.png)
4. Turn on **Auto-recover Endpoint** toggle button to automatically recover the endpoint configuration.
   ![How to enable Auto-recover Endpoint in... - screenshot 4](/images/intercom/11008747/0ea9a799-b1f6-41a6-b3d8-92d8ccbd1d79-6b56e580.png)

Click **Save**.

![How to enable Auto-recover Endpoint in... - screenshot 5](/images/intercom/11008747/610686bf-09a9-4e9c-9344-c4e62c68b52e-928d1bb6.png)

The configuration is saved successfully.

<Note>
  **Note:** In **Windows Authenticator** app, you must sync the configuration to Auto-recover Endpoint. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
</Note>

## Steps to check Auto-recover Endpoint in Oloid Supervisor app

1. Launch the Oloid Supervisor app.
2. Click **Yes, pair my device.**
   ![How to enable Auto-recover Endpoint in... - screenshot 6](/images/intercom/11008747/f6ea5828-eb44-47d4-af7f-0099378dde38-a06bb740.png)
   Welcome screen is displayed.
   ![How to enable Auto-recover Endpoint in... - screenshot 7](/images/intercom/11008747/image-60198f6f.png)
   After the endpoint pairing completes, the **Device pairing success** page is displayed.
   ![How to enable Auto-recover Endpoint in... - screenshot 8](/images/intercom/11008747/image-6fe1e397.png)

   <Note>
     **Note:** You must download the auto-configure file to your local system. For more information, refer to [How to generate Auto-Pair config file for Windows Login in Oloid Portal
   </Note>

   ](https://oloid.help/en/articles/10441578-how-to-generate-auto-pair-config-file-for-windows-login-in-oloid-portal)
