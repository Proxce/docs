## Steps to Delete the QR Code

1. Log in to the **Tenant Admin Portal**.
2. Go to **Directory > Users > Credentials** > click **QR Code**.
   QR code page is displayed.
3. Click Delete icon.
4. Confirm Deletion pop-up box is displayed.
5. Click Delete.
   The QR code is deleted successfully.
