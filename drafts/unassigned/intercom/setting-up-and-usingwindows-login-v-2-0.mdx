## Setting Up and Using Windows Login 2.0

Oloid’s **Windows Login 2.0** is an advanced, secure, and scalable passwordless authentication solution that enables enterprise users to log into Windows devices and enterprise applications using **physical identity factors** such as **Face, Badge, NFC, and PIN**.

Windows Login 2.0 introduces improved **performance, device management, security controls, and deployment flexibility**, making it ideal for large-scale enterprise environments with shared or distributed systems.

With Windows Login 2.0:

- Users **do not need to remember or enter passwords**
- Authentication is **faster and more reliable**
- Access is **revoked instantly** when users are deactivated
- Supports **multi-factor authentication with factor sequencing**
- Enhanced support for **shared device environments**

---

### Prerequisites

Before setting up Windows Login 2.0, ensure:

- You have access to the **Tenant Admin Portal.**
- Ensure that the Oloid Tray Application is running in the background.
- Supervisor App (latest version compatible with Windows 2.0) is installed.
- Devices meet **Windows Login 2.0 system requirements.** For more information, refer: [Windows Login Version 2 - Hardware and Software Requirements](https://oloid.help/en/articles/13670511-windows-login-version-2-hardware-and-software-requirements)
- Network connectivity and required ports are configured
- Users are created in the system and ready for assignment

### Installation and Device Configuration

Windows Login 2.0 is installed and managed through the **Supervisor App**.

### Step 1: Download Windows Login 2.0

- Log in to **Tenant Admin Portal**
- Navigate to **Tenant Settings > Oloid Apps.**
- Download the **Windows Login 2.0 installer**

For more information, refer: [Windows Login v 2.0 - How to download Windows Login v 2.0 installer file from Tenant Admin Portal](https://oloid.help/en/articles/15069295-windows-login-v-2-0-how-to-download-windows-login-v-2-0-installer-file-from-tenant-admin-portal)

### Step 2: Install Windows Login 2.0

- Run the installer on the target Windows device
- Complete installation with administrator privileges

For more information, refer: [Windows Login v2.0 - How to Download, Install, and Auto-Pair Windows Login v 2.0 App](https://oloid.help/en/articles/13670102-windows-login-v2-0-how-to-download-install-and-auto-pair-windows-login-v-2-0-app)

### Step 3: Configure via Supervisor App

- Launch the Supervisor App
- Register the device
- Link the device to the appropriate tenant and environment
- Sync configurations

For detailed instructions, refer to:
**Setting up and using Supervisor App**
