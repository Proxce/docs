**Chrome vault > Details tab**

pre-requisite:

To edit the Details tab, you need to create a Passwordless Chrome Vault application in the Oloid Portal. If you haven't created it yet, refer to [How to Create and Configure a Chrome Vault Application](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application)

## How to set or select the time zone for the Chrome Vault application?

Steps To select the time zone for the Chrome Vault application:

a. Click on the **Chrome Vault** application you want to edit.

b. In the *Details* tab of the application page, find the **Time Zone** dropdown list.

c. Click on the dropdown list to see the available time zones.

d. Select the appropriate time zone for your application (optional).

f. Click **Save**.

## How to set Session Limit for Chrome Vault?

**A4:**

To set the Session Limit for Chrome Vault, follow these steps:

1. Log in to the Oloid Portal.
2. Go to the *Applications* page.
3. Click on the *Chrome Vault* application you want to edit.
4. Navigate to the *Configure* tab.
5. Click on *Settings*.
6. Under the *Time-out durations for Re-authentication* section, find the *Session Limit* field.
7. Set the maximum duration a user can remain signed into Chrome Vault (up to a maximum of 55 minutes).
8. Save your changes.
