## Introduction

The Configure tab for the Chrome Vault application in the Tenant Admin portal allows Admins control vault behavior, security settings, session timeouts, and user experience options. From here, you can enable features like auto-submit, password copy, face camera in a new tab, passkey saving, and customize authentication button labels.

## Prerequisite

You must create a Chrome Vault application in the Tenant Admin Portal. To create refer [How to Create and Configure Chrome Vault Application in the Tenant Admin Portal](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application-in-the-tenant-admin-portal).

## Steps to Setup Configure Tab

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click on the preferred Oloid Vault application.
   ![How to Setup Configure tab for Chrome... - screenshot 1](/images/intercom/12468363/image-df79047a.png)
   The application detail page is displayed.
3. Go to **Configure** tab and do the following:
   1. [Configure Settings](#configure-settings)
   2. [Customize Button](#customize-buttons)

### Configure Settings

#### Vault Behavior

1. **Enable Auto-Submit:** Turn on this toggle toautomatically submits credentials after successful authentication, streamlining the login process for users.
2. **Enable Copy Password:** Turn on this toggle to allow users to copy passwords from the Oloid Vault home page after logging in.
3. **Enable Face Camera to open in a new Tab:** Turn on this toggle to open the face camera in a new tab for Chrome Vault users.
4. **Enable Saving Passkey:** Turn on this toggle to allow users to save passkeys within the Chrome vault application for websites supporting passkey logins.
   ![How to Setup Configure tab for Chrome... - screenshot 2](/images/intercom/12468363/842fca1b-c242-4dda-b4b2-fa6eaa9e4167-22b5664f.png)

#### Set Time-out durations for Re-authentication

1. **Session Limit:** Set the maximum duration a user can remain signed into the Chrome Vault per session.

   <Note>
     **Note:** The maximum session duration that can be set is **55 minutes**.
   </Note>

2. **Inactivity Timer:**  Turn on this toggle to protect user sessions from unauthorized access. Set the timer to automatically log off the user after a specified period of inactivity.

   <Note>
     **Note:** When this option is enabled, re-authentication will be enforced for every new website login, overriding the session time limit.
   </Note>

3. Click **Save**.
4. **Apply Endpoint Template:** *Coming Soon*
   ![How to Setup Configure tab for Chrome... - screenshot 3](/images/intercom/12468363/image-35e32b44.png)
   The setting menu is configured successfully.
   ![How to Setup Configure tab for Chrome... - screenshot 4](/images/intercom/12468363/image-16787f1e.png)

### Customize Buttons

1. Select **Customize Buttons** from the left menu panel.
2. Enter the Button Label in the text field.

   <Note>
     **Note:** Default setting is **'Verify with &lt;Credential Name>'**.
   </Note>

3. Click **Save**.
   ![How to Setup Configure tab for Chrome... - screenshot 5](/images/intercom/12468363/image-eb20e216.png)
   The Customize Button is updated successfully.
   ![How to Setup Configure tab for Chrome... - screenshot 6](/images/intercom/12468363/image-58ba5ad5.png)
