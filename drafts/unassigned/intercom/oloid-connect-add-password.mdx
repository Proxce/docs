## Steps to add Password for Windows Domain User

1. Log in to **Admin Mode** in **Oloid Connect**.

   <Note>
     **Note:** For more information about logging in to Admin Mode, see[**How to log into the admin mode of Oloid Connect App as a Supervisor/Admin**](https://oloid.help/en/articles/8671144-how-to-log-into-the-admin-mode-of-oloid-connect-app-as-a-supervisor-admin)**.**
   </Note>

   The **Users** screen is displayed.
2. Select **user**.
   ![Oloid Connect: Add Password - screenshot 1](/images/intercom/10299840/af57dcff-760e-47b6-8f98-ba089027cd10-f1208d2c.png)
   The **details** screen is displayed.
3. Go to **Password** > tap **Create Credential**.
   ![Oloid Connect: Add Password - screenshot 2](/images/intercom/10299840/image-c6e44180.png)
   The **Create Credentials** pop-up is displayed.
   ![Oloid Connect: Add Password - screenshot 3](/images/intercom/10299840/image-ffba548f.png)
4. Do the following.
   1. Select **Windows Domain User** from the **User type** dropdown.
   2. Enter **Display Name**.
   3. Enter **Domain Name**.
   4. Select **Preferred Machine** from the dropdown. (Optional)
   5. Enter **User Name**.
   6. Enter **Password**.(Optional)
   7. Click **Create**.
      The Windows Domain Password is created for the user successfully.
      ![Oloid Connect: Add Password - screenshot 4](/images/intercom/10299840/image-55e29e60.png)

## Steps to add Password for Windows Local User

1. Log in to **Admin Mode** in **Oloid Connect**.
   The **Users** screen is displayed.
2. Select **user**.
   ![Oloid Connect: Add Password - screenshot 5](/images/intercom/10299840/af57dcff-760e-47b6-8f98-ba089027cd10-bc58c954.png)
   The **details** screen is displayed.
3. Go to **Password** > tap **Create Credential**.
   ![Oloid Connect: Add Password - screenshot 6](/images/intercom/10299840/image-71a9d158.png)
   The **Create Credentials** pop-up is displayed.
   ![Oloid Connect: Add Password - screenshot 7](/images/intercom/10299840/image-a85ab95f.png)
4. Do the following.
   1. Select **Windows Local User** from the **User Type** dropdown.
   2. Enter **Display Name**.
   3. Select **Machine Name** from the dropdown.
   4. Enter **User Name**.
   5. Enter **Password**. (Optional)
   6. Click **Create**.
      The Windows Local Password is created for the user successfully.
      ![Oloid Connect: Add Password - screenshot 8](/images/intercom/10299840/image-09ff08db.png)
