Steps to Add Location:

1. Go to **App Store** and download **Oloid Connect** ![Oloid Connect: Add Location - screenshot 1](/images/intercom/10315344/image-6def886f.png)App.
2. Install the application and upon successful installation, launch the app.
   The **Welcome** screen is displayed.
   ![Oloid Connect: Add Location - screenshot 2](/images/intercom/10315344/3c4f92ad-a669-4a54-9e1c-04413a264e6b-f8a233e9.png)
   Enter **Tenant Name**, then tap **Next.**
3. Do the following:
   1. Enter your email ID in the **Email** text field.
   2. Enter your password in the **Password** text field.
      ![Oloid Connect: Add Location - screenshot 3](/images/intercom/10315344/8a7eea6a-5915-4ac0-913f-dcad9a2cbbc3-bf6c7586.png)
4. Log in to **Admin Mode**.

   <Note>
     **Note:** For knowing more about logging in to Admin Mode, see **How to log into the admin mode of Oloid Connect App as a Supervisor/Admin.** You can also log in with SSO. See How to Login with Google SSO in Oloid Connect , How to login with Microsoft SSO in Oloid connect, and How to Login with Okta SSO in Oloid Connect to know more.
   </Note>

   The Allow "OloidConnect" to use your location? Pop-up box is displayed.

   <Note>
     **Note:** This pop-up is displayed only the first time you open the App. See How to update Location to change the Location settings.
   </Note>

   ![Oloid Connect: Add Location - screenshot 4](/images/intercom/10315344/image-c8102cb1.png)
   On the pop-up box, tap a permission type.
5. Select an option:
   - **Allow Once**: Every time you open the app, it’ll ask to use your location.
   - **Allow While Using App:** The app can use your location only when you're using that app.
   - **Don't Allow:** The app cannot use your location, even when you’re using the app.
     The Location is added to the Oloid Connect App and the Setting screen is displayed.
     ![Oloid Connect: Add Location - screenshot 5](/images/intercom/10315344/image-e260fb53.png)
6. Do the following on the **Settings** page.
   1. Add **Template** (optional).
   2. Enter **Endpoint Name**.
   3. Select Application Name from **Application Name** list.
   4. Tap **Pair.**
      The settings are saved and the Device Setup success message is displayed.
      ![Oloid Connect: Add Location - screenshot 6](/images/intercom/10315344/image-f1bb79ad.png)
      The application prompts you to log out of Admin mode.
      ![Oloid Connect: Add Location - screenshot 7](/images/intercom/10315344/image-494deb27.png)
7. Do one of the following:
   1. Click **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to capture live Images for facial transactions.

      <Note>
        **Note:** To go back to admin mode, double-click on preview mode and tap **Yes- To Continue**.
      </Note>

   2. Click **No** to stay logged in to the admin mode.
      You can now log in to the **Oloid Portal** to check the location added to the specific endpoint.
