## Steps to add QR code

1. Log in to admin mode in **Oloid verify** App.
   See **[How to log into the admin mode of Oloid Verify App as a Supervisor/Admin](https://oloid.help/en/articles/8671139-how-to-log-into-the-admin-mode-of-oloid-verify-app-as-a-supervisor-admin)** too know more
   The **Users** page is displayed.
2. Select a user.
   ![Oloid Verify: Add QR Code - screenshot 1](/images/intercom/10198762/701841f2-22b4-48d8-9fc8-62ce30e70da6-086c5587.png)
   The user details page is displayed.
   ![Oloid Verify: Add QR Code - screenshot 2](/images/intercom/10198762/65823c68-a395-457a-b0d6-18b8153c2a4d-c135d5ee.png)
3. Go to **QR Code** > click **+ Add QR Code**.
   ![Oloid Verify: Add QR Code - screenshot 3](/images/intercom/10198762/9d21f690-2cef-4df5-8bcb-40a8b66e1aa8-a033f51c.png)
   The **Add QR Code** pop-up is displayed.
   ![Oloid Verify: Add QR Code - screenshot 4](/images/intercom/10198762/image-d1e8e9fc.png)
4. On the pop-up, do the following.
   1. Select **QR Code Validity**.

      <Note>
        **Note:** The default value for QR Code validity is Dec 31, 2099 23:59.
      </Note>

   2. Enter Email ID(s) in **Share QR Code with**. (Optional)

      <Note>
        **Note:** Separate the Email IDs with a comma.
      </Note>

   3. Click **Save**.
      The QR Code is generated successfully.
      ![Oloid Verify: Add QR Code - screenshot 5](/images/intercom/10198762/image-1c3761ad.png)
