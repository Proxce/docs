### Install and Configure Citrix Workspace

1. On your **local** machine, go to [https://www.citrix.com/downloads/workspace-app/windows/workspace-app-for-windows-latest1.html](https://www.citrix.com/downloads/workspace-app/windows/workspace-app-for-windows-latest1.html)
   ![Install, Pair and Configure Oloid... - screenshot 1](/images/intercom/17132215/1-ce02c63c.png)
   Welcome to Citrix Workspace app screen is displayed.
2. Click **Continue**.

   ![Install, Pair and Configure Oloid... - screenshot 2](/images/intercom/17132215/2-604b9efa.png)
   The Citrix License Agreement screen is displayed.
3. Select **I agree** checkbox and click **Continue**.

   ![Install, Pair and Configure Oloid... - screenshot 3](/images/intercom/17132215/3-59e9286b.png)
   The Add-on(s) screen is displayed.
4. Select the preferred Add-on(s) and click Install.

   ![Install, Pair and Configure Oloid... - screenshot 4](/images/intercom/17132215/4-6f1f8ea8.png)
   If prompted, restart your Windows device.
5. Launch **Citrix Workspace**.
   The Welcome screen is displayed.
6. Enter the **Store URL** > **Continue**.

   ![Install, Pair and Configure Oloid... - screenshot 5](/images/intercom/17132215/5-367ee398.png)
   The Citrix Workspace pop-up box is displayed.
7. Do the following:
   1. Enter the User name.
   2. Enter Password.
   3. Click Log ON.
      ![Install, Pair and Configure Oloid... - screenshot 6](/images/intercom/17132215/6-b0eadee5.png)
      You are successfully logged into Citrix Workspace.
8. In the Citrix Workspace app, go to the Desktops Tab on top and select the published virtual desktop to connect.

   ![Install, Pair and Configure Oloid... - screenshot 7](/images/intercom/17132215/7-8cc31bef.png)
   Wait for the Windows VDI session to start.
9. You have successfully logged into the Virtual Desktop.
   Citrix should automatically use your Workspace credentials to sign in to the Windows session. If Windows prompts you for credentials, enter the same username and password.

   <Note>
     **Note:** If Microsoft Edge prompts you to create or configure a profile when you first access the VDI, complete the required setup before proceeding.
   </Note>

### Install the Oloid Windows Authenticator App on Citrix VDI

1. On your **local** device, login to Tenant Admin Portal.
2. Go to User profile > Tenant Settings > Oloid App.
3. Download the latest **Windows Authenticator app v2** installer.
4. Get the installer from your local machine into the remote session using whichever of these works given the customer's Citrix policy:
   1. **Clipboard copy-paste** — copy locally (Ctrl+C), paste inside the session's File Explorer (Ctrl+V).
   2. **Browser download inside the session** — if the session has internet access, open a browser inside it and download directly from the tenant URL in 2.1.
      ![Install, Pair and Configure Oloid... - screenshot 8](/images/intercom/17132215/8-5fbaadd3.png)
5. Run the installer inside the session (as administrator if not prompted automatically) and step through the wizard.
6. The **Oloid Passwordless Login Setup** pop-up box is displayed.
7. Do the following
   1. Click **Start**.
      ![Install, Pair and Configure Oloid... - screenshot 9](/images/intercom/17132215/image-b7a55ec8.png)
      The **End-User License Agreement** page is displayed.
   2. Select **License Agreement** checkbox and click **Next**.
      ![Install, Pair and Configure Oloid... - screenshot 10](/images/intercom/17132215/image-9bbdd795.png)
      The **Destination Folder** screen is displayed.
   3. Use the default path to install the application and click **Next**.
      ![Install, Pair and Configure Oloid... - screenshot 11](/images/intercom/17132215/image-479dd967.png)
      The **Capabilities** pop-up box is displayed.
   4. Select the required feature check box(es) and click **Next**.

      <Note>
        **Note:** The following provides additional details about each capability:
      </Note>

      1. **On-device Face Recognition:** Authenticates users locally using facial recognition even if the device is offline.
      2. **Local Cache Server:** Enables users to log in and authenticate using locally stored data when the network is unavailable or experiencing connectivity issues. This option is **selected by default**.
      3. **Presence Detection:** Detects user presence to enable hands-free login and auto-lock when the user leaves.
      4. **Oloid Launcher:** Provides a central interface to launch apps and workflows after authentication.
      5. **EPIC Integration:** Enables secure, passwordless access to Epic workflows through seamless authentication.
         ![Install, Pair and Configure Oloid... - screenshot 12](/images/intercom/17132215/image-fcb0b640.png)
         The **Proxy Settings** screen is displayed.
   5. Select one of the following:
      1. **None:** Connects to OLOID services without using a proxy.
      2. **Use Local System Proxy:** Uses the proxy settings already configured on the Windows device to connect to OLOID services.
      3. **Use Explicit Proxy:** Uses a specific proxy server to connect to OLOID services. Enter the proxy server address in the **URL** field.
      4. Click **Next**.
         ![Install, Pair and Configure Oloid... - screenshot 13](/images/intercom/17132215/image-8808c1dc.png)
         The Autopair Settings screen is displayed.
   6. Do one of the following:
      1. Select **Manual** > click **Next.**

         <Note>
           **Note:** Select this option to pair the Windows Login App after installation. Once installed, you can pair the application using one of the following methods:
         </Note>

         - **Supervisor App:** Pair the Windows app using the **Supervisor App.** To pair the Windows app via supervisor app**,** refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app) or
         - **Automatic Config File:** Pair the Windows app using the **Auto-Pair Config File.** To pair the Windows app via Auto-Pair Config File, refer [Windows Login - How to pair Supervisor App using auto-pair config file option](https://oloid.help/en/articles/9637781-windows-login-how-to-pair-supervisor-app-using-auto-pair-config-file-option)
           ![Install, Pair and Configure Oloid... - screenshot 14](/images/intercom/17132215/image-19a7af4b.png)
           (Or)
      2. Select **Automatic** > Enter **Encoded String** in Text Box> click **Next.**

         <Note>
           **Note:**

              - The **Automatic** option enables the endpoint to pair automatically during installation. The pairing is completed after the Windows device restarts.
              - To get the **Encoded string**, go to the Tenant Admin Portal and select **TEXT** as the Auto-pair config file format. Then, copy the config text or download the TEXT file. To copy or download the Text format refer, [Windows Login - How to Generate and Download Auto-Pair config file for Windows Login in Tenant Admin Portal](https://oloid.help/en/articles/10441578-windows-login-how-to-generate-and-download-auto-pair-config-file-for-windows-login-in-tenant-admin-portal)
                ![Install, Pair and Configure Oloid... - screenshot 15](/images/intercom/17132215/image-cb4dac84.png)
                The **Ready to Install** screen is displayed.
           3. Click **Install**.
              ![Install, Pair and Configure Oloid... - screenshot 16](/images/intercom/17132215/image-eb00834d.png)
         </Note>

Installation is complete once the machine has restarted. This restart ends your Citrix session. **OloidPasswordlessAdminNew** should be installed on the desktop in the VM Windows session.

### Add a Citrix VDI Endpoint to a Group

1. Sign in to the **Oloid Tenant Admin Portal**.
2. Go to **Groups**.
3. Select the group to which you want to assign the Citrix VDI endpoint.
4. Select the **Endpoints** tab.
5. Click **Add Endpoint**.
6. Select and add the Windows VDI endpoint to the group.

Verify that the endpoint appears in the selected group.

### Configure Oloid Launcher Settings

1. Oloid Launcher configuration can be applied at three levels:
   - **Group:** In the Tenant Admin Portal, open the required group, select the three-dot menu, and select **Raw JSON** to configure Launcher settings.
   - **Application:** Open the required application, go to **Configure**, select the three-dot menu, and select **Raw JSON**.
   - **Endpoint:** Open the corresponding endpoint and configure the Launcher settings using **Raw JSON**.
     Refer to the **Oloid Configuration Guide** for the complete list of supported Launcher configuration keys and values.
