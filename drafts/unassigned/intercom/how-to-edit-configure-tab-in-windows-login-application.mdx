**Pre-requisite:**

You must create a Passwordless application of type Windows Login. For further details, refer [How to create a Windows Login Application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#:~:text=2%20weeks%20ago-,Steps%20to%20create%20and%20configure%20Windows%20Login%20application%3A,-Log%20in%20to)

Steps to edit Configure tab:

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, click on an Windows application to edit.
   ![How to edit Configure tab in Windows... - screenshot 1](/images/intercom/10766296/image-6eeaf72f.png)
   The application page is displayed.
3. Click the **Configure** tab.
   ![How to edit Configure tab in Windows... - screenshot 2](/images/intercom/10766296/image-e5bd1de3.png)
4. Do the following:

[Configure Settings tab](#configure-settings-tab)

[Configure rf IDEAS tab](#configure-rf-ideas-tab)

[Customize Buttons tab](#customize-buttons-tab)

## Configure Settings Tab

- **Enable Auto Launch Mode:** Select this option to auto-launch the Windows Login app in the login screen.
  ![How to edit Configure tab in Windows... - screenshot 3](/images/intercom/10766296/image-d1adbcb4.png)
- **Use Groups for Authorization:** *Coming Soon*
- **Auto Update Windows Device Agent:** Select this option to auto-update the Windows device agents on Windows endpoints run by this application.

  <Note>
    **Note:** Select the **Sync** option in the Supervisor App and then close the app. Wait for one hour before restarting. For details, see **[How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)**.
  </Note>

  ![How to edit Configure tab in Windows... - screenshot 4](/images/intercom/10766296/image-5af0dc05.png)
- **Validate Windows Credential:** Select this option to ensure Oloid Agent checks the validity of the user’s Windows credentials before logging in.
  ![How to edit Configure tab in Windows... - screenshot 5](/images/intercom/10766296/image-0135b04b.png)
- **Allow Credential Updates and Enrollment:** Select this option to allow users to self-enroll or update their credentials.
  ![How to edit Configure tab in Windows... - screenshot 6](/images/intercom/10766296/image-67e9a3ea.png)
- **Capture Windows User Events:** Select this option to capture Windows events for user logins, logouts, locks, unlocks, and credential provider details. All captured data is stored in the transaction tab.
  ![How to edit Configure tab in Windows... - screenshot 7](/images/intercom/10766296/image-4646f247.png)
- **Enable Manual Capture Accessibility:** Turn on this option to allow users to manually capture their face during face authentication.
  ![How to edit Configure tab in Windows... - screenshot 8](/images/intercom/10766296/image-cea27b4f.png)
- **Enable Badge Out:** Select **Badge out using Windows Service** option to allow users to log out of their Windows system using their badge. For details, refer to [Windows Login - How to configure Enable Badge Out option](https://oloid.help/en/articles/10616183-windows-login-how-to-enable-badge-out-option)
  ![How to edit Configure tab in Windows... - screenshot 9](/images/intercom/10766296/image-6f0c62ec.png)
- **Set Time-Out for Login Screen:** Select this option to allow users to configure the maximum time the system will wait on the login screen before timing out.
  ![How to edit Configure tab in Windows... - screenshot 10](/images/intercom/10766296/image-0e399276.png)
- **Master Admin override passcode:** Follow the onscreen instruction to create master admin override passcode. For details, refer [How to create device-admin passcode for Supervisor App](https://oloid.help/en/articles/9244629-how-to-create-device-admin-passcode-for-supervisor-app)
  ![How to edit Configure tab in Windows... - screenshot 11](/images/intercom/10766296/image-410f3bf9.png)

**Apply Endpoint Template**: Select a Windows Login endpoint template that is applied during the endpoint pairing process.

![How to edit Configure tab in Windows... - screenshot 12](/images/intercom/10766296/image-d0974a45.png)

## Configure rf IDEAS Tab

1. Do the following:
   1. Select **RFID Reader Type** from the **Select RFID reader type** dropdown .
   2. Enter **Description**. (Optional)
   3. Click to browse the file or drag the file to upload/download.
   4. Click **Save**.
      The application is updated successfully. For more details, refer [How to upload/download HWG file in Oloid Portal](https://oloid.help/en/articles/9215874-how-to-upload-download-hwg-file-in-oloid-portal)
      ![How to edit Configure tab in Windows... - screenshot 13](/images/intercom/10766296/image-4cc823ac.png)

## Customize Buttons Tab

- **Customize Authentication Button Labels**: Enter customized **Button Label** to display on the Windows application.
- Select **Enable Badge Options** to display on the Windows Login app.
  - Do one of the following:
    - Select **Enroll Badge Only** to enable Badge login
    - Select **Enroll Badge + Pin** to enable Badge and Pin login.
