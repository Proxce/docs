To enable Azure SSO:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to configure Azure SSO in Oloid... - screenshot 1](/images/intercom/10356885/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![Image](/images/intercom/10356885/dbb3ba06-85c5-488f-8762-8fdebf21e109-0a65913b.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > **Okta**.
5. Turn on **Enable Azure SSO** button.
   ![How to configure Azure SSO in Oloid... - screenshot 2](/images/intercom/10356885/image-81c2385c.png)
6. Click **Save**.
   The Azure SSO is configured.
