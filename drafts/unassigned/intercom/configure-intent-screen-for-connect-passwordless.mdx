**Show Intent Screen** option helps to set up the intent screen for the Endpoint Kiosk mode. This screen allows users to define their actions, such as entering a job code or selecting from multiple buttons.

<Note>
  **Note:** The Intent screen will be automatically disabled if Passwordless Configuration is enabled.
</Note>

To configure intent screen:

1. Do the following:
   1. Select Job-code.
      OR
   2. Select multi-button to choose the options.

## Multi button Configuration

Select one of the following:

- **Process data locally**: Handle data processing locally.
- **Conduct Survey**: Allow users to complete a survey.
- **Choose Departments**:Enable users to select a department.
