### 10.1 System Requirements

- **Hardware**: Minimum 8GB RAM, GPU (recommended for better performance)
- **Software Dependencies**: Python, Ultralytics YOLOv8, OpenCV, TensorFlow/PyTorch

### 10.2 Installation Instructions

Install Python (if not installed):

```
sudo apt install python3
```

Install required libraries:

```
pip install ultralytics opencv-python torch torchvision
```

3. Clone or download the Oloid Presence Detection module.

### 10.3 Running the Gadget Detection Model

1. Open a terminal or command prompt.

Run the following command to start detection:

```
python detect_gadgets.py --source webcam
```

3. The system will analyze the environment for unauthorized gadgets.
4. If a gadget is detected, the system will display a warning message and take predefined security actions.

### 10.4 Troubleshooting

- **Issue: Model not detecting gadgets correctly**
  - Ensure the webcam is functioning properly.
  - Check if the dataset includes diverse gadget types.
- **Issue: Performance lag**
  - Reduce image resolution.
  - Optimize model by reducing batch size.
