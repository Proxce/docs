Steps to invite a tenant admin:

1. Log in to **Oloid Portal.**
   The homepage is displayed.
2. Go to **user profile icon**
   The user profile menu is displayed.
3. Do one of the followings:
   1. Click **Tenant Settings**
      The Tenant Settings page is displayed.
      Click **Advance tab** > **Tenant admin** > **Invite tenant admin.**
      OR
      Click **Action** > **Invite Tenant admin**
   2. Go to **user profile icon** > **Invite admin.**
      The Invite Tenant Admin pop-up is displayed.
4. On the pop-up box, do the following:
   1. Enter **User name** or **Primary ID** of existing User in the search field.
   2. Select the accurate user name from the dropdown list.
   3. Select **Invite.**
      The tenant admin is listed on the **Tenant Admin** tab. An invite email is sent to the user for verification.
