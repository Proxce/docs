Incorporating Single Sign-On (SSO) into the Oloid's WebKey streamlines user access and enhances security. This document provides a step-by-step guide on configuring the Oloid's WebKey Application for SSO login.

## Step-by-Step Configuration

Follow these steps to configure WebKey Application for SSO Login :

### 1. Create Applications

Begin by creating the Passwordless application which is done in the Oloid Portal.

See, **[How to create Passwordless Application](https://oloid.help/en/articles/8294483-how-to-create-an-application-completed)** and **[How to Configure Application Type - Passwordless](https://oloid.help/en/articles/8300330-how-to-configure-application-type-passwordless)**

### 2.Create Connections

After creating the applications, it's time to organize users into connections. Connections are groups of users who will interact with the application functionalities provided by the paired endpoints.

This is done in the Oloid Portal. See, [How to create Connections](https://oloid.help/en/articles/8294297-how-to-create-connection)

### 3. Map Connections to Applications

Now that you have both application and connections in place, it's time to establish the link between them. This step ensures that users within the connections can access the functionalities provided by the designated application.

This is done in the Oloid Portal. See, **[Map Connections to Applications](https://oloid.help/en/articles/8304594-how-to-map-connection-to-application-in-oloid-portal)**

### 4. Configure Third-Party Application URL

You need to configure the third-party url to interact with Okta application.

You need to share the url with Oloid Team.

### 5. Enable Integration

You need to enable **HTTP Request** under Enable Integrations in the Oloid Portal.

This is done by Oloid Admin.

### 6. Selecting credential for authentication.

Select the authentication method to login to your Okta system. You can either user Face, Badge , Pin or a combination of Badge and Pin or NFC/ID and Pin, depending on your requirement.

This is done by Oloid Admin.

The Oloid WebKey is configured for SSO Login.

You can now use your Oloid WebKey Application.

Contact [Oloid Support](mailto:support@oloid.ai) if you need assistance.
