## Introduction

The Badge credential feature in the Tenant Admin Portal allows administrators to enable badge-based multi-factor authentication (MFA) for the Windows Login application. Once enabled, users can log in to Windows endpoints by scanning their badge or smart card.

## Steps to configure Badge credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application.
   ![How to configure Badge credential in... - screenshot 1](/images/intercom/11483850/image-5c78bf9e.png)
   The application page is displayed.
   ![How to configure Badge credential in... - screenshot 2](/images/intercom/11483850/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Authenticato**r tab.
4. Turn on **Badge ID** toggle.
   ![How to configure Badge credential in... - screenshot 3](/images/intercom/11483850/5f379f1d-fc57-4757-bbee-37fc92d974b4-bd058791.png)
   The **Advanced Settings** page is displayed.
5. Configure **Select Badge Input**, and **Badge Auth Source** on the Advanced Settings page.
   ![How to configure Badge credential in... - screenshot 4](/images/intercom/11483850/c4fb8411-6201-4eb5-a2e9-d15e0ab6ebc6-b5d5c47a.png)
6. Do the following setting for **Select Badge Input**.

   <Note>
     **Note:** You must consult your Oloid admin before you make any changes to badge input and type as it may result authentication error.
   </Note>

   ![How to configure Badge credential in... - screenshot 5](/images/intercom/11483850/image-1fb141d1.png)
   1. Configure **RFID HF/LF Settings**.
      - Select **SDK** to use the integrated SDK to handle badge input.
      - Select **Keyboard** to allow manual keyboard entry of badge IDs.
   2. Select **PC/SC (UID)** to read the card’s **unique identifier (UID)**. The UID is a number (numeric or binary) that is permanently stored on the RFID card.

      <Note>
        **Note:** This feature is automatically enabled when a **PC/SC-compatible connection** is added to the application.
      </Note>

   3. Select **RFID Badge Type** from the **Select Badge Type** drop-down list.
      ![How to configure Badge credential in... - screenshot 6](/images/intercom/11483850/image-b22922c5.png)
7. Select the following options for **Badge Auth Source**.
   1. Select **Hybrid: online First(default)**. This option verifies the updated badge information from the cloud.
   2. Select **Hybrid: on device-first.** This option checks the device’s local storage and verifies badge authentication based on the successful transaction.
      ![How to configure Badge credential in... - screenshot 7](/images/intercom/11483850/2e26af02-d344-4252-bf39-3e3b96b5ac29-edac6817.png)

Click **Save**.

The Badge authenticator for Windows Login application is configured successfully.
