## Introduction

In Oloid Portal, enabling the Capture Windows User Events feature in the Windows Login application track user activity, including log-in and out, and when the device is locked or unlocked. The feature also captures the authentication method used, such as face recognition, badge, NFC, or PIN.

## Steps to enable Capture Windows User Events

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to enable Capture Windows User... - screenshot 1](/images/intercom/10978430/image-6eeaf72f.png)
   The application page is displayed.
   ![How to enable Capture Windows User... - screenshot 2](/images/intercom/10978430/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to enable Capture Windows User... - screenshot 3](/images/intercom/10978430/d6ac5f50-d13c-4c30-8c82-f1ccbdbe53e2-aaefe3f2.png)

4. Turn on **Capture Windows User Events** toggle button to create events that track when an endpoint logs in and out.

   ![How to enable Capture Windows User... - screenshot 4](/images/intercom/10978430/fe5201a8-52e5-4f2b-9b09-5489724c1432-d82fe0cd.png)

Click **Save**.

![How to enable Capture Windows User... - screenshot 5](/images/intercom/10978430/9bdc1732-6517-406d-9a5f-58d7487a3adc-c26f6b1b.png)

The configuration is saved successfully. See, [Sample screen for Capture Windows User Events feature](#sample-screen-for-capture-windows-user-events)

<Note>
  **Note:** In **Windows Authenticator** app, you must sync the configuration to Capture Windows User Events. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
</Note>
