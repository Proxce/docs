Configuring the Windows Device app with Workflow as proxy enables the device app to work offline.

Steps to configure Windows Device App:

1. Double-click on the **Windows Device** app to open.
   The **Welcome** page is displayed.
   ![How to configure Windows Device Admin... - screenshot 1](/images/intercom/8878376/image-110e0ec0.png)
2. Enable **Use Proxy to connect to OLOID Cloud**.
   ![How to configure Windows Device Admin... - screenshot 2](/images/intercom/8878376/image-a5a7d913.png)
3. Enter Oloid Proxy URL in the **OLOID Proxy URL** field.
   ![How to configure Windows Device Admin... - screenshot 3](/images/intercom/8878376/image-cd0e0da8.png)
4. Click **Next**.
   ![How to configure Windows Device Admin... - screenshot 4](/images/intercom/8878376/image-b05ea4a4.png)
   If the tenant name is available in different environments then **Select Environment** page is displayed.
   ![How to configure Windows Device Admin... - screenshot 5](/images/intercom/8878376/image-1653bb34.png)
5. Select an environment and click **Next**.
   ![How to configure Windows Device Admin... - screenshot 6](/images/intercom/8878376/image-8b6d4926.png)
   The Windows device is configured with the tenant. You can now activate the endpoint to use the app.
   ![How to configure Windows Device Admin... - screenshot 7](/images/intercom/8878376/image-b614f8f5.png)
