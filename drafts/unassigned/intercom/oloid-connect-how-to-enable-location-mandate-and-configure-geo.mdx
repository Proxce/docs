## Introduction

This document explains how to enable **Location Mandate** feature and configure **Geo-Fencing Radius** for the Oloid Connect application.

## Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- You must create and configure Oloid Connect application in the Tenant Admin Portal. For more, refer to [How to Create and Configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)

## Steps to Enable Location Mandate

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on **Oloid Connect** application.
   ![How to Enable Location Mandate and... - screenshot 1](/images/intercom/15869578/9f89c7a2-1c62-4a42-b386-2859701842fc-db03b701.png)
   The application **details** page is displayed.
   ![How to Enable Location Mandate and... - screenshot 2](/images/intercom/15869578/image-80a12fb7.png)
3. Go to **Configure** tab > **Settings.**
   ![How to Enable Location Mandate and... - screenshot 3](/images/intercom/15869578/image-52d69d6e.png)
   The settings page is displayed.
4. **Enable Location Mandate** toggle.

   <Note>
     **Note:** When enabled, users must grant device location access before authentication.
   </Note>

5. In the **Geo-fencing Radius** section, configure the allowed authentication distance:
   **Miles** – Enter the allowed radius in miles.
   **Feet** – Enter the allowed radius in feet.

Click **Save.**

![How to Enable Location Mandate and... - screenshot 4](/images/intercom/15869578/image-47aea4f9.png)

The Location Mandate is configured successfully.

![How to Enable Location Mandate and... - screenshot 5](/images/intercom/15869578/image-d884b23a.png)
