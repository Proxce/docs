1. Log in to **preview.oloiddev.com** and go to endpoints section.
2. Pair Endpoint with the below application-
   **Tenant** : Preview
   **Application Name** : Pepsi Demo
3. Add the below integrations to the endpoint –
   "Integrations": [
   &#123;
   "IntentValueEnd": "LaunchEnd",
   "endpointName": "HTTP Request",
   "IntegrationID": "EndpointHTTPRequest",
   "Intent": true,
   "Token": "",
   "Method": "POST",
   "BreakTimeMinMinute": 30,
   "descriptions": "HTTP Request",
   "URL": "[https://api.oloiddev.com/credentials/passwordless/transaction/new](https://api.oloiddev.com/credentials/passwordless/transaction/new)",
   "TimeZone": "Asia/Kolkata",
   "UseAuth": true,
   "Username": "admin",
   "IntentValueStart": "LaunchStart",
   "AuthType": "Firebase",
   "BreakTimeMaxMin": 60,
   "AllowBody": true,
   "IntegrationType": null,
   "Password": "root123"
   &#125;
   ],
   "WebButton": &#123;
   "Show": true,
   "AutoLaunch": false,
   "URL": "[https://preview.oloid-sso.com/login?tranid=#&#123;&#123;TransactionID&#125;&#125;](https://preview.oloid-sso.com/login?tranid=)",
   "Timeout": 36000,
   "ShowOnlyOnAuth": false
   &#125;,
   "PreviewHomePage": "VisualAuth",
4. Save the above changes.
5. Kill the Oloid Connect App and relaunch it. You should see the preview screen with the web button icon at the bottom. (If you do not wish to see the web button icon on the preview screen, in the Web Button config change “**Show**”:true, to False.)
6. The key "**PreviewHomePage**" has 3 values –
   **VisualAuth** – this is for Face Auth
   **PinAuth** – this is for PIN.( note that to use this PIN needs to be set under user)
   **BadgeAuth** – this is to scan the badge for auth. ( note that for this Badge needs to be connected to the ipad and badge details present in the user credentials)
7. If you want to create a fresh Application, Create Application with Type: Oloid Verify.
   Add the below config in raw json –
   "AutoLaunchWebPagePostAuth": true,
   "FRMode": "Hybrid",
   "ShowActionStatus": true,
