## Introduction

The Tenant Admin Portal provides Tenant Admins with the ability to manage and assign Oloid Vault Shared Passwords to users.

## Prerequisites

- You must create Vault Shared Password. To create Vault Shared Password refer [How to Create Vault Shared Password in the Tenant Admin Portal](https://oloid.help/en/articles/12275469-how-to-create-vault-shared-password-in-the-tenant-admin-portal).
- You must create User. To create User, refer [How to add Users in the Tenant Admin Portal](https://oloid.help/en/articles/8185048-how-to-add-users-in-the-tenant-admin-portal).

## Steps to assign vault shared password

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Assign Chrome Vault Shared... - screenshot 1](/images/intercom/12275961/image-3b224d1d.png)
   The **Users** page is displayed.
3. Select **Shared Credentials > Vault Passwords** on the left menu panel.
   ![How to Assign Chrome Vault Shared... - screenshot 2](/images/intercom/12275961/image-4c72aa8f.png)
   The **Vault Shared Password** page is displayed.
4. Do one of the following:
   1. Assign Password inVault Shared Passwordpage.
      or
   2. Assign Password in Passworddetails page.

### Assign Password in Vault Shared Password page

1. Select the preferred password name(s).
   ![How to Assign Chrome Vault Shared... - screenshot 3](/images/intercom/12275961/image-ab051d39.png)
2. Click **Assign Passwords to Users**.
   ![How to Assign Chrome Vault Shared... - screenshot 4](/images/intercom/12275961/image-e2f1e294.png)
   The **Assign Password to Users** pop-up box is displayed.
3. On the pop-up box, do the following:
   1. Enter the **User Name** in the **Select Users** field > select the user from dropdown menu.
   2. Click **Assign**.
      ![How to Assign Chrome Vault Shared... - screenshot 5](/images/intercom/12275961/image-192a5bb8.png)

The Vault Password is assigned successfully.

![How to Assign Chrome Vault Shared... - screenshot 6](/images/intercom/12275961/image-bf09d99c.png)

### Assign Password in **Vault Password** details page

1. Click on the preferred Vault Password
   ![How to Assign Chrome Vault Shared... - screenshot 7](/images/intercom/12275961/image-a0fb352f.png)
   The Password details page is displayed.
2. Select **Assign Shared password to Users**.
   ![How to Assign Chrome Vault Shared... - screenshot 8](/images/intercom/12275961/image-8741261f.png)
   The **Assign Password to Users** pop-up box is displayed.
3. On the pop-up box, do the following:
   1. Enter the **User Name** in the **Select Users** field > select the user from dropdown menu.
   2. Click **Assign**.
      ![How to Assign Chrome Vault Shared... - screenshot 9](/images/intercom/12275961/image-192a5bb8.png)

The Vault Password is assigned successfully.

![How to Assign Chrome Vault Shared... - screenshot 10](/images/intercom/12275961/image-bf09d99c.png)
