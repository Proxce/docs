**Introduction**

This document contains detailed troubleshooting steps for resolving the "User Blocked" issue encountered during login via the Oloid Windows Login application. It explains the causes of PIN lockout, outlines methods to unlock or reset the PIN, and provides guidance for users and administrators to regain access.

**Issue:**

The Oloid Windows Login application displays a “User Blocked” message after multiple incorrect PIN attempts, preventing the user from logging in using the PIN credential.

**Applies to:**

- Oloid Windows Login users authenticating with **PIN** credential.
- Users receiving the **User Blocked** screen on the Windows login app.
- Devices running the **Oloid Windows Login** application.

**Cause:**

The PIN lockout issue may occur due to the following reason:

- The user has entered an incorrect PIN multiple times consecutively.

**Solution:**

Once the user exceeds the maximum allowed PIN attempts, the user will be blocked for further login attempts for the configured lockout duration. If you know the correct PIN, wait for the defined time period before trying again. Otherwise, proceed to reset the PIN. For more details refer [Enroll PIN](https://oloid.help/en/articles/10932990-how-to-enroll-credentials-using-windows-login-app#h_e7735da2e1).
