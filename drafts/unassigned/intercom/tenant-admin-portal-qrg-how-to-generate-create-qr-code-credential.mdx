## Steps to Generate/Create QR Code

1. Log in to the **Tenant Admin Portal**.
2. Go to **Directory > Users >** click **applicable user.**
   ![How to Generate/Create QR Code... - screenshot 1](/images/intercom/13333168/image-cdcf4843.png)
   The user detail page is displayed.
3. Click **Credentials > QR Code >** click **Create QR Code.**
   ![How to Generate/Create QR Code... - screenshot 2](/images/intercom/13333168/58cb6ffe-ed30-41c8-94a0-57582f6fc590-5be22fdf.png)
   The QR code page is displayed.
4. Do the following:
   1. Select **QR Code Validity**.
   2. Enter **Mail ID** in the **Share QR Code with** field.
   3. Click **Assign**.
      ![How to Generate/Create QR Code... - screenshot 3](/images/intercom/13333168/image-262fd786.png)
      The QR code is created successfully.
