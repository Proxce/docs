## Introduction

## Prerequisite

- You must have access to the Tenant Admin Portal.
- Ensure **Windows Post-login Module** is enabled.
- Ensure the 'Enable Badge Out' feature (Tap to Lock/Logout) is not active in the linked Application's Configure tab.

## Steps to Configure Post Oloid Login

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Configure Post Oloid Login - screenshot 1](/images/intercom/15501099/image-4410c43e.png)
   The Endpoints page is displayed.
3. Click an endpoint name to edit from the listed endpoints.
   The Endpoint details page is displayed.
4. Select **Post-Login** tab > Click **Post Oloid Login**.
   ![How to Configure Post Oloid Login - screenshot 2](/images/intercom/15501099/image-93ceb27a.png)
   The Post Oloid Login page is displayed.
5. Do the following:
   1. Open Web View: Select the **Open Web View** checkbox.
   2. Enter the Oloid **User Portal URL** as recommended by your Oloid representative.
   3. Invoke a .SH script file: Select the **Invoke a .SH script file** checkbox.
   4. Enter the local path to the .SH script file.
   5. Open Browser with configured URL: Select the **Open Browser with configured URL** checkbox.
   6. Enter the **Auto-SSO URL** provided by your Oloid representative.
   7. Redirect to Epic SAML SDK: Select the **Redirect to Epic SAML SDK** checkbox.
   8. Enter the **static client ID.** Refer to documentation for configuration details.
   9. Click **Save.**
