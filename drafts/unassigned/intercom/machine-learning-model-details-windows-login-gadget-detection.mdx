## Overview

Oloid has developed an advanced gadget detection feature as part of its Windows Login solution, leveraging computer vision and deep learning techniques to enhance security and user experience. At the core of this system is a customized implementation of the Primary Model object detection model, optimized for identifying unauthorized or unusual devices during login events.

## Key Objectives

- Detect presence of external gadgets such as mobile phones, tablets, or unauthorized USB devices during Windows login.
- Enhance workplace security by flagging potential security breaches.
- Automate visual gadget detection to reduce reliance on manual surveillance.

**Model Selection – Oloid’s Primary Model** has following features:

- High inference speed and real-time processing capabilities.
- Accuracy in object detection with fewer false positives.
- Lightweight architecture suitable for on-device and edge deployments.
- Robust support for custom object classes and transfer learning.

Model Architecture & Training:

- Training Dataset: Curated dataset containing images from office environments with labeled gadgets (phones, laptops, USBs, tablets, etc.).
- Data Augmentation: Techniques such as random cropping, brightness variation, rotation, and occlusion applied to improve generalization.
- Transfer Learning: Pretrained weights used for faster convergence and improved accuracy.

Detection Pipeline:

1. Image Capture: Webcam or external camera captures login environment.
2. Preprocessing: Image resized and normalized to match model input specifications.
3. Inference: Oloid’s models detect and classifies objects in real-time.
4. Post-processing: Bounding boxes filtered based on confidence scores and non-max suppression.
5. **Alerting & Logging:** If unauthorized gadgets are detected, alerts are triggered and the event is logged.

**Integration with Windows Login:**

- The detection module is embedded within the Oloid login agent.
- Before login is authorized, the gadget detection module performs a real-time scan.
- Based on detection results, login can be approved, delayed for review, or blocked.

**Performance Metrics:**

- **Detection Accuracy:** ~92% mAP on internal validation set.
- **Latency:** Average inference time &lt; 100ms per frame on edge GPU.
- **False Positive Rate:** Maintained under 3% with ongoing model tuning.

**Security and Privacy Considerations:**

- All detection is done locally to preserve privacy.
- No images are transmitted or stored unless flagged for review with user consent.
- Model updates are securely deployed over the air.

**Conclusion:** Oloid's gadget detection feature for Windows Login provides a proactive layer of security in enterprise environments. By combining real-time object detection with smart login workflows, it helps ensure secure and compliant access to Windows systems.
