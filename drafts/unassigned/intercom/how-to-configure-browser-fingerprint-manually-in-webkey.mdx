Steps to configure browser fingerprint manually:

1. Log in to **Oloid Portal**.
2. On the homepage, select **WebKey application**.
   ![How to configure Browser Fingerprint... - screenshot 1](/images/intercom/10473440/07a97381-0f1f-4962-a8f1-96bce47f8976-f9c73769.png)
   The **WebKey Details** page is displayed.
3. Go to **Configure** > select **Settings** tab.
   ![How to configure Browser Fingerprint... - screenshot 2](/images/intercom/10473440/f6bb4ffa-3010-40c1-a766-8e67cd15d11e-461c33be.png)
4. Do the following:
   ![How to configure Browser Fingerprint... - screenshot 3](/images/intercom/10473440/90390652-d7a2-4160-8658-e0c1e3f00258-e68d0df1.png)
   1. Turn on **Enable Browser Fingerprint**.
   2. Click **+ Browser Fingerprint**.
      The **Add Browser Fingerprint** pop-box is displayed.
5. Do the following:
   ![How to configure Browser Fingerprint... - screenshot 4](/images/intercom/10473440/image-b6b350f7.png)
   1. Enter **Browser**.
   2. Enter **bowser Version**.
   3. Enter **OS**.
   4. Enter **Version** of the OS.
   5. Enter **Browser Fingerprint**.
   6. Click **Add**.
6. Click **Save**.

The Browser Fingerprint is added to the WebKey application successfully.
