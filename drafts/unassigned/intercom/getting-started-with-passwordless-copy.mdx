Oloid Passwordless Authenticator is a simple, seamless, secure and scalable Authentication application that enables username(-less) and password-less authentication for devices ( Windows Desktop/ Laptop, Android Tablets and iPads) and Workforce/HRMS Platforms (OKTA, VMWare WorkspaceOne, Workday, Salesforce etc).

Oloid Passwordless does not require an Enterprise employee to use Username and Password to log into devices or Workforce/HRMS Platforms. With Oloid Passwordless employees can use physical identity factors (like Face, Badge , NFC tags and Pin) to log into devices and Workforce/HRMS Platforms using secure Multi-factor Authentication (MFA).

Oloid’s Passwordless Application combines virtual identity with physical identity of employees.

Oloid’s passwordless application is especially suitable for deskless and frontline workers who have difficulty in remembering or using Username and Password to access devices or Workforce/HRMS Platforms.

Oloid's Passwordless Authenticator is of four types :

· **Web Key( Browser Based )**

· **[Windows Device Login](https://oloid.help/en/articles/7220876-getting-started-with-passwordless-authenticator#h_fa4e909986) ( Windows Desktop/Laptop, Windows Server)**

· **[Oloid DeviceLock](https://oloid.help/en/articles/7220876-getting-started-with-passwordless-authenticator#h_38a18fc0a0) ( Android)**

· **[Oloid Connect App](https://oloid.help/en/articles/7220876-getting-started-with-passwordless-authenticator#h_849ff3c657) ( Apple iOS)**

This browser-based application enables Multi-factor authentication(MFA) of users using physical identity factors (like Face, Badge , NFC tags and Pin) .This application allows employees to seamlessly log into Workforce/ HRMS systems without entering Username and Password.

## Windows Device Login

Oloid's Windows login is a secure and user-friendly authentication method that allows Enterprise employees to log into Windows Laptops/Desktops/Servers , apps, online services, and Workforce/HRMS Platform using physical identity factors (like Face, Badge , NFC tags and Pin). The Physical Identity factors can be combined in any order using factor sequencing for Multi-factor Authentication.

This application is especially useful for factory workers, warehousing staff, supply chain operations, Pharmacy chains etc. where large number of employees use shared device using shared credentials. These credentials are currently shared among all employees and even after the employee leaves remain the same. This creates security threat. With Oloid’s Passwordless solution for Windows, employees do not need to know Username and password and their access is immediately deactivated, the day they leave.The access can be easily enabled on the day a new employee joins.
