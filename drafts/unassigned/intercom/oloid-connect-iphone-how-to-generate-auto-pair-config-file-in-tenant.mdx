## Steps to generate auto-pair config file

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to generate Auto-Pair config file... - screenshot 1](/images/intercom/13524540/8011311c-7f26-4413-aab1-1e3152722f5f-8aeb4733.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to generate Auto-Pair config file... - screenshot 2](/images/intercom/13524540/ead0edef-db9a-403c-9b28-f6f8973b7432-0cd0a3e1.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > **API Token** > **API Key**.
   ![How to generate Auto-Pair config file... - screenshot 3](/images/intercom/13524540/45633202-6454-4d3a-9836-b22ac299a1b2-fe15e691.png)
5. In the **Generate Temporary Access Token** section, do the following:
   1. In the **Generate Temporary Access Token** section, select the **Start Date/Time** field.
      - To set the start date and time, click the date picker or select **Now**.
   2. Select the **End Date/Time** field.
      - Click the date picker, choose when the token will expire, and then click **OK**.
   3. Specify **Number of Endpoints** that can be created using the endpoint. (Optional)
   4. Click **Generate**.
      ![How to generate Auto-Pair config file... - screenshot 4](/images/intercom/13524540/b700b191-2b42-4aa7-9bfe-0d5c41b866f3-0401d10e.png)
      The auto-pair config file is generated.
      ![How to generate Auto-Pair config file... - screenshot 5](/images/intercom/13524540/ca6e65c5-4747-4b0a-89f6-2f2f2e20d16e-c6095aa9.png)
6. Click **Auto-pair config file**.
   The Auto-pair config file pop-up box is displayed.
   ![How to generate Auto-Pair config file... - screenshot 6](/images/intercom/13524540/image-75e08da5.png)
7. Do the following:
   1. Select **Application** as **Oloid Verify** from **Application Type** dropdown list.
   2. From the **Select Application** drop-down list, select the application that you want the endpoints to pair with.
   3. Under **Download file format**, select one of the following:
      - **JSON** → For local device setup.
      - **XML** → For MDM deployment.
   4. Select **Skip user confirmation for pairing** option to auto-pair endpoints without requiring user confirmation (optional but recommended).
      - **If selected:** When the configuration file is uploaded to the endpoint, the system will pair automatically without prompting the user for confirmation.
      - **If not selected:** The system will display a confirmation pop-up to the user before completing the pairing process.
   5. Click **Download**.
      The AutopairConfig file is downloaded to the local device.
