Steps to export transactions:

1. Login to the **Oloid Portal**.
2. On homepage, click **Directory** on the left menu panel.
   ![How to Export Transactions of a user - screenshot 1](/images/intercom/9789752/image-3b224d1d.png)
   The **User** page is displayed.
3. Click on user name to edit.
   ![Image](/images/intercom/9789752/e7eb79d0-7251-47e0-ac04-14a8b0395931-c2cb3dea.png)
   The user details page is displayed.
4. Select **Transactions tab** and click **Export to excel** on the top right corner.
   ![How to Export Transactions of a user - screenshot 2](/images/intercom/9789752/image-b029abe3.png)
   The **Export to Excel** pop-up page is displayed.
5. Do the following:
   ![How to Export Transactions of a user - screenshot 3](/images/intercom/9789752/image-f5d78bf2.png)
   1. Select **From Date & Time** from the calendar. (optional)
   2. Select **Time Zone** from the drop down list. (optional)
   3. Select **Application name** from the drop down list. (optional)
   4. Select **Mode** from the drop down list. (optional)
   5. Select T**o Date Time** from the calendar. (optional)
   6. Select **Transaction Status** from the drop down list. (optional)
   7. Select **Endpoint Name** from the drop down list.
   8. Select **Face Match Status** from the drop down list. (optional)
   9. Click **Download**.

      <Note>
        **Note:** If the filters under **Export to Excel** page is not selected then all transactions of the user will be exported to excel.
      </Note>

      The transaction is exported to excel successfully.
