## Introduction

This document describes how to configure Advanced User Sync for ADP Workforce Now - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- An **Advanced User Sync profile for ADP Workforce Now - Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for ADP Workforce Now - Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.
   ![How to Configure Advanced User Sync for... - screenshot 1](/images/intercom/15201369/image-0b56f77e.png)
   The **Advanced User Sync** page is displayed.
3. Select the preferred **ADP Workforce Now - Inbound** Advanced User Sync.
   ![How to Configure Advanced User Sync for... - screenshot 2](/images/intercom/15201369/image-61602389.png)
   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
5. Click **Activate**.
   ![How to Configure Advanced User Sync for... - screenshot 3](/images/intercom/15201369/image-69ddad28.png)
   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 4](/images/intercom/15201369/image-d34599bd.png)
   The Advanced User Sync is configured and activated successfully.
   ![How to Configure Advanced User Sync for... - screenshot 5](/images/intercom/15201369/image-94646ea9.png)
7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![How to Configure Advanced User Sync for... - screenshot 6](/images/intercom/15201369/image-2ebf7278.png)
   The **Sync Now** pop-up box is displayed.
8. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 7](/images/intercom/15201369/image-4a69c1f4.png)
   The **Success** pop-up box is displayed.
   ![How to Configure Advanced User Sync for... - screenshot 8](/images/intercom/15201369/image-13993bbd.png)
   The Advanced User Sync for ADP Workforce Now - Inbound is configured successfully.

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (Optional).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 9](/images/intercom/15201369/image-d5c72c82.png)
   The Details tab is configured successfully.

### Setup Configuration Tab

This tab is used to map user data from **ADP Vantage HCM - Inbound** to **Oloid**.

Do the following:

1. Select the **Data Mapper Table** from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. Select **Connection** from the drop-down.
3. Enable **Sync Schedule**.

   <Note>
     **Note:** Sync Schedule toggle is used sync the User Transaction.
   </Note>

4. Enable **User by Time & Attendance** toggle.
5. Enable **Terminated Users** toggle.
6. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 10](/images/intercom/15201369/image-31ba978c.png)

The Configuration tab is configured successfully.

![How to Configure Advanced User Sync for... - screenshot 11](/images/intercom/15201369/image-da5b7d20.png)

### Configure Account Tab

This tab is used to add and configure the **ADP ETime - Inbound** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**.
2. Enter **Token Endpoint**.
3. Enter **Organization ID (OOID)**.
4. Enter **Read Credential Endpoint**.
5. Enter **API URL**.
6. Enter **Client ID**.
7. Enter **Client Secret**.

   <Note>
     **Note:** Contact Oloid support for **Organization ID, Client ID** and **Client Secret**.
   </Note>

   ![How to Configure Advanced User Sync for... - screenshot 12](/images/intercom/15201369/image-77a185e9.png)
   The Account tab is configured successfully.
8. Click **Test**.
   ![How to Configure Advanced User Sync for... - screenshot 13](/images/intercom/15201369/image-5420cb4b.png)
   The **Success** pop-up box is displayed.

   ![How to Configure Advanced User Sync for... - screenshot 14](/images/intercom/15201369/image-5a2afcad.png)

### Configure Schedule Tab

This tab is used to define when the **ADP Vantage HCM - Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![How to Configure Advanced User Sync for... - screenshot 15](/images/intercom/15201369/image-cbf45361.png)

The Schedule tab is configured successfully.

### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 16](/images/intercom/15201369/image-bd030c36.png)
   The **Repeat Every** section is configured successfully.
   ![How to Configure Advanced User Sync for... - screenshot 17](/images/intercom/15201369/image-c0980993.png)

### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![How to Configure Advanced User Sync for... - screenshot 18](/images/intercom/15201369/image-9d30415b.png)

The **Run Once When Activated** section is configured successfully.

![How to Configure Advanced User Sync for... - screenshot 19](/images/intercom/15201369/image-908f04c8.png)
