Pre-requisite

The NFC/ID needs to be assigned to the user first.

Steps to check in with the NFC/ID:

1. Launch **Oloid Connect App**.

   <Note>
     **Note:** If Intent screen is displayed then you have to follow the Intent screen process to reach Welcome screen. To know more see, Oloid Connect- How to use Intent screen.
   </Note>

   The **Welcome** screen is displayed.
2. Tap on NFC/ID Auth.

   <Note>
     **Note:** Make sure the NFC/ID reader is connected to the endpoint.
   </Note>

3. Tap NFC Tag at the reader.
   You are checked in with NFC/ID successfully.
