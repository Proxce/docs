## Introduction

**Oloid’s Epic EHR integration** enables secure, passwordless access to Epic applications by combining biometric authentication with enterprise identity workflows. This integration allows healthcare organizations to streamline user authentication into Epic environments without relying solely on traditional username and password-based logins.

### Overview

By leveraging Oloid’s authentication platform with supported applications such as Windows Authenticator (Healthcare), users can securely log in to Epic systems using enrolled credentials like Face or PIN.

### About Epic EHR

Epic EHR (Electronic Health Record) is a healthcare software platform used to manage patient records and clinical workflows within a centralized system. Integrating Epic EHR with Oloid enables secure and seamless access to sensitive healthcare data while supporting compliance with security standards.

---

## How It Works

Oloid integrates with Epic EHR to:

- Authenticate users at Windows login or application launch.
- Enable passwordless access using biometric credentials.
- Support authentication through stored Epic credentials or SAML-based Identity Providers.
- Facilitate seamless login into Epic workflows without repeated credential entry.

Once configured through the Tenant Admin Portal, Oloid securely communicates with Epic to validate user identity and initiate login into supported Epic applications.

### Key Features

- **Passwordless Authentication**
  Enables login using Face or PIN credentials.
- **Epic Credential Integration**
  Supports Username/Password or SAML-based authentication methods.
- **Reauthentication Workflow**
  Allows secure re-verification during active Windows sessions.
- **Two-User Authentication**
  Supports dual authentication for sensitive workflows.
- **Healthcare Security Compliance**
  Enhances identity verification for clinical environments.
