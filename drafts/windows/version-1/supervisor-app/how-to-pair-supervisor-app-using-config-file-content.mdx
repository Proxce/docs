## Pre-requisite

If endpoint is created through the Oloid Portal, you need to download the config file of the preferred endpoint from the Oloid Portal. For details, refer [How to download endpoint config file for Windows Login?](https://oloid.help/en/articles/8778331-how-to-download-endpoint-config-file-for-windows-login)

To pair an endpoint:

1. Double-click on the **Supervisor App** to start. <img src="/images/intercom/9036798/image-a8da1205.png" alt="How to pair Supervisor App using Config... - screenshot 1" /> The **Pair Endpoint** screen is displayed.
2. Select **Pair Device Using Config File**. <img src="/images/intercom/9036798/image-b7e1b9b2.png" alt="How to pair Supervisor App using Config... - screenshot 2" /> The **Pair Device Using Config File** screen is displayed.
3. Select the json file you want to upload and click **Open**. <img src="/images/intercom/9036798/image-9c065c89.png" alt="How to pair Supervisor App using Config... - screenshot 3" />
   <Note>
     **Note:** Check mark to **Use the Machine Name as Endpoint Name** (Optional).
   </Note>
4. Click to **Upload** the endpoint JSON file.
   <Note>
     **Note:** You can choose **Reset** to upload the JSON file again.
   </Note>
   The **Pairing endpoint** screen is displayed.
5. The **Endpoint Name** is auto-populated. <img src="/images/intercom/9036798/image-80c621f6.png" alt="How to pair Supervisor App using Config... - screenshot 4" />
6. Select **Publish**. The endpoint is paired successfully. <img src="/images/intercom/9036798/image-88a365b2.png" alt="How to pair Supervisor App using Config... - screenshot 5" /> Now, you can log in to admin mode. <img src="/images/intercom/9036798/image-162bd16d.png" alt="How to pair Supervisor App using Config... - screenshot 6" />
