  ## Configuration

  To configure the Oloid DeviceLock app, perform the below steps in the Oloid Portal:

  1. Create "**Application**".
     <Note>
       **Note:** You must create an application of "**Passwordless**" type.
     </Note>
  2. Create "**User**".
  3. Add "**Connection**" to the "**Application**".
     <Note>
       **Note:** Add the same Connection to the Application in which the User is present.
     </Note>
  4. Onboard "**Face**".

  The Oloid DeviceLock app is now configured and ready for use.

  For step-by-step instructions to create an application, read [How to create an application](/platform/tenant-admin-portal/tenant-admin-portal-how-to-create-an-application).

  For step-by-step instructions to create an user, read [How to add an user](/platform/tenant-admin-portal/tenant-admin-portal-how-to-create-user).

  For step-by-step instructions to add Connection to the Application, read [How to Configure Application Type - Passwordless.](/platform/tenant-admin-portal/how-to-create-and-configure-application-type-passwordless)

  For step-by-step instructions to add face, read [How to onboard face of a single user](/platform/tenant-admin-portal/tenant-admin-portal-how-to-add-face-of-a-single-user)**.**
