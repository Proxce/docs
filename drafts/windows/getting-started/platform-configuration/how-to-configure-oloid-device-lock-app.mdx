## Configuration

To configure the Oloid DeviceLock app, perform the below steps in the Oloid Portal:

1. Create "**Application**".

   <Note>
     **Note:** You must create an application of "**Passwordless**" type.
   </Note>

2. Create "**User**".
3. Add "**Connection**" to the "**Application**".

   <Note>
     **Note:** Add the same Connection to the Application in which the User is present.
   </Note>

4. Onboard "**Face**".

The Oloid DeviceLock app is now configured and ready for use.

For step-by-step instructions to create an application, read [How to create an application](https://oloid.help/en/articles/8294483-how-to-create-an-application).

For step-by-step instructions to create an user, read [How to add an user](https://oloid.help/en/articles/8185048-how-to-add-user).

For step-by-step instructions to add Connection to the Application, read [How to Configure Application Type - Passwordless.](https://oloid.help/en/articles/8300330-how-to-configure-application-type-passwordless)

For step-by-step instructions to add face, read [How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user)**.**
