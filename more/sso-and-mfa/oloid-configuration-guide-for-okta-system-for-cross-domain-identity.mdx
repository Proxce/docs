## Overview

You can provision users from Okta to Oloid to reduce manually adding each employee to Oloid. The provisioning process reduces administrative errors and is a great way to save time and efforts.

With Okta to Oloid provisioning features, you can automate these tasks

- **Push new users** – Any users you create into Okta can be provisioned / created into Oloid.
- **Push profile updates** – Profile updates done in Okta are pushed to Oloid.
- **Push user deactivation** – Deactivating or removing a user in Okta terminates the user in Oloid.

## How to configure SCIM provisioning from Okta to Oloid

### Prerequisite

You must have permission to create application in Okta Console.

### Steps to Configure SCIM in OKTA

1. Log in to Okta Tenant Administration console.
2. Go to **Applications** > **Applications** and click **Browse App Catalog.**

   ![Go to Applications &gt; Applications and click Browse App Catalog.](/images/intercom/9822466/image-e9f53785.png)

3. Search **SCIM 2.0 Test App (Header Auth).**

   ![Search SCIM 2.0 Test App (Header Auth).](/images/intercom/9822466/image-2063bb71.png)

   The **SCIM 2.0 Test App (Header Auth).**
4. Click **Add Integration**.

   ![Click Add Integration.](/images/intercom/9822466/7bd3d222-3cfd-4179-98b2-19d00ba4ea33-f51d58e3.png)

5. Enter Application Labeland click **Next.**

   ![Enter Application Labeland click Next.](/images/intercom/9822466/8e2324ea-426a-4657-92cc-298ae75f6682-bc7054b6.png)

   The Sign-On Options is displayed.
6. Click **Done.**

   ![Click Done.](/images/intercom/9822466/image-c869b902.png)

   The General settings tab is configured successfully.
7. Go to **Provisioning** tab and click **Configure API Integration.**

   ![Go to Provisioning tab and click Configure API Integration.](/images/intercom/9822466/image-b20d2f3f.png)

8. Do the following:
   1. Select **Enable API integration**.
   2. Enter **Base URL.**
   3. Enter **API Token**.

      <Note>
        **Note:** To enter the **Base URL** and **API Token**, go to **Oloid Tenant Admin Portal** > **Agents > SCIM** and copy the **Base URL** and **API Token**.
      </Note>

      ![Enter API Token.](/images/intercom/9822466/image-80633e0f.png)

   4. Click **Test API Credentials**.

      <Note>
        **Note:** Validation should succeed and you should see the message "Okta-SCIM was verified successfully".
      </Note>

   5. Click **Save.**

      ![Click Save.](/images/intercom/9822466/image-b463f953.png)

9. Go to **Provisioning >** **Settings >** **To App.**
10. Enable the following sections:
    1. Create Users
    2. Update User Attributes
    3. Deactivate Users.

       ![Deactivate Users.](/images/intercom/9822466/image-bdcfd44e.png)

    4. Under attribute mapping, map following attributes:

       ![Under attribute mapping, map following attributes](/images/intercom/9822466/image-2fdac0e6.png)

       ![Under attribute mapping, map following attributes (2)](/images/intercom/9822466/image-00618295.png)

       <Note>
         **Note:** Email is case insensitive attribute in Oloid.
       </Note>

11. Go to **Assignments** tab and click **Assign**.

    ![Go to Assignments tab and click Assign.](/images/intercom/9822466/7c5847f0-1bd0-4641-a757-adb343986052-a338f5c4.png)

    The Assignment tab is displayed.
12. Do the following:
    1. **Assign to People**:
       1. Go to **Assign > Assign to People**.

          ![Go to Assign &gt; Assign to People.](/images/intercom/9822466/d8c43f3d-fc93-4c2e-af32-48065fc85b2a-cb60e8a1.png)

          The **List of People** is displayed.
       2. Click **Assign**.

          ![Click Assign.](/images/intercom/9822466/3f6af1fc-8446-4a35-bfd1-dcbbbeaf48d5-685b4d72.png)

          The **Assign SCIM 2.0 Test App** pop-up is displayed.
       3. Click **Save and Go Back**.

          ![Click Save and Go Back.](/images/intercom/9822466/f70eae05-7683-4c18-bf90-513019ca6ad8-24628518.png)

          The user is assigned successfully and listed on the User.

          ![The user is assigned successfully and listed on the User.](/images/intercom/9822466/b5bbb98b-e6c7-443c-9e44-a4f9948dacd7-ef04c0fd.png)

    2. **Assign to Groups**
       1. Go to **Assign > Assign to Groups.**

          ![Go to Assign &gt; Assign to Groups.](/images/intercom/9822466/f23f8ef0-6374-4359-a0cb-81d2c835f007-8e6164ba.png)

          The list of groups is displayed.
       2. Click **Assign**.

          ![Click Assign. (2)](/images/intercom/9822466/4aba3291-b687-4362-b371-e90837067119-3bfbdbc9.png)

          The Group is assigned successfully.

          ![The Group is assigned successfully.](/images/intercom/9822466/image-2f99de38.png)

The Okta SCIM client is configured.
