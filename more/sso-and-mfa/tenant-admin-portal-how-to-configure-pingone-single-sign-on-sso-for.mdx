## Introduction

This document provides step-by-step instructions to configure **PingOne Single Sign-On (SSO)** for the Tenant Admin Portal.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- You must configure PingOne and generate the required SSO configuration details in the **PingOne Administrator Console**. For instructions, see [How to Configure PingOne Single Sign-On (SSO) for the Oloid Portal in the PingOne Admin Console](/more/sso-and-mfa/how-to-configure-pingone-single-sign-on-sso-for-the-oloid-portal-in).

## Steps to Configure PingOne SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **user profile icon** on the bottom-left of the menu panel.

   ![On the homepage, click user profile icon on the bottom-left of the menu panel.](/images/intercom/10316179/image-3c6dd5f3.png)

   The user profile menu is displayed.
3. Click **Tenant Settings**.

   ![Click Tenant Settings.](/images/intercom/10316179/image-6835c36d.png)

   The **Tenant Settings** page is displayed.
4. Go to **Security** > **PingOne**.
   The PingOne configuration section is displayed.

   ![The PingOne configuration section is displayed.](/images/intercom/10316179/image-61133ce8.png)

5. Turn on **Enable PingOne SSO** toggle.

   ![Turn on Enable PingOne SSO toggle.](/images/intercom/10316179/acbec1de-099c-4412-ae4c-17a77e175e24-8cca301c.png)

6. Do the following:
   1. Copy the **Sign-in Redirect URL.**

      ![Copy the Sign-in Redirect URL.](/images/intercom/10316179/image-d4e1a936.png)

      <Note>
        **Note:** Enter the **Sign-in Redirect URL** in the **PingOne Admin Console**. Navigate to **Applications > OpenID Connect** and enter the URL in the **Redirect URIs** field.
      </Note>

      ![Copy the Sign-in Redirect URL. (2)](/images/intercom/10316179/image-b917e7c2.png)

   2. Enter the **Environment ID**.

      ![Enter the Environment ID.](/images/intercom/10316179/3f507c3a-b8e0-414b-99f5-99f7001396df-94deb9e4.png)

   3. Enter the **Client ID**.

      ![Enter the Client ID.](/images/intercom/10316179/4a39cff8-5981-4fde-ae86-37c5f32a7a3b-1f729d19.png)

   4. Enter the **Client Secret**.

      ![Enter the Client Secret.](/images/intercom/10316179/image-7330ebc3.png)

      <Note>
        **Note:** You can find the **Environment ID**, **Client ID**, and **Client Secret** in the **PingOne Administrator Console**. To get these details, go to **Applications > Overview > General**, and copy the required information.
      </Note>

      ![Enter the Client Secret. (2)](/images/intercom/10316179/image-a0e8d80c.png)

   5. Enter the **Auth URL**.

      ![Enter the Auth URL.](/images/intercom/10316179/6ddd73b6-2786-4778-a582-a111cb33e270-8de8bcc1.png)

   6. Enter the **Token URL**.

      ![Enter the Token URL.](/images/intercom/10316179/image-e9c3396b.png)

   7. Enter the **User Info URL**.

      ![Enter the User Info URL.](/images/intercom/10316179/image-4ac4b3c1.png)

      <Note>
        **Note:** You can find the **Auth URL**, **Token URL**, and **User Info URL** in the **PingOne Administrator Console**. To get these URLs, go to **Applications > Overview > Connection Details**, and copy the required URLs.
      </Note>

      ![Enter the User Info URL. (2)](/images/intercom/10316179/image-5094c684.png)

7. Click **Save**.

   ![Click Save.](/images/intercom/10316179/image-21f52b60.png)

   The PingOne SSO is configured successfully.

   ![The PingOne SSO is configured successfully.](/images/intercom/10316179/image-6806811a.png)
