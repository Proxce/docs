## Introduction

Okta Single Sign-On (SSO) allows users to sign in to Oloid using their existing Okta credentials. To enable this integration, admin must generate specific parameters in the Okta Admin Console and enter them in the Oloid Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- To configure the integration between Okta and Oloid, generate the required parameters in the **Okta Admin Console**. For detailed steps, see [Okta Settings for Oloid SSO](https://oloid.help/en/articles/8158793-integrate-okta-sso-in-okta-admin-console).

## Steps to Configure Okta SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Configure Okta SSO in Tenant... - screenshot 1](/images/intercom/10299914/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![Image](/images/intercom/10299914/dbb3ba06-85c5-488f-8762-8fdebf21e109-0a65913b.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** > **Okta**.
   ![How to Configure Okta SSO in Tenant... - screenshot 2](/images/intercom/10299914/3e6632e9-f5f7-4d1d-830a-625e189bfc8e-dbe23b8f.png)
5. Turn on **Enable Okta SSO** toggle.
   ![How to Configure Okta SSO in Tenant... - screenshot 3](/images/intercom/10299914/f3bba344-7b67-459e-afdb-7a8832fa02fb-278182a6.png)
6. Do the following:
   1. **Redirect URL**: Copy the redirect URL.
      ![How to Configure Okta SSO in Tenant... - screenshot 4](/images/intercom/10299914/image-f800cf33.png)
      Use the Redirect URLs when configuring client application in the Okta Admin Console.
      ![How to Configure Okta SSO in Tenant... - screenshot 5](/images/intercom/10299914/b74def0d-c8db-4404-ac6f-8ffd95d66dde-b0d3d41e.png)
   2. **Iss**:Enter the default Issuer URL in the Iss field.
      ![How to Configure Okta SSO in Tenant... - screenshot 6](/images/intercom/10299914/image-28de668b.png)
      You can find the **default Issuer URL** from your Okta Admin Console under **Security** > **API** > **Authorization server** tab.
      ![How to Configure Okta SSO in Tenant... - screenshot 7](/images/intercom/10299914/fda85d90-a162-4cab-aed0-8deb53a96fdd-1a3a4b6f.png)
   3. **Native Client ID** (Not Applicable).
   4. **Domain**: Enter the **Domain ID** in the domain field.
      ![How to Configure Okta SSO in Tenant... - screenshot 8](/images/intercom/10299914/image-5046c0b0.png)
      You can find the Domain ID from your Okta Admin Console under **User Profile** icon.
      ![How to Configure Okta SSO in Tenant... - screenshot 9](/images/intercom/10299914/image-9c189ef5.png)
   5. **Web Client ID:** Enter the client ID in the Web Client ID field.
      ![How to Configure Okta SSO in Tenant... - screenshot 10](/images/intercom/10299914/image-c2be5eea.png)
      You can find the Client ID from your Okta Admin Console under **General** tab.
      ![How to Configure Okta SSO in Tenant... - screenshot 11](/images/intercom/10299914/image-15825762.png)
   6. **User Info URL** (Not Applicable).
   7. Click **Save**.
      The Okta SSO is configured successfully.
      ![How to Configure Okta SSO in Tenant... - screenshot 12](/images/intercom/10299914/image-804b88d2.png)
