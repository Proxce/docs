## Introduction

This document provides instructions to log in to the Oloid User Portal using Okta Single Sign-On (SSO). Okta SSO enables users to access the Oloid User Portal using their existing Okta credentials.

## Prerequisite

You must have valid Okta user credentials.

## Steps to log in to Oloid User Portal using **Okta SSO**

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**. The **Oloid User Portal** page is displayed.
3. Click **Login with SSO**.
   ![How to log in Oloid User Portal with... - screenshot 1](/images/intercom/9531562/21c7b54e-35fb-44f2-8244-5e9777d30675-1fc5c0ed.png)
   The Configured Login options are displayed.
4. Click **Continue with Okta**.
   ![How to log in Oloid User Portal with... - screenshot 2](/images/intercom/9531562/229b3b25-092a-4526-a8a0-832793f8716c-870438e0.png)
   The **Sign In** pop-up box is displayed.
5. Do the following:
   1. Enter your **Okta User name**.
   2. Enter **Password**.
   3. Click **Sign In**.
      ![How to log in Oloid User Portal with... - screenshot 3](/images/intercom/9531562/image-f3316986.png)
      You are logged in to the Oloid User portal using Okta SSO successfully.
      ![How to log in Oloid User Portal with... - screenshot 4](/images/intercom/9531562/image-b679eafa.png)
