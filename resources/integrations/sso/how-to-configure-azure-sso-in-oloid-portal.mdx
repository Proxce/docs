**To configure Azure SSO:**

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to configure Azure SSO in Oloid... - screenshot 1](/images/intercom/11129577/bab0b76b-781d-4114-8e69-aecbdfdef605-3ce15fb4.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to configure Azure SSO in Oloid... - screenshot 2](/images/intercom/11129577/image-ed1023fc.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > click **Azure**.
   ![How to configure Azure SSO in Oloid... - screenshot 3](/images/intercom/11129577/91c05e3f-a896-4df2-b5d5-2c9e5b419b65-354d1818.png)
5. Turn on **Enable Azure SSO** toggle > click **Save**.
   ![How to configure Azure SSO in Oloid... - screenshot 4](/images/intercom/11129577/81d8b2d1-e91b-4a00-9ffa-9d3abef16fcd-c02922c2.png)
   The Azure SSO is successfully configured.
   ![How to configure Azure SSO in Oloid... - screenshot 5](/images/intercom/11129577/image-0dd890ca.png)
