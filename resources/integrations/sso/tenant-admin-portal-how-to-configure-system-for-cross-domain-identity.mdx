## Introduction

The **SCIM integration** in **Oloid** helps to automate user provisioning and management between identity providers (IDPs) and connected applications. It ensures that user accounts, roles, and attributes stay synchronized automatically across platforms.

## Prerequisite

You have **access** to the **Tenant Admin Portal**.

## Steps to Enable and Map the Inbound SCIM

1. Log in to the **Oloid Tenant Admin Portal**.
2. On theTenant Admin Portal, click the **Agent** dropdown > **SCIM**.
   ![How to Configure System for... - screenshot 1](/images/intercom/12740850/image-478576b6.png)
   The **System For Cross-Domain Identify Management (SCIM)** page is displayed.
3. Turn on the **Enable Inbound SCIM** toggle.
4. Select one of the following Authentication modes:
   1. [Configure API Token](#configure-api-token)
   2. [Configure OAuth 2.0](#configure-oauth-2-0)
      The System for Cross-Domain Identify Management (SCIM) is successfully configured.

#### Configure API Token

An API Token is a unique secret key used to verify the identity of an application. The application includes the token with each SCIM request to securely access Oloid.

1. Select **API Token**.
2. In **Mapping** section, select the applicable **Connection** from the Connection drop-down.
   ![How to Configure System for... - screenshot 2](/images/intercom/12740850/image-5b60573c.png)
3. Click **Save**.
   The **Endpoint** details are generated successfully. These details are required to configure SCIM integration.
   - **Base URL:** It is the endpoint URL used for SCIM integration.
   - **Token:** It is the authentication token used to authorize SCIM requests.

     <Note>
       **Note:** Use the **Base URL** and **Token** keys when configuring the OKTA SCIM or Microsoft Entra ID SCIM. For more information, refer [Oloid Configuration Guide for Okta SCIM Client](https://oloid.help/en/articles/9822466-oloid-configuration-guide-for-okta-scim-client) and [Microsoft Entra ID - How to Configure Cross-Domain Identity Management (SCIM) Provisioning for Oloid](https://oloid.help/en/articles/15652452-microsoft-entra-id-how-to-configure-cross-domain-identity-management-scim-provisioning-for-oloid).
     </Note>

     ![How to Configure System for... - screenshot 3](/images/intercom/12740850/image-b3597e62.png)

#### Configure OAuth 2.0

OAuth 2.0 is a secure authentication standard that uses temporary access tokens to authenticate applications. The application obtains an access token using the client credentials and uses it to authorize SCIM requests.

1. Select **OAuth 2.0**.
2. Click **Generate**.
   ![How to Configure System for... - screenshot 4](/images/intercom/12740850/image-6132c014.png)
   The client credentials generated successfully.

   <Note>
     **Note:**

        - Use the **Enter Base URL**, **Endpoint Token**, **Client ID** and **Client Secret** when configuring the OKTA SCIM.
        - Use the **Base URL, Endpoint Token, Client ID** and **Client Secret** when configuring the Microsoft Entra ID SCIM. For more information, refer [Microsoft Entra ID - How to Configure Cross-Domain Identity Management (SCIM) Provisioning for Oloid](https://oloid.help/en/articles/15652452-microsoft-entra-id-how-to-configure-cross-domain-identity-management-scim-provisioning-for-oloid).
          ![How to Configure System for... - screenshot 5](/images/intercom/12740850/image-c68b6ff2.png)
     3. In **Mapping** section, select the applicable **Connection** from the Connection drop-down.
   </Note>

Click **Save**.

![How to Configure System for... - screenshot 6](/images/intercom/12740850/image-589c996f.png)

The OAuth 2.0 is configured successfully.
