**Pre-requisite:**

To set up the configuration between Auth0 and Oloid, you must generate the parameters in Auth0 dashboard. For detailed instructions, see [Auth0 Settings for Oloid SSO](https://oloid.help/en/articles/11103554-auth0-settings-for-oloid-sso)

To configure Auth0 SSO:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to configure Auth0 SSO in Oloid... - screenshot 1](/images/intercom/11098861/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![Image](/images/intercom/11098861/dbb3ba06-85c5-488f-8762-8fdebf21e109-0a65913b.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** > **Auth0**.
   ![How to configure Auth0 SSO in Oloid... - screenshot 2](/images/intercom/11098861/4f50c2aa-7d33-4c09-b08b-50ef8022b424-e94e0479.png)
5. Turn on **Enable Auth0 Identity SSO** button.
   ![How to configure Auth0 SSO in Oloid... - screenshot 3](/images/intercom/11098861/25c9a61d-a49c-43dc-99e6-1b518778b340-c6c0cc83.png)
6. Do the following:
   ![How to configure Auth0 SSO in Oloid... - screenshot 4](/images/intercom/11098861/image-53faa84e.png)
   1. Copy **Redirect URL**.
      Use both the provided Redirect URLs when configuring login in the Auth0 dashboard.
   2. Enter **Client ID.**
      You can find the Client ID from your Auth0 dashboard under **Created Application** > **Settings** > **Basic Information**. See, [Sample Screen for Client ID](#sample-screen-for-client-id-and-client-secret).
   3. Enter **Auth URL.**
      You can find the Auth URL as `authorization_endpoint` value in the OpenID configuration URL. See, Sample Screen for Auth URL
   4. Enter **Token URL**.
      You can find the **Token URL** as `token_endpoint` value in the OpenID configuration URL. See, Sample Screen for Token URL
   5. Enter **Client Secret**.
      You can find the Client Secret from your Auth0 dashboard under **Created Application > Settings** > **Basic Information**. See, Sample Screen for Client Secret.
   6. Enter **User Info URL**
      You can find the **User Info URL** as `userinfo_endpoint` value in the OpenID configuration URL. See, Sample Screen for User Info URL
   7. Click **Save**.
      The Auth0 Identity SSO is configured.

## To obtain Auth0 endpoint parameters

1. Log in to your Auth0 dashboard.
2. In the top-left menu bar, select your Auth0 tenant name.
   ![How to configure Auth0 SSO in Oloid... - screenshot 5](/images/intercom/11098861/df7d757f-df2b-467a-8407-7afca40e9c67-c09ff916.png)
3. Replace `&lt;your-auth0-domain>` in the following URL with your actual Auth0 domain:
   `https://&lt;your-auth0-domain>/.well-known/openid-configuration`
   Example:
   [https://dev-1hnsh6lb8jg6s16v.us.auth0.com/.well-known/openid-configuration](https://dev-1hnsh6lb8jg6s16v.us.auth0.com/.well-known/openid-configuration)
4. Open the URL in a browser to view the OpenID configuration.
5. Copy the following endpoint values and paste them into the corresponding fields in the Oloid Portal:
- `authorization_endpoint`
- `token_endpoint`
- `userinfo_endpoint`
