## Introduction

This Document explains how to log in to the Oloid User Portal using Duo SSO.

Before you begin, make sure Duo SSO is enabled for your account. To enable it, contact [Oloid Support.](mailto:Support@oloid.ai)

## Prerequisites

- You should be a user in the Tenant Admin Portal.
- Duo SSO is **enabled for your account**. For more details, refer to [How to configure Oloid User Portal in Tenant Admin Portal.](https://oloid.help/en/articles/9969120-oloid-user-portal-how-to-configure-oloid-user-portal-in-tenant-admin-portal)
- You have the **login URL** provided to access the User Portal.

## Steps to Log in using Duo SSO Login

1. Launch your browser.
2. Enter the provided **URL** in the browser’s address bar and press **Enter**. The **Oloid User Portal** page is displayed.
3. Click **Login with SSO**.
   ![How to Log in to Oloid User Portal... - screenshot 1](/images/intercom/12094207/image-eb43540e.png)
   The configured Login options are displayed.
4. Click **Continue with Duo**.
   ![How to Log in to Oloid User Portal... - screenshot 2](/images/intercom/12094207/162d41f6-160e-4abc-8259-d694407ed0c9-7f483da8.png)
   The Single Sign-on screen is displayed.
5. Follow below steps to complete the sign-in process.
   1. Enter your **Email address >** click **Next**.
      ![A screenshot of a login formAI-generated content may be incorrect.](/images/intercom/12094207/a3ac3210-6526-42ed-852d-da83a2322cc0-41428600.png)
   2. Enter your **Password** > click **Log in.**
      ![How to Log in to Oloid User Portal... - screenshot 3](/images/intercom/12094207/image-17502103.png)
      The **Duo authenticator** screen is displayed.

      <Note>
        **Note:** On authenticator screen, **select your preferred authentication method**. The available authentication method may vary depending on how you configured Duo when setting up your device in the **Duo Consent**.
      </Note>

      **For Example:** If you choose **Duo Mobile passcode,** a code will appear in the app. For **Text Message** or **Duo Push**, you will receive a message or push notification.
      ![How to Log in to Oloid User Portal... - screenshot 4](/images/intercom/12094207/image-1994b776.png)
      The Success pop up page is displayed.
      ![How to Log in to Oloid User Portal... - screenshot 5](/images/intercom/12094207/image-896cea67.png)
      On successful authentication, you are logged in to the Oloid User Portal using Duo SSO.
      ![How to Log in to Oloid User Portal... - screenshot 6](/images/intercom/12094207/image--287-29-3367b3ae.png)
