## Introduction

This document provides step-by-step instructions to configure PingOne Single Sign-On (SSO) for the Oloid Portal in the PingOne Admin Console.

## Prerequisite

You must have **administrator access** to the PingOne Admin Console.

## Steps to Configure PingOne SSO

Create Environment

Create and Configure Applications

### Steps to Create an Environment

<Note>
  **Note:** If an environment already exists, skip this section.
</Note>

1. Sign in to the Ping Identity Administrator Console with your PingOne account credentials.
2. Click **Create Environment**
   ![How to Configure PingOne Single Sign-On... - screenshot 1](/images/intercom/8727716/image-55816dee.png)
   The Create Environment screen is displayed.
3. Select **Customer Solution** and then click **Next**.
   ![How to Configure PingOne Single Sign-On... - screenshot 2](/images/intercom/8727716/image-c3cfcb6e.png)
4. Click **Next**.
   ![How to Configure PingOne Single Sign-On... - screenshot 3](/images/intercom/8727716/image-76265e66.png)
5. Do the following:
   1. Enter **Trial Environment Name**.
   2. Enter **Description (Optional)**
   3. Select **Environment ID**.
   4. Select a **Region**.
   5. Select a **Licence**.
   6. Click **Finish**.
      ![How to Configure PingOne Single Sign-On... - screenshot 4](/images/intercom/8727716/image-f2818bfb.png)
      The environment is created successfully.

### Steps to Create and Configure Application

1. Go to the newly created environment, select **Applications > Applications**.
   ![How to Configure PingOne Single Sign-On... - screenshot 5](/images/intercom/8727716/image-b9f2584b.png)
   The application page is displayed.
2. Click Add icon (![How to Configure PingOne Single Sign-On... - screenshot 6](https://downloads.intercomcdn.com/i/o/e4gi378c/1315355866/00d82bfa56619275fd638dfe1eae/image.png?expires=1790294400&signature=796dcf57e24b74dfb291b0a73c69d4a75404ee6f51c92b4239ddb2ea650098ce&req=dSMmE8p7mIlZX%2FMW3nq%2BgeSv0FFImK1byUIqowgVWWIf0GWmWBBiAwOsAIdR%0AxJW0o2nD9KaoXvmn1Ub8wOD4Z14%3D%0A)).
   ![How to Configure PingOne Single Sign-On... - screenshot 7](/images/intercom/8727716/image-43ab0fde.png)
   The **Add Application** page is displayed.
3. Do the following:
   1. Enter **Application Name**.
   2. Enter **Description** (Optional).
   3. Select **OIDC Web App** as the **Application Type**.
   4. Click **Save**.
      ![How to Configure PingOne Single Sign-On... - screenshot 8](/images/intercom/8727716/944a2c5e-7b97-4b11-9b63-6e35d2b48a7c-4dcf6157.png)
      The application is created successfully.
4. Select the newly created application.
   ![How to Configure PingOne Single Sign-On... - screenshot 9](/images/intercom/8727716/image-850592a4.png)
   The Application detail page is displayed.
5. On the application **profile** page, enable the app using the toggle button next to the application name.
   ![How to Configure PingOne Single Sign-On... - screenshot 10](/images/intercom/8727716/91fb6103-146a-4839-9efb-1d172966a5c5-6185909f.png)
   The app is enabled successfully.
6. Select **Overview** > **OpenID Connect.**
   ![How to Configure PingOne Single Sign-On... - screenshot 11](/images/intercom/8727716/68423eb7-8889-465c-ba36-51509beef8d9-e3c47489.png)
   The **Edit Configuration** screen is displayed.
7. Do the following:
   1. Enter the **Redirect URIs**.

      <Note>
        **Note:** To get the Redirect URIs, go to your **Oloid Portal**, select **Tenant Settings > Security > SSO > PingOne**, and copy the required **Redirect URLs**.
      </Note>

      ![How to Configure PingOne Single Sign-On... - screenshot 12](/images/intercom/8727716/image-4b34c75c.png)
   2. Click **+ Add** to add additional redirect URIs, if required (Optional).
   3. Ensure that **Client Secret Basic** is selected as the **Token Endpoint Authentication Method**.
   4. Click **Save**.

      ![How to Configure PingOne Single Sign-On... - screenshot 13](/images/intercom/8727716/d31aed42-18b4-4272-837d-582a8415a70d-bcc7cbcf.png)
8. In the application overview, click **Resources >** Allowed Scopes **Edit icon.**
   ![How to Configure PingOne Single Sign-On... - screenshot 14](/images/intercom/8727716/image-5afa18e9.png)
   The **Edit Resources** page is displayed.
9. Select **email >** click **Save**.
   ![How to Configure PingOne Single Sign-On... - screenshot 15](/images/intercom/8727716/38be17f1-f621-4bf8-867c-d8b641319ca0-438f36f8.png)
   The **email** scope is added in the allowed scopes list.
   ![How to Configure PingOne Single Sign-On... - screenshot 16](/images/intercom/8727716/image-5e905c86.png)
   The PingOne SSO for Oloid portal is configured successfully.
