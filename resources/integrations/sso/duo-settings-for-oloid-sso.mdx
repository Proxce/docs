## Introduction

This document provides step-by-step instructions for configuring Duo Single Sign-On (SSO) in the Duo Identity Administrator Console for use with the Tenant Admin Portal.

## Prerequisites

Before you begin, ensure the following:

- You have **administrator access** to the **Duo Identity Administrator Console**.
- You have the **redirect URLs** from the Oloid team to complete the SSO configuration. If you don’t have the redirect URLs, contact [Oloid Support.](mailto:Support@oloid.ai)

## Steps to Configure Duo SSO Login for Tenant Admin Portal in Duo Admin Console

1. Sign in to the Duo Identity Administrator Console with your Duo account credentials.
   The Duo Console page is displayed.
   ![Duo Settings for Oloid SSO - screenshot 1](/images/intercom/12094549/image-b2bed055.png)
2. Click **Applications > Applications.**
   ![Duo Settings for Oloid SSO - screenshot 2](/images/intercom/12094549/image-df7949c0.png)
   The Applications page is displayed.
3. Click + **Add Application.**
   ![Duo Settings for Oloid SSO - screenshot 3](/images/intercom/12094549/image-29174f57.png)
   The **Application Catalog** page is displayed.
4. Find the Oloid application in the list or use the search bar to search for it.
   ![A screenshot of a computerAI-generated content may be incorrect.](/images/intercom/12094549/8f4a887f-d855-4f85-8c4d-6e4e122a7258-f86495ce.png)
5. Click **+ Add** on the **Oloid Application**.
   ![A screenshot of a application catalogAI-generated content may be incorrect.](/images/intercom/12094549/86184875-b973-4b6c-8246-9f2a0ecce6a6-d94c1814.png)
   The application is added, and the application details are displayed.
6. By default, the **Single Sign-On** tab is displayed.
   ![Duo Settings for Oloid SSO - screenshot 4](/images/intercom/12094549/image-8e61f4a3.png)
7. Do the following in the **Single Sign-On** tab.
   1. **Basic Configuration:** In this section configure the basic information of the application.
      1. **Application Name:** If required, update the application name.
      2. **User Access:** Click **Enable for all users**.
         ![Duo Settings for Oloid SSO - screenshot 5](/images/intercom/12094549/image-ff9b0ebd.png)
   2. **Metadata:** Select **Copy** next to each of the following parameter and then add these values into the corresponding field in the Tenant Admin Portal.
      1. **Authorization URL**.
      2. **Token URL**.
      3. **Client ID**.
      4. **Client Secret**.
      5. **User Info URL**.
         ![Duo Settings for Oloid SSO - screenshot 6](/images/intercom/12094549/image-5fd73b82.png)

         <Note>
           **Note:** Add the parameters to the relevant sections in the Tenant Admin Portal.
         </Note>

         ![Duo Settings for Oloid SSO - screenshot 7](/images/intercom/12094549/image-fd9c90a5.png)
   3. **Sign-In Redirect URLs:** These URLs allow Duo to redirect users back to the Tenant Admin Portal after successful authentication.
      1. Add the **Redirect URLs** in the **Sign-In Redirect URL** field from Tenant Admin Portal.
         ![Duo Settings for Oloid SSO - screenshot 8](/images/intercom/12094549/f6547586-1256-4e86-b5af-55aac7d5b855-2bffe234.png)
         The redirected URLs are added for the Tenant Admin Portal and Oloid User Portal.

         <Note>
           **Note:** To add more redirect URL, click **+ Add Redirect URL** to add another Sign-In Redirect URL field in this section.
         </Note>

**Example Redirect URLs:**

```
https://<tenantname>.oloid.cloud.com/login/duo/callback
```

```
https://<tenantname>.myoloid.com/login/duo/callback
```

4. **Policy:** Apply a policy to define user access and authentication rules for the application. Select an existing policy or create a new one, if required.
   1. To add policy, click on **Apply a policy to all users**.
      ![A screenshot of a computerAI-generated content may be incorrect.](/images/intercom/12094549/14a5db61-01e0-4cfb-9c25-fa7747f9dacb-f9093c37.png)
      The Add policy pop-up is displayed.
   2. Select the policy from the drop-down menu.

      <Note>
        **Note:** If required, you can create a new policy.
      </Note>

      ![Duo Settings for Oloid SSO - screenshot 9](/images/intercom/12094549/10fa4d63-ebe4-4aa2-9380-a21ccf0576f5-60012d96.png)
   3. Click **Apply Policy.**
      The policy is added to the application.
      You have successfully configured Duo SSO for the Tenant Admin Portal.
