## Introduction

This document provides step-by-step instructions to configure **PingOne Single Sign-On (SSO)** for the Tenant Admin Portal.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- You must configure PingOne and generate the required SSO configuration details in the **PingOne Administrator Console**. For instructions, see [How to Configure PingOne Single Sign-On (SSO) for the Oloid Portal in the PingOne Admin Console](https://oloid.help/en/articles/8727716-how-to-configure-pingone-single-sign-on-sso-for-the-oloid-portal-in-the-pingone-admin-console).

## Steps to Configure PingOne SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **user profile icon** on the bottom-left of the menu panel.
   ![How to Configure PingOne Single Sign-On... - screenshot 1](/images/intercom/10316179/image-3c6dd5f3.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Configure PingOne Single Sign-On... - screenshot 2](/images/intercom/10316179/image-6835c36d.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** > **PingOne**.
   The PingOne configuration section is displayed.
   ![How to Configure PingOne Single Sign-On... - screenshot 3](/images/intercom/10316179/image-61133ce8.png)
5. Turn on **Enable PingOne SSO** toggle.
   ![How to Configure PingOne Single Sign-On... - screenshot 4](/images/intercom/10316179/acbec1de-099c-4412-ae4c-17a77e175e24-8cca301c.png)
6. Do the following:
   1. Copy the **Sign-in Redirect URL.**
      ![How to Configure PingOne Single Sign-On... - screenshot 5](/images/intercom/10316179/image-d4e1a936.png)

      <Note>
        **Note:** Enter the **Sign-in Redirect URL** in the **PingOne Admin Console**. Navigate to **Applications > OpenID Connect** and enter the URL in the **Redirect URIs** field.
      </Note>

      ![How to Configure PingOne Single Sign-On... - screenshot 6](/images/intercom/10316179/image-b917e7c2.png)
   2. Enter the **Environment ID**.
      ![How to Configure PingOne Single Sign-On... - screenshot 7](/images/intercom/10316179/3f507c3a-b8e0-414b-99f5-99f7001396df-94deb9e4.png)
   3. Enter the **Client ID**.
      ![How to Configure PingOne Single Sign-On... - screenshot 8](/images/intercom/10316179/4a39cff8-5981-4fde-ae86-37c5f32a7a3b-1f729d19.png)
   4. Enter the **Client Secret**.
      ![How to Configure PingOne Single Sign-On... - screenshot 9](/images/intercom/10316179/image-7330ebc3.png)

      <Note>
        **Note:** You can find the **Environment ID**, **Client ID**, and **Client Secret** in the **PingOne Administrator Console**. To get these details, go to **Applications > Overview > General**, and copy the required information.
      </Note>

      ![How to Configure PingOne Single Sign-On... - screenshot 10](/images/intercom/10316179/image-a0e8d80c.png)
   5. Enter the **Auth URL**.
      ![How to Configure PingOne Single Sign-On... - screenshot 11](/images/intercom/10316179/6ddd73b6-2786-4778-a582-a111cb33e270-8de8bcc1.png)
   6. Enter the **Token URL**.
      ![How to Configure PingOne Single Sign-On... - screenshot 12](/images/intercom/10316179/image-e9c3396b.png)
   7. Enter the **User Info URL**.
      ![How to Configure PingOne Single Sign-On... - screenshot 13](/images/intercom/10316179/image-4ac4b3c1.png)

      <Note>
        **Note:** You can find the **Auth URL**, **Token URL**, and **User Info URL** in the **PingOne Administrator Console**. To get these URLs, go to **Applications > Overview > Connection Details**, and copy the required URLs.
      </Note>

      ![How to Configure PingOne Single Sign-On... - screenshot 14](/images/intercom/10316179/image-5094c684.png)
7. Click **Save**.
   ![How to Configure PingOne Single Sign-On... - screenshot 15](/images/intercom/10316179/image-21f52b60.png)
   The PingOne SSO is configured successfully.
   ![How to Configure PingOne Single Sign-On... - screenshot 16](/images/intercom/10316179/image-6806811a.png)
