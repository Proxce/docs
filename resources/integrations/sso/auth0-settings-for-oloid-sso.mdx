Steps to configure Auth0 SSO log in the Auth0 for Oloid Portal:

1. Sign in to the Auth0 dashboard using your Auth0 account credentials.
2. In the left menu panel, select **Applications** > **Applications**.
   ![Auth0 Settings for Oloid SSO - screenshot 1](/images/intercom/11103554/56dde240-82d1-4ccc-9811-48172349226b-97bca02a.png)
   The Applications page is displayed.
3. Select **+ Create Application**.
   ![Auth0 Settings for Oloid SSO - screenshot 2](/images/intercom/11103554/f9381264-a136-45ef-b6c7-34f18b8e92d8-618bf9b6.png)
   The Create Application dialog box is displayed.
4. In the dialog box, do the following:
   1. Edit the **Name** field, if needed.
   2. Select **Regular Web Applications**, and then select **Create**.
      ![Auth0 Settings for Oloid SSO - screenshot 3](/images/intercom/11103554/d5c5cca1-8761-4aa4-a93a-9428947044a9-01a835ec.png)
      The application is created successfully.
5. Select the **Settings** tab, and then do the following:
   - In the **Application URIs** section, enter the following Redirect URLs from Oloid Tenant Admin Portal in the **Allowed Callback URLs** field.
     ![Auth0 Settings for Oloid SSO - screenshot 4](/images/intercom/11103554/8c879a55-759a-4b7e-9b08-f6bfbd526664-5778dd94.png)
     ![Auth0 Settings for Oloid SSO - screenshot 5](/images/intercom/11103554/45d86200-2369-4164-a1a0-68184f36d949-a26eafec.png)
   - In the **Basic Information** section, share the **Client ID** and **Client Secret** with [Oloid Support](mailto:support@oloid.ai).
     ![Auth0 Settings for Oloid SSO - screenshot 6](/images/intercom/11103554/87a1a188-6f4c-4df6-8ff7-bbb7bc60e7a1-e4bafe0e.png)
6. Auth0 endpoint parameters can be obtained from the following location -
   `https://&lt;your-auth0-domain>/.well-known/openid-configuration`
   Example:
   [https://dev-1hnsh6lb8jg6s16v.us.auth0.com/.well-known/openid-configuration](https://dev-1hnsh6lb8jg6s16v.us.auth0.com/.well-known/openid-configuration)
