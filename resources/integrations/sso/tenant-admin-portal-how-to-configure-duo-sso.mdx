## Introduction

This document provides steps on how to set up Duo Single Sign-On (SSO) in the Tenant Admin Portal by enabling Duo SSO and adding the required parameters from the Duo Administrator Console.

## Prerequisite

To set up the configuration between Duo and Oloid, you must generate the parameters in Duo Administrator Console. For detailed instructions, see [Duo Settings for Oloid SSO](https://oloid.help/en/articles/12094549-duo-settings-for-oloid-sso).

## Steps to Configure Duo SSO

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Configure Duo SSO - screenshot 1](/images/intercom/12086393/image-edf44676.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Configure Duo SSO - screenshot 2](/images/intercom/12086393/image-190743a7.png)
   The **Tenant Settings** page is displayed.
4. On Tenant Settings page, go to **Security** tab, and click **Duo.**
   The Duo configuration page is displayed.
   ![How to Configure Duo SSO - screenshot 3](/images/intercom/12086393/image-bb8deabc.png)
5. Turn on **Enable Duo SSO** toggle.
   ![How to Configure Duo SSO - screenshot 4](/images/intercom/12086393/image-bce77d6a.png)
6. Copy both **Redirect URLs** from the Duo configuration page and add them to the **Duo Identity Administrator Console**.
   1. Use the first URL for the Tenant Admin Portal.
   2. Use the second URL for the User Portal.
      ![How to Configure Duo SSO - screenshot 5](/images/intercom/12086393/image-8172bd6a.png)

      <Note>
        **Note:** You must enter both URLs in the Duo Identity Administrator Console. They are required to complete the login configuration. For more, refer to [Duo Settings for Oloid SSO](https://oloid.help/en/articles/12094549-duo-settings-for-oloid-sso)
      </Note>

7. In the **Duo Identity Administrator Console**, go to **Application > Single Sign-On** tab, and locate the **[Metadata](https://oloid.help/en/articles/12094549-duo-settings-for-oloid-sso#:~:text=all%20users.-,Metadata%3A,-Select%E2%80%AFCopy%E2%80%AFnext)**section and then Copy the parameters and add the following details.
   1. **Client ID:** Add the Client ID in the Client ID field.
   2. **Auth URL:** Add the Authorization URL in the Auth URL field.
   3. **Token URL:** Add the Token URL in the Token URL field.
   4. **Client Secret:** Add the Client Secret in the Client Secret field.
   5. **User Info URL:** Add the User Info URL in the User Info URL field.
      ![How to Configure Duo SSO - screenshot 6](/images/intercom/12086393/image-4b534934.png)
8. Click **Save**.
   ![How to Configure Duo SSO - screenshot 7](https://downloads.intercomcdn.com/i/o/e4gi378c/2598435600/f0322ab9d9c442cb62cbe52bb868/image.png?expires=1790294400&signature=b19aeed1a8ae610afbb3b37253134cff5efd7f0019b2fef4a9ed4512de419b5c&req=diUuHs19mIdfWfMW3nq%2BgZSSatRQATYuN9WpH%2FXRMMH5rLGXY5Pu9gWzorkt%0AMtGb9%2FAE9Fa1zQv4HR1lULONu8k%3D%0A)
   The Duo Identity SSO is configured.
