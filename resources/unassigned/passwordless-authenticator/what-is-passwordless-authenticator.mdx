Passwordless Authenticator enables authentication of users using facial recognition system and logging into Workforce Identity platforms.

![What is Passwordless Authenticator - screenshot 1](/images/intercom/7199805/image-0c296288.png)

**Benefits of Passwordless Authenticator**

- Face-based login for enterprise applications.
- Fully integrable with existing single-sign-on (SSO) login systems.
- Username, password, or OTP is not required.
- Works on all desktop, laptop, and mobile devices with standard web cameras. No special hardware is required.
