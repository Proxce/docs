## Introduction

In Oloid’s Passwordless feature, adding face refers to the process of integrating a new user using facial recognition for Okta integration. You can log into Okta effortlessly and securely by simply looking at your device's camera.

The process of face onboarding in Oloid Platform involves adding faces to respective users.

### Pre-requisite

You should be a Tenant Admin in the Oloid Platform.

Face onboarding can be done in four ways:

1. [Add face to user](#invite-to-add-face-to-user)
2. [Invite to add face to user](#invite-to-add-face-to-user)
3. [Invite to add face to user in bulk](#invite-to-add-face-to-user-in-bulk)
4. [Import faces in bulk](#import-faces-in-bulk)

### Add face to a user

To add face:

1. Log in to the **Oloid Platform**.
   Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.
   Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu.
   In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Add face**" option.
   In the "**Users**" page select the user to whom you want to add a face. Then, follow the on-screen instructions to complete the process.

For detailed guide on adding face to a user, refer [How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user).

### Invite to add face to user

To invite to add face:

1. Log in to the **Oloid Platform**.

2. Locate the "**Directory**" section.
   Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
