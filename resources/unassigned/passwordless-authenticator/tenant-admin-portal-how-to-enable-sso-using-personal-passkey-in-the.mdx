## Introduction

This document provides step-by-step instructions for enabling SSO using Personal Passkey in the Tenant Admin Portal.

## Prerequisites

- You must have a Tenant Admin account.
- OKTA IDP must be created for the application. To create, refer [How to create IDP Profile for OIDC-Okta in the Tenant Admin Portal](https://oloid.help/en/articles/9214537-how-to-create-idp-profile-for-oidc-okta-in-the-tenant-admin-portal)

## **Steps to** Enable SSO using Personal Passkey

1. Login to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Profile icon** on the bottom left corner of the menu panel.
   ![How to Enable SSO using Personal... - screenshot 1](/images/intercom/13856829/image-6aab28d0.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Enable SSO using Personal... - screenshot 2](/images/intercom/13856829/image-43b533cf.png)
   The **Tenant Settings** page is displayed.
4. Click **Security** tab.
   ![How to Enable SSO using Personal... - screenshot 3](/images/intercom/13856829/image-0d4f4999.png)
   On the Security tab section in the left menu panel select **Passkey.**
5. Do the following:
   1. Turn on **Enable SSO using Personal Passkey** toggle.
   2. Click **Save**.

![How to Enable SSO using Personal... - screenshot 4](/images/intercom/13856829/image-4ecc73ed.png)

The Oloid Passkey SSO is successfully enabled.

![How to Enable SSO using Personal... - screenshot 5](/images/intercom/13856829/image-74cce2a9.png)
