## Introduction

The **Attributes** column in the **Users** list displays key status indicators for each user. These attributes help admins quickly identify account configuration, credential availability, and consent status.

<Note>
  **Note:** Multiple attributes can be displayed as labels for quick identification and reflect the user’s current configuration.
</Note>

## Attribute Descriptions

**Attribute**

**Description**

Oloid Account

Indicates that an Oloid account is created for the user.

Admin

Indicates that the user has administrative access in the Tenant Admin Portal.

Face Descriptor

Indicates that a face credential is enrolled for the user.

Consent Provided

Indicates that the user has provided consent. Face-related features are enabled.

Consent Denied

Indicates that the user has denied consent. Face-related features are restricted.

Re-consent Pending

Indicates that the user must provide consent again to continue using face-related features.
