## Introduction

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Assign Badge ID to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
- Enable Badge as an authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_9366168092:~:text=by%20Oloid%20admin.-,Badge%20ID,-To%20use%20Badge)

## Steps to Login using Badge

1. Double-click on the **Supervisor App** to start.
   ![How to Login to Supervisor App using... - screenshot 1](/images/intercom/16817007/image-78170438.png)
   The Login screen is displayed.
2. Click **Continue with Oloid**.
   ![How to Login to Supervisor App using... - screenshot 2](/images/intercom/16817007/image-fe492c61.png)
   The Credential screen is displayed.
3. Click **Login with Badge.**
   ![How to Login to Supervisor App using... - screenshot 3](/images/intercom/16817007/image-0095ca26.png)
   The Scan badge screen is displayed.
4. Tap the **Badge** on the **Badge Reader** to scan it.
   ![How to Login to Supervisor App using... - screenshot 4](/images/intercom/16817007/image-1db4be72.png)
   On successful authentication User is logged in to Supervisor App.

   ![How to Login to Supervisor App using... - screenshot 5](/images/intercom/16817007/image-f07e463a.png)
