## Introduction

This document explains how to authenticate a user and record punches using the **Offline Intent Screen** in the Oloid Connect application.

When the endpoint is offline, users can select an intent (such as Clock In, Start Break, End Break, or Clock Out) to record punches. These punches are stored locally and sync automatically when the endpoint reconnects to the network.

## Prerequisites

- The Oloid Connect application must be created and configured. For more, refer to [How to Create and Configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- The Offline screen must be configured in the Tenant Admin Portal. For more, refer to [Oloid Connect - How to Configure Offline Intent Screen in Tenant Admin Portal](https://oloid.help/en/articles/13212909-oloid-connect-how-to-configure-offline-intent-screen-in-tenant-admin-portal)
- The Oloid Connect endpoint must be paired. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)
- Badge reader

## Steps to Authenticate using Offline Intent Screen using Badge

1. On the Oloid Connect endpoint preview screen, tap **Login with Badge**.
   ![How to Authenticate User and Record... - screenshot 1](/images/intercom/14280401/36ca7420-bf2e-49ab-b1d8-2ddfad242a9a-0fba21cb.png)
   The **Scan Badge at the Reader** screen is displayed.
2. Scan the Badge at the Reader.
   ![How to Authenticate User and Record... - screenshot 2](/images/intercom/14280401/image-87640728.png)
   After successful authentication, the user details appear at the top of the screen, and the **Choose Your Intent** screen is displayed.

## Record Punch Using Offline Intent Screen

1. On the **Choose Your Intent** screen, tap the required intent button:
   - **Clock In**
   - **Start Break**
   - **End Break**
   - **Clock Out**

Verify the date and time displayed on the screen.

![How to Authenticate User and Record... - screenshot 3](/images/intercom/14280401/image-f0f0f2f9.png)

The success pop-up is displayed after the punch is recorded.

<Note>
  **Note:** These punches are stored locally and sync automatically when the endpoint reconnects to the network.
</Note>
