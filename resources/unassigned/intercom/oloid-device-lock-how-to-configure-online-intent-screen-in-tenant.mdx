## Introduction

The Online Intent Screen in the Oloid Device Lock application allows administrators to capture user actions such as clock-in, clock-out, job selection, and break management during authentication.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- The **Oloid Device Lock application** must be created and configured in the Tenant Admin Portal. For more information, refer

## Steps to Configure Online Intent Screen

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the preferred Oloid Device Lock application.
   ![How to Configure Online Intent Screen... - screenshot 1](/images/intercom/14084945/image-6666d3e9.png)
   The application **details** page is displayed.
   ![How to Configure Online Intent Screen... - screenshot 2](/images/intercom/14084945/image-057ffc51.png)
3. Go to **Configure** tab > **Online Intent Screen.**
   The Online Intent Screen is displayed.
4. Turn on **Show Intent Screen** toggle.
   ![How to Configure Online Intent Screen... - screenshot 3](/images/intercom/14084945/image-13abca35.png)
5. Configure one of the following:
   1. [Job-Code](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal#h_7270caa3ac)
   2. [Multi button](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal#h_7c3498a212)
      The Intent screen is configured successfully.

      <Note>
        **Note:** You must prepare the Job and Charge Code template before configuring the Job and Charge Code. For more, refer to [Oloid Connect - How to prepare Job and Charge Code Template](https://oloid.help/en/articles/11948333-oloid-connect-how-to-prepare-job-and-charge-code-template)
      </Note>

### Configure Multi-Button

<Note>
  **Note:** Once enabled you must add the required fields else blank intent screen will be displayed.
</Note>

1. Go to the **Multi-button** section on the configuration screen.
2. Select **Multi-button.**
3. Do the following:
   1. Configure the Intent Screen
   2. Configure Departments
      ![How to Configure Online Intent Screen... - screenshot 6](/images/intercom/14084945/8e216907-bad1-4257-8e97-b3f31098be3c-e0614695.png)

#### Configure Intent Screen

1. Enter the intent screen title in the **Intent Screen Heading** field. This title appears at the top of the intent screen.
2. Enter a short and clear description in the Intent Screen Description field.
   ![How to Configure Online Intent Screen... - screenshot 7](/images/intercom/14084945/image-3652d26f.png)
   The intent screen heading and description are displayed on the preview screen.
   **Sample intent screen heading and description for reference**
   **Could not display content**
3. Configure the following:
   1. [Configure Intent Screen Buttons](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal#h_60bec37554)
   2. [Design Minimum Lunch Break Config](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal#h_9941417330)
4. Click **Save**.

The intent screen is configured.

#### Design Minimum Lunch Break Config

You can configure the minimum lunch break requirements for the user.

<Note>
  **Note:** You must add Start Lunch and End Lunch button type in your intent screen before you configure minimum lunch break.
</Note>

1. **Lunch Break Validation Message**: Enter the message that will be displayed if the minimum lunch break requirement is not met. (See [Sample Screen](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal#h_2790fbae98) below)
2. **Minimum Lunch Break**: Set the minimum time for a lunch break, specifying hours and minutes. (See [Sample Screen](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal#h_2790fbae98) below)
3. Click **Save** to apply your changes.

#### Setup Departments

You can configure a department section for users during the clock-in and clock-out process.

<Note>
  **Note:** Ensure that the Choose Departments is selected in the Multi-button section.
</Note>

1. Click **+Add Department**.
   ![How to Configure Online Intent Screen... - screenshot 13](/images/intercom/14084945/ce4e29fb-5eaf-4c03-a70b-8419536961a7-fefe8ea4.png)
   The department detail is displayed.
2. Configure the following details:
   1. **Department Name**: Enter the department name.
   2. **Department Code**: Enter a department code.
   3. **Clock ID**: Enter the unique clock ID for the sub-department. (Optional)
   4. Click **Save** to apply your changes.

<Note>
  **Note:** Repeat steps 1–2 for each department you want to add.
</Note>
