## Introduction

The **Adoption Metrics** tab under **Insights** provides administrators with visibility into user adoption and engagement across the organization. It helps measure how actively users are using the platform by tracking successful transactions, daily active users, adoption rates across connections or groups, and week-over-week usage trends.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Access Adoption Metrics

1. Log in to the **Tenant Admin Portal.**
2. From the left navigation menu, click **Insights**.
   ![How to Download Adoption Metrics... - screenshot 1](/images/intercom/17062899/jira-u-_1-314444e0.png)
   The Insight dashboard screen is displayed.
3. Click **Adoption Metrics** tab.
   ![How to Download Adoption Metrics... - screenshot 2](/images/intercom/17062899/jira-u-_5-f415f21d.png)
   The Adoption Metrics page is displayed.
   ![How to Download Adoption Metrics... - screenshot 3](/images/intercom/17062899/jira-7-_1-b5737830.png)
4. You can view and download the following reports.
   1. [Tenant level user adoption](#tenant-level-user-adoption)
   2. [Daily Active Users](#daily-active-users)
   3. Users Adoption by Connection/Groups
   4. Week-over-Week usage

### Tenant level user adoption

The **Tenant Level User Adoption** section displays the percentage of successful transactions out of the total transactions performed during the selected period.

<Note>
  **Note:** The center of the chart displays the **Successful Transactions** percentage.
</Note>

The chart includes the following metrics:

- **Successful Transactions:** The total number of transactions completed successfully.
- **Total Transactions:** The total number of transactions processed during the selected period.
- **User Adoption Percentage:** The percentage of successful transactions compared to total transactions.

**Do the following:**

1. Select a **date** range to view user adoption metrics for the desired period and click **ok**.

![How to Download Adoption Metrics... - screenshot 4](/images/intercom/17062899/jira-7-_2_1-5229605e.png)

Successful transaction out of total transaction is displayed.

### Daily Active Users

1. Do one of the following:
   1. **Connection:**
      Select **Connection**.
      Select **preferred one or more connection(s)** from theConnections drop-down list and click **Apply.**
   2. Select the specific **date** and click **ok**.
   3. Click the **Download** icon and select **CSV** or **Excel**.

      <Note>
        **Note:** You can download the Daily Active Users report in CSV or Excel format.
      </Note>

   4. **Group:**
      1. **Group:**
         1. Select **Group** to filter users based on specific user groups.
         2. Select **preferred one or more group(s)** from thegroups drop-down list and click **Apply.**
      2. **Groups:**
         Select **Connection**.
   5. Select **preferred one or more connection(s)** from theConnections drop-down list and click **Apply.**
   6. Select the specific **date** and click **ok**.
   7. Click the **Download** icon and select **CSV** or **Excel**.

      <Note>
        **Note:** You can download the Daily Active Users report in CSV or Excel forma
      </Note>
