## Introduction

This document provides information about the different **Endpoint Health Statuses** displayed in the Tenant Admin Portal and the basic actions required for each status.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- If the **Endpoint Health Status** is not displayed, contact [Oloid Support](mailto:support@oloid.ai) for assistance.

## Endpoint Health Status

The Endpoint Health Status indicates the current health of an endpoint based on the latest health check performed by the system.

**Status**

**Description**

**Required Action**

**Healthy**

The endpoint is functioning as expected, and all health checks have passed successfully.

No action is required.

**Attention Needed**

The endpoint is reachable, but a connectivity issue has been detected.

**For Example:** One or more URLs or services associated with the endpoint may be unreachable.

Check the endpoint connectivity and the affected URLs or services. If required, review the network, firewall, DNS, or other connectivity settings.

**Critical**

A serious issue has been detected that requires immediate attention. This status occurs primarily when the endpoint battery level falls below 20%.

Check the endpoint battery level and investigate the issue immediately. Take the necessary action to restore the endpoint to normal operation.

**Unknown**

Health monitoring is enabled, but the endpoint is not sending a response to the server or database. Therefore, the system cannot determine its current health status.

Review the health-check results and endpoint connectivity to identify the issue.

**Health Not Enabled**

Health monitoring is not enabled for the endpoint. Therefore, the system does not perform health checks or display health information for the endpoint.

Enable health monitoring for the endpoint if health monitoring is required.

**Offline**

The endpoint is unreachable. This can occur when the device is powered off, disconnected from the network, unable to respond to connectivity checks, or experiencing another communication issue.

Ensure that the endpoint is powered on, connected to the network, and reachable.

## Endpoint Health Checks

The system performs periodic health checks to determine the current health status of an endpoint.

### a. Initial Health Check - 7 Minute

The system performs a preliminary health check around the 7th minute. This check verifies whether the endpoint:

- Has internet or network connectivity.
- Can communicate with the system.

### b. Detailed Health Check - 15 Minutes

The system performs a detailed health check around the 15th minute. This check verifies the health of the endpoint and its associated URLs and services.

If one or more associated URLs or services are unreachable, the endpoint may display the **Attention Needed** status. This indicates that the endpoint is reachable, but a connectivity issue exists with one or more associated URLs or services.

The system updates the **Endpoint Health Status** based on the results of these health checks.
