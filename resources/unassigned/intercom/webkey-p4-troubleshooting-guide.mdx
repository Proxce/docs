## Introduction

This document provides troubleshooting steps for **P4 (Low Severity) issues** in **Windows Login (WebKey)**.

P4 issues are **non-critical** and typically resolved through configuration updates, user sync corrections, or application fixes.

- User Sync Issues (Okta)

## Common Root Causes

- Okta sync delays
- Incorrect group mapping
- User profile updates (rehire, email change)
- Missing application access
- Outdated app version
- Device-level issues

---

## Standard Troubleshooting Workflow

1. Verify user details and recent changes
2. Identify issue category
3. Perform basic validation (restart, retry, version check)
4. Check Okta sync and group mapping
5. Apply fix (manual sync, access update, app update)
6. Confirm resolution with customer

---

## Best Practices

- Ensure correct **Okta group mapping**
- Communicate **sync timing expectations**
- Keep apps **updated to latest version**
- Separate **Oloid vs device issues early**
- Use **manual sync only when required**
