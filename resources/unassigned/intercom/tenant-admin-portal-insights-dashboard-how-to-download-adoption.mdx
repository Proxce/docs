## Introduction

The **Adoption Metrics** tab under **Insights** provides administrators with visibility into user adoption and engagement across the organization. It helps measure how actively users are using the platform by tracking successful transactions, daily active users, adoption rates across connections or groups, and week-over-week usage trends.

## Prerequisites

You must have admin access to the Tenant Admin Portal.

## Steps to Access Adoption Metrics

1. Log in to the **Tenant Admin Portal.** To login refer, [Tenant Admin Portal - How to Log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-tenant-admin-portal-how-to-log-in-to-the-tenant-admin-portal).
2. From the left navigation menu, click **Insights**.
   **The Insight dashboard screen is displayed.**
   ![Insights Dashboard: How to Download... - screenshot 1](/images/intercom/17062899/jira-2-_1-d894bc0b.png)
3. Click **Adoption Metrics** tab.
   The Adoption Metrics page is displayed.
   ![Insights Dashboard: How to Download... - screenshot 2](/images/intercom/17062899/jira-7-_1-4e85f015.png)
4. Select **Date of specific period** > click **Ok.**
   ![Insights Dashboard: How to Download... - screenshot 3](/images/intercom/17062899/jira-7-_2_1-cf5452c9.png)
   Successful transaction out of total transaction of the specific period will be displayed.
   ![Insights Dashboard: How to Download... - screenshot 4](/images/intercom/17062899/jira-7-_2-9236a392.png)
   Users can download reports for the following sections.
5. Do one of the following:
   1. **Connection:**
      1. Select **Connection** to download unique users who have done at least one transaction in a day.
      2. Select the **Connections checkbox** from drop-down and click **apply**.

![Insights Dashboard: How to Download... - screenshot 5](/images/intercom/17062899/jira-8-_2-359501d5.png)
