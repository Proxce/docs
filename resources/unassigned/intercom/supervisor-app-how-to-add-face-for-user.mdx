## Introduction

## Prerequisite

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)

## **Steps to Add** Face

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Add Face for User - screenshot 1](/images/intercom/15732109/image-dfe8be4b.png)
   The **Users** screen with list of users is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top.
   ![How to Add Face for User - screenshot 2](/images/intercom/15732109/image-3c66ca96.png)
   The user's **Details** screen is displayed
4. Click **Submit Consent.**
   ![How to Add Face for User - screenshot 3](/images/intercom/15732109/image-d49a700c.png)
   The Consent pop-up box is displayed.
5. Click **Agree.**
   ![How to Add Face for User - screenshot 4](/images/intercom/15732109/image-61152668.png)
   Consent submitted successfully.
   ![How to Add Face for User - screenshot 5](/images/intercom/15732109/image-8e450eb9.png)
6. Select **Face** tab > Tap **ADD +**.
   ![How to Add Face for User - screenshot 6](/images/intercom/15732109/image-979804b1.png)
   The Camera turns on.
7. Position your face in front of the camera and tap the **Capture** button to enroll your face.

   <Note>
     **Note:** If you do not tap the **Capture** button, the app automatically captures your face after a few seconds.
   </Note>

8. Do one of the following:
   1. Tap **Yes- Submit** to submit the image.
      The face is submitted successfully and is displayed on the details screen.
   2. Tap **No- Retake** to take the photo again.
      The camera turns on to retake the photo.
