## Introduction

## Prerequisites

- Ensure Auth Policy is created.

## Steps to Create Factor Sequence

1. Log in to the Tenant Admin Portal.
2. Select **Security** > Click **Factor Sequencing.**
   The **Factor Sequence for Adaptive MFA** page is displayed.
3. Click **Create Factor Sequence.**
   The **Create Factor Sequence** pop-up box is displayed.
4. Do the following:
   1. Enter **Factor Sequence Name.**
   2. Select Webkey from the **Application Type** dropdown.
   3. Click **Create.**
      The **Factor Sequence Details** page is displayed.
5. Do the following:

[Configure Online Rule.](#configure-online-rule)

[Configure Offline Rule.](#configure-offline-rule)

### Configure Online Rule.

1. Select **Online Rule** tab > Click **+Add Rule.**
2. Do the following:
   1. Select the **IF** credential from dropdown.
   2. Select **Auth Policy** from dropdown.
      Auth Policy must be created for Factor sequence. Refer:
   3. Select **THEN** rule from dropdown.
      1. Select **Allow**
         (OR)
      2. Select **Second factor** > Select checkbox of the required credential as second factor.
   4. Click **Save.**
      The Online Rule is configured.
      To create a new rule click +Add Rule again and repeat the aforementioned steps.

### Configure Offline Rule.

1. Select **Offline Rule** tab > Click **+Add Rule.**
2. Do the following:
   1. Select the **IF** credential from dropdown.
   2. Select **THEN** rule from dropdown.
      1. Select **Allow**
         (OR)
      2. Select **Second factor** > Select checkbox of the required credential as second factor.
   3. Click **Save.**
      The Offline Rule is configured.
      To create a new rule click +Add Rule again and repeat the aforementioned steps.

#### Add Policy Sub-Type

1. Under **AND** Apply Policy section click Edit.
2. Select Policy Sub-type from dropdown.
   1. Select Condition **If User has used** from dropdown,
   2. Select PIN credential from credential dropdown.
   3. Set Auth session time limit.
   4. Click **Save.**
      Multiple Policy Sub-type rules can be added for each rule.
