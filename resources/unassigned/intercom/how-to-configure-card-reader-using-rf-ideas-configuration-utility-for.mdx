## Introduction

This document provides step-by-step instructions for configuring the Card Reader using the RF IDEAS Configuration Utility for Oloid Connect, WebKey, Chrome Vault, and DeviceLock applications.

## Prerequisites

- Ensure a compatible RF IDeas badge reader is available.
- Ensure the required badge/card is available.
- Ensure the RF IDeas Configuration Utility is installed on the laptop.
- You must configure the badge card. For further details, refer [How to configure rf IDEAS readers for badge card](https://oloid.help/en/articles/9398720-how-to-configure-rf-ideas-readers-for-badge-card)
- You must identify the card type and card format. For further details, refer [How to find the Card Type and Card Format using the RF IDeas Configurator Tool](https://oloid.help/en/articles/9720607-how-to-find-the-card-type-and-card-format-using-the-rf-ideas-configurator-tool)

### Identify the card type

1. Launch the **rf IDEAS Configuration Utility** app.
   ![How to configure Card Reader Using RF... - screenshot 1](/images/intercom/11079712/image-0a9e4387.png)
   The app opens.
2. Connect the card reader to the system.
3. Once the badge reader is connected to the laptop, Click On the **“Connect”** button in the **rf IDEAS Configuration Utility**

![How to configure Card Reader Using RF... - screenshot 2](/images/intercom/11079712/image-6dcb6d62.png)

The Device List is configured and displayed.

![How to configure Card Reader Using RF... - screenshot 3](/images/intercom/11079712/image-86bd9ebc.png)

### Verify Badge Type and Reader Compatibility

1. Select the **Tools** option from the **rf IDEAS Configuration Utility** menu.
2. Click **Start** in the “**Card Analyzer**” section.
   ![How to configure Card Reader Using RF... - screenshot 4](/images/intercom/11079712/image-a2982638.png)
   Place the card/badge on the reader.
3. Click **Learn Card**.
   ![How to configure Card Reader Using RF... - screenshot 5](/images/intercom/11079712/image-a5eb5926.png)
   The Learn Card screen is displayed.
4. Click **Start Scan** to begin scanning the badge/card.
   ![How to configure Card Reader Using RF... - screenshot 6](/images/intercom/11079712/image-c44f7fcf.png)

Place the badge/card on the reader and click “**OK**” on the pop-up window that appears.

![How to configure Card Reader Using RF... - screenshot 7](/images/intercom/11079712/image-d504c083.png)

The badge scanning process will begin, and a **“Scanning in Progress”** message will be displayed. Wait until the scanning process is complete.

![How to configure Card Reader Using RF... - screenshot 8](/images/intercom/11079712/image-1edad12a.png)

Once the scanning is completed, the identified card type will be displayed in the “**Card Type**” field. The “**Supporting Readers**” field will also display a list of rf IDEAS readers that support the identified card type.

![How to configure Card Reader Using RF... - screenshot 9](/images/intercom/11079712/image-ec2d4204.png)

### Configure the reader using Auto-Config

6. Click “**Auto Config**” to automatically configure the reader to read the Card ID, of the scanned badge/card.
   ![How to configure Card Reader Using RF... - screenshot 10](/images/intercom/11079712/image-21fc4886.png)
   The Card ID of the scanned/configured card will be displayed in the **Card ID** field, as illustrated in the image below. For example, **16148** represents the Card ID of the card that has been scanned/configured.
7. Click the **Write** button to save the configuration.
   ![How to configure Card Reader Using RF... - screenshot 11](/images/intercom/11079712/image-7f7739af.png)
8. Remove the card from the reader, then click **OK** on the pop-up message.
   ![How to configure Card Reader Using RF... - screenshot 12](/images/intercom/11079712/image-f6e7fb59.png)
9. Finally, click the **Exit** button to close the application.

### Steps to Retrieve Configured Badge Values

Ensure the **RF IDeas reader** is connected to the laptop and is displayed in the **Device List** section.

![How to configure Card Reader Using RF... - screenshot 13](/images/intercom/11079712/image-c811a973.png)

1. Select a **valid card type** from the **Configuration(s) Dropdown**.

   <Note>
     **Note:** The **Configuration(s) Dropdown** refers to the type of card/badge being used to obtain the **badge value**. Select the card type based on the badge type identified earlier.
   </Note>

   Ex : HID Prox, HID iClass CSN,
   **→** “ Based on the badge type identified earlier, select the corresponding card type from the **Configuration(s) Dropdown**.”
   **→** If multiple supporting card types are identified in the card configuration, you can select any one of them.
   **→** If an invalid badge type is selected in the **Configuration(s) Dropdown**, the reader will not read the badge value.
   ![How to configure Card Reader Using RF... - screenshot 14](/images/intercom/11079712/image-3984fedd.png)
2. In the left menu panel, select **SDK**.
3. Turn off the **Disable Keystrokes for SDK** toggle button to disable keystrokes for the SDK-type readers.

   <Note>
     **Note:** If **“Disable Keystroke for SDK”** is already turned off, proceed without making any changes to this setting.
   </Note>

   ![How to configure Card Reader Using RF... - screenshot 15](/images/intercom/11079712/image-8480ebdd.png)
4. Select a **valid card type** from the **Configuration(s) Dropdown**.
5. Click **Write** to apply the configuration.
   ![How to configure Card Reader Using RF... - screenshot 16](/images/intercom/11079712/image-db491ac7.png)
6. Click on the **Test Area** and scan the badge using the reader. If the correct configuration is applied, the reader will read the badge value and display it in the **Text Area**. By default, the badge value is displayed in **Decimal value (12 digits)** format. ### Convert the 12-digit Decimal value into a **5-digit Decimal value**

1. In the left menu panel, select **Format** > **Data Format**
   ![How to configure Card Reader Using RF... - screenshot 18](/images/intercom/11079712/image-0543abcd.png)
2. In the **Data Format** tab, do the following:
   1. Under **Wiegand to Keystroke Data Format → Parity Bits**:
      - Set **Strip Leading Bit Count** to **1**.
      - Set **Strip Trailing Bit Count** to **1**.
      - Turn **Send ID ON**
   2. In the Under **Advanced Settings**:
      - Check the **“ID Extended Precision Math On”** checkbox.
      - Check the **“Invert Wiegand Bits”** checkbox.
        ![How to configure Card Reader Using RF... - screenshot 19](/images/intercom/11079712/image-bdf6f864.png)
3. Click **Write** to save and apply the latest configuration changes.
   ![How to configure Card Reader Using RF... - screenshot 20](/images/intercom/11079712/image-2f28017c.png)
4. Click on the **Test Area** and scan the badge using the reader. If the correct configuration is applied, the reader will read the badge value and display it in the **Text Area**. By default, the badge value is displayed in **Decimal value (5 digits)** format.
   ![How to configure Card Reader Using RF... - screenshot 21](/images/intercom/11079712/image-ac4b130b.png)
