## Introduction

This document provides step-by-step instructions for logging in to the Supervisor App using face authentication. When configured, users can authenticate their identity using their enrolled face to securely access the Supervisor App.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Enable Face under the Windows application. For more details, refer [How to create and configure Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_5bc83c7490:~:text=needing%20further%20authentication.-,Face,-To%20use%20face)
- Manual face capture (as per the requirement) must be configured in Oloid Portal. You need to turn on [Enable Manual Capture Accessibility](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_26561b72fa:~:text=Enable%20Manual%20Capture%20Accessibility%3A)toggle buttonin Windows Configuration.
- Ensure the User Face is added to HR Picture Verification.

## Steps to Login using Face

1. Double-click on the **Supervisor App** to start.
   ![How to Login to Supervisor App using... - screenshot 1](/images/intercom/16816423/image-78170438.png)
   The Login screen is displayed.
2. Click **Continue with Oloid**.
   ![How to Login to Supervisor App using... - screenshot 2](/images/intercom/16816423/image-fe492c61.png)
   The Credential screen is displayed.
3. Click **Login with Face**.
   ![How to Login to Supervisor App using... - screenshot 3](/images/intercom/16816423/image-d2c24614.png)
4. The camera opens.

   <Note>
     **Note:** Provide camera permission if prompted.
   </Note>

5. Position your face in front of the camera to authenticate face.
   On successful authentication User is logged in to Supervisor App.
   ![How to Login to Supervisor App using... - screenshot 4](/images/intercom/16816423/image-8be5ece8.png)
