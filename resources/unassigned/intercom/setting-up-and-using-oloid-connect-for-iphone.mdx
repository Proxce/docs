**Oloid Connect** is a secure, contactless authentication solution. It enables seamless access, attendance tracking, and identity verification using face recognition, PINs, QR codes.

## Installation and Configuration

The Oloid Connect app is installed and configured on the iPhone.

- Download and Install the Oloid Connect App
- Configure the Oloid Connect App

For more details, see [How to Download and Install the Oloid Connect App on iPhone](https://oloid.help/en/articles/12554658-how-to-download-and-install-the-oloid-connect-app-on-iphone)

For more details, see [Oloid Connect - Admin Setup on iPhone](https://oloid.help/en/articles/12554774-oloid-connect-admin-setup-on-iphone)

## Configuration

### Platform

For an end-user to use the Oloid Connect for Passwordless app, the Tenant admin must perform the following configuration in the Oloid Platform.

- Set up Application and Connection
  For more details, see [How to create and configure Oloid Connect for Passwordless application](https://oloid.help/en/articles/9896977-how-to-create-and-configure-oloid-connect-for-passwordless-application)
- Create User and assign to Connection
  For creating user assigning them to Connection, see [How to add user](https://oloid.help/en/articles/8185048-how-to-add-user) guide
- Assign Credentials to users
  For assigning credential to users, see [User Onboarding](https://oloid.help/en/articles/8463554-user-onboarding) guide
- Configure Oloid Connect Endpoint

  <Note>
    **Note:** Oloid Connect Endpoint is created in the Oloid Connect app.
  </Note>

  For more details, see [How to configure Oloid Connect Endpoint](https://oloid.help/en/articles/10550185-how-to-configure-oloid-connect-endpoint)
- Create and Configure Endpoint Template
  For more details, see [How to create and configure Oloid Connect endpoint template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template#h_f874845dd7)
- Grant Supervisor privileges to perform the assigned activities
  - Grant Supervisor permission to pair the endpoint in Oloid Connect app
    For more details, [How to activate Endpoint Pairing action in Oloid Portal](https://oloid.help/en/articles/10000759-how-to-activate-endpoint-pairing-action-in-oloid-portal)

## Oloid Connect App

1. After installing the Oloid Connect app, the Tenant Admin or Supervisor can log in to pair the endpoint.
   For details, see [Oloid Connect - Admin Setup on iPhone](https://oloid.help/en/articles/12554774-oloid-connect-admin-setup-on-iphone)

   <Note>
     **Note:** Endpoint pairing in Oloid Connect generates an endpoint ID with endpoint details in the Oloid Portal.
   </Note>

2. Once the endpoint is paired successfully, log in using:
   1. Face Recognition
   2. Single Sign-On
      For details, see [Oloid Connect - Admin Setup on iPhone](https://oloid.help/en/articles/12554774-oloid-connect-admin-setup-on-iphone)

### Settings

The Tenant Admin or Supervisor can access the settings section of the Oloid Connect app to pair, repair, and unpair endpoint.

For details, refer to the following guides:
