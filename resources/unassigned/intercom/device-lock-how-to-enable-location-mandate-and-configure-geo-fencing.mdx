## Steps to Enable Location Mandate

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Device Lock application.
   ![How to Enable Location Mandate and... - screenshot 1](/images/intercom/15515518/image-6666d3e9.png)
   The application **details** page is displayed.
   ![How to Enable Location Mandate and... - screenshot 2](/images/intercom/15515518/image-057ffc51.png)
3. Go to **Configure** tab > **Settings.**
   ![How to Enable Location Mandate and... - screenshot 3](/images/intercom/15515518/image-212dbafe.png)
   The settings page is displayed.
4. **Enable Location Mandate** toggle.
   When enabled, users must grant device location access before authentication. For more, refer to
5. In the **Geo-fencing Radius** section, configure the allowed authentication distance:
   **Miles** – Enter the allowed radius in miles.
   **Feet** – Enter the allowed radius in feet.
6. Click **Save.**
   ![How to Enable Location Mandate and... - screenshot 4](/images/intercom/15515518/image-0ca3b8ab.png)
   The Location mandate is configured successfully.
   ![How to Enable Location Mandate and... - screenshot 5](/images/intercom/15515518/image-3fa5c761.png)
