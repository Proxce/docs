## Introduction

This document provides instructions to configure PingOne Single Sign-On (SSO) for the DeviceLock App in the PingOne Admin Console.

## Prerequisite

You must have **administrator access** to the PingOne Admin Console.

## Steps to Configure PingOne SSO

[Create Environment](https://oloid.help/en/articles/8727716-how-to-configure-sso-for-oloid-in-the-pingone-admin-console#h_f697741594)

[Create and Configure Applications](https://oloid.help/en/articles/8727716-how-to-configure-sso-for-oloid-in-the-pingone-admin-console#h_4110261098)

### Steps to Create an Environment

<Note>
  **Note:** If an environment already exists, skip this section.
</Note>

1. Sign in to the Ping Identity Administrator Console with your PingOne account credentials.
2. Click **Create Environment**
   ![How to Configure PingOne Single Sign-On... - screenshot 1](/images/intercom/16779341/image-55816dee.png)
   The Create Environment screen is displayed.
3. Select **Customer Solution** and then click **Next**.
   ![How to Configure PingOne Single Sign-On... - screenshot 2](/images/intercom/16779341/image-c3cfcb6e.png)
4. Click **Next**.
   ![How to Configure PingOne Single Sign-On... - screenshot 3](/images/intercom/16779341/image-76265e66.png)
5. Do the following:
   1. Enter **Trial Environment Name**.
   2. Enter **Description (Optional)**
   3. Select **Environment ID**.
   4. Select a **Region**.
   5. Select a **Licence**.
   6. Click **Finish**.
      ![How to Configure PingOne Single Sign-On... - screenshot 4](/images/intercom/16779341/image-f2818bfb.png)
      The environment is created successfully.

### Steps to Create and Configure Application

1. Go to the newly created environment, select **Applications > Applications**.
   ![How to Configure PingOne Single Sign-On... - screenshot 5](/images/intercom/16779341/image-b9f2584b.png)
   The Applications page is displayed.
2. Click Add icon (![How to Configure PingOne Single Sign-On... - screenshot 6](https://downloads.intercomcdn.com/i/o/e4gi378c/1315355866/00d82bfa56619275fd638dfe1eae/image.png?expires=1790294400&signature=796dcf57e24b74dfb291b0a73c69d4a75404ee6f51c92b4239ddb2ea650098ce&req=dSMmE8p7mIlZX%2FMW3nq%2BgeSv0FFImK1byUIqowgVWWIf0GWmWBBiAwOsAIdR%0AxJW0o2nD9KaoXvmn1Ub8wOD4Z14%3D%0A)).
   ![How to Configure PingOne Single Sign-On... - screenshot 7](/images/intercom/16779341/image-43ab0fde.png)
   The **Add Application** page is displayed.
3. Do the following:
   1. Enter **Application Name**.
   2. Enter **Description** (Optional).
   3. Select **Native** as **Application Type**.
   4. Click **Save**.
      ![How to Configure PingOne Single Sign-On... - screenshot 8](/images/intercom/16779341/image-e7e37f21.png)
      The application is created successfully.
4. Select the newly created application.
   ![How to Configure PingOne Single Sign-On... - screenshot 9](/images/intercom/16779341/image-e46640eb.png)
   The Application detail page is displayed.
5. On the application **Profile** page, enable the app using the toggle button next to the application name.
   ![How to Configure PingOne Single Sign-On... - screenshot 10](/images/intercom/16779341/image-6969b0be.png)
   The app is enabled successfully.
6. Select **Overview** > **OpenID Connect.**
   ![How to Configure PingOne Single Sign-On... - screenshot 11](/images/intercom/16779341/image-bfc43c48.png)
   The **Edit Configuration** screen is displayed.
7. Do the following:
   1. Enter `com.connect.oloid://callback` in the **Redirect URIs** field.

      <Note>
        **Note:** Click **+ Add** to add additional redirect URIs, if required (Optional).
      </Note>

   2. Ensure that **None** is selected as the **Token Endpoint Authentication Method**.
   3. Click **Save**.

      ![How to Configure PingOne Single Sign-On... - screenshot 12](/images/intercom/16779341/image-a4a6ed22.png)
8. In the application overview, click **Resources >** Allowed Scopes **Edit icon.**
   ![How to Configure PingOne Single Sign-On... - screenshot 13](/images/intercom/16779341/image-13be02e6.png)
   The **Edit Resources** page is displayed.
9. Select **email >** click **Save**.
   ![How to Configure PingOne Single Sign-On... - screenshot 14](/images/intercom/16779341/image-31e5be94.png)
   The Email is added in the allowed scopes list.
   ![How to Configure PingOne Single Sign-On... - screenshot 15](/images/intercom/16779341/image-910a2490.png)
   The PingOne SSO for Oloid Connect is configured successfully.
