# Introduction

The **Theme** tab in the Tenant Admin Portal for **DeviceLock App** allows admin to customize the app’s appearance to match their organization’s branding. 

 

# Prerequisites

- You must have admin access to the Tenant Admin Portal.
- You must create DeviceLock Application. To create, refer [How to create and configure Device Lock application](https://oloid.help/en/articles/8698213-how-to-create-and-configure-device-lock-application).

# Steps to Configure Theme Tab

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click the **Device Lock Application** to be configured.

#### Configure Theme Section

The **Theme** section allows you to customize the appearance of the application.

1. Click **Theme** section**.**

    
   <img
     src={"https://downloads.intercomcdn.com/i/o/e4gi378c/2739477419/e2c82fc6b3b6d48c56d10a1984df/image.png?expires=1793988000&signature=b81f8cb2c1fcceb513152764131feef6b683e1e411df6f23ab1c03d4d7c18755&req=dickH815moVeUPMW3nq%2BgdQsSYvjBShAiegNxO221kWUg13LAkI6jmf%2B55Ky%0APo2tA2ZUd7kPO5bUrR6AnxPORpI%3D%0A"}
     style={{ width:"1790%" }}
   />
    

   The **Theme** section is displayed.
2. Do the following: 
   1. Edit Customer logo.

      **Note:** The maximum file dimensions for the logo are **264x72 px**, with a maximum size of **1 MB** in **PNG** format.

       
      <img
        src={"https://downloads.intercomcdn.com/i/o/e4gi378c/1778941297/ec5675840f48758e58fa2c0b42c6/image.png?expires=1793988000&signature=3ee2078a519598120bcb60c0591fe45cbd90e074e0929b598726744793cf2ab7&req=dScgHsB6nINWXvMW3nq%2BgZXvSs0Iwfy8ejt1YsFreMSMC5vvJwB%2FKv7ywmGl%0A%2B6mcPq9%2FCnCjzWBZOHt0%2FVgI5JM%3D%0A"}
        style={{ width:"553%" }}
      />
       
   2. **Foreground:** Do one of the following: 
      1. Click or drag an image to the **Foreground Image** area to upload it.<br />​**Note:** For best results, upload a portrait PNG image with a 1:2 ratio. The maximum file size is 2 MB, and the maximum resolution is 1080 x 2048 px.
      2. Select the **Solid Background** checkbox and then enter the color code in the **Foreground Color** field.<br />​**Note:** When the **Solid Background** checkbox is selected, the **Foreground Image** field changes to **Foreground Color**.

          
         <img
           src={"https://downloads.intercomcdn.com/i/o/e4gi378c/2739504853/414ad5e8613ea5cfb30cc549ca90/image.png?expires=1793988000&signature=2a4382f8b21457d0165263b14eb2cbb35243baaea4304575abdb9bdcabbe6339&req=dickH8x%2BmYlaWvMW3nq%2BgfH23THNueU%2Fst97AihNbngqdb9V5iCRiHTv7Kjf%0AKk6zeYhPOujboqLVVeqBavNNcDQ%3D%0A"}
           style={{ width:"901%" }}
         />
          
   3. **Primary Color/Button Default:** Update the primary color code to define the primary button's default background and its hover-state text color.
   4. **Secondary Color/Hover State:** Update the secondary color code to define the primary button's hover background and its default text color.
   5. **Customize Heading:** Update the heading that appears at the top of the screen.
   6. **Heading Text Color:** Update the text color code of the screen heading.
   7. **Widget Header/Footer Color:** Update the background color for the Widget's header and footer.
   8. **Footer Text Color:** Update the footer text color code in Login App.
   9. **Enable Help-text:** Turn on **Enable Help-text** toggle and then enter the help text to display on the **Identity Selection** screen.

      **Note:** The help text is displayed only on the **Identity Selection** screen and must not exceed **100 characters**.

        src={"https://downloads.intercomcdn.com/i/o/e4gi378c/2450024382/04382ea6ded3535f0f7ce4bbcda2/image.png?expires=1793988000&signature=67bc15b31bfde1388597c59820bb0afefecf7afffb90d25447bfb9b1cffb6ac0&req=diQiFsl8mYJXW%2FMW3nq%2BgU%2Bmp5f7Uhvw%2BSezFwCDU88KQfT%2BQ4LiQRtJ3SjR%0A9p0qnnEr8epRDkNRS3bq9a%2BM9io%3D%0A"}

3.  (Optional) In the **Preview** section, select one of the following tabs to preview the theme configuration:
   1. **Identity Selection:** Preview the appearance of the identity selection screen displayed before user authentication.
   2. **Authentication:** Preview the authentication screen displayed when users authenticate using their configured credentials.
   3. **Error:** Preview how error messages and error screens are displayed to users during authentication failures.

#### Configure Language Support

The **Language Support** section allows you to set the default language of the application and control how users can view or change it.

1. Click **Language Support.**

    
   <img
     src={"https://downloads.intercomcdn.com/i/o/e4gi378c/2767496152/7e0b79909b0860dff28f24e128ac/image.png?expires=1793988000&signature=6fdafd5c689dbbfa7aabb8e982ccaf9324bbbf36d22ffa449307bb71eb637c3d&req=dichEc13m4BaW%2FMW3nq%2BgRJDvDW2PMMBHe3yM0SHq0Cwl5XonNoDYi34%2BDBB%0APxQeNttqR5Gz0DTpXlN%2FfNX8DLI%3D%0A"}
     style={{ width:"1864%" }}
   />
    
2. Select the **Default App Language** from dropdown.

   **Note:** 
   - This language is used for all users unless another language is selected.
   - Currently, six languages are supported: English, French, German, Spanish, Portuguese, and Chinese.
3. Select the **Use device language as display language** checkbox. (Optional)

   **Note:** If the device language is not supported, the application is displayed in the default language.
4. Select the **Show language selection dropdown** checkbox to allow users to switch languages on the Oloid login widget. 
   1. Select the preferred dropdown style.<br />​**Note:** You can display the language as a country flag or as a language code (for example, **EN**).
5. Click **Deploy Changes**.
