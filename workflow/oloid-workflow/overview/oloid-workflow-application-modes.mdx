## 1. Workflow - On-prem

The Workflow - On-prem mode allows the Oloid workflow application to operate within your local network infrastructure. This mode requires minimal outbound internet connectivity, primarily for telemetry and maintenance. It ensures data security by keeping most processes and data within your local network, offering robust control and privacy.

### Key Features

- **Local Network Integration**: Seamlessly integrates with your existing on-premises infrastructure.
- **Minimal Internet Dependency**: Only necessary outbound connections for updates and maintenance.
- **Enhanced Security**: Data and workflows remain largely within your internal network.

### Use Cases

- Organizations with strict data privacy requirements.
- Environments with reliable internal network infrastructure.

---

## 2. Workflow - Standalone (On-prem with No Internet Connectivity)

In the Workflow - Standalone mode, the Oloid workflow application operates entirely within your local network infrastructure without any internet connectivity. This mode is ideal for highly secure environments where external internet access is restricted or prohibited.

### Key Features

- **Complete Offline Operation**: No internet connectivity required, ensuring total isolation from external networks.
- **Local Configuration and Updates**: All configurations and updates are managed locally.
- **High Security**: Suitable for environments with stringent security protocols.

### Creating an Application Pairing Config-File

To configure the application in Standalone mode, follow these steps:

1. **Prepare the Config-File**: Create a config-file with the necessary parameters for pairing the application with your local infrastructure.
2. **Include Security Protocols**: Ensure all security measures, such as encryption keys and access controls, are defined in the config-file.
3. **Deploy the Config-File**: Deploy the config-file to the designated local servers or devices hosting the Oloid workflow application.

This configuration ensures that the Workflow - Standalone mode is fully functional within your local environment, providing secure and isolated workflow management.

---

## 3. Workflow - Cloud

The Workflow - Cloud mode offers a fully cloud-based solution, leveraging full internet connectivity. This mode provides scalability, flexibility, and ease of access, allowing users to manage workflows from anywhere with an internet connection.

### Key Features

- **Cloud Integration**: Hosted on cloud servers, providing scalable and flexible workflow management.
- **Full Internet Connectivity**: Enables access to workflows from any location, ensuring seamless operation across distributed teams.
- **Automatic Updates**: Benefit from automatic updates and maintenance, keeping your workflow application up-to-date with the latest features and security patches.

### Use Cases

- Organizations with geographically distributed teams.
- Environments requiring flexible access and scalability.

---

Each application mode is designed to meet specific operational needs, whether you prioritize local control and security or require the flexibility and scalability of cloud-based services. Choose the mode that best fits your organization's requirements and infrastructure.
