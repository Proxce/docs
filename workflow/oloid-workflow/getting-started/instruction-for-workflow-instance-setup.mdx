## Applications to be installed

1. Node JS v22.18.0 (prerequisite)
2. Oloid Workflow application

## Installation Procedure

### Steps to Install Node JS

1. Double-click on **node-v22.18.0** and click **Next** on the pop-up screen to continue with the installation.
   ![Instruction for Workflow Instance Setup - screenshot 1](/images/intercom/8052890/image-7e8c5242.png)
2. Accept the license agreement and click **Next**.
   ![Instruction for Workflow Instance Setup - screenshot 2](/images/intercom/8052890/image-bade5fed.png)
3. Click **Next** on **Destination Folder** screen.
   ![Instruction for Workflow Instance Setup - screenshot 3](/images/intercom/8052890/image-6ffb97f2.png)
4. Click **Next** on **Custom Setup** screen.
   ![Instruction for Workflow Instance Setup - screenshot 4](/images/intercom/8052890/image-d486ab60.png)
5. Click **Next**.
   ![Instruction for Workflow Instance Setup - screenshot 5](/images/intercom/8052890/image-dc0a405a.png)
6. Click **Install**.
   ![Instruction for Workflow Instance Setup - screenshot 6](/images/intercom/8052890/image-7adff49b.png)
7. Click **Finish**.

![Instruction for Workflow Instance Setup - screenshot 7](/images/intercom/8052890/image-7d81773b.png)

### Steps to Install Oloid-Workflow

1. Right-click & open **Oloid Workflow Installer** with **Run as Administrator** option.
2. Select **Installation mode** and click **Initiate Installation**.
   (In Online mode, the installer will fetch necessary install files from internet)
   (In Offline mode, the installer will fetch necessary install files from build.zip file shared by Oloid executive)
   ![Instruction for Workflow Instance Setup - screenshot 8](/images/intercom/8052890/image-020d2556.png)
3. Click **Continue**.

   <Note>
     **Note:** The installer will do various checks and show the status here. In case, installer detects any failure, please contact Oloid executive with screenshot.
   </Note>

   ![Instruction for Workflow Instance Setup - screenshot 9](/images/intercom/8052890/image-dbc16156.png)
4. Fill in the required details – Please talk to Oloid executive for this information.
   1. Tenant Name – Please talk to Oloid executive for this information
   2. Tenant ID – Please talk to Oloid executive for this information
   3. Choose Installer version – Please talk to Oloid executive for this information
   4. Installation Path – local path where application will be installed
   5. Port – default is 80
   6. Installation environment – UAT for sandbox, Prod for Production
      ![Instruction for Workflow Instance Setup - screenshot 10](/images/intercom/8052890/image-48f7fd14.png)
      ![Instruction for Workflow Instance Setup - screenshot 11](/images/intercom/8052890/image-ed46ee73.png)
5. Check the license agreement and Click **Install**.
   ![Instruction for Workflow Instance Setup - screenshot 12](/images/intercom/8052890/image-b54821a9.png)
6. Wait till the installation is complete.
   ![Instruction for Workflow Instance Setup - screenshot 13](/images/intercom/8052890/image-5d15b419.png)
7. Installation Progress will be shown here.
   ![Instruction for Workflow Instance Setup - screenshot 14](/images/intercom/8052890/image-135c2b6d.png)
8. Installation is complete.
9. Click **Finish and Open Application**.
   ![Instruction for Workflow Instance Setup - screenshot 15](/images/intercom/8052890/image-665239a5.png)
