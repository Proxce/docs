## Platform Specific Network Access Requirements

The Oloid Workflow application requires network connectivity to certain
external services during installation and normal operation. The application requires Only OUTBOUND connections over **HTTPS (TCP port 443)**.

## Account Specific Network Access Requirements

1. **ServiceNow**
   - Configure your firewall to allow outbound network traffic from Oloid Workflow application to ServiceNow cloud instance over https. Typically, ServiceNow cloud instances have URLs of the form:
     - https://&lt;tenant-name>.service-now.com
2. **Workday**
   - Configure your firewall to allow outbound network traffic from Oloid Workflow application to Workday cloud instance over https. Typically, Workday cloud instances have URLs of the following forms:

### Installing Oloid Workflow Software: Temporary Outbound Internet Access Required

For a smooth and successful installation of the Oloid Workflow Software, ensure temporary outbound internet access is provided to the system. This access facilitates fetching necessary files, updates, and dependencies from Oloid's servers. Without this connectivity, the installation process might face interruptions or fail to fetch the latest version of the software. It's important to note that this is a **one-time requirement**, primarily for the installation phase. Once the software is installed and up-to-date, continuous internet access might not be mandatory unless specified otherwise for particular functionalities. If you operate within a restricted network environment, please coordinate with your IT team to grant this temporary access.
