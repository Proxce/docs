To pair Oloid Workflow instance:

1. Open your web browser and navigate to – http://localhost.
2. Enter **Tenant Admin Username** and **Password**, then Click **Login**.
   ![How to pair Oloid Workflow instance... - screenshot 1](/images/intercom/9674352/image-833f1a8f.png)
3. Select **Create New Application Instance**, thenClick **Continue**.
   ![How to pair Oloid Workflow instance... - screenshot 2](/images/intercom/9674352/image-128e7442.png)
   The Welcome page is displayed.
4. Do the following:
   1. Enter name for workflow application instance in **New Workflow Instance** field.
   2. Select appropriate tag in the **Select Tags** field
   3. Click **Create Application**.
      ![How to pair Oloid Workflow instance... - screenshot 3](/images/intercom/9674352/image-7e070694.png)
      You are logged in the application.
      ![How to pair Oloid Workflow instance... - screenshot 4](/images/intercom/9674352/image-eb350f61.png)
