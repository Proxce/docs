To assist with the setup of Oloid workflow instance, we need either of below options:

1. Remote Desktop connection of the host machine (OR)
2. Video conference call to dictate setup steps

To install Oloid Workflow, you can follow these general steps:

1. **Install Node.js:** Oloid Workflow is built on top of Node.js, so you need to have Node.js installed first. You can download the latest version of Node.js from the official website (**[https://nodejs.org/en/download/](https://nodejs.org/en/download/)**)
2. **Install Oloid Workflow:** Once Node.js is installed, you can install Oloid Workflow using the Oloid Provided Installer
   This will start Oloid Workflow and it will be accessible via a web browser.
