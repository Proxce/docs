Integrating **Honeywell Pro-watch** with **ServiceNow** using **Oloid Workflow** can offer several benefits to organizations, including:

1. **Improved Security**:
   Honeywell Pro-watch is a comprehensive security management system that provides real-time monitoring and control of access, video, and intrusion events. By integrating it with ServiceNow, organizations can automate security incident response and reduce response times, which can help prevent or mitigate security breaches.
2. **Increased Efficiency:**
   By integrating Pro-watch with ServiceNow, organizations can streamline their security operations and improve operational efficiency. For example, security incidents can be automatically logged and routed to the appropriate security team member for resolution. This can help reduce manual processes and errors, and enable faster resolution times.
3. **Enhanced Visibility:**
   The integration of Pro-watch with ServiceNow provides enhanced visibility into security events and incidents, enabling security teams to identify and respond to issues more quickly. This can help reduce the impact of security incidents and improve overall security posture.
4. **Centralized Management:**
   The integration of Pro-watch with ServiceNow provides a centralized location for managing security incidents, which can help reduce complexity and improve communication between security teams. This can help ensure that all relevant stakeholders are informed of security incidents, enabling faster resolution times.
5. **Increased Compliance:**
   ServiceNow offers a range of compliance management features, including audit trails, reporting, and risk assessments. By integrating Pro-watch with ServiceNow, organizations can improve compliance management by automating compliance-related processes, such as incident response and reporting.

Oloid workflow has a common integration pattern which allows users to integrate **ProWatch** with **ServiceNow** application instance.

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 1](/images/intercom/7041159/image-f4c38b8b.png)

## Usecase

Create ServiceNow ticket when desired ProWatch Event happens,

- ***[Trigger]*** Oloid workflow subscribes to listen to new events happening on ProWatch.

- ***[Action]*** Oloid Workflow creates an incident ticket for ProWatch Event and assigns it to right user.

## Steps to deploy

### 1. Add ProWatch Account

To add a ProWatch account, go to **Accounts** and click **Add Account** and fill up ProWatch Account form and save it.

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 3](/images/intercom/7041159/image-5e2cc5ff.png)

### 2. Add ServiceNow Account

To add a **ServiceNow** account, go to **Accounts** and click **Add Account** and fill up ServiceNow Account form and save it.

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 4](/images/intercom/7041159/image-d9c7b5f8.png)

### 3. Import Pre-built Flow

To import a flow, Click on **Import** and browse the shared **flow Json** file and import it into the application.

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 5](/images/intercom/7041159/image-a16ee3ac.png)

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 6](/images/intercom/7041159/image-a755c4c5.png)

### 4. Update Account associations in the Trigger & Action node

**Double-click** to open **ProWatch Trigger** node for edit, and go to **Account zone** and select the account created in step-1. **Double-click** to open **ServiceNow** Action node for edit, go to **Account zone** and select the account created in step-2.

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 7](/images/intercom/7041159/image-b94358b8.png)

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 8](/images/intercom/7041159/image-62827a11.png)

### 5.Deploy

Hit **Deploy** to start the flow. The flow will capture all trigger events and will perform intended actions.

![ProWatch &lt;&gt; ServiceNow Integration - screenshot 9](/images/intercom/7041159/image-5c6b467a.png)
