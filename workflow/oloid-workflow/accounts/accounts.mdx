Oloid Workflow Accounts contain a method of authentication and authorization for a specific application. Application Trigger/Action nodes use these accounts to connect to them. Users need to rightly configure credentials in the Account. Account is never tied to a flow one-to-one, instead, a single Account can be used by multiple flows.

Once configured, Account can be tested for connectivity and credentials validity. This helps users quickly check if they have configured the right account. Accounts can be created, edited & deleted based on the user's needs. The credentials are stored in AWS Secrets Manager for data security.

The below sections explain how to configure accounts for various applications.
