## Introduction

This document provides instructions to configure Microsoft Entra ID for user synchronization with Oloid.

## Prerequisite

You must have admin access for Microsoft Entra ID Admin console.

## Steps to Configure Microsoft Entra ID for User Sync

1. [Register an Application](#register-an-application)
2. [Configure the Application](https://oloid.help/en/articles/13607433-how-to-configure-advanced-user-sync-in-microsoft-entra-id-admin-console#h_98bc76e322)
3. [Create Client Secret](#create-client-secret)
   Microsoft Entra ID is configured Successfully.

### Register an Application

1. Log in to Azure Portal and select **Microsoft Entra ID** on the home page.
   ![How to Configure User Sync in Microsoft... - screenshot 1](/images/intercom/9807063/aff19387-f8d9-4670-a7cb-ce371450db4e-41197c65.png)
   The Microsoft Entra ID page is displayed.
2. Go to **Overview > Manage** **> App registrations > New registration**.
   ![How to Configure User Sync in Microsoft... - screenshot 2](/images/intercom/9807063/e02687c4-25cf-49f0-81a7-e6a3386ee0b1-e8e7b925.png)
   The Register an application page is displayed.
3. Do the following.
   1. Enter **Name**.
   2. Select Supported account types as **Single tenant only - Oloid AzureAD**.
   3. Click **Register**.
      ![How to Configure User Sync in Microsoft... - screenshot 3](/images/intercom/9807063/image-2d19482c.png)
      The application is registered successfully.

### Configure the Application

1. Navigate to the **newly registered app > API permissions >** **Add a permission > Microsoft Graph.**
   ![How to Configure User Sync in Microsoft... - screenshot 4](/images/intercom/9807063/image-68e341e3.png)
   The **Request API permissions** pop-up box is displayed.
2. Select **Application permissions**.
   ![How to Configure User Sync in Microsoft... - screenshot 5](/images/intercom/9807063/55f4749d-f9c8-4a95-91be-e0a9cd108acd-289b3f95.png)
   The **Request API permissions** screen is displayed.
3. On **User** drop-down, select **User.Read.All.**
4. Click **Add permissions**.
   ![How to Configure User Sync in Microsoft... - screenshot 6](/images/intercom/9807063/image-3de2a63c.png)
   The API is added in the list.
5. Click **Grant admin consent for Oloid-AzureAD.**
   ![How to Configure User Sync in Microsoft... - screenshot 7](/images/intercom/9807063/image-f4ee2a39.png)
   The **Grant admin consent confirmation** pop-up box is displayed.
6. Click **Yes**.
   ![How to Configure User Sync in Microsoft... - screenshot 8](/images/intercom/9807063/image-c7347cb2.png)
   The API is added successfully.
   ![How to Configure User Sync in Microsoft... - screenshot 9](/images/intercom/9807063/image-3c669540.png)

### Create Client Secret

1. Go to **Certificates & secrets** > **Client Secrets > + New client secret**.
   ![How to Configure User Sync in Microsoft... - screenshot 10](/images/intercom/9807063/image-9bca5a3a.png)
   The **Add a client secret** screen is displayed.
2. Do the following:
   1. Enter **Description**.
   2. Select the **Expires** duration from the drop-down list.

      <Note>
        **Note:** Select a key duration (preferably the max available).
      </Note>

   3. Click **Add**.
      ![How to Configure User Sync in Microsoft... - screenshot 11](/images/intercom/9807063/image-60048c30.png)
      The **Client Secret** is added successfully and listed on **Client Secret** tab.

      <Note>
        **Note:** Click on the **Copy to Clipboard** icon next to the value field to copy the secret. This option is available only at the time of creation.
      </Note>

      ![How to Configure User Sync in Microsoft... - screenshot 12](/images/intercom/9807063/image-a639cdf2.png)
      The application is configured successfully.
3. Share the **Application (client) ID**, **Directory (tenant) ID,** and **Client Secret** with Oloid support.
   ![How to Configure User Sync in Microsoft... - screenshot 13](/images/intercom/9807063/image-0154f988.png)
