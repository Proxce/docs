Each Oloid Workflow instance can be configured for health monitoring. This keeps the users updated with the status of application instance.

Health monitoring can be of two types - basic and detailed. It can be configured from the Health Setup section in Oloid Workflow instance UI.

1. Basic health runs every 5 min intervals and it checks the following parameters. Basic health configurations cannot be customized.

a. Application – Core URL set connectivity

b. System – CPU, Memory Usage

c. Network – Interface IP & Connectivity

2. Detailed health runs every 30 min interval and it checks connectivity for a list of user-defined URLs.

## Health Alerts

Health alerts are email notifications that are sent to intended users if the application's health status is not healthy. Users can enable/disable health alerts. Users can also configure recipients for health alerts.

## Detailed Health URLs

Users can define URLs for detailed health check. Every URL is given a name called integration. These URLs are checked for connectivity every 30 min as part of the detailed health check.
