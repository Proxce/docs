## Introduction

The **Oloid Vault (Chrome / Chromium)** application in the Tenant Admin Portal enables secure passwordless access to stored credentials. Admin can configure authentication methods such as Face, QR Code, Badge ID, NFC/ID, and Oloid Session.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- You must create a connection in the Tenant Admin Portal. To create connection, refer [How to create Connections in the Tenant Admin Portal](https://oloid.help/en/articles/8294297-how-to-create-connections-in-the-tenant-admin-portal).

## Steps to Create and Configure Oloid Vault (Chrome / Chromium) Application

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** on the top right corner.
   ![How to Create and Configure Oloid Vault... - screenshot 1](/images/intercom/9586885/image-d590c1b8.png)
   The **Create New Application** pop-up box is displayed.
3. Do the following:
   1. Enter **Application Name.**
   2. Select **Application Type** as **Passwordless**.
   3. Click **Next**.
      ![How to Create and Configure Oloid Vault... - screenshot 2](/images/intercom/9586885/image-b2ab9fa4.png)
      The **Select Passwordless Use Case** screen is displayed.
   4. Select **Oloid Vault**.
   5. Click **Next**.
      ![How to Create and Configure Oloid Vault... - screenshot 3](/images/intercom/9586885/image-2e1a85c3.png)
      The **Select Vault Type** pop-up box is displayed.
   6. Select **Chromium Vault**.
   7. Click **Create**
      ![How to Create and Configure Oloid Vault... - screenshot 4](/images/intercom/9586885/image-873c6b34.png)
      The **Chromium Vault** application is created, and the configuration page is displayed.
4. Configure the following tabs
   1. [Details tab](#configure-details-tab)
   2. [Authenticator tab](#configure-authenticator-tab)
   3. [Configure tab](#setup-configure-tab)
   4. [Connections tab](#configure-connections-tab)

<Note>
  These settings need to be configured only once, and it is recommended to keep the default values.
</Note>

![How to Create and Configure Oloid Vault... - screenshot 5](/images/intercom/9586885/image-71961f7b.png)

### Configure Details Tab

The **Details** tab is used to configure the basic application information, such as the application name, description, and time zone.

Do the following:

1. Update the **Application Name** (if needed).
2. Add the **Description** (Optional).
3. Select the **Time Zone** from the drop-down menu.
4. Click **Save**.
   ![How to Create and Configure Oloid Vault... - screenshot 6](/images/intercom/9586885/image-8841bb3a.png)

### Configure Authenticator Tab

This tab is used to enable the login methods you want to support such as Face, Badge ID, NFC/ID, QR Code and Oloid Session.

<Note>
  You can enable one or more credential options based on your requirements.
</Note>

#### Face

The **Face** authenticator enables users to authenticate using facial recognition for secure passwordless access.

Do the following:

1. Enable **Face** toggle.
   ![How to Create and Configure Oloid Vault... - screenshot 7](/images/intercom/9586885/image-7ce88210.png)
   The **Advanced Settings** page is displayed.
2. Configure the **Face Match Parameters** and **Liveness Check Parameters** on the Advanced Settings page.

   <Note>
     The parameters are pre-configured. This is done by Oloid admin.
   </Note>

3. Click **Save**.

#### Additional Settings

- **Configure Image Capture Resolution:** Select the preferred resolution from the **Select Resolution** drop-down.

  <Note>
    If the selected resolution is not available, the browser will default to the closest supported resolution.
  </Note>

- Click **Save**.
  ![How to Create and Configure Oloid Vault... - screenshot 8](/images/intercom/9586885/1d65c6dd-2523-4099-ad4a-69f3e9a29f0b-26914dc0.png)

#### Badge ID

The **Badge ID** authenticator allows users to authenticate using a badge for quick and secure access.

Do the following:

1. Enable **Badge ID** Toggle.
   ![How to Create and Configure Oloid Vault... - screenshot 9](/images/intercom/9586885/image-417a8b9f.png)
   The **Advanced Settings** page is displayed.
2. Select **RFID Badge Type** from the drop-down.
3. Click **Save**.
   The Badge ID is configured successfully.

#### QR Code

The QR Code feature allows users to authenticate by scanning a QR code.

Do the following.

1. Enable **QR Code** toggle.
2. Enable **Show Camera Flip button** to allow users to switch between the front and rear cameras.

   <Note>
     By default, the front camera opens for QR code scanning.
   </Note>

   1. Under **Default camera selection**, select a camera option:
      1. **Front Camera** (default)
      2. **Rear Camera.**
3. Click **Save**.
   ![How to Create and Configure Oloid Vault... - screenshot 10](/images/intercom/9586885/image-1750c6f7.png)

The QR code is enabled successfully.

#### NFC/ID

The **NFC/ID** authenticator allows users to authenticate by tapping an NFC card or ID badge on a supported reader, enabling quick and secure passwordless access.

1. Enable the **NFC/ID** toggle.
   The **NFC/ID** toggle is enabled successfully.
   ![How to Create and Configure Oloid Vault... - screenshot 11](/images/intercom/9586885/image-5536201e.png)

#### Oloid Session

The **Oloid Session** feature uses the existing Oloid authentication session to securely authenticate users without requiring re-authentication.

<Note>
  - Ensure **Include user token in session response** is enabled in **Endpoint Integration Settings** under **Passwordless Session Token**, as the Oloid session token works only for endpoints that include the user token in the session response.
  - **Oloid Session** can be used as an authenticator for Windows applications only with builds that support **Presence Detection** or **Epic**.
</Note>

Do the following:

1. Enable the **Oloid Session** toggle.
2. Select the **Session Expiry Time** with the help of drop-down.

   <Note>
     The maximum expiry time is **12** Hours.
   </Note>

3. Select one or both of the following options as required:
   1. **Allow login to Oloid Vault only once using an active Oloid session:** Allows the active Oloid session to be used only once to log in to Oloid Vault.
   2. **Auto-login into Oloid Vault using an active Oloid session:** Automatically logs the user in to Oloid Vault when an active Oloid session is available.
4. Click **Save.**
   ![How to Create and Configure Oloid Vault... - screenshot 12](/images/intercom/9586885/image-fb1dfe46.png)
   The Oloid Session is configured successfully.

### Setup Configure Tab

Do the following:

1. [Configure Settings tab](#configure-settings-tab)
2. [Customize Buttons tab](#customize-buttons-tab)

#### Configure Settings Tab

Do the following:

1. **Enable Auto-Submit:** Enable the toggle toautomatically submits prefilled passwords from Oloid Vault to websites.
   ![How to Create and Configure Oloid Vault... - screenshot 14](/images/intercom/9586885/image-7edc6150.png)
2. **Enable Copy Password:** Enable the toggle to allow users to copy passwords from the Oloid Vault home page after logging in.
   ![How to Create and Configure Oloid Vault... - screenshot 15](/images/intercom/9586885/image-65174b6a.png)
3. **Enable Camera to open in a new Tab:** Enable the toggle to open the face camera in a new tab for Oloid Vault users.
   ![How to Create and Configure Oloid Vault... - screenshot 16](/images/intercom/9586885/image-13c9909d.png)
4. **Enable Saving Passkeys:** Enable the toggle to allow users to securely store and use passkeys within the Oloid Vault application for websites that support passkey authentication. For more information, refer, [Oloid Vault (Chrome / Chromium) - How to Enable Saving Passkeys](https://oloid.help/en/articles/12441699-oloid-vault-chrome-chromium-how-to-enable-saving-passkeys)
   ![How to Create and Configure Oloid Vault... - screenshot 17](/images/intercom/9586885/image-159aac9c.png)
5. **Enforce Login via Vault:** Enable the toggle to require authentication to specified URLs using **Oloid Vault** instead of manually entering credentials.
   Do the following:
   1. Enable the **Enforce Login via Oloid Vault** toggle.
   2. In the **Add URL** field, enter the login URL where Vault-based authentication must be enforced.
      ![How to Create and Configure Oloid Vault... - screenshot 18](/images/intercom/9586885/image-74d0eca9.png)
6. **Enable Browser Tracking** toggle to record users' browsing activity as Browser Tracking alerts in the Windows Alert section.
   ![How to Create and Configure Oloid Vault... - screenshot 19](/images/intercom/9586885/image-57e9fe97.png)
7. **Enable Location Alerts** toggle to generate an alert transaction when a user's authentication occurs outside the configured geo-fencing radius. For more, refer to [How to Enable Location Mandate and Configure Geo-fencing Radius](https://oloid.help/en/articles/15699935-oloid-vault-chrome-chromium-how-to-enable-location-mandate-and-configure-geo-fencing-radius)
   ![How to Create and Configure Oloid Vault... - screenshot 20](/images/intercom/9586885/ae8cecd3-c02d-4e1d-bd52-f087e5af5528-70f5fdeb.png)
8. **Show On-screen Floating Action Button:** Enable this feature to add a floating button to provide on-screen quick access to logout.
   ![How to Create and Configure Oloid Vault... - screenshot 21](/images/intercom/9586885/image-2606980c.png)

**Configure Re-authentication Login**

This setting is used to define the **session, browser lock and inactivity time-out durations** for Oloid Vault to ensure secure user sessions.

Do the following:

1. **Session Limit:** Set the maximum duration a user can remain signed into the Oloid Vault per session.

   <Note>
     The maximum session limit is 24 hours.
   </Note>

   ![How to Create and Configure Oloid Vault... - screenshot 22](/images/intercom/9586885/image-fb758565.png)
2. **Enable Browser Lock:** When enabled, the browser is locked until the user re-authenticates through Oloid Vault. To know more, refer [Oloid Vault (Chrome / Chromium) - How to Enable and Configure Enable Browser Lock in the Tenant Admin Portal](https://oloid.help/en/articles/16592657-oloid-vault-chrome-chromium-how-to-enable-and-configure-enable-browser-lock-in-the-tenant-admin-portal)
   ![How to Create and Configure Oloid Vault... - screenshot 23](/images/intercom/9586885/image-b66e9449.png)
3. **Browser Inactivity Timer:** Enable the toggle and set the time duration to protect user sessions from unauthorized access. To know more, refer [Oloid Vault (Chrome / Chromium) - How to Configure Browser Inactivity Timer in the Tenant Admin Portal](https://oloid.help/en/articles/16592724-oloid-vault-chrome-chromium-how-to-configure-browser-inactivity-timer-in-the-tenant-admin-portal)

   <Note>
     Set the timer to automatically log off the user after a specified period of inactivity.
   </Note>

   ![How to Create and Configure Oloid Vault... - screenshot 24](/images/intercom/9586885/image-69763672.png)
4. **Clear Browser Redirect URL:** Enter the URL that opens in a new tab when a different user unlocks the browser using a Windows transaction.
   ![How to Create and Configure Oloid Vault... - screenshot 25](/images/intercom/9586885/image-e01313b7.png)
5. **Clear Browser data:** Select the applicable data to clear browser data when a new user unlocks the browser or when **Logout All** is triggered.
   ![How to Create and Configure Oloid Vault... - screenshot 26](/images/intercom/9586885/image-c7cc8230.png)
6. **Apply Endpoint Template** isused to apply a predefined endpoint template to configure the endpoint with the required settings. Select the Endpoint Template from the drop-down.
   ![How to Create and Configure Oloid Vault... - screenshot 27](/images/intercom/9586885/09aef669-f4bd-4fad-b97d-6c53d0f8123f-f9bb9e2e.png)
7. Click **Save**.
   ![How to Create and Configure Oloid Vault... - screenshot 28](/images/intercom/9586885/image-2f06019e.png)
   The settings tab is configured successfully.

### Configure Connections Tab

This tab is used to select the connections that provide the set of users allowed to authenticate via Oloid vault application.

<Note>
  Ensure that **Oloid ID is enabled**, as it is mandatory for Oloid Vault authentication.
</Note>

Do the following:

1. Select **+ Add Connections**.
   ![How to Create and Configure Oloid Vault... - screenshot 30](/images/intercom/9586885/image-d0310d43.png)
   The **Add Connections** pop-up box is displayed.
2. Select connection from the drop-down and click **Add**.

   <Note>
     You can add maximum 5 connections in an application.
   </Note>

   ![How to Create and Configure Oloid Vault... - screenshot 31](/images/intercom/9586885/image-cb5db837.png)
   The connection is added to the application successfully.

The Oloid Vault application is configured successfully.
