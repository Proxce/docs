The OLOID API is a JSON REST API for your OLOID tenant. Every call is made over HTTPS and authenticated with an ID token you get from the login endpoint.

## Quickstart

<Steps>
  <Step title="Get an ID token">
    Call [`POST /login`](/api-reference/standard/authentication/login) with your username, password and tenant name. The response carries an `IdToken`.
  </Step>
  <Step title="Call the API">
    Send the token on every request as `Authorization: Bearer <id_token>`.
  </Step>
  <Step title="Handle the response">
    Successful calls return `200` with a JSON body. Anything else returns an [error object](/api-reference/get-started/errors) with a status and a message.
  </Step>
</Steps>

```bash
curl --request GET \
  --url 'https://api.oloidpreview.com/users' \
  --header 'Authorization: Bearer <id_token>'
```

## Conventions

| | |
| :--- | :--- |
| Base URL | `https://api.oloidpreview.com` (preview) &middot; `https://api.oloiddev.com` (development) |
| Format | JSON in and out. Send `Content-Type: application/json` with a body. |
| Authentication | `Authorization: Bearer <id_token>` on every call except login. See [Authentication](/api-reference/get-started/authentication). |
| IDs | OLOID IDs (`oloID`, `connectionID`, ...) are 32-character hexadecimal strings. |
| Responses | `{ "message": ..., "data": ... }` on success; see [Errors](/api-reference/get-started/errors). |
