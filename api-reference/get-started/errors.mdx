OLOID APIs use standard HTTP status codes. A `2xx` status means the call worked; anything else returns a JSON error object.

## Status codes

| Status | Meaning |
| :--- | :--- |
| `200` | Success. The body carries `message` and `data`. |
| `400` | Bad request: a required field is missing or a value is invalid. |
| `401` | Unauthorized: the ID token is missing, invalid or expired. |
| `404` | Not found: the ID in the path does not exist in your tenant. |
| `500` | Internal server error. Retry later; contact support if it persists. |
| `502` | Bad gateway: an upstream service did not respond. Retry with backoff. |
