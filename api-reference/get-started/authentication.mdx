Every OLOID API call except login carries an ID token in the `Authorization` header. You get the token from the login endpoint and reuse it until it expires.

## 1. Sign in

Send your credentials to [`POST /login`](/api-reference/standard/authentication/login). No token is needed for this call.

<CodeGroup>

```bash cURL
curl --request POST \
  --url 'https://api.oloidpreview.com/login' \
  --header 'Content-Type: application/json' \
  --data '{
    "UserName": "jane.doe@example.com",
    "TenantName": "acme",
    "Password": "<password>"
  }'
```

</CodeGroup>

## 2. Read the token

A successful login returns Cognito tokens. Use `IdToken` for API calls; keep `RefreshToken` to sign in again without the password.

```json Response
{
  "cognitoToken": {
    "$metadata": {
      "httpStatusCode": 200,
      "requestId": "6607dfa0-4c7c-4d58-9393-08df997d9c0",
      "attempts": 1,
      "totalRetryDelay": 0
    },
    "AuthenticationResult": {
      "AccessToken": "eyJraWQiOiJKZ...access",
      "IdToken": "eyJraWQiOiJGSl...id",
      "RefreshToken": "eyJjdHkiOiJKV1...refresh",
      "ExpiresIn": 3600,
      "TokenType": "Bearer"
    },
    "ChallengeParameters": {}
  },
  "user": {
    "OloID": "c4d2a2909b6711ef81534be9be30797b",
    "TenantID": "FA0280A8A0E64DF9",
    "TenantName": "acme"
  }
}
```

## 3. Call the API

```bash
curl --url 'https://api.oloidpreview.com/users' \
  --header 'Authorization: Bearer <id_token>'
```

<Tip>In this reference, select **Try it** on any endpoint and paste the ID token into the **Authorization** field to send a real request from the page.</Tip>

## Token errors

| Status | Meaning | What to do |
| :--- | :--- | :--- |
| `401` | The token is missing, malformed or expired. | Sign in again and retry with the new token. |
| `400` | The login body is missing a field. | Send `UserName`, `Password` and `TenantName`. |

<Note>Advanced and Scoped APIs have their own login pages, visible after you sign in to these docs. Scoped tokens use a client ID and secret instead of a user password.</Note>
