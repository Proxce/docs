Scoped APIs serve specific reporting and integration use cases. Their tokens come from a separate login and carry only the scopes you grant in the Tenant Admin Portal, so an integration can read activity logs or transactions without full administrator rights.

<Steps>
  <Step title="Create scoped credentials">
    In the Tenant Admin Portal, create a client ID and client secret and choose the scopes the integration needs.
  </Step>
  <Step title="Get a scoped token">
    Call the scoped [login](/api-reference/scoped/authentication/login) with the client ID as `UserName`, your tenant as `TenantName`, and the client secret as `Password`.
  </Step>
  <Step title="Call a scoped API">
    Send the ID token from the response as `Authorization: Bearer <id_token>`.
  </Step>
</Steps>
