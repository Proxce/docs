## Introduction

This document provides step-by-step instructions for logging in with NFC/ID and PIN to Workforce / HRMS platforms.

## Prerequisites

- You must have an Okta account.
- In the Tenant Admin Portal, you must do the following:
  - Assign NFC to the user. For more details, refer [How to assign NFC/ID as a credential to the user](https://oloid.help/en/articles/8403103-how-to-assign-nfc-id-as-a-credential-to-the-user)
  - Add a PIN for the user. For more details, refer [How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
- In the Tenant Admin Portal, you must enable NFC/ID and PIN under the WebKey Application. For more details, refer [How to create and configure Webkey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application) > [Configure Authenticator tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_6e2751be8f)

## Login using Badge and PIN

1. Launch the **Webkey** Application URL in your browser.
2. On the home page of the app, select **Login with NFC/ID**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/9245333/image-88f5b85f.png)
   The **Scan NFC/ID Tag** screen is displayed.
3. Tap the **NFC/ID** tag on the **Reader** to scan it.

   <Note>
     **Note:** The Reader should be connected to your system.
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/9245333/image-7e783cac.png)
   On NFC/ID authentication, the **Type or Scan PIN** screen is displayed.
4. Do any of the following:
   1. Tap the card that contains the PIN on the **Reader** to scan it.

<Note>
  **Note:** The Reader should be connected to your system.
</Note>

**(OR)**

1. Enter the **PIN**.
2. Click **Submit**.

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/9245333/image-1f442433.png)

On PIN authentication, you are signed in to the **Workforce /HRMS** platform.

![How to log into Workforce /HRMS... - screenshot 4](/images/intercom/9245333/image-5d8c6a40.png)
