## Introduction

Badge Authentication enables users to securely sign in to supported Workforce and HRMS platforms by scanning a registered badge on a connected badge reader. Once the badge is verified, Webkey authenticates the user and signs them in to the configured HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:
  - Assign badge to the user. For more details, refer[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
  - Enable badge option under the Webkey Application. For more details, refer [How to create and configure Webkey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)

## Steps to Login with Badge

1. Launch the **Webkey** Application URL in your browser.
2. On the home page of the app, select **Login with Badge**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/9259058/image-bba74839.png)
   The **Scan Badge at the Reader** screen is displayed.
3. Tap the **Badge** on the **Badge Reader** to scan it.

![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/9259058/image-6acd3f7d.png)

On Badge authentication, you are signed in to the **Workforce /HRMS** platform.

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/9259058/image-5f4f02b9.png)
