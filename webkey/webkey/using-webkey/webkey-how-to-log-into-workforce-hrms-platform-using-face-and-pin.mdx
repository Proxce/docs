## Introduction

This document provides step-by-step instructions for logging in with face and PIN to Workforce /HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:
  - Add Face to the user. For more details, refer [How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user)
  - Add PIN for the user. For more details, refer[How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable Face and PIN under the WebKey Application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)
  - Manual face capture (as per the requirement) must be configured in Tenant Admin Portal.

## Steps to Login with Face

1. Launch the **Webkey** application URL in your browser.
2. On the home screen of the app, select **Login with Face**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/8608007/image-d66e4779.png)
3. Place your face in front of the camera for facial authentication and press **Enter or Spacebar.**

   <Note>
     **Note:** For manual capture to function it must be configured in the Tenant Admin Portal.
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/8608007/image-95b832bb.png)
4. On Face authentication, the **Type or Scan PIN** screen is displayed.
5. Do any of the following:
   1. Enter **PIN**.
   2. Tap the card which contains the PIN on the **Reader** to scan it.

      <Note>
        **Note:** The Reader should be connected to your system.
      </Note>

Click **Submit**.

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/8608007/image-d93df36c.png)

On PIN authentication, you are signed in to the **Workforce /HRMS** platform.

![How to log into Workforce /HRMS... - screenshot 4](/images/intercom/8608007/image-bad26fb9.png)

</Note>
