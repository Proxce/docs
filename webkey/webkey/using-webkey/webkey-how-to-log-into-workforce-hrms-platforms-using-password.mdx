## Introduction

This document provides step-by-step instructions for logging in with Password to Workforce / HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the Tenant Admin Portal, you must enable custom login option under the WebKey application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application) > [Design Configure Tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_ba84a9ee65) > [Configure Login Page Options](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_d92b43727a).

### Steps to Log in with Password

1. Launch the **Webkey** Application URL in your browser.
2. On the home page of the app, select **Login with Password**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/8856182/image-7e77fe30.png)
   The Okta Sign In page is displayed.
3. Enter your login credential.

![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/8856182/image-5738b9ad.png)

On password authentication, you are successfully signed in to the Okta system.

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/8856182/image-d61970d9.png)

---

#### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

<Note>
  **Note:** Languages supported: English, Spanish, French, German, and Portuguese language.
</Note>
