## Introduction

Users must first authenticate by scanning their registered badge and then verify their identity using their PIN before being signed in to the configured Workforce or HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:
  - Assign badge to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
  - Add a PIN for the user. For more details, refer [How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable Badge and PIN options under the WebKey Application. For more details, refer [How to create and configure Webkey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)

## Steps to Log in using Badge

1. Launch the **Webkey** Application URL in your browser.
2. On the home page of the app, select **Login with Badge**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/8611424/image-36021802.png)
   The **Scan Badge at the Reader** screen is displayed.
3. Tap the **Badge** on the **Reader** to scan it.
   ![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/8611424/image-31fd5830.png)
   On Badge authentication, the **Type or Scan PIN** screen is displayed.
4. Do any of the following:
   1. Enter **PIN**.
   2. Tap the card that contains the PIN on the **Reader** to scan it.

      <Note>
        **Note:** The Reader should be connected to your system.
      </Note>

5. Enter the **PIN**.
6. Click **Submit**.

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/8611424/image-6bddbe6b.png)

On PIN authentication, you are signed in to the **Workforce /HRMS** platform.

![How to log into Workforce /HRMS... - screenshot 4](/images/intercom/8611424/image-fe5bbe9b.png)

</Note>
