## Introduction

This document provides step-by-step instructions for logging in to the Workforce / HRMS platform using NFC/ID authentication through Webkey.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:
  - Assign NFC/ID to the user. For more details, refer [How to assign NFC/ID as a credential to the user](https://oloid.help/en/articles/8403103-how-to-assign-nfc-id-as-a-credential-to-the-user)
  - Enable NFC/ID under the WebKey Application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application) >[Configure Authenticator tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_6e2751be8f)

### Steps to Login using the NFC/ID

1. Launch the **WebKey** Application URL in your browser.
2. On the home page of the app, select **Login with NFC/ID**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/9286137/image-88f5b85f.png)
   The **Scan NFC/ID Tag** screen is displayed.
3. Tap the **NFC/ID** tag on the **Reader** to scan it.

   <Note>
     **Note:** The Reader should be connected to your system.
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/9286137/image-7e783cac.png)
   You are signed in to the **Workforce / HRMS** platform when NFC authentication is done.
   ![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/9286137/image-d3a017ea.png)

#### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

<Note>
  **Note:** Languages supported: English, Spanish, French, German, and Portuguese language.
</Note>
