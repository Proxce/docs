## Introduction

This document provides step-by-step instructions for logging in with face to Workforce /HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential (user email ID) must be added to the user detail page.
- In the Tenant Admin Portal, you must do the following:
  - Add Face to the user. For more details, refer [How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user)
  - Enable Face under the WebKey Application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)
  - Manual face capture (as per the requirement) must be configured in Oloid Portal. You need to turn on [Enable Manual Capture Accessibility](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_ba84a9ee65:~:text=Enable%20Manual%20Capture%20Accessibility)toggle buttonin WebKey Configuration. For detailed instruction see, [WebKey: Platform Configuration for manual capture of face](https://oloid.help/en/articles/10454903-webkey-platform-configuration-for-manual-capture-of-face)

## Steps to Login using Face

1. Launch the **Webkey** Application URL in your browser.
2. On the home page of the app, select **Login with Face**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/9259082/image-734b20d8.png)
   Place your face in front of the camera for facial authentication.
3. The camera auto-captures the user's face.
   If manual capture is enabled, press **Enter or Spacebar,** or click on the camera icon.

![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/9259082/image-39eff08f.png)

Authentication in progress.

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/9259082/image-cb81fd47.png)

You are signed in to the **Workforce / HRMS** platform when facial authentication is done.

#### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

<Note>
  **Note:** Languages supported: English, Spanish, French, German, and Portuguese language.
</Note>
