## Introduction

This document provides step-by-step instructions for logging in with QR Code and PIN to Workforce /HRMS platform.

## Prerequisites

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the Tenant Admin Portal, you must do the following:
  - Create QR Code for the user. For more details, refer [How to create QR code as credential for User](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-for-user)
  - Enable QR Code option under the WebKey Application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)
  - Add PIN for the user. For more details, refer[How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable QR and PIN under the WebKey Application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)
  - If you are using iOS or Android devices, you can select camera options (front/rear). To configure camera options, refer to [Show Camera Flip button](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application?q=webkey+qr+code#h_49002bcbb7:~:text=Show%20Camera%20Flip%20button)

### Steps to Login using the QR Code and PIN

1. Launch the **Webkey** application URL in your browser.
2. On the home page of the application, select **Login with QR Code**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into OKTA Workforce /HRMS... - screenshot 1](/images/intercom/10454981/image-88ff302e.png)
   By default, the front camera opens for QR code scanning.
3. Hold your mobile device or tablet with the QR code facing the preview screen. Next, scan QR Code for QR Code authentication.
   ![How to log into OKTA Workforce /HRMS... - screenshot 2](/images/intercom/10454981/image-1695acc4.png)
4. If your device supports multiple cameras, then do the following:
   1. Tap the **Camera Flip Button** in the preview screen.
   2. Select **Front Camera** or **Back Camera** as needed.
   3. Scan the QR code.

      <Note>
        **Note:** The Camera Flip option must be configured for WebKey application.
      </Note>

      ![How to log into OKTA Workforce /HRMS... - screenshot 3](/images/intercom/10454981/image-a1388803.png)
5. Scan QR Code for QR Code authentication.
   ![How to log into OKTA Workforce /HRMS... - screenshot 4](/images/intercom/10454981/image-fd6cd493.png)
   On QR Code authentication, the **Type or Scan PIN** screen is displayed.
6. Do any of the following:
   1. Tap the card that contains the PIN on the **Reader** to scan it.

<Note>
  **Note:** The Reader should be connected to your system.
</Note>

**(OR)**

1. Enter the **PIN**.
2. Click **Submit**.

![How to log into OKTA Workforce /HRMS... - screenshot 5](/images/intercom/10454981/image-7dcfb0bd.png)

On PIN authentication, you are signed in to the **Workforce /HRMS** platform.

![How to log into OKTA Workforce /HRMS... - screenshot 6](/images/intercom/10454981/image-fe5bbe9b.png)

</Note>
