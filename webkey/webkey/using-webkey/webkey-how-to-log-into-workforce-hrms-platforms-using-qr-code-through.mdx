## Introduction

This document provides step-by-step instructions for logging in with QR Code to Workforce /HRMS platform.

### Pre-requisite

- You must have an Okta account.
- The Okta credential must be added to the user detail page. For more details, refer [How to configure user details](https://oloid.help/en/articles/8347344-how-to-configure-user-details)
- In the tenant Admin Portal, you must do the following:
  - Create QR Code for the user. For more details, refer [How to create QR code as credential for User](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-for-user)
  - Enable QR Code option under the WebKey Application. For more details, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)
  - If you are using Android phones, tablets, dual-camera laptops, and laptops with external cameras, you can select camera options (front/rear). To configure camera options, refer to [Show Camera Flip button](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application?q=webkey+qr+code#h_49002bcbb7:~:text=Show%20Camera%20Flip%20button)

### Using the QR Code

1. Launch the **Webkey** Application URL in your browser.
2. On the home page of the app, select **Login with QR Code**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to log into Workforce /HRMS... - screenshot 1](/images/intercom/8855767/image-6703600e.png)
   By default, the front camera opens for QR code scanning.
3. Hold your mobile device or tablet with the QR code facing the preview screen. Next, scan QR Code for QR Code authentication.
   ![How to log into Workforce /HRMS... - screenshot 2](/images/intercom/8855767/image-1695acc4.png)
4. If your device supports multiple cameras, then do the following:
   1. Tap the **Camera Flip Button** in the preview screen.
   2. Select **Front Camera** or **Back Camera** as needed.
   3. Scan the QR code.

<Note>
  **Note:** The Camera Flip option must be configured for WebKey application.
</Note>

![How to log into Workforce /HRMS... - screenshot 3](/images/intercom/8855767/image-a1388803.png)

You are logged into the Workforce /HRMS platform when QR Code authentication is done.

![How to log into Workforce /HRMS... - screenshot 4](/images/intercom/8855767/image-bad26fb9.png)

#### Additional Information

**WebKey** now supports multiple language versions, allowing users to select their preferred display language from the **Language Dropdown Selector** on the Login screen.

<Note>
  **Note:** Languages supported: English, Spanish, French, German, and Portuguese language.
</Note>
