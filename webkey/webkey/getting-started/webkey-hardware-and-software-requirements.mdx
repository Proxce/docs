## Introduction

This document provides the minimum hardware and software requirements needed to run the Webkey application in browser or android device. Ensure that your system meets these requirements before installing the Webkey in your system to avoid compatibility or performance issues.

## Minimum Software Requirements

**Components**

**Minimum Requirement**

Browser

Supports all major browsers for Windows (Google Chrome, Mozilla Firefox, Microsoft Edge etc.,) and Apple Macs (Apple Safari, Google Chrome, Mozilla Firefox etc.).

Operating System

Windows 10 or above; macOS Mojave (version 10.14) or macOS Catalina (version 10.15).

## Minimum Hardware Requirements

**Components**

**Minimum Requirement**

RAM

4 GB or more

Camera

Minimum 5 MP resolution (required for Face recognition and QR code).

Camera Resolution

Minimum camera resolution will be 640*480.

Card Reader

Required Card reader for Badge/NFC authentication.

Badge

Required Badge for authentication.

NFC ID

Required NFC ID for authentication.

<Note>
  **Note:** For supported card types, refer [Oloid Supported Card Types](https://oloid.help/en/articles/9900195-oloid-supported-card-types)
</Note>

## Web NFC (Android Device)

**Components**

**Minimum Requirement**

Device

Android

Device Version

Android 10 or higher

Browser Version

Chrome 89 or above

NFC Hardware

Your device must have built-in NFC hardware.

## Incompatibility Warnings

Webkey **may not function properly** on web browser with the following limitations:

- Operating system is below window 10.
- Devices without a functional camera or NFC module.
- Device RAM is below 4 GB.
- Android version is below 10.
