## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

**Field**

**Value**

Product Name

Webkey

HTTPS

Use the following table for URL whitelisting.

**Service**

**UAT**

**Description**

Passwordless Authentication

&lt;tenantname>.oloidsso.net

Passwordless Authentication used for secure user authentication without passwords.

Admin API

api.oloidpreview.com

The Admin API is used for Authentication.

Tenant User API **(Optional - Required only for Enrollment)**

api.previewoloid.net

The Tenant User API is used for Enrollment.

Oloid Document Bucket **(Optional)**

oloiddocument-preview.s3.us-east-2.amazonaws.com

This URL is required when a theme is configured.

##### Notes

- Replace **&lt;tenantname>** and **&lt;tenantid>** with your organization's Tenant name and Tenant ID.
- Enter the **&lt;tenantname>** and **&lt;tenantid>** values in lowercase only.
- Contact [Oloid Support](mailto:support@oloid.ai), if you do not have the **&lt;tenantname>** and **&lt;tenantid>** details.
