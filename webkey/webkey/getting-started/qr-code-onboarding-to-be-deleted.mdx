**Introduction**

In Oloid’s Passwordless feature, adding QR code functionality enhances the authentication process for your Okta account. Instead of passwords, users simply scan a QR code to integrate with Okta.

In the Oloid Platform, QR code onboarding involves creating unique QR Codes for respective users. It’s a simple and secure way to manage user access.

**Pre-requisite:**

- You should be a Tenant Admin in the Oloid Portal.
- User is added to Oloid Portal.

**To create QR Code:**

1. Log in to the Oloid Platform.
   Log in to your account with the appropriate credentials.
2. Locate the "**Directory**" section.
   Navigate to the "**Directory**" section to find a range of options for managing user profiles and permissions.
3. Navigate to the "**Users**" menu.
   In the "**Directory**" section, select the "**Users**" menu.
4. Select "**Create QR Code**".
   On the "**Users**" page select the user for whom you want to create a QR Code. Then, follow the on-screen instructions to complete the process.
   For detailed guide on QR Code onboarding, refer [How to create QR code as credential for User](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-for-user)
