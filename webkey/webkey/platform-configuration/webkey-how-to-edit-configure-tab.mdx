## Introduction

The Configure tab in the Webkey Passwordless application allows Tenant Admins to customize authentication behavior.

## Prerequisites

- You must have a Tenant Admin account.
- Webkey Application must be created. For further details, refer [How to create a Webkey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)

## Steps to edit Configure Tab

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Webkey application to edit.
   ![How to edit Configure tab - screenshot 1](/images/intercom/10800566/image-d74a8c32.png)
   The application page is displayed.
   ![How to edit Configure tab - screenshot 2](/images/intercom/10800566/image-8d7449fb.png)
3. Go to **Configure tab** > Click **Settings**.
   ![How to edit Configure tab - screenshot 3](/images/intercom/10800566/image-5c3690cc.png)
   The Configure page is displayed.
4. Do the following.
   1. **Enable Inactivity Session Time Out:** Webkey will automatically return to the previous screen if credential capture fails within the set limit.
      1. Enable **Inactivity Session Time Out** toggle.
      2. Set **Time Out Duration.** (Unit is in seconds)
      3. Enable **Custom Time-out Redirect URL.**
      4. Enter **Custom Time-out Redirect URL.**

         <Note>
           **Note:** Enabling the custom timeout redirect URL will redirect the browser to the specified URL after a period of inactivity session time-out, instead of returning the user to the default login home page.
         </Note>

         ![How to edit Configure tab - screenshot 4](/images/intercom/10800566/image-ba3e7382.png)
   2. Turn on **Enable Auto-Authentication using Windows Oloid Session** toggle button. This will allow user to auto-authenticate into Webkey after device login.
   3. Turn on **Enable Continue Without Oloid Session** toggle button.
      This will allow user to authenticate manually without giving an error if local authentication transaction is not found.
   4. Click **Save.**
      ![How to edit Configure tab - screenshot 5](/images/intercom/10800566/image-8e4ad28e.png)

### Client Authentication

#### Enable **Custom User Agent**

1. Enable **Custom User Agent** To allow users to log in to Webkey app from custom browsers.
2. Enter the custom browser’s user agent string in **Add user agent header** field.
   ![How to edit Configure tab - screenshot 6](/images/intercom/10800566/d9fb4479-7716-4f8c-8e0b-5f97cd2f8763-4c9fc783.png)
3. **Add Device** enables the configuration of custom user agents.For more detail, refer to [How to configure Custom User Agent in Webkey Application](https://oloid.help/en/articles/11659241-how-to-configure-custom-user-agent-in-webkey-application#:~:text=Go%20to%20Configure%20tab%20%3E%20Settings%20%3E%20Browser%20Settings)

   <Note>
     **Note:** Agent browser should be configured for User agent. Reach out to [Oloid Support](mailto:support@oloid.ai) for details.
   </Note>

#### Enable Browser Fingerprint

Select **Enable Browser Fingerprint** to allow Webkey login to function only on registered browsers.

Do the following:

- Enable **+ Browser Fingerprint** toggle to manually add browser fingerprint.
- Select **Transactions** > **Action** dropdown > **Add Browser Fingerprint to Application**. For more information, see [How to configure Browser Fingerprint for Webkey](https://oloid.help/en/articles/9545445-how-to-configure-browser-fingerprint-for-webkey#:~:text=Go%20to%20Configure%20tab%20%3E%20Settings%20tab%20%3E%20Select%20Enable%20Browser%20Fingerprint.)
- Click **Save**.
  ![How to edit Configure tab - screenshot 7](/images/intercom/10800566/e2bd16ca-28f6-438b-a4f8-bdff0bf44fd7-313e01bd.png)
  Webkey is accessible after permission is provided.

### Configure Customize Buttons Tab

To configure customize buttons tab, do the following:

1. Enter customized **Button Label** to display on the Webkey application.
2. **Enable Enrollment**: Enabling this option will add a button to enroll face credential.
   1. Select **Enable Enrollment** checkbox
   2. Enter Customized **Button Label**.
   3. Enter **Enroll URL** to the login page of the Webkey application.
   4. Select **Show Option Only on Face Login Failure** to display the selected option only when face authentication fails.
3. Select **Enable Custom Button** option to add a customized button.
   1. Enter Customized **Button Label**.
   2. Enter **Redirect URL** to the login page of the Webkey application.
4. Click **Save.**

   <Note>
     **Note:** Click **Save** after each action to save your configuration.
   </Note>

![How to edit Configure tab - screenshot 8](/images/intercom/10800566/image-e2d9808a.png)

### Configure Enable Custom Button in Authentication Flow

Tenant Admin can configure a **Custom Button** in the Authentication Flow that redirects users to a specified URL.

To configure Enable Custom Button in Authentication Flow do the following:

1. Turn on **Enable Custom button in Authentication Flow** toggle button.
2. Enter **Button Label**.
   This text will show up as button label on the Login page. Default label is
   back.

   <Note>
     **Note:** The default label is **Back**.
   </Note>

3. Enter **Redirect URL**
   On clicking this custom button, the user will be redirected to the URL configured above.
4. Select **Show button only on authentication failure page** to display the button only when NFC or Badge authentication fails. (Optional)
5. Click **Save** to apply the changes.

![How to edit Configure tab - screenshot 9](/images/intercom/10800566/image-3e929978.png)

The Tab is successfully configured.
