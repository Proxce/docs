**Introduction**

The Badge credential feature in the Tenant Admin Portal allows admin to enable badge for the WebKey application. Once enabled, Users can authenticate to the Webkey application by scanning their badge.

**Steps to configure Badge ID credential:**

1. Log in to the **Tenant Admin Portal**. For more details, refer [How to log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).
2. On the **Applications** page, select the Webkey application to edit.
   ![How to configure Badge ID credential... - screenshot 1](/images/intercom/11494069/image-d74a8c32.png)
   The application page is displayed.
   ![How to configure Badge ID credential... - screenshot 2](/images/intercom/11494069/image-8d7449fb.png)
3. Go to **Authenticator** tab**.**
4. Turn on **Badge ID** toggle.
   ![How to configure Badge ID credential... - screenshot 3](/images/intercom/11494069/8aa2840c-0d14-44e9-8277-11c6046e72c8-88ac8639.png)
5. Select a **RFID Badge Type** from the dropdown list.
6. Click **Save**.
   ![How to configure Badge ID credential... - screenshot 4](/images/intercom/11494069/b9f3f074-4f3a-4cac-a120-04a197056655-d13ca447.png)
   Badge authenticator for WebKey application is configured successfully.
   ![How to configure Badge ID credential... - screenshot 5](/images/intercom/11494069/image-270d29b4.png)
