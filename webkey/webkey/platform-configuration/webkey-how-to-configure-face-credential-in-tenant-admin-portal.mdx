## Introduction

The Face credential feature in the Tenant Admin Portal allows admin to enable face recognition for the Web Key application. Once enabled, users can log in to Web Key application through face recognition.

## Prerequisites

- You must have a Tenant Admin Account.
- The **Webkey application** must be created and configured in the Tenant Admin Portal. For more, refer to[How to create and configure WebKey Application in Tenant Admin Portal](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application-in-tenant-admin-portal)

## Steps to configure face credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit.
   ![How to configure Face credential in... - screenshot 1](/images/intercom/11493834/image-d74a8c32.png)
   The application page is displayed.
   ![How to configure Face credential in... - screenshot 2](/images/intercom/11493834/image-8d7449fb.png)
3. Go to **Authenticator tab** > Turn on **Face** toggle.
   ![How to configure Face credential in... - screenshot 3](/images/intercom/11493834/bbb85156-9125-40e3-80fa-f3453b9e3f71-a30be9d8.png)
   The **Advanced Settings** page is displayed.
   ![How to configure Face credential in... - screenshot 4](/images/intercom/11493834/51a50c15-e5b8-4f86-b8a0-256876d1e537-d1b5df6d.png)
4. Enable **Take Re-consent During Transactions** toggle to to display the re-consent form to users with invalid consent during every face authentication attempt until they successfully re-sign.
   ![How to configure Face credential in... - screenshot 5](/images/intercom/11493834/08a045b1-20c7-49ce-a198-e4769b686100-a600420c.png)
5. Configure **Face Match Parameters**.
   ![How to configure Face credential in... - screenshot 6](/images/intercom/11493834/8da7fc74-c8a3-4a12-b56f-4c68ebc9d633-4d0d969a.png)
   1. Adjust the **Face Match Threshold** slider or enter a value directly into the input box to set the face match threshold value.
      ![How to configure Face credential in... - screenshot 7](/images/intercom/11493834/b4ccdefe-ad5e-4772-9e8d-6b1a0f118131-ee65b6db.png)
   2. **Enable Virtual Camera** toggle to to allow third-party virtual camera app to be used for face capture. If a user attempts to spoof the system using a third-party app, this feature helps detect and flag potential spoofing attempts.
      ![How to configure Face credential in... - screenshot 8](/images/intercom/11493834/32a7d6a5-09d8-4e06-a9eb-e1d1de66f814-2883f870.png)
6. Configure **Liveness Check Parameters**.
   - **Min Liveness Probability**: Specifies the threshold used to determine whether an image is live or spoofed.
     - **Default value:** 0.5
     - Images with a liveness probability of **0.5 or higher** are classified as live.
   - **Min Liveness Quality**: Specifies the minimum quality required for an image to be suitable for a liveness check..
     - Default: 0.1
     - Images with a quality score of **0.1 or higher** are considered suitable for liveness verification.
       ![How to configure Face credential in... - screenshot 9](/images/intercom/11493834/c1879efd-a46e-4b06-a30d-901ef64b8749-24160284.png)
7. **Enable Manual Capture Accessibility** toggle to allow users manually capture their face during the face recognition process.
   1. Select **Disable Auto-capture** to disable automatic face capture. When enabled, users must manually capture their face using:
      - **Enter** or **Space bar** on desktops and laptops.
      - **Tap anywhere** on the screen for mobile and tablet devices.
        ![How to configure Face credential in... - screenshot 10](/images/intercom/11493834/cbfdcc0c-f8a9-41d6-bc33-05608deb21cb-3a69be87.png)
8. **Enable Timed Auto-Capture** to allow the system to automatically capture the user's face if it is not captured within a set time.
   - Set the **Time-out Duration** in seconds.
   - After the timer ends, the system captures the face automatically, even without user action.
     ![How to configure Face credential in... - screenshot 11](/images/intercom/11493834/e6ec0a7e-7a2e-4ab2-8495-3e300d813fb9-ec6003d6.png)
9. **Configure Image Capture Resolution.**
   - **Select Capture Resolution** from the **Select Resolution** dropdown list.
   - **Low: 640×480:** Lower quality image.
   - **Medium: 1280×720:** Balanced quality.
   - **High: 1920×1080:** High-quality image, Best clarity.
     ![How to configure Face credential in... - screenshot 12](/images/intercom/11493834/6c601886-1feb-45a2-ae6f-2e52c62348c1-f3ca8371.png)
10. Enable **Adjust Video Preview Container Spacing From Top** toggle to move the face capture preview upward for better alignment with the camera. (e.g. Chromebook )
11. Click **Save**.
    ![How to configure Face credential in... - screenshot 13](/images/intercom/11493834/df2e78b4-85fc-49af-89b2-08877c93f027-f4bc5f44.png)
    The Face recognition for Webkey application is configured successfully.
    ![How to configure Face credential in... - screenshot 14](/images/intercom/11493834/image-24db95ab.png)
