**Pre-requisite:**

You must create a Passwordless application of type WebKey. For further details, refer [How to create a WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application).

## Steps to configure Custom User Agent

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Webkey application to edit.
   ![Webkey – How to Configure a Custom User... - screenshot 1](/images/intercom/11659241/image-d74a8c32.png)
   The application page is displayed.
   ![Webkey – How to Configure a Custom User... - screenshot 2](/images/intercom/11659241/image-8d7449fb.png)
3. Go to **Configure tab** > **Settings** > **Browser Settings**.
   ![Webkey – How to Configure a Custom User... - screenshot 3](/images/intercom/11659241/6c5d9891-8da3-489c-bf27-3115f266a73a-e3a7dd1f.png)
4. Enable **Custom User Agent** to allow users to log in to WebKey app from custom browsers.
5. Enter the custom browser’s user agent name in **Type user agent header** field.
6. Click **Save**.

   <Note>
     **Note:** Agent browser should be configured for User agent. Reach out to [Oloid Support](mailto:support@oloid.ai) for details.
   </Note>

   ![Webkey – How to Configure a Custom User... - screenshot 4](/images/intercom/11659241/dda7beba-3114-43ab-8aac-560b2d05efc5-2c567cc0.png)
7. Click **Add Device**.
   ![Webkey – How to Configure a Custom User... - screenshot 5](/images/intercom/11659241/e5c5db66-9d6c-433a-8c0e-1fbb2ec43637-8be60ecb.png)
   The **Upload File to Add Device** Pop up box is displayed.
   ![Webkey – How to Configure a Custom User... - screenshot 6](/images/intercom/11659241/image-5c21ff44.png)
8. Do the following:
   1. [Bulk upload the devices](#bulk-upload-the-devices)
   2. [Add individual devices](#add-individual-devices)
      The Custom User Agent is configured for the added devices.

## Bulk upload the devices.

1. Drag and drop the **.XLSX** or **.CSV** file to bulk upload the devices.

   <Note>
     **Note:** You can download the templates by clicking on the respective download links.
   </Note>

   ![Webkey – How to Configure a Custom User... - screenshot 7](/images/intercom/11659241/19070500-47ce-4178-b6eb-a4fec7648289-92a1b624.png)
   The XLSX or CSV template file is downloaded to your system.
2. Prepare the XLSX or CSV template file for upload.

   <Note>
     **Note:** To prepare the user upload template, refer [How to prepare User Upload Template](https://oloid.help/en/articles/10650742-how-to-prepare-user-upload-template).
   </Note>

3. Drag and drop the file or click on the **Import .XLSX** or **.CSV file** area to upload your prepared XLSX or CSV file.
   ![Webkey – How to Configure a Custom User... - screenshot 8](/images/intercom/11659241/0c9d3679-b398-4cc8-b8ac-329669ae0621-bf226aba.png)
4. Select **Upload File**.
   ![Webkey – How to Configure a Custom User... - screenshot 9](/images/intercom/11659241/image-28b31139.png)

The file is uploaded in the **Upload** section.

## Add individual devices

1. Enter **Device ID (Kiosk/Terminal ID)**.
2. Enter **Mac Address**.
3. Click **Add**.
   ![Webkey – How to Configure a Custom User... - screenshot 10](/images/intercom/11659241/50be1912-58fe-4cee-95a1-be85c90abd3a-05d4f455.png)
   The device is added successfully in the list with their Device ID and MAC Address. You can update deviceinformation or remove the device:
   - **Edit Device information** – Select the pencil icon to update the device information.
   - **Remove Device** – Select the trash icon to remove the device from the list.
     ![Webkey – How to Configure a Custom User... - screenshot 11](/images/intercom/11659241/2740a74b-dba5-48f2-850c-c4caa0ac000d-af31b34d.png)
