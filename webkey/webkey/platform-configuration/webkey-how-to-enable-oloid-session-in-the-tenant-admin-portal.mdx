## Introduction

Oloid Session uses the existing Oloid authentication session to securely pass the user's credential to the next step in the workflow. When enabled, the user will be seamlessly authenticated using their active Oloid session token, without needing to re-authenticate.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure **Enable Auto Authentication of Webkey using Local Transaction** is enabled. Refer: [How to Enable Auto Authentication using Windows Oloid Session](https://oloid.help/en/articles/10800566-webkey-how-to-edit-configure-tab#:~:text=Turn%20on%20Enable%20Auto%2DAuthentication%20using%20Windows%20Oloid%20Session%20toggle).
- Enable Auto authentication using Local transaction for Windows Login. Refer: [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal#h_26561b72fa:~:text=Enable%20Auto%20Authentication%20of%20Webkey%20using%20Local%20Transaction%20toggle)

## Steps to Enable Oloid Session

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit.
   ![How to Enable Oloid Session in the... - screenshot 1](/images/intercom/15420148/image-d74a8c32.png)
   The application page is displayed.
   ![How to Enable Oloid Session in the... - screenshot 2](/images/intercom/15420148/image-eba385e4.png)
3. Go to **Authenticator tab.**
   ![How to Enable Oloid Session in the... - screenshot 3](/images/intercom/15420148/image-c1b74334.png)
   The Authenticator page is displayed.
4. Do the following:
   1. Turn on **Oloid Session** toggle.
   2. Set the **Session Time-out** duration.
      **Session Time-out** duration specifies how long users can continue to access the device without re-authenticating after an Oloid sign-in.
   3. Click **Save.**

![How to Enable Oloid Session in the... - screenshot 4](/images/intercom/15420148/image-d64e5ebf.png)

Oloid Session is successfully enabled.
