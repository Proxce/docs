## Introduction

Enabling a Custom User Agent allows the tenant admin to register new devices directly from user transactions.

## Prerequisite

- You must have a tenant admin account.
- Custom User agent must be enabled.
  Devices can also be added to Webkey application from Oloid portal. For further information please refer: [How to configure Custom User Agent in WebKey Application](https://oloid.help/en/articles/11659241-how-to-configure-custom-user-agent-in-webkey-application)

## Steps to Add Device to Application

1. Log in to the **Tenant Admin Portal**.
2. Click **Transactions** from the left menu panel.
   ![How to Add a Device from Failed... - screenshot 1](/images/intercom/13175211/image-4fb3c141.png)
   The **User Transaction Through Your Device** page is displayed.
3. Selectthe latest transactionto edit.

   <Note>
     **Note:** Device can only be added from failed transaction.
   </Note>

   ![How to Add a Device from Failed... - screenshot 2](/images/intercom/13175211/image-b1d3e8a8.png)
4. On the top right, select **Action** > **Add Device to Application**.
   ![How to Add a Device from Failed... - screenshot 3](/images/intercom/13175211/image-5573482d.png)
5. On the Confirm Device Registration pop-up box, select **Confirm**.

   <Note>
     **Note:** Registering will link the device to the application using its User Agent or Device ID
   </Note>

   ![How to Add a Device from Failed... - screenshot 4](/images/intercom/13175211/image-d5cbad67.png)

The device is successfully added to the WebKey application.

![How to Add a Device from Failed... - screenshot 5](/images/intercom/13175211/image-f38fc66e.png)
