Tenant Admin/Supervisor can detect spoofing attempts in WebKey application by checking if a user has logged in using a virtual camera instead of a real face scan.

**Pre-requisite:**

You must turn on **Enable Virtual Camera** in Webkey application. For more information, refer [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application) > [Enable Virtual Camera](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_6150176796:~:text=Enable%20Virtual%20Camera)

To identify spoofing:

1. Log in to **Oloid Portal**.
2. Go to **Transactions** in the left menu panel.
   ![Webkey – How to Identify Spoofing in... - screenshot 1](/images/intercom/10469404/5c93b8e8-78ff-4645-949e-860eddfc53c5-5dec0d57.png)
   The User Transaction page is displayed.
3. Select the login transaction.
   ![Webkey – How to Identify Spoofing in... - screenshot 2](/images/intercom/10469404/910ad39e-49ce-4969-a164-f8903fbb03fe-f8eaca65.png)
4. Go to **Details** tab, check **Virtual Camera** status.
   ![Webkey – How to Identify Spoofing in... - screenshot 3](/images/intercom/10469404/c6a64fdd-b98f-4427-b4de-7543ada85215-e6f1a4fd.png)
   If Virtual Camera is **True**, the user has used a spoofing method to log in.
