This is based on client requirement. **Oloid's WebKey** functions with a single factor (like Face, Badge, QR Code, NFC tags, and PIN) or a combination of factors ( **Face + PIN**, **Badge +PIN** and **NFC +PIN**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](https://oloid.help/en/articles/8413861-face-onboarding) guide.
- Create Badges for users. Refer [Badge Onboarding](https://oloid.help/en/articles/8402155-badge-onboarding) guide.
- Create NFC and assign to users. Refer [NFC Onboarding](https://oloid.help/en/articles/8600311-nfc-onboarding) guide.
- Add PIN and send to users. Refer [Pin Onboarding](https://oloid.help/en/articles/8408444-pin-onboarding) guide.
- Create QR Code and send to user. Refer [QR Code Onboarding](https://oloid.help/en/articles/8408452-qr-onboarding) guide.
