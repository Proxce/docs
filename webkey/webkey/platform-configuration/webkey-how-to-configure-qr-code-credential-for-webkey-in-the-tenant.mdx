**Introduction**

The QR Code credential feature in the Tenant Admin Portal allows admin to enable QR code-based multi-factor authentication (MFA) for the WebKey application. Once enabled, Users can authenticate to the Webkey application by scanning a QR code.

## Steps to configure QR Code credential

1. Log in to the **Tenant Admin Portal**. For more details, refer [How to log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).
2. On the **Applications** page, select the Webkey application to edit.
   ![How to configure QR Code credential for... - screenshot 1](/images/intercom/11494129/image-d74a8c32.png)
   The application page is displayed.
   ![How to configure QR Code credential for... - screenshot 2](/images/intercom/11494129/image-8b23fee5.png)
3. Go to **Authenticator tab.**
4. Turn on **QR Code** toggle.
   ![How to configure QR Code credential for... - screenshot 3](/images/intercom/11494129/2d59b0f6-cd62-47c2-853f-5802a06b923d-f8bb0315.png)
5. Enable **Show Camera Flip button** to allow users to switch between the front and rear cameras.
   This option displays a camera flip button on the preview screen during QR code scanning.
   Under **Default camera selection**, select a camera option:
   - **Back Camera**
   - **Front Camera**

     <Note>
       **Note:** This feature is available only for iOS devices and Android devices.
     </Note>

6. Click **Save.**
   ![How to configure QR Code credential for... - screenshot 4](/images/intercom/11494129/73e269fe-6cd9-4ac1-8ffd-cc43f75927b3-642ce53c.png)
   QR Code authenticator for Webkey application is configured successfully.
   ![How to configure QR Code credential for... - screenshot 5](/images/intercom/11494129/image-8dbd72ce.png)
