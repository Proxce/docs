For Oloid's WebKey to function, it needs to be configured in the Oloid Platform.

## Initial set up

### Step 1: Set up IDP Profile

1. Create IDP Profile for OIDC-Okta. Refer to [How to create IDP Profile for OIDC-Okta](https://oloid.help/en/articles/9214537-how-to-create-idp-profile-for-oidc-okta) guide.
2. Configure OIDC-Okta IDP Profile. Refer to [How to configure OIDC - Okta IDP Profile](https://oloid.help/en/articles/9215949-how-to-configure-oidc-okta-idp-profile)

### Step 2: Set up Application and Connection

1. Create and Configure WebKey Application. Refer to [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)
2. Create Connections. Refer to [How to create Connections](https://oloid.help/en/articles/8294297-how-to-create-connection)

### Step 3: Map Connections to Applications.

Once both Application and Connection are created, you need to map the Connection to the Application.

Refer to [How to Map Connection to Application](https://oloid.help/en/articles/8304594-how-to-map-connection-to-application)

### Step 4: Create user and assign user to connection.

Create users and assign users to connections in Oloid Portal. Refer to [User Onboarding](https://oloid.help/en/articles/8463554-user-onboarding) guide.

### Step 5: Enable Authenticator factors

Based on the requirement , enable authenticator factors in the tenant application. Refer to [How to create and configure WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application) > [Configure Authenticator tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_6e2751be8f)
