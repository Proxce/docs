## Introduction

The **Theme** tab allows Tenant Admin to customize the appearance and branding of the WebKey application. Administrators can configure logos, colors, background images, welcome screen branding, language settings, Help URL, and user-facing messages to provide a consistent authentication experience that aligns with their organization's branding.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- You must create a WebKey application. For more details, refer [How to create a WebKey application](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application)

## Steps to edit Theme Tab

1. Log in to the **Tenant Admin Portal**. For more details, refer [How to log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).
2. On the **Applications** page, click on the Webkey application to edit.
   ![How to Configure Theme tab for Webkey... - screenshot 1](/images/intercom/10800135/image-d74a8c32.png)
   The application page is displayed.
   ![How to Configure Theme tab for Webkey... - screenshot 2](/images/intercom/10800135/image-973f44cd.png)
3. Go to **Theme** tab.
   ![How to Configure Theme tab for Webkey... - screenshot 3](/images/intercom/10800135/image-f3e58afc.png)
   The **Theme** page is displayed.
4. Do the following.
   [Edit theme](#edit-theme)
   [Edit Welcome Screen Image](#edit-welcome-screen-image)
   [Edit Language Support](#edit-language-support)
   [Enable Help URL](#enable-help-url)
   [Configure Messages](#configure-messages)

Click **Deploy Changes** to save the configurations.

#### Edit theme

1. Edit Customer logo.

   <Note>
     **Note:** The maximum file dimensions for the logo are **264x72 px**, with a maximum size of **1 MB** in **PNG** format.
   </Note>

   ![How to Configure Theme tab for Webkey... - screenshot 4](/images/intercom/10800135/image-5ef153f0.png)
2. **Background Image:** Do one of the following:
   1. Edit Background image.

      <Note>
        **Note:** The maximum file size is **2 MB** (JPG, PNG, JPEG). This image is used as the widget background.
      </Note>

      or
   2. Select **Solid Background** option > enter color code.
      ![How to Configure Theme tab for Webkey... - screenshot 5](/images/intercom/10800135/image-758b5aec.png)
3. **Primary Color/Button Default:** Update the primary color code to define the primary button's default background and its hover-state text color.
4. **Secondary Color/Hover State:** Update the secondary color code to define the primary button's hover background and its default text color.
5. **Widget Header/Footer Color:** Update the background color for the Widget's header and footer.
6. **Footer Text Color:** Update the footer text color code in Login App.
   ![How to Configure Theme tab for Webkey... - screenshot 6](/images/intercom/10800135/image-7d04b2d6.png)
1. (Optional) In the **Preview** section, select one of the following tabs to preview the theme configuration:
   1. **Identity Selection:** Preview the appearance of the identity selection screen displayed before user authentication.
   2. **Authentication:** Preview the authentication screen displayed when users authenticate using their configured credentials.
   3. **Error:** Preview how error messages and error screens are displayed to users during authentication failures.

#### Edit Welcome Screen Image

1. Edit **Welcome screen image.**
   Use this setting to customize the image displayed on the app’s welcome screen.
   - **Default**
     - Select this option to use the system-provided default image.
   - **Custom Image/App Logo**
     - Select this option to upload your own image or app logo.
     - Click or drag an image into the upload area.
     - Supported file types: SVG or PNG
     - Maximum dimensions: 436 x 165 pixels
     - Maximum file size: 2 MB
       ![How to Configure Theme tab for Webkey... - screenshot 7](/images/intercom/10800135/e2b6cb9f-bf11-462d-acb5-f913e87bd121-bb2f8cf9.png)

#### Edit Language Support

1. Select **Default App Language** from the dropdown.
2. Select the **Use Browser Language as Display Language** checkbox.
   If Browser language is not supported, UI will be displayed in the default language
3. Select the **Allow Language Selection on Login Page** checkbox.
   Language dropdown will be available only on the Login screen if checkbox is selected.
   ![How to Configure Theme tab for Webkey... - screenshot 8](/images/intercom/10800135/image-0e95f4cc.png)

#### Enable** **Help URL

1. Select **Enable Help URL** checkbox to enable the Help URL feature.
2. Enter a valid URL in the text box. This URL will be displayed as a clickable **Help** link on the login page.

   <Note>
     **Note:** users can click the Help link on the login screen to open the specified URL in a browser. Use this link to direct users to support documentation, system requirements, or troubleshooting instructions.
   </Note>

![How to Configure Theme tab for Webkey... - screenshot 9](/images/intercom/10800135/57f4e61b-430b-4166-ae99-bffd950041a6-bcfafffd.png)

#### Configure Messages

1. Turn on the **Enable Face Capture Instruction** toggle.
   Enable this toggle to displays instructions to the user during face authentication.
2. Enable the **Customize Face Authentication Failure Message** toggle.
   Enable this toggle to show a fixed error message instead, regardless of error reason.
3. Click **Deploy Changes**.
   ![How to Configure Theme tab for Webkey... - screenshot 10](/images/intercom/10800135/image-4d9044ca.png)
   The **Confirm Update** pop-up box is displayed.
4. Click **Update**.

![How to Configure Theme tab for Webkey... - screenshot 11](/images/intercom/10800135/image-0daad6a3.png)

The Theme tab for Webkey is configured.

![How to Configure Theme tab for Webkey... - screenshot 12](/images/intercom/10800135/image-b81f6363.png)

The theme customization is set for Webkey Application successfully. You can see the changes in the preview screen
