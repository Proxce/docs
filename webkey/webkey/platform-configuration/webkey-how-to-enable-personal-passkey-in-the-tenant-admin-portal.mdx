## Introduction

Personal Passkey enables users to authenticate to supported Webkey applications using a passkey associated with their individual account.

## Prerequisite

- You must have access to Tenant Admin account.
- Personal Passkey must be enabled in the Tenant Admin portal. Refer: [How to Enable Passkey SSO in Tenant Admin Portal](https://oloid.help/en/articles/13856829-how-to-enable-passkey-sso-in-tenant-admin-portal)
- Ensure Personal Passkey is created for the user. Refer: [How to Generate Personal Passkey in the Tenant Admin Portal](https://oloid.help/en/articles/13856872-how-to-generate-personal-passkey-in-the-tenant-admin-portal)

## Steps to Enable Personal Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Webkey application to edit.
   ![How to Enable Personal Passkey in the... - screenshot 1](/images/intercom/15733222/image-d74a8c32.png)
   The application page is displayed.
   ![How to Enable Personal Passkey in the... - screenshot 2](/images/intercom/15733222/image-eba385e4.png)
3. Go to **Authenticator tab.**
   ![How to Enable Personal Passkey in the... - screenshot 3](/images/intercom/15733222/image-552831b2.png)
   The Authenticator page is displayed.
4. Turn on **Personal Passkey** toggle.

![How to Enable Personal Passkey in the... - screenshot 4](/images/intercom/15733222/image-828f6c67.png)

Personal Passkey is successfully Enabled.
