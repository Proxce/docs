## Introduction

The Auto-Pair configuration file simplifies the process of pairing endpoints with a WebKey application without requiring manual user intervention. It allows admins to securely connect endpoints using predefined configuration settings, enabling faster and more consistent deployments.

## Prerequisites

- You must have a Tenant Admin Account.
- Ensure that the Webkey application is created. For more information, refer: [How to create and configure WebKey Application in Tenant Admin Portal](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application-in-tenant-admin-portal)

## Steps to generate auto-pair config file

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to generate Auto-Pair config file... - screenshot 1](/images/intercom/15220838/image-8fbbb0fd.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to generate Auto-Pair config file... - screenshot 2](/images/intercom/15220838/image-960d81c6.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > **API Token** > **API Key**.
   ![How to generate Auto-Pair config file... - screenshot 3](/images/intercom/15220838/45633202-6454-4d3a-9836-b22ac299a1b2-fe15e691.png)
5. In the **Generate Temporary Access Token** section, do the following:
   1. In the **Generate Temporary Access Token** section, select the **Start Date/Time** field.
      - To set the start date and time, click the date picker or select **Now**.
   2. Select the **End Date/Time** field.
      - Click the date picker, choose when the token will expire, and then click **OK**.
   3. Specify **Number of Endpoints** that can be created using the endpoint. (Optional)
   4. Click **Generate**.
      ![How to generate Auto-Pair config file... - screenshot 4](/images/intercom/15220838/b700b191-2b42-4aa7-9bfe-0d5c41b866f3-0401d10e.png)
      The auto-pair config file is generated.
6. Click **Auto-pair config file**.
   ![How to generate Auto-Pair config file... - screenshot 5](/images/intercom/15220838/ca6e65c5-4747-4b0a-89f6-2f2f2e20d16e-c6095aa9.png)
   The Auto-pair config file pop-up box is displayed.
7. Do the following:
   1. Select **Application** as **Passwordless - Webkey** from **Application Type** dropdown list.
   2. From the **Select Application** drop-down list, select the application that you want the endpoints to pair with.

      <Note>
        **Note:** Select **Skip user confirmation for pairing** option to auto-pair endpoints without requiring user confirmation.
      </Note>

   3. Click **Copy Config Text.** (optional)

      <Note>
        **Note:** This button will copy (to clipboard) the config file JSON or TEXT as a single line string.
      </Note>

   4. Click **Download**.
      ![How to generate Auto-Pair config file... - screenshot 6](/images/intercom/15220838/image-425a29ba.png)
      The Autopair Config file is downloaded to the local device.
