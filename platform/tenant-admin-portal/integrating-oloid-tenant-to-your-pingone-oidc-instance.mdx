**Introduction**

This document provides step-by-step instructions on how Oloid's WebKey application integrates with PingOne as an external OpenID Connect (OIDC) Identity Provider (IdP).

1. Sign in to the Ping Identity Administrator Console with your PingOne account credentials
2. Select **Create Environment**, then select **Create a Customer Solution**.

   ![Select Create Environment, then select Create a Customer Solution.](/images/intercom/10796370/image-26f01078.png)

   ![Select Create Environment, then select Create a Customer Solution. (2)](/images/intercom/10796370/image-7cf8bf37.png)

3. Go to the newly created environment and select **Manage Environment**.

   ![Go to the newly created environment and select Manage Environment.](/images/intercom/10796370/4c4ba1e5-eb54-450f-9107-ed1724bdca3f-af92483c.png)

4. On the left menu panel, select **Integrations > External IdPs**.

   ![On the left menu panel, select Integrations &gt; External IdPs.](/images/intercom/10796370/8a5158f9-2f6b-461d-9fff-7da75f002bd4-0c2c21af.png)

   The Identity Providers page is displayed.
5. Select **+Add Provider**.

   ![Select +Add Provider.](/images/intercom/10796370/52b58014-749a-4425-91ec-12c322fc2b6f-6a60eaeb.png)

6. Select **OpenID Connect** under Custom.

   ![Select OpenID Connect under Custom.](/images/intercom/10796370/2c519bd8-55a7-4735-b222-68e4dbff12d6-03da13d3.png)

7. Do the following:
   1. Enter a unique name for the Identity Provider profile in the **NAME** field.
   2. Enter a description to help identify the purpose of this profile in the **DESCRIPTION** field.
   3. Click **Continue**.

      ![Click Continue.](/images/intercom/10796370/cc7c2e23-912f-45b2-99d9-f13dfa8a1cdf-19f7dffd.png)

      The Configure OpenID Connect Connection section is displayed.
   4. Enter **ClientID** and **Client Secret** provided by Oloid Admin.

      ![Enter ClientID and Client Secret provided by Oloid Admin.](/images/intercom/10796370/d00bdbdc-da34-41a0-9824-a22ab164194f-a0fffb89.png)

   5. Enter **OpenID Configuration Endpoint** from Oloid Tenant Admin Portal in the **Discovery Document URI** field.

      <Note>
        **Note:** To find the **OpenID Configuration Endpoint** in the Oloid Tenant Admin Portal, go to **Auth Policies** > **Identity Provider** > select **IDP Profile** > **Meta Data** tab > **OpenID Configuration Endpoint**.
      </Note>

      ![Enter OpenID Configuration Endpoint from Oloid Tenant Admin Portal in the Discovery Document URI field.](/images/intercom/10796370/d5512f46-f368-4ee2-8b66-18d5bc27be0d-ea4a75c0.png)

      ![Enter OpenID Configuration Endpoint from Oloid Tenant Admin Portal in the Discovery Document URI field. (2)](/images/intercom/10796370/b087c1e3-2a4c-46f9-8555-f40ca827477f-db57caab.png)

   6. Next, select **Use Discovery Document**.
      This auto-fills the remaining endpoints.

      ![This auto-fills the remaining endpoints.](/images/intercom/10796370/1ce1f7c5-036b-4648-baf9-00d6c5f29e78-ce8956b7.png)

   7. Select **Client Secret Basic** as **TOKEN ENDPOINT AUTHENTICATION METHOD**.

      ![Select Client Secret Basic as TOKEN ENDPOINT AUTHENTICATION METHOD.](/images/intercom/10796370/image-df809ed5.png)

   8. Click **Save and Continue**.

      ![Click Save and Continue.](/images/intercom/10796370/78eb6cd7-12b8-40c3-a3ec-f01aa26d9427-e4afe936.png)

      The Map Attributes section is displayed.
   9. Click **+ADD ATTRIBUTE**.

      ![Click +ADD ATTRIBUTE.](/images/intercom/10796370/b92c083a-e7cb-4259-923b-6c974e61a68c-9208e91d.png)

   10. Select **Email Address** from **PINGONE USER PROFILE ATTRIBUTE** dropdown list.

       ![Select Email Address from PINGONE USER PROFILE ATTRIBUTE dropdown list.](/images/intercom/10796370/image-6ca072d4.png)

   11. Set **providerAttributes.Email** in **OIDC ATTRIBUTE** field.

       ![Set providerAttributes.Email in OIDC ATTRIBUTE field.](/images/intercom/10796370/91efed97-dde6-4198-bcd0-0397c8fff6cf-99d0cee4.png)

   12. Select **Empty Only** from **UPDATE CONDITION** dropdown list.

       ![Select Empty Only from UPDATE CONDITION dropdown list.](/images/intercom/10796370/f929c124-b7ac-41d5-84f5-407a2a29d180-81f1dc1b.png)

   13. Select **Save and Finish**.

       ![Select Save and Finish.](/images/intercom/10796370/78748a6d-cbf4-4674-9695-82cd3aa5ca27-791b5992.png)

8. Enable the newly created IDP from the External IdPs list.

   ![Enable the newly created IDP from the External IdPs list.](/images/intercom/10796370/eb0dda5a-3a0a-4c28-bf31-4664794d4651-95977573.png)

9. Go to the **Connection** tab, copy the **CALLBACK URL,** and paste it in the Oloid Tenant Admin Portal in **Callback URL** field.

   <Note>
     **Note:** To find the **Callback URL** field in the Oloid Tenant Admin Portal, go to **Auth Policies** > **Identity Provider** > select **IDP Profile** > **IDP Settings** tab > **Callback URL**.
   </Note>

   ![Go to the Connection tab, copy the CALLBACK URL, and paste it in the Oloid Tenant Admin Portal in Callback](/images/intercom/10796370/94647849-25ad-4e3f-aabe-cafce7f496e2-b83cffe4.png)

   ![Go to the Connection tab, copy the CALLBACK URL, and paste it in the Oloid Tenant Admin Portal in Callback (2)](/images/intercom/10796370/53056d81-a7a1-42de-a90b-d8c264c7c9c1-cc0dc7f4.png)

10. Update the Authentication Policies to use the new IDP.
    1. On the left navigation menu panel, go to **Authentication** > **Policies** > **Authentication**.

       ![On the left navigation menu panel, go to Authentication &gt; Policies &gt; Authentication.](/images/intercom/10796370/c1268022-6ae3-4245-91cf-95c43d9d0850-546274cb.png)

       The Authentication Policies page is displayed.
    2. Select **+Add Policy** to create a new authentication policy.

       ![Select +Add Policy to create a new authentication policy.](/images/intercom/10796370/951713c7-dc1e-4174-b9b7-60f37f10b044-1138da61.png)

       The Policy page is displayed.
    3. Enter policy name in the **POLICY NAME** field.
    4. Under **STEP TYPE,** select **External Identity Provider** from dropdown.

       ![Under STEP TYPE, select External Identity Provider from dropdown.](/images/intercom/10796370/192e0ce1-ed0d-49b3-8f0c-562a2a58bf5d-e6348b93.png)

       The EXTERNAL IDENTITY PROVIDER section is displayed.
    5. Select the created external identity provider from the **EXTERNAL IDENTITY PROVIDER** section.

       ![Select the created external identity provider from the EXTERNAL IDENTITY PROVIDER section.](/images/intercom/10796370/fc5804b1-db13-4cca-960a-9b5c4546771f-e34e56ea.png)

    6. Click **Save**.
       The policy is created successfully.

       ![The policy is created successfully.](/images/intercom/10796370/b695622e-abf8-4795-a37b-132479053dde-b159c81a.png)

11. Next, go to the left menu navigation panel and select **Applications** > **Applications**.

    ![Next, go to the left menu navigation panel and select Applications &gt; Applications.](/images/intercom/10796370/3cb60681-58fd-4d90-bee1-7b0cdf967c8a-faccdce6.png)

12. On the Application page, select **PingOne Application Portal** > copy the **Home Page URL**.

    ![On the Application page, select PingOne Application Portal &gt; copy the Home Page URL.](/images/intercom/10796370/ce330d19-03eb-4f79-995a-fa2d92d5420d-b6441a86.png)

    ![On the Application page, select PingOne Application Portal &gt; copy the Home Page URL. (2)](/images/intercom/10796370/e5a6b37c-ef6c-4022-aed7-bd5bdae122ec-a3176b70.png)

13. Select **Applications** from the left menu, and click the Add <img src="https://downloads.intercomcdn.com/i/o/e4gi378c/1510083718/732161c5a054e654bfbc35893bc1/image.png?expires=1795154400&amp;signature=99148c01f4943c4be735750dffb3a2412a5417071d79281ee894133a8e3c2ebf&amp;req=dSUmFsl2noZeUfMW3nq%2BgQY%2Fqnx1C7nwPoF3H3%2BmVDljkeZ4tmhCk710wuOr%0AxlVega0N0ASPs6wSzzOb8Va%2Fjbo%3D%0A" alt="left menu, Add icon" className="oloid-icon" noZoom /> icon to add a new application.

14. Do the following:

       The application is created successfully.
15. Select the newly created application from the application list to edit.

    ![Select the newly created application from the application list to edit.](/images/intercom/10796370/503dd0fb-516c-4d7c-9bfd-9f851c8759aa-8207b61b.png)

16. On the application **Profile** page, enable the app using the toggle button next to the application name.

    ![On the application Profile page, enable the app using the toggle button next to the application name.](/images/intercom/10796370/c44a54c7-6faf-4dac-9f00-3f4dd3063692-2d2a2173.png)

17. Paste the copied URL in the **Configuration tab** > **Redirect URL** field of the created application.

    <Note>
      **Note:** Create an application.
    </Note>

    ![Paste the copied URL in the Configuration tab &gt; Redirect URL field of the created application.](/images/intercom/10796370/bac122bd-a57e-4e92-b4ac-cd17ed9d5441-9170432f.png)

18. In the Oloid Tenant Admin Portal, go to **IDP Settings > Redirect URL** and paste the same Home Page URL in the **Redirect URL** field.

    ![In the Oloid Tenant Admin Portal, go to IDP Settings &gt; Redirect URL and paste the same Home Page URL in the](/images/intercom/10796370/5a1c03ed-272e-48c1-aba5-a96afd467b84-da4d3673.png)

    <Note>
      **Note:** Ensure that the Redirect URL in both PingOne and the Oloid Tenant Admin Portal match exactly to enable successful authentication.
    </Note>

19. Select the created application.
    The application details page is displayed.
20. Go to **Resources** > edit **ALLOWED SCOPES**.

    ![Go to Resources &gt; edit ALLOWED SCOPES.](/images/intercom/10796370/cdcab448-838f-4d5a-b1d7-8077d1a27222-72b98d0d.png)

21. Select **email**, and then click **Save**.

    ![Select email, and then click Save.](/images/intercom/10796370/a1a8ce03-d189-4174-8087-e692fbfde3c4-e05eb30e.png)

22. Then, go to **Access and edit > add groups >** click **Save**.
23. Under **Policies** tab, click **+Add Policies**.

    ![Under Policies tab, click +Add Policies.](/images/intercom/10796370/60ef20fa-f3b3-48e5-8f55-e2355ad8e785-38b2b8e8.png)

24. Select the created policy, then click **Save**.

    ![Select the created policy, then click Save.](/images/intercom/10796370/2ff6e6f5-67fc-4358-8ba8-167a876c5634-18530d39.png)
