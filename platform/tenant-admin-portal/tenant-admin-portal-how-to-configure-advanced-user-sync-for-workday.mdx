## Introduction

This document describes how to configure Advanced User Sync for Workday - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have admin access to the **Tenant Admin Portal**.
- An **Advanced User Sync profile for Workday -Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for Workday -Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.

   ![Go to Agents &gt; Advanced User Sync.](/images/intercom/13569620/image-0b56f77e.png)

   The **Advanced User Sync** page is displayed.
3. Select the preferred Workday Inbound Advanced User Sync.

   ![Select the preferred Workday Inbound Advanced User Sync.](/images/intercom/13569620/image-100ec660.png)

   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
   5. [Task Run Logs](#task-run-logs)
5. Click **Activate**.

   ![Click Activate.](/images/intercom/13569620/image-a4632efa.png)

   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.

   ![Click Confirm.](/images/intercom/13569620/image-8decfbf2.png)

   The Advanced User Sync is configured and activated successfully.

   ![The Advanced User Sync is configured and activated successfully.](/images/intercom/13569620/image-9a7c141c.png)

7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![(Optional) Go to Action &gt; User Sync.](/images/intercom/13569620/image-7cde15cf.png)

   The **Sync Now?** pop-up box is displayed.
8. Click **Confirm**.

   ![Click Confirm. (2)](/images/intercom/13569620/image-b566e6b5.png)

   The **Success** pop-up box is displayed.

   ![The Success pop-up box is displayed.](/images/intercom/13569620/image-28c1dcf8.png)

   The Advanced User Sync for Workday - Inbound is configured successfully.

   ![The Advanced User Sync for Workday - Inbound is configured successfully.](/images/intercom/13569620/image-b9fc6c54.png)

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (if required).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.

   ![Click Save.](/images/intercom/13569620/image-5fae6dfc.png)

   The Details tab is configured successfully.

### Setup Configuration Tab

This tab is used to map user data from **Workday** to **Oloid** and select the Oloid connection where users are added during the inbound user sync.

Do the following:

1. Select the data mapper table from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. On **Add Users to Selected Connection**, do one of the following:
   1. Select the **Connection** option, and then select the required **Connection** from the drop-down list.
      **Note: (Optional)** Select **Group** from the Groups drop-down to add users only to the selected groups.
      OR
   2. Select the **Data Filter Table** option, and then select the required **Data Filter Table** from the drop-down list.

      <Note>
        **Note:** Click **View Tables** to review or create a data filter table, if required.
      </Note>

3. Under **Update User**, select **Sync photos from Workday and add as Face credential**. If selected, user photos are also synced from Workday.
4. Click **Save**.

   ![Click Save. (2)](/images/intercom/13569620/9d8e5cca-941f-46c7-9019-346e25b6444f-27ec5d23.png)

   A **Confirm Update** pop-up box is displayed.
5. Click **Confirm**.

   ![Click Confirm. (3)](/images/intercom/13569620/image-30d117a2.png)

   The Configuration tab is configured successfully.

   ![The Configuration tab is configured successfully.](/images/intercom/13569620/image-a91bf240.png)

### Configure Account Tab

This tab is used to add and configure the **Workday** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**.

   ![Enter Account Name.](/images/intercom/13569620/image-7e67c08b.png)

2. Enter **Token Endpoint**.

   ![Enter Token Endpoint.](/images/intercom/13569620/image-9f6e98e8.png)

3. Enter **Workday REST API Endpoint**.

   ![Enter Workday REST API Endpoint.](/images/intercom/13569620/image-092d42a8.png)

   <Note>
     **Note:** You can see the **Token Endpoint** and **Workday REST API Endpoint** on **View API Clients** for Integrations page in the Workday HRIS admin console. To know more, click **[here](/more/workflow/connecting-workday-hris-with-oloid-cloud-platform)**.
   </Note>

   ![Enter Workday REST API Endpoint. (2)](/images/intercom/13569620/image-45d398fb.png)

4. Enter **WQL Query**.

   ![Enter WQL Query.](/images/intercom/13569620/image-9303396c.png)

   <Note>
     **Note:** You can see the **WQL Query** on **Convert Report to WQL** in the Workday HRIS admin console. To know more, click **[here](/more/workflow/connecting-workday-hris-with-oloid-cloud-platform)**.
   </Note>

   ![Enter WQL Query. (2)](/images/intercom/13569620/image-cbf4ca6a.png)

5. Enter **Client ID**.

   ![Enter Client ID.](/images/intercom/13569620/image-e8c3c41b.png)

6. Enter **Client Secret**.

   ![Enter Client Secret.](/images/intercom/13569620/image-ad13eb7e.png)

   <Note>
     **Note:** You can see the **client ID and client Secret** on Register API Client for Integrations page in the Workday HRIS admin console. To know more, click **[here](/more/workflow/connecting-workday-hris-with-oloid-cloud-platform)**.
   </Note>

   ![Enter Client Secret. (2)](/images/intercom/13569620/ffaa9331-9357-464c-9ed3-0364bd2c89dc-97ce0bb9.png)

7. Enter **Workday Tenant Name**.

   ![Enter Workday Tenant Name.](/images/intercom/13569620/image-cc5e5684.png)

   <Note>
     **Note:** You can see the **Workday Tenant Name** on **View API Clients** for Integrations page in the Workday HRIS admin console. To know more, click **[here](/more/workflow/connecting-workday-hris-with-oloid-cloud-platform)**.
   </Note>

   ![Enter Workday Tenant Name. (2)](/images/intercom/13569620/image-1faf8be0.png)

8. Enter **Refresh Token**.

   ![Enter Refresh Token.](/images/intercom/13569620/image-52b630f7.png)

   <Note>
     **Note:** You can see the **Refresh Token** on Delete or Regenerate Refresh Token page in the Workday HRIS admin console. To know more, click **[here](/more/workflow/connecting-workday-hris-with-oloid-cloud-platform)**.
   </Note>

   ![Enter Refresh Token. (2)](/images/intercom/13569620/image-ac2f70ae.png)

9. Click **Save**.

   ![Click Save. (3)](/images/intercom/13569620/2e64e7bf-2234-492b-9f62-26bf71ead040-af8db90d.png)

   The Account tab is configured successfully.
10. Click **Test**.

    ![Click Test.](/images/intercom/13569620/image-c8d9acc9.png)

    The **Success** pop-up box is displayed.

    ![The Success pop-up box is displayed. (2)](/images/intercom/13569620/image-25122805.png)

The Account tab is configured successfully.

### Configure Schedule Tab

This tab is used to define when the **Workday - Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![Run Once When Activated](/images/intercom/13569620/image-3cf37c87.png)

The Schedule tab is configured successfully.

#### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.

   ![Click Save. (4)](/images/intercom/13569620/image-25d6ed0e.png)

   The **Repeat Every** section is configured successfully.

   ![The Repeat Every section is configured successfully.](/images/intercom/13569620/image-b50d56ff.png)

#### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![Click Save. (5)](/images/intercom/13569620/image-64f69d3e.png)

The **Run Once When Activated** section is configured successfully.

![The Run Once When Activated section is configured successfully.](/images/intercom/13569620/image-746e9bce.png)

### Task Run Logs

This tab is used to view the run history of the **Workday – Inbound** user sync, including the status of each job run and the number of user records processed during synchronization.

<Note>
  **Note:** Task run logs are available only after the user sync has run at least once. If the user sync is in **Draft** status or has not run yet, **No Data** is displayed.
</Note>

Do the following:

1. Click the **Task Run Logs** tab.
   The **Task Run Logs** tab is displayed.
2. (Optional) Click **Select Dates** and select the required date range to filter the logs.
3. In the **Logs** column, click the **Download** icon to download the logs of the required job run.

   ![In the Logs column, click the Download icon to download the logs of the required job run.](/images/intercom/13569620/image-2d468ccb.png)
