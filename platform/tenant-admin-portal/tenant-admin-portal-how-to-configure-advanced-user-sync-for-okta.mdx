## Introduction

This document describes how to configure Advanced User Sync for Okta - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- An **Advanced User Sync profile for Okta - Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for Okta -Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.

   ![Go to Agents &gt; Advanced User Sync.](/images/intercom/13700588/image-0b56f77e.png)

   The **Advanced User Sync** page is displayed.
3. Select the preferred Okta - Inbound Advanced User Sync.

   ![Select the preferred Okta - Inbound Advanced User Sync.](/images/intercom/13700588/image-880493a0.png)

   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
   5. [Task Run Logs](#task-run-logs)
5. Click **Activate**.

   ![Click Activate.](/images/intercom/13700588/image-3953d74a.png)

   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.

   ![Click Confirm.](/images/intercom/13700588/image-ab056a1a.png)

   The Advanced User Sync is configured and activated successfully.

   ![The Advanced User Sync is configured and activated successfully.](/images/intercom/13700588/image-05b22023.png)

7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![(Optional) Go to Action &gt; User Sync.](/images/intercom/13700588/image-7703a7d0.png)

   The **Sync Now?** pop-up box is displayed.
8. Click **Confirm**.

   ![Click Confirm. (2)](/images/intercom/13700588/image-2e197d43.png)

   The **Success** pop-up box is displayed.

   ![The Success pop-up box is displayed.](/images/intercom/13700588/image-63b89133.png)

   The Advanced User Sync for Okta - Inbound is configured successfully.

   ![The Advanced User Sync for Okta - Inbound is configured successfully.](/images/intercom/13700588/image-8bc452b0.png)

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (if required).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.

   ![Click Save.](/images/intercom/13700588/image-e7fcccb9.png)

   The Details tab is configured successfully.

   ![The Details tab is configured successfully.](/images/intercom/13700588/image-c0f6a164.png)

### Setup Configuration Tab

This tab is used to map user data from **Okta** to **Oloid** and select the Oloid connection where users are added during the inbound user sync.

Do the following:

1. Select the **Data Mapper Table** from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. On **Add Users to Selected Connection**, do one of the following:
   1. Select the **Connection** option, and then select the required **Connection** from the drop-down list.
      OR
   2. Select the **Data Filter Table** option, and then select the required **Data Filter Table** from the drop-down list.

      <Note>
        **Note:** Click **View Tables** to review or create a data filter table, if required.
      </Note>

3. Click **Save**.

   ![Click Save. (2)](/images/intercom/13700588/image-5877c025.png)

   The Configuration tab is configured successfully.

   ![The Configuration tab is configured successfully.](/images/intercom/13700588/image-d107139e.png)

### Configure Account Tab

This tab is used to add and configure the **Okta** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**.
2. Select **Auth Type**.

   <Note>
     **Note:** Select **Basic**.
   </Note>

3. Enter **Organisational URL**.

   <Note>
     **Note:** You can find the Organisational URL under **User Profile** in Okta Admin console.
   </Note>

   ![Enter Organisational URL.](/images/intercom/13700588/aa759b47-fc68-47f6-9e1b-4e77d14e81bc-bd9fd460.png)

4. Enter **Token**.

   <Note>
     **Note:** You can find the Token in the OKTA Admin Console under **Security > API > Tokens**.
   </Note>

   ![Enter Token.](/images/intercom/13700588/a1e14be6-4764-4936-af71-9f443d29a43b-2328c658.png)

5. Enter **Groups.**
6. Click **Save**.

   ![Click Save. (3)](/images/intercom/13700588/image-16767de5.png)

   The Account tab is configured successfully.
7. Click **Test**.

   ![Click Test.](/images/intercom/13700588/image-f44e6efe.png)

   The **Success** pop-up box is displayed.

   ![The Success pop-up box is displayed. (2)](/images/intercom/13700588/image-3a81252f.png)

### Configure Schedule Tab

This tab is used to define when the **Okta – Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![Run Once When Activated](/images/intercom/13700588/image-ee654788.png)

The Schedule tab is configured successfully.

### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.

   ![Click Save. (4)](/images/intercom/13700588/image-56bf9000.png)

   The **Repeat Every** section is configured successfully.

   ![The Repeat Every section is configured successfully.](/images/intercom/13700588/image-65c71363.png)

### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![Click Save. (5)](/images/intercom/13700588/image-a5d214b0.png)

The **Run Once When Activated** section is configured successfully.

![The Run Once When Activated section is configured successfully.](/images/intercom/13700588/image-ba038878.png)

### Task Run Logs

This tab is used to view the run history of the **OKTA – Inbound** user sync, including the status of each job run and the number of user records processed during synchronization.

<Note>
  **Note:** Task run logs are available only after the user sync has run at least once. If the user sync is in **Draft** status or has not run yet, **No Data** is displayed.
</Note>

Do the following:

1. Click the **Task Run Logs** tab.
   The **Task Run Logs** tab is displayed.
2. (Optional) Click **Select Dates** and select the required date range to filter the logs.
3. In the **Logs** column, click the **Download** icon to download the logs of the required job run.

   ![In the Logs column, click the Download icon to download the logs of the required job run.](/images/intercom/13700588/image-c15d00b4.png)
