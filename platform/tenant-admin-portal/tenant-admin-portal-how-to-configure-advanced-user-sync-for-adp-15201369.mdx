## Introduction

This document provides steps how to configure Advanced User Sync for ADP Workforce Now - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- An **Advanced User Sync profile for ADP Workforce Now - Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for ADP Workforce Now - Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.

   ![Go to Agents &gt; Advanced User Sync.](/images/intercom/15201369/image-0b56f77e.png)

   The **Advanced User Sync** page is displayed.
3. Select the preferred **ADP Workforce Now - Inbound** Advanced User Sync.

   ![Select the preferred ADP Workforce Now - Inbound Advanced User Sync.](/images/intercom/15201369/image-61602389.png)

   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
   5. [Task Run Logs](#task-run-logs)
5. Click **Activate**.

   ![Click Activate.](/images/intercom/15201369/image-3d581355.png)

   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.

   ![Click Confirm.](/images/intercom/15201369/image-d34599bd.png)

   The Advanced User Sync is configured and activated successfully.

   ![The Advanced User Sync is configured and activated successfully.](/images/intercom/15201369/image-c0de4582.png)

7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![(Optional) Go to Action &gt; User Sync.](/images/intercom/15201369/image-1500d35c.png)

   The **Sync Now** pop-up box is displayed.
8. Click **Confirm**.

   ![Click Confirm. (2)](/images/intercom/15201369/image-4a69c1f4.png)

   The **Success** pop-up box is displayed.

   ![The Success pop-up box is displayed.](/images/intercom/15201369/image-671c0d0e.png)

   The Advanced User Sync for ADP Workforce Now - Inbound is configured successfully.

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (Optional).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.

   ![Click Save.](/images/intercom/15201369/image-16ce6278.png)

   The Details tab is configured successfully.

### Setup Configuration Tab

This tab is used to map user data from **ADP Workforce - Inbound** to **Oloid**.

Do the following:

1. Select the **Data Mapper Table** from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. Select **Connection** from the drop-down.
3. Enable **Sync Schedule**.

   <Note>
     **Note:** Sync Schedule toggle is used sync the User Transaction.
   </Note>

4. Enable **User by Time & Attendance** toggle.
5. Enable **Terminated Users** toggle.
6. Click **Save**.

![Click Save. (2)](/images/intercom/15201369/image-ab44c3da.png)

The Configuration tab is configured successfully.

![The Configuration tab is configured successfully.](/images/intercom/15201369/image-52b07e83.png)

### Configure Account Tab

This tab is used to add and configure the **ADP Workforce Now - Inbound** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**.
2. Enter **Token Endpoint**.
3. Enter **Organization ID (OOID)**.
4. Enter **Read Credential Endpoint**.
5. Enter **API URL**.
6. Enter **Client ID**.
7. Enter **Client Secret**.

   <Note>
     **Note:** Contact Oloid support for **Organization ID, Client ID** and **Client Secret**.
   </Note>

   ![Enter Client Secret.](/images/intercom/15201369/image-7c823314.png)

   The Account tab is configured successfully.
8. Click **Test**.

   ![Click Test.](/images/intercom/15201369/image-bac70af1.png)

   The **Success** pop-up box is displayed.

![The Success pop-up box is displayed. (2)](/images/intercom/15201369/image-47971e9f.png)

### Configure Schedule Tab

This tab is used to define when the **ADP Workforce Now - Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![Run Once When Activated](/images/intercom/15201369/image-76b38750.png)

The Schedule tab is configured successfully.

#### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.

   ![Click Save. (3)](/images/intercom/15201369/image-9f0d6002.png)

   The **Repeat Every** section is configured successfully.

   ![The Repeat Every section is configured successfully.](/images/intercom/15201369/image-155f5302.png)

#### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![Click Save. (4)](/images/intercom/15201369/image-7849dbc5.png)

The **Run Once When Activated** section is configured successfully.

![The Run Once When Activated section is configured successfully.](/images/intercom/15201369/image-06b0df8e.png)

### Task Run Logs

This tab is used to view the run history of the **ADP Workforce Now – Inbound** user sync, including the status of each job run and the number of user records processed during synchronization.

<Note>
  **Note:** Task run logs are available only after the user sync has run at least once. If the user sync is in **Draft** status or has not run yet, **No Data** is displayed.
</Note>

Do the following:

1. Click the **Task Run Logs** tab.
   The **Task Run Logs** tab is displayed.
2. (Optional) Click **Select Dates** and select the required date range to filter the logs.
3. In the **Logs** column, click the **Download** icon to download the logs of the required job run.

   ![In the Logs column, click the Download icon to download the logs of the required job run.](/images/intercom/15201369/image-b5420ffd.png)
