## Introduction

The Data Mapper Table in the Tenant Admin Portal allows admins to map employee data from external systems such as Microsoft Entra ID to Oloid. This document provides instructions on how to create the Data Mapper table for Entra ID - Inbound.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Data Mapper Table

1. Log in to Tenant Admin Portal.
2. Go to **Agents** tab > click **Data Tables**.

   ![Go to Agents tab &gt; click Data Tables.](/images/intercom/13597715/image-62bfe739.png)

   The Data Tables page is displayed.
3. Click **Create Table**.

   ![Click Create Table.](/images/intercom/13597715/image-9d7271ec.png)

   The **Create Data Table** pop-up box is displayed.
4. Do the following:
   1. Enter **Table Name**.
   2. Select **Data-mapper Table** in Type of Table.
   3. Click **Next**.
   4. Select **Entra ID - Inbound** as a Category.
   5. Click **Create**.

      ![Click Create.](/images/intercom/13597715/image-61e0a1e4.png)

      The data mapper table is created successfully.

      ![The data mapper table is created successfully.](/images/intercom/13597715/image-60ac5be0.png)
