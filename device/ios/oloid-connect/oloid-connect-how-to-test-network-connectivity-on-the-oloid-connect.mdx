## Steps to test network connectivity on the Endpoint

1. Launch the **Oloid Connect** ![How to test Network Connectivity on the... - screenshot 1](/images/intercom/8611826/image-6def886f.png)  **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the initial screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to test Network Connectivity on the... - screenshot 2](/images/intercom/8611826/image-00093ad5.png)
2. Double tap with two fingers on the initial screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to test Network Connectivity on the... - screenshot 3](/images/intercom/8611826/9a24b866-2972-486d-be7e-a343751fdba2-c6ddcb79.png)
   The **Settings** screen is displayed.
4. Tap **Start** in the **Health Check** section.
   ![How to test Network Connectivity on the... - screenshot 4](/images/intercom/8611826/ad3e1f5c-df2f-41ec-87de-67ed6d669ad2-dda6a8a1.png)
   The **Please Select Health Type** pop-up box is displayed.
5. On the pop-up box, tap **Network Route Status**.

![How to test Network Connectivity on the... - screenshot 5](/images/intercom/8611826/71869eb2-5d25-4b74-84b2-6018788d5bae-20bdfe50.png)

The **Network Status** page is displayed.

![How to test Network Connectivity on the... - screenshot 6](/images/intercom/8611826/image-0522e367.png)
