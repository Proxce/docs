## Introduction

This document provides instructions to log in to the **Oloid Connect** application using **Microsoft Single Sign On (SSO)**.

## Prerequisite

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](https://oloid.help/en/articles/12554658-how-to-download-and-install-the-oloid-connect-app-on-iphone)

## **Steps to log in with Microsoft** SSO

1. Launch the **Oloid Connect** ![Login Using Microsoft SSO - screenshot 1](/images/intercom/13595980/image-6def886f.png) app.
   ![Login Using Microsoft SSO - screenshot 2](/images/intercom/13595980/image-02ba2845.png)
   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**
   ![Login Using Microsoft SSO - screenshot 3](/images/intercom/13595980/d77a4a4e-7ec2-412c-8aa8-bb42212fafdb-449c6e31.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**.
   ![Login Using Microsoft SSO - screenshot 4](/images/intercom/13595980/6ff99e10-2f0c-4988-8158-771e66d20758-57d7cf98.png)
   TheLogin page is displayed.
4. Tap **Login with SSO**.
   ![Login Using Microsoft SSO - screenshot 5](/images/intercom/13595980/b23a8b3c-6865-406e-99cb-023d8bfca1da-f49c45df.png)
   The screen with **SSO options** is displayed.
5. Select **Continue with Microsoft**.
   ![Login Using Microsoft SSO - screenshot 6](/images/intercom/13595980/image-1218b4fc.png)
   The confirmation pop-up is displayed.
6. Click **Continue**.
   ![Login Using Microsoft SSO - screenshot 7](/images/intercom/13595980/image-10b2cf54.png)
   The **Sign in** page is displayed.
7. Do the following:
   1. Enter **Email ID**.
   2. Tap **Next**.
      ![Login Using Microsoft SSO - screenshot 8](/images/intercom/13595980/image-a543644e.png)
      The **Enter password** screen is displayed.
8. Do the following:
   1. Enter **Password**.
   2. Tap **Next**.

![Login Using Microsoft SSO - screenshot 9](/images/intercom/13595980/46165050-fada-4f29-a81b-c14c15329540-acd980a6.png)

You are successfully logged in to Oloid Connect Admin Mode.

![Login Using Microsoft SSO - screenshot 10](/images/intercom/13595980/image-22bd0fa1.png)
