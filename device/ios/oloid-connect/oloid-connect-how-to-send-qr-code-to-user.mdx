**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to email QR code to users.

## Steps to send QR Code via email

1. Launch the **Oloid Connect** ![How to send QR code to user - screenshot 1](/images/intercom/8789251/image-6def886f.png) app and login with the provided options.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)**.**
   </Note>

   ![How to send QR code to user - screenshot 2](/images/intercom/8789251/image-659839b6.png)
2. The **Settings** page is displayed.
   ![How to send QR code to user - screenshot 3](/images/intercom/8789251/image-6c2feb88.png)
3. Tap **Users** on the menu at the bottom of the screen.
   ![How to send QR code to user - screenshot 4](/images/intercom/8789251/c9b6e886-ef63-4347-b476-6365dccd406d-bd909cb2.png)
   The **Users** page is displayed.
   ![How to send QR code to user - screenshot 5](/images/intercom/8789251/1baaf485-ba8f-4932-baf1-40934b7ddb26-803fd803.png)
4. Select a user from **Users** list, or search for a user using the search bar at the top to send QR code via email.
   ![How to send QR code to user - screenshot 6](/images/intercom/8789251/03a6c29b-fdac-4efb-ba97-3ac8d9d8d391-52b8039f.png)
   The User details screen opens.
   ![How to send QR code to user - screenshot 7](/images/intercom/8789251/3432c0a1-22fd-4acf-87e6-747e100911af-0b8557d5.png)
5. Tap **QR Code** tab.
   ![How to send QR code to user - screenshot 8](/images/intercom/8789251/a8d7da12-e5d6-4d76-b768-229463acce82-3eb9480d.png)
   The QR Code is displayed.
6. Tap **Email** icon.
   ![How to send QR code to user - screenshot 9](/images/intercom/8789251/94de2ce5-8a0d-4b2a-9d5d-fb7077f777b2-c734c8b6.png)
   The **Send QR Code on Email** pop-up box is displayed.
7. Enter the email addresses to share the QR code.
8. Tap **Save**.
   ![How to send QR code to user - screenshot 10](/images/intercom/8789251/5bf49013-11da-4e0d-81c7-7a71270bea83-72e4f56a.png)
   The QR code is sent to the user's email id.
