## Introduction

The Auto-Pair configuration file in the Tenant Admin Portal helps Tenant Admins simplify and automate the endpoint pairing process for the Oloid Connect app by which, endpoints can pair automatically without manual confirmation. This ensures faster setup, consistent configuration, and improved security across devices.

## Prerequisite

- You must have a Tenant Admin account.
- You must create an Oloid Connect application. To create application refer [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal).

## Steps to generate auto-pair config file

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to generate Auto-Pair config file... - screenshot 1](/images/intercom/11513590/8011311c-7f26-4413-aab1-1e3152722f5f-8aeb4733.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to generate Auto-Pair config file... - screenshot 2](/images/intercom/11513590/ead0edef-db9a-403c-9b28-f6f8973b7432-0cd0a3e1.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > **API Token** > **API Key**.
   ![How to generate Auto-Pair config file... - screenshot 3](/images/intercom/11513590/45633202-6454-4d3a-9836-b22ac299a1b2-fe15e691.png)
5. In the **Generate Temporary Access Token** section, do the following:
   1. Set the **Start Date/Time** field.
      - To set the start date and time, click on the date picker then, select the date or **Now** > click **OK**.
   2. Set the **End Date/Time** field.
      - To set the end date and time, click on the date picker then, select the date > click **OK**.
   3. Specify **Number of Endpoints** that can be created using the endpoint. (Optional)
   4. Click **Generate**.
      ![How to generate Auto-Pair config file... - screenshot 4](/images/intercom/11513590/b700b191-2b42-4aa7-9bfe-0d5c41b866f3-0401d10e.png)
      The Auto-pair config file is generated successfully.
6. Click **Auto-pair config file**.
   ![How to generate Auto-Pair config file... - screenshot 5](/images/intercom/11513590/ca6e65c5-4747-4b0a-89f6-2f2f2e20d16e-73ce49df.png)
   The Auto-pair config file pop-up box is displayed.
7. On the pop-up box, do the following:
   1. Select **Application** as **Oloid Verify** from **Application Type** dropdown list.
   2. Select the application that you want the endpoints to pair with from the **Select Application** drop-down list.
   3. Under **Download file format**, select one of the following:
      - **JSON** → For local device setup.
      - **XML** → For MDM deployment.
   4. Select **Skip user confirmation for pairing** option to auto-pair endpoints without requiring user confirmation (optional but recommended).
      - **If selected:** When the configuration file is uploaded to the endpoint, the system will pair automatically without prompting the user for confirmation.
      - **If not selected:** The system will display a confirmation pop-up to the user before completing the pairing process.
   5. Click **Download**.
      ![How to generate Auto-Pair config file... - screenshot 6](/images/intercom/11513590/e5ac7ddc-4e27-445f-b345-814b3cba94d8-e355fbad.png)
      The AutopairConfig file is downloaded successfully to the local device.
