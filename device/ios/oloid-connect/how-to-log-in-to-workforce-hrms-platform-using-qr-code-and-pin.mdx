## Introduction

This document provides step-by-step instructions for logging in with QR Code and PIN to Workforce / HRMS platform.

## Pre-requisite

- User must have an Okta account.
- In the Oloid Portal, admin must do the following:
  - Okta credential (user email ID) must be added to the user details page in Oloid Portal.
  - Assign QR Code to the user. For more details, refer [How to create QR code as credential for User.](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-for-user)
  - Add PIN for the user. For more details, refer [How to add PIN as credential to users.](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable QR Code and PIN options under the Oloid Verify Application. For more details, refer [How to create and configure Connect for Passwordless application.](https://oloid.help/en/articles/9896977-how-to-create-and-configure-oloid-connect-for-passwordless-application)

## Using the QR Code

1. Launch the Oloid Connect app in your iPad.
2. On the home page of the app, select **QR Auth**.
   ![How to log in to Workforce /HRMS... - screenshot 1](/images/intercom/9842058/image-08e6c9d3.png)
   This opens the camera on your iPad.
3. Show your QR Code for automatic capture.
   ![How to log in to Workforce /HRMS... - screenshot 2](/images/intercom/9842058/image-daabe29d.png)
4. On QR code authentication, the **Enter PIN to Login** screen is displayed.
   ![How to log in to Workforce /HRMS... - screenshot 3](/images/intercom/9842058/image-623a2d67.png)
5. Enter the **PIN**.
   On PIN authentication, you are signed in to the **Workforce /HRMS** platform.
   ![How to log in to Workforce /HRMS... - screenshot 4](/images/intercom/9842058/image-b50262c0.png)
