## Introduction

This document provides step-by-step instructions to re-pair an endpoint using the Oloid Connect iPhone app.

## Steps to re-pair an endpoint

1. Launch the **Oloid Connect** app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [Oloid Connect - Admin Setup on iPhone](https://oloid.help/en/articles/12554774-oloid-connect-admin-setup-on-iphone)
   </Note>

   The **Settings** page is displayed.
   ![How to Re-pair an Endpoint in Oloid... - screenshot 1](/images/intercom/12595558/image-5fd3c70d.png)
2. Tap **Re-pair.**
   ![How to Re-pair an Endpoint in Oloid... - screenshot 2](/images/intercom/12595558/b0937a2c-2357-4d0d-b55a-ec1252499f9c-35f544c9.png)
   **Re-pair Endpoint** pop-up is displayed.

   <Note>
     **Note:** You can only re-pair an endpoint if it is not paired.
   </Note>

   ![How to Re-pair an Endpoint in Oloid... - screenshot 3](/images/intercom/12595558/c34afb08-bba5-46f3-959a-3653e7aec689-43fb4d0a.png)
3. On the pop-up box, do the following:
   1. Enter **Endpoint ID**.
   2. Tap **Re-pair**.

The Endpoint is re-paired successfully.

![How to Re-pair an Endpoint in Oloid... - screenshot 4](/images/intercom/12595558/image-14347e7c.png)

<Note>
  **Note:** Kill and relaunch the app to make the new updates function properly.
</Note>
