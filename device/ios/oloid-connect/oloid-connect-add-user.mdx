**Introduction:**

This feature of the Oloid Connect app allows Tenant admins and supervisors to add new users. Endpoint pairing is not required to complete this action.

<Note>
  **Note:** Supervisors privileges should be enabled to allow the supervisor to add user. For more, refer to [How to enable Add or Delete Users in Tenant Admin Portal for Supervisors](https://oloid.help/en/articles/9127132-how-to-enable-add-or-delete-users-in-tenant-admin-portal-for-supervisors)
</Note>

## Steps to add user

1. Launch the **Oloid Connect** ![Oloid Connect - Add User - screenshot 1](/images/intercom/8601079/image-6def886f.png) app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   The **Settings** page is displayed.
   ![Oloid Connect - Add User - screenshot 2](/images/intercom/8601079/d1ea0f71-e1b1-4953-a9f6-1e92d22ca7b9-8f1ccefd.png)
2. Tap **Actions** on the menu at the bottom of the screen.
   ![Oloid Connect - Add User - screenshot 3](/images/intercom/8601079/f947a98c-f349-4392-871a-5eb7b18be9d0-cf461bfa.png)
   The **Actions** screen opens.
3. Tap **Add User**.
   ![Oloid Connect - Add User - screenshot 4](/images/intercom/8601079/335da16f-74c4-41e9-bba6-580c92db14b9-3c7db630.png)
   The **Add User** screen is displayed.
4. Do the following:
   1. Enter **Name**.
      First name and Last name should be separated by a space.
   2. Enter **Primary ID**.
      Only alphabets, numbers, and hyphen are accepted.
   3. Enter **Secondary ID**.
      Only numbers are accepted.
   4. Select connection name from **Connection Name** list.
5. Tap **Add User**.
   ![Oloid Connect - Add User - screenshot 5](/images/intercom/8601079/image-6e79d92a.png)
   A new user is added and user details are displayed in Details screen.
