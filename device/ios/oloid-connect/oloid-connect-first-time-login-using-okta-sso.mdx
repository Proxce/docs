## Prerequisite

You must download the Oloid Connect app from App Store. For more details, refer [How to download Oloid Connect app](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application).

## Steps to log in with Okta SSO

1. Launch the **Oloid Connect** ![First Time Login Using Okta SSO - screenshot 1](/images/intercom/10345413/image-6def886f.png) app.
   ![First Time Login Using Okta SSO - screenshot 2](/images/intercom/10345413/image-b161bff5.png)
2. Tap **Pair as Supervisor.**
   ![First Time Login Using Okta SSO - screenshot 3](/images/intercom/10345413/ecc40269-285d-4f4e-88e2-f9771a362fd6-9a614ee0.png)
   The **Welcome** page is displayed.
3. Enter **Tenant Name,** then tap **Next**.
   ![First Time Login Using Okta SSO - screenshot 4](/images/intercom/10345413/image-d878b584.png)
   The **Login** page is displayed.
4. Tap **Login with SSO**.
   ![First Time Login Using Okta SSO - screenshot 5](/images/intercom/10345413/bccab0d0-afda-4533-91d6-7bbcb81148ee-a5ef771c.png)
   The screen with **SSO options** is displayed.
5. Select **Continue with Okta**.
   ![First Time Login Using Okta SSO - screenshot 6](/images/intercom/10345413/f020194c-3bb7-4226-a59f-8f00191918a6-5d519dbb.png)
   The confirmation pop-up is displayed.
6. Tap **Continue**.
   ![First Time Login Using Okta SSO - screenshot 7](/images/intercom/10345413/image-6e01f6ba.png)
   The Sign In screen is displayed.
7. Enter **Username** > tap **Next**.
   ![First Time Login Using Okta SSO - screenshot 8](/images/intercom/10345413/c4c3e1c0-c607-43ee-a6f2-21f8a1e89fac-982983d3.png)
8. Enter **Password** in the **Password** field > tap **Sign In**.
   ![First Time Login Using Okta SSO - screenshot 9](/images/intercom/10345413/93424782-2e19-4668-9fe2-b7742748c3f4-c2e52424.png)
   You are logged in to Admin Mode successfully.

![First Time Login Using Okta SSO - screenshot 10](/images/intercom/10345413/91a4d3c6-378d-473d-ba83-bf2ad7da1dfd-a0544fd1.png)
