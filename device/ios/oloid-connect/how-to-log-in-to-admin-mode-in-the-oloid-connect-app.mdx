A Tenant Admin and Supervisor can log in to the admin mode of the Oloid Connect App through the following methods:

- [Log in Using Email and Password](#log-in-using-email-and-password)
- [Log in Using Face](#log-in-using-face)
- [Log in Using SSO](#log-in-using-sso)

## Log in Using Email and Password

## Pre-requisite

- The user must be a Tenant Admin or Supervisor to log in to Admin Mode.
- The endpoint must be paired.
  For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)

### Steps to log using Email and Password

1. Launch the **Oloid Connect** ![How to Log in to Admin Mode in the... - screenshot 1](/images/intercom/8671144/image-6def886f.png) **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to Log in to Admin Mode in the... - screenshot 2](/images/intercom/8671144/image-270d1b87.png)
2. Double tap with two fingers on the preview screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Log in to Admin Mode in the... - screenshot 3](/images/intercom/8671144/2bcb7eb0-d20e-4e72-8e12-002c80b37342-dd2c821c.png)
   The **Settings** screen is displayed.
4. Click **Login as Admin**.
   ![How to Log in to Admin Mode in the... - screenshot 4](/images/intercom/8671144/4864244b-41ee-4166-9edf-3226e7ffdf53-af2ddefa.png)
   The Login screen is displayed.
5. Do the following:
   1. Enter your email ID in the **Email** text field.
   2. Enter your password in the **Password** text field.
6. Tap **Login.**
   ![How to Log in to Admin Mode in the... - screenshot 5](/images/intercom/8671144/5d3ba15a-6576-45fe-8f0f-fe33ae9f7053-1d93b064.png)
   You are logged in to the Admin Mode successfully.

## Log in Using Face

**Pre-Requisite:**

- Face should be onboarded for the Tenant Admin or Supervisor.
- Endpoint should be paired with the Oloid Connect application.
- The Connection assigned to the Supervisor must be linked to the application paired with the endpoint.
  For further details, refer [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)

### Steps to log in with Face

1. Launch the **Oloid Connect** ![How to Log in to Admin Mode in the... - screenshot 6](/images/intercom/8671144/image-6def886f.png) **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to Log in to Admin Mode in the... - screenshot 7](/images/intercom/8671144/image-270d1b87.png)
2. Double tap with two fingers on the preview screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Log in to Admin Mode in the... - screenshot 8](/images/intercom/8671144/2bcb7eb0-d20e-4e72-8e12-002c80b37342-dd2c821c.png)
   The **Settings** screen is displayed.
4. Click **Login as Admin**.
   ![How to Log in to Admin Mode in the... - screenshot 9](/images/intercom/8671144/4864244b-41ee-4166-9edf-3226e7ffdf53-af2ddefa.png)
   The Login screen is displayed.
5. On the Login Page, tap **Login with Face**.
   ![How to Log in to Admin Mode in the... - screenshot 10](/images/intercom/8671144/80b3ea30-c2fb-4f9d-8dd9-f5aeff6678df-c449b56b.png)
   This will open the camera preview screen.
6. Tenant Admin and Supervisor needs to show their face.
   ![How to Log in to Admin Mode in the... - screenshot 11](/images/intercom/8671144/image-15ea316f.png)
   As soon as face match is done, you are logged in to the Admin Mode.

## Log in Using SSO

### Pre-requisite

- Tenant admin and Supervisor's Email ID needs to be updated in the Tenant Admin Portal.
- The endpoint must be paired.
  For further details, refer [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)

### Steps to log in with SSO Options

1. Launch the **Oloid Connect** ![How to Log in to Admin Mode in the... - screenshot 12](/images/intercom/8671144/image-6def886f.png) **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to Log in to Admin Mode in the... - screenshot 13](/images/intercom/8671144/image-270d1b87.png)
2. Double tap with two fingers on the preview screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Log in to Admin Mode in the... - screenshot 14](/images/intercom/8671144/2bcb7eb0-d20e-4e72-8e12-002c80b37342-dd2c821c.png)
   The **Settings** screen is displayed.
4. Click **Login as Admin**.
   ![How to Log in to Admin Mode in the... - screenshot 15](/images/intercom/8671144/4864244b-41ee-4166-9edf-3226e7ffdf53-af2ddefa.png)
   The Login screen is displayed.
5. On the login page, tap **Login with SSO**.
   ![How to Log in to Admin Mode in the... - screenshot 16](/images/intercom/8671144/30de32ea-29e8-4c7e-8898-94fa96370666-02b01b0b.png)

   ![How to Log in to Admin Mode in the... - screenshot 17](/images/intercom/8671144/c0761e6e-0e66-47b4-a9ac-ce07ba2663a0-1e06c8dc.png)

<Note>
  **Note:** Oloid Connect uses **SSO login** and also allows you to log in to the portal with your [Google](https://oloid.help/en/articles/10293811-how-to-log-in-with-google-sso-in-oloid-connect-admin-mode) , [Microsoft](https://oloid.help/en/articles/10293864-how-to-log-in-with-microsoft-sso-in-oloid-connect-admin-mode), and [Okta](https://oloid.help/en/articles/10345413-oloid-connect-how-to-log-in-with-okta-sso).
