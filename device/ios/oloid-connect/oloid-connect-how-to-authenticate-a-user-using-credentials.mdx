## Introduction

The Oloid Connect app provides five secure and convenient authentication methods- Face, QR Code, Badge, NFC/ID, and PIN. These methods allow users to quickly authenticate ensuring a seamless and reliable login experience.

Following are the authentication method used:

[Authenticate using Face](#authenticate-using-face)

[Authenticate using QR Code](#authenticate-using-qr-code)

[Authenticate using Badge](#authenticate-using-badge-id)

[Authenticate using NFC/ID](#authenticate-using-nfc-id)

[Authenticate using PIN](#authenticate-using-pin)

## Authenticate using Face

#### Prerequisite

Your face must be registered in the Oloid Connect app.

#### Steps to authenticate using face

1. Launch the **Oloid Connect** ![How to Authenticate a User Using... - screenshot 1](/images/intercom/10337624/image-c7df2478.png) **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)
   </Note>

   The **Welcome** screen is displayed.
2. Tap **Login with Face**.
   ![How to Authenticate a User Using... - screenshot 2](/images/intercom/10337624/bda2535d-56b6-4c13-8f2e-cc534f04cf0b-42bdf955.png)
   The Camera opens to capture the user's face.
3. Place your Face inside the oval frame in the screen.
   After successful authentication, the user details appear at the top of the screen.
   ![How to Authenticate a User Using... - screenshot 3](/images/intercom/10337624/image-2110f79e.png)

## Authenticate using QR Code

#### Prerequisite

You must have your assigned QR Code.

#### Steps to authenticate using QR Code

1. Launch the **Oloid Connect** ![How to Authenticate a User Using... - screenshot 4](/images/intercom/10337624/image-c7df2478.png) **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)
   </Note>

   The **Welcome** screen is displayed.
2. Tap **Login with QR code**.
   ![How to Authenticate a User Using... - screenshot 5](/images/intercom/10337624/c3e585dc-5f40-4dec-a7a8-c19b1e799cac-e23fbf0a.png)
   The Camera opens to scan the **QR Code**.
3. Place your QR Code within the oval frame on the camera to capture your QR code for authentication.
   After successful authentication, the user details appear at the top of the screen.
   ![How to Authenticate a User Using... - screenshot 6](/images/intercom/10337624/image-47924d53.png)

## Authenticate using Badge ID

#### Prerequisite

- Make sure that the badge reader is connected with the endpoint.

#### Steps to authenticate using Badge ID

   <Note>

   </Note>

2. The **Welcome** screen is displayed.
3. Tap **Login with Badge**.
