**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to

extend QR code expiry date and time.

## Steps to extend QR Code expiry date and time

1. Launch the **Oloid Connect**  app and login with the provided options.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   ![How to extend QR code - screenshot 1](/images/intercom/11735953/image-659839b6.png)
2. The **Settings** page is displayed.
   ![How to extend QR code - screenshot 2](/images/intercom/11735953/image-6c2feb88.png)
3. Tap **Users** on the menu at the bottom of the screen.
   ![How to extend QR code - screenshot 3](/images/intercom/11735953/c9b6e886-ef63-4347-b476-6365dccd406d-bd909cb2.png)
   The **Users** page with list of users is displayed.
4. Select the user from **Users** list to extend the QR code.
   ![How to extend QR code - screenshot 4](/images/intercom/11735953/03a6c29b-fdac-4efb-ba97-3ac8d9d8d391-81417cc9.png)
   The User details screen opens.
   ![How to extend QR code - screenshot 5](/images/intercom/11735953/3432c0a1-22fd-4acf-87e6-747e100911af-34123678.png)
5. Tap **QR Code** tab.
   ![How to extend QR code - screenshot 6](/images/intercom/11735953/a8d7da12-e5d6-4d76-b768-229463acce82-e33adc42.png)
   The QR Code is displayed under the **QR Code** tab.
6. Tap **Edit** icon.
   ![How to extend QR code - screenshot 7](/images/intercom/11735953/ee87f87a-09c1-490f-9f77-9bdb2a892597-31e91dca.png)
   The **Extend expiry time** pop-up box is displayed.
   ![How to extend QR code - screenshot 8](/images/intercom/11735953/1f13bdf2-4e5a-4b0c-a87d-79d280644654-8952445b.png)
7. Select the QR code validity date and time from the calendar.
8. Tap **Done**.

![How to extend QR code - screenshot 9](/images/intercom/11735953/c20e5e00-1f37-429b-8044-cf98fc02a19e-0fa2b403.png)

The QR Code expiry time is extended.
