## Introduction

The PingOne SSO Login feature in the Oloid Connect App allows Tenant Admin and Supervisor to securely access Admin Mode using PingOne SSO credentials.

## Prerequisite

You must download the Oloid Connect app from App Store. For more details, refer [How to download Oloid Connect app](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application).

## Steps to log in with Ping One SSO

1. Launch the **Oloid Connect** ![Login using Ping One SSO - screenshot 1](/images/intercom/13866936/image-6def886f.png) app.
   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**
   ![Login using Ping One SSO - screenshot 2](/images/intercom/13866936/ecc40269-285d-4f4e-88e2-f9771a362fd6-9a614ee0.png)
   The **Welcome** page is displayed.
3. Enter **Tenant Name.**
4. Tap **Next**.
   ![Login using Ping One SSO - screenshot 3](/images/intercom/13866936/image-d878b584.png)
   The **Login** page is displayed.
5. Tap **Login with SSO**.
   ![Login using Ping One SSO - screenshot 4](/images/intercom/13866936/bccab0d0-afda-4533-91d6-7bbcb81148ee-a5ef771c.png)
   The screen with **SSO options** is displayed.
6. Select **Continue with Ping**.
   ![Login using Ping One SSO - screenshot 5](/images/intercom/13866936/image-e182490e.png)
   The Sign on screen is displayed.
7. Do the following:
   1. Enter **Username.**
   2. Enter **Password.**
8. Tap **Sign On**.
   ![Login using Ping One SSO - screenshot 6](/images/intercom/13866936/image-ba177d79.png)
   You are logged in to Admin Mode successfully.
   ![Login using Ping One SSO - screenshot 7](/images/intercom/13866936/91a4d3c6-378d-473d-ba83-bf2ad7da1dfd-94c22065.png)
