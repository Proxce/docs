## Introduction

This document explains how to assign a badge to a user using the Oloid Connect iPad app. Admin can scan a physical badge using a connected badge reader to enroll it for a user.

## Prerequisites

- User should be added to the connection paired with the application.
- The badge reader must be connected to the iPad.

## Steps to assign Badge

1. Launch the **Oloid Connect** app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   The **Settings** page is displayed.
   ![Assign Badge - screenshot 1](/images/intercom/13395774/image-1ed4d308.png)
2. Tap **Users** on the menu at the bottom of the screen.
   ![Assign Badge - screenshot 2](/images/intercom/13395774/c9b6e886-ef63-4347-b476-6365dccd406d-4afd3f12.png)
   The **Users** page is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top to assign the badge.
   ![Assign Badge - screenshot 3](/images/intercom/13395774/f4cfd404-3251-4290-9302-d9cc154da41a-70870aab.png)
   The user **details** screen is displayed.
4. Go to **BadgeID**.
   ![Assign Badge - screenshot 4](/images/intercom/13395774/image-4351a16f.png)
   The **BadgeID** screen is displayed.
5. Tap **Scan Badge.**
   ![Assign Badge - screenshot 5](/images/intercom/13395774/image-26e1a39c.png)
   The **Scan Badge** pop up is displayed.
6. Scan the **Badge** on the **Badge reader**.

   <Note>
     **Note:** The badge reader must be connected to the iPad.
   </Note>

   ![Assign Badge - screenshot 6](/images/intercom/13395774/image-73a57efd.png)
   The Badge is scanned Successfully.

Tap **Create.**

![Assign Badge - screenshot 7](/images/intercom/13395774/image-31c62110.png)

The **Badge** is assigned successfully to the user.

![Assign Badge - screenshot 8](/images/intercom/13395774/image-5674396c.png)

The assigned badge ID details are displayed on the **BadgeID** screen.

![Assign Badge - screenshot 9](/images/intercom/13395774/image-6e44f39a.png)
