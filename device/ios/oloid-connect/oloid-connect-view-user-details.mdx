## Introduction

The Users screen in the Oloid Connect app provides access to a list of all registered users. From this screen, you can view detailed information about any individual user.

## Steps to view User details

1. Launch the **Oloid Connect** ![View user details - screenshot 1](/images/intercom/8616669/image-6def886f.png) app and login with the provided options.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to
   </Note>

   [How to log in to the Admin mode in Oloid Connect App](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)**.**
   ![View user details - screenshot 2](/images/intercom/8616669/image-04a5d966.png)
   The **Settings** page is displayed.
   ![View user details - screenshot 3](/images/intercom/8616669/image-70462c77.png)
2. Tap **Users** on the menu at the bottom of the screen.
   ![View user details - screenshot 4](/images/intercom/8616669/c9b6e886-ef63-4347-b476-6365dccd406d-77588022.png)
   The **Users** page with list of users is displayed.
3. Tap on the selected user to view details, or search for a user using the search bar at the top.

![View user details - screenshot 5](/images/intercom/8616669/f4cfd404-3251-4290-9302-d9cc154da41a-4961f495.png)

The User details are displayed on the screen.
