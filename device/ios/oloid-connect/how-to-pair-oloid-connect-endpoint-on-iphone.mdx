## Introduction

This feature of the **Oloid Connect app** allows Tenant Admins and Supervisors to pair an endpoint on iPhone. Pairing an endpoint enables the app to connect with the configured application and perform transactions.

## Prerequisite

- You must download and the install the Oloid Connect app. To download and install refer to [How to Download and Install the Oloid Connect App on iPhone](https://oloid.help/en/articles/12554658-how-to-download-and-install-the-oloid-connect-app-on-iphone).
- You must complete the Admin setup before pairing an endpoint. To complete the Admin setup refer to [Oloid Connect - Admin Setup on iPhone](https://oloid.help/en/articles/12554774-oloid-connect-admin-setup-on-iphone).

## Steps to pair an endpoint

1. Launch the Oloid Connect app.
   ![How to pair Oloid Connect endpoint on... - screenshot 1](/images/intercom/12577230/image-298dfc47.png)
2. Log in to **Oloid Connect** app.
   The Settings page is displayed on a successful login.
3. Do the following:
   1. Add **Template** (optional).

      <Note>
        **Note:** Templates allow Admins to configure Endpoints at scale. A template has to be created in Oloid Portal. See [How to create and configure Oloid Connect endpoint template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template)
      </Note>

   2. Enter **Endpoint Name**.
   3. Select **Application Name** from **Application Name** dropdown list.
   4. Click **Pair**.
      ![How to pair Oloid Connect endpoint on... - screenshot 2](/images/intercom/12577230/2bb3e003-e3f0-4d85-afb2-64b29727a79f-d133cd29.png)
      The settings are saved and endpoint is successfully paired.
      ![How to pair Oloid Connect endpoint on... - screenshot 3](/images/intercom/12577230/image-75b7bb73.png)
      The application prompts you to log out of Admin mode.
4. Do one of the following:
   1. Click **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to do the transactions.
   2. Click **No** to stay logged in to the admin mode.
      ![How to pair Oloid Connect endpoint on... - screenshot 4](/images/intercom/12577230/image-02a73b8a.png)
      The app remains in Admin mode.
      ![How to pair Oloid Connect endpoint on... - screenshot 5](/images/intercom/12577230/image-489782b3.png)
      The endpoint is successfully paired with your iPhone.
