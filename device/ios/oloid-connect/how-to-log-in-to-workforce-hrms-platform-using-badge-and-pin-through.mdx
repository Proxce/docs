## Introduction

This document provides step-by-step instructions for logging in with badge and PIN to Workforce / HRMS platform.

## Pre-requisite

- User must have an Okta account.
- In the Oloid Portal, admin must do the following:
  - Okta credential (user email ID) must be added to the user details page in Oloid Portal.
  - Assign badge to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
  - Add a PIN for the user. For more details, refer[How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable Badge option under the Oloid Verify application in Authentication tab. For more details, refer [How to create and configure Connect for Passwordless application.](https://oloid.help/en/articles/9896977-how-to-create-and-configure-oloid-connect-for-passwordless-application)

## Using the Badge

1. Launch the Oloid Connect app on your iPad.
2. On the home page of the app, select **Badge Auth**.
   ![How to log in to Workforce /HRMS... - screenshot 1](/images/intercom/9789771/image-e6b5ba5c.png)
   The **Scan Badge at the Reader** screen is displayed.
   ![How to log in to Workforce /HRMS... - screenshot 2](/images/intercom/9789771/image-97a2733f.png)
3. Tap the **Badge** on the **Reader** to scan it.

   <Note>
     **Note:** The Card Reader should be connected to your iPad.
   </Note>

4. On Badge authentication, the **Enter PIN to Login** screen is displayed.
   ![How to log in to Workforce /HRMS... - screenshot 3](/images/intercom/9789771/image-623a2d67.png)
5. Enter the **PIN**.
   On PIN authentication, you are signed in to the **Workforce /HRMS** platform.
   ![How to log in to Workforce /HRMS... - screenshot 4](/images/intercom/9789771/image-14ac8cb4.png)
