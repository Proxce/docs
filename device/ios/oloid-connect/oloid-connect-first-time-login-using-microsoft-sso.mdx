## Prerequisite

You must download the Oloid Connect app from App Store. For more details, refer [How to download Oloid Connect app](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application).

## Steps to log in with Microsoft SSO

1. Launch the **Oloid Connect** ![First Time Login Using Microsoft SSO - screenshot 1](/images/intercom/10293864/image-6def886f.png) app.
   ![First Time Login Using Microsoft SSO - screenshot 2](/images/intercom/10293864/image-8023bdfb.png)
2. Tap **Pair as Supervisor.**
   ![First Time Login Using Microsoft SSO - screenshot 3](/images/intercom/10293864/ecc40269-285d-4f4e-88e2-f9771a362fd6-2acb4e46.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name,** then tap **Next**.
   ![First Time Login Using Microsoft SSO - screenshot 4](/images/intercom/10293864/image-68b311a7.png)
   The **Login** page is displayed.
4. Tap **Login with SSO**.
   ![First Time Login Using Microsoft SSO - screenshot 5](/images/intercom/10293864/bccab0d0-afda-4533-91d6-7bbcb81148ee-1bd8f66b.png)
   The screen with **SSO options** is displayed.
5. Select **Continue with Microsoft**.
   ![First Time Login Using Microsoft SSO - screenshot 6](/images/intercom/10293864/b71d107a-4cf0-4148-9329-cdeec81cabca-d357b3bd.png)
   The confirmation pop-up is displayed.
6. Click **Continue**.
   ![First Time Login Using Microsoft SSO - screenshot 7](/images/intercom/10293864/2d5c1975-c4a9-4be2-9f1f-46a375f47b07-dd1b38ed.png)
   The **Sign in** page is displayed.
7. Do the following:
   1. Enter **Email ID**.
   2. Click **Next**.
      ![First Time Login Using Microsoft SSO - screenshot 8](/images/intercom/10293864/image-7322e753.png)
      The **Enter password** screen is displayed.
8. Do the following:
   1. Enter **Password**.
   2. Click **Sign in**.
      ![First Time Login Using Microsoft SSO - screenshot 9](/images/intercom/10293864/b7358811-3f61-4e89-8f53-33a4a9439b7f-242ba43a.png)
      You are successfully logged in to Oloid Connect Admin Mode.

![First Time Login Using Microsoft SSO - screenshot 10](/images/intercom/10293864/91a4d3c6-378d-473d-ba83-bf2ad7da1dfd-effe245e.png)
