## Prerequisite

You must download the Oloid Connect from App Store. For more details, refer [How to download Oloid Connect app](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application).

## Steps to log in with Google SSO

1. Launch the **Oloid Connect** ![First Time Login Using Google SSO - screenshot 1](/images/intercom/10293811/image-6def886f.png) app.
   ![First Time Login Using Google SSO - screenshot 2](/images/intercom/10293811/image-04a5d966.png)
2. Tap **Pair as Supervisor.**
   ![First Time Login Using Google SSO - screenshot 3](/images/intercom/10293811/ecc40269-285d-4f4e-88e2-f9771a362fd6-9a614ee0.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**.
   ![First Time Login Using Google SSO - screenshot 4](/images/intercom/10293811/image-d9d52b5e.png)
   TheLogin page is displayed.
4. Tap **Login with SSO**.
   ![First Time Login Using Google SSO - screenshot 5](/images/intercom/10293811/bccab0d0-afda-4533-91d6-7bbcb81148ee-859f42c1.png)
   The screen with **SSO options** is displayed.
5. Select **Continue with Google**.
   ![First Time Login Using Google SSO - screenshot 6](/images/intercom/10293811/3c0e9197-eecf-4bc4-8bd1-9555262b987a-5bd43c7f.png)
   The confirmation pop-up is displayed.
6. Click **Continue**.
   ![First Time Login Using Google SSO - screenshot 7](/images/intercom/10293811/4d6e53c6-d23a-49e7-a280-6f90d695e990-ac5692f0.png)
   The **Sign in** screen is displayed.
7. Do the following:
   1. Enter **Email ID**.
   2. Click **Next**.
      ![First Time Login Using Google SSO - screenshot 8](/images/intercom/10293811/image-4d282014.png)
      The **Welcome** screen is displayed.
8. Do the following:
   1. Enter **Password**.
   2. Click **Next**.
      ![First Time Login Using Google SSO - screenshot 9](/images/intercom/10293811/image-746a95be.png)
      You are logged in to admin mode in Oloid Connect successfully.
      ![First Time Login Using Google SSO - screenshot 10](/images/intercom/10293811/91a4d3c6-378d-473d-ba83-bf2ad7da1dfd-81a11caa.png)
