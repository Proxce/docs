**Prerequisite:**

Make sure you have a stable internet connection and an Apple ID.

## Steps to download and install Oloid Connect App in iPad

1. Locate the **App Store** on your home screen and tap on it to launch the application.
   ![How to Download and Install the Oloid... - screenshot 1](/images/intercom/8592076/image-f8f4b869.png)
2. Tap on the **Search** icon located at the upper right corner of the screen.
   ![How to Download and Install the Oloid... - screenshot 2](/images/intercom/8592076/8121dc86-2a60-4856-a1c6-d8c3564f64a5-36c449c2.png)
   The Search bar is displayed.
3. In the search bar at the top of the screen, enter **Oloid Connect** and tap on the search result.
   ![How to Download and Install the Oloid... - screenshot 3](/images/intercom/8592076/image-22d8f40e.png)
4. Select **Oloid Connect** ![How to Download and Install the Oloid... - screenshot 4](/images/intercom/8592076/image-6def886f.png) app.
   ![How to Download and Install the Oloid... - screenshot 5](/images/intercom/8592076/cf9d2299-8190-486e-bb02-844310ce779d-8755f5a7.png)
5. Review the app's details, ratings, and user reviews to make sure it's the correct app you want to download.
   ![How to Download and Install the Oloid... - screenshot 6](/images/intercom/8592076/image-ed0cee80.png)
6. Tap the **Get** button located next to the **Oloid Connect** ![How to Download and Install the Oloid... - screenshot 7](/images/intercom/8592076/image-6def886f.png) app icon.
   ![How to Download and Install the Oloid... - screenshot 8](/images/intercom/8592076/5db47996-bdc8-46d7-bb2a-9d6c339eed80-4fd8726a.png)

   <Note>
     **Note:** If prompted, enter your Apple ID password or use Touch ID/Face ID to confirm the download.
   </Note>

   Once the installation is complete, the **Get** button is changed to an **Open** button.
   ![How to Download and Install the Oloid... - screenshot 9](/images/intercom/8592076/50f9a036-07a8-4ba9-84b9-fdf92a695922-5359266d.png)
7. Tap the **Open** button to launch the **Oloid Connect** ![How to Download and Install the Oloid... - screenshot 10](/images/intercom/8592076/image-6def886f.png) app.
   The welcome screen is displayed.
   ![How to Download and Install the Oloid... - screenshot 11](/images/intercom/8592076/image-537556cf.png)
