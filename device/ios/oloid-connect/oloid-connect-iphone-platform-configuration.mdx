## Introduction

Tenant Admin must configure the required components in the **Tenant Admin Portal**, including the Oloid Connect application, endpoint settings, templates, and intent screens. These configurations ensure that Oloid Connect endpoints are properly managed and can perform authentication transactions.

## Platform Configuration

Configuring Oloid Connect for iPhone involves the following components in the **Tenant Admin Portal**:

- Create and configure the **Oloid Connect Application**
- Configure the **Intent Screen**
- Create an **Endpoint Template**
- Configure **Endpoints**

The following sections describe each configuration step and provide links to detailed documentation

### Create and Configure Oloid Connect Application

The **Oloid Connect application** must be created in the Tenant Admin Portal.
This configuration allows Tenant Admins to:

- Define authentication methods
- Configure application behaviour
- Enable integrations
- Manage endpoint access

For detailed configuration steps, refer to
**How to create and configure Oloid Connect application in Tenant Admin Portal**
[https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)

### Configure Intent Screen

The **Intent Screen** defines the user interface displayed on the Oloid Connect endpoint.
Tenant Admins can configure:

- Display message for users
- Authentication prompts
- Transaction instructions
- UI behavior for authentication workflows

This helps ensure users clearly understand how to complete authentication on the endpoint.
For detailed configuration steps, refer to
**How to configure Intent Screen for Oloid Connect app in Tenant Admin Portal**
[https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal](https://oloid.help/en/articles/9937044-how-to-configure-intent-screen-for-oloid-connect-app-in-tenant-admin-portal)

### Create and Configure Endpoint Template

Endpoint Templates allow admin to **standardize endpoint configurations**.
Templates help apply predefined settings such as:

- Application settings
- Authentication configuration
- Integration settings
- UI and device behavior

Using templates helps ensure consistent configuration across multiple endpoints.
For detailed configuration steps, refer to
**How to create and configure Oloid Connect Endpoint Template**
[https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template)

### Configure Endpoint

Configuration of an endpoint in the Tenant Admin Portal allows Tenant Admins manage device settings, appearance, groups, integrations, and transaction behaviour for the Oloid Connect app.

<Note>
  **Note:** Once you pair an endpoint with Oloid Connect application, it gets saved and appears in the Tenant Admin Portal. After pairing, you can configure the endpoint.
</Note>

For detailed configuration steps, refer to
Oloid Connect – How to configure endpoint in the Tenant Admin Portal
[https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal)

### Apply Endpoint Template During Auto-Pair

Endpoint Templates can be applied during the **endpoint auto-pair process**.
For detailed configuration steps, refer to
**How to apply Endpoint Template during Auto-Pair process for Oloid Connect application**
[https://oloid.help/en/articles/12750269-how-to-apply-endpoint-template-during-auto-pair-process-for-oloid-connect-application](https://oloid.help/en/articles/12750269-how-to-apply-endpoint-template-during-auto-pair-process-for-oloid-connect-application)

## Apply Endpoint Template After Auto-Pair

If a template was not applied during pairing, admin can apply it **after the endpoint is paired**.
This allows admin to update endpoint configuration without re-pairing the device.
For detailed configuration steps, refer to
**How to apply Endpoint Template after Auto-Pair for Oloid Connect application**
[https://oloid.help/en/articles/12838474-how-to-apply-endpoint-template-after-auto-pair-for-the-oloid-connect-application-in-the-tenant-admin-portal](https://oloid.help/en/articles/12838474-how-to-apply-endpoint-template-after-auto-pair-for-the-oloid-connect-application-in-the-tenant-admin-portal)
