## Introduction

This document provides instructions to log in to the **Oloid Connect** application using **OKTA Single Sign On (SSO)**.

## Prerequisite

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](https://oloid.help/en/articles/12554658-how-to-download-and-install-the-oloid-connect-app-on-iphone)

## Steps to log in with Okta SSO

1. Launch the **Oloid Connect** ![Login Using Okta SSO - screenshot 1](/images/intercom/13595968/image-6def886f.png) app.
   ![Login Using Okta SSO - screenshot 2](/images/intercom/13595968/image-02ba2845.png)
   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**
   ![Login Using Okta SSO - screenshot 3](/images/intercom/13595968/d77a4a4e-7ec2-412c-8aa8-bb42212fafdb-449c6e31.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**.
   ![Login Using Okta SSO - screenshot 4](/images/intercom/13595968/11823a70-da4b-486f-8b7c-b84e1e0fb7a3-2fff858e.png)
   TheLogin page is displayed.
4. Tap **Login with SSO**.
   ![Login Using Okta SSO - screenshot 5](/images/intercom/13595968/c427d9dd-5e87-4f91-9f1a-2a16927a426e-ee298f35.png)
   The screen with **SSO options** is displayed.
5. Select **Continue with Okta**.
   ![Login Using Okta SSO - screenshot 6](/images/intercom/13595968/image-67256898.png)
   The confirmation pop-up is displayed.
6. Tap **Continue**.
   ![Login Using Okta SSO - screenshot 7](/images/intercom/13595968/2d074a40-6efa-4067-9238-7cb451b43a72-2efc8a41.png)
   The Sign In screen is displayed.
7. Do the following:
   1. Enter **Username**.
   2. Tap **Next**.
      ![Login Using Okta SSO - screenshot 8](/images/intercom/13595968/image-ed2fe06c.png)
8. Enter **Password** in the **Password** field.
9. Tap **Sign In**.
   ![Login Using Okta SSO - screenshot 9](/images/intercom/13595968/fc7cc703-b764-49a1-bc74-a7c57092a7dd-ceda9e11.png)
   You are successfully logged in to Oloid Connect Admin Mode.
   ![Login Using Okta SSO - screenshot 10](/images/intercom/13595968/image-d3833a39.png)
