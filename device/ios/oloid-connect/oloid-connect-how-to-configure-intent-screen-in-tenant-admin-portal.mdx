## Introduction

The intent screen is used in Endpoint Kiosk mode, allowing users to define their actions, such as entering a job code or selecting from multiple available authentication options.

## Steps to configure intent screen

1. Log in to Tenant Admin Portal.
2. Go to **Application** > **Configure** tab > **Configure Intent Screen**.

   <Note>
     **Note:** You must configure the application with which your endpoint is paired.
   </Note>

   ![How to configure Intent screen in... - screenshot 1](/images/intercom/9937044/image-977bb5ba.png)
3. Turn on **Show Intent Screen** toggle.
   ![How to configure Intent screen in... - screenshot 2](/images/intercom/9937044/image-13abca35.png)
4. Configure one of the following:
   1. [Job-Code](#configuring-job-code)
      OR
   2. [Multi button](#configuring-multi-button)
      The Intent screen is configured.

### Prerequisite

You must prepare the Job and Charge Code template before configuring the Job and Charge Code. For more, refer to [Oloid Connect - How to prepare Job and Charge Code Template](https://oloid.help/en/articles/11948333-oloid-connect-how-to-prepare-job-and-charge-code-template)

Select **Job Code** to allow users to enter the job code.

   1. Go to the **Job-Code** section.

### Upload Job Code File

1. In the **Job Codes** section, click or drag your file to the upload area.

   <Note>
     **Note:** The file must be in **XLSX** or **CSV** format.
   </Note>

2. If needed, download the file template:
   - Click **XLSX** to download the Excel template.
   - Click **CSV** to download the CSV template.

     <Note>
       **Note:** Fill out the template with valid job codes before uploading.
     </Note>

     ![How to configure Intent screen in... - screenshot 6](/images/intercom/9937044/image-4f758a5f.png)
     The Job Code file is uploaded successfully.

### Upload Charge Code file

1. In the **Charge Codes** section, click or drag your file to the upload area.

   <Note>
     **Note:** The file must be in **XLSX** or **CSV** format.
   </Note>

2. If needed, download the file template:
   - Click **XLSX** to download the Excel template.
   - Click **CSV** to download the CSV template.

<Note>
  **Note:** Fill out the template with valid Charge codes before uploading.
</Note>

### Configuring Multi-Button

Configure multi-button intent screen based on your requirement

<Note>
  **Note:** Once enabled you must add the required fields else blank intent screen will be displayed.
</Note>

### Multi-Button Intent Screen Configuration

1. Go to the **Job-Code** section on the configuration screen.
2. Select **Multi-Button.**
   ![How to configure Intent screen in... - screenshot 9](/images/intercom/9937044/8e216907-bad1-4257-8e97-b3f31098be3c-e693c03c.png)

Enable the following options based on your requirements:

1. **Choose Departments**: Select this option to enable users to select a department. For detailed information, see Configure Departments.
2. **Conduct Survey**: Select this option to create a survey form after end-of-shift authentication, allowing the user to submit and proceed to the next screen. To create your survey form, see Customize Survey Form.

### Configure Intent Screen

1. Enter a clear title in the **Intent Screen Heading** field. This title appears at the top of the intent screen.
2. Type a short and clear description in the Intent Screen Description field.

![How to configure Intent screen in... - screenshot 10](/images/intercom/9937044/image-256f89bd.png)

The intent screen heading and description are displayed on the preview screen.

**Sample intent screen heading and description for reference**

![How to configure Intent screen in... - screenshot 11](/images/intercom/9937044/image-b18e0233.png)

1. Configure the following as per your requirement:
   1. [Configure Intent Screen Buttons](#configure-intent-screen)
   2. Design Minimum Lunch Break Config
   3. Customize Survey Form
   4. Configure Departments
2. Click **Save** to apply your changes.

The intent screen is configured.

**Configure Intent Screen Buttons**

You can configure at least one and up to six intent buttons.

1. Do the following:
   1. Click **+Add Button** to add an intent button.
      The button section is displayed.
      ![How to configure Intent screen in... - screenshot 12](/images/intercom/9937044/8a8f0eee-459a-4140-9948-28866079c734-87e9f3da.png)
   2. Select **Button Type** from the Button Type dropdown menu.
   3. Enter **Button Label** for different user intents.

      <Note>
        **Note:** The label is displayed on the intent screen. (See [Sample intent screen](#sample-intent-screen-for-job-code))
      </Note>

   4. Click **Save** to apply your changes.

![How to configure Intent screen in... - screenshot 13](/images/intercom/9937044/3045bced-2385-4625-aa1b-7fa1af99092a-4622684b.png)

**Design Minimum Lunch Break Config**

You can configure the minimum lunch break requirements for the user.

<Note>
  **Note:** You must add Start Lunch and End Lunch button type in your intent screen before you configure minimum lunch break.
</Note>

1. **Lunch Break Validation Message**: Enter the message that will be displayed if the minimum lunch break requirement is not met. (See Sample Screen below)
2. **Minimum Lunch Break**: Set the minimum time for a lunch break, specifying hours and minutes. (See Sample Screen below)
3. Click **Save** to apply your changes.

**Customize Survey Form**

You can configure at least one and up to seven survey question options to present to users after they complete an action.

1. Click **+Add Question** to add survey questions to the survey form.
   The enter question text field is displayed.
   1. Enter the survey question in the **Question 1: Enter question** text field.
   2. Click **Save** to apply your changes.

**Design Configure Departments**

You can configure a department section for users during the clock-in and clock-out process.

1. Click **+Add Department** to create a new department.

![How to configure Intent screen in... - screenshot 19](/images/intercom/9937044/ce4e29fb-5eaf-4c03-a70b-8419536961a7-287e8e69.png)

The department detail section is displayed.

![How to configure Intent screen in... - screenshot 20](/images/intercom/9937044/c218ffda-6490-493c-a0c4-dc07c5642ce4-23e88448.png)

1. Configure the department details:
   1. **Department Name**: Enter the department name.
   2. **Department Code**: Enter a department code.
   3. **Clock ID**: Enter the unique clock ID for the sub-department. (Optional)
   4. Click **Save** to apply your changes.

<Note>
  **Note:** Repeat steps 1–2 for each department you want to add.
</Note>
