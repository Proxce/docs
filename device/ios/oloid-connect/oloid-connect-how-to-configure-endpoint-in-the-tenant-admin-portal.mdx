## Introduction

Configuration of an endpoint in the Tenant Admin Portal allows Tenant Admins manage device settings, appearance, groups, integrations, and transaction behaviour for the Oloid Connect app.

<Note>
  **Note:** Once you pair an endpoint with Oloid Connect application, it gets saved and appears in the Tenant Admin Portal. After pairing, you can configure the endpoint.
</Note>

## Prerequisite

You must pair Oloid Connect endpoint. To pair, refer [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).

## Steps to Configure the Endpoint

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Configure Endpoint in the Tenant... - screenshot 1](/images/intercom/10550185/635e3de4-675c-46a8-93f8-37de42aa1b85-013fb478.png)
   The **Endpoints** page is displayed.
3. Select the paired Oloid Connect Endpoint.
   ![How to Configure Endpoint in the Tenant... - screenshot 2](/images/intercom/10550185/image-85d8e665.png)
   The **Endpoint Details** page is displayed.
   ![How to Configure Endpoint in the Tenant... - screenshot 3](/images/intercom/10550185/image-1a843ee1.png)
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Design Configure Tab](#design-configure-tab)
   3. [Configure Transactions Tab](#configure-transactions-tab)
   4. [Configure Health Response Tab](#configure-health-response-tab)

## Configure Details Tab

1. Edit **Endpoint Name** if required.
2. Enter **Endpoint Description**. (Optional)
3. Select **Time Zone** from the dropdown list. (Optional)

   <Note>
     **Note:** If time zone is not set for the Endpoint, it automatically uses the application's default time zone.
   </Note>

4. Click **Save**.
   ![How to Configure Endpoint in the Tenant... - screenshot 4](/images/intercom/10550185/image-d7874df4.png)
   The Details tab is configured successfully.
   ![How to Configure Endpoint in the Tenant... - screenshot 5](/images/intercom/10550185/image-444d1e14.png)

## Design Configure Tab

Configure the following:

- [Endpoint Settings](#endpoint-settings)
- [Groups](#groups)
- [Web Button](#web-button)
- [Integration](#integration)
- [Health Setup](#health-setup)

### Endpoint Settings

1. Turn on **Use Endpoint in Admin Mode Only** toggle to restrict the endpoint device to Admin mode.
2. Turn on **Capture Location** toggleto activate location capture on the endpoint for each transaction.

   <Note>
     **Note:** The **Location Permission** of the device must be enabled to make the feature functional.
   </Note>

3. Turn on **Generate Debug Logs** toggle to activate log generation for the endpoint until disabled.
4. Turn on **Landscape Mode for Preview Screen** toggle to change the user preview screen from portrait to landscape mode.
5. Click **Save**.
   ![How to Configure Endpoint in the Tenant... - screenshot 6](/images/intercom/10550185/e5c027d9-08bb-43fa-98cd-407f6e05799d-c4de6965.png)
   The Endpoint setting is configured successfully.
   ![How to Configure Endpoint in the Tenant... - screenshot 7](/images/intercom/10550185/image-392e310c.png)

### Groups

1. Turn on **One Face/User (On Device FR)** toggle to ensure that only one facial image of each user is stored on the device as a reference for On-device Transaction.
   ![How to Configure Endpoint in the Tenant... - screenshot 8](/images/intercom/10550185/2d7782d2-a7c6-483d-ac1c-ae50b533eff3-ef1696f1.png)
2. Click **+ Add Group**.
   ![How to Configure Endpoint in the Tenant... - screenshot 9](/images/intercom/10550185/image-0f34bcb3.png)
   The **Add Group** pop-up box is displayed.
3. Select group(s) in **Add Group** field.
4. Click **Save**.
   ![How to Configure Endpoint in the Tenant... - screenshot 10](/images/intercom/10550185/d2daf6f8-a70d-4041-8f39-3fa01f9fc262-5ee5d0aa.png)
   The Group is added successfully.
   ![How to Configure Endpoint in the Tenant... - screenshot 11](/images/intercom/10550185/image-d28c99df.png)

### Web Button

1. Turn on **Web Button** toggle to display the Web Button on the endpoint preview screen. This button allows users to view transactions.
   1. In the **URL** field, enter the complete URL of the website where users will review punch data.

      <Note>
        **Note:** You have to enter the URL of the website where the user will review the punches.
      </Note>

   2. In the **Timeout** field, enter the delay (in minutes) before the URL launches.
2. Turn on **Show only on Auth** toggle to display the Web Button only after the user is successfully authorized. (Optional)
3. Turn on **Auto Launch** toggle to automatically launch the web button and view transaction. (Optional)
4. Click **Save**.
   ![How to Configure Endpoint in the Tenant... - screenshot 12](/images/intercom/10550185/d15de618-45e1-450f-9736-6b3bf0756ca6-0ecdd07e.png)
   The Web Button is configured successfully.
   ![How to Configure Endpoint in the Tenant... - screenshot 13](/images/intercom/10550185/image-20d42045.png)

### Integration

You can **Enable Integrations** to perform cloud-based actions (Optional). For more, Contact [Oloid Support](mailto:support@oloid.ai)

![How to Configure Endpoint in the Tenant... - screenshot 14](/images/intercom/10550185/0e5493e6-ddb1-4461-bef9-4d5157b21e2b-c90148e9.png)

### Health Setup

1. Enter **Server Name**.
2. Enter URL of the server in **Add URL that needs to be monitored** field.
3. Click **Add**.
   The monitored URLs will appear in the list below, with columns for **Server Name** and **URL**.

   <Note>
     **Note:** Configure the settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

![How to Configure Endpoint in the Tenant... - screenshot 15](/images/intercom/10550185/0addc711-6730-411f-81c8-f487cd69eb9b-abee4fe2.png)

The Server is added along with its URL successfully.

## Configure Transactions Tab

The Transactions tab allows you to view detailed user transactions. You can monitor transaction statuses and filter results based on success or failure.

![How to Configure Endpoint in the Tenant... - screenshot 16](/images/intercom/10550185/image-d71265b1.png)

## Configure Health Response Tab

1. Turn on **Share Endpoint Logs** toggle to share logs.
2. Turn on **Relaunch** toggle to automatically apply changes made on the Tenant Admin Portal to the Oloid Connect app without manually closing or restarting the app.
3. Click **Check Health** to initiate a health check successfully.

![How to Configure Endpoint in the Tenant... - screenshot 17](/images/intercom/10550185/5f12bbb2-9842-4a24-a7e3-bb7b089feb99-d87aaf60.png)

In this section, you can see the endpoint status, check health of the endpoint and configure health alert. For more information on health alert, see**[How to configure health alert for an endpoint](https://oloid.help/en/articles/8245679-how-to-add-health-alerts-in-the-endpoint)**.
