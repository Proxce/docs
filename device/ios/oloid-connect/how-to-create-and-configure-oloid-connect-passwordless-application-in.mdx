## Introduction

This document explains how to **create and configure an Oloid Connect application for passwordless login** in the Tenant Admin Portal.

## Prerequisite

You must have admin access to **Tenant Admin Portal.**

## Steps to create and configure Connect for Passwordless application

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right.
   ![How to Create and Configure Oloid... - screenshot 1](/images/intercom/9896977/image-6cf3c393.png)
   The **Create New Application** pop-up box is displayed.
3. On the pop-up box, do the following:
   1. Enter **Application Name** and select **Application Type** as Oloid Verify.
   2. Click **Create**.
      ![How to Create and Configure Oloid... - screenshot 2](/images/intercom/9896977/image-0c98cb5c.png)
      The **Oloid Connect for passwordless** application is created and the configuration page is displayed.
      ![How to Create and Configure Oloid... - screenshot 3](/images/intercom/9896977/image-387fba31.png)
4. Configure the following:
   1. [Configure Details tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_1819a9e861)
   2. [Authenticator tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_e9f9194b90)
   3. [Configure tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_a2c5538f8f)
   4. [Design Theme tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_1509b17f13)
   5. [Configure Health Setup tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_6e50d72a2b)
   6. [Configure Connections tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_3d81b1d8a6)
   7. [Configure Integrations tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_3d81b1d8a6)
   8. [Configure Exception tab](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify#h_7d8a48a2ae)
5. Click **Save** after each action to save your configuration.
   The application is created and configured.

   <Note>
     **Note:** These are one-time settings and all the default settings are recommended.
   </Note>

## Configure Authenticator Tab

You may enable one or more credential options based on your requirements. **Face** is enabled by default.

#### Face

To use face as a credential, enable Face toggle.

![How to Create and Configure Oloid... - screenshot 5](/images/intercom/9896977/image-cdaf6b77.png)

Do the following:

1. Select **FR Mode** from the FR Mode dropdown. select the preferred face recognition mode:(if required)
   - **Hybrid**: Combines cloud and on-device facial recognition.
   - **Cloud**: Uses cloud-based facial recognition.
   - **On Device**: Uses on-device facial recognition.(if required)
2. **On-Device Model**: Edit this field if required. (Optional)
3. Choose a liveness mode:
   - Enable **Hardware Liveness** in devices with dedicated hardware sensors for higher accuracy.
   - Enable **Software Liveness** to use software-based analysis to verify the captured face image authenticity.

     <Note>
       **Note:** Software Liveness verification may take longer to complete compared to Hardware Liveness verification.
     </Note>

     By default Hardware Liveness is enabled.
4. Adjust the following settings for Software Liveness:
   - **Min Liveness Probability**:
     - Determines the probability threshold to classify an image as live.
     - Default: 0.5
   - **Min Liveness Quality**:
     - Defines the minimum acceptable quality for images used in liveness checks.
     - Default: 0.1
5. Click **Save**.

<Note>
  **Note:** The parameters are pre-configured. This is done by Oloid admin.
</Note>

#### Badge ID

To use Badge ID as credential, enable **Badge ID**. Select **Badge Type(s)** from the dropdown and click **Save**.

![How to Create and Configure Oloid... - screenshot 6](/images/intercom/9896977/image-5bcd040f.png)

#### QR Code

To use QR Code credential, enable **QR Code**.

1. Enable **QR Code** option.
2. Enable **Show Camera Flip button** to allow users to switch between the front and rear cameras.
   This option displays a camera flip button on the preview screen during QR code scanning.
- Under **Default camera selection**, select a camera option:
  - **Front Camera** (default)
  - **Rear Camera**

![How to Create and Configure Oloid... - screenshot 7](/images/intercom/9896977/67df4478-597e-46e3-8c12-f8c4159d6ae6-dbb2e86d.png)

#### PIN

To use PINcredential, enable **PIN**.

**Enable PIN Selfie**  to capture and save a selfie every time a user enters their PIN.

<Note>
  **Note:** The system will automatically take a photo (selfie) during each PIN transaction.
</Note>

![How to Create and Configure Oloid... - screenshot 8](/images/intercom/9896977/image-1ab305f1.png)

#### NFC/ID

To use NFC credential, enable **NFC/ID** toggle.

![How to Create and Configure Oloid... - screenshot 9](/images/intercom/9896977/image-0584e517.png)

### Configure Factor Sequence

The **Factor Sequence** section allows to define the order of authentication factors used for multi-factor authentication (MFA).

In the **Factor Sequence** section, do the following:

- Enable **Factor Sequence** toggle.
- Select **Factor Sequence** from the drop-down list. To create and configure Factor Sequence refer to [How to create and configure Factor Sequence](https://oloid.help/en/articles/9699393-how-to-create-and-configure-factor-sequence#h_acfe4fb747).

  <Note>
    **Note:** The Factor Sequence feature is applicable only when using multi-factor authentication (MFA).
  </Note>

- Click **Save**.

### Configure Settings Tab

1. **Enable Offline Mode**: Enable this option to allow users to perform authentication even without network connectivity.
2. **Use Group Authorization**: Enable this option to download groups so that users and endpoints of the same group are downloaded for authorization in offline mode.
3. **Authentication Timeout**: Set an appropriate timeout value to determine the duration the auth screen waits for the user to begin the authentication process before being redirected to the initial screen.
4. **Apply Endpoint Template**: Use this option to choose a template that will be applied automatically when pairing an endpoint.
5. **Show Clock on Intent/Auth Screens**: Turn on this toggle to show the clock on all screens Intent, Authentication selection, and Identity verification.
6. **Enable Landscape Mode for Preview Screen:** Turn on this toggle to change the user preview screen from portrait to landscape mode.

### Customize Messages Tab

1. **Enable Show Action Status**: Enable this option to display the action status of the user's facial transaction. You can customize the messages your user sees on the Oloid Verify App.
   1. Select **Show default message from the integration** to show success or error messages from the system after user logs in.
   2. Select **Auto-dismiss the error prompt after** to enter the preferred time (in seconds).
      - **Action Initialization Label**: Enter Action InitializationLabel in the text field.
      - **Action Success Label**: Enter Action Success Label in the text field.
      - **Action Failure Label**: Enter Action Failure Label in the text field.
2. Edit **Authentication Failure Error Message** field (Optional).

### Configure Passwordless

The Configure Passwordless feature allows you to enable and set up passwordless authentication for endpoints.

![How to Create and Configure Oloid... - screenshot 16](/images/intercom/9896977/9a00eeb3-333f-4d75-b217-bc334f0c0d3b-d726abb0.png)

1. Turn on **Enable Passwordless Config** toggle to switch the endpoint's functionality to **Passwordless Login**.

   <Note>
     **Note:** When enabled, the **Passwordless SSO URL** toggle is automatically turned on.
   </Note>

   1. **Passwordless SSO URL:**

      <Note>
        **Note:** When you enable **Passwordless Config**, the **Passwordless SSO URL** toggle is automatically enabled.
      </Note>

      1. Enter all the URLs in the  **URL** field.
         ![How to Create and Configure Oloid... - screenshot 17](/images/intercom/9896977/9414d448-da9f-4165-aba9-2fa2d887e330-4d4c4411.png)
   2. **Workday Punch Integration:**
      1. Turn on **Workday Punch Integration** toggle.
      2. In the **Workday Punch Integration** field, enter the URL.
         ![How to Create and Configure Oloid... - screenshot 18](/images/intercom/9896977/5a847f47-5928-41ab-9170-23886bab3ef0-2e380eb4.png)
   3. Set the desired **Timeout** duration (in minutes and seconds) after which the screen automatically times out.
   4. Click **Save**.
      ![How to Create and Configure Oloid... - screenshot 19](/images/intercom/9896977/dcabfcbd-f801-4e0b-99cc-c6ccbe74eed8-b1ac677d.png)
