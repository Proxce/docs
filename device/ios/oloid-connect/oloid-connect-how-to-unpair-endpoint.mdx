## Introduction

This document explains how to unpair an endpoint using the **Oloid Connect** application.

## Prerequisites

- The Oloid Connect endpoint must be paired. For more, refer to [Oloid Connect – How to Pair an Endpoint](https://oloid.help/en/articles/8616268-oloid-connect-how-to-pair-an-endpoint)
- You must have Tenant Admin or Supervisor access.

## Steps to Unpair Endpoint

1. Launch the **Oloid Connect** ![How to Unpair Endpoint - screenshot 1](https://downloads.intercomcdn.com/i/o/e4gi378c/2578264040/7928c76f5505562761eb2814725c/image.png?expires=1790294400&signature=98f722a0353c06ba956c29dc34c2604c0816c36dfdd219b6077434183e5a7d27&req=diUgHst4mYFbWfMW3nq%2BgTP%2Fb2hiIFmP7gBuGa2VAsrYHdAGxk5c1s%2FH1mnL%0A6HeACC%2F1ZHRXjxoKt7AxYpiyf98%3D%0A) **App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint).
   </Note>

   ![How to Unpair Endpoint - screenshot 2](/images/intercom/16159084/image-037a8d73.png)
2. Log in to Admin mode. For more refer to[Oloid Connect - How to Log in to Admin Mode](https://oloid.help/en/articles/8671144-how-to-log-in-to-admin-mode-in-the-oloid-connect-app)
   The **Users** page is displayed.
3. Tap **Settings**.
   ![How to Unpair Endpoint - screenshot 3](/images/intercom/16159084/image-bb444972.png)
   The **Settings** page is displayed.
4. Tap **Unpair**.
   ![How to Unpair Endpoint - screenshot 4](/images/intercom/16159084/image-7128bcd5.png)
   The **Confirm Unpair** pop up box is displayed.

Tap **Unpair.**

![How to Unpair Endpoint - screenshot 5](/images/intercom/16159084/image-fd72b5b8.png)

The Success pop up is displayed and Oloid Connect Endpoint is unpaired successfully.

![How to Unpair Endpoint - screenshot 6](/images/intercom/16159084/image-2dbcc507.png)
