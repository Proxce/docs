**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to add user's face credential.

<Note>
  **Note:** If user consent is enabled in the connection, the app will ask for permission before uploading the picture.
</Note>

## Steps to add Face

1. Launch the **Oloid Connect** ![Oloid Connect - Add Face - screenshot 1](/images/intercom/8536726/image-6def886f.png) app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

2. The **Settings** page is displayed.
   ![Oloid Connect - Add Face - screenshot 2](/images/intercom/8536726/image-6c2feb88.png)
3. Tap **Users** on the menu at the bottom of the screen.
   ![Oloid Connect - Add Face - screenshot 3](/images/intercom/8536726/c9b6e886-ef63-4347-b476-6365dccd406d-bd909cb2.png)
   The **Users** page with list of users is displayed.
4. Tap on the selected user to view details, or search for a user using the search bar at the top.
   ![Oloid Connect - Add Face - screenshot 4](/images/intercom/8536726/f4cfd404-3251-4290-9302-d9cc154da41a-d9d07a48.png)
   The Details screen is displayed.
5. Tap **Submit Consent**.
   ![Oloid Connect - Add Face - screenshot 5](/images/intercom/8536726/3dc85003-3fe5-4046-b5e8-2ef42b485546-4206d281.png)
   Consent form page is displayed.
6. Tap **Accept.**
   ![Oloid Connect - Add Face - screenshot 6](/images/intercom/8536726/79a02754-8eae-4d77-88dc-48bfda741ceb-e38c492b.png)
7. Tap **Face** tab, then do the following:
   **a.** Tap **+Add Face.**
   **b.** Place your face within the oval frame on the screen to confirm your identity.
   ![Oloid Connect - Add Face - screenshot 7](/images/intercom/8536726/ef308f69-f387-4ae2-96fc-7740629a7c1e-0f771c77.png)
   The pop-up screen appears with the captured image.
8. Do one of the following:
   1. Tap **Yes- Submit** to submit the image.
   2. Tap **No- Retake** to click the image again.
      ![Oloid Connect - Add Face - screenshot 8](/images/intercom/8536726/image-fba07d45.png)
      The face credential is submitted successfully.

<Note>
  **Note:** You can add a maximum of five faces per user.
</Note>

Your face should be visible in the camera, else it might get rejected. It is recommended to avoid wearing things that cover your facial features such as sunglasses, masks, headbands etc. Refer to Oloid's [Image Reference Guide](https://oloid.help/en/articles/9886279-guidelines-for-face-enrollment-onboarding-images) to see guidelines on face onboarding images.
