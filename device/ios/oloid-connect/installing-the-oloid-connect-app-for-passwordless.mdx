## Introduction

This document explains how to install the **Oloid Connect app** for passwordless authentication.

## Prerequisites

- You should be a Tenant Admin and Supervisor.
- Application, Connections, and template (optional) must be configured in Tenant Admin Portal.

## Device Compatibility

Ensure that your device is compatible with the Oloid Connect App. See, [Oloid Connect Passwordless - Hardware and Software Requirements](https://oloid.help/en/articles/12320265-oloid-connect-passwordless-hardware-and-software-requirements)

## Internet Connection

Ensure that the device is connected to the internet using Wi-Fi or mobile data, for the app installation and setup.

## Steps to install and setup the Admin Mode

1. Go to **App Store** and download **Oloid Connect App**.
   For detailed information see, **[How to download Oloid Connect application](https://oloid.help/en/articles/8592076-how-to-download-oloid-connect-application).**
2. Install the application and launch it after the installation is complete.
   The **Welcome** screen is displayed.
   ![Installing the Oloid Connect App for... - screenshot 1](/images/intercom/8400084/image-d9832467.png)
3. Tap **Pair as Supervisor.**
   ![Installing the Oloid Connect App for... - screenshot 2](/images/intercom/8400084/ecc40269-285d-4f4e-88e2-f9771a362fd6-9a614ee0.png)
   The Welcome screen is displayed.
4. Enter **Tenant Name** > tap **Next**.
   ![Installing the Oloid Connect App for... - screenshot 3](/images/intercom/8400084/image-d9d52b5e.png)
   The **Login** page is displayed.
5. Do the following:
   1. Enter your email ID in the **Email** text field.
   2. Enter your password in the **Password** text field.
   3. Tap **LOGIN**.

      <Note>
        **Note:** You may also log in using SSO options. For more, refer to[Log in Using SSO](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app#h_6a328cd429)
      </Note>

      ![Installing the Oloid Connect App for... - screenshot 4](/images/intercom/8400084/d348fa09-f559-4ea2-9fce-b86c01ad6e3e-522bee6c.png)
      The **Settings** page is displayed.
6. Pair the endpoint. For more information, refer to [How to pair the endpoint in Oloid Connect app](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)
   ![Installing the Oloid Connect App for... - screenshot 5](/images/intercom/8400084/f12212cf-e367-49cd-83e0-4d9da65a4480-26f494bd.png)
   The settings are saved and the Device Setup success message is displayed.
   ![Installing the Oloid Connect App for... - screenshot 6](/images/intercom/8400084/image-c66d3ab5.png)

   <Note>
     **Note:** Once the iPad is successfully paired, other settings can be configured in the Tenant Admin Portal.
   </Note>

   The application prompts you to log out of Admin mode.
7. Do one of the following:
   1. Tap **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to capture live Images for facial transactions.

      <Note>
        **Note:** To go back to admin mode, **double-click with two fingers** on preview mode and tap **Yes- To Continue**.
      </Note>

   2. Tap **No** to stay logged in to the admin mode.

![Installing the Oloid Connect App for... - screenshot 7](/images/intercom/8400084/image-259ba45e.png)

You can perform the following actions without pairing the endpoint:

- [Add Face](https://oloid.help/en/articles/8536726-oloid-connect-add-face)
- [Add QR Code](https://oloid.help/en/articles/8764539-oloid-connect-add-qr-code)
- [Set PIN](https://oloid.help/en/articles/8768778-oloid-connect-set-pin)
- [Add NFC/ID](https://oloid.help/en/articles/10304065-oloid-connect-add-nfc-id)

#### Common Installation Issues

Ensure your device meets the app's requirements.

- Check your internet connection during installation.
- Verify that you've granted the necessary permissions to the app.
