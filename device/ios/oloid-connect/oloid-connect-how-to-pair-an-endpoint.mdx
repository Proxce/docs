## Introduction

This document explains how to pair an endpoint using the **Oloid Connect** application. Pairing connects the endpoint to the Oloid Connect application in the Tenant Admin Portal and prepares the endpoint for authentication and transaction activities.

## Prerequisite

- You must have Admin or Supervisor access.
- You must install Oloid Connect and complete the Admin setup before pairing an endpoint. For more, refer to [How to Download and Install the Oloid Connect App](https://oloid.help/en/articles/8592076-how-to-download-and-install-the-oloid-connect-app)

## Steps to Pair an Endpoint

1. Log in to **Oloid Connect** ![Oloid Connect – How to Pair an Endpoint - screenshot 1](/images/intercom/8616268/image-6def886f.png) app.
   The **Welcome** screen is displayed.
   ![Oloid Connect – How to Pair an Endpoint - screenshot 2](/images/intercom/8616268/image-43da21ef.png)

   <Note>
     **Note:** You must Complete the Admin setup**.** For more information, refer to[Oloid Connect - Admin Setup](https://oloid.help/en/articles/8592262-oloid-connect-admin-setup)
   </Note>

   The Settings page is displayed on a successful login.
2. Do the following:
   1. Add **Template** (optional).

      <Note>
        **Note:** Templates allow Admins to configure Endpoints at scale. A template has to be created in Tenant Admin Portal. For more, refer to [How to create and configure Oloid Connect endpoint template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template)
      </Note>

   2. Enter **Endpoint Name**.
   3. Select **Application Name** from **Application Name** dropdown list.
   4. Tap **Pair**.
      ![Oloid Connect – How to Pair an Endpoint - screenshot 3](/images/intercom/8616268/1545f34a-2c71-4865-80c9-bc979c2614ef-902257cb.png)
      The settings are saved and endpoint is successfully paired.
      ![Oloid Connect – How to Pair an Endpoint - screenshot 4](/images/intercom/8616268/image-f3634569.png)
      The application prompts you to log out of Admin mode.
3. Do one of the following:
   1. Tap **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to do the transactions.
   2. Tap **No** to stay logged in to the admin mode.
      ![Oloid Connect – How to Pair an Endpoint - screenshot 5](/images/intercom/8616268/image-04056200.png)
