**Introduction**

The Shared Credential feature in the Oloid Connect app allows Tenant Admins and Supervisors to assign shared credentials to users.

## Steps to add Shared Credential

1. Launch the **Oloid Connect** ![How to add Shared Credential to a User... - screenshot 1](/images/intercom/10307929/image-6def886f.png) app and login with the provided options.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log into the admin mode of Oloid Connect App as a Supervisor/Admin](https://oloid.help/en/articles/8671144-how-to-log-into-the-admin-mode-of-oloid-connect-app-as-a-supervisor-admin).
   </Note>

   ![How to add Shared Credential to a User... - screenshot 2](/images/intercom/10307929/image-e14a56f2.png)
2. The **Settings** page is displayed.
   ![How to add Shared Credential to a User... - screenshot 3](/images/intercom/10307929/image-70462c77.png)
3. Tap **Users** on the menu at the bottom of the screen.
   ![How to add Shared Credential to a User... - screenshot 4](/images/intercom/10307929/c9b6e886-ef63-4347-b476-6365dccd406d-77588022.png)
   The **Users** page with list of users is displayed.
4. Tap on the selected user to view details.
   ![How to add Shared Credential to a User... - screenshot 5](/images/intercom/10307929/f4cfd404-3251-4290-9302-d9cc154da41a-a2ddd5c1.png)
   The user **Details** screen is displayed.
5. Go to **Password** > tap **Add Shared Credential**.
   ![How to add Shared Credential to a User... - screenshot 6](/images/intercom/10307929/acb9f48b-d21e-43a6-8fee-0613cea44784-f95d84c0.png)
6. Select **Credential(s)** from the list.
7. Click **Assign**.
   ![How to add Shared Credential to a User... - screenshot 7](/images/intercom/10307929/74d6946b-9201-4d9d-9c18-c72e2415ec53-8728011e.png)
   The **Shared Credentials** are added and listed in the Password tab.
   ![How to add Shared Credential to a User... - screenshot 8](/images/intercom/10307929/54578843-e600-4a20-8f7b-58c4380e5ccc-cf465b38.png)
