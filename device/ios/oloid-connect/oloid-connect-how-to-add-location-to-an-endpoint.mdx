## Introduction

The Oloid Connect app allows Tenant Admins to assign a location to an endpoint during the setup process. Adding a location ensures accurate tracking and management of endpoints within your organization, enabling the system to associate activity and transactions with the correct physical site.

## Prerequisite

- You should be a Tenant Admin and Supervisor.
- You must download the Oloid Connect app. To download refer [How to Download and Install the Oloid Connect App](https://oloid.help/en/articles/8592076-how-to-download-and-install-the-oloid-connect-app-in-ipad).

## Steps to add location to an endpoint

1. Launch the **Oloid Connect** app.
   ![How to Add Location to an Endpoint - screenshot 1](/images/intercom/8601123/image-d4476220.png)
   The Welcome screen is displayed.
2. Tap **Pair as Supervisor.**
   ![How to Add Location to an Endpoint - screenshot 2](/images/intercom/8601123/ecc40269-285d-4f4e-88e2-f9771a362fd6-2acb4e46.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name,** then tap **Next**.
   ![How to Add Location to an Endpoint - screenshot 3](/images/intercom/8601123/image-68b311a7.png)
   The **Login** screen is displayed.
4. Do the following:
   1. Enter your email ID in the **Email** text field.
   2. Enter your password in the **Password** text field.
   3. Tap **LOGIN**.
      ![How to Add Location to an Endpoint - screenshot 4](/images/intercom/8601123/c0b30f46-b1ee-496c-b215-3e4d2277148a-ba7e03d4.png)

      <Note>
        **Note:** If your face is added to the Tenant Admin Portal as a Tenant Admin, you can tap on **Log in with Face** to log in using your face.
      </Note>

      You can also use **Log in using SSO** to continue with [Google](https://oloid.help/en/articles/10293811-how-to-log-in-with-google-sso-in-oloid-connect-admin-mode), [Microsoft](https://oloid.help/en/articles/10293864-how-to-log-in-with-microsoft-sso-in-oloid-connect-admin-mode), and [Okta](https://oloid.help/en/articles/10345413-oloid-connect-how-to-log-in-with-okta-sso).
      ![How to Add Location to an Endpoint - screenshot 5](/images/intercom/8601123/image-8c253772.png)
      The location access pop-up box is displayed.
5. On the pop-up box, select an option:
   - **Allow Once:** Each time you open the app, it will request access your location.
   - **Allow While Using App:** The app can access your location only when you are actively using it.
   - **Don't Allow:** The app cannot access your location, even while you are using it.

     <Note>
       **Note:** You can also update location from the device settings. To update refer [How to update Location for Oloid Connect](https://oloid.help/en/articles/10288412-how-to-update-location-for-oloid-connect).
     </Note>

     ![How to Add Location to an Endpoint - screenshot 6](/images/intercom/8601123/image-3a33256c.png)

     <Note>
       **Note:** You can now log in to the **Tenant Admin Portal** to check the location added to the specific endpoint.
     </Note>
