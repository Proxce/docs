## Introduction

To use the Oloid Connect app, you must first create and configure the application in the Tenant Admin Portal. This includes creating and managing the application, connection, and template(optional). Once configured, the app can be used to manage user authentication and access.

## Prerequisites

You must have Tenant admin access to the Tenant Admin Portal.

## Steps to Create and Configure Oloid Connect application

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right.
   ![How to Create and Configure Application... - screenshot 1](/images/intercom/8655943/image-5be7319e.png)
   The **Create New Application** pop-up box is displayed.
3. On the pop-up box, do the following:
   1. Enter **Application Name** and select **Application Type** as Oloid Verify.
   2. Click **Create**.
      ![How to Create and Configure Application... - screenshot 2](/images/intercom/8655943/image-383b9f7c.png)
      The **Oloid Connect** application is created and the **Details** page is displayed.
      ![How to Create and Configure Application... - screenshot 3](/images/intercom/8655943/image-d6992407.png)
4. Configure the following:
   1. [Configure Details tab](#configure-details-tab)
   2. [Authenticator tab](#configure-authenticator-tab)
   3. [Design Theme tab](#design-theme-tab)
   4. [Configure tab](#design-configure-tab)
   5. [Configure Health Setup tab](#configure-health-setup-tab)
   6. [Configure Connections tab](#configure-connections-tab)
   7. [Configure Integrations tab](#configure-integrations-tab)
5. Click **Save** after each action to save your configuration.
   The application is created and configured.

   <Note>
     **Note:** These are one-time settings and all the default settings are recommended.
   </Note>

### Configure Details Tab

1. Modify **Application name** (if required).
2. Add **Description** (Optional).
3. Set **Time-zone** (Optional).
4. Set **Idle Screen Soft Time Limit** (Optional).
5. Set **Idle Screen Hard Time Limit** (Optional).
6. Click **Save**.
   ![How to Create and Configure Application... - screenshot 4](/images/intercom/8655943/image-54b4a54a.png)

### Configure Authenticator Tab

You may enable one or more credential options based on your requirements. **Face** is enabled by default.

### Face

To use face as a credential, enable **Face** option.

![How to Create and Configure Application... - screenshot 5](/images/intercom/8655943/image-8df1b069.png)

Do the following:

1. Select **FR Mode** from the FR Mode dropdown. select the preferred face recognition mode:(if required)
   - **Hybrid**: Combines cloud and on-device facial recognition.
   - **Cloud**: Uses cloud-based facial recognition.
   - **On Device**: Uses on-device facial recognition.(if required)
2. **On-Device Model**: Edit this field if required. (Optional)
   ![How to Create and Configure Application... - screenshot 6](/images/intercom/8655943/image-285a629e.png)
3. Enable **Take Re-consent During Transactions** toggle to prompt users with invalid consent to re-consent during each face authentication until they provide consent.
   ![How to Create and Configure Application... - screenshot 7](/images/intercom/8655943/image-9d5783c8.png)
4. Select one of the following liveness modes:
   1. Select **Hardware Liveness** in devices with dedicated hardware sensors for higher accuracy.
   2. Select **Software Liveness** to use software-based analysis to verify the captured face image authenticity.

      <Note>
        **Note:** Software Liveness verification may take longer to complete compared to Hardware Liveness verification.
      </Note>

      By default Hardware Liveness is enabled.

Adjust the following settings for Software Liveness:

- **Min Liveness Probability**:
  - Determines the probability threshold to classify an image as live.
  - Default: 0.5
- **Min Liveness Quality**:
  - Defines the minimum acceptable quality for images used in liveness checks.
  - Default: 0.1
    ![How to Create and Configure Application... - screenshot 8](/images/intercom/8655943/df972e3c-74a6-4589-b81b-26ca0d119105-f782a373.png)

c. Select **Software Liveness On- Device.**

- **Min. Liveness Confidence:** Set the minimum confidence value for the on-device liveness check. Select a value between **0.3 and 1**. A higher value applies a stricter liveness check and may require better lighting and a clearer face capture.
5. Click **Save**.
   ![How to Create and Configure Application... - screenshot 9](/images/intercom/8655943/image-ea2a2013.png)

<Note>
  **Note:** The parameters are pre-configured. This is done by Oloid admin.
</Note>

### QR Code

To use QR Code credential, enable **QR Code**.

1. enable **QR Code** option.
   By default, the front camera opens for QR code scanning.
2. Enable **Show Camera Flip button** to allow users to switch between the front and rear cameras.
   This option displays a camera flip button on the preview screen during QR code scanning.
- Under **Default camera selection**, select a camera option:
  - **Front Camera** (default)
  - **Rear Camera**

![How to Create and Configure Application... - screenshot 11](/images/intercom/8655943/67df4478-597e-46e3-8c12-f8c4159d6ae6-3e0f313d.png)

### PIN

**Enable PIN Selfie**  to capture and save a selfie every time a user enters their PIN.

<Note>
  **Note:** The system will automatically take a photo (selfie) during each PIN transaction.
</Note>

### Configure Factor Sequence

The **Factor Sequence** section allows to define the order of authentication factors used for multi-factor authentication (MFA).

In the **Factor Sequence** section, do the following:

- Enable **Factor Sequence** toggle.
- Select **Factor Sequence** from the drop-down list. To create and configure Factor Sequence refer to [How to create and configure Factor Sequence](https://oloid.help/en/articles/9699393-how-to-create-and-configure-factor-sequence#h_acfe4fb747).

  <Note>
    **Note:** The Factor Sequence feature is applicable only when using multi-factor authentication (MFA).
  </Note>

- Click **Save**.
  ![How to Create and Configure Application... - screenshot 14](/images/intercom/8655943/image-13636df3.png)

### Design Theme Tab

The **Theme** tab allows you to customize the appearance of the Oloid Connect app login page. (Optional)

Do the following:

1. Go to the **Theme** tab.
2. Configure the following settings:
   - **Customer Logo:** Add the customer logo. The supported formats are SVG and PNG. The maximum file size is 1 MB and the recommended maximum dimensions are 264 × 72 pixels.
   - **Background Image:** Add the background image used on the sign-in page, error page, and emails. The supported formats are JPG, PNG, and JPEG, with a maximum file size of 2 MB.

     <Note>
       **Note:** Select **Solid Background** to use a solid background instead of an image.
     </Note>

   - **Primary Color/Button Default:** Enter the hex color code for the default background color of primary buttons.
   - **Secondary Color/Hover State:** Enter the hex color code for the hover state of primary buttons and the default background color of secondary buttons.
   - **Widget Header/Footer Color:** Enter the hex color code for the background of the widget header and footer.
   - **Footer Text Color:** Enter the hex color code for the footer text in the Login App.
     ![How to Create and Configure Application... - screenshot 15](/images/intercom/8655943/image-f895e15f.png)

### Configure Settings Tab

1. **Enable Offline Mode**: Enable this option to allow endpoint transactions to be processed even without network connectivity.
   ![How to Create and Configure Application... - screenshot 17](/images/intercom/8655943/image-27e76ab9.png)
2. **Use Group Authorization**: Enable this option to download groups so that users and endpoints of the same group are downloaded for authorization in offline mode.
   ![How to Create and Configure Application... - screenshot 18](/images/intercom/8655943/image-32f5d6c3.png)
3. **Authentication Timeout**: Set an appropriate timeout value to determine the duration the application waits for the user to begin the authentication process before being redirected to the initial screen.
   ![How to Create and Configure Application... - screenshot 19](/images/intercom/8655943/image-1c20c9b7.png)
4. **Apply Endpoint Template**: Use this option to choose a template that will be applied automatically when connecting an endpoint device.
   ![How to Create and Configure Application... - screenshot 20](/images/intercom/8655943/image-710c78b9.png)
5. **Enable Location Mandate** toggle. In the **Geo-fencing Radius** section, configure the allowed authentication distance. For more, refer to [How to Enable Location Mandate and configure Geo-fencing Radius](https://oloid.help/en/articles/15869578-oloid-connect-how-to-enable-location-mandate-and-configure-geo-fencing-radius-in-tenant-admin-portal)
   ![How to Create and Configure Application... - screenshot 21](/images/intercom/8655943/image-86ff93be.png)
6. **Show Clock on Intent/Auth Screens**: Turn on this toggle to show the clock on all screens Intent, Authentication selection, and Identity verification.

   <Note>
     **Note:** To display the time in 24-hour format, select Check box **When enabled, time is displayed in 24-hour format based on the selected application time zone**.
   </Note>

   ![How to Create and Configure Application... - screenshot 22](/images/intercom/8655943/image-38ba2814.png)
7. **Enable Landscape Mode for Preview Screen:** Turn on this toggle to change the user preview screen from portrait to landscape mode.
8. Click **Save.**
   ![How to Create and Configure Application... - screenshot 23](/images/intercom/8655943/image-e6e8f2fb.png)

   <Note>
     **Note:** When enabled, the **Passwordless SSO URL** toggle is automatically turned on.
   </Note>

   1. **Passwordless SSO URL:**

      <Note>
        **Note:** When you enable **Passwordless Config**, the **Passwordless SSO URL** toggle is automatically enabled.
      </Note>

      1. Enter all the URLs in the  **URL** field.
         ![How to Create and Configure Application... - screenshot 28](/images/intercom/8655943/9414d448-da9f-4165-aba9-2fa2d887e330-4d4c4411.png)
   2. **Workday Punch Integration:**
      1. Turn on **Workday Punch Integration** toggle.
