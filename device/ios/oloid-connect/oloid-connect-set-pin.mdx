**Introduction**

This feature of Oloid Connect app allows Tenant Admin and Supervisors to set the PIN for a user.

## Steps to Set PIN

1. Launch the **Oloid Connect** ![Oloid Connect - Set PIN - screenshot 1](/images/intercom/8768778/image-6def886f.png) app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   The **Settings** page is displayed.
   ![Oloid Connect - Set PIN - screenshot 2](/images/intercom/8768778/image-6c2feb88.png)
2. Tap **Users** on the menu at the bottom of the screen.
   ![Oloid Connect - Set PIN - screenshot 3](/images/intercom/8768778/c9b6e886-ef63-4347-b476-6365dccd406d-bd909cb2.png)
   The **Users** page with list of users is displayed.
3. Tap on the selected user to view details, or search for a user using the search bar at the top.
   ![Oloid Connect - Set PIN - screenshot 4](/images/intercom/8768778/f4cfd404-3251-4290-9302-d9cc154da41a-d9d07a48.png)
   The Details screen is displayed.
4. Select a user from the list.
   ![Oloid Connect - Set PIN - screenshot 5](/images/intercom/8768778/381545de-89b8-4d4a-b11f-81678d58b8ff-728e8b45.png)
   The user's details screen is displayed.
5. Go to the **PIN** tab >Tap **Add** to set PIN.
   ![Oloid Connect - Set PIN - screenshot 6](/images/intercom/8768778/d8648d98-821a-4eeb-b82a-bc20a2d844cd-f0206935.png)
   The **Create PIN** pop-up box is displayed.
6. Do the following:
   1. **Enter your new PIN**.
   2. **Re-enter new PIN**.
   3. Enter **Email ID(s)** you want to **Share PIN With**. (Optional)
   4. Tap **Save**.
      ![Oloid Connect - Set PIN - screenshot 7](/images/intercom/8768778/b51b90f4-33c5-43ca-ad35-4a045dd97aa4-6d721cce.png)
      The PIN credential is successfully created for the user.
      ![Oloid Connect - Set PIN - screenshot 8](/images/intercom/8768778/57664bea-702f-40c3-ab82-df6639de62a6-6a87dc45.png)
