To use the **Oloid Connect app for passwordless login**, you must first configure the required **Application and Connection** in the Tenant Admin Portal.

## Understanding the Basics

### Application

### Application

An **Application** defines the configuration used by the **Oloid Connect app** for passwordless authentication.

The application is created in the **Tenant Admin Portal** and then associated with an **endpoint** (the user device running the Oloid Connect app). This configuration determines how authentication is performed on the device.

### Connection

A **Connection** represents a group of users who are allowed to use the configured application.

After creating the **Application** and **Connection**, map the **Connection** to the **Application**. This mapping allows users in the connection to access the authentication functionality configured for the associated endpoints.

## Setting up Applications

### Step 1: Create an Application

1. Open the Tenant Admin Portal.
2. Navigate to the "**Applications**" section.
3. Click on "**Create Application**."
4. Follow the on-screen instructions to create the application.
   For detailed instructions, see [How to create and configure Connect App for Passwordless](https://oloid.help/en/articles/9896977-how-to-create-and-configure-oloid-connect-for-passwordless-application).

### Step 2: Map Endpoints to the Application

1. After creating the Application, proceed to map specific Endpoints (user devices) with it.
2. This pairing establishes a connection between the Application and the Endpoints.
   For detailed instructions, See, [How to pair Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)

### Step 3: Test Endpoints

- Test the paired **endpoints** to ensure they work correctly for **Oloid Connect app**.

### Setting up Connections

**Step 1: Create Connections**

- Open the Tenant Admin Portal.
- Navigate to the "Connections" section.
- Click "Create Connection."
- Follow the on-screen instructions to create Connection.
  For detailed instructions, see [How to create Connection.](https://oloid.help/en/articles/8294297-how-to-create-connection)

**Step 2: Assign Users to Connections**

- Assign users to the relevant Connections. This is done when creating user in the Tenant Admin Portal.
- For detailed instructions, see [How to create User.](https://oloid.help/en/articles/8185048-how-to-add-user)

By following these steps, you can effectively set up Applications and Connections within the Tenant Admin Portal for the Oloid Connect for Passwordless.
