## Introduction

The PingOne SSO Login feature in the Oloid Connect App allows Tenant Admin and Supervisor to securely access Admin Mode using PingOne SSO credentials.

## Prerequisites

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](https://oloid.help/en/articles/12554658-how-to-download-and-install-the-oloid-connect-app-on-iphone)

## Steps to Log in with PingOne SSO

1. Launch the **Oloid Connect** ![Login Using PingOne SSO - screenshot 1](/images/intercom/14484092/image-6def886f.png) app.
   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**
   ![Login Using PingOne SSO - screenshot 2](/images/intercom/14484092/d77a4a4e-7ec2-412c-8aa8-bb42212fafdb-449c6e31.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**.
   ![Login Using PingOne SSO - screenshot 3](/images/intercom/14484092/fe90a5f2-9be5-4c65-803b-128174c6d20a-7c997912.png)
   TheLogin page is displayed.
4. Tap **Login with SSO**.
   ![Login Using PingOne SSO - screenshot 4](/images/intercom/14484092/ca239fcd-407e-4a7a-a949-0802d1c9d140-b243e7c0.png)
   The screen with **SSO options** is displayed.
5. Tap **Continue with Ping**.
   ![Login Using PingOne SSO - screenshot 5](/images/intercom/14484092/image-7affee6a.png)
   The **Sign on** screen is displayed.
6. Do the following:
   1. Enter **Username**.
   2. Enter **Password**.
7. Tap **Sign On**.
   ![Login Using PingOne SSO - screenshot 6](/images/intercom/14484092/image-7cf0a4d2.png)
   You are successfully logged in to Oloid Connect Admin Mode.
