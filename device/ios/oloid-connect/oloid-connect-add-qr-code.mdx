**Introduction**

This feature in the Oloid Connect app allows Tenant Admins and Supervisors to assign a QR code to user.

## Steps to add QR Code

1. Launch the **Oloid Connect** ![Oloid Connect - Add QR Code - screenshot 1](/images/intercom/8764539/image-6def886f.png) app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   The **Settings** page is displayed.
   ![Oloid Connect - Add QR Code - screenshot 2](/images/intercom/8764539/d1ea0f71-e1b1-4953-a9f6-1e92d22ca7b9-8f1ccefd.png)
2. Tap **Users** on the menu at the bottom of the screen.
   ![Oloid Connect - Add QR Code - screenshot 3](/images/intercom/8764539/c9b6e886-ef63-4347-b476-6365dccd406d-77588022.png)
   The **Users** page with list of users is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top.
   ![Oloid Connect - Add QR Code - screenshot 4](/images/intercom/8764539/82b371a1-a15b-403e-bac7-4680b4fd737d-892fa48f.png)
   The user's **Details** screen is displayed.
4. Tap **QR Code** tab>Tap **Add**.
   ![Oloid Connect - Add QR Code - screenshot 5](/images/intercom/8764539/13e3d130-8492-4902-ba01-102b2893979d-3c1b7f08.png)
   The **Create QR Code** pop-up box is displayed.
5. Do the following:
   1. Select **QR code Validity** from the calendar.
   2. Enter **Email ID(s)** to whom you want to S**hare QR Code With**. (Optional)
   3. Tap **Save**.
      ![Oloid Connect - Add QR Code - screenshot 6](/images/intercom/8764539/9f8ac367-b8cf-4401-a8c7-34a4cbd7726c-fe0cf634.png)
      The QR code is assigned to the user.
      ![Oloid Connect - Add QR Code - screenshot 7](/images/intercom/8764539/1201038a-3488-4b0e-8e5c-e05d994870a7-1e6cca0c.png)
