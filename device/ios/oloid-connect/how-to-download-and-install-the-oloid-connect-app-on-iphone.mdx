The **Oloid Connect app** allows users to authenticate securely using their iPhone for Oloid’s passwordless access solutions. This guide provides step-by-step instructions to download and install the app on an iPhone.

## Prerequisite

- Make sure you have a stable internet connection and an Apple ID.
- Your iPhone runs on **iOS 15 or later**.
- You have access to the **Apple App Store**.

## Steps to download and install Oloid Connect App on iPhone

1. Locate the **App Store** on your home screen and tap on it to launch the application.
   ![How to Download and Install the Oloid... - screenshot 1](/images/intercom/12554658/c9fbec24-de9e-4250-a4b2-a588a55bc6c8-82cff1dc.png)
2. In the search bar, type **“Oloid Connect.”**.
   ![How to Download and Install the Oloid... - screenshot 2](/images/intercom/12554658/7d0445ff-c7dd-4549-adc7-b8e258dc0f37-1a4e4608.png)
3. Select **Oloid Connect** app.
   ![How to Download and Install the Oloid... - screenshot 3](/images/intercom/12554658/f6161f82-3d0b-4701-84be-4e4fe1cc3f5e-2d8ad56d.png)
4. Review the app's details, ratings, and user reviews to make sure it's the correct app you want to download.
   ![How to Download and Install the Oloid... - screenshot 4](/images/intercom/12554658/image-f78ec5b6.png)
5. Tap the **Get** button located next to the **Oloid Connect** app icon.
   ![How to Download and Install the Oloid... - screenshot 5](/images/intercom/12554658/facd686e-47c0-4c1b-b3ac-758857173712-237bc076.png)

   <Note>
     **Note:** If prompted, enter your Apple ID password or use Touch ID/Face ID to confirm the download.
   </Note>

   Wait for the app to finish downloading.
   ![How to Download and Install the Oloid... - screenshot 6](/images/intercom/12554658/326a6f37-623c-428d-967c-51a02ecd5364-8082f0f2.png)
6. Once installation is complete, tap **Open** to launch the **Oloid Connect** app.
   The welcome screen is displayed.
   ![How to Download and Install the Oloid... - screenshot 7](/images/intercom/12554658/image-45c9a135.png)
   The Oloid Connect app is successfully installed.
