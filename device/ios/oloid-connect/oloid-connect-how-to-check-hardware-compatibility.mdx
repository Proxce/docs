## Introduction

To check hardware compatibility using the Oloid Connect app, you can perform a hardware check through Admin Mode to ensure the device meets the required specifications for proper functionality.

## Prerequisite

- The user must be a Tenant Admin or Supervisor.
- The endpoint must be paired. For more details, refer to [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)

## Steps to check hardware compatibility

1. Launch the **Oloid Connect App**.
   ![How to Check Hardware Compatibility - screenshot 1](/images/intercom/10308108/image-3159e180.png)

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the initial screen of the App.
   </Note>

   ![How to Check Hardware Compatibility - screenshot 2](/images/intercom/10308108/image-00093ad5.png)
2. Double tap with two fingers on the initial screen to launch the app in Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Check Hardware Compatibility - screenshot 3](/images/intercom/10308108/9a24b866-2972-486d-be7e-a343751fdba2-c6ddcb79.png)
   The **Settings** screen is displayed.
4. Tap **Start** in the **Hardware Check** section.
   ![How to Check Hardware Compatibility - screenshot 4](/images/intercom/10308108/21575f13-04ff-459b-bc25-00094b118bb2-d69a6875.png)
   The Hardware type selection pop-up box is displayed.

Select **Endpoint**.

![How to Check Hardware Compatibility - screenshot 5](/images/intercom/10308108/841ad435-a558-4ed4-b306-883cf3b151e2-d3bbf3be.png)

The **Hardware Check** details are displayed successfully.

![How to Check Hardware Compatibility - screenshot 6](/images/intercom/10308108/image-2aacd3df.png)
