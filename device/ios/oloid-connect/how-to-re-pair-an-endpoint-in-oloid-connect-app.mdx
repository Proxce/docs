## Introduction

The Re-pair Endpoint feature in the Oloid Connect App allows Admins and Supervisors to restore an endpoint that requires reconfiguration. This process ensures that the endpoint reconnects properly with the assigned application and continues to operate as expected.

## Steps to re-pair an endpoint

1. Launch the **Oloid Connect** app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   The **Settings** page is displayed.
   ![How to Re-pair an Endpoint in Oloid... - screenshot 1](/images/intercom/10288447/image-6c2feb88.png)
2. Tap **Re-pair.**
   ![How to Re-pair an Endpoint in Oloid... - screenshot 2](/images/intercom/10288447/fe8093bf-6ad1-46af-8c29-0a4eea15aa11-49a9b88c.png)
   **Re-pair Endpoint** pop-up is displayed.

   <Note>
     **Note:** You can only re-pair an endpoint if it is not paired.
   </Note>

   ![How to Re-pair an Endpoint in Oloid... - screenshot 3](/images/intercom/10288447/22c7849b-084f-489a-919e-e28030285bf2-689883e9.png)
3. On the pop-up box, do the following:
   1. Enter **Endpoint ID**.
   2. Tap **Re-pair**.
      The Endpoint is re-paired successfully.
      ![How to Re-pair an Endpoint in Oloid... - screenshot 4](/images/intercom/10288447/image-d9d52a0f.png)

      <Note>
        **Note:** Kill and relaunch the app to make the new updates function properly.
      </Note>
