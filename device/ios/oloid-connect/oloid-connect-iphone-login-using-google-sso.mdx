## Introduction

This document provides instructions to log in to the **Oloid Connect** application using **Google Single Sign On (SSO)**.

## Prerequisite

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](https://oloid.help/en/articles/12554658-how-to-download-and-install-the-oloid-connect-app-on-iphone)

## Steps to Log in with Google SSO

1. Launch the **Oloid Connect** ![Login Using Google SSO - screenshot 1](/images/intercom/13595983/image-6def886f.png) app.
   ![Login Using Google SSO - screenshot 2](/images/intercom/13595983/image-02ba2845.png)
   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**
   ![Login Using Google SSO - screenshot 3](/images/intercom/13595983/d77a4a4e-7ec2-412c-8aa8-bb42212fafdb-449c6e31.png)
   The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**.
   ![Login Using Google SSO - screenshot 4](/images/intercom/13595983/fe90a5f2-9be5-4c65-803b-128174c6d20a-7c997912.png)
   TheLogin page is displayed.
4. Tap **Login with SSO**.
   ![Login Using Google SSO - screenshot 5](/images/intercom/13595983/ca239fcd-407e-4a7a-a949-0802d1c9d140-b243e7c0.png)
   The screen with **SSO options** is displayed.
5. Tap **Continue with Google**.
   ![Login Using Google SSO - screenshot 6](/images/intercom/13595983/image-cb99f25a.png)
   The confirmation pop-up is displayed.
6. Tap **Continue**.
   ![Login Using Google SSO - screenshot 7](/images/intercom/13595983/image-5b361f52.png)
   The **Sign in** screen is displayed.
7. Do the following:
   1. Enter **Email ID**.
   2. Tap **Next**.
      ![Login Using Google SSO - screenshot 8](/images/intercom/13595983/image-e788652e.png)
      The **Welcome** screen is displayed.
8. Do the following:
   1. Enter **Password**.
   2. Tap **Next**.
      ![Login Using Google SSO - screenshot 9](/images/intercom/13595983/288000da-9bc1-485a-91c8-af362d86d174-4ef2d722.png)
      You are successfully logged in to Oloid Connect Admin Mode.
