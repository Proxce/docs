**Introduction:**

This feature of the Oloid Connect app allows Tenant Admins and Supervisors to assign NFC to users.

**Pre-requisite:**

User should be added to the connection paired with the application.

## Steps to add NFC/ID

1. Launch the **Oloid Connect**  app.

   <Note>
     **Note:** For more information about how to log in to the Oloid Connect, refer to [How to log in to the Admin mode in Oloid Connect App.](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app)
   </Note>

   The **Settings** page is displayed.
   ![Oloid Connect - Add NFC/ID - screenshot 1](/images/intercom/10304065/image-1ed4d308.png)
2. Tap **Users** on the menu at the bottom of the screen.
   ![Oloid Connect - Add NFC/ID - screenshot 2](/images/intercom/10304065/c9b6e886-ef63-4347-b476-6365dccd406d-4afd3f12.png)
   The **Users** page with list of users is displayed.
3. Tap on the selected user to view details.
   ![Oloid Connect - Add NFC/ID - screenshot 3](/images/intercom/10304065/f4cfd404-3251-4290-9302-d9cc154da41a-70870aab.png)
   The details screen is displayed.
4. Go to **NFC/ID** tab.
   The **Add NFC/ID** screen is displayed.
   ![Oloid Connect - Add NFC/ID - screenshot 4](/images/intercom/10304065/037259d8-9108-43ce-bb88-96c5920d4d8e-ebda222f.png)

   <Note>
     **Note:** The card reader must be connected to the iPad.
   </Note>

5. Scan the **NFC token** on the **NFC reader**.
   The **NFC/ID** is successfully assigned to the user.

![Oloid Connect - Add NFC/ID - screenshot 5](/images/intercom/10304065/02de510e-2c95-4a01-8dd6-3d1d3155bd42-2e53276d.png)
