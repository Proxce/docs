## Introduction

This document provides step-by-step instructions to test network connectivity on the Oloid Connect iPhone app.

## Prerequisite

The endpoint must be paired.

For more, refer to [How to pair an Oloid Connect endpoint on iPhone](https://oloid.help/en/articles/12577230-how-to-pair-an-oloid-connect-endpoint-on-iphone)

## Steps to test Network Connectivity

1. Launch the **Oloid Connect App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the initial screen of the App. For more, refer to [How to pair an Oloid Connect endpoint on iPhone](https://oloid.help/en/articles/12577230-how-to-pair-an-oloid-connect-endpoint-on-iphone)
   </Note>

   ![How to Test Network Connectivity on... - screenshot 1](/images/intercom/12644692/image-2089d1c7.png)
2. Double tap with two fingers on the initial screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Test Network Connectivity on... - screenshot 2](/images/intercom/12644692/3cc855a2-0c23-4e54-a44d-e1f22f5afbfe-18fed654.png)
   The **Settings** screen is displayed.
4. Tap **Start** in the **Health Check** section.
   ![How to Test Network Connectivity on... - screenshot 3](/images/intercom/12644692/2167915d-4cc3-4e5f-8276-76338515ecc1-33b5a2bd.png)
   The **Please Select Health Type** pop-up box is displayed.

On the pop-up box, tap **Network Route Status**.

![How to Test Network Connectivity on... - screenshot 4](/images/intercom/12644692/image-244c404d.png)

The **Network Status** page is displayed.

![How to Test Network Connectivity on... - screenshot 5](/images/intercom/12644692/image-789b19cf.png)
