## Introduction

Guided Access Mode keeps the iPad limited to one app or a few apps, so users are unable to access other features or apps. This setup is useful for check-ins, time tracking, or using the iPad as a display screen. For more, refer to [Use Guided Access with iPhone and iPad](https://support.apple.com/en-in/111795)

#### The following topics are covered in this document.

- How to set up Guided Access in iPad
- [How to enable Guided Access Mode in iPad](#enable-guided-access-mode)
- [How to disable Guided Access Mode in iPad](#disable-guided-access-mode)

### Setting up Guided Access

1. Open your iPad.
2. Go to **Settings > General > Accessibility**
   ![Set up iPad in Guided Access Mode - screenshot 1](/images/intercom/8655926/9a62f1d3-9972-4410-b8b3-0a615729b85d-b4dec596.png)
3. Scroll down the list to the bottom and tap **Guided Access.**
4. Tap the toggle to switch on Guided Access.
   ![Set up iPad in Guided Access Mode - screenshot 2](/images/intercom/8655926/6beb4e32-ee61-4427-84fa-1894154b71b7-70dc410b.png)
5. Tap **Passcode Settings**. Tap **Set Guided Access Passcode.**
   ![Set up iPad in Guided Access Mode - screenshot 3](/images/intercom/8655926/d577df91-ffa5-4823-bc7e-350abbbf812b-41813b93.png)
6. Tap **Set Guided Access Passcode.**
   ![Set up iPad in Guided Access Mode - screenshot 4](/images/intercom/8655926/82a5beaf-ca62-4fb4-9a90-e2de94b9bd5f-afa71946.png)
7. Enter a passcode, then re-enter it to confirm.
   ![Set up iPad in Guided Access Mode - screenshot 5](/images/intercom/8655926/image-9aedd563.png)

### Enable Guided Access Mode

1. Open the Oloid Connect application, then triple-press the **Home/Power** button.
2. Click **Start**.

![Set up iPad in Guided Access Mode - screenshot 6](/images/intercom/8655926/8e26de78-1361-4d69-82e9-d9d935abbc1b-c2fc64a3.png)

### Disable Guided Access Mode

1. To end a Guided Access session, triple-press the **Home/Power** button.
2. Enter your **passcode** when prompted.
3. Click **End**.
   ![Set up iPad in Guided Access Mode - screenshot 7](/images/intercom/8655926/fabff35b-8e59-48f7-af38-0ebccf823499-0a94b609.png)
