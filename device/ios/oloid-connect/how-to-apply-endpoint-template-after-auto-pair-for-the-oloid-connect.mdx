## Introduction

This document explains how to apply an endpoint template to a paired Oloid Connect endpoint in the Tenant Admin Portal. Applying the template makes sure the preset settings are automatically applied to the endpoint.

## Prerequisites

- You must have a Tenant Admin Account.
- The Oloid Connect endpoint must be paired. To pair refer [How to pair an Oloid Connect endpoint](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)
- An Endpoint template must be created. To create refer [How to create and configure Oloid Connect endpoint template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template)

## Steps to apply Endpoint Template

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** from the left panel menu.
   ![How to apply Endpoint Template after... - screenshot 1](/images/intercom/12838474/2e77e818-0456-4972-8080-8c6befda4a89-83136c0f.png)
   The endpoint screen is displayed.
3. Select the **Endpoint**.
   ![How to apply Endpoint Template after... - screenshot 2](/images/intercom/12838474/4f106f81-f5bb-4c1d-a8fa-8b848bbb9279-c0eb2153.png)
   The **Endpoint Detail** page is displayed.
4. Select **Action** dropdown > **Apply Template**.
   ![How to apply Endpoint Template after... - screenshot 3](/images/intercom/12838474/b303f0eb-6230-4aae-b76b-ef790005b6b3-918ef1d4.png)
   The **Apply Template** pop-up box is displayed.
5. Choose the applicable template from the **Select Template** dropdown.
   ![How to apply Endpoint Template after... - screenshot 4](/images/intercom/12838474/image-73ffbd03.png)
   The selected template is displayed in the **Select Template** field.
6. Click **Apply**.
   ![How to apply Endpoint Template after... - screenshot 5](/images/intercom/12838474/090d3ccf-3195-40ea-81e4-0eb0fc25fb96-fd9c9bbe.png)
   The template is successfully applied to the endpoint.
   ![How to apply Endpoint Template after... - screenshot 6](/images/intercom/12838474/f0f831a6-2cba-4b41-bce8-3d01f01d7d33-d74169a8.png)
