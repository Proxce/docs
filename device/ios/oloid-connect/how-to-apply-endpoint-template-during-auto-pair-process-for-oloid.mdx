## Introduction

This document explains how to apply an Endpoint Template during the auto-pair configuration process for the Oloid Connect application. Applying the Endpoint Template ensures that predefined settings are automatically assigned to endpoint as part of the pairing process.

## Prerequisites

1. You have **Tenant Admin** access to the **Tenant Admin Portal**.
2. An **Endpoint Template** has been created. To create refer[How to create and configure Oloid Connect endpoint template](https://oloid.help/en/articles/10345475-how-to-create-and-configure-oloid-connect-endpoint-template)

## Steps at a Glance

1. Create the Oloid Connect application in the Tenant Admin Portal and select the desired endpoint template in the **“Apply Endpoint Template”** field.
2. Generate and download the auto-pair config file; ensure it is mapped to the application with the predefined template.
3. Pair the Oloid Connect endpoint using the auto-pair option. The endpoint template is applied automatically.

## Steps to Apply Endpoint Template During Auto-Pair Process

### Step 1: Create and Configure the Oloid Connect Application

1. Log in to the **Tenant Admin Portal**.
2. Create the **Oloid Connect** application. Refer[How to create and configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)

   <Note>
     **Note:** If Oloid Connect application is already created then select the desired application from the application list.
   </Note>

3. In the **Settings section**, select the applicable template from [Apply Endpoint Template](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal#h_c214dcb2c4:~:text=Apply%20Endpoint%20Template%3A%20Use%20this%20option%20to%20choose%20a%20template%20that%20will%20be%20applied%20automatically%20when%20connecting%20an%20endpoint%20device.) dropdown.

   <Note>
     **Note:** Endpoint template must be added to apply template when using auto-pair option to pair the endpoint.
   </Note>

   ![How to apply Endpoint Template during... - screenshot 1](/images/intercom/12750269/image-516c020a.png)
   The endpoint template is selected.
4. Select **Save**.
   ![How to apply Endpoint Template during... - screenshot 2](/images/intercom/12750269/e8dad220-72c9-4498-b63b-e03e55e446bf-f76acc54.png)

The Endpoint Template is successfully applied to the selected Oloid Connect Application.

### Step 2: Generate and Download the Auto-config File

1. Generate and download the auto-pair config file. Refer [How to generate Auto-Pair config file for Oloid Connect in Tenant Admin Portal](https://oloid.help/en/articles/11513590-how-to-generate-auto-pair-config-file-for-oloid-connect-in-tenant-admin-portal)

   <Note>
     **Note:** Ensure that the **Application Mapping** includes the application where the **Endpoint Template** is specified. This mapping ensures that auto-pair applies the correct endpoint configuration.
   </Note>

   ![How to apply Endpoint Template during... - screenshot 3](/images/intercom/12750269/18270f7e-0306-4fe0-964f-ad921ac727cf-f107402a.png)

### Step 3: Pair Oloid Connect endpoint with Auto-config File

1. On the target iPad, launch the **Oloid Connect App.**

Pair the endpoint using auto-pair option. To auto-pair refer [How to pair Oloid Connect App using Auto config file](https://oloid.help/en/articles/11822152-how-to-pair-oloid-connect-app-using-auto-config-file)

<Note>
  **Note:** Once the auto-pair process completes, the **Endpoint Template** settings is automatically applied to the paired endpoint.
</Note>
