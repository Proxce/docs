## Introduction

The **Oloid Connect - Admin Setup** process includes logging into the Oloid Connect app, pairing the endpoint with the Oloid Connect application.

## Prerequisites

- You must have access to Admin or Supervisor account.
- Oloid Connect Application and Connections must be configured in Tenant Admin Portal. For more information, refer to [How to Create and Configure Oloid Connect Application in Tenant Admin Portal](https://oloid.help/en/articles/8655943-how-to-create-and-configure-oloid-connect-application-in-tenant-admin-portal)

### Device Compatibility

Ensure that your device is compatible with Oloid Connect App. See, [Oloid Connect - Hardware and Software Requirements](https://oloid.help/en/articles/8617065-oloid-connect-hardware-and-software-requirements)

### Internet Connection

Make sure your device is connected to the internet for the setup.

## Steps to setup the Admin Mode

1. Launch the **Oloid Connect** ![Oloid Connect - Admin Setup - screenshot 1](/images/intercom/8592262/image-6def886f.png) app.
   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**
   ![Oloid Connect - Admin Setup - screenshot 2](/images/intercom/8592262/ecc40269-285d-4f4e-88e2-f9771a362fd6-9a614ee0.png)
   The Welcome screen is displayed.
   ![Oloid Connect - Admin Setup - screenshot 3](/images/intercom/8592262/image-d9d52b5e.png)
3. Enter **Tenant Name**, then tap **Next**.
   The **Login** page is displayed.
4. Do the following:
   1. Enter **Tenant Name**.
   2. Enter your email ID in the **Email** text field.
   3. Enter your password in the **Password** text field.
   4. Tap **LOGIN**.

      <Note>
        **Note:** You may also log in using SSO options. For more, refer to[Log in Using SSO](https://oloid.help/en/articles/8671144-how-to-log-in-to-the-admin-mode-in-oloid-connect-app#h_6a328cd429)
      </Note>

      ![Oloid Connect - Admin Setup - screenshot 4](/images/intercom/8592262/d348fa09-f559-4ea2-9fce-b86c01ad6e3e-522bee6c.png)
      The **Settings** page is displayed.
5. Pair the Endpoint. For more details, see [How to pair the endpoint in Oloid Connect app](https://oloid.help/en/articles/8616268-how-to-pair-an-oloid-connect-endpoint)
   ![Oloid Connect - Admin Setup - screenshot 5](/images/intercom/8592262/f12212cf-e367-49cd-83e0-4d9da65a4480-26f494bd.png)
   The Endpoint is paired successfully and the Device Setup successful pop up box is displayed.
   ![Oloid Connect - Admin Setup - screenshot 6](/images/intercom/8592262/image-c66d3ab5.png)

   <Note>
     **Note:** Once the iPad is successfully paired, other settings can be configured in the Tenant Admin Portal.
   </Note>

   The application prompts you to log out of Admin mode.
6. Do one of the following:
   1. Tap **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to capture live Images for facial transactions.

      <Note>
        **Note:** To go back to admin mode, **double-click with two fingers** on preview mode and tap **Yes- To Continue**.
      </Note>

   2. Tap **No** to stay logged in to the admin mode.

![Oloid Connect - Admin Setup - screenshot 7](/images/intercom/8592262/image-2f59c0d5.png)
