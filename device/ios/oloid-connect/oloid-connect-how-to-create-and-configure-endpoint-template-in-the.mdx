## Introduction

The Tenant Admin Portal allows Tenant Admins to create and configure Endpoint Templates for Oloid Connect, enabling quick deployment of multiple endpoints with predefined settings. This ensures consistency across devices and simplifies setup by defining behavior, appearance, location, groups, web button settings, integrations, and health monitoring in advance.

## Prerequisite

You must have a Tenant Admin Account.

## Steps to create Endpoint Template

1. Log in to the **Tenant Admin Portal**.
   The **Application** page is displayed.
2. Select **Endpoint** from the left menu panel.
   ![How to Create and Configure Endpoint... - screenshot 1](/images/intercom/10345475/2e77e818-0456-4972-8080-8c6befda4a89-97cd9706.png)
   The **Endpoint** page is displayed.
3. On the top right click **Endpoint Template**.
   ![How to Create and Configure Endpoint... - screenshot 2](/images/intercom/10345475/image-601749e2.png)
   The **Endpoint Template** page is displayed.
4. On the top right, click **Create Template**.
   ![How to Create and Configure Endpoint... - screenshot 3](/images/intercom/10345475/d72bb8de-d95f-4e11-bd37-3e550baa4659-a0850d12.png)
   The **Create New Template** pop-up box is displayed.
5. Do the following:
   1. Enter **Template Name**.
   2. Select **Application Type** as **Oloid Verify** from the dropdown list.
   3. Select **Endpoint Type** as **Oloid Connect** from the dropdown list.
   4. Click **Create**.

![How to Create and Configure Endpoint... - screenshot 4](/images/intercom/10345475/d0d311bb-26f0-42e3-878d-5f036a1197f1-a95cfaae.png)

The Endpoint is created and listed successfully on Endpoint Template page.

![How to Create and Configure Endpoint... - screenshot 5](/images/intercom/10345475/image-d2aecd20.png)

## Steps to Configure Endpoint template

1. Click **Endpoint Template** to be configured from the listed templates.
   ![How to Create and Configure Endpoint... - screenshot 6](/images/intercom/10345475/image-5817be3a.png)
2. Configure the following:
   1. [Details tab](#configure-details-tab)
   2. [Configure tab](#setting-up-configure-tab)

### Configure Details Tab

![How to Create and Configure Endpoint... - screenshot 7](/images/intercom/10345475/image-975538c8.png)

1. Edit **Template Name** (If required).
2. Enter **Template Description**. (Optional)
3. Select **Endpoint Type** from the dropdown list.
4. Select **Time Zone** from the dropdown list. (Optional)

   <Note>
     **Note:** In case the Endpoint time zone is not specified, by default the endpoint inherits the time zone specified for the application.
   </Note>

5. Enter name in **Name Endpoint As** text field. (Optional)
6. Select **Location** from the dropdown list. Once selected, this activates the **Building** field. For more information on creating a location, refer [How to create a new location and add location details](https://oloid.help/en/articles/8227103-how-to-create-a-new-location-and-add-location-details?q=for+more+information). (Optional)
7. Select **Building** associated with the chosen locationfrom the dropdown list. Once selected, this activates the **area** field. (Optional)
8. Select **area** within the building from the dropdown list. (Optional)
9. Click **Save**.

   <Note>
     **Note:** The **Building** and **Area** fields remain disabled until a valid **Location** is selected.
   </Note>

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

   The **Details tab** is configured successfully.
   ![How to Create and Configure Endpoint... - screenshot 8](/images/intercom/10345475/image-1a9c956b.png)

### Setting up Configure Tab

1. Endpoint Settings
2. [Group](#groups)
3. [Web Button](#configure-web-button)
4. [Integration](#configure-integration)
5. [Health Setup](#configure-health-setup)

#### Configure Endpoint Setting

![How to Create and Configure Endpoint... - screenshot 9](/images/intercom/10345475/dd95c168-92b7-48d1-acc9-9d013c19ede3-c66d8f37.png)

1. **Use Endpoint in Admin Mode Only**: Turn on this toggle to restrict the endpoint device to admin mode and discard user's access control.
2. **Capture Location:** Turn on this toggle to capture location on the endpoint for each transaction.
   **Note: Location Permission** on the Endpoint device must be enabled to Capture Location.
3. **Generate Debug Logs:** Turn on this toggle to generate and send debug logs from the endpoint to the backend.
4. **Enable Landscape Mode for Preview Screen:** Turn on this toggle to allow the user preview screen to switch from portrait to landscape orientation.
5. Click **Save**.

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

The **Endpoint Settings** is configured successfully.

![How to Create and Configure Endpoint... - screenshot 10](/images/intercom/10345475/image-64c4e8b2.png)

#### Groups

![How to Create and Configure Endpoint... - screenshot 11](/images/intercom/10345475/689a1ecc-83ec-44e1-ad68-2ff9f4312467-1a138783.png)

1. Click **+Add Group**.
   The **Add Group** pop-up box is displayed.
   ![How to Create and Configure Endpoint... - screenshot 12](/images/intercom/10345475/image-9ae0067a.png)
2. Select **Group(s)** from the dropdown list.
3. Click **Add**.
   The group is added and listed in the Group Name section.

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

The Group is added successfully.

![How to Create and Configure Endpoint... - screenshot 13](/images/intercom/10345475/image-52875c3f.png)

#### Configure Web Button

![How to Create and Configure Endpoint... - screenshot 14](/images/intercom/10345475/fd4b8e31-1af1-4ad5-8707-51161e2d5a7e-bd1ba64c.png)

1. Turn on **Web Button** toggle to activate the web button on the endpoint preview screen to view transaction.
   1. Enter **URL**.

      <Note>
        **Note:** You have to enter the URL of the website where the user will review the punches.
      </Note>

   2. Enter **Timeout** duration.
2. Turn on **Show only on Auth** to allow the web button to appear only after successful authorization.
3. Turn on **Auto Launch** to automatically launch the web button and view transaction.
4. Click **Save**.

   <Note>
     **Note:** Configure settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

The **Web Button** is configured successfully.

![How to Create and Configure Endpoint... - screenshot 15](/images/intercom/10345475/image-2153d685.png)

#### Configure Integration

![How to Create and Configure Endpoint... - screenshot 16](/images/intercom/10345475/fc2134ff-b26f-4651-9f8c-a5df03f9d180-01cf9102.png)

The Integration section allows the Oloid Admin to configure post-authentication actions for the template. These actions can include API calls, relay triggers, or updates to external systems, triggered after user authentication. (Optional)

#### Configure Health Setup

![How to Create and Configure Endpoint... - screenshot 17](/images/intercom/10345475/7b2c2996-111f-4100-b022-3187c4e19b33-ebeb4afd.png)

**Enable Health Alerts**

Do the following:

1. Turn on **Enable Health Alerts** toggle to monitor the health of the paired endpoints. (Optional)
2. Enter the recipient email ID(s) in **Add recipients for Endpoint Health Alerts** to share the health alert notifications. (Optional)
3. Set **Email frequency** in Hours and Mins to adjust the frequency of email notifications.
4. Click **Save** to apply your changes.
   The Health Alert is configured for the endpoint.
   ![How to Create and Configure Endpoint... - screenshot 18](/images/intercom/10345475/image-1f74eec5.png)

**Add URLs to Monitor**

Do the following:

1. Enter **Server Name**.
2. Enter URL in **Add URL that needs to be monitored** field.
3. Click **Add**.

![How to Create and Configure Endpoint... - screenshot 19](/images/intercom/10345475/image-18f78ed1.png)

The health check server URL is added successfully.

![How to Create and Configure Endpoint... - screenshot 20](/images/intercom/10345475/image-5c6da2df.png)

The Endpoint Template is created and configured successfully.
