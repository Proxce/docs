## Introduction

The Okta SSO Login feature in the Oloid Verify App allows Admin and Supervisor to securely access Admin Mode using Okta credentials.

## Prerequisite

- You must have a Tenant Admin account.

## Steps to log in with Okta SSO

1. Launch the **Oloid Verify** App.
   The Login screen is displayed.
2. On the login screen, tap **Login with SSO**.
   ![Login using Okta SSO - screenshot 1](/images/intercom/10367862/df5c70b0-d05c-4ec5-8c55-cc2f0c39ae1b-60e971b1.png)
   The screen with **SSO options** are displayed.
3. Tap **Continue with Okta**.
   ![Login using Okta SSO - screenshot 2](/images/intercom/10367862/image-d28389bc.png)
   The confirmation pop-up box is displayed.
4. Tap on **Continue**.
   ![Login using Okta SSO - screenshot 3](https://downloads.intercomcdn.com/i/o/e4gi378c/1327132841/f25b6f05c1bbfa76225b426521a7/image.png?expires=1790294400&signature=332c00d3ac198393acd14f6b4f914c1640023fb3c95285c1b9abc673cde53b79&req=dSMlEch9n4lbWPMW3nq%2BgV18T9%2Fy14wlhDszO%2FxjwLPCLuXN1FXUtcviDbPY%0A9DkjHQgQNUg9ZUcFSx3FJdboMw8%3D%0A)
   The **Okta Sign In** screen is displayed.
5. Enter **Username** > tap **Next**.
   ![Login using Okta SSO - screenshot 4](/images/intercom/10367862/c4c3e1c0-c607-43ee-a6f2-21f8a1e89fac-982983d3.png)

Enter **Password** in the Password field > tap **Sign In**.

![Login using Okta SSO - screenshot 5](/images/intercom/10367862/93424782-2e19-4668-9fe2-b7742748c3f4-c2e52424.png)

You are logged in to Admin Mode in Oloid Verify using Okta SSO successfully.
