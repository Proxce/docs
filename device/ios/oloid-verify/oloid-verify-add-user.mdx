## Introduction

The Add User feature in the Oloid Verify app allows Admins and Supervisors to directly add user from the endpoint.

## Prerequisite

- You must complete the Admin Setup. To setup, refer [Oloid Verify - Admin Setup.](https://oloid.help/en/articles/8601056-oloid-verify-app-installation-and-admin-setup)
- You must enable Supervisors privileges to allow the supervisor to add user. To enable, refer to [How to enable Add or Delete Users in Tenant Admin Portal for Supervisors](https://oloid.help/en/articles/9127132-how-to-enable-add-or-delete-users-in-tenant-admin-portal-for-supervisors)
- The Oloid Verify endpoint must be paired. To pair refer [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)

## Steps to Add user

1. Launch the **Oloid Verify** app.
   ![Oloid Verify - Add User - screenshot 1](/images/intercom/8601073/image-7fb0f024.png)
2. Log in to Admin mode in Oloid Verify app. To login refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor](https://oloid.help/en/articles/8671139-how-to-log-in-to-the-admin-mode-of-oloid-verify-app-as-an-admin-or-supervisor)
   The **Home** screen is displayed.
3. Tap **+Actions** on the menu at the bottom of the screen.
   ![Oloid Verify - Add User - screenshot 2](/images/intercom/8601073/image-089b48d7.png)
   The **Actions** screen is displayed.
4. Tap **Add User.**
   ![Oloid Verify - Add User - screenshot 3](/images/intercom/8601073/91b92473-f129-40ba-a7ae-c7814b7dafb0-8f565ece.png)
   The **Add User** screen is displayed.
5. Enter **Name**.

   <Note>
     **Note:** First name and Last name should be separated by a space.
   </Note>

6. Enter **Primary ID**.
   Only alphabets, numbers, and hyphen are accepted.
7. Enter **Secondary ID** (Optional).
   Only numerals are accepted.
8. Select connection name from **Connection Name** list.
9. Tap **Add User**.

![Oloid Verify - Add User - screenshot 4](/images/intercom/8601073/b78a751e-8278-49f4-aa8d-bc1a4d64d6ed-2a531cc9.png)

A new user is added and user details are displayed in User **Details** screen.

![Oloid Verify - Add User - screenshot 5](/images/intercom/8601073/image-831ca661.png)
