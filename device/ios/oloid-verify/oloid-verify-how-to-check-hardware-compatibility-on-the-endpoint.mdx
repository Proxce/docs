## Introduction

The Hardware Compatibility Check in the Oloid Verify app ensures that the iPad meets the required technical standards for smooth operation. It allows Tenant Admin and Supervisor to quickly verify that key hardware components are working properly before using the device.

## Prerequisite

You must complete the Admin Setup. To Setup. refer [Oloid Verify - Admin Setup.](https://oloid.help/en/articles/8601056-oloid-verify-app-installation-and-admin-setup)

## Steps to check hardware compatibility

1. Launch the **Oloid Verify App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the initial screen of the App. For more information, refer to [How to pair an Oloid Verify endpoint.](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)
   </Note>

   ![How to Check Hardware Compatibility on... - screenshot 1](/images/intercom/10255794/image-e5c8f8d7.png)
   The Preview screen is displayed.
2. **Double**-**tap** on the Preview screen with two fingers.
   The Admin mode pop up box is displayed.
3. Tap **YES-CONTINUE** to log into **Admin Mode**.
   ![How to Check Hardware Compatibility on... - screenshot 2](/images/intercom/10255794/f3c33ca3-1d13-43fd-974b-d2e76380c74a-1aa723d8.png)
   The **Settings** page is displayed.
4. Tap **Start** in the **Hardware Check** section.

![How to Check Hardware Compatibility on... - screenshot 3](/images/intercom/10255794/image-3536455b.png)

The **Hardware Check** page is displayed to view.

![How to Check Hardware Compatibility on... - screenshot 4](/images/intercom/10255794/image-bfd546bf.png)
