## Introduction

The Auto Config file is created and downloaded from the Tenant Admin Portal. It includes all the necessary settings to automatically connect your iPad to the Oloid Connect application. After downloading, transfer the file to your iPad.

This process allows the endpoint to connect with the Oloid Connect application configured in the Tenant Admin Portal, without requiring manual setup.

## Prerequisites

- You must generate the Auto-config file, transfer it to the iPad, and save it. For more, refer to [How to generate Auto-Pair config file for Oloid Connect in Tenant Admin Portal](https://oloid.help/en/articles/11513590-how-to-generate-auto-pair-config-file-for-oloid-connect-in-tenant-admin-portal)
- In the Tenant Admin Portal, select Skip user confirmation for pairing when generating the auto-config file. The endpoints pair automatically without user confirmation (recommended).

## Steps to pair an Oloid Connect endpoint using Auto Config file

1. Launch the **Oloid Connect** ![How to Pair Oloid Connect App using... - screenshot 1](/images/intercom/11822152/image-6def886f.png) app.
   The **Welcome** screen is displayed.
   ![How to Pair Oloid Connect App using... - screenshot 2](/images/intercom/11822152/image-6a2ba9cb.png)
2. Tap **Auto-pair using config file.**
   ![How to Pair Oloid Connect App using... - screenshot 3](/images/intercom/11822152/03e1a26f-4732-46ff-903e-06dddcc62d1f-cdb57b9b.png)
   The **Pair Device Using Config File** page is displayed.
3. On the **Pair Device Using Config File**, tap on **Click here to pair file**.
4. Upload the auto-config file from your iPad.
   ![How to Pair Oloid Connect App using... - screenshot 4](/images/intercom/11822152/image-27d32f51.png)
   The auto-config file is uploaded successfully, and the selected file is displayed on the screen.
5. Tap **Upload** to initiate endpoint pairing.
   ![How to Pair Oloid Connect App using... - screenshot 5](/images/intercom/11822152/50b1fdd7-188c-429a-9490-8b497e48ad36-61eed9b7.png)
   The Pairing Initiated screen is displayed.
   ![How to Pair Oloid Connect App using... - screenshot 6](/images/intercom/11822152/image-385a0000.png)
   The Endpoint Paired Successfully.
   ![How to Pair Oloid Connect App using... - screenshot 7](/images/intercom/11822152/image-0f8b9bea.png)
   After successful pairing, the preview screen is displayed.
