## Introduction

Guided Access Mode limits the iPad to one or a few specific apps, preventing users from accessing other features or applications.

The following topics are covered in this document:

- Set up Guided Access in iPad
- Start Guided Access Mode in iPad
- End Guided Access Mode in iPad

## Steps to set up Guided Access

1. Open your iPad.
2. Go to **Settings > Accessibility > Guided Access.**
   ![Set up iPad in Guided Access Mode or... - screenshot 1](/images/intercom/8650264/9a62f1d3-9972-4410-b8b3-0a615729b85d-fa707417.png)
3. Turn on the **Guided Access** toggle.
   ![Set up iPad in Guided Access Mode or... - screenshot 2](/images/intercom/8650264/6beb4e32-ee61-4427-84fa-1894154b71b7-8c993971.png)
4. Tap **Passcode Settings**.
   ![Set up iPad in Guided Access Mode or... - screenshot 3](/images/intercom/8650264/d577df91-ffa5-4823-bc7e-350abbbf812b-91744eb2.png)
5. Tap **Set Guided Access Passcode.**
   ![Set up iPad in Guided Access Mode or... - screenshot 4](/images/intercom/8650264/82a5beaf-ca62-4fb4-9a90-e2de94b9bd5f-a86b19ad.png)
6. Enter a passcode.
7. Re-enter the passcode to confirm.
   ![Set up iPad in Guided Access Mode or... - screenshot 5](/images/intercom/8650264/image-c20a943c.png)
   The Guided Access is set up successfully.

## Steps to start Guided Access Mode

1. Launch **Oloid Verify** app.
   ![Set up iPad in Guided Access Mode or... - screenshot 6](/images/intercom/8650264/image-12f44f5b.png)
2. Quickly press the **Home/Power** button **three** times.
3. Tap **Start**.
   ![Set up iPad in Guided Access Mode or... - screenshot 7](/images/intercom/8650264/5197ef20-ae98-4604-97e1-42b2a31ee3f9-2f449752.png)

The Guided Access mode is started successfully.

## Steps to End Guided Access Mode

1. Quickly press the **Home/Power** button **three** times.
   The enter passcode pop-up box is displayed.
2. Enter your **passcode** when prompted.
   ![Set up iPad in Guided Access Mode or... - screenshot 8](/images/intercom/8650264/image-148eb2d7.png)

Tap **End**.

![Set up iPad in Guided Access Mode or... - screenshot 9](/images/intercom/8650264/fabff35b-8e59-48f7-af38-0ebccf823499-0a94b609.png)

The Guided Access mode is ended successfully.
