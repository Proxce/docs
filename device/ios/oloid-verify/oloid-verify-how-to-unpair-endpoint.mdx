## Introduction

This document explains how to unpair an endpoint using the **Oloid Verify** application.

## Prerequisites

- The Oloid Verify endpoint must be paired. For more, refer to [Oloid Verify - How to Pair an Endpoint](https://oloid.help/en/articles/8616605-oloid-verify-how-to-pair-an-endpoint)
- You must have Tenant Admin or Supervisor access.

## Steps to Unpair Endpoint

1. Launch the **Oloid Verify App**.

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App. For more, refer to [Oloid Verify - How to Pair an Endpoint](https://oloid.help/en/articles/8616605-oloid-verify-how-to-pair-an-endpoint)
   </Note>

   ![How to Unpair Endpoint - screenshot 1](/images/intercom/16159090/image-71d2722b.png)
2. Log in to Admin mode. For more refer to [Oloid Verify - How to Log In to Admin Mode as an Admin or Supervisor](https://oloid.help/en/articles/8671139-oloid-verify-how-to-log-in-to-admin-mode-as-an-admin-or-supervisor)
   The **Users** page is displayed.
3. Tap **Settings**.
   ![How to Unpair Endpoint - screenshot 2](/images/intercom/16159090/image-424f161e.png)
   The **Settings** page is displayed.
4. Tap **Unpair**.
   ![How to Unpair Endpoint - screenshot 3](/images/intercom/16159090/image-89f02140.png)
   The confirmation pop-up box is displayed.

Tap **Yes.**

![How to Unpair Endpoint - screenshot 4](/images/intercom/16159090/image-cefbf154.png)

The Oloid Verify Endpoint is unpaired successfully.

![How to Unpair Endpoint - screenshot 5](/images/intercom/16159090/image-d74be132.png)
