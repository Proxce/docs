Admin and Supervisor can log in to Admin Mode in the Oloid Verify App using following three methods:

1. [Log in using Email and Password](https://oloid.help/en/articles/8464035-how-to-log-into-the-admin-mode-of-oloid-verify-connect-app-as-a-supervisor#_Login_Using_Email)
2. [Log in using Face](https://oloid.help/en/articles/8464035-how-to-log-into-the-admin-mode-of-oloid-verify-connect-app-as-a-supervisor#h_4895bd25f4)
3. [Log in using SSO](#log-in-using-sso)

## Login using Email and Password

#### Prerequisite

- You must complete the Admin Setup. For more details refer [Oloid Verify: App Installation and Admin Setup](https://oloid.help/en/articles/8601056-oloid-verify-app-installation-and-admin-setup).
- Password must be updated using the invite email received by the Supervisor.

  <Note>
    **Note:** In case, supervisor has not received any invite email, they should contact the Tenant Admin.
  </Note>

#### Steps to log in with Email and Password

1. Launch the **Oloid Verify** App.
   ![How to Log In to Admin Mode as an Admin... - screenshot 1](/images/intercom/8671139/image-494e77e2.png)

   <Note>
     **Note:** Since the endpoint is already paired, the app will launch in the preview mode. For more, refer to [Oloid Verify - How to Pair an Endpoint](https://oloid.help/en/articles/8616605-oloid-verify-how-to-pair-an-endpoint)
   </Note>

   ![How to Log In to Admin Mode as an Admin... - screenshot 2](/images/intercom/8671139/image-e1149a9c.png)
2. Double tap with two fingers on the screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Log In to Admin Mode as an Admin... - screenshot 3](/images/intercom/8671139/image-f03a84ca.png)
   The Settings screen is displayed.
4. Tap **Login as Admin**.
   ![How to Log In to Admin Mode as an Admin... - screenshot 4](/images/intercom/8671139/fd2c5c2f-c876-4b44-86cf-155ac72dc2c2-b1751960.png)
   The Login screen is displayed and the tenant name is pre-populated.
5. Do the following:
   1. Enter **Email ID** in the **Email** field.
   2. Enter **Password** in the **Password** field.
   3. Tap **LOGIN**.
      ![How to Log In to Admin Mode as an Admin... - screenshot 5](/images/intercom/8671139/6e0a1a01-fce1-4cfc-8c76-a7c9c5005b68-62a7bfa0.png)
      You are logged in to the Admin Mode successfully.

      <Note>
        **Note:** After successfully logging in to Admin mode, the Users page is displayed. For more details, refer to the [sample screen](#sample-screen)
      </Note>

## Login using Face

#### Prerequisite

- Face must be onboarded for the Supervisor/Admin.
- Endpoint must be paired in the iPad. For more details refer **[How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint).**
- The connection that the supervisor belongs to, must be linked to the application the endpoint is paired with.

#### Steps to log in with Face

1. Launch the **Oloid Verify** App.
   ![How to Log In to Admin Mode as an Admin... - screenshot 6](/images/intercom/8671139/image-ab25b43e.png)

   <Note>
     **Note:** Since the endpoint is already paired, the app will launch in the preview mode.
   </Note>

   ![How to Log In to Admin Mode as an Admin... - screenshot 7](/images/intercom/8671139/image-e1149a9c.png)
2. Double tap with two fingers on the screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Log In to Admin Mode as an Admin... - screenshot 8](/images/intercom/8671139/image-820a48fa.png)
   The Settings screen is displayed.
4. Tap **Login as Admin**.
   ![How to Log In to Admin Mode as an Admin... - screenshot 9](https://downloads.intercomcdn.com/i/o/e4gi378c/1327075089/3f01b914bcf3b4e713f7d2376c71/727400bf-bd75-4c92-9c23-2ee0391d817b?expires=1790294400&signature=34f6ff9ddae180d4668d670eb7d083107581749736ecb15d9aba2a6f7a11cc71&req=dSMlEcl5mIFXUPMW3nq%2BgagtNhGnDY0LWXngbdajNSlFXwEMG7y5qTyMe1uY%0AO38FKo6GwD8HKm9YCdNpFQFKmoM%3D%0A)
   The Login screen is displayed and the tenant name is pre-populated.
5. Tap **LOG IN WITH FACE**.
   ![How to Log In to Admin Mode as an Admin... - screenshot 10](/images/intercom/8671139/e76a9399-d912-48cc-a9bc-b97380da2e94-0eb71b12.png)
   This will open the camera preview screen.
6. Look at the camera to confirm your identity.
   ![How to Log In to Admin Mode as an Admin... - screenshot 11](/images/intercom/8671139/image-d4905363.png)
   You are logged in to the Admin Mode successfully.

   <Note>
     **Note:** After successfully logging in to Admin mode, the Users page is displayed. For more details, refer to the [sample screen](#sample-screen)
   </Note>

## Log in using SSO

#### Prerequisite

- Endpoint must be paired in the iPad. For more details refer **[How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint).**
- Tenant admin and Supervisor's Email ID needs to be updated in the Tenant Admin Portal.

#### Steps to log in with SSO

1. Launch the **Oloid Verify** App.
   ![How to Log In to Admin Mode as an Admin... - screenshot 12](/images/intercom/8671139/image-17fd6f50.png)

   <Note>
     **Note:** Since the endpoint is already paired, the App will launch in the preview screen of the App.
   </Note>

   ![How to Log In to Admin Mode as an Admin... - screenshot 13](/images/intercom/8671139/image-03d0fef4.png)
2. Double tap with two fingers on the preview screen to launch the Admin Mode.
3. Tap **Yes- Continue.**
   ![How to Log In to Admin Mode as an Admin... - screenshot 14](/images/intercom/8671139/image-72717af8.png)
   The **Settings** screen is displayed.
4. Tap **Login as Admin**.
   ![How to Log In to Admin Mode as an Admin... - screenshot 15](/images/intercom/8671139/727400bf-bd75-4c92-9c23-2ee0391d817b-9ebc527e.png)
   The Login screen is displayed.
5. On the login screen, tap **Login with SSO**.
   ![How to Log In to Admin Mode as an Admin... - screenshot 16](/images/intercom/8671139/df5c70b0-d05c-4ec5-8c55-cc2f0c39ae1b-60e971b1.png)
   The screen with **SSO options** is displayed.
   Do one of the following:
   1. Login with [Google](https://oloid.help/en/articles/10247971-how-to-login-with-google-sso-in-oloid-verify).
   2. Login with [Microsoft](https://oloid.help/en/articles/10255679-how-to-login-with-microsoft-sso-in-oloid-verify-app).

Login with [Okta](https://oloid.help/en/articles/10367862-how-to-login-with-okta-sso-in-oloid-verify).

![How to Log In to Admin Mode as an Admin... - screenshot 17](/images/intercom/8671139/c0761e6e-0e66-47b4-a9ac-ce07ba2663a0-caa86072.png)

<Note>
  **Note:** After successfully logging in to Admin mode, the Users page is displayed. For more details, refer to the [sample screen](#sample-screen)
</Note>
