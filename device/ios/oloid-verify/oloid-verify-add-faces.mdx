## Introduction

The Add Faces feature in the Oloid Verify app allows Tenant Admins and Supervisors to register a user’s face as a credential.

<Note>
  **Note:** If consent option is enabled for connection to take consent for user, it will ask for consent before uploading the picture. To enable refer [How to add a Consent Template to a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8237994-how-to-add-a-consent-template-to-a-connection-in-the-tenant-admin-portal).
</Note>

## Prerequisite

- You must have a Tenant Admin or Supervisor account.
- You must add the user. To add user refer [Oloid Verify-Add User](https://oloid.help/en/articles/8601073-oloid-verify-add-user).
- The Oloid Verify endpoint must be paired. To pair, refer [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)

## Steps to add faces

1. Launch the **Oloid Verify** app.
   ![Oloid Verify - Add Faces - screenshot 1](/images/intercom/8535373/image-7fb0f024.png)
2. Log in to Admin mode in Oloid Verify app. To login, refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](https://oloid.help/en/articles/8671139-how-to-log-in-to-the-admin-mode-of-oloid-verify-app-as-an-admin-or-supervisor)
   The **Users** page is displayed with the list of users.
3. Select the preferred user to add a face.
   ![Oloid Verify - Add Faces - screenshot 2](/images/intercom/8535373/5fcf05cb-e154-401d-afb5-439de0ab2476-f82645cc.png)
   The user details page is displayed.
   ![Oloid Verify - Add Faces - screenshot 3](/images/intercom/8535373/f908dcbc-1529-4add-954b-ce7d1b45bb85-e416e83a.png)
4. Go to **Face** tab > tap **Submit Consent.**
   ![Oloid Verify - Add Faces - screenshot 4](/images/intercom/8535373/647d4ff7-e234-44d7-9918-d7aa36fa1d09-f26d7288.png)
   The Consent form is displayed.
5. Tap **Accept.**
   ![Oloid Verify - Add Faces - screenshot 5](/images/intercom/8535373/521a0a37-542f-413c-af39-06d25feab1cb-3f6f6f5e.png)
   The Consent is collected successfully.
   ![Oloid Verify - Add Faces - screenshot 6](/images/intercom/8535373/image-44a86acb.png)
6. Tap **+Add Face**.
   This opens the camera on your device.
   ![Oloid Verify - Add Faces - screenshot 7](/images/intercom/8535373/7b7e9782-50f5-4415-a245-5eda2d2c2bd0-1abf8a42.png)
7. Look at the camera to confirm your identity.
   The pop-up screen appears with the captured image.
8. Do one of the following:
   1. Tap **Yes- Submit** to submit the image.
      The face is submitted successfully and is displayed on the details screen.
   2. Tap **No- Retake** to take the photo again.
      The camera turns on to retake photo.
      ![Oloid Verify - Add Faces - screenshot 8](/images/intercom/8535373/image-ea0870fd.png)
      The face credential is added successfully.
      ![Oloid Verify - Add Faces - screenshot 9](/images/intercom/8535373/image-d5c92953.png)

      <Note>
        **Note:** You can add a maximum of five faces per user.
      </Note>

      Ensure your face is clearly visible to avoid rejection. Avoid wearing items that cover facial features, such as sunglasses, masks, or headbands. For more details, refer to [Oloid’s Image Reference Guide](https://oloid.help/en/articles/9886279-guidelines-for-face-enrollment-onboarding-images) for face onboarding guidelines.
