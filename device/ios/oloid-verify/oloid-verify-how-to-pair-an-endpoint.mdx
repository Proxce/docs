## Introduction

This document explains how to pair an endpoint using the **Oloid Verify** application. Pairing connects the endpoint to the Oloid Verify application in the Tenant Admin Portal and prepares the endpoint for authentication and transaction activities.

## Prerequisite

- You should be a Tenant Admin or Supervisor.
- You must create and configure Oloid Verify application in the Tenant Admin Portal. To create refer[How to create and configure Application Type - Oloid Verify](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify).
- You must download and install Oloid Verify app from the App store. To download and install refer [How to download and install Oloid Verify App](https://oloid.help/en/articles/8592228-how-to-download-oloid-verify-app).

## Step to Pair an Endpoint

1. Launch the Oloid Verify app.
   ![How to Pair an Endpoint - screenshot 1](/images/intercom/8616605/image-0c54e2cc.png)
   The **LOGIN** page is displayed.
2. Enter **Tenant Name**.
3. Enter email id in the **Email** text field.
4. Enter password in the **Password** text field.
5. Tap **LOGIN**.
   ![How to Pair an Endpoint - screenshot 2](/images/intercom/8616605/image-a5a9882b.png)
   The **Settings** page is displayed.
6. Do one of the following on the **Settings** page.
   1. Add **Template** (optional). For more, refer to [How to create and configure Oloid Verify Endpoint Template](https://oloid.help/en/articles/10506225-how-to-create-and-configure-oloid-verify-endpoint-template).
   2. Enter **Endpoint Name**.
   3. Select Application Name from **Application Name** list.
   4. Tap **Pair.**
      ![How to Pair an Endpoint - screenshot 3](/images/intercom/8616605/image-4bd876cd.png)
      The settings are saved and endpoint is successfully paired and Device Setup successful pop up box is displayed.
      ![How to Pair an Endpoint - screenshot 4](/images/intercom/8616605/image-ab34911a.png)
      The application prompts you to log out of Admin mode.
7. Do one of the following:
   1. Click **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to do the transactions.
   2. Click **No** to stay logged in to the admin mode.
      ![How to Pair an Endpoint - screenshot 5](/images/intercom/8616605/image-fbaea99f.png)
