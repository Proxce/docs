## Introduction

The Oloid Verify app allows Tenant Admin to assign a location to an endpoint during the setup process. Adding a location ensures accurate tracking and management of endpoints within your organization.

## Prerequisite

- You must have a Tenant Admin or Supervisor account.
- You must download the Oloid Verify app. To download refer [How to download Oloid Verify App](https://oloid.help/en/articles/8592228-how-to-download-oloid-verify-app).

## Steps to add location to an endpoint

1. Launch the **Oloid Verify** app.
   ![How to Add Location to an Endpoint - screenshot 1](/images/intercom/8601170/image-7fb0f024.png)
2. Log in to Admin mode in Oloid Verify app. To login, refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](https://oloid.help/en/articles/8671139-how-to-log-in-to-the-admin-mode-of-oloid-verify-app-as-an-admin-or-supervisor)
   The location access pop-up box is displayed.
3. On the pop-up box, tap an option:
   - **Allow Once:** Each time you open the app, it will request access your location.
   - **Allow While Using App:** The app can access your location only when you are actively using it.
   - **Don't Allow:** The app cannot access your location, even while you are using it.

     <Note>
       **Note:** You can also update location from the device settings. To update refer **[How to update location in Oloid Verify.](https://oloid.help/en/articles/10204617-how-to-update-location-in-oloid-verify)**
     </Note>

     ![How to Add Location to an Endpoint - screenshot 2](/images/intercom/8601170/image-8b361c41.png)

     <Note>
       **Note:** You can now log in to the **Tenant Admin Portal** to check the location that is added to the specific endpoint.
     </Note>
