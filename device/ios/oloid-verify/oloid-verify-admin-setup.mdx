## Introduction

The **Oloid Verify Admin Setup** process allows Tenant Admins and Supervisors to configure and prepare the Oloid Verify app for use on an iPad. This setup ensures that the endpoint is properly linked to the Oloid Verify application and ready for user authentication.

## Prerequisite

- You should be a Tenant Admin or Supervisor.
- You must create and configure Oloid Verify application in the Tenant Admin Portal. To create refer[How to create and configure Application Type - Oloid Verify](https://oloid.help/en/articles/8300813-how-to-create-and-configure-application-type-oloid-verify).
- You must download and install Oloid Verify app from the App store. To download and install refer [How to download and install Oloid Verify App](https://oloid.help/en/articles/8592228-how-to-download-oloid-verify-app).

## Steps to setup

1. Launch the Oloid Verify app.
   ![Oloid Verify - Admin Setup - screenshot 1](/images/intercom/8601056/image-0c54e2cc.png)
   The Login screen is displayed.
2. Enter **Tenant Name**.
3. Enter your email id in the **Email** text field.
4. Enter your password in the **Password** text field.
5. Tap **LOGIN**.

   <Note>
     **Note:** If your face is added to the Tenant Portal as a Tenant Admin, you can tap on **LOG IN WITH FACE** to log in using your face.
   </Note>

   ![Oloid Verify - Admin Setup - screenshot 2](/images/intercom/8601056/903203c2-989f-4b87-a9ce-720727b7d0c8-6d802332.png)
   The location access pop-up box is displayed
6. Do one of the following:
   1. **Allow Once:** Each time you open the app, it will request access your location.
   2. **Allow While Using App:** The app can access your location only when you are actively using it.
   3. **Don't Allow:** The app cannot access your location, even while you are using it.
      ![Oloid Verify - Admin Setup - screenshot 3](/images/intercom/8601056/image-9f05762b.png)
      The **Settings** page is displayed.
7. Do one of the following on the **Settings** page.
   1. Add **Template** (optional).
   2. Enter **Endpoint Name**.
   3. Select Application Name from **Application Name** list.
   4. Tap **Pair.**
      ![Oloid Verify - Admin Setup - screenshot 4](/images/intercom/8601056/image-d66e190e.png)
      The settings are saved and the Device Setup success message is displayed.
      ![Oloid Verify - Admin Setup - screenshot 5](/images/intercom/8601056/image-ab34911a.png)

      <Note>
        **Note:** Once the iPad is successfully paired, other settings can be configured in the Tenant Admin Portal.
      </Note>

8. The application prompts you to log out of Admin mode.
9. Do one of the following:
   1. Tap **Yes** to log out and launch the application (**preview mode**).
      The app displays preview mode and allows you to authenticate.

      <Note>
        **Note:** To go back to admin mode, **double-tap with two fingers** on preview mode and tap **Yes- to Continue**.
      </Note>

   2. Tap **No** to stay logged in to the admin mode.

      3. [Add Faces](https://oloid.help/en/articles/8535373-oloid-verify-add-faces)
