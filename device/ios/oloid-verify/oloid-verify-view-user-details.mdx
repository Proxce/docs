## Introduction

The View User Details feature in the Oloid Verify app allows Admin and Supervisor to quickly access essential information about a user. From this, you can view key details such as the user’s name, primary ID, and the connection assigned to them.

## Prerequisite

- You must have a Tenant Admin or Supervisor account.
- You must add the user. To add user refer[Oloid Verify: Add User](https://oloid.help/en/articles/8601073-oloid-verify-add-user).
- The Oloid Verify endpoint must be paired. To pair, refer [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)

## Steps to view User details

1. Launch the **Oloid Verify** app.
   ![View User details - screenshot 1](/images/intercom/8616846/image-7fb0f024.png)
2. Log in to Admin mode in Oloid Verify app. To login, refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](https://oloid.help/en/articles/8671139-how-to-log-in-to-the-admin-mode-of-oloid-verify-app-as-an-admin-or-supervisor)
   The **Users** screen with list of users is displayed.

Tap on the preferred **user** to view details.

![View User details - screenshot 2](/images/intercom/8616846/e47ef40b-7431-4fbc-a7a4-16693889a243-004daf35.png)

The User details are displayed on the **Details** screen.

![View User details - screenshot 3](/images/intercom/8616846/image-4a1dd04d.png)
