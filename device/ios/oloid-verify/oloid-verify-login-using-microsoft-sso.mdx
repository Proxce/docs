## Introduction

The Microsoft SSO Login feature in the Oloid Verify App allows Tenant Admin and Supervisor to access Admin Mode using Microsoft credentials.

## Prerequisite

You must have a Tenant Admin account.

## Steps to log in with Microsoft SSO

1. Launch the **Oloid Verify** App.
   The **Settings** screen is displayed.
2. Tap **Login as Admin**.
   ![Login using Microsoft SSO - screenshot 1](/images/intercom/10255679/727400bf-bd75-4c92-9c23-2ee0391d817b-6e7b5964.png)
   The Login screen is displayed.
3. On the login screen, tap **Login with SSO**.
   ![Login using Microsoft SSO - screenshot 2](/images/intercom/10255679/df5c70b0-d05c-4ec5-8c55-cc2f0c39ae1b-60e971b1.png)
   The screen with **SSO options** are displayed.
4. Tap **Continue with Microsoft**.
   ![Login using Microsoft SSO - screenshot 3](/images/intercom/10255679/image-e2b2a520.png)
   The confirmation pop-up box is displayed.
5. Tap **Continue**.
   ![Login using Microsoft SSO - screenshot 4](/images/intercom/10255679/image-ea12478e.png)
   The **Microsoft Sign in** page is displayed.
6. Enter **Email ID** > tap **Next**.
   ![Login using Microsoft SSO - screenshot 5](/images/intercom/10255679/image-6fff1336.png)

Enter **Password** > tap **Sign in**.

![Login using Microsoft SSO - screenshot 6](/images/intercom/10255679/image-ecaafd28.png)

You are logged in to Admin Mode in Oloid Verify using Microsoft SSO successfully.
