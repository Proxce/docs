## Introduction

The Add QR Code feature in the Oloid Verify app allows Tenant Admins and Supervisors to generate and add a QR Code credential.

## Prerequisites

- You must have a Tenant Admin or Supervisor account.
- You must add the user. To add user refer[Oloid Verify: Add User](https://oloid.help/en/articles/8601073-oloid-verify-add-user).
- The Oloid Verify endpoint must be paired. To pair refer [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)

## Step to add QR Code

1. Launch the **Oloid Verify** app.
   ![Oloid Verify - Add QR Code - screenshot 1](/images/intercom/9570790/image-7fb0f024.png)
2. Log in to Admin mode in Oloid Verify app. To login, refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](https://oloid.help/en/articles/8671139-how-to-log-in-to-the-admin-mode-of-oloid-verify-app-as-an-admin-or-supervisor)
   The **Users** screen with list of users is displayed.
3. Tap on the preferred **user**.
   ![Oloid Verify - Add QR Code - screenshot 2](/images/intercom/9570790/e47ef40b-7431-4fbc-a7a4-16693889a243-004daf35.png)
   The User details are displayed on the **Details** screen.
   ![Oloid Verify - Add QR Code - screenshot 3](/images/intercom/9570790/image-4a1dd04d.png)
4. Go to **QR Code** > **Add QR Code**.
   ![Oloid Verify - Add QR Code - screenshot 4](/images/intercom/9570790/714ac463-9c51-4975-9759-a8ad6f919891-d09e05e2.png)
   The **Add QR Code** pop-up box is displayed.
5. On the pop-up box, do the following:
   1. Set **QR code Validity** from the calendar.
   2. Enter the recipient **Email ID(s)** to share **QR Code.** (Optional)
   3. Tap **Save**.
      ![Oloid Verify - Add QR Code - screenshot 5](/images/intercom/9570790/7d1879fc-93f6-46d1-8d01-5db1a04f17b5-db03152f.png)

The QR code is successfully assigned to the user.

![Oloid Verify - Add QR Code - screenshot 6](/images/intercom/9570790/image-c59e0e25.png)
