## Introduction

This document explains how to apply an endpoint template to a paired Oloid Verify endpoint in the Tenant Admin Portal. Applying the template makes sure the pre-set settings are automatically applied to the endpoint.

## Prerequisites

- You must have admin access to Tenant Admin Portal.
- The Oloid Verify endpoint must be paired. To pair, refer [How to pair an Oloid Verify endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)
- An Endpoint template must be created. To create, refer [How to create and configure Oloid Verify Endpoint Template](https://oloid.help/en/articles/10506225-how-to-create-and-configure-oloid-verify-endpoint-template)

## Steps to Apply Endpoint Template

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** from the left panel menu.
   ![How to Apply Template to Paired... - screenshot 1](/images/intercom/12866693/2e77e818-0456-4972-8080-8c6befda4a89-83136c0f.png)
   The endpoint screen is displayed.
3. Select the **Endpoint**.
   ![How to Apply Template to Paired... - screenshot 2](/images/intercom/12866693/33cd2326-27ec-49c8-95a5-5d1ba6552364-a9d548c4.png)
   The **Endpoint Detail** page is displayed.
4. Select **Action** dropdown > **Apply Template**.
   ![How to Apply Template to Paired... - screenshot 3](/images/intercom/12866693/1ef3173b-efdd-41ab-8cb4-3e84e889c036-acffd48b.png)
   The **Apply Template** pop-up box is displayed.
5. Choose the applicable template from the **Select Template** dropdown.
   ![How to Apply Template to Paired... - screenshot 4](/images/intercom/12866693/image-73ffbd03.png)
   The selected template is displayed in the **Select Template** field.
6. Click **Apply**.
   ![How to Apply Template to Paired... - screenshot 5](/images/intercom/12866693/a3a9dfb6-4607-4d8a-8d76-b25c569b6285-9783ca66.png)
   The Endpoint Template is successfully applied to the endpoint.
   ![How to Apply Template to Paired... - screenshot 6](/images/intercom/12866693/image-36b8da65.png)
