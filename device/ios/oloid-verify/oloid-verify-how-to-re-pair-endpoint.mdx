## Introduction

The Re-pair Endpoint feature in the Oloid Verify App allows Admin and Supervisor to restore an endpoint. This process ensures that the endpoint reconnects properly with the assigned application and continues to operate as expected.

## Prerequisite

- You must have a Tenant Admin account.
- You must complete the Admin Setup. To setup refer [Oloid Verify: Admin Setup.](https://oloid.help/en/articles/8601056-oloid-verify-app-installation-and-admin-setup)

## Steps to re-pair an endpoint

1. Launch the **Oloid Verify** app.
   **Could not display content**
2. Log in to Admin mode in Oloid Verify app. To login refer [How to log in to the admin mode of Oloid Verify App as an Admin or Supervisor.](https://oloid.help/en/articles/8671139-how-to-log-in-to-the-admin-mode-of-oloid-verify-app-as-an-admin-or-supervisor)
   The **Home** screen is displayed.
   ![How to Re-pair Endpoint - screenshot 1](/images/intercom/10198654/34dd8670-f732-465c-8a6d-5840774bee13-0e7ac140.png)
3. Go to **Settings** tab.
4. Tap **Click here to Re-pair if advised by Admin**.
   ![How to Re-pair Endpoint - screenshot 2](/images/intercom/10198654/fa270937-e100-432a-a7f5-0e7ac5c78a59-0d99c306.png)
   The **Enter Endpoint ID** pop-up is displayed.
5. On the pop-up, do the following:
   1. Enter **Endpoint ID**.
   2. Tap **Re-pair**.
      ![How to Re-pair Endpoint - screenshot 3](/images/intercom/10198654/image-b54d5027.png)

The Endpoint is re-paired successfully.

![How to Re-pair Endpoint - screenshot 4](/images/intercom/10198654/image-a49235da.png)

<Note>
  **Note:** Kill and relaunch the app to make the new updates function properly.
</Note>
