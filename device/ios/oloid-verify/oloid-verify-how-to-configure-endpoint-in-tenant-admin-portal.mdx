## Introduction

This document explains how to configure an endpoint in the Tenant Admin Portal. Endpoint configuration allows Tenant Admin to manage endpoint settings, appearance, groups and transaction behaviour for the **Oloid Verify** app.

<Note>
  **Note:** Once you pair an endpoint with Oloid Verify application, it gets saved and appears in the Tenant Admin Portal. After pairing, you can configure the endpoint.
</Note>

## Prerequisite

The Oloid Verify Endpoint must be paired. For more, refer to[How to Pair an Oloid Verify Endpoint](https://oloid.help/en/articles/8616605-how-to-pair-an-oloid-verify-endpoint)

## Steps to Configure the Endpoint

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Configure Endpoint in Tenant... - screenshot 1](/images/intercom/10511068/635e3de4-675c-46a8-93f8-37de42aa1b85-013fb478.png)
   The **Endpoints** page is displayed.
3. Select the paired Oloid Verify Endpoint.
   ![How to Configure Endpoint in Tenant... - screenshot 2](/images/intercom/10511068/image-3310ee8b.png)
   The **Endpoint Details** page is displayed.
   ![How to Configure Endpoint in Tenant... - screenshot 3](/images/intercom/10511068/image-0e0f3f91.png)
4. Do the following:
   1. [Configure Details Tab](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_468c479a7e)
   2. [Design Configure Tab](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_6dd96f73df)
   3. [Configure Transactions Tab](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_a6a25e71ec)
   4. [Configure Health Response Tab](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_79b6afb7ff)
      The Endpoint is configured successfully.

## Configure Details Tab

1. Edit **Endpoint Name** if required.
2. Enter **Endpoint Description**. (Optional)
3. Select **Time Zone** from the dropdown list. (Optional)

   <Note>
     **Note:** If time zone is not set for the Endpoint, it automatically uses the application's default time zone.
   </Note>

4. Click **Save**.
   ![How to Configure Endpoint in Tenant... - screenshot 4](/images/intercom/10511068/image-18075a1c.png)
   The Details tab is configured successfully.
   ![How to Configure Endpoint in Tenant... - screenshot 5](/images/intercom/10511068/image-ef84de75.png)

## Design Configure Tab

Configure the following:

- [Endpoint Settings](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_3e05774120)
- [Groups](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_a7bea6ee66)
- [Web Button](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_2b9aa9dc1e)
- [Health Setup](https://oloid.help/en/articles/10550185-oloid-connect-how-to-configure-endpoint-in-the-tenant-admin-portal#h_6ec36633ed)

#### Endpoint Settings

1. Turn on **Capture Location** toggleto activate location capture on the endpoint for each transaction.

   <Note>
     **Note:** The **Location Permission** of the device must be enabled to make the feature functional.
   </Note>

2. Turn on **Generate Debug Logs** toggle to activate log generation for the endpoint until disabled.
3. Click **Save**.
   ![How to Configure Endpoint in Tenant... - screenshot 6](/images/intercom/10511068/image-423c8ab5.png)
   The Endpoint setting is configured successfully.
   ![How to Configure Endpoint in Tenant... - screenshot 7](/images/intercom/10511068/image-69978342.png)

#### Groups

1. Turn on **One Face/User (On Device FR)** toggle to ensure that only one facial image of each user is stored on the device as a reference for On-device Transaction.
   ![How to Configure Endpoint in Tenant... - screenshot 8](/images/intercom/10511068/2d7782d2-a7c6-483d-ac1c-ae50b533eff3-ef1696f1.png)
2. Click **+ Add Group**.
   ![How to Configure Endpoint in Tenant... - screenshot 9](/images/intercom/10511068/image-0f34bcb3.png)
   The **Add Group** pop-up box is displayed.
3. Select group(s) in **Add Group** field.
4. Click **Save**.
   ![How to Configure Endpoint in Tenant... - screenshot 10](/images/intercom/10511068/d2daf6f8-a70d-4041-8f39-3fa01f9fc262-5ee5d0aa.png)
   The Group is added successfully.
   ![How to Configure Endpoint in Tenant... - screenshot 11](/images/intercom/10511068/image-c8069eac.png)

#### Web Button

1. Turn on **Web Button** toggle to display the Web Button on the endpoint preview screen. This button allows users to view transactions.
2. In the **URL** field, enter the complete URL of the website where users will review punch data.

   <Note>
     **Note:** You have to enter the URL of the website where the user will review the punches.
   </Note>

3. In the **Timeout** field, enter the delay (in minutes) before the URL launches.
4. Turn on **Show only on Auth** toggle to display the Web Button only after the user is successfully authorized. (Optional)
5. Turn on **Auto Launch** toggle to automatically launch the web button and view transaction. (Optional)

Click **Save**.

![How to Configure Endpoint in Tenant... - screenshot 12](/images/intercom/10511068/image-520e9202.png)

The Web Button is configured successfully.

![How to Configure Endpoint in Tenant... - screenshot 13](/images/intercom/10511068/image-544c6212.png)

#### Health Setup

1. Enter **Server Name**.
2. Enter URL of the server in **Add URL that needs to be monitored** field.
3. Click **Add**.
   The monitored URLs will appear in the list below, with columns for **Server Name** and **URL**.

   <Note>
     **Note:** Configure the settings only if they are applicable. Consult your Oloid representative before making any changes.
   </Note>

![How to Configure Endpoint in Tenant... - screenshot 14](/images/intercom/10511068/162d8483-a775-4d6d-ad86-a1a03916f163-3b2dcd7d.png)

The Server is added along with its URL successfully.

## Configure Transactions Tab

The Transactions tab allows you to view detailed user transactions. You can monitor transaction statuses and filter results based on success or failure.

![How to Configure Endpoint in Tenant... - screenshot 15](/images/intercom/10511068/image-7052b023.png)

## Configure Health Response Tab

1. Turn on **Share Endpoint Logs** toggle to share logs.
2. Turn on **Relaunch** toggle to automatically apply changes made on the Tenant Admin Portal to the Oloid Verify app without manually closing or restarting the app.
3. Click **Check Health** to initiate a health check successfully.

![How to Configure Endpoint in Tenant... - screenshot 16](/images/intercom/10511068/5f12bbb2-9842-4a24-a7e3-bb7b089feb99-67a4e5c0.png)

In this section, you can see the endpoint status, check health of the endpoint and configure health alert. For more information on health alert, see [How to configure health alert for an endpoint](https://oloid.help/en/articles/8245679-how-to-add-health-alerts-in-the-endpoint).
