## Introduction

The Unpair Endpoint feature in the Oloid DeviceLock App allows admins to disconnect an endpoint that is no longer in use or requires reconfiguration.

## Prerequisite

The Endpoint must be paired. To pair refer [How to pair a DeviceLock endpoint](https://oloid.help/en/articles/9291207-how-to-pair-a-devicelock-endpoint).

## Steps to Unpair Endpoint

1. Launch **Oloid DeviceLock App** on your device.
   ![How to Unpair an Endpoint - screenshot 1](/images/intercom/10329310/image-785b943a.png)
   The welcome screen is displayed.
2. Login to the Admin mode in **DeviceLock App.** To login refer[How to log in to admin mode in DeviceLock App](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-devicelock-app).
   The **Settings** screen is displayed.
3. Tap **Unpair**.
   ![How to Unpair an Endpoint - screenshot 2](/images/intercom/10329310/image-4748541a.png)
   The **Confirm Unpair** pop-up box is displayed.
4. Tap **Unpair**.
   ![How to Unpair an Endpoint - screenshot 3](/images/intercom/10329310/image-6e430f42.png)
   The device is unpaired successfully.
   ![How to Unpair an Endpoint - screenshot 4](/images/intercom/10329310/image-157f8d92.png)
