## Introduction

The Oloid DeviceLock App allows Admin and Supervisors to securely reset their password using the **Forgot Password** option. This feature helps restore access to the app by sending a confirmation code to the registered email address.

## Steps to reset Admin Password

1. Launch DeviceLock app.
   ![How to Reset the Admin Password - screenshot 1](/images/intercom/12106226/image-aee76465.png)
   The Welcome screen is displayed.
2. Click **More option** icon (![How to Reset the Admin Password - screenshot 2](https://downloads.intercomcdn.com/i/o/e4gi378c/1697246301/cbd5ba75d248ec277789a16716d8/image.png?expires=1790294400&signature=a0b64178580fa6fa3dac817b73493b9614879d9b13f806ec7bfecb1f9d29052c&req=dSYuEct6m4JfWPMW3nq%2BgUPQMtopLfxOe%2FKHwOwnODZte8L%2BhLoKGj1wxuyt%0AjF5snLFPrKjiSsd7V5VlFjk4oU0%3D%0A)) on bottom-right side of the screen.
   ![How to Reset the Admin Password - screenshot 3](/images/intercom/12106226/image-425363f0.png)
   The **Enter Admin Mode** pop-up box is displayed.
3. On the **Enter Admin Mode** pop-up box, tap **Continue**.
   ![How to Reset the Admin Password - screenshot 4](/images/intercom/12106226/image-c475ff59.png)
   The setting page is displayed.
4. Tap **Login as Supervisor**.
   ![How to Reset the Admin Password - screenshot 5](/images/intercom/12106226/image-5fe612aa.png)
   Pair as Supervisor screen is displayed.
5. Tap **Forgot Password**.
   ![How to Reset the Admin Password - screenshot 6](/images/intercom/12106226/image-28a1c288.png)
   Reset Password screen is displayed.
6. Enter Email ID > tap **Reset**.
   ![How to Reset the Admin Password - screenshot 7](/images/intercom/12106226/image-5bf32d67.png)
   Reset Password instructions are sent to the registered email ID successfully.
   ![How to Reset the Admin Password - screenshot 8](/images/intercom/12106226/Screenshot_20250828_141531_Oloid-DeviceLock-1--a2270bf5.jpg)
7. Open your email account and go to the **inbox.**
8. Copy the **confirmation code** > click on the **Reset Password** link.
   ![How to Reset the Admin Password - screenshot 9](/images/intercom/12106226/image-cae9a81d.png)
   The **Set New Password** page is displayed.
9. Enter **Work Email ID**.
10. Enter **Confirmation Code** in the **Code** field.
11. Enter **New Password**.
12. Click **Login.**
    ![How to Reset the Admin Password - screenshot 10](/images/intercom/12106226/image-2164ad13.png)
    The Password for Oloid DeviceLock is reset successfully.
    ![How to Reset the Admin Password - screenshot 11](/images/intercom/12106226/image-cd25d412.png)
