## Introduction

The **Auto-Pair Config File** feature in the **Tenant Admin Portal** allows admin to generate configuration files used for automatically pairing endpoints or devices with specific applications. This simplifies the setup process by eliminating the need for manual pairing, ensuring faster deployment and secure authentication between devices and applications.

## Prerequisite

You have **Admin access** to the **Tenant Admin Portal**.

## Steps to Generate Auto-pair Config File

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Generate Auto-Pair Config File... - screenshot 1](/images/intercom/12728542/image-83a78116.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Generate Auto-Pair Config File... - screenshot 2](/images/intercom/12728542/image-466c99a1.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > **API Token `**> **API Key**.
   ![How to Generate Auto-Pair Config File... - screenshot 3](/images/intercom/12728542/image-edfd3a2b.png)
5. In the **Generate Temporary Access Token** section, do the following:
   1. Select the **Start Date/Time** field.
      - To set the start date and time, click the date picker or select **Now**.
   2. Select the **End Date/Time** field.
      - Click the date picker, choose when the token will expire, and then click **OK**.
   3. Specify **Number of Endpoints** that can be created using the auto-config file. (Optional)
   4. Click **Generate**.
      ![How to Generate Auto-Pair Config File... - screenshot 4](/images/intercom/12728542/image-8bbf5573.png)
      The auto-pair config file is generated.
6. Click **Auto-pair config file**.
   ![How to Generate Auto-Pair Config File... - screenshot 5](/images/intercom/12728542/ca6e65c5-4747-4b0a-89f6-2f2f2e20d16e-c6095aa9.png)
   The Auto-pair config file pop-up box is displayed.
7. Do the following:
   1. Select **Application** as **Passwordless - DeviceLock** from **Application Type** dropdown list.
   2. From the **Select Application** dropdown list, select the application that you want the endpoints to pair with.
   3. Select **Skip user confirmation for pairing** option to auto-pair endpoints without requiring user confirmation (optional but recommended).
      - **If selected:** When the configuration file is uploaded to the endpoint, the system will pair automatically without prompting the user for confirmation.
      - **If not selected:** The system will display a confirmation pop-up to the user before completing the pairing process.
   4. Click **Download**.
      ![How to Generate Auto-Pair Config File... - screenshot 6](/images/intercom/12728542/image-56e6cef8.png)
      The Autopair Config file is downloaded to the local device.

      <Note>
        **Note:** To update the Auto-Pair configuration after generating the configuration file, refer to [Tenant Admin Portal - How to Update Auto-Pair Config File for Oloid DeviceLock App](https://oloid.help/en/articles/12105399-tenant-admin-portal-how-to-update-auto-pair-config-file-for-oloid-devicelock-app). After updating the configuration, upload the updated Auto-Pair configuration file to the endpoints manually or deploy it using your MDM solution for the changes to take effect.
      </Note>
