Device Lock is an Android-based application that allows you to log in to your Workforce/HRMS platforms using physical identity factors (like Face, Badge, NFC tags, QR Code, and PIN). The physical identity factors can be combined to implement Multi-factor Authentication.

## Installation

You can download and install the Device lock from the Play Store.

For instructions to download the app, see [How to download Device Lock app](https://oloid.help/en/articles/10062644-how-to-download-device-lock-app)

For instructions to install the app, see [How to install Oloid Device Lock app](https://oloid.help/en/articles/8679116-how-to-install-oloid-devicelock-app)

## Configuration

For Device Lock app to function, it needs to be configured in the Oloid Platform.

### Initial set up

- Set up Application and Connection
- Create user and assign user to Connection.
- Enable Authenticator factors in Application

For setting up Application and Connection, see [How to create and configure Device Lock application](https://oloid.help/en/articles/8698213-how-to-create-and-configure-device-lock-application) guide

For creating user in Oloid Portal, see [User Onboarding](https://oloid.help/en/articles/8463554-user-onboarding) guide.

For assigning user to Connection, see [How to add user](https://oloid.help/en/articles/8185048-how-to-add-user) guide.

**For enabling Authenticator factors, see TBD**

### Credential Set up

This is based on client requirements. Device Lock functions with a single factor (like Face, Badge, NFC tags, QR Code, and PIN) or a combination of factors ( **Badge + PIN**, **QR + PIN**, and **NFC + PIN**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](https://oloid.help/en/articles/8413861-face-onboarding) guide
- Create Badge and assign it to users. Refer [Badge Onboarding](https://oloid.help/en/articles/8402155-badge-onboarding) guide
- Create NFC and assign it to users. Refer [NFC Onboarding](https://oloid.help/en/articles/8600311-nfc-onboarding) guide
- Create PIN and assign it to users. Refer [PIN Onboarding](https://oloid.help/en/articles/8408444-pin-onboarding) guide
- Create QR Code and assign it to users. Refer [QR Onboarding](https://oloid.help/en/articles/8408452-qr-onboarding) guide

### Multi-factor Authentication(MFA) Config

To enable Multi-factor Authentication (MFA) in Oloid's Device Lock, see [Factor Sequencing for Multi-factor authentication in Oloid Device Lock](https://oloid.help/en/articles/8402909-factor-sequencing-for-multi-factor-authentication-in-oloid-devicelock)
