## Introduction

The Add User feature in the Oloid DeviceLock App allows administrators to register new users and assign them unique identification details for device access. By adding users through Admin Mode, organizations can efficiently manage user credentials, maintain secure access control, and ensure proper tracking of device usage.

## Prerequisite

You must create a connection. To create connection refer [How to create Connections in the Tenant Admin Portal](https://oloid.help/en/articles/8294297-how-to-create-connections-in-the-tenant-admin-portal).

## Steps to add user

1. Launch **Oloid DeviceLock App** on your device.
   ![How to Add User in Oloid DeviceLock App - screenshot 1](/images/intercom/9335055/image-bb3c9fe0.png)
2. Log in to the Admin Mode in **Oloid DeviceLock** App. For more details, refer this [How to log in to admin mode in DeviceLock App](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-devicelock-app).
3. Click **Add User** on the right-top side of the screen.
   ![How to Add User in Oloid DeviceLock App - screenshot 2](/images/intercom/9335055/image-60b986b8.png)
   The **Add User** screen is displayed.
4. Enter **Name**.

   <Note>
     **Note:** First name and Last name should be separated by a space.
   </Note>

5. Enter **Primary ID**.

   <Note>
     **Note:** Only alphabets, numbers, and hyphen are accepted.
   </Note>

6. Enter **Secondary ID**.

   <Note>
     **Note:** Only numbers are accepted.
   </Note>

7. Click **Select connection**.
   ![How to Add User in Oloid DeviceLock App - screenshot 3](/images/intercom/9335055/image-6989f71f.png)
   The Select Connections pop-up box is displayed.
8. Select the preferred connection.
9. Click **Add**.
   ![How to Add User in Oloid DeviceLock App - screenshot 4](/images/intercom/9335055/image-96bd09b4.png)
   The **Add User** screen is displayed.

Click **Add User**.

![How to Add User in Oloid DeviceLock App - screenshot 5](/images/intercom/9335055/image-d9e6b711.png)

The user is successfully added and listed in the users list.

![How to Add User in Oloid DeviceLock App - screenshot 6](/images/intercom/9335055/image-04525dc4.png)
