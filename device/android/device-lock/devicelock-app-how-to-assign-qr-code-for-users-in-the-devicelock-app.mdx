## Introduction

The **QR Code** feature in the **Oloid DeviceLock App** allows admin to assign QR codes to users for secure, passwordless authentication on Android devices.

## Prerequisite

You must have **Admin Access** in the Device Lock Application.

## Steps to Assign QR Code

1. Login to the Admin mode in **DeviceLock App.** To login refer[How to log in to admin mode in DeviceLock App](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-devicelock-app).
2. Go to **Users** tab > select the preferred user.
   ![How to Assign QR Code for Users in the... - screenshot 1](/images/intercom/12741303/7e9c4483-8ed9-487b-847d-2a7439a2533d-ce730aac.png)
   The user details screen is displayed.
3. Tap **QR Code**.
   ![How to Assign QR Code for Users in the... - screenshot 2](/images/intercom/12741303/ad739067-f762-4224-9147-74d549a0f2ae-3bbaed54.png)
   The QR Code screen is displayed.
4. Tap **Add**.
   ![How to Assign QR Code for Users in the... - screenshot 3](/images/intercom/12741303/37d1dbb5-86b6-40a9-9a10-576681c0113d-73cd642d.png)
   The **Create QR Code** pop-up box is displayed.
5. Do the following:
   1. Select **QR Code Validity**.
   2. Enter the Email ID (Optional).
   3. Tap **Create**.

![How to Assign QR Code for Users in the... - screenshot 4](/images/intercom/12741303/39cd8e18-e724-422f-a8d6-5d69fac092a5-627db1a3.png)

The QR Code is added successfully.

![How to Assign QR Code for Users in the... - screenshot 5](/images/intercom/12741303/image-e76488fd.png)

The created QR code is displayed in the QR Code tab.

![How to Assign QR Code for Users in the... - screenshot 6](/images/intercom/12741303/27d25950-94f5-4293-8bf8-ae54c1ac3fc6-9f99be9b.png)
