## Introduction

The Oloid DeviceLock App allows admins to manage and monitor user access efficiently. By viewing user details, admins can verify user information such as name, credentials, and access status directly within the app. This feature helps ensure proper user management and quick troubleshooting when needed.

## Prerequisite

You must add the User. To add refer [How to add user in Oloid DeviceLock App](https://oloid.help/en/articles/9335055-how-to-add-user-in-oloid-devicelock-app).

## Steps to view user details

1. Launch **Oloid DeviceLock App** on your device.
   ![How to View User Details in Oloid... - screenshot 1](/images/intercom/11495355/image-ab1a8646.png)
2. Log in to the Admin Mode in **Oloid DeviceLock** App. For more details, refer this [How to log in to admin mode in DeviceLock App](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-devicelock-app).
   The User's screen is displayed.

Tap on the preferred User's profile.

![How to View User Details in Oloid... - screenshot 2](/images/intercom/11495355/image-14eeb3d3.png)

The User's details is successfully viewed.
