## Introduction

A tenant in Oloid DeviceLock App is a dedicated space with its own users, devices, and configurations. Resetting a tenant clears all existing data and settings, allowing you to start over.

## Prerequisite

You must pair DeviceLock endpoint. For more details refer: [Oloid DeviceLock - How to pair an endpoint](https://oloid.help/en/articles/9291207-how-to-pair-a-devicelock-endpoint).

## Steps to Reset Tenant

1. Launch **Oloid DeviceLock App** on your device.
   ![DeviceLock App – How to Reset Tenant - screenshot 1](/images/intercom/10473240/image-bb3c9fe0.png)
2. Log in to the Admin Mode in **Oloid DeviceLock** App. For more details, refer this [Oloid DeviceLock App - How to log in to admin mode](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-oloid-devicelock-app)
3. On the bottom right, select More Options ![DeviceLock App – How to Reset Tenant - screenshot 2](https://downloads.intercomcdn.com/i/o/e4gi378c/1354478417/06ea3078bfcb2128928f2d3d25ef/image.png?expires=1790294400&signature=7dbdcfdad3cbf00fdecc694c50dc9734da90c689b895582665f1779aff72dcc4&req=dSMiEs15lYVeXvMW3nq%2BgXiv46IW%2BfKP30PBG4mK4IId%2FiBeQuaZ7Ifb9VK6%0Ap3nGW4AKDKGZUU8sWTUihEbkLgk%3D%0A) icon > tap **Reset Tenant**.
   ![DeviceLock App – How to Reset Tenant - screenshot 3](/images/intercom/10473240/5c70c4ee-a96d-4517-a2e0-44fe44304eca-4f9bcf22.png)
   The confirmation pop-up box is displayed.

Tap **Reset**.

![DeviceLock App – How to Reset Tenant - screenshot 4](/images/intercom/10473240/image-2baa111e.png)

The tenant reset successfully.
