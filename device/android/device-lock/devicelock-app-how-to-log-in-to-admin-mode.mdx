## Introduction

The **Admin Mode** in the Oloid DeviceLock app allows the Tenant Admin or Supervisor to access advanced settings and manage application configurations securely.

## Prerequisite

You must pair your endpoint with the Oloid DeviceLock app. To pair refer [How to pair a DeviceLock endpoint](https://oloid.help/en/articles/9291207-how-to-pair-a-devicelock-endpoint).

<Note>
  **Note:** After pairing the endpoint using either the *"Auto-Pair"* or *"Auto-Pair using Config File"* option, you can tap **Continue with Admin** on the success screen to log in as Admin. If Endpoint is paired you can follow the below steps.
</Note>

## Steps to log in to admin mode

1. Launch Oloid DeviceLock app.
   ![How to Log in to Admin Mode - screenshot 1](/images/intercom/10353022/image-7f9bcfb2.png)
   The Welcome screen is displayed.
2. Do one of the following:
   1. Tap more option ( ![How to Log in to Admin Mode - screenshot 2](https://downloads.intercomcdn.com/i/o/e4gi378c/1737629734/408ce32a1286414e5abe40f4dc61/image.png?expires=1790294400&signature=6fc2820b187870a72fd50f882f5ae245b8822702bcf8302d3704e3eed5d3d3b1&req=dSckEc98lIZcXfMW3nq%2BgWc2i84Uq7zF9PE4oY7UmmYaer3f8zNtg7DgRHAF%0AqfpjkmIHMvIPUC1Grmwu%2B%2BLXF5U%3D%0A) ) on the bottom right side of the screen.
      or
   2. Double tap on the screen.
      ![How to Log in to Admin Mode - screenshot 3](/images/intercom/10353022/image-5d929026.png)
      The Enter Admin pop-up box is displayed.
3. Tap **Continue**.
   ![How to Log in to Admin Mode - screenshot 4](/images/intercom/10353022/image-c60dd704.png)
   The Setting page is displayed.
4. Tap **Login as Supervisor**.
   ![How to Log in to Admin Mode - screenshot 5](/images/intercom/10353022/image-04581961.png)
   The Pair as Supervisor screen is displayed.
5. Do the following:
   1. Enter **Username** or **Email ID** in the text field.
   2. Enter **Password**.
   3. Tap **Login**.

![How to Log in to Admin Mode - screenshot 6](/images/intercom/10353022/image-b705a4b6.png)

You have logged in to Oloid DeviceLock in Admin mode successfully.
