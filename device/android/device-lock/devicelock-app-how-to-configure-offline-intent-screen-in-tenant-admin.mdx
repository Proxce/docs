## Introduction

The Offline Intent Screen allows users to choose an intent when the device is not connected to internet. You can enable the Offline intent screen, show an offline message, and configure intent buttons that appear on the screen.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- The **Oloid Device Lock** application must be created and configured in the Tenant Admin Portal. For more details refer, [How to Create and Configure DeviceLock Application in the Tenant Admin Portal](https://oloid.help/en/articles/8698213-how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal)
- Ensure that the authentication method (FR Mode) is set to **Hybrid**.
- Ensure that the user and endpoint are added to the appropriate group. For more information, refer [How to Configure Group](https://oloid.help/en/articles/8311585-tenant-admin-portal-how-to-configure-group).

## Steps to Configure Offline Intent Screen

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Device Lock application.
   ![How to Configure Offline Intent Screen... - screenshot 1](/images/intercom/14084872/image-6666d3e9.png)
   The application **details** page is displayed.
   ![How to Configure Offline Intent Screen... - screenshot 2](/images/intercom/14084872/image-057ffc51.png)
3. Go to **Configure** tab > **Offline Intent Screen.**
   ![How to Configure Offline Intent Screen... - screenshot 3](/images/intercom/14084872/image-bf62d36b.png)
4. Do the following:
   1. [Configure Show Intent Screen](#configure-show-intent-screen)
   2. [Configure Multi Button Intent Screen](#configure-multi-button-intent-screen)
      The Offline Intent Screen is configured successfully.

### Configure Show Intent Screen

1. Enable **Show Intent Screen** toggle.
2. Do the following:
   1. Turn on **Show Offline Mode Banner** toggle.
   2. Review or edit the banner message displayed to users on the Intent Screen (Optional)

      ![How to Configure Offline Intent Screen... - screenshot 4](/images/intercom/14084872/ad55e70d-a460-40ab-b37a-e2c1d472e239-48efdefd.png)
      The Show Intent Screen is configured successfully.

### Configure Multi-Button Intent Screen

1. Enter a title in the **Intent Screen Heading** field. This title appears at the top of the intent screen.
2. Type a short description in the **Intent Screen Description** field.
   ![How to Configure Offline Intent Screen... - screenshot 5](/images/intercom/14084872/02851a8a-b811-45d7-9442-3bfccf240ba8-e33365dc.png)
3. Configure the intent screen buttons.
   The intent screen is configured successfully.

#### Configure Intent Screen Buttons

<Note>
  **Note:** You can configure at least one and up to six intent buttons.
</Note>

1. Click **+Add Button** to add an intent button.
   The button section is displayed.
   ![How to Configure Offline Intent Screen... - screenshot 6](/images/intercom/14084872/image-07758e17.png)
2. Select **Button Type** from the dropdown list.
3. Enter **Button Label**.

   <Note>
     **Note:** The button label is displayed on the intent screen.
   </Note>

4. Configure the Advanced Settings (Optional).
   The intent screen buttons are configured.

#### Configure Advanced Settings Flags

1. Select **Show Pop up** to display a confirmation pop-up box when a user taps the intent button.
2. Do the following:
   1. In the **Popup Heading** field**,** enter the title text that appears at the top of the popup.

      <Note>
        **Note:** This heading should clearly describe the purpose of the popup.
      </Note>

   2. In the **Popup Content** field, enter the main message or instructions displayed inside the popup.

      <Note>
        **Note:** This content should provide clear and concise information to the user.
      </Note>

      ![How to Configure Offline Intent Screen... - screenshot 7](/images/intercom/14084872/image-15b5b0d7.png)
3. Select **Show Selection Dropdown 1** (or Dropdown 2 if required).
4. Configure the following fields:
   - **Heading:** Enter the title displayed on the dropdown screen.
   - **Sub-heading:** (Optional) Provide additional context.
   - **Dropdown Label:** Enter the label shown for the dropdown field.
5. Enable the **Full Width Button** toggle (Optional).
6. Click **View and Edit Options**.
   ![How to Configure Offline Intent Screen... - screenshot 8](/images/intercom/14084872/image-5b892b89.png)
   The **View or Edit Dropdown Options** pop-up box is displayed.
7. Click **Download Template** and select one of the following formats:
   - CSV
   - XLSX
8. Open the downloaded file and add or update the dropdown values as required.
9. Upload the CSV/XLSX file using one of the following options:
   - **Drag and drop** the file.
   - **Click to upload** and select the file from your system.
     ![How to Configure Offline Intent Screen... - screenshot 9](/images/intercom/14084872/image-9dd5548f.png)
10. After the file is uploaded, review the **Analyze** section.
    - Ensure the result displays **"result": "ok"**, indicating a successful validation.
11. Click **Import**.
    ![How to Configure Offline Intent Screen... - screenshot 10](/images/intercom/14084872/image-0a77eeac.png)
    The Offline Intent Screen is configured successfully.
