## Introduction

Pairing a DeviceLock endpoint with the app establishes a secure connection, ensuring proper management and readiness for use.

## Prerequisites

- You must install Oloid DeviceLock app. To install refer [How to install Oloid DeviceLock App](https://oloid.help/en/articles/8679116-how-to-install-oloid-devicelock-app).
