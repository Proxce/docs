## Introduction

This document provides step by step instructions for configuring passwordless access on Android devices using **Oloid DeviceLock** and **WebKey (Oloid Browser).** The setup enables users to authenticate via **Face or NFC** through the **DeviceLock** app and automatically launch the **WebKey page** in Oloid Browser to seamlessly access the **Okta dashboard** without entering credentials.

## Prerequisites

- You must have **Admin access** to the Tenant Admin Portal.
- You must **create and configure the DeviceLock application** and enable Face and NFC under the authenticator tab.
- You must **create and configure WebKey application.**

## Step 1: Configure Device Lock and Webkey Applications

- Setup Device Lock Application in platform
- Setup Webkey Application in the platform

### Setup Device Lock Application in Tenant Admin Portal

1. Log in to the **Tenant Admin Portal.**
2. On the homepage of the portal, click on the **Device Lock** application to edit.

   <Note>
     **Note:** Refer to [create and configure the DeviceLock application.](https://oloid.help/en/articles/8698213-how-to-create-and-configure-devicelock-application-in-the-tenant-admin-portal)
   </Note>

   ![Android Passwordless Device Unlock with... - screenshot 1](/images/intercom/13855587/image-49053a90.png)
   The application details page is displayed.
   ![Android Passwordless Device Unlock with... - screenshot 2](/images/intercom/13855587/image-7ba91b8c.png)
3. Go to **Configure** tab > Click **Settings**.
   ![Android Passwordless Device Unlock with... - screenshot 3](/images/intercom/13855587/image-21957e62.png)
   The Settings page is displayed.
4. Enable **Auto Authentication of Webkey using Local Transaction** toggle**.**
5. Click **Save.**
   ![Android Passwordless Device Unlock with... - screenshot 4](/images/intercom/13855587/a00ff168-af9f-4419-a558-03868a02ad8c-14b40469.png)
6. Go to **Configure Passwordless.**
   The Configure Passwordless screen is displayed.
7. Do the following:
   1. **Enable Passwordless Config** toggle.
   2. Select **Device Lock Mode.**
   3. Click **Save.**
      ![Android Passwordless Device Unlock with... - screenshot 5](/images/intercom/13855587/image-463fe1ec.png)
      The Device Lock application setup is completed successfully.
      ![Android Passwordless Device Unlock with... - screenshot 6](/images/intercom/13855587/image-615a5fbb.png)

### Setup Webkey Application in the Tenant Admin Portal

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the **Webkey** application to edit. For more, refer to [create and configure WebKey application.](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application-in-tenant-admin-portal)
   ![Android Passwordless Device Unlock with... - screenshot 7](/images/intercom/13855587/image-0b85b191.png)
   The **Application Details** page is displayed.
   ![Android Passwordless Device Unlock with... - screenshot 8](/images/intercom/13855587/image-bf51329e.png)
3. Go to **Configure** > Click **Settings**.
   The settings page is displayed.
   ![Android Passwordless Device Unlock with... - screenshot 9](/images/intercom/13855587/image-6f0485fb.png)
4. Do the following:
   1. Enable **Auto-Authentication using Local transactions** toggle button will allow user to auto-authenticate into Webkey after device login.
   2. Enable **Continue Without Local Transaction** toggle button will allow user to authenticate manually without giving an error if local authentication transaction is not found.
   3. Click **Save.**
      ![Android Passwordless Device Unlock with... - screenshot 10](/images/intercom/13855587/image-f1e0478d.png)
      The **Webkey** application setup is completed successfully.
      ![Android Passwordless Device Unlock with... - screenshot 11](/images/intercom/13855587/image-9a0365fb.png)

## Step 2: Install, Pair and Setup the Oloid Browser and Device Lock Application on Android Device

### Installation

1. Install Oloid Browser on your android device.

   <Note>
     **Note:** Contact **Oloid support** to get the **APK files.**
   </Note>

2. Download and install the **DeviceLock** app from the **Google Play Store**. For More, refer to [How to Download DeviceLock App](https://oloid.help/en/articles/10062644-how-to-download-devicelock-app)
3. Provide all the required permissions to DeviceLock app. (Go to Settings and allow Restricted Permissions for the DeviceLock app to provide all required permissions.)

### Steps to Pair Device Lock Endpoint

Once the Device Lock application is successfully installed you need to pair your endpoint.
You can pair DeviceLock endpoint using any of the following options:

- [How to pair Oloid DeviceLock App using "Pair as Supervisor" option](https://oloid.help/en/articles/10323332-how-to-pair-oloid-devicelock-app-using-pair-as-supervisor-option).
- [How to Pair Oloid DeviceLock App using "Auto-Pair" option](https://oloid.help/en/articles/12164310-how-to-pair-oloid-devicelock-app-using-auto-pair-option).
- [How to Pair Oloid DeviceLock App using the “Auto-Pair using Config File” option](https://oloid.help/en/articles/12114460-how-to-pair-oloid-devicelock-app-using-the-auto-pair-using-config-file-option).
- (Optional) You can select the Device Lock Endpoint template while pairing the endpoint. For more, refer to [How to Create and Configure DeviceLock Endpoint Template in Tenant Admin Portal](https://oloid.help/en/articles/10489271-how-to-create-and-configure-devicelock-endpoint-template-in-tenant-admin-portal)

  <Note>
    **Note:** After the endpoint is successfully paired, you must enable the **Passwordless Session Token** toggle and the **Include user token in response** toggle for the endpoint in the **Tenant Admin Portal**. For more, refer to [How to Configure Endpoint in the Tenant Admin Portal](https://oloid.help/en/articles/13330667-devicelock-app-how-to-configure-endpoint-in-the-tenant-admin-portal#:~:text=is%20added%20successfully.-,Integration%20tab,-Click%20Integration.)
  </Note>

### Add WebKey Shortcut to Oloid Browser

1. Open **Oloid Browser** on the Android device.
2. Open a new tab and navigate to the **configured WebKey URL**.
3. Tap the **browser menu** (kebab icon).
   ![Android Passwordless Device Unlock with... - screenshot 12](/images/intercom/13855587/image-de45cc34.png)
4. Select **Add app to Home screen.**
   ![Android Passwordless Device Unlock with... - screenshot 13](/images/intercom/13855587/31fb618f-513a-4b1a-9b96-549286561ece-7ec00532.png)
   A Confirmation pop-up box is displayed.
5. Tap **Add**.
   ![Android Passwordless Device Unlock with... - screenshot 14](/images/intercom/13855587/c14a4393-f214-48eb-a1af-57705ef2efdb-cdf9cac2.png)
   The **Oloid WebKey App** shortcut is added to the Android home screen.
   ![Android Passwordless Device Unlock with... - screenshot 15](/images/intercom/13855587/image-ad2ef9b4.png)

## Step 3: Use Case

### Authenticate using Face

1. Press the **Power button** or tap the screen on your device.
   The **Welcome** screen is displayed.
2. Tap **Login with Face**.
   ![Android Passwordless Device Unlock with... - screenshot 16](/images/intercom/13855587/image-a2fb42c8.png)
   The camera turns on.
3. Position your face in front of the camera and tap the **Capture** button to complete the authentication process.

   <Note>
     **Note:** If you do not tap the Capture button, the app automatically captures your face after a few seconds.
   </Note>

   ![Android Passwordless Device Unlock with... - screenshot 17](/images/intercom/13855587/eb6797bc-35b4-45ee-b9e4-e91db0bb1cd6-d79c8698.png)
   After successful authentication, the user is redirected to the Android home page.
4. Tap **Oloid Webkey App.**

![Android Passwordless Device Unlock with... - screenshot 18](/images/intercom/13855587/image-e1b28a0b.png)

The Oloid Browser redirects the user to the **WebKey page**.

![Android Passwordless Device Unlock with... - screenshot 19](/images/intercom/13855587/e4b89cc5-5afc-4d4c-a5ef-1ab3ec06ce17-ae6e14d9.png)

The WebKey page redirects to the Okta dashboard automatically and Okta dashboard is launched successfully.

![Android Passwordless Device Unlock with... - screenshot 20](/images/intercom/13855587/e1cfe1a1-6c8c-4409-91c5-e09e4e6d8a1b-7dfe39f7.png)

### Authenticate using NFC

1. Press the **Power** button or tap the screen on your device.
   The **Welcome** screen is displayed.
2. Tap **Login with NFC Tag**.

   <Note>
     **Note:** Ensure that the Android device must be connected to an external NFC reader/card reader.
   </Note>

   ![Android Passwordless Device Unlock with... - screenshot 21](/images/intercom/13855587/image-972b8d08.png)
   The **Tap NFC Tag at the device** pageis displayed.
3. Scan the NFC Tag.
   ![Android Passwordless Device Unlock with... - screenshot 22](/images/intercom/13855587/image-12558d86.png)
   After successful NFC authentication, the user is redirected to the Android home page.
4. Tap **Oloid Webkey App** to launch the browser.

![Android Passwordless Device Unlock with... - screenshot 23](/images/intercom/13855587/image-73213410.png)

The Oloid Browser redirects the user to the **WebKey page**.

![Android Passwordless Device Unlock with... - screenshot 24](/images/intercom/13855587/e4b89cc5-5afc-4d4c-a5ef-1ab3ec06ce17-85e6bae3.png)

The WebKey page redirects to the Okta dashboard automatically and Okta dashboard is launched successfully.
