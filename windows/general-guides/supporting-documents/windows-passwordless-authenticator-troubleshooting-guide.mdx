## Introduction

This guide provides troubleshooting steps for commonly reported issues in **Windows Login**. It helps admins identify and resolve issues related to authentication, badge/QR login, device pairing, and connectivity.

---

## Prerequisites

Before troubleshooting, ensure:

- You have access to the **Tenant Admin Portal**
- The endpoint device is powered on and connected to the network
- Required hardware (camera, NFC reader, badge reader) is connected and functional
- The Windows Authenticator App is installed and running
- The endpoint is successfully paired with the Tenant Admin Portal

### Badge / QR Issues

**Issue / Error Message**

**Problem Description**

**Possible Cause**

**Troubleshooting Steps**

**Resolution / Action**

<Note>
  **Note:**

  **Badge Not Recognized**
</Note>

Badge scan does not trigger login.

Badge not mapped or reader issue.

1. Verify badge ID mapping.
2. Check reader connection.
3. Confirm configuration.
4. Retry scan.

Map correct badge or restart reader/device.

Ensure correct badge format.

**QR Code Scan Failed**

QR authentication fails.

Invalid or expired QR code, camera issue.

1. Regenerate QR code.
2. Check camera functionality.
3. Ensure session is active.
4. Retry scan.

Use valid QR code and ensure camera works.

QR codes are time-sensitive.
