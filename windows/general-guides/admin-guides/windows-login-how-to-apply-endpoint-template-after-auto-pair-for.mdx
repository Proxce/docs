## Introduction

This document describes how to apply an endpoint template in the Tenant Admin Portal after completing auto-pair configuration on the Windows Login application. Applying an endpoint template ensures that predefined settings are consistently and automatically applied across all applicable device(s).

## Prerequisites

- You must have a Tenant Admin Account.
- The Windows Login App must be auto paired. To auto-pair refer [How to Install and Auto-Pair Windows Authenticator App through MDM](https://oloid.help/en/articles/10449230-how-to-install-and-auto-pair-windows-authenticator-app-through-mdm#h_356ec33c7a)
- An Endpoint template must be created. To create refer [How to create an endpoint template](https://oloid.help/en/articles/8217339-how-to-create-an-endpoint-template).

## Steps to apply Endpoint Template after Auto-pair

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click **Endpoints** from the left panel menu.
   ![How to apply Endpoint Template after... - screenshot 1](/images/intercom/12576484/image-74f0ecac.png)
   The endpoint screen is displayed.
3. Select the **Endpoint**.
   ![How to apply Endpoint Template after... - screenshot 2](/images/intercom/12576484/0ae2709a-6f9a-42fb-a288-31d1d4112865-51b62ba7.png)
   The **Endpoint Detail** page is displayed.
4. Select **Action** dropdown > **Apply Template**.
   ![How to apply Endpoint Template after... - screenshot 3](/images/intercom/12576484/image-91b9b917.png)
   The **Apply Template** pop-up box is displayed.
5. Choose the applicable template from the **Select Template** dropdown.
   ![How to apply Endpoint Template after... - screenshot 4](/images/intercom/12576484/image-f484da34.png)
   The selected template is displayed in the **Select Template** field.
6. Click **Apply**.
   ![How to apply Endpoint Template after... - screenshot 5](/images/intercom/12576484/image-3aeacea1.png)
   The template is successfully applied to the endpoint.
   ![How to apply Endpoint Template after... - screenshot 6](/images/intercom/12576484/image-dd7db911.png)
