## Introduction

The On-Screen Keyboard feature in the Tenant Admin Portal allows admins to enable a virtual keyboard for Windows Login endpoints. Once enabled, users can use the touchscreen keyboard to enter their PIN during Windows authentication.

## Prerequisites

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable On-Screen Keyboard Configuration

1. Log in to **Tenant Admin Portal**.
2. On the homepage of the portal, click **Endpoints** on the left panel menu.
   ![How to Enable Show On-Screen Keyboard... - screenshot 1](/images/intercom/10259846/image-bce72818.png)
   The Endpoints page is displayed.
3. Select the endpoint to be configured.
   ![How to Enable Show On-Screen Keyboard... - screenshot 2](/images/intercom/10259846/image-74db8a24.png)
4. Go to **Configure** tab > **Endpoint Settings** tab.
   ![How to Enable Show On-Screen Keyboard... - screenshot 3](/images/intercom/10259846/image-fe69f0bd.png)
5. Turn on **Show on-screen keyboard** option to display an on-screen keyboard during Windows login. This option is useful for devices without a physical keyboard, such as tablets.
   ![How to Enable Show On-Screen Keyboard... - screenshot 4](/images/intercom/10259846/6ff1a3bd-ecfc-4b87-ab01-c0fb78b83e65-47021332.png)
6. Click **Save**.
   The touchscreen is configured for the endpoint.

## To use the touchscreen keyboard for the Windows login app

1. On the Windows lock screen, tap **Login with OLOID**.
   ![How to Enable Show On-Screen Keyboard... - screenshot 5](/images/intercom/10259846/image-5ab55282.png)
   The Windows login app opens and the **Scan Badge** page is displayed.
2. Tap the **Badge** on the **Badge Reader** to scan it.
   ![How to Enable Show On-Screen Keyboard... - screenshot 6](/images/intercom/10259846/image-9f9a3429.png)
   After Badge authentication, the **Enter PIN** pop-up box is displayed, and the onscreen keyboard automatically appears.
   ![How to Enable Show On-Screen Keyboard... - screenshot 7](/images/intercom/10259846/image-9ec3f7a9.png)

   <Note>
     **Note:** In case you are unable to view the onscreen keyboard or is accidentally closed, then tap the more ![How to Enable Show On-Screen Keyboard... - screenshot 8](https://downloads.intercomcdn.com/i/o/e4gi378c/1299342170/b99374f588029e87cf6751f8e8cc/image.png?expires=1790294400&signature=0f3275015fed4b263a83481c8dbd54cd1800f8028c1370c3fada47e31e5300d3&req=dSIuH8p6n4BYWfMW3nq%2Bgeji32P4RwKGLck5wpHEDCe%2F3owOHvNie1QZDato%0AHx0x%2FZKNfvem7WDr8SAS9%2FD0RL0%3D%0A) option > **On-screen Keyboard**.
   </Note>

   ![How to Enable Show On-Screen Keyboard... - screenshot 9](/images/intercom/10259846/image-627f38a6.png)
3. Enter the **PIN**, then tap **Enter**.
   On PIN authentication, you are signed in to the Windows device.
