## Introduction

The Customize Buttons section allows Tenant admin to rename the authenticator button label displayed on the Windows Login app.

## Prerequisites

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to configure Customize Buttons

1. Log in to the **Oloid Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to Customize Buttons in Windows... - screenshot 1](/images/intercom/11069364/image-6eeaf72f.png)
   The application page is displayed.
   ![How to Customize Buttons in Windows... - screenshot 2](/images/intercom/11069364/image-961dadde.png)
3. Go to **Configure** > **Customize Buttons** tab.
   ![How to Customize Buttons in Windows... - screenshot 3](/images/intercom/11069364/image-00f9bca7.png)
4. In **Button Label** field, enter the text to be displayed on the Windows Login app.
   Example- Sign in with, Login with, Authenticate with.
   ![How to Customize Buttons in Windows... - screenshot 4](/images/intercom/11069364/image-0e320c40.png)
5. **Enable Badge Options** toggle to allow badge assignment through the Supervisor App.

   <Note>
     **Note:** You must enable Badge Credential in the Authenticator tab of the Windows Login application.
   </Note>

   After enabling Badge option, select one of the following modes:
   **Default:** Enroll Badge + PIN
   - **Enroll Badge Only**
     Select this option to enroll badge using the Supervisor App.
   - **Enroll Badge + PIN**
     Select this option to enroll badge with PIN credential using the Supervisor App.
6. Click **Save**.
   ![How to Customize Buttons in Windows... - screenshot 5](/images/intercom/11069364/87ce3cb9-982a-4cee-92ec-bb693bbdd9a2-09269ef9.png)
   The configuration is saved successfully. See, [Sample screen for customized button](#sample-screen-for-customized-button)
   ![How to Customize Buttons in Windows... - screenshot 6](/images/intercom/11069364/image-af6f990d.png)

   <Note>
     **Note:** This note applies only to **Windows Login Version 1**. In the Windows Authenticator app, you must sync the configuration for the function to work. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
   </Note>
