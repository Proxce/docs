## Introduction

Auto update features keep all Windows Device Agents up to date without manual effort. It allows the tenant admin to install the latest version or select a specific version. They can also schedule updates to run at a set time, with options to retry if an update fails.

## Prerequisites

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to configure Auto Update

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to configure Auto Update feature... - screenshot 1](/images/intercom/11114161/image-b59f3404.png)
   The application page is displayed.
3. Go to **Configure** > **Auto Update** tab.
   ![How to configure Auto Update feature... - screenshot 2](/images/intercom/11114161/d5c4729e-646d-4994-b344-8e6f24afb8b8-3b459d3c.png)
4. Turn on **Enable Scheduled Auto-updates on all Endpoints** toggle to automatically update Windows Device Agents based on the selected settings.

   <Note>
     **Note:** If MDM auto-updates are already available or in use, this setting should be left disabled.
   </Note>

   ![How to configure Auto Update feature... - screenshot 3](/images/intercom/11114161/e737e9c5-2408-4ea4-bf4d-7f80f0677501-08f7cc4e.png)
   Select one of the following:
   - **Latest Version** – Always install the latest available version.
   - **Select Version** – Manually select a specific version from the dropdown list.
5. Select any of the following options to schedule auto-update:
   1. Select **Default Schedule** to define a schedule update.
      - Updates are triggered automatically at **2:00 AM local time** on the endpoint.
      - If the update fails, retries will occur **every hour** up to **5 times**.
        ![How to configure Auto Update feature... - screenshot 4](/images/intercom/11114161/image-79f32a1a.png)
   2. Select **Custom Schedule** to define a custom update
      1. Set the **Start Time** and **End Time** using the calendar and time picker options.
      2. Configure retry settings:
         - **Retry Frequency** – Maximum number of retry attempts during the update window.
         - **Retry Interval** – Time (in minutes) between each retry attempt.
           **Example:** Retry Frequency = 5 and Retry Interval = 60 mins → The update will retry every hour, up to 5 times.
           ![How to configure Auto Update feature... - screenshot 5](/images/intercom/11114161/image-c18d6d84.png)
   3. Select **Staggered Update Schedule** to distribute updates in phases
      1. Select Batch 1, and do the following:
         - **Select Groups** – Choose group(s) to include in the batch from the dropdown list.
         - Define **Start Time** and **End Time**.
         - Configure retry settings:
           - **Retry Frequency** – Maximum number of retry attempts during the update window.
           - **Retry Interval** – Time (in minutes) between each retry attempt.

             <Note>
               **Note:** You can select **+Add Batch** to add more batches as required.
             </Note>

             ![How to configure Auto Update feature... - screenshot 6](/images/intercom/11114161/image-192c185b.png)
   4. **Send Daily consolidated reports:** *Coming Soon*
   5. Click **Save**.

The auto update is configured successfully.

![How to configure Auto Update feature... - screenshot 7](/images/intercom/11114161/image-2d40c3e8.png)

<Note>

For more, refer to [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
