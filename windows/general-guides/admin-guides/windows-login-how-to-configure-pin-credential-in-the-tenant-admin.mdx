## Introduction

The PIN credential feature allows admins to configure PIN-based multi-factor authentication (MFA) for the Windows Login application. When enabled, users must enter a secure PIN as a secondary authentication factor after successful primary authentication.

## Prerequisites

- You must have **Tenant Admin** access to the Tenant Admin Portal.
- The **Windows Login application** must be created and configured in the Tenant Admin Portal. For More, refer to[How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to configure PIN credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application.
   ![How to Configure PIN Credential in the... - screenshot 1](/images/intercom/11484425/image-6eeaf72f.png)
   The **Details** page is displayed.
   ![How to Configure PIN Credential in the... - screenshot 2](/images/intercom/11484425/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Authenticato**r tab.
4. Turn on **PIN** toggle.
   ![How to Configure PIN Credential in the... - screenshot 3](/images/intercom/11484425/image-04efb5a0.png)
5. **Enable Face followed by PIN MFA** toggle to enable **multi-factor authentication (MFA)** by requiring a **PIN as the second authentication factor** when **Face** is used as the first factor.
6. Do the following configuration on **Adaptive Multi-Factor** which skips second factor authentication after first successful login: (Optional)
   1. Turn on **Enable PIN as Adaptive Multi Factor** toggle.
   2. Set **Adaptive Factor Duration** (in hours and minutes) to define how long the system skips prompting for second-factor authentication after a successful log in.
7. **Enable Forgot PIN link** toggle. For more, refer to [How to Enable Forgot PIN Link in Windows Login Application](https://oloid.help/en/articles/14015958-tenant-admin-portal-how-to-enable-forgot-pin-link-in-windows-login-application)

Click **Save**.

![How to Configure PIN Credential in the... - screenshot 4](/images/intercom/11484425/image-a287ebea.png)

The PIN credential is configured successfully.

![How to Configure PIN Credential in the... - screenshot 5](/images/intercom/11484425/image-3d3c9687.png)

<Note>
  **Note:** For setting up PIN rules, see [How to Configure PIN Settings in the Tenant Admin Portal](https://oloid.help/en/articles/8407872-how-to-configure-pin-settings-in-the-tenant-admin-portal).
</Note>

**Sync Configuration to Apply Changes**
