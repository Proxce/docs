## Introduction

The Theme tab in the Tenant Admin Portal for windows login application allows you to customize the appearance of your Windows Login Application. You can upload your organization’s logo, change the login icon, and update the button text to align with your company’s standards.

## Prerequisite

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Edit Theme Tab

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the preferred Windows Login application to edit.
   ![How to Edit Theme tab for Windows Login... - screenshot 1](/images/intercom/10756679/image-3576b8f7.png)
   The application page is displayed.
3. Go to **Theme** tab.

Do the following:

[Configure Theme Section](#configure-theme-section)

[Configure Welcome Screen](#configure-welcome-screen)

[Configure Language Support](#configure-language-support)

[Configure Messages](#configure-messages)

#### Configure Theme Section

4. ![How to Edit Theme tab for Windows Login... - screenshot 2](/images/intercom/10756679/image-6b482219.png)
   The theme tab is displayed.
5. Do the following:
   1. Edit Customer logo.

      <Note>
        **Note:** The maximum file dimensions for the logo are **264x72 px**, with a maximum size of **1 MB** in **PNG** format.
      </Note>

      ![How to Edit Theme tab for Windows Login... - screenshot 3](/images/intercom/10756679/image-5ef153f0.png)
   2. **Kiosk Background Image:** Do one of the following:
      1. Edit Background image.

         <Note>
           **Note:** The maximum file size is **2 MB** (JPG, PNG, JPEG). This image is used as the widget background.
         </Note>

         or
      2. Select **Solid Background** option > enter color code.
         ![How to Edit Theme tab for Windows Login... - screenshot 4](/images/intercom/10756679/image-ad5e7910.png)
   3. **Primary Color/Button Default:** Update the primary color code to define the primary button's default background and its hover-state text color.
   4. **Secondary Color/Hover State:** Update the secondary color code to define the primary button's hover background and its default text color.
   5. **Customize Heading:** Update the heading that appears at the top of the screen.
   6. **Widget Header/Footer Color:** Update the background color for the Widget's header and footer.
   7. **Footer Text Color:** Update the footer text color code in Login App.
      ![How to Edit Theme tab for Windows Login... - screenshot 5](/images/intercom/10756679/image-6ba5dc31.png)
6. (Optional) In the **Preview** section, select one of the following tabs to preview the theme configuration:
   1. **Identity Selection:** Preview the appearance of the identity selection screen displayed before user authentication.
   2. **Authentication:** Preview the authentication screen displayed when users authenticate using their configured credentials.
   3. **Error:** Preview how error messages and error screens are displayed to users during authentication failures.
      ![How to Edit Theme tab for Windows Login... - screenshot 6](/images/intercom/10756679/image-3a4e2ffa.png)
7. Click **Deploy**.
   ![How to Edit Theme tab for Windows Login... - screenshot 7](/images/intercom/10756679/image-8c66901d.png)
   The **Confirm Update** pop-up box is displayed.
8. Click **Update**.
   ![How to Edit Theme tab for Windows Login... - screenshot 8](/images/intercom/10756679/image-edd2d88a.png)
   The Windows Login theme tab is updated successfully.

#### Configure Welcome Screen

1. Select Custom Image/App Logo
2. Click or Drag an Image to Upload.

![How to Edit Theme tab for Windows Login... - screenshot 9](/images/intercom/10756679/image-ee2b740e.png)

#### Configure Language Support

1. Select Language Support.
2. Select **Default App Language** from dropdown.
3. Select the **Show Language selection dropdown** checkbox.
   The Language selection option will be available on the Oloid login widget wherever applicable.
4. Select Language Selection widget type (Flag or Language code).

![How to Edit Theme tab for Windows Login... - screenshot 10](/images/intercom/10756679/image-cf44c4c0.png)

#### Configure Messages

1. Enable the **Face Capture Instructions** toggle.
2. Type the Face capture instructions. (Optional)
3. Enable the **Customize Face Authentication Failure Message** toggle.
4. Type the Face Authentication Failure Message. (Optional)
   ![How to Edit Theme tab for Windows Login... - screenshot 11](/images/intercom/10756679/image-c0b53e83.png)
5. Click **Deploy**.
   The **Confirm Update** pop-up box is displayed.
6. Click **Update**.
   ![How to Edit Theme tab for Windows Login... - screenshot 12](/images/intercom/10756679/image-edd2d88a.png)
   The Windows Login theme tab is updated successfully.

![How to Edit Theme tab for Windows Login... - screenshot 13](/images/intercom/10756679/image-02f0398c.png)
