**Introduction**

This document provides step-by-step instructions for configuring the Card Reader using the RF IDEAS Configuration Utility for Windows Login app.

**Pre-requisite:**

- You must configure the badge card. For further details, refer [How to configure rf IDEAS readers for badge card](https://oloid.help/en/articles/9398720-how-to-configure-rf-ideas-readers-for-badge-card)
- You must identify the card type and card format. For further details, refer [How to find the Card Type and Card Format using the RF IDeas Configurator Tool](https://oloid.help/en/articles/9720607-how-to-find-the-card-type-and-card-format-using-the-rf-ideas-configurator-tool)

To configure rfIDEAS for SDK Type Reader:

1. Launch the **rf IDEAS Configuration Utility** app.
   ![How to configure Card Reader Using RF... - screenshot 1](/images/intercom/11087967/image-0a9e4387.png)
   The app opens.
   ![How to configure Card Reader Using RF... - screenshot 2](/images/intercom/11087967/image-b192a153.png)
2. Connect the card reader to the system.
3. Click **Connect** from the top left menu bar.
   ![How to configure Card Reader Using RF... - screenshot 3](/images/intercom/11087967/ccc9c4ca-856b-4796-ae69-dd55acfa6c89-eba4aae3.png)
   The DEVICE LIST is configured and displayed.
   ![How to configure Card Reader Using RF... - screenshot 4](/images/intercom/11087967/5491a920-3fe3-4d8f-b4e4-2b1ea661bde8-62bebe56.png)
4. In the left menu panel, select **SDK**.
   ![How to configure Card Reader Using RF... - screenshot 5](/images/intercom/11087967/9016fbd6-6363-49d2-81b3-d2ea100f1123-9c71d5d8.png)

   <Note>
     **Note:** It is not always necessary for the card reader to support both SDK and keyboard types. Some readers may support only one of the types.
   </Note>

   1. Turn on the **Disable Keystrokes for SDK** toggle button to disable keystrokes for the SDK-type readers.
      ![How to configure Card Reader Using RF... - screenshot 6](/images/intercom/11087967/c3184292-bbb4-48c2-b4e8-cf6f8aa236c9-58d14e3f.png)

      <Note>
        **Note:** If this option is turned off, keystrokes will be enabled. This option applies only to keystroke-type readers.
      </Note>

   2. Click **Write**, and then click **Connect** to apply the configuration.

      <Note>
        **Note:** Make sure the **Disable Keystrokes for SDK** setting remains as configured (enabled or disabled) after applying the action. This ensures that the card reader works correctly based on your intended use case, whether supporting SDK, keystrokes, or both.
      </Note>

      ![How to configure Card Reader Using RF... - screenshot 7](/images/intercom/11087967/image-3b9dc521.png)
   3. In the **Card ID** section, click **GetID** to retrieve the card ID.

      <Note>
        **Note:** You need toscan the badge card using the card reader for the card ID to get displayed.
      </Note>

      ![How to configure Card Reader Using RF... - screenshot 8](/images/intercom/11087967/aaadb404-a784-4400-a0ea-60bd97957535-5c1ada1b.png)
   4. Select the **Test Area** to scan your badge card with the card reader.
      The badge number is displayed in the Test Area.

      <Note>
        **Note:** Make sure the badge number matches the card number. To calculate the card number, see [Facility Code Calculation](https://oloid.help/en/articles/10229274-how-to-use-data-from-configurator-tool-to-create-wiegand-format-definition-in-oloid#:~:text=the%20Data%20bytes-,Facility%20Code%20Calculation,-To%20calculate%20the).
      </Note>

5. In the left menu panel, select **Format**.
6. In the **Data Format** tab, do the following:
   1. Set **Strip leading bit count** and **Strip trailing bit count** to **0**.
   2. Disable both **Send FAC** and **Send ID** options.

      <Note>
        **Note:**

              - In the **Wiegand to keystroke data format** section, select the **Send ID as hexadecimal number** checkbox.
              - In the **Advanced Settings** section, select the **ID extended precision math on** checkbox.
                ![How to configure Card Reader Using RF... - screenshot 9](/images/intercom/11087967/a3a74900-ce09-45fd-989e-56beaa2595ab-776c51cd.png)
        7. Go to **Delimiters** tab, and do the following:
           1. In the **Pre-data delimiters (ABC)** section, select **Insert Keystroke 1**.
              ![How to configure Card Reader Using RF... - screenshot 10](/images/intercom/11087967/104fc158-f46f-43f7-aa2e-fc355ab398f7-10dc75c0.png)
              The **Virtual keyboard - select keycode and modifier(s)** is displayed.
           2. Select **&lt;NONE>** and press **Enter** on your keyboard.
              ![How to configure Card Reader Using RF... - screenshot 11](/images/intercom/11087967/89a0e935-716a-44e2-ac8b-fcb9ba081237-6a5bb178.png)
        8. Click **Write** to apply the changes.
      </Note>
