It is recommended to contact your Oloid Account Manager for configuration support to ensure a smooth setup.

**Pre-requisite:**

- Download the latest "rf IDEAS Configuration Utility" from the [RF IDEAS website](https://www.rfideas.com/support/tools/downloads).

To configure your card reader:

1. Launch the rf IDEAS configuration utility app.
   Make sure the card reader is connected to the system.
2. Select **Connect** from the top menu bar.
   ![How to configure rf IDEAS readers for... - screenshot 2](/images/intercom/9398720/ccc9c4ca-856b-4796-ae69-dd55acfa6c89-9e2ea78a.png)
   The DEVICE LIST is configured and displayed.
   ![How to configure rf IDEAS readers for... - screenshot 3](/images/intercom/9398720/5491a920-3fe3-4d8f-b4e4-2b1ea661bde8-3acadea7.png)
3. Select the preferred configuration from the **CONFIGURATION(s)** dropdown list.
   ![How to configure rf IDEAS readers for... - screenshot 4](/images/intercom/9398720/image-118a6f57.png)
4. Select **Write** from the top menu bar.
   ![How to configure rf IDEAS readers for... - screenshot 5](/images/intercom/9398720/aee7fda2-7143-4de5-a4f1-b894c7e2062c-f5fd7928.png)
   The badge reader is updated with the new settings.
5. Select the **Test Area** to scan your badge card with the card reader.
   ![How to configure rf IDEAS readers for... - screenshot 6](/images/intercom/9398720/image-dae98b45.png)
   The badge number is displayed in the Test Area.
   ![How to configure rf IDEAS readers for... - screenshot 7](/images/intercom/9398720/image-65b6879f.png)
   The card reader is configured for the badge card.
