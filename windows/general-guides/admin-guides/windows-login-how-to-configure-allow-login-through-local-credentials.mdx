## Introduction

This document explains how to configure **Allow Login Through Local Credentials** for the Windows Login application in the Tenant Admin Portal. Enabling this setting allows users to sign in to Windows using their local Windows credentials.

## Prerequisites

- Tenant Admin access to the **Tenant Admin Portal.**
- You must create and configure Windows Login application. For More, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Configure Allow Login Through Local Credentials

1. Log in to the Tenant Admin Portal.
2. Go to **Applications** > select **Windows Login** application.
   ![How to Configure Allow Login Through... - screenshot 1](/images/intercom/13615407/image-3330cbb9.png)
   The **Details** page is displayed.
   ![How to Configure Allow Login Through... - screenshot 2](/images/intercom/13615407/image-90b6e777.png)
3. Go to **Configure** > **Settings** tab.
4. Enable **Allow Credential Updates and Enrollment** toggle to allow users to update or enroll credentials using Windows credentials.
   - Enable **Allow Login Through Local Credentials** to allow users to log in to Windows using their local Windows credentials.

Click **Save**.

![How to Configure Allow Login Through... - screenshot 3](/images/intercom/13615407/image-5789d2c9.png)

The **Allow Login Through Local Credentials** setting is enabled successfully.

![How to Configure Allow Login Through... - screenshot 4](/images/intercom/13615407/image-aafb288f.png)

### Sync Configuration to Apply Changes

You must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app).
