## Introduction

The Oloid Windows Login application enables secure, passwordless sign-in. Tenant Admins can configure a default Windows domain in the Tenant Admin Portal to streamline logins in domain-connected environments. Once set, users are automatically directed to the specified domain, making the login process faster and error-free.

## Prerequisites

The **Allow Credential Updates and Enrollment** toggle must be enabled for the application. For more details refer the **configure** section of this document [How to create and configure Windows Login application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application).

## Steps to enable Windows default domain

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to enable Windows Default Domain... - screenshot 1](/images/intercom/12266470/image-4e5f3c78.png)
   The user profile menu is displayed.
3. Go to **Tenant Settings**.
   ![How to enable Windows Default Domain... - screenshot 2](/images/intercom/12266470/ccec9289-b154-4b97-83ed-6a66a27484c3-3e6f29c0.png)
   The **Tenant Settings** page is displayed.
4. Go to **App Settings** tab > **others** > **Windows App**.
   ![How to enable Windows Default Domain... - screenshot 3](/images/intercom/12266470/image-cea77b67.png)
5. Do the following:
   1. Turn on **Enable Windows default domain** toggle.
   2. Enter Domain name in the text field.
   3. Click **Save**.

![How to enable Windows Default Domain... - screenshot 4](/images/intercom/12266470/image-c5fc6286.png)

The Windows default domain is enabled successfully.

![How to enable Windows Default Domain... - screenshot 5](/images/intercom/12266470/image-36ee23a9.png)

### Sync Configuration to Apply Changes

After enabling the **Windows Default Domain**, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app).

Once the configuration is synced, you can view the changes during login. A sample preview screen is shown below for reference.
