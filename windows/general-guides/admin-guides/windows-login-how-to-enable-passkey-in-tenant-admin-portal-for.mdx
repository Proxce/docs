## Introduction

The Passkey feature enables secure, passwordless authentication for users accessing a Windows application. This article explains how an admin can enable Passkey login for a Windows application from the Tenant Admin Portal.

## Prerequisite

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Windows application to edit.
   ![How to enable Passkey in Tenant Admin... - screenshot 1](/images/intercom/11035277/image-6eeaf72f.png)
   The application page is displayed.
   ![How to enable Passkey in Tenant Admin... - screenshot 2](/images/intercom/11035277/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to enable Passkey in Tenant Admin... - screenshot 3](/images/intercom/11035277/image-fbf8d2f6.png)
4. Turn on **Enable Passkeys** toggle button to allow users to log in using Passkey credential.
   ![How to enable Passkey in Tenant Admin... - screenshot 4](/images/intercom/11035277/4ca57c09-bbde-4364-9747-4fb2b48a86a3-e8f289ed.png)

Click **Save**.

The application is configured successfully.
