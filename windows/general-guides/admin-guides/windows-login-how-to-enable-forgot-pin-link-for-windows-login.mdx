## Introduction

This **document** explains how to enable the **Forgot PIN link** in Windows Login in the Tenant Admin Portal and configure the settings that allow users to recover or manage their PIN from the Windows Login screen.

## Prerequisites

- You must have **Admin access to the Tenant Admin Portal**.
- The **Windows Login application** must be created and configured. For more, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- You must enable **Allow Login Through Local Credentials** toggle in Windows Login application. For more, refer to [How to Configure Allow Login Through Local Credentials](https://oloid.help/en/articles/13615407-windows-login-how-to-configure-allow-login-through-local-credentials)

## Steps to Enable the Forgot PIN Link

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, select the **Windows Login application**.
   ![How to Enable Forgot PIN Link for... - screenshot 1](/images/intercom/14015958/image-b485e65a.png)
   The **Details** page is displayed.
   ![How to Enable Forgot PIN Link for... - screenshot 2](/images/intercom/14015958/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Authenticato**r tab.
4. Under **MFA Credentials**, enable the **PIN** toggle.
   ![How to Enable Forgot PIN Link for... - screenshot 3](/images/intercom/14015958/image-04efb5a0.png)
5. **Enable Forgot PIN link** toggle.
6. Select one of the following options:
   1. Select **Show Popup** to display a popup message with instructions when users click the Forgot PIN link. See, Sample screen.
      Do the following:
      - Enter the **Heading**.
      - Enter the **Description**.
        OR
   2. Select **Allow PIN enrollment using 'Windows credential verification'** to redirects users to the Windows credentials management page. See, Sample screen.

Click **Save.**

![How to Enable Forgot PIN Link for... - screenshot 4](/images/intercom/14015958/image-060dcceb.png)

The **Forgot PIN link** is enabled successfully.

![How to Enable Forgot PIN Link for... - screenshot 5](/images/intercom/14015958/image-5aea4fc3.png)
