For Oloid's Windows Login to function, it needs to be configured in the Oloid Platform.

## Initial set up

### Step 1: Set up Application and Connection

1. Create and Configure Windows Login Application. Refer to [How to create and configure Windows Login application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application) guide.
2. Create Connections. Refer to [How to create Connections](https://oloid.help/en/articles/8294297-how-to-create-connection)

### Step 2: Map Connections to Applications.

Once both Application and Connection are created, you need to map the Connection to the Application.

Refer to [How to Map Connection to Application](https://oloid.help/en/articles/8304594-how-to-map-connection-to-application)

### Step 3: Create user and assign user to connection.

Create users and assign users to connections in Oloid Portal. Refer to [User Onboarding](https://oloid.help/en/articles/8463554-user-onboarding) guide.

### Step 4: Enable Authenticator factors

Based on the requirement , enable authenticator factors in the tenant application. Refer to [How to create and configure Windows Login application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application) > [Configure Authenticator tab](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_d3f5dd6c43)
