## Introduction

The QR Code credential feature in the Tenant Admin Portal allows admin to enable QR code-based single factor authentication and multi-factor authentication (MFA) for the Windows Login application. Once enabled, users can log in to Windows endpoints by scanning a QR code.

## Prerequisites

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable QR Code

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the preferred Windows Login application.
   ![How to enable QR Code credential for... - screenshot 1](/images/intercom/11484322/image-6eeaf72f.png)
   The application page is displayed.
   ![How to enable QR Code credential for... - screenshot 2](/images/intercom/11484322/image-b8e353d8.png)
3. Go to **Authenticato**r tab.
4. Turn on **QR Code** toggle.
   ![How to enable QR Code credential for... - screenshot 3](/images/intercom/11484322/image-445c72ff.png)
   The QR code authenticator for Windows Login application is enabled successfully.
   ![How to enable QR Code credential for... - screenshot 4](/images/intercom/11484322/image-efdbd982.png)
