## Introduction

This document provides step-by-step instructions for enabling Auto Launch Mode in the Windows Login application. When enabled, the Windows Login app automatically launches on the Windows pre-login screen, allowing users to access the configured Oloid authentication options without manually launching the application.

## Prerequisites

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to enable Auto Launch Mode

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to enable Auto Launch Mode in... - screenshot 1](/images/intercom/10852057/image-c7f21cd0.png)
   The application page is displayed.
   ![How to enable Auto Launch Mode in... - screenshot 2](/images/intercom/10852057/image-d97f12be.png)
3. Go to **Configure** > **Settings** tab.
   ![How to enable Auto Launch Mode in... - screenshot 3](/images/intercom/10852057/cefe1726-057f-4b28-b5bd-79de540b4cb5-63c23195.png)
4. Turn on **Enable Auto Launch Mode** toggle button to automatically launch the Windows Login app on the pre-login screen.
   1. Set Time-Out for Login screen. This duration will define the time the system will wait on login screen.
      ![How to enable Auto Launch Mode in... - screenshot 4](/images/intercom/10852057/image-4cf133b7.png)
5. Click **Save**.

![How to enable Auto Launch Mode in... - screenshot 5](/images/intercom/10852057/image-91f75472.png)

The configuration is saved successfully. See, [Sample screen for Auto Launch Mode](#sample-screen-for-auto-launch-mode)

<Note>
  **Note:** Note: This note applies only to Windows Login Version 1. In the Windows Authenticator app, you must sync the configuration for the function to work. For more information, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
</Note>
