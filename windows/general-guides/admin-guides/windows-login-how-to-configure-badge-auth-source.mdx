**Introduction:**

Set up the *Badge Auth Source* in the Tenant Admin Portal to define whether badge credentials for the Windows Login application are verified using local storage or cloud-based data.

**Pre-requisite:**

In the Tenant Admin Portal, you must enable Validate Windows Credential option in the Windows Login Application. For further details, refer [How to enable Validate Windows Credential in Windows Login application](https://oloid.help/en/articles/10900687-how-to-enable-validate-windows-credential-in-windows-login-application)

Steps to enable Badge Auth Source:

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Windows application to edit.
   ![How to configure Badge Auth Source - screenshot 1](/images/intercom/11274692/image-6eeaf72f.png)
   The application page is displayed.
   ![How to configure Badge Auth Source - screenshot 2](/images/intercom/11274692/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Authenticator** > **Badge ID** > **Badge Auth Source**.
   ![How to configure Badge Auth Source - screenshot 3](/images/intercom/11274692/933dbf4c-2023-4b58-a76d-a470bb33ddb4-e06296e2.png)
   The Badge Auth Source section is displayed.
   ![How to configure Badge Auth Source - screenshot 4](/images/intercom/11274692/image-3fb228a3.png)
4. Select the following:
   - **Hybrid: Online First (default)-** This option allows the Windows Login application to check the cloud first for badge authentication. You must use this option when real-time cloud data is preferred.
   - **Hybrid: On-device First-** This option allows the Windows Login application to check the local device storage first. If the badge is not found, it then checks the cloud. This option also updates and validates user data on the device after authentication.
5. Click **Save** to save the configuration successfully.

   <Note>
     **Note:** In **Windows Authenticator** app, you must sync the configuration to Validate Windows Credential to work properly. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
   </Note>
