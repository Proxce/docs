### Introduction

In Tenant Admin Portal, enabling Credential Updates and Enrollment feature allows users to update existing credentials or enroll new credentials using their Windows credentials in the Windows Login app.

### Prerequisites

You must create a Windows Login application. For further details, refer [How to create a Windows Login Application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#:~:text=2%20weeks%20ago-,Steps%20to%20create%20and%20configure%20Windows%20Login%20application%3A,-Log%20in%20to).

### Steps to Allow Credential Updates and Enrollment

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the application paired in the Supervisor App (Windows Authenticator App).
   ![How to enable Credential Updates and... - screenshot 1](/images/intercom/10912821/image-6eeaf72f.png)
   The application page is displayed.
   ![How to enable Credential Updates and... - screenshot 2](/images/intercom/10912821/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to enable Credential Updates and... - screenshot 3](/images/intercom/10912821/8f9f1b20-1a45-45d8-9a9b-5a1c41a72f16-a83f1dce.png)
4. Turn on **Allow Credential Updates and Enrollment** toggle button to allow users to enroll or update credentials in the Windows Login App and do the following:
   1. Enable **Hide option to save Windows credentials** toggle to remove the checkbox for saving Windows domain credentials to the Oloid account during enrolment.
   2. Select **Auto-save credentials on successful validation** checkbox to automatically save credentials when the Save option is hidden.
   3. Enable **Allow Login Through Local Credentials** toggle to allow users to log in to Windows using their local Windows credentials.

Click **Save**.

![How to enable Credential Updates and... - screenshot 4](/images/intercom/10912821/image-274ce08d.png)

The Allow Credential Updates and Enrollment is enabled successfully.

![How to enable Credential Updates and... - screenshot 5](/images/intercom/10912821/image-d6d24249.png)

The configuration is saved successfully. See, [Sample screen for Credential Updates and Enrollment](#sample-screen)

<Note>
  **Note:** In **Windows Authenticator** app, you must sync the configuration to Allow Credential Updates and Enrollment work properly. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
</Note>
