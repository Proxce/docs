## Introduction

This document explains how to apply an Endpoint Template during the auto-pair configuration process for the Windows Login application. Applying the Endpoint Template ensures that predefined settings are automatically assigned to devices as part of the pairing process.

## Prerequisites

- You have **Tenant Admin** access to the **Tenant Admin Portal**.
- An **Endpoint Template** has been created. To create refer [How to create and configure Windows Login Endpoint Template](https://oloid.help/en/articles/10501612-how-to-create-and-configure-windows-login-endpoint-template).
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps at a Glance

1. Create the Windows Login application in the Tenant Admin Portal and select the desired endpoint template in the **“Apply Endpoint Template”** field.
2. Generate and download the auto-pair config file; ensure it is mapped to the application with the predefined template.
3. Install the Windows Login app on the endpoint using the auto-pair option. The endpoint template is applied automatically.

## Steps to Apply Endpoint Template During Auto-Pair Process

### Step 1: Create and Configure the Windows Login Application

1. Log in to the **Tenant Admin Portal**.
2. Create the windows login application. Refer [How to create and configure Windows Login application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application).

   <Note>
     **Note:** If window login application is already created then select the desired application from the application list.
   </Note>

3. In the **Settings section**, select the applicable template from **[Apply Endpoint Template](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_d2d8db376c:~:text=Apply%20Endpoint%20Template%3A)** dropdown.

   <Note>
     **Note:** Endpoint template must be added to apply template when using auto-pair option to pair the endpoint.
   </Note>

   ![How to apply Endpoint Template during... - screenshot 1](/images/intercom/12586251/299ed8b6-5858-4a15-9a0c-fa9f15771fea-83a4c189.png)
   The endpoint template is selected.
4. Select **Save**.
   ![How to apply Endpoint Template during... - screenshot 2](/images/intercom/12586251/image-0a10c110.png)
   The Endpoint Template is successfully applied to the selected Windows Login Application.

### **Step 2:** Generate and Download the Auto-config File

1. Generate and download the auto-pair config file. Refer [How to generate Auto-Pair config file for Windows Login in Tenant Admin Portal](https://oloid.help/en/articles/10441578-how-to-generate-auto-pair-config-file-for-windows-login-in-tenant-admin-portal)

   <Note>
     **Note:** Ensure that the **Application Mapping** includes the application where the **Endpoint Template** is specified. This mapping ensures that auto-pair applies the correct endpoint configuration.
   </Note>

   ![How to apply Endpoint Template during... - screenshot 3](/images/intercom/12586251/18270f7e-0306-4fe0-964f-ad921ac727cf-f107402a.png)

### Step 3: Pair the Windows Login Application with Auto-pair config file.

1. On the target Windows device, launch the **Oloid Windows Login Installer**.
2. Pair the endpoint using auto-pair option. To auto-pair refer [How to pair Supervisor App using auto-config option](https://oloid.help/en/articles/9637781-how-to-pair-supervisor-app-using-auto-config-option)

Once the auto-pair process completes, the **Endpoint Template** settings is automatically applied to the paired endpoint.
