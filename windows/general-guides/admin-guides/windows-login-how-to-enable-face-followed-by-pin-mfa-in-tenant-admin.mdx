## Introduction

This document provides instructions to enable **Face followed by PIN multi-factor authentication (MFA)** for the Windows Login application in the Tenant Admin Portal. When enabled, users must authenticate using Face as the primary factor and then enter a PIN as the secondary factor during Windows login.

## Prerequisites

- You must create and configure Windows Login application. For More, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- You Must enable Face credential in the Windows Login application. For more, refer to [How to configure Face credential for Windows Login Application in the Tenant Admin Portal](https://oloid.help/en/articles/11476775-how-to-configure-face-credential-for-windows-login-application-in-the-tenant-admin-portal)

## Steps toEnable Face Followed by PIN MFA

1. Log in to the Tenant Admin Portal.
2. Go to **Applications** > select **Windows Login** application.
   ![How to Enable Face Followed by PIN MFA... - screenshot 1](/images/intercom/13644652/image-3330cbb9.png)
   The **Details** page is displayed.
   ![How to Enable Face Followed by PIN MFA... - screenshot 2](/images/intercom/13644652/image-90b6e777.png)
3. Go to **Authenticator** > enable **PIN** credential.
   ![How to Enable Face Followed by PIN MFA... - screenshot 3](/images/intercom/13644652/image-f063f673.png)
4. In **PIN as Authentication Factor**, turn on **Enable Face followed by PIN MFA**.

   <Note>
     **Note:** When this option is enabled, users must authenticate using **Face as the first factor** and then enter a **PIN as the second factor (MFA)** during Windows Login.
   </Note>

5. Click **Save.**
   ![How to Enable Face Followed by PIN MFA... - screenshot 4](/images/intercom/13644652/image-a04306a8.png)
   The **Face followed by PIN MFA** is configured successfully.
   ![How to Enable Face Followed by PIN MFA... - screenshot 5](/images/intercom/13644652/image-3e77005a.png)

### Sync Configuration to Apply Changes

You must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app).
