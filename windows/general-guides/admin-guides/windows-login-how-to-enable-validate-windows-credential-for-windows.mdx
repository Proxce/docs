## Introduction

Enabling the Validate Windows Credential feature in the Tenant Admin Portal allows users to create Windows credentials. It also enables users to update their account information in the Windows Login application if their Windows password has changed or expired.

## Prerequisite

You must create and configure Windows Login Application in the Tenant Admin Portal. For more details, refer [How to create and configure Windows Login Application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application).

## Steps to Enable Validate Windows Credential

1. Log in to the **Tenant Admin Portal**.
2. Select the application that is configured in the Supervisor App (Windows Authenticator App).
   ![How to Enable Validate Windows... - screenshot 1](/images/intercom/10900687/image-6eeaf72f.png)
   The application page is displayed.
   ![How to Enable Validate Windows... - screenshot 2](/images/intercom/10900687/fdfc43bb-4377-4dd4-88fa-63ee53aa82ba-a2f6d1b2.png)
3. Go to **Configure** > **Settings** tab.
   ![How to Enable Validate Windows... - screenshot 3](/images/intercom/10900687/image-9285ad5b.png)
4. Turn on **Validate Windows Credential** toggle button to validate, update, or create Windows credentials in the Windows Login app before logging in to the system. See, [Sample Screen for Create Windows Credential and Missing Windows Credential](#sample-screen)
   ![How to Enable Validate Windows... - screenshot 4](/images/intercom/10900687/1dcfdefc-fd8b-4ca6-99d8-29a542abade9-d499753b.png)
5. Click **Save**.
   ![How to Enable Validate Windows... - screenshot 5](/images/intercom/10900687/66b52f3c-df44-4862-ba72-ae31f56fed41-d8ad9100.png)
   The configuration is saved successfully.
   ![How to Enable Validate Windows... - screenshot 6](/images/intercom/10900687/image-9ee49dac.png)

   <Note>
     **Note:** In **Windows Authenticator** app, you must sync the configuration to Validate Windows Credential to work properly. For more details, refer [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app)
   </Note>

## Sample Screen

**Scenario 1:** Create Windows Credential

![How to Enable Validate Windows... - screenshot 7](/images/intercom/10900687/a7d6b0f5-1906-40b0-b8c5-5a9529099fe7-a7a037ae.png)

- If your Windows credential is missing, the **Missing Windows Credential** screen is displayed.
- Select **Create Account** to create Windows Credential.
  For further details, refer [How to Create missing Windows Credential](https://oloid.help/en/articles/10956677-how-to-create-missing-windows-credential)

**Scenario 2:** Missing Windows Credential

![How to Enable Validate Windows... - screenshot 8](/images/intercom/10900687/a461cf3c-62cb-403b-afe4-83aba56c1376-cb545316.png)

- If your Windows password is changed or expired, the **Invalid or Missing Windows Credential** screen is displayed.
- Select the account you want to update.
  For further details, refer [How to update expired Windows Credential](https://oloid.help/en/articles/10954843-how-to-update-expired-windows-credential)
