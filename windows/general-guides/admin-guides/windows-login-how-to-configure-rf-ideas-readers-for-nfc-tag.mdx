**Pre-requisite:**

- Download the latest "rf IDEAS Configuration Utility" from the [rf IDEAS website](https://www.rfideas.com/support/tools/downloads).

To configure your card reader:

1. Launch the rf IDEAS configuration utility app.
   Make sure the card reader is connected to the system.
2. Select **Connect** from the top menu bar.
   ![How to configure rf IDEAS readers for... - screenshot 1](/images/intercom/9399762/ccc9c4ca-856b-4796-ae69-dd55acfa6c89-9e2ea78a.png)
   The DEVICE LIST is configured and displayed.
   ![How to configure rf IDEAS readers for... - screenshot 2](/images/intercom/9399762/5491a920-3fe3-4d8f-b4e4-2b1ea661bde8-3acadea7.png)
3. Select the preferred configuration from the **CONFIGURATION(s)** dropdown list.
   ![How to configure rf IDEAS readers for... - screenshot 3](/images/intercom/9399762/image-423fa999.png)
4. Select **Write** from the top menu bar.
   ![How to configure rf IDEAS readers for... - screenshot 4](/images/intercom/9399762/image-ac24baa8.png)
   The card reader is updated with the new settings.
5. Place your cursor in the **Test Area** and scan your NFC tag with the card reader.
   ![How to configure rf IDEAS readers for... - screenshot 5](/images/intercom/9399762/c761d4fd-7bb8-4c0b-8c08-02fa975a7c4e-9e85ba07.png)
   The NFC tag number is displayed in the Test Area.
   ![How to configure rf IDEAS readers for... - screenshot 6](/images/intercom/9399762/image-65b6879f.png)
   The card reader is configured for the NFC tag.
