## Introduction

The **Enable Badge Out** option allows users to securely lock or sign out of a Windows system using a badge.

<Note>
  **Note:** This feature is available only in healthcare and presence detection build.
</Note>

## Prerequisites

- You must create and configure Windows Login application. For more, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- The badge reader must be connected to the Windows system.

## Steps to Configure Badge Out Option

1. Log in to the **Tenant Admin Portal.**
2. Select the application that is configured in the Supervisor App (Windows Authenticator App).
   ![How to Configure Badge Out option - screenshot 1](/images/intercom/10616183/image-9d23b047.png)
   The application details page is displayed.
   ![How to Configure Badge Out option - screenshot 2](/images/intercom/10616183/image-9669372e.png)
3. Click **Configure** tab> **Settings**.
   ![How to Configure Badge Out option - screenshot 3](/images/intercom/10616183/image-55530daa.png)
   The Settings page is displayed.
4. Turn on **Enable Badge Out** toggle button.
   This option allows user to lock or sign out of a Windows system using a badge, either by **tapping the badge on the reader** or by **removing the badge from the reader**.
5. Do one of the following:
   1. Select **Tap to Badge Out** option to badge out by tapping the badge on the reader.
   2. Select **Remove Badge to Badge Out** option to badge out.

      <Note>
        **Note:** When enabled, the user is logged in by placing their badge on the reader. Removing the badge from the reader automatically locks or signs out of the system.
      </Note>

      ![How to Configure Badge Out option - screenshot 4](/images/intercom/10616183/image-e0b8b805.png)
6. Click **Save.**
   ![How to Configure Badge Out option - screenshot 5](/images/intercom/10616183/image-d2ba1863.png)
   The options are enabled.

### Configure Windows Badge Out Options

1. Select one of the following options based on your requirement:
   1. **Lock Windows PC:**
      Select this option to **lock the Windows system** when a user badges out. The user session remains active in the background.
      - **Tap to Badge Out + Lock Windows PC**
        When the user taps the badge on the reader, Windows is locked.
        ![How to Configure Badge Out option - screenshot 6](/images/intercom/10616183/image-e465b1ed.png)

<Note>
  **Note:** To enable **User Switch**, select **Tap to Badge out** and **Lock Windows PC**, then select **User Switch**. When this is configured, if one user is already signed in to the Windows system and another user taps their badge on the reader, the first user’s session is locked automatically, and the second user is signed in successfully to use the system.
</Note>

- **Remove Badge to Badge Out + Lock Windows PC**
  When the user removes the badge from the reader, Windows is locked.
  ![How to Configure Badge Out option - screenshot 7](/images/intercom/10616183/image-782c323b.png)
2. **Sign-out of Windows**
3. Select this option to **sign the user out of Windows** when a user badges out. All open applications are closed, and the user session ends.
   - **Tap to Badge Out + Sign out of Windows**
     When the user taps the badge on the reader, all running applications are closed and the user is signed out of Windows.
     ![How to Configure Badge Out option - screenshot 8](/images/intercom/10616183/image-da1cd127.png)
   - **Remove Badge to Badge Out + Sign out of Windows**
     When the user removes the badge from the reader, all running applications are closed and the user is signed out of Windows.
     ![How to Configure Badge Out option - screenshot 9](/images/intercom/10616183/image-17908a0d.png)
4. Select the required Epic logout behavior:
   - **Secure Epic EHR**
     - Secures the Epic session without fully signing out
     - Allows quick reauthentication
   - **Sign-out of Epic EHR**
     - Completely logs the user out of Epic
     - Ends all active sessions
       ![How to Configure Badge Out option - screenshot 10](/images/intercom/10616183/image-ea344618.png)
2. Click **Save** to apply the configuration.
   ![How to Configure Badge Out option - screenshot 11](/images/intercom/10616183/image-cde79136.png)
   The **Badge Out** configuration is saved successfully.
