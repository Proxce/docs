**Introduction**

Enabling manual face capture allows the user to manually capture the face when using the Windows Login app. Users must click the camera icon or press Enter or Spacebar to capture their face.

**Pre-requisite**:

The user must be a Tenant Admin to configure manual capture.

**Steps to configure manual capture**:

1. Log in to **Oloid Portal**.
2. On the homepage, select **Windows Login** application.
   ![Windows Login- Platform Configuration... - screenshot 1](/images/intercom/10662436/de68ecf3-d285-4be0-8d6b-17b80fe47f9d-f1eb5f7a.png)
   Theapplication details page is displayed.
3. Go to **Configure** tab > select **Settings** tab from the left menu panel.
   ![Windows Login- Platform Configuration... - screenshot 2](/images/intercom/10662436/fbe205e6-77ae-494d-8bb7-f5514b40a54d-86c31b99.png)
4. Turn on **Enable Manual Capture Accessibility** toggle button.
5. Click **Save**.
   ![Windows Login- Platform Configuration... - screenshot 3](/images/intercom/10662436/e4ed824a-3003-439e-8897-807a95d8b924-608b3ec1.png)

The manual capture is configured successfully.
