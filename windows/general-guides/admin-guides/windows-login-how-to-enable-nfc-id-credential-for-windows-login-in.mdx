## Introduction

The NFC/ID credential feature in the Tenant Admin Portal allows the admin to enable NFC/ID credential for the Windows Login application. Once enabled, users can log in to Windows endpoints by tapping their registered NFC tag.

## Prerequisites

- You must have Tenant Admin Access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable NFC/ID credential

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the preferred Windows Login application.
   ![How to enable NFC/ID credential for... - screenshot 1](/images/intercom/11891768/image-2781f560.png)
   The application page is displayed.
   ![How to enable NFC/ID credential for... - screenshot 2](/images/intercom/11891768/image-f3e9a758.png)
3. Go to **Authenticato**r tab.
4. Turn on **NFC/ID** toggle.

![How to enable NFC/ID credential for... - screenshot 3](/images/intercom/11891768/image-9e06d972.png)

The NFC/ID authenticator for Windows Login application is enabled successfully.
