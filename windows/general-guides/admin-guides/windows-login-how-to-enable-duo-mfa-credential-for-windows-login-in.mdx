## Introduction

The Duo feature in the Tenant Admin Portal allows admins to enable Duo as a second factor authentication for the Windows Login application. When enabled with other primary factors, users can log in to endpoints using Duo credentials as a second factor.

<Note>
  **Note:** Windows Login supports Face, Badge, QR Code and NFC/ID as primary factor.
</Note>

## Prerequisites

- You must have a Tenant Admin Account.
- Duo Security account credentials and details must be configured.

## Steps to Enable Duo MFA

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application.
   ![How to enable Duo MFA credential for... - screenshot 1](/images/intercom/12412511/image-54b04fd4.png)
   The application page is displayed.
   ![How to enable Duo MFA credential for... - screenshot 2](/images/intercom/12412511/image-48411548.png)
3. Go to the **Authenticato**r tab.

**MFA Credential** > turn on **Duo** toggle.

![How to enable Duo MFA credential for... - screenshot 3](/images/intercom/12412511/image-15072c5d.png)

The Duo MFA credential is enabled successfully.

![How to enable Duo MFA credential for... - screenshot 4](/images/intercom/12412511/image-0df0ec44.png)

### Sync Configuration to Apply Changes

After enabling the **Duo MFA credential**, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app).
