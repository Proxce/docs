## Introduction

This document provides instructions to log in to the configured Workforce/HRMS application using Employee ID on the DeviceLock app.

## Prerequisite

You must have a valid Okta account.

## Steps to Log in with Employee ID

1. Press the **Power** button or tap the device screen.

   <Note>
     **Note:** The Device Lock app is displayed automatically, as it always runs in Kiosk Mode.
   </Note>

   The **Welcome** screen is displayed.
2. Tap **Login with Employee ID**.

   <Note>
     **Note:** You will only see the authentication methods (Face, Badge, PIN, QR Code, Password and NFC/ID) enabled for you. The button names may vary based on configuration. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
   </Note>

   ![How to Log into Workforce/HRMS... - screenshot 1](/images/intercom/16160519/ae46dce1-2607-4612-ad33-601b4fad50c1-13e5c33b.png)
   The **Employe ID** screen is displayed.
3. Enter your Employee ID and then tap **Submit**.
   ![How to Log into Workforce/HRMS... - screenshot 2](/images/intercom/16160519/bb42e22e-d018-4136-ae97-6c2a09def37c-6fef18cb.png)
   After successful authentication, you are signed in to the Okta system.
   ![How to Log into Workforce/HRMS... - screenshot 3](/images/intercom/16160519/image-31be78ce.png)
