## Introduction

This document provides instructions for enrolling **Face and PIN credentials** using **Windows Login** application.

## Prerequisites

- In Tenant Admin Portal, you must enable **Allow Credential Updates and Enrollment** to enroll credentials in Windows Login app. For more details, refer to [How to enable Allow Credential Updates and Enrollment in Windows Login application](https://oloid.help/en/articles/10912821-oloid-portal-how-to-enable-credential-updates-and-enrollment-in-windows-login-application)
- Ensure that either the user’s Primary ID or email ID matches the username configured in the Tenant Admin Portal.
- Face and PIN credential should be enabled in the Windows Login application.
- You must enable the **Face followed by PIN MFA** toggle in the Windows Login application. For more, refer to [Windows Login - How to Enable Face Followed by PIN MFA](https://oloid.help/en/articles/13644652-windows-login-how-to-enable-face-followed-by-pin-mfa).

## Steps to Enroll Face

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to Enroll Face and PIN Credential - screenshot 1](/images/intercom/13666085/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to Enroll Face and PIN Credential - screenshot 2](/images/intercom/13666085/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to Enroll Face and PIN Credential - screenshot 3](/images/intercom/13666085/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens and the camera turns on.
2. Place your face in front of the camera for facial authentication.
   ![How to Enroll Face and PIN Credential - screenshot 4](/images/intercom/13666085/image-0c3d9755.png)
   The Face authentication fails and the Missing Credentials screen is displayed.
3. Click **Enroll Credential**.
   ![How to Enroll Face and PIN Credential - screenshot 5](/images/intercom/13666085/image-3552f6da.png)
   The **Verify using Windows Credential** screen is displayed.
4. Do the following:
   1. Enter **Domain**.

      <Note>
        **Note:** The Domain name is prefilled if **Enable Windows default domain** toggle is turned on, to know more refer [How to enable Windows Default Domain for Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/12266470-how-to-enable-windows-default-domain-for-windows-login-application-in-the-tenant-admin-portal).
      </Note>

   2. Enter **Username**.
   3. Enter **Password**.

      <Note>
        **Note:** Use your Windows account password.
      </Note>

   4. Select **Enroll Windows credential to your account**. (Optional)
   5. Click **Continue**.
      ![How to Enroll Face and PIN Credential - screenshot 6](/images/intercom/13666085/image-3daef69a.png)
      The **Select Credential to Enroll or Update** screen is displayed.
5. Select **Face**.
   ![How to Enroll Face and PIN Credential - screenshot 7](/images/intercom/13666085/image-b82c0a05.png)
   The camera turns on.
6. Place your face in front of the camera for face authentication.
   Your face is automatically captured.
   ![How to Enroll Face and PIN Credential - screenshot 8](/images/intercom/13666085/image-0ac91c1d.png)
   **Are you happy with picture** pop-up box is displayed.
7. Click **Yes, Submit.**
   ![How to Enroll Face and PIN Credential - screenshot 9](/images/intercom/13666085/image-6632ead9.png)
   The Face credential is enrolled successfully, and **Enrollment Successful** pop-up is displayed.

   <Note>
     **Note:** You can enroll up to **5 Face credentials** for a single user.
   </Note>

### Enroll PIN

1. Click **Enroll Face or PIN**.
   ![How to Enroll Face and PIN Credential - screenshot 10](/images/intercom/13666085/image-539170fd.png)
   The **Select Credential to Enroll or Update** Pop up is displayed.
2. Select **PIN** to enroll PIN credential.
   ![How to Enroll Face and PIN Credential - screenshot 11](/images/intercom/13666085/image-c5aec9c5.png)
   The **Add/Update PIN** screen is displayed.
3. Do the following:
   1. Enter new PIN.
   2. Re-enter new PIN.
   3. Click **Submit**.

      <Note>
        **Note:** You can configure PIN credentials in the Tenant Admin Portal. For more details, refer to [How to configure PIN](https://oloid.help/en/articles/8407872-how-to-configure-pin)
      </Note>

      ![How to Enroll Face and PIN Credential - screenshot 12](/images/intercom/13666085/image-e534ec4d.png)
      The PIN credential is enrolled successfully.

      ![How to Enroll Face and PIN Credential - screenshot 13](/images/intercom/13666085/image-f6e567b1.png)
