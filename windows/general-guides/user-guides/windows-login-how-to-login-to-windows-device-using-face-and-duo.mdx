## Introduction

The Windows Login app allows users to securely sign in to their Windows devices using Face and Duo authentication. This passwordless, multi-factor login method provides a faster and more secure way to access devices by combining facial recognition with Duo’s two-factor authentication.

## Prerequisite

- User face must be registered. For more Information, refer [Windows Login - How to enroll Face](https://oloid.help/en/articles/10006252-windows-login-how-to-enroll-face)
- You must have your registered mobile no.
- External Username or DUO Id from Add Identifier must be added in the User Details page which is registered in DUO app.

  <Note>
    **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
  </Note>

## Steps to sign in to Windows Device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to Login to Windows Device using... - screenshot 1](/images/intercom/12421904/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to Login to Windows Device using... - screenshot 2](/images/intercom/12421904/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to Login to Windows Device using... - screenshot 3](/images/intercom/12421904/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The **camera** turns on.
2. Show your Face in front of the camera to capture the face.
   ![How to Login to Windows Device using... - screenshot 4](/images/intercom/12421904/image-ea274e47.png)
   The **Choose Your Account** pop-up box is displayed.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, they can select a specific account to sign in. If the user has only one account configured, **Choose Your Account** pop-up box will not be displayed.
   </Note>

3. Select the account to sign in.
   ![How to Login to Windows Device using... - screenshot 5](/images/intercom/12421904/image-87004acc.png)
   The **Duo Security** pop-up box is displayed.
   ![How to Login to Windows Device using... - screenshot 6](/images/intercom/12421904/d2e6a818-c915-44c6-81e1-0b28efa1d22e-f3478173.png)
4. Select the user’s phone number from the **Device** dropdown in the **User Details** section.

   <Note>
     **Note:** The **Device** dropdown displays multiple phone numbers only if the user has more than one phone number configured in the system.
   </Note>

5. Do one of the following:
   1. **Duo Push**:
      1. Select **Send push** to send a notification to the registered mobile number.
         ![How to Login to Windows Device using... - screenshot 7](/images/intercom/12421904/2ccff0c7-0104-490a-80b3-184f2f928b3d-6752a5c8.png)
         The Push notification is displayed in your registered device.
      2. Tap **Approve**.
         ![How to Login to Windows Device using... - screenshot 8](/images/intercom/12421904/image-31--476becd6.png)
   2. **Passcode:**
      1. Select **Enter a Passcode** to send a Passcode to the registered mobile number.
         ![How to Login to Windows Device using... - screenshot 9](/images/intercom/12421904/87ae0b42-5918-49ae-81a5-1043917800c2-8228a0f3.png)
         A Passcode is displayed on the Duo mobile application.
         ![How to Login to Windows Device using... - screenshot 10](/images/intercom/12421904/image-bda906c3.png)
      2. Enter the passcode in the passcode field and click **Log In**.
         ![How to Login to Windows Device using... - screenshot 11](/images/intercom/12421904/image-1acee688.png)
         After successful authentication, the Duo success screen appears, and the user is logged in to their account.
         ![How to Login to Windows Device using... - screenshot 12](/images/intercom/12421904/image-ccb252e4.png)
