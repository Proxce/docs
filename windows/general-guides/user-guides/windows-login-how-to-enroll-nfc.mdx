## Introduction

This document provides step-by-step instructions for enrolling NFC through Windows Login app.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Enable NFC as an authenticator in the Windows application. For more details, refer [Windows Login - How to enable NFC/ID credential for Windows Login in the Tenant Admin Portal](https://oloid.help/en/articles/11891768-windows-login-how-to-enable-nfc-id-credential-for-windows-login-in-the-tenant-admin-portal)

## Steps to Enroll NFC through Windows Login app

1. On the Windows lock screen, click **Login with OLOID**.
   ![How to enroll NFC - screenshot 1](/images/intercom/10002126/image-1863c32e.png)
   The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with NFC Tag**.
   ![How to enroll NFC - screenshot 2](/images/intercom/10002126/image-002730e2.png)
3. Tap the **NFC Tag** on the **Card Reader** to scan it.

   <Note>
     **Note:** The card reader must be connected to the computer.
   </Note>

   ![How to enroll NFC - screenshot 3](/images/intercom/10002126/image-0a65c9b7.png)
   The NFC authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed** screen, select **Enroll Credential**.
   ![How to enroll NFC - screenshot 4](/images/intercom/10002126/image-92e636fe.png)
   The **Verify using Windows Credential** screen is displayed.
5. Do the following:
   1. Enter **Domain Name**
      Enter your Windows domain name.
   2. Enter **Username**.
      Use your Windows account username.
   3. Enter **Password**.
      Use your Windows account password.
   4. Select **Enroll Windows credential to your account**. (Optional)
   5. Click **Continue**.
      ![How to enroll NFC - screenshot 5](/images/intercom/10002126/image-0f2f4ebc.png)
      The **Select Credential to Enroll or Update** screen is displayed.
6. Select **NFC Tag**.
   ![How to enroll NFC - screenshot 6](/images/intercom/10002126/image-e12024b7.png)
   The **Scan your NFC Tag to Enroll** screen is displayed.
7. Scan your NFC Tag in the Card Reader.
   ![How to enroll NFC - screenshot 7](/images/intercom/10002126/image-98ff5712.png)
8. Click **Submit**.
   The NFC Tag is enrolled successfully.

![How to enroll NFC - screenshot 8](/images/intercom/10002126/image-f33a8fb3.png)
