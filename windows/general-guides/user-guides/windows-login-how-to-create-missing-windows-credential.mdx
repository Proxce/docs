#### Introduction

This document provides step-by-step instructions to create your Windows credentials in the Windows Login app. The user gets a missing credential error message when trying to log in to Windows device.

#### Pre-requisite

You must enable the Validate Windows Credential toggle button in Windows Login application in the Tenant Admin Portal. For more details, refer [How to enable Validate Windows Credential in Windows Login application](https://oloid.help/en/articles/10900687-how-to-enable-validate-windows-credential-in-windows-login-application)

#### Steps to create your password on Windows device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to Create missing Windows Credential - screenshot 1](/images/intercom/10956677/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to Create missing Windows Credential - screenshot 2](/images/intercom/10956677/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to Create missing Windows Credential - screenshot 3](/images/intercom/10956677/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens.
2. Select your preferred authentication method.

   <Note>
     **Note:** For detailed instructions about signing in to your Windows device using different authentication methods, refer [User Guides sections for Windows Login Device](https://oloid.help/en/collections/9564765-user-guides-windows-login#:~:text=Guides%20%2D%20Windows%20Login-,User%20Guides%20%2D%20Windows%20Login,-12%20articles)
   </Note>

   ![How to Create missing Windows Credential - screenshot 4](/images/intercom/10956677/image-c12581e3.png)
3. After successful authentication, if your Windows credential is missing, the **Missing Windows Credential** screen is displayed.
4. Select **Create Account** to create Windows Credential.
   ![How to Create missing Windows Credential - screenshot 5](/images/intercom/10956677/a7d6b0f5-1906-40b0-b8c5-5a9529099fe7-9510eaac.png)
   The **Create Account** screen is displayed.

5. Do the following:
   - [Create credential for Domain User](#create-credential-for-domain-user)
   - [Create credential for Local User](#create-credential-for-local-user)

## Create credential for Domain User

1. Select Credential Type as Domain User from the Select Credential Type drop-down list.
2. Enter your Windows domain and username in the format `Domain\Username`.
3. Enter Username in the **Username** field.
4. Enter Password in the **Password** field.
5. Click **Create**.
   ![How to Create missing Windows Credential - screenshot 7](/images/intercom/10956677/image-123b3a5a.png)

Your Windows account is created successfully, and you can log in to your Windows device.

![How to Create missing Windows Credential - screenshot 8](/images/intercom/10956677/image-f3eb68bc.png)

## Create credential for Local User

1. Select Credential Type as Local User from the Select Credential Type drop-down list.
2. The Local machine name is auto-populated in the **Domain/Machine Name** field.
3. Enter Username in the **Username** field.
4. Enter Password in the **Password** field.
5. Click **Create**.
   ![How to Create missing Windows Credential - screenshot 9](/images/intercom/10956677/4513c610-a085-4083-ab88-7ef779e7f388-d8f21ac2.png)

Your Windows account is created successfully, and you can log in to your Windows device.
