## Introduction

This document provides step-by-step instructions for logging in to the Supervisor App using Google SSO. When SSO is enabled, users can authenticate using their Google account credentials to securely access the Supervisor App.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Ensure User has a Microsoft account.
- Ensure SSO is enabled in the Tenant Admin Portal. For more information, refer: [Tenant Admin Portal - How to Enable GSuite SSO in Tenant Admin Portal](https://oloid.help/en/articles/11129566-tenant-admin-portal-how-to-enable-gsuite-sso-in-tenant-admin-portal)

## Step to Login with Google

1. Double-click on the **Supervisor App** to start.
   ![How to Login to Supervisor App with... - screenshot 1](/images/intercom/9727729/image-78170438.png)
   The Login screen is displayed.
2. Click **Login with SSO.**
   ![How to Login to Supervisor App with... - screenshot 2](/images/intercom/9727729/image-a6dd338f.png)
   The **Login with SSO** page is displayed.
3. Select **Login with Google.**
   ![How to Login to Supervisor App with... - screenshot 3](/images/intercom/9727729/image-87dd5e97.png)
   The **Sign in** page is displayed.
   ![How to Login to Supervisor App with... - screenshot 4](/images/intercom/9727729/image-d42b266a.png)
4. Enter **Email or phone.**
5. Click **Next.**
   The **Welcome** page is displayed.
   ![Image](/images/intercom/9727729/7f6e7469-d76f-454e-963d-5949c9e88cbe-d627a2c0.png)
6. Enter **Password.**
7. Click **Next.**
   You are logged into the Supervisor app.
   ![How to Login to Supervisor App with... - screenshot 5](/images/intercom/9727729/image-6e846f4d.png)
