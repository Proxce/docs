## Introduction

The authentication process requires users to scan their assigned Badge and enter their Password to securely access the Windows device.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- In the Tenant Admin Portal, you must do the following:
  - Assign Badge ID to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users).
  - Enable Badge authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_9366168092:~:text=by%20Oloid%20admin.-,Badge%20ID,-To%20use%20Badge).
  - Configure password credential for Windows Login Application. For more details refer [How to configure Password credential in Windows Login Application](https://oloid.help/en/articles/11507597-how-to-configure-password-credential-in-windows-login-application).

    <Note>
      **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
    </Note>

## Steps to sign in to Windows device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to log in to Windows device using... - screenshot 1](/images/intercom/11848536/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to log in to Windows device using... - screenshot 2](/images/intercom/11848536/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to log in to Windows device using... - screenshot 3](/images/intercom/11848536/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens and the **Scan Badge** pop-up box is displayed.
2. Tap the **Badge** on the **Badge Reader** to scan it.
   ![How to log in to Windows device using... - screenshot 4](/images/intercom/11848536/image-7a88803b.png)
   After Badge authentication, the **Enter Password** pop-up box is displayed.
3. Enter the **Password** > click **Submit**.

![How to log in to Windows device using... - screenshot 5](/images/intercom/11848536/dfaeb2e6-e01a-4dd1-871a-6813a7f2ec4c-4d915559.png)

You have logged in to Windows device using Badge and Password credential through Windows Login app successfully.
