## Introduction

This document provides step-by-step instructions for enrolling face through Windows Login app.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- In Tenant Admin Portal, you must enable **Allow Credential Updates and Enrollment** to enroll credentials in Windows Login app. For more details, refer to [How to enable Allow Credential Updates and Enrollment in Windows Login application](https://oloid.help/en/articles/10912821-oloid-portal-how-to-enable-credential-updates-and-enrollment-in-windows-login-application)
- Ensure the **Enable Windows default domain** toggle is turned on. For more details, refer to [How to enable Windows Default Domain for Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/12266470-how-to-enable-windows-default-domain-for-windows-login-application-in-the-tenant-admin-portal)
- Make sure either the user's Primary ID or email ID matches your System Account Name.

## Steps to enroll face through Windows Login app

1. On the Windows lock screen, click **Login with OLOID**.
   ![How to enroll Face - screenshot 1](/images/intercom/10006252/image-1863c32e.png)
   The Windows login app opens and the **Welcome** page is displayed.
2. Select **Login with Face**.
   ![How to enroll Face - screenshot 2](/images/intercom/10006252/image-59096d44.png)
   The Windows login app opens and the camera turns on.
3. Place your face in front of the camera for facial authentication.
   ![How to enroll Face - screenshot 3](/images/intercom/10006252/image-0c3d9755.png)
   The Face authentication fails and the Enroll Credential option is displayed.
4. On the **Authentication Failed** screen, select **Enroll Credential**.
   ![How to enroll Face - screenshot 4](/images/intercom/10006252/image-92e636fe.png)
   The **Verify using Windows Credential** screen is displayed.
5. Do the following:
   1. Enter **Domain Name**
      Enter your Windows domain name.
   2. Enter **Username**.
      Use your Windows account username.
   3. Enter **Password**.
      Use your Windows account password.
   4. Select **Enroll Windows credential to your account**. (Optional)
   5. Click **Continue**.
      ![How to enroll Face - screenshot 5](/images/intercom/10006252/image-0f2f4ebc.png)
      The **Select Credential to Enroll or Update** screen is displayed.
6. Select **Face**.

   <Note>
     **Note:** If connection is enabled, user consent is requested before uploading the picture.
   </Note>

   ![How to enroll Face - screenshot 6](/images/intercom/10006252/image-18f1f11e.png)
   The camera turns on.
7. Place your face in front of the camera for face authentication.

![How to enroll Face - screenshot 7](/images/intercom/10006252/image-0ac91c1d.png)

Your face is automatically captured and it is enrolled successfully.

![How to enroll Face - screenshot 8](/images/intercom/10006252/image-672be44f.png)
