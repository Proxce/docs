## Introduction

This document provides step-by-step instructions for logging in to the Supervisor App using Microsoft SSO. When SSO is enabled, users can authenticate using their Microsoft account credentials to securely access the Supervisor App.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Ensure User has a Microsoft account.
- Ensure SSO is enabled in the Tenant Admin Portal. For more information, refer: [Tenant Admin Portal - How to Enable Entra ID SSO](https://oloid.help/en/articles/14663355-tenant-admin-portal-how-to-enable-entra-id-sso)

## Steps to login with Microsoft

1. Double-click on the **Supervisor App** to start.
   ![How to Login to Supervisor App with... - screenshot 1](/images/intercom/9727795/image-78170438.png)
   The Login screen is displayed.
2. Click **Login with SSO.**
   ![How to Login to Supervisor App with... - screenshot 2](/images/intercom/9727795/image-f942b8c3.png)
   The **Login with SSO** page is displayed.
3. Select **Login with Microsoft.**
   ![How to Login to Supervisor App with... - screenshot 3](/images/intercom/9727795/image-2b81d4c5.png)
   The **Sign in** page is displayed.
   ![How to Login to Supervisor App with... - screenshot 4](/images/intercom/9727795/image-73911acc.png)
4. Enter **Email, phone, or Skype.**
5. Click **Next.**
   The **Enter password** page is displayed.
   ![How to Login to Supervisor App with... - screenshot 5](/images/intercom/9727795/image-3922ed46.png)
6. Enter **Password.**
7. Click **Sign in.**
   You are logged into the Supervisor app.
   ![How to Login to Supervisor App with... - screenshot 6](/images/intercom/9727795/image-f6579a5e.png)
