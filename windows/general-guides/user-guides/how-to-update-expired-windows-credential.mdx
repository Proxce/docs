**Introduction**

This document provides step-by-step instructions to update expired Windows Credential.

**Pre-requisite**

You must enable the Validate Windows Credentials toggle button in Windows Login application in the Tenant Admin Portal. For more details, refer [How to enable Validate Windows Credential in Windows Login application](https://oloid.help/en/articles/10900687-how-to-enable-validate-windows-credential-in-windows-login-application)

**Steps to update your expired Windows Credentials:**

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to update expired Windows Credential - screenshot 1](/images/intercom/10954843/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to update expired Windows Credential - screenshot 2](/images/intercom/10954843/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to update expired Windows Credential - screenshot 3](/images/intercom/10954843/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens.
2. Select your preferred authentication method.

   <Note>
     **Note:** For detailed instructions about signing in to your Windows device using different authentication methods, refer to[User Guides sections for Windows Login Device](https://oloid.help/en/collections/9564765-user-guides-windows-login#:~:text=Guides%20%2D%20Windows%20Login-,User%20Guides%20%2D%20Windows%20Login,-12%20articles)
   </Note>

   ![How to update expired Windows Credential - screenshot 4](/images/intercom/10954843/image-d2fcc6d3.png)
   On successful authentication, you are signed in to the Windows device.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in.
   </Note>

   ![How to update expired Windows Credential - screenshot 5](/images/intercom/10954843/image-deec4dc6.png)
3. If your Windows password is changed or expired, the **Invalid or Missing Windows Credential** screen is displayed.
4. Select the account you want to update.
   ![How to update expired Windows Credential - screenshot 6](/images/intercom/10954843/a461cf3c-62cb-403b-afe4-83aba56c1376-ba188ae5.png)
   The **Edit Password** screen is displayed.
   ![How to update expired Windows Credential - screenshot 7](/images/intercom/10954843/85a031be-be9f-40e3-bf37-be97fe68491b-ffaf73e8.png)
5. Do the following:
   1. Enter Password in the **Enter new Password** field.
   2. Enter new Password in the **Re-enter New Password** field.
   3. Click **Save**.

Your password is updated, and you can log in successfully to your Windows device.

![How to update expired Windows Credential - screenshot 8](/images/intercom/10954843/image-52990346.png)
