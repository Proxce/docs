## Introduction

Enable Windows Default Domain: Allow the use of the default Windows domain for authentication. Users can enroll credentials to the default Windows domain.

## Prerequisite

- Email ID must be created for the user account.
- Default domain must be enabled for the application.
- Face + PIN credentials should be enabled for the user account.

## Steps to Enroll Face and PIN as credentials

Users can Enroll credentials:

1. [Before Authentication](#steps-to-enroll-credentials-using-default-domain-before-authentication)
2. [During Authentication](#steps-to-enroll-credentials-using-default-domain-during-authentication)

<Note>
  **Note:** Other credentials like **Badge** and **NFC** can also be enrolled using the process mentioned here, refer: [How to enroll credentials using Windows Login app](https://oloid.help/en/articles/10932990-how-to-enroll-credentials-using-windows-login-app?q=enroll+face+in)
</Note>

### Steps to Enroll Credentials using Default Domain before authentication

1. Launch the Windows User Application.
2. Click the **Three Arrows icon.**
3. Select **Enroll Credentials.**
   ![How to Enroll Face and PIN Credentials... - screenshot 1](/images/intercom/13615607/image-477af5f6.png)
   The Verification screen is displayed.
4. Do the following:
   1. Enter Domain Name (Auto filled by default)
   2. Enter **Username**
   3. Enter **Password**
   4. Select the Enroll Windows Credentials to your account checkbox. (optional)
   5. Click **Continue**.
      ![How to Enroll Face and PIN Credentials... - screenshot 2](/images/intercom/13615607/image-e7cfa77f.png)
      The Credential Enrollment screen is displayed.
      ![How to Enroll Face and PIN Credentials... - screenshot 3](/images/intercom/13615607/image-e0336d15.png)
5. Select **Face** or **PIN**
   1. For Face
   2. For PIN

### Steps to Enroll Credentials using Default Domain during authentication

1. Launch the Windows User Application.
2. The Camera opens.
3. Position your face in front of the camera and tap the **Capture** button to enroll your face.
   Missing credentials screen is displayed
4. Click **Manage Credentials**.
   ![How to Enroll Face and PIN Credentials... - screenshot 4](/images/intercom/13615607/image-4a9cd5b7.png)
   The Verification screen is displayed.
5. Do the following:
   1. Enter Domain Name (Auto filled by default)
   2. Enter **Username**
   3. Enter **Password**
   4. Select the Enroll Windows Credentials to your account checkbox. (optional)
   5. Click **Continue**.

![How to Enroll Face and PIN Credentials... - screenshot 5](/images/intercom/13615607/image-2e7b8b98.png)

The Credential Enrollment screen is displayed.

![How to Enroll Face and PIN Credentials... - screenshot 6](/images/intercom/13615607/image-1ab60376.png)

### Steps to Enroll Face

1. Click **Face**.
2. The Camera turns on.
3. Position your face in front of the camera and tap the **Capture** button to enroll your face.

   <Note>
     **Note:** If you do not tap the **Capture** button, the app automatically captures your face after a few seconds.
   </Note>

   ![How to Enroll Face and PIN Credentials... - screenshot 7](/images/intercom/13615607/image-ce6a1f61.png)
4. Do one of the following:
   1. Tap **Yes- Submit** to submit the image.
      The face is submitted successfully and is displayed on the details screen.
   2. Tap **No- Retake** to take the photo again.
      The camera turns on to retake the photo.
      ![How to Enroll Face and PIN Credentials... - screenshot 8](/images/intercom/13615607/image-ab11fae9.png)
      Enrollment Successful screen is displayed.
5. Click **Done** to finish enrollment.
6. To Enroll other credentials click **Enroll Button / Manage Credentials**.

   <Note>
     **Note:** The Manage Credentials button may have different UI lables based on the credentials enabled for the user.
   </Note>

### Steps to Enroll PIN using Default Domain during authentication

![How to Enroll Face and PIN Credentials... - screenshot 9](/images/intercom/13615607/image-0f4babaf.png)

The Enter PIN page is displayed.

1. Enter **PIN** and click **Submit**.
   Invalid PIN message is displayed.

   <Note>
     **Note:** After maximum PIN attempts have been used. User is redirected to enroll PIN.
   </Note>

   ![How to Enroll Face and PIN Credentials... - screenshot 10](/images/intercom/13615607/image-b99adfcc.png)
   Missing Credentials screen is displayed.
2. Click **Enroll Credential**.
   ![How to Enroll Face and PIN Credentials... - screenshot 11](/images/intercom/13615607/image-112aabe0.png)
   The Verification screen is displayed.
3. Do the following:
   1. Enter Domain Name (Auto filled by default)
   2. Enter **Username**
   3. Enter **Password**
   4. Select the Enroll Windows Credentials to your account checkbox. (optional)
   5. Click **Continue**.

![How to Enroll Face and PIN Credentials... - screenshot 12](/images/intercom/13615607/image-a7ad806f.png)

The Credential Enrollment screen is displayed.

![How to Enroll Face and PIN Credentials... - screenshot 13](/images/intercom/13615607/image-583d0726.png)

### To Enroll PIN

4. Click **PIN**.
   The Add/Update PIN screen is displayed.
   1. Enter **New PIN**
   2. Re-Enter **New PIN**
   3. Click **Submit**.
      ![How to Enroll Face and PIN Credentials... - screenshot 14](/images/intercom/13615607/image-22081ccc.png)
      Enrollment Successful screen is displayed.
5. Click **Done** to finish enrollment.
   ![How to Enroll Face and PIN Credentials... - screenshot 15](/images/intercom/13615607/image-46b4fa0c.png)
