## Introduction

This document provides step-by-step instructions for logging in with username to Windows device.

## Pre-requisite

- You must have an Oloid account.
- You must add face to the user. For more details, refer [How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user)

## Steps to sign in to Windows device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to log in to Windows device using... - screenshot 1](/images/intercom/8893874/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to log in to Windows device using... - screenshot 2](/images/intercom/8893874/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to log in to Windows device using... - screenshot 3](/images/intercom/8893874/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The **Welcome** screen is displayed.
2. Enter your employee ID / email ID in **Enter your Employee ID / Email ID** textbox, then click **Continue**.
   ![How to log in to Windows device using... - screenshot 4](/images/intercom/8893874/image-79272df1.png)
   The camera turns on.
3. Place your face in front of the camera for facial authentication.

   <Note>
     **Note:** Face credential must be enabled in the Oloid Portal. For more details, refer [How to create and configure Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_5bc83c7490:~:text=needing%20further%20authentication.-,Face,-To%20use%20face)
   </Note>

   ![How to log in to Windows device using... - screenshot 5](/images/intercom/8893874/image-f3e40b5a.png)
4. On successful facial authentication, you are signed in to the Windows device.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully.
   </Note>

   ![How to log in to Windows device using... - screenshot 6](/images/intercom/8893874/image-0ca0ac79.png)
