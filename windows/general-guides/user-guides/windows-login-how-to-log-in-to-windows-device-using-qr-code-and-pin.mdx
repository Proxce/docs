**Introduction**

This document provides step-by-step instructions for logging in with QR Code and PIN to Windows device.

**Pre-requisite**

- In the Oloid Portal, you must do the following:
  - Assign QR Code to the user. For more details, refer [How to create QR Code as credential for users](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-to-users)
  - Enable QR Code as an authenticator in the Windows application. For more details, refer [How to enable QR Code in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_6ce39798f2:~:text=multi%2Dfactor%20authentication.-,QR%20Code,-To%20use%20QR)
  - Add PIN access to the user. For more details, refer [How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable PIN as an authenticator in the Windows application. For more details, refer [How to enable PIN in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_0412e471e4:~:text=multi%2Dfactor%20authentication.-,PIN,-To%20use%20PIN)

    <Note>
      **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
    </Note>

Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to log in to Windows device using... - screenshot 1](/images/intercom/10627189/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to log in to Windows device using... - screenshot 2](/images/intercom/10627189/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to log in to Windows device using... - screenshot 3](/images/intercom/10627189/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens and the camera turns on.
2. Show your QR Code in front of the camera for QR Code authentication.
   ![How to log in to Windows device using... - screenshot 4](/images/intercom/10627189/image-a95606cc.png)
   On successful QR Code authentication, the **Enter PIN** pop-up box is displayed.

Enter the **PIN** then click **Submit**.

![How to log in to Windows device using... - screenshot 5](/images/intercom/10627189/image-e9cb83d8.png)

On PIN authentication, you are signed in to the Windows device.

<Note>
  **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully.
</Note>

![How to log in to Windows device using... - screenshot 6](/images/intercom/10627189/image-0ca0ac79.png)
