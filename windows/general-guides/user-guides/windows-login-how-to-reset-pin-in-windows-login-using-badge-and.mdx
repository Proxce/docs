## Introduction

This document explains how users can reset their PIN credential in Windows Login if they have forgotten their existing PIN. The Forgot PIN feature allows users to securely reset their PIN directly from the Windows Login screen after authenticating with another credential such as a Badge.

## Prerequisites

- The **Forgot PIN** toggle must be enabled and configured in the Tenant Admin Portal. For more, refer to [How to Enable Forgot PIN Link in Windows Login Application](https://oloid.help/en/articles/14015958-tenant-admin-portal-how-to-enable-forgot-pin-link-in-windows-login-application)
- The Badge reader is connected to the Windows device.
- The user must have a valid Badge credential assigned.

## Steps to Reset PIN from Windows Login Screen

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to Reset PIN in Windows Login Using... - screenshot 1](/images/intercom/14074958/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to Reset PIN in Windows Login Using... - screenshot 2](/images/intercom/14074958/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to Reset PIN in Windows Login Using... - screenshot 3](/images/intercom/14074958/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens and the **Welcome** page is displayed.
2. On the **Welcome** page, Click **Login with Badge.**
   ![How to Reset PIN in Windows Login Using... - screenshot 4](/images/intercom/14074958/3d863974-6ae6-433b-a81d-da37fc99813d-8bc532f7.png)
   The **Scan Badge at the Reader** page is displayed.
3. Tap the **Badge** on the **Badge Reader** to scan it.
   ![How to Reset PIN in Windows Login Using... - screenshot 5](/images/intercom/14074958/image-d87fee7d.png)
   On Badge authentication, the **Enter PIN** pop-up box is displayed.

Click **Forgot PIN.**

## Option 2: PIN enrollment using Windows credential verification

4. The system redirects you to the **Verify using Windows Credential page**.
   From this page, reset your PIN following the Windows credential management process.
   The **Verify using Windows Credential** screen is displayed.
1. Do the following:
   1. Enter **Domain name**.
   2. Enter **Username**.
   3. Enter **Password**.

      <Note>
        **Note:** Use your Windows account password.
      </Note>

   4. Select **Enroll Windows credential to your account**. (Optional)
   5. Click **Continue**.
      ![How to Reset PIN in Windows Login Using... - screenshot 8](/images/intercom/14074958/image-1f99584e.png)
      The **Select Credential to Enroll or Update** screen is displayed.
2. Click **PIN**.
   ![How to Reset PIN in Windows Login Using... - screenshot 9](/images/intercom/14074958/a7d14378-f5b0-4da9-a4f0-1936a6a2138c-0fa990a5.png)
   The Add/Update PIN page is displayed
3. Do the following:
   1. Enter **new PIN.**
   2. **Re-enter new PIN**.
   3. Click **Submit**.

      <Note>
