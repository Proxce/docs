## Introduction

The **Enroll Credential** process in the Windows Login app allows users to securely register authentication methods such as Face, Badge, PIN, or NFC for passwordless access.

## Prerequisites

- In Tenant Admin Portal, you must enable **Allow Credential Updates and Enrollment** to enroll credentials in Windows Login app. For more details, refer to [How to enable Allow Credential Updates and Enrollment in Windows Login application](https://oloid.help/en/articles/10912821-oloid-portal-how-to-enable-credential-updates-and-enrollment-in-windows-login-application)
- Ensure the **Enable Windows default domain** toggle is turned on. For more details, refer to [How to enable Windows Default Domain for Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/12266470-how-to-enable-windows-default-domain-for-windows-login-application-in-the-tenant-admin-portal)
- Make sure either the user's Primary ID or email ID matches your System Account Name.

## Steps to enroll credential in Windows Login app

1. Launch the Windows Login app.
2.    ![How to Enroll Credentials - screenshot 2](/images/intercom/10932990/91b77c19-4687-4741-b5cc-1b7b5131f6ac-a8e839f5.png)
   The **Verify using Windows Credential** screen is displayed.
3. Do the following:
   1. Enter **Domain Name**
      Enter your Windows domain name.
   2. Enter **Username**.
      Use your Windows account username.
   3. Enter **Password**.
      Use your Windows account password.
   4. Select **Enroll Windows credential to your account**. (Optional)
   5. Click **Continue**.
      ![How to Enroll Credentials - screenshot 3](/images/intercom/10932990/image-0f2f4ebc.png)
      The **Select Credential to Enroll or Update** screen is displayed.
      ![How to Enroll Credentials - screenshot 4](/images/intercom/10932990/image-e0a029aa.png)
4. Select any of the preferred credentials to enroll.
   - [Enroll Face](#enroll-face)
   - [Enroll Badge](#enroll-badge)
   - [Enroll PIN](#enroll-pin)
   - [Enroll NFC](#enroll-nfc)

### Enroll Face

1. Select **Face**.

   <Note>
     **Note:** If connection is enabled, user consent is requested before uploading the picture.
   </Note>

   ![How to Enroll Credentials - screenshot 5](/images/intercom/10932990/56f38f28-250f-4b24-b613-7a3a6fd9100f-7e8c44d0.png)
   The Windows login app opens and the camera turns on.
2. Place your face in front of the camera for facial authentication.
   ![How to Enroll Credentials - screenshot 6](/images/intercom/10932990/image-2c5c8f7a.png)
3. Do one of the following:
   1. Tap **Yes- Submit** to submit the image.
      The face is submitted successfully and is displayed on the details screen.
   2. Tap **No- Retake** to take the photo again.
      The camera turns on to retake the photo.

      <Note>
        **Note:** A maximum of five faces can be added.
      </Note>

      ![How to Enroll Credentials - screenshot 7](/images/intercom/10932990/image-5037342f.png)
      Your face is automatically captured and it is enrolled successfully.
4. Do one of the following:
   1. Click **Done** to finish enrollment.
   2. Click **Manage Credential** to enroll another credential.

      <Note>
        **Note:** Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
      </Note>

      ![How to Enroll Credentials - screenshot 8](/images/intercom/10932990/image-f5b371de.png)

### Enroll Badge

1. Select **Badge**.
   ![How to Enroll Credentials - screenshot 9](/images/intercom/10932990/image-09720c56.png)
   The **Scan your Badge to Enroll** screen is displayed.
2. Scan your badge on the Badge Reader.
   ![How to Enroll Credentials - screenshot 10](/images/intercom/10932990/image-ecbfc19b.png)
3. Click **Submit**.
   The badge is enrolled successfully.
4. Do one of the following:
   1. Click **Done** to finish enrollment.
   2. Click **Manage Credential** to enroll another credential.

      <Note>
        **Note:** Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
      </Note>

      ![How to Enroll Credentials - screenshot 11](/images/intercom/10932990/image-2065cd80.png)

### Enroll PIN

1. Select **PIN**.
   ![How to Enroll Credentials - screenshot 12](/images/intercom/10932990/254b1b28-b416-41ff-8aa0-41f53673b6b4-697f0b6e.png)
   The **Add/Update PIN** screen is displayed.

   <Note>

2. Do the following:
   1. Enter **PIN**.
   2. Re-enter **PIN**.
      The PIN is enrolled successfully.
3. Do one of the following:
   1. Click **Done** to finish enrollment.
   2. Click **Manage Credential** to enroll another credential.

      <Note>
        **Note:** Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
      </Note>

      ![How to Enroll Credentials - screenshot 14](/images/intercom/10932990/image-7e5ab1b2.png)

1. Select **NFC Tag**.
   ![How to Enroll Credentials - screenshot 15](/images/intercom/10932990/image-e12024b7.png)

3. Click **Submit**.
   The NFC Tag is enrolled successfully.
4. Do one of the following:

   2. Click **Manage Credential** to enroll another credential.

      <Note>
        **Note:** Button names may vary based on enrolled credentials. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
      </Note>
