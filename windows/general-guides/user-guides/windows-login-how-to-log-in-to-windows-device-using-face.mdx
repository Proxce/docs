## Introduction

This document provides step-by-step instructions for logging in with face to Windows device.

### Pre-requisite

- In the Oloid Portal, you must do the following:
  - Add Face to the user. For more details, refer [How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user)
  - Enable Face under the Windows application. For more details, refer [How to create and configure Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_5bc83c7490:~:text=needing%20further%20authentication.-,Face,-To%20use%20face)
  - Manual face capture (as per the requirement) must be configured in Oloid Portal. You need to turn on [Enable Manual Capture Accessibility](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_26561b72fa:~:text=Enable%20Manual%20Capture%20Accessibility%3A)toggle buttonin Windows Configuration.

    <Note>
      **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
    </Note>

Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to log in to Windows device using... - screenshot 1](/images/intercom/8637172/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to log in to Windows device using... - screenshot 2](/images/intercom/8637172/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to log in to Windows device using... - screenshot 3](/images/intercom/8637172/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens and the camera turns on.
2. Place your face in front of the camera for facial authentication.
   ![How to log in to Windows device using... - screenshot 4](/images/intercom/8637172/User-widget---Enroll-Face-dc17da5c.png)
   The camera auto-captures the user's face.
   If manual capture is enabled, press **Enter or Spacebar,** or click on the camera icon.
   ![How to log in to Windows device using... - screenshot 5](/images/intercom/8637172/40280676-db31-407a-81b8-079007677dc8-dba5bcb4.png)
   On successful facial authentication, you are signed in to the Windows system.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully.
   </Note>

   ![How to log in to Windows device using... - screenshot 6](/images/intercom/8637172/image-0ca0ac79.png)
