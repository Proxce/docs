## Introduction

This document provides step-by-step instructions for logging in with badge and PIN to Windows device.

### Pre-requisite

- In the Oloid Portal, you must do the following:
  - Assign Badge ID to the user. For more details, refer [How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)
  - Enable Badge as an authenticator in the Windows application. For more details, refer [How to enable Badge in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_9366168092:~:text=by%20Oloid%20admin.-,Badge%20ID,-To%20use%20Badge)
  - Add PIN access to the user. For more details, refer [How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users)
  - Enable PIN as an authenticator in the Windows application. For more details, refer [How to enable PIN in Windows application](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application#h_0412e471e4:~:text=multi%2Dfactor%20authentication.-,PIN,-To%20use%20PIN)

    <Note>
      **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
    </Note>

Steps to sign in to Windows device:

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to log in to Windows device using... - screenshot 1](/images/intercom/8893845/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to log in to Windows device using... - screenshot 2](/images/intercom/8893845/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to log in to Windows device using... - screenshot 3](/images/intercom/8893845/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows login app opens and the **Scan Badge** page is displayed.
2. Tap the **Badge** on the **Badge Reader** to scan it.
   ![How to log in to Windows device using... - screenshot 4](/images/intercom/8893845/image-d87fee7d.png)
   On Badge authentication, the **Enter PIN** pop-up box is displayed.
3. Enter the **PIN** then click **Submit**.
   ![How to log in to Windows device using... - screenshot 5](/images/intercom/8893845/89dfc4a7-836c-447f-8c26-d3feabde1d53-2c6e1a97.png)
   On PIN authentication, you are signed in to the Windows device.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, then the **Choose Your Account** page is displayed. You can select a specific account to sign in successfully.
   </Note>

   ![How to log in to Windows device using... - screenshot 6](/images/intercom/8893845/image-0ca0ac79.png)
