## Introduction

This document provides step-by-step instructions for logging out of a Windows system using a badge through the Windows Login app. When configured, users can scan their assigned badge to lock or sign out of the Windows system, based on the configured logout action.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- The badge must be assigned to the user. For more details, refer [Supervisor App: Assign Badge](https://oloid.help/en/articles/9115843-supervisor-app-assign-badge).
- The **Enable Badge Out** option must be enabled in the Windows Login application. For details see, [Windows Login - How to enable Badge out option](https://oloid.help/en/articles/10616183-windows-login-how-to-enable-badge-out-option)
- The badge reader must be connected to the Windows system..

## Steps to log out of Windows System using Badge

1. On the Lock screen, select **Login with OLOID**.
   ![How to log out of Windows System using... - screenshot 1](/images/intercom/10616223/image-dc9b6bb9.png)
   The Welcome screen of the Windows Login App is displayed.
2. Enter your credentials to log in to the system..
   The Windows homepage is displayed.
   ![How to log out of Windows System using... - screenshot 2](/images/intercom/10616223/image-d69dd9a7.png)

Scan the badge on the badge reader to lock your Windows system

![How to log out of Windows System using... - screenshot 3](/images/intercom/10616223/image-d75b5625.png)

Your Windows system is successfully locked, and the **Lock** screen appears.

![How to log out of Windows System using... - screenshot 4](/images/intercom/10616223/image-07fd6ce0.png)

<Note>
  **Note:** If the Windows Login application is configured with the **Sign out of Windows** option, all open applications in the system will close, and the **Lock** screen will appear.
</Note>
