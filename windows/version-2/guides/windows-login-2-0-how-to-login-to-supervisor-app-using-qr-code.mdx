## Introduction

Oloid Windows Login lets users sign in to the Supervisor App on a shared Windows endpoint without typing a username or password. With QR login, users sign in by showing their assigned QR code to the endpoint's camera. This makes sign-in fast and contactless on shared devices.

## Prerequisites

- The Windows Login application must be created in the Tenant Admin Portal. For more information, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal).
- The endpoint must be paired with the Windows Login application. For more information, refer to [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app).
- A QR code credential must be assigned to the user. For more information, refer to [How to assign QR code as a credential to users](https://oloid.help/en/articles/8294162-tenant-admin-portal-how-to-create-and-share-qr-code-credential-with-user).
- QR must be enabled as an authenticator in the Windows application. For more information, refer to [How to enable QR in Windows application](https://oloid.help/en/articles/11484322-windows-login-how-to-enable-qr-code-credential-for-windows-login-in-the-tenant-admin-portal).

## Steps to Login using QR Code

1. Double-click the Supervisor App to start it.

   ![How to Login to Supervisor App using QR... - screenshot 1](/images/intercom/17132800/image-9442aa70.png)
   The Login screen is displayed.
2. Click **Continue with Oloid**.

   ![How to Login to Supervisor App using QR... - screenshot 2](/images/intercom/17132800/image-942a8b0e.png)
   The Credential screen is displayed.
3. Click **Login with QR**.

   ![How to Login to Supervisor App using QR... - screenshot 3](/images/intercom/17132800/image-578276c1.png)
   The Scan QR screen is displayed and the camera turns on.
4. Hold the QR code in front of the camera, inside the scan frame, until it is scanned.

   ![How to Login to Supervisor App using QR... - screenshot 4](/images/intercom/17132800/image-6ac54fcc.png)
   When authentication succeeds, the user is logged in to the Supervisor App.
