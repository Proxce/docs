## Introduction

Focus Monitor helps ensure that users remain attentive while using a Windows device. It monitors whether the authenticated user looks away from the screen beyond a configured angle for a specified duration and triggers the configured action when the defined threshold is exceeded.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure the endpoint is paired with the Windows Login application. refer: [How to pair endpoint using Pair as Supervisor in Supervisor App](https://oloid.help/en/articles/9059601-how-to-pair-endpoint-using-pair-as-supervisor-in-supervisor-app)
- Ensure that your system is unlocked
- Ensure that your system's camera is working properly

## Steps to** configure **Focus Monitor

1. Log in to Tenant Admin Portal.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to Enable Focus Monitor for... - screenshot 1](/images/intercom/16012060/image-719d9eff.png)
   The Endpoints page is displayed.
3. Click endpoint name (Windows Login) to edit from the listed endpoints.
   ![How to Enable Focus Monitor for... - screenshot 2](/images/intercom/16012060/c0293f24-670a-43ec-b324-5bff4c4f673c-733dd133.png)
   The Endpoint details page is displayed.
4. Go to **Windows Alert** tab.
   ![How to Enable Focus Monitor for... - screenshot 3](/images/intercom/16012060/01ffaaaa-f640-4f9d-a22a-e79469502995-c148a8b8.png)
5. Do the following:
   1. Enable the **Focus Monitor** toggle button.
   2. Enter the **Look-away angle**.
      The **Look-away Angle** defines the maximum angle (in Degrees) a user can turn away from the screen before focus is considered lost.
   3. Enter the duration for **Focus Lost**.
      This defines how long the user must remain outside the allowed angle before an alert is triggered.
   4. Select **Action** from drop down.
   5. Click **Save.**

![How to Enable Focus Monitor for... - screenshot 4](/images/intercom/16012060/image-0cb10319.png)

Windows Alerts for presence detection is configured.
