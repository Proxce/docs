## Notes

· Replace &lt;tenantname> and &lt;tenantid> with the organization's Tenant Name and Tenant ID.

· Use lowercase values for &lt;tenantname> and &lt;tenantid>.

· Some deployments may require only PROD URLs or only UAT/Preview URLs, depending on the environment being used.

· [https://download.oloid.cloud/](https://download.oloid.cloud/) always routes to PROD and should not be replaced with a Preview/UAT domain.

· [https://oloidcache.oloidpreview.com/](https://oloidcache.oloidpreview.com/) is for Windows Login Version 2.0 in UAT/Preview.

· For domain-based firewall rules, whitelist the hostnames. For URL-based firewall rules, include the full HTTPS URLs where shown.
