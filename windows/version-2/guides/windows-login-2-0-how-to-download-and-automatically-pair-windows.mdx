## Introduction

Automatic pairing simplifies the deployment of Windows Login by pairing the endpoint with a Windows Login application during installation. Instead of manually pairing each device after installation, administrators can use an Auto-pair configuration string generated from the Tenant Admin Portal to automatically register the endpoint when the system restarts.

## Prerequisites

- You have local administrator access on the Windows machine.
- Check System Requirements. For more information, refer: [Windows Login Version 2 - Hardware and Software Requirements](https://oloid.help/en/articles/13670511-windows-login-version-2-hardware-and-software-requirements).
- Download the Windows Login v2.0 Installer file. For more details, see: [Windows Login v 2.0 - How to download Windows Login v 2.0 installer file from Tenant Admin Portal](https://oloid.help/en/articles/15069295-windows-login-v-2-0-how-to-download-windows-login-v-2-0-installer-file-from-tenant-admin-portal)

## Steps to Automatically pair Windows Login App

There are two steps to required to Automatically pair Windows Login App:

- [Generate Config Text](#generate-config-text)
- [Install Windows Login v2.0](#install-windows-login-v2-0)

### Generate Config Text

1. Generate Autopair Config file. For more information, refer: [Windows Login - How to generate Auto-Pair config file for Windows Login in Tenant Admin Portal](https://oloid.help/en/articles/10441578-windows-login-how-to-generate-auto-pair-config-file-for-windows-login-in-tenant-admin-portal)
   The Auto-pair config file pop-up box is displayed.
2. Do the following:
   1. Select **Application** as **Passwordless - Windows Login** from **Application Type** dropdown list.
   2. From the **Select Application** drop-down list, select the application that you want the endpoints to pair with.

      <Note>
        **Note:** Select **Skip user confirmation for pairing** option to auto-pair endpoints without requiring user confirmation.
      </Note>

   3. Select **TEXT** as the Download file format.
   4. Click **Copy Config Text.**
      ![How to Download and Automatically Pair... - screenshot 1](/images/intercom/15653468/image-66cea73a.png)

### Install Windows Login v2.0

Automatic Pairing can be done only at the time of installation of Windows Login v2.0 application for more details refer: [Windows Login v2.0 - How to Install, and Auto-Pair Windows Login v2.0 App](https://oloid.help/en/articles/13670102-windows-login-v2-0-how-to-install-and-auto-pair-windows-login-v2-0-app)

1. When the Autopair Settings screen is displayed. Do the following: Select **Automatic** > Enter **Encoded String** in Text Box> click **Next.**

   <Note>
     **Note:** Enter the **Copied Config text** in the **Enconded String** field.
   </Note>

   ![How to Download and Automatically Pair... - screenshot 2](/images/intercom/15653468/image-b9958932.png)
   The **Ready to Install** screen is displayed.
2. Click **Install**.
   ![How to Download and Automatically Pair... - screenshot 3](/images/intercom/15653468/image-c76bbd0e.png)
   The **Completing the Oloid Passwordless Login Setup Wizard** screen is displayed.
3. Click **Finish**.
   ![How to Download and Automatically Pair... - screenshot 4](/images/intercom/15653468/image-9d19efd5.png)
   The **Oloid Passwordless Login** pop-up box is displayed.
4. Click **Yes** to restart the system.

   <Note>
     **Note:** You must restart your system after successful installation.
   </Note>

   ![How to Download and Automatically Pair... - screenshot 5](/images/intercom/15653468/image-7be7e058.png)
   After successful installation, you can find the Oloid app icon ![How to Download and Automatically Pair... - screenshot 6](/images/intercom/15653468/image-40ad07a0.png) on your desktop.

   <Note>
     **Note:** The **Apache CouchDB** is installed on the system by default.
   </Note>
