## Introduction

This document explains how to add a supervisor note to a Windows Alert in the Tenant Admin Portal.

## Prerequisite

- You must have access to the Tenant Admin Portal.
- Ensure that Windows Alerts are enabled and configured.

## Steps to Add Supervisor Note in Windows Alert

1. Log in to the **Tenant Admin Portal**.
2. Click **Transactions** on the left menu panel > click **Windows Alert**.
   ![How to Add Supervisor Note in Windows... - screenshot 1](/images/intercom/15516986/image-6c349de0.png)
   The Windows Alert list page is displayed.
3. Click **All Alerts**.
4. Do one of the following:
   1. Click the **Alert Name**
      The **Windows Alerts** Credential page is displayed.
   2. Click **+ Add Note.**
      ![How to Add Supervisor Note in Windows... - screenshot 2](/images/intercom/15516986/image-09646f33.png)
   3. Enter the **Note** in the Note field > Click **Save**.
      ![How to Add Supervisor Note in Windows... - screenshot 3](/images/intercom/15516986/image-48d5fa8c.png)
      The Note is added.
      ![How to Add Supervisor Note in Windows... - screenshot 4](/images/intercom/15516986/image-52dc5302.png)
      (OR)
   4. Select the **Notes** icon in the **Action** column for the required Windows alert.
      ![How to Add Supervisor Note in Windows... - screenshot 5](/images/intercom/15516986/image-f824e15c.png)
   5. The **Add Note** pop-up box is displayed.

Enter the **Note** in the Note field > Click **Save**.

![How to Add Supervisor Note in Windows... - screenshot 6](/images/intercom/15516986/image-88107a6b.png)

Note is added for the selected alert.

![How to Add Supervisor Note in Windows... - screenshot 7](/images/intercom/15516986/image-d2db0b44.png)
