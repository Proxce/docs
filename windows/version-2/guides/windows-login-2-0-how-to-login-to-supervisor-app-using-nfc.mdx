## Introduction

O**LOID** Windows Login lets users sign in to the Supervisor App on a shared Windows endpoint without typing a username or password. With NFC login, users sign in by tapping an NFC-enabled card or tag on the NFC reader connected to the endpoint. This makes sign-in quick and secure for frontline and shared-device workers.

### Prerequisites

- The Windows Login application must be created in the Tenant Admin Portal. For more information, refer to [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal).
- The endpoint must be paired with the Windows Login application. For more information, refer to [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app).
- An NFC credential must be assigned to the user. For more information, refer to [How to assign NFC as a credential to users](https://oloid.help/en/articles/8403103-how-to-assign-nfc-id-as-a-credential-to-the-user).
- NFC must be enabled as an authenticator in the Windows application. For more information, refer to [How to enable NFC in Windows application](https://oloid.help/en/articles/11891768-windows-login-how-to-enable-nfc-id-credential-for-windows-login-in-the-tenant-admin-portal).
- An NFC reader must be connected to the endpoint and working.

### Steps to Login using NFC ID

1. Double-click the Supervisor App to start it.

   ![How to Login to Supervisor App using NFC - screenshot 1](/images/intercom/17132771/image-680629b4.png)
   The Login screen is displayed.
2. Click **Continue with Oloid**.
   ![How to Login to Supervisor App using NFC - screenshot 2](/images/intercom/17132771/image-bdb9c10a.png)
   The Credential screen is displayed.
3. Click **Login with NFC Tag**.
   The Scan NFC screen is displayed.
4. Tap the NFC card or tag on the NFC reader to scan it.

![How to Login to Supervisor App using NFC - screenshot 3](/images/intercom/17132771/image-b9e406c9.png)

When authentication succeeds, the user is logged in to the Supervisor App.
