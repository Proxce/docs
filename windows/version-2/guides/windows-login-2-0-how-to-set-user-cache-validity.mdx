## Introduction

User Cache Validity controls how long user data is stored locally on an endpoint after authentication. This document explains how to configure the User Cache Validity duration for an endpoint in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Windows Login Application is created. [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the Endpoint is paired with the application. Refer: [Windows Login - How to pair Supervisor App using auto-pair config file option](https://oloid.help/en/articles/9637781-windows-login-how-to-pair-supervisor-app-using-auto-pair-config-file-option)

## Steps to Set User Cache Validity

1. Log in to the **Tenant Admin Portal**.
2. On the Left menu Panel of the Home page select **Endpoints**.
   ![How to Set User Cache Validity - screenshot 1](/images/intercom/15431849/image-bc695cc7.png)
   The **Endpoints** page is displayed.
3. Select the **Endpoint name** to edit.
   ![How to Set User Cache Validity - screenshot 2](/images/intercom/15431849/image-013d07ed.png)
   The **Endpoints** Details page is displayed.
4. Go to **Endpoint Tab** > **Endpoint Settings**.
   ![How to Set User Cache Validity - screenshot 3](https://downloads.intercomcdn.com/i/o/e4gi378c/2522927868/086ebe31dd065e5dcf7cc303c074/image.png?expires=1790294400&signature=9064b96d65df98e10c329fc66f3a72011fa4ffa4509f14834e18767a3999e002&req=diUlFMB8molZUfMW3nq%2BgSe5Jo3EHk%2B%2FYRUp6KABr6pstHpoNqB%2Fih6oBQbB%0ASyKJqsv%2BHxbqE%2BePh07nX1oGHFQ%3D%0A)
   The **Endpoint Settings** page is displayed.
5. Enable the **User Cache Validity** toggle.
6. Under User Cache Validity set the **Duration** as required.

   <Note>
     **Note:** User Cache validity is the duration for which the user data will be saved on the machine as cache.
   </Note>

7. Click **Save**.
   ![How to Set User Cache Validity - screenshot 4](/images/intercom/15431849/image-a14cbb49.png)
   The User Cache Validity duration is set.
