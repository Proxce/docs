## Introduction

The **Dev Dashboard** in the Windows System Tray application provides access to session tracking for the Windows Login environment. It allows users to view system-level details and validate logs directly from the device.

## Prerequisites

- You must have the Windows Login version 2.0 installed on your windows machine. Refer: [How to Download, Install, and Auto-Pair Windows Authenticator App (Version 2.0)](https://oloid.help/en/articles/13670102-how-to-download-install-and-auto-pair-windows-authenticator-app-version-2-0)
- Ensure System Tray application is running in the background.

## Steps to Access Dev Dashboard

1. Log in to **Windows device** your Windows Machine. refer: [How to log in to Windows device using Badge and PIN through Windows Login app](https://oloid.help/en/articles/8893845-how-to-log-in-to-windows-device-using-badge-and-pin-through-windows-login-app)
   The Windows home screen is displayed.
   ![How to access Dev Dashboard - screenshot 1](/images/intercom/14796550/image-311fbc36.png)
2. On the bottom Menu Bar click **Show Hidden Icons** arrow.
3. Click **Oloid System Tray** icon.
   ![How to access Dev Dashboard - screenshot 2](/images/intercom/14796550/image-b47ddca6.png)
   The **Oloid System Tray Application** is displayed.
   ![How to access Dev Dashboard - screenshot 3](/images/intercom/14796550/image-d59b052f.png)
4. Select **Launch Dev Dashboard** from the **Actions** dropdown.
   ![How to access Dev Dashboard - screenshot 4](/images/intercom/14796550/image-66f0d12a.png)
5. Click **Apply Action**
   ![How to access Dev Dashboard - screenshot 5](/images/intercom/14796550/image-b4132faf.png)
   The Dev Dashboard is displayed.
   The **Dev Dashboard** in the Windows System Tray application provides system administrators with visibility into the **current active session** on the device.
   ![How to access Dev Dashboard - screenshot 6](/images/intercom/14796550/image-34338e45.png)
