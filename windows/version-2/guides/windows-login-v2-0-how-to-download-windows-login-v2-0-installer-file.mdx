## Introduction

This document explains how to download the **Windows Login v2.0** installer from the Tenant Admin Portal. After downloading the installer, you can proceed with the installation and setup of the Windows Login application on your system.

## Prerequisites

- You must have access to a Tenant Admin account.
- You have local administrator access on the Windows machine.
- Check System Requirements. For more information, refer: [Windows Login Version 2 - Hardware and Software Requirements](https://oloid.help/en/articles/13670511-windows-login-version-2-hardware-and-software-requirements)

## Steps to download Windows Login v 2.0

1. Log in to **Tenant Admin Portal**.
2. On the homepage of the portal, click **User profile icon** on the bottom left corner of the menu panel.
   ![How to download Windows Login v2.0... - screenshot 1](/images/intercom/15069295/28d58c31-d184-44b0-a450-2cbd72f80ad6-f1aeedd1.png)
3. The user profile menu is displayed.
4. Select **Tenant Settings**.
   ![How to download Windows Login v2.0... - screenshot 2](/images/intercom/15069295/240f19ab-474e-4c7e-b213-103d5ce45fc3-2a52c6fc.png)
   The **Tenant Settings** screen is displayed.
   ![How to download Windows Login v2.0... - screenshot 3](/images/intercom/15069295/image-1c391802.png)
5. Go to **Oloid Apps** tab > **Windows Authenticator App V2** Login.
   ![How to download Windows Login v2.0... - screenshot 4](/images/intercom/15069295/image-efb56799.png)
6. Select the preferred version from the **Win-Login-Installer** dropdown list, then click the **Download** button ![How to download Windows Login v2.0... - screenshot 5](https://downloads.intercomcdn.com/i/o/e4gi378c/2377021058/162e1794155840e1f06a93a1773a/image.png?expires=1790294400&signature=6ff875f8dce5a1443d5ac4c14bb75499e86680cd698c67a7eddd5cdaa3432bc8&req=diMgEcl8nIFaUfMW3nq%2BgYa0dcuUTyFvF40o5GW4uj%2FZzdYkbBcrpNCM1Uoo%0A4TayQrC0v5f1jBDsHvbQtVyBSII%3D%0A) icon.
   ![How to download Windows Login v2.0... - screenshot 6](/images/intercom/15069295/image-322ef66c.png)
   The installer file is downloaded to your local device.
   After the download is complete, you can proceed with installing Windows Login App.
