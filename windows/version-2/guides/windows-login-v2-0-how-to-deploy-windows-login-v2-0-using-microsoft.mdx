## Introduction

This document provides step-by-step instructions to deploy Windows Passwordless v2.0 on managed Windows devices using Microsoft Intune (MDM).

## Prerequisites

- You must have admin access to the Microsoft Intune Admin Center.
- You must have the installation PowerShell script (.ps1).
- You must have the detection rule PowerShell script (rule.ps1).

  <Note>
    **Note:** Contact [Oloid Support](mailto:support@oloid.ai) to obtain the PowerShell script (.ps1) and detection rule script (rule.ps1).
  </Note>

- You must have downloaded the Microsoft Win32 Content Prep Tool (IntuneWinAppUtil).

  <Note>
    **Note:** To download the **Microsoft Win32 Content Prep Tool**, click [here](https://github.com/microsoft/Microsoft-Win32-Content-Prep-Tool/archive/refs/tags/v1.8.7.zip).
  </Note>

- You must download the **AutoPairConfig.txt** file from the Tenant Admin Portal. For more information, refer to [Windows Login - How to generate Auto-Pair config file for Windows Login in Tenant Admin Portal](https://oloid.help/en/articles/10441578-how-to-generate-auto-pair-config-file-for-windows-login-in-tenant-admin-portal).
- You must download the **Windows Login v2.0 installer file**. For more information, refer to [Windows Login v2.0 - How to download Windows Login v2.0 installer file from Tenant Admin Portal](https://oloid.help/en/articles/15069295-windows-login-v2-0-how-to-download-windows-login-v2-0-installer-file-from-tenant-admin-portal)

## Steps to Deploy Windows Passwordless 2.0 using Microsoft Intune (MDM)

1. [Create App Package](#steps-to-create-app-package)
2. [Create and Configure App](#create-and-configure-app)
   The Windows Passwordless v2.0 is deployed successfully to the target devices.

### Steps to Create App Package

1. Place the **Windows Login v2.0 installer file, AutoPairConfig.txt file**, and **installation PowerShell (.ps1) script** in the same folder.

   <Note>
     **Note:** If the AutoPair configuration file is added, the app is installed and paired automatically. If not, manual pairing is required after installation.
   </Note>

   ![How to Deploy Windows Login v2.0 using... - screenshot 1](/images/intercom/15357528/image-6bba1895.png)
2. Download and open the Microsoft Win32 Content Prep Tool.
3. Enter the following details when prompted by the tool:
   1. **Source folder:** Enter the folder path that contains the `install.ps1` file, autopair config file and the installer file.
   2. **Setup file:** Enter the installer file name with the file extension.
   3. **Output folder:** Enter the folder path where the `.intunewin` file must be created.

      <Note>
        **Note:** Before you generate the `.intunewin` file, update the following values in the `install.ps1` script:
      </Note>

      - Set `$InstallerName` to the name of the `.exe` installer file used to install the app.
      - In `$SilentArgs`, set the required feature flags to `true` or `false` based on the features you want to install.
        ![How to Deploy Windows Login v2.0 using... - screenshot 2](/images/intercom/15357528/image-e3adb2f6.png)
        ![How to Deploy Windows Login v2.0 using... - screenshot 3](/images/intercom/15357528/image-08157d91.png)
        The app package is created successfully.
        Navigate to the output folder and verify that the **.intunewin** app package file has been created successfully.
        ![How to Deploy Windows Login v2.0 using... - screenshot 4](/images/intercom/15357528/image-d11d1f0b.png)

### Create and Configure App

1. Log in to **Microsoft Intune Admin Account**.
   The Microsoft Intune home screen is displayed.
2. Navigate to **Apps > Windows.**
   ![How to Deploy Windows Login v2.0 using... - screenshot 5](/images/intercom/15357528/image-86312310.png)
   The **Windows apps** screen is displayed.
3. Click **+ Create**.
   ![How to Deploy Windows Login v2.0 using... - screenshot 6](/images/intercom/15357528/image-37b228d7.png)
   The **Select app type** screen is displayed.
4. In the app type dropdown, select **Windows app (Win32)** and click **Select**.
   ![How to Deploy Windows Login v2.0 using... - screenshot 7](/images/intercom/15357528/image-e7fba6f8.png)
   The **Add App** screen is displayed.
5. On **App Information** tab, do the following:
   1. Click **Select app package file**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 8](/images/intercom/15357528/image-76ebb94e.png)
      The **App package file** screen is displayed.
   2. Browse and select the **.intunewin app package file**.

      <Note>
        **Note:** Select the same **.intunewin** package file that was created in the Steps to Create Package File section.
      </Note>

   3. Click **OK**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 9](/images/intercom/15357528/3dbd4722-34a1-4c3f-b02b-32ab3748191c-84063e1a.png)
      The **App information** tab is displayed.
   4. Enter **Publisher**.
   5. Click **Next**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 10](/images/intercom/15357528/image-00a89d4d.png)
      The **Program** tab is displayed.
6. On the Program tab, do the following:
   1. Ensure command line is selected as installer type.

Enter **Install command**.

<Note>
  **Note:** Use the following command.
</Note>

```
%SystemRoot%\sysnative\WindowsPowerShell\v1.0\powershell.exe -ExecutionPolicy Bypass -File .\install.ps1
```

3. Ensure command line is selected as uninstaller type.

Enter **Uninstaller command**.

<Note>
  **Note:** Use the following command.
</Note>

```
%SystemRoot%\sysnative\WindowsPowerShell\v1.0\powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "Uninstall-Package -Name 'Oloid Passwordless Login' -Force"
```

5. Select **No** as Allow available uninstall (Optional).

   <Note>
     **Note:** Select **No** to prevent the application from being uninstalled through the **Company Portal** or **Windows Control Panel**.
   </Note>

6. Ensure **System** is selected as Install behaviour.
7. Click **Next**.
   ![How to Deploy Windows Login v2.0 using... - screenshot 11](/images/intercom/15357528/image-d59303d4.png)
   The **Requirements** tab is displayed.
7. On the requirements tab, do the following.
   1. Select **No** as Check operating system architecture.
   2. Select **Windows 10 1607** as Minimum operating system.
   3. Click **Next**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 12](/images/intercom/15357528/image-1cb75c03.png)
      The **Detection Rules** tab is displayed.
8. On the Detection Rules tab, do the following.
   1. Select **Use a custom detection script** as Rules format.
   2. **Upload** Script file.

      <Note>
        **Note:** To get the Script file, contact [Oloid Support](mailto:support@oloid.ai).
      </Note>

   3. Ensure **No** isselected as Run script as 32-bit process on 64-bit clients.
   4. Ensure **No** isselected as Enforce script signature check and run script silently.
   5. Click **Next**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 13](/images/intercom/15357528/image-316d5f0b.png)
      The **Dependencies** tab is displayed.
   6. Click **Next**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 14](/images/intercom/15357528/image-c4dc9b9a.png)
      The **Supersedence** tab is displayed.
   7. Click **Next**.
      ![How to Deploy Windows Login v2.0 using... - screenshot 15](/images/intercom/15357528/image-812e8242.png)
      The **Assignments** tab is displayed.
9. On the Assignments tab, do the following.
   1. On **Required** section, click **Add group** to assign this profile to your target device groups.
      ![How to Deploy Windows Login v2.0 using... - screenshot 16](/images/intercom/15357528/image-ebda34dd.png)
      The **Select groups** pop-up is displayed.
   2. Do the following.
      1. Select the **group(s**) from the list.

         <Note>
           **Note:** You can select multiple groups (If required).
         </Note>

      2. Click **Select**.
         ![How to Deploy Windows Login v2.0 using... - screenshot 17](/images/intercom/15357528/image-6a76655a.png)
         The Group is added in the list.
10. Click **Next**.
    ![How to Deploy Windows Login v2.0 using... - screenshot 18](/images/intercom/15357528/image-8bf08c5e.png)
    The Assignment tab is configured successfully and **Review + create** tab is displayed.

    <Note>
      **Note:** To assign groups under the **Available for enrolled devices** and **Uninstall sections**, repeat Steps **9a** and **9b** as required.
    </Note>

11. Review all settings and click **Create.**
    ![How to Deploy Windows Login v2.0 using... - screenshot 19](/images/intercom/15357528/image-79b5de1f.png)
    The app the created successfully and added in the apps screen.
    ![How to Deploy Windows Login v2.0 using... - screenshot 20](/images/intercom/15357528/image-675713ec.png)
