## Introduction

This document provides the minimum hardware and software requirements needed to run the Windows Login application. Ensure that your system meets these requirements before installing the Windows Login in your system to avoid compatibility or performance issues.

## Minimum Software Requirement

**Components**

**Minimum Requirements**

Operating System

Windows 10 and above

## Minimum Hardware Requirement

**Components**

**Minimum Requirements**

RAM

8 GB or more

Card Reader

Required Card reader for Badge/NFC authentication.

Hard Disk

256 GB or more

Badge

Required Badge for authentication.

NFC ID

Required NFC ID for authentication.

External WebCam (Optional, if inbuilt camera is present)

- **Minimum resolution**: 720 MP (1280 x 720 pixels) or higher.
- **Recommended resolution**: 1080 MP (1920 x 1080 pixels).

<Note>
  **Note:** For supported card types, refer [Oloid Supported Card Types](https://oloid.help/en/articles/9900195-oloid-supported-card-types)
</Note>

## Incompatibility Warnings

Windows Login **may not function properly** on web browser with the following limitations:

- Devices without a functional camera or NFC module.
- Device RAM is below 8 GB.
