The Windows Authenticator App provides secure, passwordless access to your Windows machine, making it easy to log in without the need for traditional passwords. This guide provides step-by-step instructions on downloading, installing, and configuring the app using the Oloid Portal.

## Steps to download Windows Authenticator App

1. Log in to **Oloid Portal**.
2. On the home page of the Oloid Portal, do one of the following to download the Windows Authenticator App:
   - Using File Sharing tab
     Navigate to **User Profile Menu** > **Tenant Setting** > **Oloid Apps** tab > download **Windows Authenticator App**.For more details, see [Download from File Sharing](https://oloid.help/en/articles/9036607-how-to-download-supervisor-app#h_fa8597c5f2:~:text=the%20installer%20file.-,Steps%20to%20download%20from%20File%20Sharing%3A,-Log%20in%20to)
   - Using Tenant Settings tab
     Navigate to **User Profile Menu** > **File Sharing**. For more details, see [Download from Tenant Setting](https://oloid.help/en/articles/9036607-how-to-download-supervisor-app#h_7bf81eaafc:~:text=the%20local%20device.-,Steps%20to%20download%20from%20Tenant%20Settings%3A,-Log%20in%20to)

After the download is complete, you can proceed with installing Windows Authenticator App.

## Steps to install Windows Authenticator App

1. Download **Windows Authenticator App** file on your system.

   <Note>
     **Note:** Select the version as advised by your Oloid Rep.
   </Note>

   ![How to download, install, and configure... - screenshot 1](/images/intercom/10568115/image-745f5d25.png)
   The **OloidPasswordlessSupervisor.Setup.zip** file is downloaded in your system.
2. Right-click and select **Extract All** > **OloidPasswordlessSupervisor.Setup.zip** file.
   The extracted files will be saved in the same folder as the original zipped file.
3. Double-click on **setup.exe** file.
   The **Oloid Passwordless Supervisor Setup** window is displayed.
   ![How to download, install, and configure... - screenshot 2](/images/intercom/10568115/image-084978cd.png)
4. Review the listed components and click **Install** to proceed.

   <Note>
     **Note:** If any of the files are missing, the application prompts to install the missing component.
   </Note>

5. On the **Oloid Passwordless Supervisor** Setup wizard, click **Next**.
   ![How to download, install, and configure... - screenshot 3](/images/intercom/10568115/image-d0d5f077.png)
6. Use the default path to install the application and click **Next**.
   ![How to download, install, and configure... - screenshot 4](/images/intercom/10568115/image-b2235393.png)
7. Click **Next** to confirm the installation.
   ![How to download, install, and configure... - screenshot 5](/images/intercom/10568115/image-f7b9700c.png)
8. Click **Close** after the installation is complete.
   ![How to download, install, and configure... - screenshot 6](/images/intercom/10568115/image-438e28b7.png)
   After successful installation, you can find the app icon ![How to download, install, and configure... - screenshot 7](/images/intercom/10568115/image-40ad07a0.png) on your desktop. For first-time installation, it is recommended to restart your system.

## Steps to auto-pair the Windows Authenticator App

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to download, install, and configure... - screenshot 8](/images/intercom/10568115/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to download, install, and configure... - screenshot 9](/images/intercom/10568115/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to download, install, and configure... - screenshot 10](/images/intercom/10568115/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The Windows Login app is displayed.
2. Select **Yes, pair my device** to auto-pair the device.
   ![How to download, install, and configure... - screenshot 11](/images/intercom/10568115/36ba5c1c-da02-44b6-a6da-a1ce9cc3ef00-cf621823.png)
   The Windows machine has been successfully paired and is now ready for use.
