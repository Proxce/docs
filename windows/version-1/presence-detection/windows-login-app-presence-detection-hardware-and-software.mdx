## Introduction

This document provides the minimum hardware and software requirements needed to run the Windows Login application (Presence Detection). Ensure that your system meets these requirements before installing the Windows Login application in your system to avoid compatibility or performance issues.

## Minimum Software Requirement

**Components**

**Minimum Requirements**

Operating System

Windows 10 and above

Software

- .Net Runtime 8.0
- .Net Desktop Runtime 8.0
- Visual C++ 14 Runtime Libraries

## Minimum Hardware Requirement

**Components**

**Minimum Requirements**

RAM

8 GB or more

Card Reader

Required Card reader for Badge/NFC authentication.

Badge

Required Badge for authentication.

NFC ID

Required NFC ID for authentication.

External WebCam (Optional, if inbuilt camera is present)

- **Minimum resolution**: 720 MP (1280 x 720 pixels) or higher.
- **Recommended resolution**: 1080 MP (1920 x 1080 pixels).

## Incompatibility Warnings

Windows Login (Presence Detection) **may not function properly** on web browser with the following limitations:

- Operating system is below window 10.
- Devices without a functional camera or NFC module.
- Device RAM is below 8 GB.
