The Tenant Admin / Supervisor can unblock the user's blocked screen in one of the following ways:

- [Using transaction tab](#using-transaction-tab)
- [Using Windows endpoint](#using-windows-endpoint)

## Using Transaction Tab

1. Log in to Oloid Portal.
2. On the home page of the portal, select **Transactions** on the left menu panel.
   ![How to unblock a user's blocked screen - screenshot 1](/images/intercom/9790398/image-034c75b3.png)
   The User Transaction Through Your Device page is displayed.
   ![How to unblock a user's blocked screen - screenshot 2](/images/intercom/9790398/image-15915b5f.png)
3. Select **Windows Alert**.
   ![How to unblock a user's blocked screen - screenshot 3](/images/intercom/9790398/image-3aa45d2d.png)
   The Windows Alert page is displayed.
4. Do one of the following:
   1. Go to the **Alert ID** and click **Unblock**.
      ![How to unblock a user's blocked screen - screenshot 4](/images/intercom/9790398/image-35647e60.png)
      Or
   2. Go to the user endpoint detail page and select **Unblock**.

      <Note>
        **Note:** You can also navigate to the user detail page from the Transactions (**User Transaction Through your Device)** page.
      </Note>

      ![How to unblock a user's blocked screen - screenshot 5](/images/intercom/9790398/image-b6b471dd.png)
      The user's screen is unblocked successfully.
      ![How to unblock a user's blocked screen - screenshot 6](/images/intercom/9790398/image-6d4db1e8.png)
      ![How to unblock a user's blocked screen - screenshot 7](/images/intercom/9790398/image-4ae9d209.png)

## Using Windows endpoint

1. Log in to Oloid Portal.
2. Navigate to **Endpoints** > select preferred **Endpoint Name**.
   ![How to unblock a user's blocked screen - screenshot 8](/images/intercom/9790398/image-f7811143.png)
   The endpoint details page is displayed.
   ![How to unblock a user's blocked screen - screenshot 9](/images/intercom/9790398/image-1bf5fdd4.png)
3. Select **Unblock** to unblock the user's screen.
   ![How to unblock a user's blocked screen - screenshot 10](/images/intercom/9790398/image-75de3909.png)
   The endpoint is unblocked successfully and the user can continue using the system.
   ![How to unblock a user's blocked screen - screenshot 11](/images/intercom/9790398/image-2f3b3c83.png)
