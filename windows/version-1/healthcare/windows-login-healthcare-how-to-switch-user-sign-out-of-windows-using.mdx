## Introduction

The **Switch User** workflow in Epic Hyperspace enables secure session transfer on shared Windows devices. When the **Sign out** option is enabled, all active applications are closed and the system is locked, allowing the next user to authenticate and access the system.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user.
- Ensure that Epic SSO is enabled. Refer: **[Windows Authenticator (Healthcare) - How to Enable Epic SSO in the Tenant Admin Portal](https://oloid.help/en/articles/13713982-windows-authenticator-healthcare-how-to-enable-epic-sso-in-the-tenant-admin-portal)**
- Ensure that the Supervisor app is closed.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the User. Refer: **[Windows Login - How to Configure PIN Credential in the Tenant Admin Portal](https://oloid.help/en/articles/11484425-windows-login-how-to-configure-pin-credential-in-the-tenant-admin-portal)**
- The badge reader must be connected to the Windows system.
- Badge Out options must be configured. Refer:

## Steps to Switch User using Badge ID

1. On the Lock screen, select **Login with OLOID**.
   ![How to Switch User + Sign Out of... - screenshot 1](/images/intercom/14836306/image-d88b9bb2.png)
   The **Scan Badge** screen is displayed.

   <Note>
     **Note:**

     2. Tap the **Badge** on the **Badge Reader** to scan it.
        ![How to Switch User + Sign Out of... - screenshot 2](/images/intercom/14836306/image-3a908d43.png)
        The **Enter PIN** screen is displayed.
     3. Enter the **PIN**.
        ![How to Switch User + Sign Out of... - screenshot 3](/images/intercom/14836306/image-a6aa3d47.png)
        The Windows homepage is displayed.
        ![How to Switch User + Sign Out of... - screenshot 4](/images/intercom/14836306/image-14c0007f.png)
     4. Log in to **Epic Hyperspace** refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](https://oloid.help/en/articles/14780782-how-to-log-in-to-epic-hyperspace-using-badge-id-pin)**
        User is successfully logged in to **Epic Hyperspace.**
        ![How to Switch User + Sign Out of... - screenshot 5](/images/intercom/14836306/image-53d3d59f.png)
     5. The Second User must tap the **Badge** on the **Badge Reader** to initiate User Switch.
   </Note>

   <Note>
     **Note:** The User will switch from User 1 to User 2.
   </Note>

   ![How to Switch User + Sign Out of... - screenshot 6](/images/intercom/14836306/image-85b93a8c.png)
   All open applications in the system will close, and the **Lock** screen appears

   <Note>
     **Note:** If the Windows Login application is configured with the **Sign out of Windows** option, all open applications in the system will close, and the **Lock** screen will appear.
   </Note>

   ![How to Switch User + Sign Out of... - screenshot 7](/images/intercom/14836306/image-51482016.png)
   The **Validating Badge** screen is displayed.
   ![How to Switch User + Sign Out of... - screenshot 8](/images/intercom/14836306/image-a123e84e.png)
   The **Enter PIN** screen is displayed.
6. Enter the **PIN**.

   <Note>
     **Note:** If Multi Factor Authentication (MFA) is enabled the second user must authenticate using the configured second factor, In this case PIN.
   </Note>

   ![How to Switch User + Sign Out of... - screenshot 9](/images/intercom/14836306/image-f6c800d3.png)
   The Windows homepage is displayed.
   ![How to Switch User + Sign Out of... - screenshot 10](/images/intercom/14836306/image-6fd13045.png)
7. The Second User must Launch Epic Hyperspace to Login. Refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](https://oloid.help/en/articles/14780782-how-to-log-in-to-epic-hyperspace-using-badge-id-pin)**

The User is successfully switched and the second User is logged in to Epic Hyperspace.
