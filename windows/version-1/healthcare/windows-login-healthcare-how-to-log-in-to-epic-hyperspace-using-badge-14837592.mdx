## Introduction

Logging into **Epic Hyperspace using Badge and PIN** provides a secure and efficient authentication method for accessing Epic applications on Windows devices. When SSO is enabled, users are not prompted for reauthentication upon launching Epic Hyperspace after unlocking the system using badge and PIN.

## Prerequisites

- The Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)**
- The badge reader must be connected to the Windows system.
- Ensure the Tray application is running in the background.
- Ensure the Supervisor app is closed.
- Ensure Epic SSO is enabled. Refer: [How to Enable Epic SSO in the Tenant Admin Portal](https://oloid.help/en/articles/13713982-windows-login-healthcare-how-to-enable-epic-sso-in-the-tenant-admin-portal)
- **Epic Vault Password** must be created for the User. Refer: **[How to create Vault Password for a user](https://oloid.help/en/articles/9936961-chrome-vault-how-to-create-vault-password-for-a-user)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](https://oloid.help/en/articles/8407872-tenant-admin-portal-how-to-configure-pin)**

## Steps to log in using Badge

1. On the Lock screen, select **Login with OLOID**.
   ![Windows Login (Healthcare)- How to log... - screenshot 1](/images/intercom/14837592/image-dc9b6bb9.png)
   The **Scan Badge** screen is displayed.

   <Note>
     **Note:**

     2. Tap the **Badge** on the **Badge Reader** to scan it.
        ![Windows Login (Healthcare)- How to log... - screenshot 2](/images/intercom/14837592/image-3a908d43.png)
        The **Enter PIN** screen is displayed.
     3. Enter the **PIN**.
        ![Windows Login (Healthcare)- How to log... - screenshot 3](/images/intercom/14837592/image-a6aa3d47.png)
        The Windows homepage is displayed.
        ![Windows Login (Healthcare)- How to log... - screenshot 4](/images/intercom/14837592/image-14c0007f.png)
     4. Launch the **Epic Hyperspace** application on your Windows machine.
        ![Windows Login (Healthcare)- How to log... - screenshot 5](/images/intercom/14837592/image-416f9531.png)
        The **Authentication in progress** screen is displayed.
        ![Windows Login (Healthcare)- How to log... - screenshot 6](/images/intercom/14837592/image-c1e413e5.png)
     5. The **Login confirmation** screen is displayed. Click **Continue.**
   </Note>

![Windows Login (Healthcare)- How to log... - screenshot 7](/images/intercom/14837592/image-935f3469.png)

User is successfully logged in to **Epic Hyperspace.**
