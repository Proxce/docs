## Introduction

This method requires the logged-in user to verify their identity again using a factors selected under the reauthentication workflow configuration.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user. Refer: **[How to create Vault Password for a user](https://oloid.help/en/articles/9936961-chrome-vault-how-to-create-vault-password-for-a-user)**
- The badge reader must be connected to the Windows system.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](https://oloid.help/en/articles/8407872-tenant-admin-portal-how-to-configure-pin)**

## Steps to Reauthenticate current user in Epic Hyperspace

1. Log in to **Epic Hyperspace** application on your Windows Machine. refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](https://oloid.help/en/articles/14780782-how-to-log-in-to-epic-hyperspace-using-badge-id-pin)**
   The **Epic Hyperspace** home page is displayed.
   ![How to Use the Reauthenticate Current... - screenshot 1](/images/intercom/14753012/image-41d76c5f.png)
2. On the top menu panel of the homepage, click **Reauthentication Test View**.
   ![How to Use the Reauthenticate Current... - screenshot 2](/images/intercom/14753012/image-c08051b9.png)
   The Reauthentication Test view page is displayed.
3. Click **Reauthenticate Current User - Second Factor.**
   ![How to Use the Reauthenticate Current... - screenshot 3](/images/intercom/14753012/image-77f7921f.png)
   The **Enter PIN** screen is displayed.

   <Note>
     **Note:** Authentication is based on the factor selected in Reauthenticate Current User (Second Factor) under the reauthentication workflow. Contact [Support](mailto:Support@oloid.ai) if no authentication method appears.
   </Note>

4. The current user must enter the **PIN** > click **Submit.**

   <Note>
     **Note:** The current user (the user already logged into Epic Hyperspace) must authenticate.
   </Note>

   ![How to Use the Reauthenticate Current... - screenshot 4](/images/intercom/14753012/image-1be5208d.png)
   The **Oloid Re-authentication** screen is displayed.
5. The current user must tap the **Badge** on the **Badge Reader** to scan it.
   ![How to Use the Reauthenticate Current... - screenshot 5](/images/intercom/14753012/image-e25fc24a.png)
   The **Enter PIN** screen is displayed.
6. The current user must enter the **PIN** > click **Submit.**

   <Note>
     **Note:** Authentication mode is based on Application factors configured for you.
   </Note>

   ![How to Use the Reauthenticate Current... - screenshot 6](/images/intercom/14753012/image-f7fb2143.png)
7. Hyperspace pop-up box is displayed. Click **Ok**
   The current user is successfully reauthenticated.

![How to Use the Reauthenticate Current... - screenshot 7](/images/intercom/14753012/image-e86f2e61.png)
