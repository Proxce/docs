## Introduction

The **Two User Authentication** feature in **Epic Hyperspace** provides an additional layer of security by requiring authentication from two authorized users before completing sensitive actions.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user. Refer: **[How to create Vault Password for a user](https://oloid.help/en/articles/9936961-chrome-vault-how-to-create-vault-password-for-a-user)**
- The badge reader must be connected to the Windows system.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](https://oloid.help/en/articles/8407872-tenant-admin-portal-how-to-configure-pin)**

## Steps to use Two User Authentication in Epic Hyperspace

1. Log in to **Epic Hyperspace** application on your Windows Machine. refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](https://oloid.help/en/articles/14780782-how-to-log-in-to-epic-hyperspace-using-badge-id-pin)**
   The **Epic Hyperspace** home page is displayed.
   ![Windows Login (Healthcare)-Two User... - screenshot 1](/images/intercom/13903549/image-41d76c5f.png)
2. On the top menu panel of the homepage, click **Reauthentication Test View**.
   ![Windows Login (Healthcare)-Two User... - screenshot 2](/images/intercom/13903549/image-c08051b9.png)
   The Reauthentication Test view page is displayed.
3. Click **Two User Authentication**

   <Note>
     **Note:** Authentication is based on the factor configured in **Two User Authentication** under the reauthentication workflow. eg: Application factors, First factor only or Second factor only.
   </Note>

   ![Windows Login (Healthcare)-Two User... - screenshot 3](/images/intercom/13903549/image-0bc07d03.png)
   The **Scan Badge** screen is displayed.

   <Note>
     **Note:** Authentication mode is based on Application factors configured for you
   </Note>

4. The current user must tap the **Badge** on the **Badge Reader** to scan it.

   <Note>
     **Note:** The current user (the user already logged into Epic Hyperspace) must authenticate first, followed by the second user.
   </Note>

   ![Windows Login (Healthcare)-Two User... - screenshot 4](/images/intercom/13903549/image-59f46140.png)
   The **Oloid Re-authentication** screen is displayed.
5. The second user must tap the **Badge** on the **Badge Reader** to scan it.
   ![Windows Login (Healthcare)-Two User... - screenshot 5](/images/intercom/13903549/image-0153d878.png)
6. Hyperspace pop-up box is displayed. Click **Ok**
   The Two User authentication is successfully completed and the authentication details are displayed.

![Windows Login (Healthcare)-Two User... - screenshot 6](/images/intercom/13903549/image-f04c6918.png)
