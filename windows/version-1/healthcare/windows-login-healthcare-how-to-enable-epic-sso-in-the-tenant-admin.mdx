## Introduction

The **Enable EPIC SSO** feature allows Tenant Admin to configure Single Sign-On (SSO) for applications integrated with Epic EHR.

## Prerequisites

- You must have access to Tenant Admin account.
- The Windows Login application must be created in the Tenant Admin Portal, for more information refer: [How to create and configure Application Type - Passwordless](https://oloid.help/en/articles/8300330-how-to-create-and-configure-application-type-passwordless)

## Steps to Enable EPIC SSO

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the preferred **Windows Login application**.
   ![How to Enable Epic SSO in the Tenant... - screenshot 1](/images/intercom/13713982/image-94b1b089.png)
   The application details page is displayed.
   ![How to Enable Epic SSO in the Tenant... - screenshot 2](/images/intercom/13713982/image-307351e4.png)
3. Click **Configure** tab> **Epic EHR** .
   ![How to Enable Epic SSO in the Tenant... - screenshot 3](/images/intercom/13713982/image-86235462.png)
   The Epic EHR page is displayed.
4. Do the following:
   1. Turn on **Enable Epic SSO** toggle button.
   2. Click **Save.**
      ![How to Enable Epic SSO in the Tenant... - screenshot 4](/images/intercom/13713982/image-6f1d8cc1.png)
      Epic SSO is successfully enabled.

![How to Enable Epic SSO in the Tenant... - screenshot 5](/images/intercom/13713982/image-d74402ce.png)
