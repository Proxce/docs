## Introduction

The **Switch User** workflow in **Epic Hyperspace** allows a second user to securely take over an active session on a shared Windows device. The current active session is closed and a new session is activated for the second user.

## Prerequisites

- You must have access to Epic Hyperspace.
- Epic Vault Password must be created for the user. Refer: **[How to create Vault Password for a user](https://oloid.help/en/articles/9936961-chrome-vault-how-to-create-vault-password-for-a-user)**
- Ensure that the Supervisor app is closed.
- Ensure the Tray application is running in the background.
- Badge must be assigned to the user. Refer: **[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)**
- The PIN must be enabled and assigned to the user. Refer: **[Tenant Admin Portal - How to Configure PIN](https://oloid.help/en/articles/8407872-tenant-admin-portal-how-to-configure-pin)**
- The badge reader must be connected to the Windows system.
- Badge Out options must be configured. Refer: [Windows Login - How to Configure Badge Out option](https://oloid.help/en/articles/10616183-windows-login-how-to-configure-badge-out-option)

## Steps to Switch User using Badge ID

1. On the Lock screen, select **Login with OLOID**.
   ![How to Switch User within Epic... - screenshot 1](/images/intercom/14817588/image-dc9b6bb9.png)
   The **Scan Badge** screen is displayed.

   <Note>
     **Note:**

     2. Tap the **Badge** on the **Badge Reader** to scan it.
        ![How to Switch User within Epic... - screenshot 2](/images/intercom/14817588/image-3a908d43.png)
        The **Enter PIN** screen is displayed.
     3. Enter the **PIN**.
        ![How to Switch User within Epic... - screenshot 3](/images/intercom/14817588/image-a6aa3d47.png)
        The Windows homepage is displayed.
        ![How to Switch User within Epic... - screenshot 4](/images/intercom/14817588/image-14c0007f.png)
     4. Log in to **Epic Hyperspace** refer: **[How to log in to Epic Hyperspace using Badge ID + PIN](https://oloid.help/en/articles/14780782-how-to-log-in-to-epic-hyperspace-using-badge-id-pin)**
        User is successfully logged in to **Epic Hyperspace.**
        ![How to Switch User within Epic... - screenshot 5](/images/intercom/14817588/image-53d3d59f.png)
     5. The Second User must tap the **Badge** on the **Badge Reader** to initiate User Switch.
   </Note>

   <Note>
     **Note:** The User will switch from User 1 to User 2.
   </Note>

   ![How to Switch User within Epic... - screenshot 6](/images/intercom/14817588/image-85b93a8c.png)
   The **Enter PIN** screen is displayed.
6. Enter the **PIN**.

   <Note>
     **Note:** If Multi Factor Authentication (MFA) is enabled the second user must authenticate using the configured second factor, In this case PIN.
   </Note>

   ![How to Switch User within Epic... - screenshot 7](/images/intercom/14817588/image-523d56ab.png)
7. The **Login confirmation** screen is displayed. Click **Continue.**

![How to Switch User within Epic... - screenshot 8](/images/intercom/14817588/image-c9ab93cb.png)

The User is successfully switched and the second User is logged in to Epic Hyperspace.

![How to Switch User within Epic... - screenshot 9](/images/intercom/14817588/image-28ea3d27.png)
