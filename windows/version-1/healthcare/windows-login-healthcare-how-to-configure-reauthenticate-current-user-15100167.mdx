## Introduction

The **Reauthenticate Current User** workflow allows the logged-in user to verify their identity again during an active session in Epic workflows. Admins can configure this workflow in the Tenant Tenant Admin Portal.

## Prerequisites

- You must have access to Tenant Admin account.
- The Windows Login application must be created in the Tenant Admin Portal, for more information refer: [How to create and configure Application Type - Passwordless](https://oloid.help/en/articles/8300330-how-to-create-and-configure-application-type-passwordless)

## Steps to Configure Reauthenticate Current User

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the preferred **Windows Login application**.
   ![How to Configure Reauthenticate Current... - screenshot 1](/images/intercom/15100167/image-94b1b089.png)
   The application details page is displayed.
   ![How to Configure Reauthenticate Current... - screenshot 2](/images/intercom/15100167/image-307351e4.png)
3. Click **Configure** tab> **Epic EHR** .
   ![How to Configure Reauthenticate Current... - screenshot 3](/images/intercom/15100167/image-86235462.png)
   The Epic EHR page is displayed.
4. Do the following:
   1. Turn on **Enable Reauthentication Workflow** toggle button.
      ![How to Configure Reauthenticate Current... - screenshot 4](/images/intercom/15100167/image-74bf6f42.png)
   2. Turn on **Enable Reauthentication Workflow** toggle button.
   3. Select **Reauthenticate Current User**. From the Application Factor dropdown, choose the authentication factor.
   4. Click **Save**.
      ![How to Configure Reauthenticate Current... - screenshot 5](/images/intercom/15100167/image-112cac0e.png)
      Reauthenticate current user is configured.
