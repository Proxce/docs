## Introduction

The **Current User Editable** reauthentication workflow allows the currently logged-in user to reauthenticate while also enabling a different authorized user to authenticate if required.

## Prerequisites

- You must have access to Tenant Admin account.
- The Windows Login application must be created in the Tenant Admin Portal, for more information refer: [How to create and configure Application Type - Passwordless](https://oloid.help/en/articles/8300330-how-to-create-and-configure-application-type-passwordless)

## Steps to Enable Current User Editable

1. Log in to the Tenant Admin Portal.
2. On the **Applications** page, select the preferred **Windows Login application**.
   ![How to Enable Current User Editable for... - screenshot 1](/images/intercom/15102516/image-94b1b089.png)
   The application details page is displayed.
   ![How to Enable Current User Editable for... - screenshot 2](/images/intercom/15102516/image-307351e4.png)
3. Click **Configure** tab> **Epic EHR** .
   ![How to Enable Current User Editable for... - screenshot 3](/images/intercom/15102516/image-86235462.png)
   The Epic EHR page is displayed.
4. Do the following:
   1. Turn on **Enable Reauthentication Workflow** toggle button.
   2. Click **Save.**
      ![How to Enable Current User Editable for... - screenshot 4](/images/intercom/15102516/image-74bf6f42.png)
      Current User Editable; Reauthenticates the currently logged-in user but allows the authentication device to submit a different user if required.

      <Note>
        **Note:** The default factor for this authentication is set to application factor and cannot be changed.
      </Note>

      ![How to Enable Current User Editable for... - screenshot 5](/images/intercom/15102516/image-187fa2fb.png)

Current User editable is enabled for Epic EHR.
