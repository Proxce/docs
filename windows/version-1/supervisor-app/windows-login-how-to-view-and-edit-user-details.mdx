## Introduction

The **Details** tab in the Supervisor App allows the Admin and authorized Supervisor to view and update a user's profile information, such as the user's name, Secondary ID, and Wiegand format.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the required **Add User** privilege is enabled for the Supervisor. Without this privilege, Supervisors can only view users and their details.
- Ensure the **Add User** action is enabled for the application in the Tenant Admin Portal. If the **Add User** button is unavailable, contact your Tenant Admin. For more information, refer [How to Activate Add User Action on the App for Supervisor](https://oloid.help/en/articles/9127132-how-to-activate-add-user-action-on-the-app-for-supervisor) guide.
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal.

## Steps to View User Details

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. Select **User Management**.
   ![How to View and Edit User Details - screenshot 1](/images/intercom/9087842/image-fc670a69.png)
   The **Users** screen is displayed.
3. Select a user to view details.
   ![How to View and Edit User Details - screenshot 2](/images/intercom/9087842/image-f436d9cf.png)
   The **Details** tab is displayed.
4. Do the following:
   1. Edit **Name**. (Optional)
   2. Add or update the **Badge ID (Secondary ID)**. (Optional)
   3. Edit **Weigand Format**. (Optional)
   4. Click **Save.**

![How to View and Edit User Details - screenshot 3](/images/intercom/9087842/image-4015fc58.png)

The user details are successfully updated.

![How to View and Edit User Details - screenshot 4](/images/intercom/9087842/image-e07e714c.png)
