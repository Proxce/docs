You can view and download diagnostics report from Supervisor app in the following ways:

- [Using Network Diagnostics](#using-network-diagnostics)
- [Using Settings Feature](#using-settings-feature)

## Using Network Diagnostics

To view diagnostics and download report:

1. Double-click on Supervisor app ![How to view diagnostics and download... - screenshot 1](/images/intercom/9040866/image-be119dd5.png) icon.
   The app opens.
2. Click **More Options** > **Network Diagnostics**.
   ![How to view diagnostics and download... - screenshot 2](/images/intercom/9040866/image-b5eab2c2.png)
   The **Diagnostics** screen opens. You can view all the active URLs.

   <Note>
     **Note:** Type **Custom URL** in the text field and press **Enter**. (Optional)
   </Note>

   ![How to view diagnostics and download... - screenshot 3](/images/intercom/9040866/image-e7ece93f.png)
3. Do the following:
   1. Click **Diagnose** to refresh the URLs.
      ![How to view diagnostics and download... - screenshot 4](/images/intercom/9040866/image-ea9b7f7f.png)
      The URLs get refreshed with status.
   2. Click **Download Report** to download the diagnostic report.
      ![How to view diagnostics and download... - screenshot 5](/images/intercom/9040866/image-1623a36c.png)
      The diagnostic report is successfully downloaded to the local device

## Using Settings Feature

1. Double-click on Supervisor app![How to view diagnostics and download... - screenshot 6](/images/intercom/9040866/image-be119dd5.png) icon.
   The app opens.
2. Log in to **Supervisor App**.
   The **Admin Home** screen opens.
3. Click **Settings**.
   ![How to view diagnostics and download... - screenshot 7](/images/intercom/9040866/image-d884431e.png)
   The **Settings** screen opens.
4. Click **Diagnostics**.
   ![How to view diagnostics and download... - screenshot 8](/images/intercom/9040866/image-e7ece93f.png)
5. The **Diagnostics** screen opens. You can view all the active URLs.
   ![How to view diagnostics and download... - screenshot 9](/images/intercom/9040866/image-e7ece93f.png)

   <Note>
     **Note:** Type **Custom URL** in the text field and press **Enter**. (Optional)
   </Note>

6. Do the following:
   1. Click **Diagnose** to refresh the URLs.
      ![How to view diagnostics and download... - screenshot 10](/images/intercom/9040866/image-ea9b7f7f.png)
      The URLs get refreshed with status.
   2. Click **Download Report** to download the diagnostic report.

![How to view diagnostics and download... - screenshot 11](/images/intercom/9040866/image-1623a36c.png)

The diagnostic report is successfully downloaded to the local device.
