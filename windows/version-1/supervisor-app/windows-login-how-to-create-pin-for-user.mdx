## Introduction

Admin and Supervisor can create a PIN for a user through the Supervisor App and optionally share it with the user via email.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)**

## Steps to Create PIN

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. Select **User Management**.
   ![How to Create PIN for User - screenshot 1](/images/intercom/9088123/image-8c3156a2.png)
   The **Users** screen is displayed.
3. Select the user to view details.
   ![How to Create PIN for User - screenshot 2](/images/intercom/9088123/image-538dbcde.png)
   The user details page is displayed.
4. Go to **PIN** tab > Click **Add**.
   ![How to Create PIN for User - screenshot 3](/images/intercom/9088123/image-91d8fffc.png)
   The **Create PIN** dialog box is displayed.
5. Do the following:
   1. Enter **new PIN**.
   2. Re-enter **new PIN**.
   3. In the Share PIN with field add the email IDs of users to share this pin Via email. (Optional)
   4. Click **Create**.
      ![How to Create PIN for User - screenshot 4](/images/intercom/9088123/image-2bc5c1ca.png)
      The PIN is successfully created.
      ![How to Create PIN for User - screenshot 5](/images/intercom/9088123/image-21765ab7.png)

The newly created PIN is displayed on the PIN tab.

![How to Create PIN for User - screenshot 6](/images/intercom/9088123/image-cc54a18b.png)
