## Introduction

The **Password** tab in the Supervisor App allows Admin and Supervisor to create Windows credentials for users. Password credentials can be created for either **Domain Users** or **Windows Local Users**, enabling users to authenticate to their assigned Windows devices.

This document comprises of the following:

- [Create credential for domain](#create-credential-for-domain)
- [Create credential for local windows machine](#create-credential-for-local-windows-machine)

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)**

## Steps to Add Password

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Add Password - screenshot 1](/images/intercom/9153831/image-b44d7e0a.png)
   The **Users** screen is displayed.
3. Select a user to view details.
   ![How to Add Password - screenshot 2](/images/intercom/9153831/image-0f47e281.png)
   The **Details** tab is displayed.
4. Select **Password** tab> **+Password**.
   ![How to Add Password - screenshot 3](/images/intercom/9153831/image-26ee8cd6.png)
   The **Create Password** pop-up box is displayed.
   ![How to Add Password - screenshot 4](/images/intercom/9153831/image-26d0b362.png)

### Create credential for domain

1. Select **Domain User** from the **Credential Type** drop-down list.
2. Enter **Display Name**.
3. Enter **Domain Name**.
4. Select one or more **Preferred machines**. By default, the paired endpoint is selected.
5. Enter **Username** of your Windows account.
6. Enter **Password** of your Windows account.
7. Click **Save**.
   ![How to Add Password - screenshot 5](/images/intercom/9153831/image-ed424573.png)
   The Password is successfully created.
   ![How to Add Password - screenshot 6](/images/intercom/9153831/image-1f3ce347.png)
   The credential is created and displayed under the **Password** tab.
   ![How to Add Password - screenshot 7](/images/intercom/9153831/image-d4f11076.png)

### Create credential for local Windows machine

1. Select user type as **Local User** from **Select Credential Type** dropdown.
2. Enter **Display Name**.
3. Select **Machine Name**. (System Default paired machine name is selected)

   <Note>
     **Note:** You can select only single machine name.
   </Note>

4. Enter **User Name**.
5. Enter **Password**.
6. Click **Save**.

![How to Add Password - screenshot 8](/images/intercom/9153831/image-99f44b2a.png)

The Password is successfully created.

![How to Add Password - screenshot 9](/images/intercom/9153831/image-b3d5ac00.png)

The credential is created and displayed under the **Password** tab.

![How to Add Password - screenshot 10](/images/intercom/9153831/image-bc84a82f.png)
