## Introduction

Assigning users to a shared credential enables centralized credential management while controlling which users are authorized to use the credential.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the shared credential is created. For more information, refer: **[How to Create Shared Credentials Using the Supervisor App](https://oloid.help/en/articles/9045726-windows-login-how-to-create-shared-password-using-the-supervisor-app)**.

## Steps to Assign Shared Password

1. Log in to **Supervisor App**.
   The **Admin Home** screen is displayed.
2. Select **Shared Credentials**.
   ![How to Assign Users to Shared Passwords... - screenshot 1](/images/intercom/9121212/image-6a2d7080.png)
3. Select **Shared Password**.
   ![How to Assign Users to Shared Passwords... - screenshot 2](/images/intercom/9121212/image-e1e40f9e.png)
   The **Shared Password** page is displayed.
4. Select **Users Assigned** tab > **+ Assign Users**.
   ![How to Assign Users to Shared Passwords... - screenshot 3](/images/intercom/9121212/image-9a5c764d.png)
   The **Select Users** pop-up box is displayed.
5. You can select user(s) from the displayed list.

   <Note>
     **Note:** You can search the user(s)
   </Note>

6. Click **Assign**.

![How to Assign Users to Shared Passwords... - screenshot 4](/images/intercom/9121212/image-9b68443f.png)

The user(s) are assigned successfully to the shared credential.

![How to Assign Users to Shared Passwords... - screenshot 5](/images/intercom/9121212/image-92bdbeb7.png)

The assigned Users are displayed in the Credential Owners tab.

![How to Assign Users to Shared Passwords... - screenshot 6](/images/intercom/9121212/image-2fa94100.png)
