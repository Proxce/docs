To unpair endpoint:

1. Log in to **Supervisor** App.
   The **Admin Home** screen is displayed.
2. Select **Settings**.
   ![How to unpair Endpoint using Supervisor... - screenshot 1](/images/intercom/9053859/image-77ee4660.png)
3. Select **Unpair Endpoint**.
   ![How to unpair Endpoint using Supervisor... - screenshot 2](/images/intercom/9053859/image-4fa59d06.png)
   The **Confirm Unpair** screen is displayed.
4. Click **Confirm Unpair**.
   ![How to unpair Endpoint using Supervisor... - screenshot 3](/images/intercom/9053859/image-cb779bd0.png)
   The Device is unpaired successfully.

   <Note>
     **Note:** You can not unpair the device if it is associated with a group.
   </Note>
