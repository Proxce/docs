## Introduction

Credential Owners are users who are authorized to manage a shared credential. Assigning Credential Owners allows designated Admins or Supervisors to maintain ownership of shared credentials and manage them as required.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the shared credential is created. For more information, refer: **[How to Create Shared Credentials Using the Supervisor App](https://oloid.help/en/articles/9045726-windows-login-how-to-create-shared-password-using-the-supervisor-app)**.

## Steps to Assign Password Owners

1. Log in to **Supervisor App**.
   The **Admin Home** screen is displayed.
2. Select **Shared Credentials**.
   ![How to Assign Credential Owners to... - screenshot 1](/images/intercom/9188537/image-6a2d7080.png)
3. Select **Shared Password**.
   ![How to Assign Credential Owners to... - screenshot 2](/images/intercom/9188537/image-e1e40f9e.png)
   The **Shared Password** page is displayed.
4. Select **Credential Owners** tab > **+ Assign Owners**.
   ![How to Assign Credential Owners to... - screenshot 3](/images/intercom/9188537/image-5224d71b.png)
   The **Select Credential Owner** pop-up box is displayed.
5. You can select credential owner(s) from the displayed list.

   <Note>
     **Note:** You can search the credential owner(s).
   </Note>

6. Click **Assign**.

![How to Assign Credential Owners to... - screenshot 4](/images/intercom/9188537/image-a2b17859.png)

The credential owner(s) are assigned successfully to the shared credential.

![How to Assign Credential Owners to... - screenshot 5](/images/intercom/9188537/image-44a80a5a.png)

The assigned Credential Owners are displayed in the Credential Owners tab.

![How to Assign Credential Owners to... - screenshot 6](/images/intercom/9188537/image-d1396398.png)
