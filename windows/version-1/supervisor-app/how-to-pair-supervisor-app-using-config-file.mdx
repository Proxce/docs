## Pre-requisite

If endpoint is created through the Oloid Portal, you need to download the config file of the preferred endpoint from the Oloid Portal. For details, refer [How to download endpoint config file for Windows Login?](https://oloid.help/en/articles/8778331-how-to-download-endpoint-config-file-for-windows-login)

To pair an endpoint:

1. Double-click on the **Supervisor App** to start.
   ![How to pair Supervisor App using Config... - screenshot 1](/images/intercom/9036798/image-a8da1205.png)
   The **Pair Endpoint** screen is displayed.
2. Select **Pair Device Using Config File**.
   ![How to pair Supervisor App using Config... - screenshot 2](/images/intercom/9036798/image-b7e1b9b2.png)
   The **Pair Device Using Config File** screen is displayed.
3. Select the json file you want to upload and click **Open**.
   ![How to pair Supervisor App using Config... - screenshot 3](/images/intercom/9036798/image-9c065c89.png)

   <Note>
     **Note:** Check mark to **Use the Machine Name as Endpoint Name** (Optional).
   </Note>

4. Click to **Upload** the endpoint JSON file.

   <Note>
     **Note:** You can choose **Reset** to upload the JSON file again.
   </Note>

   The **Pairing endpoint** screen is displayed.
5. The **Endpoint Name** is auto-populated.
   ![How to pair Supervisor App using Config... - screenshot 4](/images/intercom/9036798/image-80c621f6.png)
6. Select **Publish**.
   The endpoint is paired successfully.
   ![How to pair Supervisor App using Config... - screenshot 5](/images/intercom/9036798/image-88a365b2.png)
   Now, you can log in to admin mode.
   ![How to pair Supervisor App using Config... - screenshot 6](/images/intercom/9036798/image-162bd16d.png)
