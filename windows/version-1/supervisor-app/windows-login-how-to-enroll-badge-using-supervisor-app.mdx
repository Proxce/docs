## Introduction

The **Enroll Badge** feature in the Supervisor App allows Admins and Supervisors to enroll a badge for an existing user by scanning it with a connected badge reader. Once enrolled, the badge can be used as a credential for passwordless authentication with Windows Login.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the Badge option is enabled for the application in the Tenant Admin Portal to make the Enroll Badge option available in the Supervisor App. Refer to **[How to enable badge option for Supervisor App.](https://oloid.help/en/articles/9182568-how-to-enable-badge-option-for-supervisor-app)**
- Ensure a supported badge reader is connected to the system.
- Ensure the user exists in the Tenant Admin Portal. Refer: [Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)

## Steps to Enroll Badge

1. Log in to **Supervisor App**. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. Click **Enroll Credential.**
   ![How to Enroll Badge using Supervisor App - screenshot 1](/images/intercom/9182563/image-e29170b9.png)
3. Click **Enroll Badge**.
   ![How to Enroll Badge using Supervisor App - screenshot 2](/images/intercom/9182563/image-e1b560f5.png)
   The **Enroll For Badge Login** screen is displayed.
4. Enter **Employee ID**.

   <Note>
     **Note:** The **Employee ID** is the user's Primary ID in the Tenant Admin Portal. Select the **Make Employee ID case sensitive** checkbox to enforce case-sensitive matching. (Optional)
   </Note>

5. Click **Continue**.
   ![How to Enroll Badge using Supervisor App - screenshot 3](/images/intercom/9182563/image-ae567c2b.png)
   The Scan Your Badge screen is displayed.
6. Do the following:
   1. Scan your badge in the Badge Reader.
      The scanned badge number is auto-populated on the **Scan Badge to Edit** field.
   2. Click **Submit**.

![How to Enroll Badge using Supervisor App - screenshot 4](/images/intercom/9182563/image-b2a694a5.png)

The badge is successfully enrolled.

![How to Enroll Badge using Supervisor App - screenshot 5](/images/intercom/9182563/image-444a005d.png)
