The Supervisor App can be downloaded from Tenant Settings section in the Tenant Admin Portal.

### Steps to download from Tenant Settings

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **User profile icon** on the bottom left corner of the menu panel.
   ![How to download Supervisor App - screenshot 1](/images/intercom/9036607/28d58c31-d184-44b0-a450-2cbd72f80ad6-37b01151.png)
   The user profile menu is displayed.
3. Select **Tenant Settings**.
   ![How to download Supervisor App - screenshot 2](/images/intercom/9036607/240f19ab-474e-4c7e-b213-103d5ce45fc3-2a52c6fc.png)
   The **Tenant Settings** screen is displayed.
   ![How to download Supervisor App - screenshot 3](/images/intercom/9036607/image-a3aa73d9.png)
4. Go to **Oloid Apps** tab > **Windows Authenticator App**.
   ![How to download Supervisor App - screenshot 4](/images/intercom/9036607/image-b9592a2c.png)
5. Select the preferred version from the **Win-Login-Installer** dropdown list, then click the **Download** button![How to download Supervisor App - screenshot 5](/images/intercom/9036607/image-73c7d2ae.png)icon.
   ![How to download Supervisor App - screenshot 6](/images/intercom/9036607/image-3c797bb6.png)
   The installer file is downloaded to your local device.
