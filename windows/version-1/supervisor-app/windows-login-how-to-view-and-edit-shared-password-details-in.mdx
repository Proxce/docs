## Introduction

Shared Credentials can be updated after they are created to reflect changes such as the display name, username, password, associated machine, preferred machines, or external ID.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the shared credential is created. For more information, refer: **[How to Create Shared Credentials Using the Supervisor App](https://oloid.help/en/articles/9045726-windows-login-how-to-create-shared-password-using-the-supervisor-app)**.

## Steps to view and edit Shared Password

1. Log in to **Supervisor App**.
   The **Admin Home** screen is displayed.
2. Select **Shared Credentials**.
   ![How to View and Edit Shared Password... - screenshot 1](/images/intercom/9196014/image-6a2d7080.png)
3. Select **Shared Password**.
   ![How to View and Edit Shared Password... - screenshot 2](/images/intercom/9196014/image-e1e40f9e.png)
   The **Shared Password** page is displayed.
4. Select one of the following based on the type of shared credential you want to edit:
   1. View and Edit Local Shared Credential
   2. View and Edit Domain Shared Credential
      The respective (Local / Domain) Shared Credential screen is displayed.

### View and Edit a Windows Local User Shared Credential

1. Select the required Shared Password from the list.
2. Go to **Details** tab.
   ![How to View and Edit Shared Password... - screenshot 3](/images/intercom/9196014/image-8efc3c2f.png)
3. Edit **Display Name**.
4. Select **Machine** from the **Select Machine** list.
   1. Select a machine and then click **Assign**.
      ![How to View and Edit Shared Password... - screenshot 4](/images/intercom/9196014/image-f2a84349.png)
5. Edit **Username**.
6. Enter **Password**. (Optional)
7. Enter **External ID**. (Optional)
8. Click **Save.**

![How to View and Edit Shared Password... - screenshot 5](/images/intercom/9196014/image-ffeeedb9.png)

The Local Shared Credential is updated successfully.

![How to View and Edit Shared Password... - screenshot 6](/images/intercom/9196014/image-e52eec9e.png)

### View and Edit a Domain User Shared Credential

1. Select the required Shared Password from the list.
2. Go to **Details** tab.
   ![How to View and Edit Shared Password... - screenshot 7](/images/intercom/9196014/image-ece408a8.png)
3. Edit **Display Name**.
4. Edit **Domain Name**.
5. Select **Preferred Machine** from the **Select Preferred Machine** list.
   1. Select machine(s) and then click **Assign**.
      ![How to View and Edit Shared Password... - screenshot 8](/images/intercom/9196014/image-b64423a7.png)
6. Edit **Username**.
7. Enter **Password**. (Optional)
8. Enter **External ID**. (Optional)
9. Click **Save.**

![How to View and Edit Shared Password... - screenshot 9](/images/intercom/9196014/image-b8d4ccdd.png)

The Domain Shared Credential is updated successfully.

![How to View and Edit Shared Password... - screenshot 10](/images/intercom/9196014/image-66ff4268.png)
