To reset tenant:

1. Double-click on the **Supervisor** App.
2. Enter **Tenant Name**.
   ![How to reset tenant in Supervisor App - screenshot 1](/images/intercom/9059054/image-419ee789.png)
3. Select **Next**.
   The **Pair Endpoint** screen is displayed.
4. On the bottom right, select **More Options** > **Reset Tenant**.
   ![How to reset tenant in Supervisor App - screenshot 2](/images/intercom/9059054/image-2de6fa0f.png)
   The confirmation pop-up box is displayed.
   ![How to reset tenant in Supervisor App - screenshot 3](/images/intercom/9059054/image-790df50c.png)
5. Select **Confirm** to reset the tenant.
   The tenant name is reset successfully.
