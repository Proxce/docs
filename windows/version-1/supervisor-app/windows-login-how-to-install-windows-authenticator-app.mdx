The Windows Authenticator App is a Windows-based application that enables you to configure the Windows Login app. It allows you to set up endpoints, manage users and shared credentials, and support multiple authentication methods such as badge, PIN, and password.

**Pre-requisite**

The Windows Authenticator App must be downloaded. For detailed instructions, see [How to download Windows Authenticator App](https://oloid.help/en/articles/9036607-how-to-download-supervisor-app)

<Note>
  **Note:** It is recommended to use [Tenant Settings](https://oloid.help/en/articles/9036607-how-to-download-supervisor-app#h_7bf81eaafc:~:text=the%20local%20device.-,Steps%20to%20download%20from%20Tenant%20Settings%3A,-Log%20in%20to) tab to download the installer file.
</Note>

Make sure your system has the following installed components:

- Visual C++ "14" Runtime Libraries (x64)
- .Net Runtime 6.0.36 (x64)
- .Net Desktop Runtime 6.0.36 (x64)

If any of these components are missing, you'll need to run the **setup.exe** file included in the installation file.

**Steps to install Windows Authenticator App:**

1. Download **Windows Authenticator App** file on your system.
   ![How to install Windows Authenticator App - screenshot 1](/images/intercom/9036683/image-745f5d25.png)

   <Note>
     **Note:** If you have subscribed to Presence Detection feature, then download **Windows Authenticator App (Presence Detection)** file on your system.
   </Note>

   ![How to install Windows Authenticator App - screenshot 2](/images/intercom/9036683/image-07a5fbca.png)
   The **OloidPasswordlessSupervisor.Setup.zip** file is downloaded to your system.
2. Right-click and select **Extract All** > **OloidPasswordlessSupervisor.Setup.zip** file.
   The extracted files will be saved in the same folder as the original zipped file.
3. Confirm the presence of required components:
   - If all required components are already installed, then double-click **OloidPasswordlessSupervisor.Setup** file.
     ![How to install Windows Authenticator App - screenshot 3](/images/intercom/9036683/6bf89c3c-1ba6-409f-8634-e114b820b0b2-ae4b5880.png)
   - If any component is missing, double-click **setup.exe** to install missing dependencies.
     ![How to install Windows Authenticator App - screenshot 4](/images/intercom/9036683/b152d682-281c-47a9-81ca-97453a9c7e8d-6d2fcadd.png)
4. In the **Oloid Passwordless Supervisor Setup** window, review the listed components, and click **Install** to proceed.
   ![How to install Windows Authenticator App - screenshot 5](/images/intercom/9036683/image-084978cd.png)

   <Note>
     **Note:** If components are missing, the setup prompts you to install them.
   </Note>

   ![How to install Windows Authenticator App - screenshot 6](/images/intercom/9036683/image-73a60012.png)
5. On the **Oloid Passwordless Supervisor** Setup wizard, click **Next**.
   ![How to install Windows Authenticator App - screenshot 7](/images/intercom/9036683/image-d0d5f077.png)
6. Use the default path to install the application and click **Next**.
   ![How to install Windows Authenticator App - screenshot 8](/images/intercom/9036683/image-b2235393.png)
7. Click **Next** to confirm the installation.
   ![How to install Windows Authenticator App - screenshot 9](/images/intercom/9036683/image-f7b9700c.png)
8. Click **Close** after the installation is complete.
   ![How to install Windows Authenticator App - screenshot 10](/images/intercom/9036683/image-438e28b7.png)
   You can find the app icon ![How to install Windows Authenticator App - screenshot 11](https://downloads.intercomcdn.com/i/o/e4gi378c/1420361100/13b986445df6938d5fc06d48daf9/image.png?expires=1790488800&signature=ed5d8a9b94b36bdd0f962defe70870b5d424ef891c15fffb583605911a973e55&req=dSQlFsp4nIBfWfMW3nq%2Bgd0hUKQPI1r8bpRJrcUl2VZEsyoFE2bK5xShVJjl%0Ans088hnWH6%2F%2FhRTivNXTLyrjwAw%3D%0A) on your desktop.
   Now restart your system for the Windows Supervisor App to take effect
