## Introduction

The Enable Badge Options setting allows Tenant Admin to control the badge enrollment options available in the Supervisor App. Depending on your authentication requirements, you can allow users to enroll using Badge only or require Badge + PIN authentication.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Windows Login application is created in the Tenant Admin Portal. For more information, refer [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable Badge Enrollment Options

1. Log in to the Tenant Admin Portal.
   The Application Detail page is displayed.
2. Select the application that is configured in the Supervisor App.
   ![How to Enable Enroll Badge Option for... - screenshot 1](/images/intercom/9182568/image-a680b5d8.png)
   The Application Details page is displayed.
   Go to **Configure** > click **Customize Buttons** > click **Enable Badge Options**.
   ![How to Enable Enroll Badge Option for... - screenshot 2](/images/intercom/9182568/image-5ac15f10.png)
   The Configuration page is displayed.
3. Do one of the following:
   1. Select **Enroll Badge Only** to allow badge-only enrollment.
   2. Select **Enroll Badge + PIN** to require badge and PIN authentication.
4. Click **Save**.

![How to Enable Enroll Badge Option for... - screenshot 3](/images/intercom/9182568/image-5fceadb9.png)

The badge enrollment configuration is saved successfully.

![How to Enable Enroll Badge Option for... - screenshot 4](/images/intercom/9182568/image-f18be6f5.png)
