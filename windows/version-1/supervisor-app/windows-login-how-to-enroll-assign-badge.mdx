## Introduction

The **Badge** tab in the Supervisor App allows Admin and Supervisor to assign a badge credential to a user. A badge can be assigned either by scanning it with a connected badge reader or by manually entering the Badge ID and Wiegand format.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)**

## Steps to Assign Badge

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Enroll / Assign Badge - screenshot 1](/images/intercom/9115843/image-2bd774cb.png)
   The **Users** screen is displayed.
3. Select the user to view details.
   ![How to Enroll / Assign Badge - screenshot 2](/images/intercom/9115843/image-e81c6294.png)
   The User details screen is displayed.
4. Select **Badge** tab.
5. Click **Assign Badge**.
   ![How to Enroll / Assign Badge - screenshot 3](/images/intercom/9115843/image-70d89d88.png)
   The Assign Badge pop-up box is displayed.
6. Do the following:
   1. Enter **Badge ID/Secondary ID**.
   2. Select **Wiegand Format** from dropdown.
   3. Click **Save**.
      ![How to Enroll / Assign Badge - screenshot 4](/images/intercom/9115843/image-dff6c8cf.png)
      The badge is enrolled and assigned successfully.
      ![How to Enroll / Assign Badge - screenshot 5](/images/intercom/9115843/image-99f5a1bc.png)
