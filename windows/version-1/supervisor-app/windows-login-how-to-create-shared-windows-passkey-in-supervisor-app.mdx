## Introduction

The **Create Shared Passkey** feature in the Windows Supervisor App allows the authorized supervisor to generate and assign Windows shared passkeys to user(s).

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- You must have a Windows Pro Machine.
- OpenVPN must be enabled for authenticating with passkey.
- Ensure the user exists in the Tenant Admin Portal. Refer: [Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)
- Domain account must be created for the User.

## Steps to Create Shared Passkey in Windows Supervisor app

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Supervisor App Home** screen is displayed.
2. Click **Shared Credentials**
   ![How to Create Shared Windows Passkey in... - screenshot 1](/images/intercom/14338949/image-b08f4662.png)
   The **Shared Credentials** screen is displayed
3. Select **Shared Passkey**.
   ![How to Create Shared Windows Passkey in... - screenshot 2](/images/intercom/14338949/image-78a5ef1d.png)
   The **Shared Passkey** details page is displayed
4. Click **Create**.
   ![How to Create Shared Windows Passkey in... - screenshot 3](/images/intercom/14338949/image-a747cb9a.png)
   The Create Shared Passkey pop-up box is displayed.
5. Do the following
   1. Enter **Display Name**
   2. Edit **Domain Name** (System Default Domain name is selected)
   3. Enter **Username**
   4. Select **Credential Owner(s)**
   5. Select **Preferred Machine** from the Preferred Machine list. (System Default paired machine name is selected)
   6. Enter **Tags.** (Optional)
   7. Enter **External ID** (Optional)
   8. Click **Generate.**

![How to Create Shared Windows Passkey in... - screenshot 4](/images/intercom/14338949/image-76e2aa10.png)

The Shared Passkey is successfully created.
