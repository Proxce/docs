The preferred credential is applicable for domain user.

To mark as preferred credential:

1. On the admin home page, select **Shared Credentials**.
   ![How to mark as a preferred credential... - screenshot 1](/images/intercom/9324029/image-76c27d2e.png)
   The **Shared Credentials** screen is displayed.
2. Select **Mark as Preferred Credential**![How to mark as a preferred credential... - screenshot 2](/images/intercom/9324029/image-e7d6ec8d.png)icon on a shared credential.
   ![How to mark as a preferred credential... - screenshot 3](/images/intercom/9324029/image-0f916925.png)
3. Select Confirm to add your endpoint as preferred machine on the displayed pop-up box.
   ![How to mark as a preferred credential... - screenshot 4](/images/intercom/9324029/image-2b63fb2e.png)
   The shared credential is marked as preferred machine successfully.
   ![How to mark as a preferred credential... - screenshot 5](/images/intercom/9324029/image-8c6cb6df.png)

   <Note>
     **Note:** To remove shared credential as the preferred machine, you can unstar them.
   </Note>
