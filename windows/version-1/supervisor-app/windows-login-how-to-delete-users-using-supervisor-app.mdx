## Introduction

The **Delete User** feature in the Supervisor App allows authorized Admins and Supervisors to permanently remove users from the application when they no longer require access.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Supervisors can delete users only if the required Delete User privilege is enabled for the application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)

## Steps to Delete a User

1. Log in to **Supervisor App**. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. Select **User Management**.
   ![How to delete users using Supervisor App - screenshot 1](/images/intercom/9546517/image-8cda33bc.png)
   The **Users** screen is displayed.
3. Select the **User** you want to delete.
   ![How to delete users using Supervisor App - screenshot 2](/images/intercom/9546517/image-2b60f5e6.png)
   The user details screen is displayed.
4. Click Delete on the top right corner of the screen.
   ![How to delete users using Supervisor App - screenshot 3](/images/intercom/9546517/image-fa6990ee.png)
   The confirmation dialog box is displayed.
5. Click **Confirm** to delete the user.

![How to delete users using Supervisor App - screenshot 4](/images/intercom/9546517/image-5c0f72d3.png)

The user is successfully deleted.

![How to delete users using Supervisor App - screenshot 5](/images/intercom/9546517/image-1c789da6.png)

<Note>
  **Note:** Deleting a user permanently removes the user from the Oloid platform. This action cannot be undone. Supervisors cannot delete users who are assigned to one or more groups.
</Note>
