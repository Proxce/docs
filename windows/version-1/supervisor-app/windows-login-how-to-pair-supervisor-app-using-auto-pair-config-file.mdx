## Introduction

This document provides instructions to pair a windows device using the Auto-Pair Config File in the supervisor app.

## Prerequisites

- You must have Admin or Supervisor credentials to perform endpoint pairing.
- You must have the Auto-Pair Config File in JSON format. To download the Auto-Pair Config File, refer to [Windows Login - How to Generate and Download Auto-Pair config file for Windows Login in Tenant Admin Portal](https://oloid.help/en/articles/10441578-windows-login-how-to-generate-and-download-auto-pair-config-file-for-windows-login-in-tenant-admin-portal#h_92d9e3460c).

## To Pair Supervisor App using Auto-Pair Config File

1. Double-click on the **Supervisor App** ![How to Pair Supervisor App using... - screenshot 1](/images/intercom/9637781/image-05ca7bd9.png) icon.
   The Welcome screen is displayed, showing the message "**Auto-pair config found!**"

   <Note>
     **Note:** The Auto-Pair Config File must be in JSON format and is available in the installer directory at `C:\OloidV2\Oloid\config`. If you do not see the auto-pair option, reach out to [Oloid Support](mailto:support@oloid.ai).
   </Note>

2. Select **Yes, Pair my device** to auto-pair the device.
   ![How to Pair Supervisor App using... - screenshot 2](/images/intercom/9637781/image-d4c9b192.png)
   The device is pairing.
   ![How to Pair Supervisor App using... - screenshot 3](/images/intercom/9637781/image-2f51ad2f.png)
   The device is paired successfully.
3. Click **Enter Supervisor Mode** to continue as Supervisor.
   ![How to Pair Supervisor App using... - screenshot 4](/images/intercom/9637781/image-ff9ac0b9.png)
