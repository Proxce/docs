## Introduction

The Scan Badge to Enroll feature allows Admin and Supervisor to enroll a user's badge by scanning it with a connected badge reader.

## Prerequisites

- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)**

## Steps to Enroll badge

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Enroll Badge - screenshot 1](/images/intercom/9619247/image-b44d7e0a.png)
   The **Users** screen is displayed.
3. Select a user to view details.
   ![How to Enroll Badge - screenshot 2](/images/intercom/9619247/image-31837102.png)
   The **Details** tab is displayed.
4. Select **Badge** tab > **Scan Badge to Enroll**.
   ![How to Enroll Badge - screenshot 3](/images/intercom/9619247/image-5fbf931a.png)
   The **Scan Badge to Enroll** pop-up box is displayed.
5. Do the following:
   1. Scan your badge in the Badge Reader.
      The scanned badge number is auto-populated on the **Scan Badge to Edit** field.
   2. Click **Create**.

![How to Enroll Badge - screenshot 4](/images/intercom/9619247/image-0254d216.png)

The badge is enrolled successfully.
