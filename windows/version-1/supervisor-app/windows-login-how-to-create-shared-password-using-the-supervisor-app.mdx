## Introduction

Shared Credentials are passwords that can be used to access a local Windows machine or a domain. It is shared among the users to whom they are assigned.

This document comprises the following:

- Create Shared Credential for Domain User
- Create Shared Credential for Local User

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. Refer: [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)

## Steps to Create Shared Password for Domain user

1. Log in to **Supervisor App**.
   The **Admin Home** screen is displayed.
2. Select **Shared Credentials**.
   ![How to create Shared Password using the... - screenshot 1](/images/intercom/9045726/image-1f4d4698.png)
3. Select **Shared Password**.
   ![How to create Shared Password using the... - screenshot 2](/images/intercom/9045726/image-03785f0d.png)
   The **Shared Password** page is displayed.
4. On the top right, click **+ Create**.
   ![How to create Shared Password using the... - screenshot 3](/images/intercom/9045726/image-9954a253.png)
   The **Create Shared Password** page is displayed.
5. Do the following:
   1. Select **Credential Type** as Domain User.
   2. Enter **Display Name**.
   3. Select **Users** for **Credential Owner**. (System Default)
   4. Enter **Domain Name**.
   5. Select **Preferred Machine** from the Preferred Machine list. (System Default paired machine name is selected)
   6. Enter **Username**.
   7. Enter **Password**.
   8. Enter **External ID**. (Optional)
   9. Click **Create Password**.

![How to create Shared Password using the... - screenshot 4](/images/intercom/9045726/image-56e0315c.png)

The Shared Password is created successfully.

![How to create Shared Password using the... - screenshot 5](/images/intercom/9045726/image-9a36466c.png)

The shared credential of type Domain User is created and listed on the **Shared Credential** screen.

![How to create Shared Password using the... - screenshot 6](/images/intercom/9045726/image-56f1f16a.png)

## Steps to Create Shared Password for Local User

1. Log in to **Supervisor App**.
   The **Admin Home** screen is displayed.
2. Select **Shared Credentials**.
   ![How to create Shared Password using the... - screenshot 7](/images/intercom/9045726/image-e602597e.png)
3. Select **Shared Password**.
   ![How to create Shared Password using the... - screenshot 8](/images/intercom/9045726/image-88abac13.png)
   The **Shared Password** page is displayed.
4. On the top right, click **+ Create**.
   ![How to create Shared Password using the... - screenshot 9](/images/intercom/9045726/image-9954a253.png)
   The **Create Shared Password** page is displayed.
5. Do the following:
   1. Enter **Display Name**.
   2. Select user(s) for **Credential Owner**. (System Default)
   3. Select **Machine.** (System Default paired machine name is selected)
   4. Enter **User Name**.
   5. Enter **Password**.
   6. Enter **External ID**. (Optional)
   7. Click **Create Password**.

![How to create Shared Password using the... - screenshot 10](/images/intercom/9045726/image-44a6b02a.png)

The Shared Password is created successfully.

![How to create Shared Password using the... - screenshot 11](/images/intercom/9045726/image-7cc5ca2d.png)

The shared credential of type Windows Local User is created and listed on the **Shared Credential** screen.

![How to create Shared Password using the... - screenshot 12](/images/intercom/9045726/image-0a347013.png)
