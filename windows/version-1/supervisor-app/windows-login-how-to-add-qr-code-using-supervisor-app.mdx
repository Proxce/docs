## Introduction

QR Code assignment allows the Supervisor to generate and assign QR-based credentials to users through the Supervisor App. These QR codes can be shared with users for authentication, providing a secure and contactless login option.

## Prerequisite

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the user exists in the Tenant Admin Portal. Refer: [Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)

## Steps to Add QR Code

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Add QR Code using Supervisor App - screenshot 1](/images/intercom/15457358/image-229adee7.png)
   The **Users** screen with list of users is displayed.
3. Select **user** from the list, or search for a user using the search bar at the top.
   ![How to Add QR Code using Supervisor App - screenshot 2](/images/intercom/15457358/image-3c66ca96.png)
   The user's **Details** screen is displayed
4. Select **QR Code** tab > Tap **ADD +**.
   ![How to Add QR Code using Supervisor App - screenshot 3](/images/intercom/15457358/image-44448e2f.png)
   The Create QR Code pop-up box is displayed.
5. Do the following:
   1. Select the QR Code Validity date.
   2. Enter Email ID of user(s) to Share QR Code with.
   3. Tap **Create.**

![How to Add QR Code using Supervisor App - screenshot 4](/images/intercom/15457358/image-339e2ce2.png)

The QR Code is successfully assigned to user.

![How to Add QR Code using Supervisor App - screenshot 5](/images/intercom/15457358/image-e41901e8.png)
