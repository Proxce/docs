## Introduction

The Add User feature in the Supervisor App allows authorized Admins and Supervisors to create user accounts directly from a paired Windows endpoint.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the required **Add User** privilege is enabled for the Supervisor. Without this privilege, Supervisors can only view users and their details.
- Ensure the **Add User** action is enabled for the application in the Tenant Admin Portal. If the **Add User** button is unavailable, contact your Tenant Admin. For more information, refer [How to Activate Add User Action on the App for Supervisor](https://oloid.help/en/articles/9127132-how-to-activate-add-user-action-on-the-app-for-supervisor) guide.
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal.

## Steps to Add User

1. Log in to **Supervisor App**.
   The **Admin Home** screen is displayed.
2. Click **User Management**.
   ![How to Add a User - screenshot 1](/images/intercom/9041346/image-2efd21fb.png)
   The **Users** screen is displayed.
3. Select **+Add User** at the top right.
   ![How to Add a User - screenshot 2](/images/intercom/9041346/image-82b0f8de.png)
   The **Add User** screen pop-up box is displayed.
4. Do the following:
   1. Enter **Name**.
   2. Enter **Primary ID**.
   3. Enter **Secondary ID** ( Optional)
   4. Click **Select Connection**.

The Select Connection pop-up box is displayed.

1. Do the following:
   1. Select **Connection** from the list.

      <Note>
        **Note:** You must add connection(s) to the selected application in the Tenant Admin Portal.
      </Note>

   2. Click **Add.**
      ![How to Add a User - screenshot 3](/images/intercom/9041346/image-06f91f62.png)
5. Click **Add User**.

![How to Add a User - screenshot 4](/images/intercom/9041346/image-5963aaba.png)

The user is successfully added to the application.

![How to Add a User - screenshot 5](/images/intercom/9041346/image-ee745c61.png)

The newly added user appears in the Users list.

![How to Add a User - screenshot 6](/images/intercom/9041346/image-92a5c919.png)
