## Introduction

Shared Credentials allow multiple users to securely access shared Windows accounts without requiring individual password credentials. Admin and Supervisor can assign one or more shared credentials to a user

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application.
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Shared Credentials must be created for the users. Refer: [How to create Shared Credentials using the Supervisor App](https://oloid.help/en/articles/9045726-how-to-create-shared-credentials-using-the-supervisor-app)

## Steps to Assign Shared Credentials

1. Log in to **Supervisor App**. For more, refer to [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Assign Shared Credential - screenshot 1](/images/intercom/9207046/image-b44d7e0a.png)
   The **Users** screen is displayed.
3. Select a user to view details.
   ![How to Assign Shared Credential - screenshot 2](/images/intercom/9207046/image-0f47e281.png)
   The **Details** tab is displayed.
4. Go to **Password** tab > **Shared Credentials**.
   ![How to Assign Shared Credential - screenshot 3](/images/intercom/9207046/image-91b224b2.png)
   The **Assign Shared Credential** screen is displayed.
5. Do the following:
   1. Select one or more **Shared Credentials** to assign to the user.
   2. Click **Assign**.

![How to Assign Shared Credential - screenshot 4](/images/intercom/9207046/image-e1150d96.png)

The shared credential is successfully assigned to the user.

![How to Assign Shared Credential - screenshot 5](/images/intercom/9207046/image-3d0b3beb.png)
