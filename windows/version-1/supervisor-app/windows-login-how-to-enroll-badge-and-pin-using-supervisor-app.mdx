## Introduction

The Enroll Badge + PIN feature in the Supervisor App allows Admin and Supervisor to enroll a badge and configure a PIN for a user in a single workflow. The enrolled badge and PIN can then be used together as a multi-factor credential for Windows Login authentication.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- **Enable Badge Options** must be enabled in the Oloid Portal for the Enroll Badge option in the Supervisor App. Refer to **[How to enable badge option for Supervisor App.](https://oloid.help/en/articles/9182568-how-to-enable-badge-option-for-supervisor-app)**
- Ensure a supported badge reader is connected to the system.
- Ensure the user exists in the Tenant Admin Portal.

## Steps to Enroll Badge and PIN

1. Log in to **Supervisor App**. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. Click **Enroll Credential.**
   ![How to Enroll Badge and PIN using... - screenshot 1](/images/intercom/9046439/image-cebd7043.png)
3. Click **Enroll Badge.**
   ![How to Enroll Badge and PIN using... - screenshot 2](/images/intercom/9046439/image-5d434e06.png)
   The **Enroll For Badge Login** screen is displayed.
4. Enter **Employee ID**.

   <Note>
     **Note:** Employee ID is the primary ID of the employee in the **Tenant Admin Portal**. Select **Make Employee ID case sensitive** checkbox to enable case sensitivity for Employee ID. (Optional)
   </Note>

5. Click **Continue**.
   ![How to Enroll Badge and PIN using... - screenshot 3](/images/intercom/9046439/image-ae567c2b.png)
   The Scan Your Badge screen is displayed.
6. Do the following:
   1. Scan your badge in the Badge Reader.
      The scanned badge number is automatically populated in the Scan Badge field.
   2. Click **Submit**.
      ![How to Enroll Badge and PIN using... - screenshot 4](/images/intercom/9046439/image-b2a694a5.png)

      <Note>
        **Note:** If a PIN already exists for the user, the Edit PIN screen is displayed. Otherwise, the **Create PIN** screen is displayed.
      </Note>

7. Do one of the following:
   1. To update PIN, follow the screen instructions in the **Edit PIN** screen and click **Update**.

      <Note>
        **Note:** Click **Skip** to escape the step and the badge is enrolled successfully.
      </Note>

      ![How to Enroll Badge and PIN using... - screenshot 5](/images/intercom/9046439/image-ebc61741.png)
      **(OR)**
   2. To add a new PIN, follow the screen instructions in the **Create PIN** screen and click **Create**.
      ![How to Enroll Badge and PIN using... - screenshot 6](/images/intercom/9046439/image-94b6d4d2.png)
      Now, you have Badge and PIN enrolled successfully.
      ![How to Enroll Badge and PIN using... - screenshot 7](/images/intercom/9046439/image-06b3ea67.png)
