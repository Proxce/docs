## Introduction

The **rf IDEAS** settings allows the Tenant Admin to upload and manage **HWG (Hardware Configuration)** files for supported RFID readers used with the Supervisor App.

Uploading the correct HWG file ensures the RFID reader is configured correctly for badge enrollment and authentication. You can also download the currently configured HWG file for backup or reuse.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure a **Windows Login** application is created in the Tenant Admin Portal.
- Ensure the required HWG file is available before starting the upload.

### Steps to Upload HWG file

1. Log in to the Tenant Admin Portal.
   The Application Detail page is displayed.
2. Select the Windows Login application configured for the Supervisor App.
   ![How to Upload/Download HWG file in... - screenshot 1](/images/intercom/9215874/image-64e613ae.png)
   The Application Details page is displayed.
3. Go to **Configure** tab > **rf IDEAS**.
   ![How to Upload/Download HWG file in... - screenshot 2](/images/intercom/9215874/image-08ce80de.png)
4. Do the following:
   1. Select an **RFID reader type** from the RFID Reader Type drop-down list.
   2. Enter **Description**. (Optional)
   3. Click the upload area to browse for the HWG file, or drag and drop the file into the upload area.
   4. Click **Save**.

![How to Upload/Download HWG file in... - screenshot 3](/images/intercom/9215874/image-4f72fc70.png)

The HWG file is downloaded successfully.

![How to Upload/Download HWG file in... - screenshot 4](/images/intercom/9215874/image-70d07d60.png)

### Steps to Download HWG file

1. Log in to the Tenant Admin Portal.
   The Application Detail page is displayed.
2. Select the Windows Login application configured for the Supervisor App.
   ![How to Upload/Download HWG file in... - screenshot 5](/images/intercom/9215874/image-64e613ae.png)
   The Application Details page is displayed.
3. Go to **Configure** tab > click **rf IDEAS**.
   ![How to Upload/Download HWG file in... - screenshot 6](/images/intercom/9215874/image-08ce80de.png)
4. Click **Download File** to download the HWG file to your local device.
   ![How to Upload/Download HWG file in... - screenshot 7](/images/intercom/9215874/image-6e24bfcc.png)
   The application is updated successfully.
