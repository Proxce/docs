## Introduction

The **Activate Add/Delete Users** setting allows the Tenant Admin to grant Supervisors permission to add and delete users directly from the Supervisor App. When enabled, authorized Supervisors can manage users without requiring Tenant Admin intervention.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure Windows Login application is created in the Tenant Admin Portal. For more information, refer [Windows Login - How to create and configure Windows Login application in the Tenant Admin Portal](https://oloid.help/en/articles/9352266-windows-login-how-to-create-and-configure-windows-login-application-in-the-tenant-admin-portal)

## Steps to Enable the Add/Delete Users Privilege

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Enable Add/Delete Users in... - screenshot 1](/images/intercom/9127132/image-75c5736b.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Enable Add/Delete Users in... - screenshot 2](/images/intercom/9127132/1f307697-1ecf-47d1-8717-c15d424772b8-84107c5f.png)
   The **Tenant Settings** page is displayed.
4. Go to **Advanced** > click **Supervisor Privileges**.
   ![How to Enable Add/Delete Users in... - screenshot 3](/images/intercom/9127132/image-12622398.png)
5. Enable the **Add/Delete Users** toggle.
6. Click **Save.**

![How to Enable Add/Delete Users in... - screenshot 4](/images/intercom/9127132/image-e6e6cb63.png)

Now, the supervisor can manage users.

![How to Enable Add/Delete Users in... - screenshot 5](/images/intercom/9127132/image-e98e3b95.png)
