## Introduction

A user's PIN can be updated at any time to maintain security or comply with organizational policies. Admins and Supervisors can view the user's PIN details and update the PIN through the Supervisor App.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure at least one connection is configured for the selected application in the Tenant Admin Portal. For more information, refer: [How to Configure a Connection in the Tenant Admin Portal](https://oloid.help/en/articles/8305588-tenant-admin-portal-how-to-configure-a-connection-in-the-tenant-admin-portal)
- Ensure User is created. Refer: **[Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)**

## Steps to View and Edit PIN

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to View and Edit PIN - screenshot 1](/images/intercom/9116073/image-59796e96.png)
   The **Users** screen is displayed.
3. Select the user whose PIN you want to view or edit.
   ![How to View and Edit PIN - screenshot 2](/images/intercom/9116073/image-c0ca158b.png)
   The User details screen is displayed.
4. Select **PIN** tab >click the **Edit** icon.
   ![How to View and Edit PIN - screenshot 3](/images/intercom/9116073/image-dda7308a.png)
   The **Edit PIN** pop-up box is displayed.
5. Do the following:
   1. Enter your new PIN.
   2. Re-enter your new PIN.
   3. Enter one or more email addresses in the **Share PIN with** field to share the updated PIN. (Optional)
   4. Click **Update**.

![How to View and Edit PIN - screenshot 4](/images/intercom/9116073/image-33d111c1.png)

The user's PIN is successfully updated.

![How to View and Edit PIN - screenshot 5](/images/intercom/9116073/image-3a79cb35.png)
