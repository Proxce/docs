To view updates in Supervisor App :

1. Double-click on Supervisor app ![How to view updates in Supervisor App - screenshot 1](/images/intercom/9637783/image-05ca7bd9.png) icon.
   The app opens.
2. Select **Updates** in the bottom left.

   The **About Windows Passwordless** screen opens.
   ![How to view updates in Supervisor App - screenshot 3](/images/intercom/9637783/image-e66d7cb3.png)
   You can now view the latest updates of the Supervisor App.
