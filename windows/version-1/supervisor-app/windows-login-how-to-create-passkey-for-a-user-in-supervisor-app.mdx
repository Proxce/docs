## Introduction

The **Create Passkey** feature in the Windows Supervisor App allows authorized supervisors to generate and assign passkeys for users.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure you have Windows Pro Machine.
- Connect to OpenVPN.
- Ensure the user exists in the Tenant Admin Portal. Refer: [Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)

## Steps to Create Passkey in Windows Supervisor app

1. Log in to **Supervisor App**. For more, refer to[How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Supervisor App Home** screen is displayed.
   ![How to Create Passkey for a User in... - screenshot 1](/images/intercom/13842978/image-fee13d3a.png)
2. Click **User Management**
   The **Users** screen is displayed.
   ![How to Create Passkey for a User in... - screenshot 2](/images/intercom/13842978/image-63beb92e.png)
3. Select the appropriate **User.**
   The **User Details** screen is displayed.
   ![How to Create Passkey for a User in... - screenshot 3](/images/intercom/13842978/image-649c98e2.png)
4. Select **Passkey** > click **+ Passkey.**
   ![How to Create Passkey for a User in... - screenshot 4](/images/intercom/13842978/image-3459c379.png)
   The Create Passkey pop-up box is displayed.
5. Do the following
   1. Enter **Display Name.**
   2. **Domain Name** (System Default Domain name is selected)
   3. Enter **Username.**
   4. Select **Preferred Machine** from the Preferred Machine list. (System Default paired machine name is selected)
   5. Click **Generate.**

![How to Create Passkey for a User in... - screenshot 5](/images/intercom/13842978/image-12bd8373.png)

The Passkey is successfully generated.
