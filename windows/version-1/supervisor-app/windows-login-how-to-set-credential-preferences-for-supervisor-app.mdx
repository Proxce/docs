## Introduction

Credential preferences allow Tenant Admin to define the authentication methods that are available and prioritized in the Supervisor App. These preferences determine which credential types are presented during user enrollment and authentication workflows.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Set credential preferences for Supervisor App

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Set credential preferences for... - screenshot 1](/images/intercom/8803434/00261e12-a275-4034-8873-f95cb58818a2-911e4a8c.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Set credential preferences for... - screenshot 2](/images/intercom/8803434/677d626d-9265-484b-bfc9-5eb927c0d3a0-e089218c.png)
   The **Tenant Settings** page is displayed.
4. Click **Preferences**.
   ![How to Set credential preferences for... - screenshot 3](/images/intercom/8803434/image-5e24d0fc.png)
   The **Let's customize the portal for you** pop-up box is displayed.
5. Do the following:
   1. Select the preferred **Credentials** you want to use.
   2. Click **Next**.
      ![How to Set credential preferences for... - screenshot 4](/images/intercom/8803434/image-d91559fe.png)
   3. Select the **Primary Credentials**.
   4. Click **Save & Next**.
      ![How to Set credential preferences for... - screenshot 5](/images/intercom/8803434/image-fdfcf913.png)
   5. Select the **Use-cases** for which you intend to use the Oloid Portal.
   6. Click **Finish Setup**.

![How to Set credential preferences for... - screenshot 6](/images/intercom/8803434/image-91a0fe2a.png)

The selected credential preferences are applied successfully and are available for the configured use cases.

![How to Set credential preferences for... - screenshot 7](/images/intercom/8803434/image-df4362e4.png)
