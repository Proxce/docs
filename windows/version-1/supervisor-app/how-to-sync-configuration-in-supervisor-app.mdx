To sync configuration:

1. On the admin home page, select **Settings**.
   ![How to sync configuration in Supervisor... - screenshot 1](/images/intercom/9329264/image-9d7d3a71.png)
2. Select **Sync Configuration**.
   ![How to sync configuration in Supervisor... - screenshot 2](/images/intercom/9329264/image-126fb59b.png)
   The Syncing Configuration is initiated.
   ![How to sync configuration in Supervisor... - screenshot 3](/images/intercom/9329264/image-78e1395f.png)
   The Supervisor App configuration is updated successfully.
   ![How to sync configuration in Supervisor... - screenshot 4](/images/intercom/9329264/image-04b56aa8.png)
