## Introduction

This document provides instructions for enrolling a PC/SC badge to a user through the Supervisor App. The badge can be scanned using a connected PC/SC badge reader and enrolled directly from the user's Badge details.

## Prerequisites

- Ensure the endpoint is paired with the Windows Login application. For more information, refer: [Windows Login - How to manually pair the Supervisor App](https://oloid.help/en/articles/9059601-windows-login-how-to-manually-pair-the-supervisor-app)
- Log in to the Supervisor App using an Admin or Supervisor account. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
- Ensure the Badge option is enabled for the application in the Tenant Admin Portal to make the Enroll Badge option available in the Supervisor App. Refer to **[How to enable badge option for Supervisor App.](https://oloid.help/en/articles/9182568-how-to-enable-badge-option-for-supervisor-app)**
- Ensure a supported badge reader is connected to the system.
- Ensure the user exists in the Tenant Admin Portal. Refer: [Windows Login - How to Add a User](https://oloid.help/en/articles/9041346-windows-login-how-to-add-a-user)
- The badge must be assigned to the user. For more details, refer [Supervisor App: Assign Badge](https://oloid.help/en/articles/9115843-supervisor-app-assign-badge).
- The connection added to the application must be PC/SC Badge input enabled. For more details refer [How to add PC/SC Badge input enabled Connection to the Application in the Tenant Admin Portal](https://oloid.help/en/articles/11710522-how-to-add-pc-sc-badge-input-enabled-connection-to-the-application-in-the-tenant-admin-portal).

## Steps to Enroll PC/SC Badge

1. Log in to **Supervisor App**. For more, refer [How to log in to Supervisor App](https://oloid.help/en/articles/9037188-how-to-log-in-to-supervisor-app)
   The **Admin Home** screen is displayed.
2. On the Admin Home screen, select **User Management**.
   ![How to Enroll PC/SC Badge using... - screenshot 1](/images/intercom/11721445/image-54947bf1.png)
   The **Users** screen is displayed.
3. Select the user to view details.
   ![How to Enroll PC/SC Badge using... - screenshot 2](/images/intercom/11721445/image-e81c6294.png)
   The User details screen is displayed.
4. Select **Badge** tab.
5. Click **Scan Badge to Enroll.**
   ![How to Enroll PC/SC Badge using... - screenshot 3](/images/intercom/11721445/image-fbbb8f8b.png)
   The **Scan Badge to Enroll** pop-up box is displayed.
6. Tap the **Badge** on the **Reader** to scan it.

   <Note>
     **Note:** PC/SC Badge reader must be connected to the system.
   </Note>

7. Click **Create**.
   ![How to Enroll PC/SC Badge using... - screenshot 4](/images/intercom/11721445/image-56961ad8.png)
   The **Badge** is enrolled successfully.
   ![How to Enroll PC/SC Badge using... - screenshot 5](/images/intercom/11721445/image-21a2f345.png)
