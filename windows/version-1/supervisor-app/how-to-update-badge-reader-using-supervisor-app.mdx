To update badge reader:

1. On the **Admin Home** screen, select **Settings**.
   ![How to update Badge Reader using... - screenshot 1](/images/intercom/9069684/image-6e347c70.png)
2. Select **rf IDEAS Reader Update**.
   ![How to update Badge Reader using... - screenshot 2](/images/intercom/9069684/image-16bd39ac.png)
3. Do one of the following:
   1. Upload Manually
   2. Select uploaded file
      The file is uploaded and the badge reader is updated.

## Upload Manually

1. Select **Upload Manually** on the screen.

   <Note>
     **Note:** The badge reader must be connected to the system.
   </Note>

   ![How to update Badge Reader using... - screenshot 3](/images/intercom/9069684/image-ad10acab.png)
2. Click **Program Reader**.
3. Click or drag and drop to upload the .hwg file.
   ![How to update Badge Reader using... - screenshot 4](/images/intercom/9069684/image-77651870.png)
4. Click **Upload File**.

<Note>
  **Note:** You can download the .hwg file from Oloid Portal. For more details, refer [How to download HWG file in Oloid Portal](https://oloid.help/en/articles/9215874-how-to-upload-download-hwg-file-in-oloid-portal#h_ca6c18bb99).
</Note>

The badge reader is updated with the latest configuration.

![How to update Badge Reader using... - screenshot 5](/images/intercom/9069684/image-026756f9.png)

## Select uploaded file

1. Select the uploaded .hwg file.
   1. **Note:** The badge reader must be connected to the system.
      ![How to update Badge Reader using... - screenshot 6](/images/intercom/9069684/image-a8b27286.png)
2. Click **Program Reader**.
   The badge reader is updated with the latest configuration.
   ![How to update Badge Reader using... - screenshot 7](/images/intercom/9069684/image-026756f9.png)
