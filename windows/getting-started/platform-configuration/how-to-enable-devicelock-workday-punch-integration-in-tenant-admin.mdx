**Steps to enable Workday Punch Integration:**

1. Log in to the **Tenant Admin Portal**. For more details refer [How to log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).
2. On the homepage of the portal, click the preferred application from the application list.
   ![How to enable DeviceLock Workday Punch... - screenshot 1](/images/intercom/11532508/image-3c3c4a2e.png)
3. Go to **Configure** tab > click **Configure Passwordless** from the left menu panel.
   ![How to enable DeviceLock Workday Punch... - screenshot 2](/images/intercom/11532508/image-d03d05d1.png)
4. Turn on **Enable Passwordless Config** toggle > select **Passwordless Login**
   ![How to enable DeviceLock Workday Punch... - screenshot 3](/images/intercom/11532508/image-d2e60df6.png)
5. Turn on **Workday Punch Integration** toggle > click **Save**.
   ![How to enable DeviceLock Workday Punch... - screenshot 4](/images/intercom/11532508/image-d4d4b693.png)
   The Workday punch integration is enabled successfully.
   ![How to enable DeviceLock Workday Punch... - screenshot 5](/images/intercom/11532508/image-ea775ad4.png)
