## Introduction

Tenant Admin or Supervisor can assign a PIN for users directly in the DeviceLock app through admin mode. Once enrolled, the PIN is linked to the user’s profile and can be used for authentication purpose, providing an additional or alternative login method to access the device.

## Steps to enroll PIN

1. Log in to the admin mode in **DeviceLock App.** To log in refer[How to log in to admin mode in DeviceLock App](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-devicelock-app).
2. Go to **Users** tab > select the preferred user.
   ![How to assign a PIN for Users in the... - screenshot 1](/images/intercom/12157257/image-44c99956.png)
3. Go to **PIN** tab > tap **Add** PIN.
   ![How to assign a PIN for Users in the... - screenshot 2](/images/intercom/12157257/image-825097d6.png)
   The **create PIN** pop-up box is displayed.
4. Do the following:
   1. Enter the **PIN**.
   2. Re-enter the **PIN**.
   3. Enter recipient email ID to share the **PIN**.
   4. Tap **Create**.

      <Note>
        **Note:** The PIN can be configured as a **4-digit**, **6-digit**, or **open (alpha- numeric) PIN** from the Tenant Admin Portal.
      </Note>

      ![How to assign a PIN for Users in the... - screenshot 3](/images/intercom/12157257/image-7a8f1d56.png)
      The PIN is successfully enrolled.
