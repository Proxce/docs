## Introduction

The **Theme** tab in the Tenant Admin Portal for **DeviceLock App** allows admin to customize the app’s appearance to match their organization’s branding.

## Prerequisite

You must create DeviceLock Application. To create, refer [How to create and configure Device Lock application](https://oloid.help/en/articles/8698213-how-to-create-and-configure-device-lock-application).

## Steps to configure Theme Tab

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click the **Device Lock Application** to be configured.
   ![How to Configure Theme Tab for... - screenshot 1](/images/intercom/10009894/image-69ddfb5a.png)
   The **Device Lock Application details** page is displayed.
3. Go to **Theme** tab.
   ![How to Configure Theme Tab for... - screenshot 2](/images/intercom/10009894/image-eeab7200.png)
   The theme tab is displayed.
   ![How to Configure Theme Tab for... - screenshot 3](/images/intercom/10009894/image-d68e6bfe.png)
4. Do the following:
   1. Edit Customer logo.

      <Note>
        **Note:** The maximum file dimensions for the logo are **264x72 px**, with a maximum size of **1 MB** in **PNG** format.
      </Note>

      ![How to Configure Theme Tab for... - screenshot 4](/images/intercom/10009894/image-5ef153f0.png)
   2. **Background Image:** Do one of the following:
      1. Edit Background image.

         <Note>
           **Note:** The maximum file size is **2 MB** (JPG, PNG, JPEG). This image is used as the widget background.
         </Note>

         or
      2. Select **Solid Background** option > enter color code.
         ![How to Configure Theme Tab for... - screenshot 5](/images/intercom/10009894/image-758b5aec.png)
   3. **Foreground Color:** Select **Solid Background** option > enter color code.
   4. **Primary Color/Button Default:** Update the primary color code to define the primary button's default background and its hover-state text color.
   5. **Secondary Color/Hover State:** Update the secondary color code to define the primary button's hover background and its default text color.
   6. **Customize Heading:** Update the heading that appears at the top of the screen.
   7. **Heading Text Color:** Update the text color code of the screen heading.
   8. **Widget Header/Footer Color:** Update the background color for the Widget's header and footer.
   9. **Footer Text Color:** Update the footer text color code in Login App.
   10. **Enable Help-text:** Turn on **Enable Help-text** toggle and then enter the help text to display on the **Identity Selection** screen.

       <Note>
         **Note:** The help text is displayed only on the **Identity Selection** screen and must not exceed **100 characters**.
       </Note>

       ![How to Configure Theme Tab for... - screenshot 6](/images/intercom/10009894/image-4b371dc5.png)
5. (Optional) In the **Preview** section, select one of the following tabs to preview the theme configuration:
   1. **Identity Selection:** Preview the appearance of the identity selection screen displayed before user authentication.
   2. **Authentication:** Preview the authentication screen displayed when users authenticate using their configured credentials.
   3. **Error:** Preview how error messages and error screens are displayed to users during authentication failures.
      ![How to Configure Theme Tab for... - screenshot 7](/images/intercom/10009894/image-3a4e2ffa.png)
6. Click **Deploy**.
   ![How to Configure Theme Tab for... - screenshot 8](/images/intercom/10009894/image-ac9ef156.png)
   The **Confirm Update** pop-up box is displayed.
7. Click **Update**.
   ![How to Configure Theme Tab for... - screenshot 9](/images/intercom/10009894/image-edd2d88a.png)
   The DeviceLock theme tab is updated successfully.
