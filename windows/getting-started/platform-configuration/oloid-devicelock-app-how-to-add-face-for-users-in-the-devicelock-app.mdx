## Introduction

This feature of Oloid DeviceLock app allows the user in tenant admin mode to add face using the app.

## Prerequisite

You must have Admin account to add a user.

## Steps to Add Face

1. Log in to the Admin mode in **DeviceLock App.** To log in refer[How to log in to admin mode in DeviceLock App](https://oloid.help/en/articles/10353022-how-to-log-in-to-admin-mode-in-devicelock-app).
2. Go to **Users** tab > select the preferred user.
   ![How to Add Face for Users in the... - screenshot 1](/images/intercom/12156735/image-4a696ad8.png)
   The user details screen is displayed.
3. Tap **Submit Consent**.
   ![How to Add Face for Users in the... - screenshot 2](/images/intercom/12156735/image-1c5331f9.png)
   The user consent screen is displayed.
4. Tap **Accept**.
   ![How to Add Face for Users in the... - screenshot 3](/images/intercom/12156735/image-9b16cb7e.png)
   The Consent is submitted successfully.
   ![How to Add Face for Users in the... - screenshot 4](/images/intercom/12156735/Screenshot_20250927_094918_Oloid-DeviceLock-f39d587a.jpg)
5. Tap **Add Face**.
   ![How to Add Face for Users in the... - screenshot 5](/images/intercom/12156735/image-87e941c4.png)

To add a face, position your face in front of the camera and tap the **Capture** button.

<Note>
  **Note:** If you do not tap the **Capture** button, the app automatically captures your face after a few seconds.
</Note>

![How to Add Face for Users in the... - screenshot 6](/images/intercom/12156735/image-00f24553.png)

Face is added successfully.
