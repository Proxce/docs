# **Introduction**

 

 

# **Prerequisites**

- You must have a Tenant Admin account.
- OKTA IDP must be created for the application. To create, refer [How to create IDP Profile for OIDC-Okta in the Tenant Admin Portal](https://oloid.help/en/articles/9214537-how-to-create-idp-profile-for-oidc-okta-in-the-tenant-admin-portal)

 

# **Steps to Configure App Settings**

1.  Login to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Profile icon** on the bottom left corner of the menu panel.
   ![](https://downloads.intercomcdn.com/i/o/e4gi378c/1692077209/a1e72bdb2540730f0fb5f0f15d20/image.png?expires=1794052800&amp;signature=351ea70305dcdf8ce5f81357ac37e5e98f12d9c729a89c09c3e8458595632841&amp;req=dSYuFMl5moNfUPMW3nq%2BgdkTF8ZVjf4mlNuIN%2BGMd2%2BfWd2Bhd1vWqieFNeT%0A6dK9ivJd4I3A%2BZKNIoXiJ9pjwvg%3D%0A)

   The user profile menu is displayed.
3. Click **Tenant** **Settings**.
   ![](https://downloads.intercomcdn.com/i/o/e4gi378c/2018775473/468d48ed586c44016587b0ae3ce0/image.png?expires=1794052800&amp;signature=c60f822aedcbb8221599d2d3c5d45aef4e1d8c37cc33803517af60187dfdc868&amp;req=diAmHs55mIVYWvMW3nq%2BgYaaye1zlelNqtFmq5ReOSHq3j2xHaXrJnFVbHWP%0ADRw0gnzytzCiS28%2Brr9LFcWikO4%3D%0A)

   The **Tenant Settings** page is displayed.
4. On Tenant Settings page > click **App Settings**.
5. Do the following: 

   Admin Portal/Platform

   [User Portal](https://oloid.help/en/articles/18171974-tenant-admin-portal-how-to-configure-app-settings#h_602bbfb207)

   [Workflow](https://oloid.help/en/articles/18171974-tenant-admin-portal-how-to-configure-app-settings#h_09415cb89b)

   [Oloid Vaults](https://oloid.help/en/articles/18171974-tenant-admin-portal-how-to-configure-app-settings#h_1216f6ba30)

   [Enterprise App Catalog](https://oloid.help/en/articles/18171974-tenant-admin-portal-how-to-configure-app-settings#h_1079d8ac9c)

   [Windows App](https://oloid.help/en/articles/18171974-tenant-admin-portal-how-to-configure-app-settings#h_a1dedcbd03)
6. Click **Save.**
