# **Introduction**

Tenant Admin can create and configure a WebKey application from the Tenant Admin Portal to define authentication methods, customize the login experience, and control security and session behavior.

# **Prerequisite**

- You must have access to the Tenant Admin portal.

# **Steps to create and configure WebKey application**

1. Log in to the **Tenant Admin Portal**. For more details refer [<u>How to log in to the Tenant Admin Portal</u>](https://oloid.help/en/articles/8462765-how-to-log-in-to-the-tenant-admin-portal).
2. On the **Applications** page, click **Create Application** in the top right corner.
   ![](https://downloads.intercomcdn.com/i/o/e4gi378c/1610813447/2c0d4a697f64add9be5fc5d410f9/image.png?expires=1793952900&amp;signature=412349a00ec3a49c48cb64907de1f4f258a7334b4e5948faa8774bcf476029b0&amp;req=dSYmFsF%2FnoVbXvMW1HO4zfoF70M%2BX2Q4vFUFHY%2BC6dql%2FwHW6PxoDExYHkfq%0AqG9l%0A)

   The **Create New Application** pop-up box is displayed.
3. Do the following:
   1. Enter **Application Name** and select **Application Type** as **Passwordless**.
      ![](https://downloads.intercomcdn.com/i/o/e4gi378c/1610820929/45cd63a7cac32d1a7c5042f881aa/image.png?expires=1793952900&amp;signature=ac1d514ba80e247c6da2d4cf79d31b7567f35c358ae57af313fe90dc1fd7d14c&amp;req=dSYmFsF8nYhdUPMW1HO4ze%2B%2F8tkg1%2F7PP4EyyqHSo0V8GOmfwvRamYrxzTGL%0AAP4%2F%0A)
   2. Click **Next**.

      The **Select Passwordless Use Case** page is displayed.
   3. Select **WebKey** > click **Create**.
      ![](https://downloads.intercomcdn.com/i/o/e4gi378c/1610823555/51a280b64841b9aec43700bca01c/image.png?expires=1793952900&amp;signature=50a21f41d7069057d92cda8494bfea22fa2ba436df2ecbd000ff0071ec8adab5&amp;req=dSYmFsF8noRaXPMW1HO4zaiQFmLcb7LkvfnO0%2F0Q9XHMOvKS1ZkAWX1mQ2AH%0AxVBu%0A)

   The Application is created successfully.
   ![](https://downloads.intercomcdn.com/i/o/e4gi378c/1947870080/c1efd45846e96daec8e412051c9f/image.png?expires=1793952900&amp;signature=0ce7ac0fc253cb295c255c86b82607619a73c0574feadd06801317fa82797ede&amp;req=dSkjEcF5nYFXWfMW1HO4zTq6pa21eJ%2Fz%2B2hLAQkuwVmD8Z8LLcjcBKDWPkGa%0ANJWf%0A)

   1. [<u>Configure Details tab</u>](https://oloid.help/en/articles/8693859-webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal#h_d6f1c16aee)

**Note**: These are one-time settings and all the default settings are recommended.

### **Credentials**

#### **Face**

To use face as credential, enable **Face** option.

![](https://downloads.intercomcdn.com/i/o/e4gi378c/1963739766/fedd0e94f595530334fddc7081fa/image.png?expires=1793952900&amp;signature=fb6f9484cfe85d8047a20786cd16ccd5ff617524e7d475fd081087c86ea418e7&amp;req=dSkhFc59lIZZX%2FMW1HO4zfazqze%2B5KPwVvdP5ujkCxoVbKuPFSEF%2B9Dkp%2FJS%0AKFjGiKStj46rTS%2Fc9Qk%3D%0A)

The **Advanced Settings** section is displayed.

1. Enable **Take Re-consent During Transactions** to show the re-consent form to users with invalid consent during every face authentication until they re-sign.
2. Select **Face Capture Mode** from the dropdown.
   1. The **Precision Capture (Default)** mode provides balanced performance across most environments. It delivers an optimal combination of speed, image quality, and reliable auto-capture.

      (or)
   2. The **Precision Capture X** mode offers enhanced performance and adaptability. It provides faster processing, improved image quality, and advanced auto-capture powered by machine learning.
3. Configure **Face Match Parameters**, and **Liveliness Check Parameters** on the Advanced Settings page.

**Note**: The parameters are pre-configured. This is done by Oloid admin.<br />​

Configure the following:

- [<u>Face Match Parameters</u>](https://oloid.help/en/articles/8693859-webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal#h_cf23cec68b)
- [<u>Liveliness Check Paraments</u>](https://oloid.help/en/articles/8693859-webkey-how-to-create-and-configure-a-webkey-application-in-tenant-admin-portal#h_83c7944b44)

#### **Face Match Parameters**

**Note:** You must consult your Oloid representative before making any changes to the **Face Match Parameters** to ensure optimal authentication performance.

1. Turn on **Strict Error Handing** toggle to skip the error and perform a direct one-to-one face match.
2. Turn on **Enable Virtual Camera** to allow third-party virtual camera app to be used for face capture. If a user attempts to spoof the system using a third-party app, this feature helps detect and flag potential spoofing attempts.
3. Turn on **Additional Face Match** toggle to perform a one-to-one face match alongside the standard face matching process.
4. Adjust the **Face Match Threshold** slider or enter a value directly into the input box to set the face match threshold value.

![](https://downloads.intercomcdn.com/i/o/e4gi378c/1618921310/9b1ebc1c5520f1987d9992675463/image.png?expires=1793952900&amp;signature=882fe9ce00fdf7956a9cc94bcfe5480db3fb0838ac9d88c2a116ce776ec89e4a&amp;req=dSYmHsB8nIJeWfMW1HO4zaiJbxbm%2F4XFM2AwRu96AZ8Ef4%2F1%2FrF8xxjoiepG%0APSG8KaTv1jaJKdW52U8%3D%0A)

#### **Liveness Check Parameters**

**Note:** You must consult your Oloid representative before making any changes to the **Liveness check parameters** value to ensure optimal authentication performance.

1. **Min Liveness Probability**: Specifies the threshold used to determine whether an image is live or spoofed.
   1. Default value: 0.5
   2. Images with a liveness probability of **0.5 or higher** are classified as live.
2. **Min Liveness Quality**: Specifies the minimum quality required for an image to be suitable for a liveness check.
   1. Default: 0.1
   2. Images with a quality score of **0.1 or higher** are considered suitable for liveness verification.

![](https://downloads.intercomcdn.com/i/o/e4gi378c/1551194611/09dbef154d9cc94d2ed7ed5de12f/de4c4faf-cbd9-475f-a84d-92435494c0ec?expires=1793952900&amp;signature=0f0dc54a60ca90bb42a7b6d210b28a3d731a15bd05d2b60d1a7b084b67e3510e&amp;req=dSUiF8h3mYdeWPMW1HO4zQI4XO9QZMGW8HJPVSlja4%2B1dBI6%2FhEwKXZFVtj9%0ABKKChSxze9e4mGTaN2g%3D%0A)

#### **NFC/ID**

To use NFC/ID credential, enable **NFC/ID** to sign in to WebKey application from your desktop/laptop.

The **NFC/ID option** section is displayed.

Do the following:

1. Enable **Use Web-NFC** to allow NFC Login from the Mobile Phone and Tablet browser that supports NFC (such as Google Chrome on Android)
2. Enable **Replace the Credential Label - NFC Tag** to replace the default **"NFC"** or **"NFC Tag"** label with a custom name.
3. Enter the new label in the **Replace label with** field. Example: Replace **NFC Tag** with **RFID**.
4. Provide **NFC Scan Instruction** to guide users on scanning their NFC badge for login.
5. **Authentication Success Message**: Enter a message to display when authentication is successful.
6. **Authentication Failure Message**: Enter a message to display when authentication fails.
   ![](https://downloads.intercomcdn.com/i/o/e4gi378c/1963746693/6c2173934a4319fe61b11363b38b/image.png?expires=1793952900&amp;signature=59e396c9a36984cd9065af4d1a8b66c78a9c3a95e6269926ffdbbf9ed4471a7e&amp;req=dSkhFc56m4dWWvMW1HO4zZcZK%2BWqw8RI610%2BB8F0W1LphU0zIieQa89i2RxH%0AG6NV%0A)

## **Design Configure tab**

You can set up the configure tab by configuring browser settings and customizing button labels.

### **Configure Settings tab**

![](https://downloads.intercomcdn.com/i/o/e4gi378c/1893692023/554cc2101b6df0747168f65e1d3b/image.png?expires=1793952900&amp;signature=30d0015c4183d978fcb4fecefca70c54821a56d611ed71fcc2958f6eca2fafc6&amp;req=dSguFc93n4FdWvMW1HO4zSY4rKrlgCL0k0DL52gF558TjgloLCF8QpWlM134%0Ayrf0ItK1iR8yzJulpzs%3D%0A)

**Do the following:**

1. Enable **Inactivity Session Time Out** toggle button to automatically return to the previous screen if credential capture fails within the set time-out duration.
2. Enable **Auto-Authentication using Local transactions** toggle button will allow user to auto-authenticate into Webkey after device login.
3. Enable **Continue Without Local Transaction** toggle button will allow user to authenticate manually without giving an error if local authentication transaction is not found.

### **Client Authentication**

1. **Enable** **Custom User Agent** to allow users to log in to WebKey app from custom browsers.
2. Select **Enable Browser Fingerprint** to allow WebKey login to function only on registered browsers.

   Do one of the following:
   1. Select **\+ Browser Fingerprint** to manually add browser fingerprint.
   2. Select **Transactions** > **Action** dropdown > **Add Browser Fingerprint to Application**. For more information, see [<u>How to configure Browser Fingerprint for WebKey</u>](https://oloid.help/en/articles/9545445-how-to-configure-browser-fingerprint-for-webkey)
   3. Click **Save**.
   4. Select **Add Device** to register devices for Webkey Login. Refer: [<u>How to configure Custom User Agent in WebKey Application</u>](https://oloid.help/en/articles/11659241-how-to-configure-custom-user-agent-in-webkey-application)

#### **Enable Custom Button in Authentication Flow**

This option allows you to add a custom button to the authentication screen and define its behaviour based on user interaction.

![](https://downloads.intercomcdn.com/i/o/e4gi378c/2221437718/02af348d5a5cf2362741cef67366/image.png?expires=1793952900&amp;signature=92e4d7ca4eadda7d0071806c25d641c4dd74c626579c0b338d1275332ef12ad9&amp;req=diIlF819moZeUfMW1HO4zcwG1qyOVbEJK7q0ejRep0hnjfEvdBD4Ibp9z3BB%0AHuuDsHIifIBgOnqehC0%3D%0A)

To configure Custom Button in Authentication Flow do the following:

1. Turn on the **Enable Custom Button in Authentication Flow** toggle.
2. **Button Label**<br />Enter the text to be displayed on the custom button in the authentication page.<br />​_Example: Back_
3. **Redirect URL**<br />Enter the URL where the user will be redirected when the custom button is clicked.
4. **Show button only on authentication failure page**<br />Select this checkbox to display the custom button **only when authentication fails**.<br />If not selected, the button will be visible on the main authentication screen.
5. Click **Save**.

   The Custom button is enabled for authentication flow.
