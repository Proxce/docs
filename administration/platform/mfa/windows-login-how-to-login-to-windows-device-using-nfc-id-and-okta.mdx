## Introduction

The Windows Login app allows users to securely sign in to their Windows devices using NFC/ID and OKTA authentication. This passwordless, multi-factor login method provides a faster and more secure way to access devices.

## Prerequisites

- An NFC ID must be assigned to you.
- You must have access to a registered mobile device where the OKTA app is installed and enrolled for your user account.

  <Note>
    **Note:** If you don't see the login option reach out to [Oloid Support](mailto:support@oloid.ai).
  </Note>

## Steps to sign in to Windows Device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.
      ![How to Login to Windows Device using... - screenshot 1](/images/intercom/13374332/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)
      The Windows login app is displayed.
   2. Select **Windows login app**.
      ![How to Login to Windows Device using... - screenshot 2](/images/intercom/13374332/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)
   3. Select **Login with OLOID**.
      ![How to Login to Windows Device using... - screenshot 3](/images/intercom/13374332/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)
      The **Tap NFC Tag at the device** screen is displayed.
2. Tap the **NFC Tag** on the **Reader** to scan it.
   ![How to Login to Windows Device using... - screenshot 4](/images/intercom/13374332/image-6a2b5884.png)
3. The **OKTA Authentication** pop-up box is displayed.
   ![How to Login to Windows Device using... - screenshot 5](/images/intercom/13374332/image-2487cd61.png)
   The Push notification is displayed in your registered device.
4. Tap **Yes, It's me**.
   ![How to Login to Windows Device using... - screenshot 6](/images/intercom/13374332/974b5af6-a4be-4b76-9680-5575aab36c4d-7cbf6319.png)
   The Authentication Approved screen is displayed.
   ![How to Login to Windows Device using... - screenshot 7](/images/intercom/13374332/image-bf58d769.png)
   The **Choose Your Account** pop-up box is displayed.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, they can select a specific account to sign in. If the user has only one account configured, **Choose Your Account** pop-up box will not be displayed.
   </Note>

5. Select the account to sign in.
   ![How to Login to Windows Device using... - screenshot 8](/images/intercom/13374332/image-5bf9cf7f.png)
   You are signed in to the Windows device successfully.
