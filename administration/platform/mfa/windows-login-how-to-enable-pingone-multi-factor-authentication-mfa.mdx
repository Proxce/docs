## Introduction

The PingOne feature in the Tenant Admin Portal allows admins to enable PingOne as a second factor authentication for the Windows Login application. When enabled with other primary factors, users can log in to endpoints using PingOne credentials as a second factor.

## Prerequisite

You must have a **Tenant Admin access** in the Tenant Admin Portal.

## Steps to Enable PingOne MFA

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, select the Windows Login application.
   ![How to Enable PingOne Multi Factor... - screenshot 1](/images/intercom/12888354/image-54b04fd4.png)
   The application page is displayed.
   ![How to Enable PingOne Multi Factor... - screenshot 2](/images/intercom/12888354/image-48411548.png)
3. Go to the **Authenticato**r tab > **MFA Credential** > turn on **PingOne** toggle.
   ![How to Enable PingOne Multi Factor... - screenshot 3](/images/intercom/12888354/image-1b082e95.png)
   The PingOne MFA credential is enabled successfully.

   <Note>
     **Note:** You must do the [Sync Configuration](#sync-configuration-to-apply-changes) to apply changes.
   </Note>

   ![How to Enable PingOne Multi Factor... - screenshot 4](/images/intercom/12888354/image-54fdd766.png)

### Sync Configuration to Apply Changes

After enabling the **PingOne MFA credential**, you must sync the configuration in the **Supervisor App** to apply the changes. For detailed steps, see [How to sync configuration in Supervisor App](https://oloid.help/en/articles/9329264-how-to-sync-configuration-in-supervisor-app).
