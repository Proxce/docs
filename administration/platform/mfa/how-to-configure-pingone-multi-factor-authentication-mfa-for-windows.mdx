## Introduction

PingOne provides authentication and MFA capabilities that can be integrated with Oloid applications. Configuring PingOne allows admin to establish a secure environment, create applications, and enable MFA for users.

## Prerequisites

- You must have **admin access** to the **PingOne Identity Administrator Console**.
- You must have the **redirect URLs** from the Oloid team to complete the SSO configuration. If you don’t have the redirect URLs, contact [Oloid Support.](mailto:Support@oloid.ai)

### Steps to Create Environment

1. Sign in to the Ping Identity Administrator Console using your PingOne account credentials.
2. Go to **Environments** > **Environments+**.
   ![How to Configure PingOne Multi-Factor... - screenshot 1](/images/intercom/12958196/image-948b04a1.png)
   The Create Environment screen is displayed.
3. Select **Workforce Solution** and click **Next**.
   ![How to Configure PingOne Multi-Factor... - screenshot 2](/images/intercom/12958196/image-ef1d017a.png)
   The Workforce Solution page is displayed.
4. Click **Next**.
   ![How to Configure PingOne Multi-Factor... - screenshot 3](/images/intercom/12958196/image-136a8c9c.png)
   The Services page is displayed.
5. Enter the **Trial Environment Name** and click **Finish**.
   ![How to Configure PingOne Multi-Factor... - screenshot 4](/images/intercom/12958196/image-68e00e08.png)
   The Trial Environment is created and listed on the Environment list.
6. Click **Created Trial Environment.**
   ![How to Configure PingOne Multi-Factor... - screenshot 5](/images/intercom/12958196/image-35a52afd.png)
   The Environment details page is displayed.
7. Click **Manage Environment.**
   ![How to Configure PingOne Multi-Factor... - screenshot 6](/images/intercom/12958196/image-52f0110a.png)
   Environment is created successfully.

### Steps to Create Application

1. On PingOne home page, go to **Applications** > **Applications**.
   ![How to Configure PingOne Multi-Factor... - screenshot 7](/images/intercom/12958196/image-565d63c9.png)
   The Applications page is displayed.
2. Click **Application +**.
   ![How to Configure PingOne Multi-Factor... - screenshot 8](/images/intercom/12958196/image-83b83667.png)
   The Add Application page is displayed.
3. Do the following:
   1. Enter the **Application Name.**
   2. Select **Worker**.
   3. Click **Save**
      ![How to Configure PingOne Multi-Factor... - screenshot 9](/images/intercom/12958196/image-1820d05e.png)

The application is created successfully.

### Steps to Configure the Application

1. Enable the **Application** toggle.
   ![How to Configure PingOne Multi-Factor... - screenshot 10](/images/intercom/12958196/image-3499539d.png)
2. Setup the following tabs:
   1. Configure Roles Tab
   2. [Configure the Resources Tab](#steps-to-configure-the-resources-tab)
   3. Setup Configuration Tab

#### Steps to Configure the Roles Tab

1. On Application detail page, click **Roles > Grant Roles**.
   ![How to Configure PingOne Multi-Factor... - screenshot 11](/images/intercom/12958196/image-50318fab.png)
   The **Available responsibilities** tab is displayed.
   ![How to Configure PingOne Multi-Factor... - screenshot 12](/images/intercom/12958196/image-abd8bbe0.png)
2. Add the following roles from the Roles list.
   1. Environment Admin.
   2. Identity Data Admin.

      <Note>
        **Note:** Always click on **Select All**.
      </Note>

   3. Organization Admin.
   4. Click **Save**.
      ![How to Configure PingOne Multi-Factor... - screenshot 13](/images/intercom/12958196/image-a573e378.png)
      The Roles added successfully.
      ![How to Configure PingOne Multi-Factor... - screenshot 14](/images/intercom/12958196/image-4379dd24.png)

#### Steps to Configure the Resources Tab

1. On Application detail page, click on **Resources > Allowed Scopes Edit icon >** select **Email > Save**.
   ![How to Configure PingOne Multi-Factor... - screenshot 15](/images/intercom/12958196/image-541040e1.png)
   The Email is added in the allowed scopes list.
   ![How to Configure PingOne Multi-Factor... - screenshot 16](/images/intercom/12958196/976e3a0c-2a84-4c3f-8660-e18e7997014a-eb0f521b.png)

#### Steps to Setup the Configuration Tab

1. On Application detail page, go to **Configuration >** click **Edit** icon.
   ![How to Configure PingOne Multi-Factor... - screenshot 17](/images/intercom/12958196/image-ea2f87f8.png)
   The Edit Configuration page is displayed.
2. Do the following:
   1. Select **Code** as Response Type.
   2. On **Grant Type** select the following:
      1. Authorization Code.

         <Note>
           **Note:** PKCE Enforcement is set to ***Optional*** by default. Keep this setting as ***Optional***.
         </Note>

      2. Client Credentials.
   3. Enter the **Redirect URls**.
      1. The redirected URLs are added for the Tenant Admin Portal and Oloid User Portal.

         <Note>
           **Note:** To add more redirect URL, click **+ Add** to add another Sign-In Redirect URL field in this section.
         </Note>

         ![How to Configure PingOne Multi-Factor... - screenshot 18](/images/intercom/12958196/image-ad69613b.png)
         ![How to Configure PingOne Multi-Factor... - screenshot 19](/images/intercom/12958196/a2423736-951b-45bb-9134-95c615e0cf2e-903fc6f4.png)
   4. Click **Save**.
      The Application is configured Successfully.

#### Steps to Configure MFA Parameter in the Oloid Tenant Admin Portal

1. Click **Overview** and copy next to each of the following parameter and then add these values into the corresponding field in the Tenant Admin Portal.
   1. Environment ID.
   2. Client ID.
   3. Client Secret.
      ![How to Configure PingOne Multi-Factor... - screenshot 20](/images/intercom/12958196/image-96b3188a.png)
      To navigate the required fields, in the **Tenant Admin Portal,** go to **User Profile Icon > Tenant Settings > Security > API Token > 3rd Party Tokens > PingOne Configuration for MFA**, and enter the required parameter in the applicable fields.
      ![How to Configure PingOne Multi-Factor... - screenshot 21](/images/intercom/12958196/image-22177803.png)

### Steps to Create User

1. Go to **Directory > Users >** **Users +** > **Create User.**
   ![How to Configure PingOne Multi-Factor... - screenshot 22](/images/intercom/12958196/image-db418201.png)
   The Add user page is displayed.
2. Do the following:
   1. Enter **Username**.
   2. Enter **Email ID**.

      <Note>
        **Note:** Select the checkbox to verify the mail ID. A verification email is sent to the entered email ID after the checkbox is selected.
      </Note>

   3. Enter **Password** or click **Generate Password**.

      <Note>
        **Note:** When click on **Generate Password**, a temporary password is generated.
      </Note>

3. Click **Save**.
   ![How to Configure PingOne Multi-Factor... - screenshot 23](/images/intercom/12958196/image-df6251a4.png)
   The user is added successfully.
   ![How to Configure PingOne Multi-Factor... - screenshot 24](/images/intercom/12958196/image-9d97624f.png)
4. On User detail, click **API** and copy the **ID** value. Use this ID in the **Ping ID** field under **User Details** in the Tenant Admin Portal.
   ![How to Configure PingOne Multi-Factor... - screenshot 25](/images/intercom/12958196/04286579-95b6-4cf6-9861-72a9d4e9790f-316345ef.png)
   To navigate the Ping ID field, on **Tenant Admin Portal**, go to **Directory > Users > Select User > Other Identifier** section, enter the ID in the **Ping ID** field.

   ![How to Configure PingOne Multi-Factor... - screenshot 26](/images/intercom/12958196/image-5a03970d.png)
   The **ID** added successfully.

#### Steps to Setup the Multi Factor Authentication

1. Go to **Applications > PingOne Self-Service - MyAccount**.
   ![How to Configure PingOne Multi-Factor... - screenshot 27](/images/intercom/12958196/6388b6c5-9dc3-4556-88a0-c794ebc643f1-71943ed3.png)
   PingOne Self-Service - MyAccount page is displayed.
2. Copy the **Home Page URL** and open it in a web browser.
   ![How to Configure PingOne Multi-Factor... - screenshot 28](/images/intercom/12958196/ae1b9ce4-fba2-47da-98db-f2f954cefff6-e906bb2f.png)
   The PingOne Identity Screen is displayed.
3. Do the following:
   1. Enter **UserName**.
   2. Enter **Password**.

      <Note>
        **Note:** Use the password that you added/generated when creating the user account.
      </Note>

   3. Click **Sign On**.
      ![How to Configure PingOne Multi-Factor... - screenshot 29](/images/intercom/12958196/ae75d7d5-2516-41f1-8fbf-2c02009cd58e-dc71c7be.png)
      The **Change Password** screen is displayed.
4. Do the following:
   1. Enter the **Current Password** in the Current Password field.

      <Note>
        **Note:** Use the password that you added/generated when creating the user account.
      </Note>

   2. Enter **New Password** in the New Password field.
   3. Enter the **Password** in the Verify New Password field.
   4. Click **Save**.
      ![How to Configure PingOne Multi-Factor... - screenshot 30](/images/intercom/12958196/076bb7af-252a-4a0b-9f15-d04f39bb48c3-579e6ee2.png)
      The password is added successfully, and the Verification code screen is displayed.
5. Do the following:
   1. Enter the **Verification Code**.

      <Note>
        **Note:** The verification code is sent to your registered email address.
      </Note>

   2. Click **Verify**.
      ![How to Configure PingOne Multi-Factor... - screenshot 31](/images/intercom/12958196/5fd4c149-9190-4bf8-8242-5e04fc559ce2-00e0e2d4.png)
      The Pingone User Profile page is displayed.
6. Go to **Authentication** tab > click **Add Method**.
   ![How to Configure PingOne Multi-Factor... - screenshot 32](/images/intercom/12958196/image-2759d7a3.png)
   The **Select Method** screen is displayed.
7. Select **PingID Mobile Application.**
   ![How to Configure PingOne Multi-Factor... - screenshot 33](/images/intercom/12958196/42503f26-1ad2-4eef-a9cb-67caef6935ed-fb92a02b.png)
   Scan QR Code screen is displayed.
8. Open the PingOne application from your device and scan the QR Code.

   <Note>
     **Note:** Make sure that PingOne application is installed in your device.
   </Note>

   The PingOne MFA setup is configured successfully.
   ![How to Configure PingOne Multi-Factor... - screenshot 34](/images/intercom/12958196/image-af4610b7.png)
