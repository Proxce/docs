## Introduction

This document describes how to configure **OKTA Multi-Factor Authentication (MFA)** in the **Oloid Tenant Admin Portal**. Enabling OKTA MFA adds an additional verification step during login and requires configuring the necessary parameters from the **OKTA Administrator Console**.

## Prerequisites

- You must have **Tenant Admin access** in the Tenant Admin Portal.
- Ensure OKTA Multi Factor Authentication toggle is enabled in the Windows Login Application. To enable, refer [How to Enable OKTA MFA Credential for Windows Login Application in the Tenant Admin Portal](https://oloid.help/en/articles/12888385-how-to-enable-okta-mfa-credential-for-windows-login-application-in-the-tenant-admin-portal)
- Ensure Token ID is created. To create, refer [How to Create Token ID in OKTA for Windows Login Application](https://oloid.help/en/articles/13175430-how-to-create-token-id-in-okta-for-windows-login-application)

## Steps to Configure OKTA MFA

1. Log in to the Tenant Admin Portal.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Configure OKTA Multi-Factor... - screenshot 1](/images/intercom/13165352/image-810b567f.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Configure OKTA Multi-Factor... - screenshot 2](/images/intercom/13165352/image-34763926.png)
   The **Tenant Settings** page is displayed.
4. Click **Security > 3rd Party Tokens** > **OKTA Configuration for MFA**.
   ![How to Configure OKTA Multi-Factor... - screenshot 3](/images/intercom/13165352/image-22c29b96.png)
   OKTA Configuration for MFA screen is displayed.
5. Do the following:
   1. **Base URL:** Add the **Base URL** in the Base URL field.
   2. **Token ID:** Enter the Token ID in the Token ID field.
   3. Click **Save**.
      ![How to Configure OKTA Multi-Factor... - screenshot 4](/images/intercom/13165352/552a0148-292e-403d-9bdd-6d3e8f477432-a19a6836.png)
      To see the Token ID in **OKTA Administrator Console**, go to **Security** > **API** > **Tokens** tab.
      ![How to Configure OKTA Multi-Factor... - screenshot 5](/images/intercom/13165352/8bde72e0-37b8-4f98-a9cd-c9fedc77d614-4cb782d2.png)
      The OKTA Configuration for MFA is configured.
      ![How to Configure OKTA Multi-Factor... - screenshot 6](/images/intercom/13165352/image-b94c084a.png)
