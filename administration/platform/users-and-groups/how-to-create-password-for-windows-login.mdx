## Create Password for local windows machine

To create Password:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/8468581/56c94b21-cd31-458b-8455-80e4c9169014-23c997cb.png)
   The **Users** page is displayed.
3. Click **User Name** to edit.
   ![Image](/images/intercom/8468581/4d1b73b9-6eac-4ce0-a11b-4cafb69f828d-29eec622.png)
   The **User details** page is displayed.
   ![How to create Password for Windows Login - screenshot 1](/images/intercom/8468581/image-865b01f8.png)
4. Go to **Credentials** tab > **Windows Password** > **+ Create Password**.
   ![Image](/images/intercom/8468581/be820f3e-2f90-4602-b62a-1ca1a23dd7d6-8c000e8f.png)
   The **Create Windows Password** pop-up box is displayed.
   ![Image](/images/intercom/8468581/0fc07405-85b1-49a5-883e-2e845f06ab42-3e1a3bdd.png)
5. Do the following:
   1. Enter **Display Name** that displays on the Windows Login page.
   2. Select **Windows Local User** type from **Credential Type** dropdown list.
   3. Click **Next.**
      ![How to create Password for Windows Login - screenshot 2](/images/intercom/8468581/image-7b26a391.png)
   4. Enter **Machine Name**.

      <Note>
        **Note:** Enter your Windows device name.
      </Note>

   5. Enter **Username** of your Windows Login.

      <Note>
        **Note:** Username should be your Windows account name..
      </Note>

   6. Enter **Password** of your Windows Login.
   7. Click **Save**.
      The password is created and listed in the **Windows Passwords** tab.
      ![Image](/images/intercom/8468581/1922cc11-db92-4542-b285-02c52fa86b32-b01e10f3.png)

## Create Password for domain

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to create Password for Windows Login - screenshot 3](/images/intercom/8468581/image-3b224d1d.png)
   The **Users** page is displayed.
3. Click **User Name** to edit.
   ![Image](/images/intercom/8468581/3ece5174-9e96-4e1c-865f-a816ac16cfa0-404644c7.png)
   The User details page is displayed.
4. Go to **Credentials** tab> **Windows Passwords** > **Create Password**.
   ![Image](/images/intercom/8468581/1579848a-4aa8-4a76-8369-4b0a204bccb3-07af7ded.png)
   The **Create Windows Password** pop-up box is displayed.
5. Do the following:
   1. Enter **Display Name** that displays on the Windows Login page.
   2. Select **Windows Domain User** type from **Credential Type** dropdown list.
   3. Click **Next.**
      ![Image](/images/intercom/8468581/0fc07405-85b1-49a5-883e-2e845f06ab42-3e1a3bdd.png)
      The next screen is displayed.
      ![How to create Password for Windows Login - screenshot 4](/images/intercom/8468581/image-d427e9e6.png)
   4. Enter **Domain Name.**
   5. Select **Preferred Machine** from the **Preferred Machine(s)** list.
   6. Enter **Username** of your Windows Login.

      <Note>
        **Note:** Username should be your Windows account name.
      </Note>

   7. Enter **Password** of your Windows Login.
   8. Click **Save**.
      The password is created and listed in the **Windows Passwords** tab.
      ![Image](/images/intercom/8468581/c223346a-d3d3-42d4-8eaf-a58f9e25922f-2d73be6d.png)
