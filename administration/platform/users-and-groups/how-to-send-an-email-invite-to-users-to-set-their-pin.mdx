## Introduction

This document provides step-by-step instructions to send an email invitation that allows a user to set PIN through the Oloid Platform.

## Pre-requisite

The registered email ID must be added to the user's profile on the Oloid Platform.

## Steps to send invite to set Pin

1. Login to the **Tenant Admin Portal**.
2. On the homepage, click **Directory**, from the left menu panel.
   ![How to Send an Email Invite to Users to... - screenshot 1](/images/intercom/9937001/image-f58db00b.png)
   The **Users** page is displayed.
3. Click **username** to edit.
   ![Image](/images/intercom/9937001/9c57efb9-2990-4bb6-9643-e121736a2c85-9e3c67ff.png)
   The **user details** page is displayed.
4. Go to **Credentials** tab > **PIN** > **Send set PIN Email**.
   ![How to Send an Email Invite to Users to... - screenshot 2](/images/intercom/9937001/dc10dbf7-2f6c-4b77-83d3-a56a535cd92d-8cab5d83.png)
   The **Email Invitation Preview** pop-up box is displayed.
5. Do the following:
   ![How to Send an Email Invite to Users to... - screenshot 3](/images/intercom/9937001/image-ef7753cc.png)
   1. Enter email ID(s) and select from the dropdown to whom you want to send the mail in **Send Email to** field.
   2. Enter subject in **Email Subject** field.
   3. Enter a message in the **Email Body** field.
   4. Click **Send**.
      The invite to set PIN is sent to Email successfully.
      ![How to Send an Email Invite to Users to... - screenshot 4](/images/intercom/9937001/image-0914b23d.png)

The link navigates the user to the self-service portal where the user can set PIN.
