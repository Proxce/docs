**Steps to deactivate User:**

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to deactivate user in the Tenant... - screenshot 1](/images/intercom/8424258/image-74d8333d.png)
   The **Users** page is displayed.
3. Click Username to edit.
   ![How to deactivate user in the Tenant... - screenshot 2](/images/intercom/8424258/image-d0e4c382.png)
   The user details page is displayed.
4. On the top-right, go to **Action** > **Deactivate**.
   ![How to deactivate user in the Tenant... - screenshot 3](/images/intercom/8424258/image-b8d211f0.png)
   The **De-activate User** pop-up box is displayed.
   ![How to deactivate user in the Tenant... - screenshot 4](/images/intercom/8424258/image-c2250128.png)
5. Click **Confirm Deactivate**.
   The user is deactivated successfully.
   ![How to deactivate user in the Tenant... - screenshot 5](/images/intercom/8424258/image-2cd9be2c.png)
