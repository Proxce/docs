## Introduction

This document provides step-by-step instructions to add a face credential for a single user in the Tenant Admin Portal.

## Prerequisites

- You must have Tenant admin access to the Tenant Admin Portal.
- User must be created. For more, refer to[Tenant Admin Portal - How to Create User](https://oloid.help/en/articles/8185048-tenant-admin-portal-how-to-create-user)

## Steps to Add Face of a Single User

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Add Face of a Single User - screenshot 1](/images/intercom/8181773/image-dfd9789d.png)
   The **Users** page is displayed.
   ![Image](/images/intercom/8181773/97b7fe92-4793-4857-86a0-84b4bd021d43-ee9eae4e.png)
3. Click **username** to edit.
   ![Image](/images/intercom/8181773/81bc9c2a-f770-4ac1-98b0-cb2678ca6c59-119a32b2.png)
   The user details page is displayed.
   ![How to Add Face of a Single User - screenshot 2](/images/intercom/8181773/image-5a7301a6.png)
4. Do one of the following:
   1. Go to **Credentials** > **Face** > + **Add Face**.
      ![How to Add Face of a Single User - screenshot 3](/images/intercom/8181773/image-cc9be48b.png)
   2. Go to **Assign Credential** > **Add Face**.
      ![How to Add Face of a Single User - screenshot 4](/images/intercom/8181773/image-328b55b0.png)
      The **Upload Face** pop-up box to upload image is displayed.
5. Click or Drag and Drop an image to be uploaded.
   ![How to Add Face of a Single User - screenshot 5](/images/intercom/8181773/image-0b9c2f10.png)
6. Click **Upload**.
   ![How to Add Face of a Single User - screenshot 6](/images/intercom/8181773/image-44424af6.png)
   The user image is uploaded and listed on the **Face** tab.

   <Note>
     **Note:** You can add a maximum of five faces per user.
   </Note>

   ![How to Add Face of a Single User - screenshot 7](/images/intercom/8181773/image-94980b88.png)
