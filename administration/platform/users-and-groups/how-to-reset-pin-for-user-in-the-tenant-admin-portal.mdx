### Introduction

The Tenant Admin Portal allows Admin to reset a user’s PIN for secure login. Admin can either update the PIN directly or send a reset PIN email to the user. These options enable quick PIN recovery and help maintain uninterrupted user access.

## Steps to reset PIN

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Directory** on the left menu panel.
   ![How to reset PIN for User in the Tenant... - screenshot 1](/images/intercom/11928944/image-72fbd8d0.png)
   The **Users** page is displayed.
3. Click **user name** to edit.
   ![How to reset PIN for User in the Tenant... - screenshot 2](/images/intercom/11928944/image-83b849fd.png)
   The user details page is displayed.
4. Go to **Credentials** tab > select **PIN** from the left menu panel.
   ![How to reset PIN for User in the Tenant... - screenshot 3](/images/intercom/11928944/image-8cdd6831.png)
5. Do one of the following:
   a. **[Edit PIN](#edit-pin)**
   or
   b. **[Send reset PIN email](#send-reset-pin-email)**
   The pin is updated successfully.

## Edit PIN

1. Select **Edit** icon.
   ![How to reset PIN for User in the Tenant... - screenshot 4](/images/intercom/11928944/image-c2bc8a99.png)
   The **Add PIN** pop-up box is displayed.
2. On the pop-up box, do the following:
   1. Enter **new PIN**.
   2. Re-enter **new PIN**.
   3. Enter the recipient's email address to share the PIN.
   4. Click **Save**.
      ![How to reset PIN for User in the Tenant... - screenshot 5](/images/intercom/11928944/image-5c7351b3.png)
      The PIN is reset successfully.
      ![How to reset PIN for User in the Tenant... - screenshot 6](/images/intercom/11928944/image-1f1dae2d.png)

## Send reset PIN email

1. Select **Send Reset PIN Email**.
   ![How to reset PIN for User in the Tenant... - screenshot 7](/images/intercom/11928944/image-9ef3b701.png)
   The **Email Invitation Preview** pop-up box is displayed.
2. On the pop-up box, do the following:
   1. Enter recipient email address.

      <Note>
        **Note:** The registered email ID will appear as the default.
      </Note>

   2. Enter **Email Subject**.
   3. Enter message in the **Email Body**.
   4. Click **Save**.

      <Note>
        **Note:** The user portal link will be auto-attached to the email.
      </Note>

      ![How to reset PIN for User in the Tenant... - screenshot 8](/images/intercom/11928944/image-6d2360c1.png)

The PIN reset email is sent successfully.

The user can follow the on-screen instructions in the email to reset the pin.
