Steps to enroll user using badge scan:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/8937141/52e474e3-80d6-42f8-ba8f-5295a5fc22a9-2de4839c.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![Image](/images/intercom/8937141/997ada76-3fc9-453a-8ce8-502cffede79a-c86d080c.png)
   The **user details** page is displayed.
   ![How to enroll users using badge scan in... - screenshot 1](/images/intercom/8937141/image-95822c44.png)
4. Go to **Credentials** tab > **Badge** > **+ Scan Badge to Enroll**.
   ![Image](/images/intercom/8937141/b1ce04cd-9be8-4617-bb30-f79679021359-ecbfb0ef.png)
   The **Scan your Badge to Enroll** pop-up box is displayed.
   ![How to enroll users using badge scan in... - screenshot 2](/images/intercom/8937141/image-b36e4664.png)
5. On the pop-up box, do the following:
   1. Select the badge setting as configured in the badge reader.
   2. Enter your badge ID by scanning your badge or manually type it in the **Scan or Type Data** field.

      <Note>
        **Note:** To scan the badge, card reader should be connected to your device.
      </Note>

   3. Enter the bits in the **Number of Bits** field. (Optional)
   4. Click **Save**.
      The badge is assigned to the user and listed on the badge tab.
      ![How to enroll users using badge scan in... - screenshot 3](/images/intercom/8937141/image-2888a234.png)
