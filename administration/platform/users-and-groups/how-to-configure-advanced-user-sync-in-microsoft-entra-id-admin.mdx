## Introduction

This document explains how to register and configure an application in **Microsoft Entra ID** and enable **FIDO2 (Passkey)** authentication for integration with the Tenant Admin Portal.

## Prerequisite

You must have Tenant Admin Access for Microsoft Entra ID.

## Steps to Configure Microsoft Entra ID for Advanced User Sync

1. [Register an Application](#register-an-application)
2. [Configure the Application](#configure-the-application)
3. [Create Client Secret](#create-client-secret)
4. [Enable FIDO2 Authentication](#enable-fido2-authentication-in-azure-portal)

Microsoft Entra ID is configured Successfully.

### Register an Application

1. Log in to Azure Portal and select **Microsoft Entra ID** on the home page.
   ![How to Configure Advanced User Sync in... - screenshot 1](/images/intercom/13607433/aff19387-f8d9-4670-a7cb-ce371450db4e-41197c65.png)
   The Microsoft Entra ID page is displayed.
2. Go to **Overview > Manage** **> App registrations > New registration**.
   ![How to Configure Advanced User Sync in... - screenshot 2](/images/intercom/13607433/e02687c4-25cf-49f0-81a7-e6a3386ee0b1-e8e7b925.png)
   The Register an application page is displayed.
3. Do the following.
   1. Enter **Name**.
   2. Select Supported account types.

      <Note>
        **Note:** Select Accounts in this organizational directory only.
      </Note>

   3. Click **Register**.
      ![How to Configure Advanced User Sync in... - screenshot 3](/images/intercom/13607433/1a274bb9-0d50-49db-8149-afb78624e212-a0f29545.png)
      The application is registered successfully.

### Configure the Application

1. Navigate to the **newly registered app > API Permissions >** **Add a permission > Microsoft Graph.**
   ![How to Configure Advanced User Sync in... - screenshot 4](/images/intercom/13607433/image-68e341e3.png)
   The **Request API Permissions** pop-up box is displayed.
2. Select **Application permissions**.
   ![How to Configure Advanced User Sync in... - screenshot 5](/images/intercom/13607433/55f4749d-f9c8-4a95-91be-e0a9cd108acd-289b3f95.png)
   The **List of API** permissions is displayed.
3. Do the following:
   1. On **User** drop-down, select the following:
      1. User.Read.All
      2. User.Read Basic.All (Optional).
         ![How to Configure Advanced User Sync in... - screenshot 6](/images/intercom/13607433/993b5cec-aaa7-43b6-8757-94bf29c67ff4-10901071.png)
   2. On **GroupMember** drop-down, select the **GroupMember.Read.All**
      ![How to Configure Advanced User Sync in... - screenshot 7](/images/intercom/13607433/image-40850ee1.png)
   3. On **UserAuthenticationMethod** drop-down, select the **UsersAuthenticationMethod.ReadWrite.All**
      ![How to Configure Advanced User Sync in... - screenshot 8](/images/intercom/13607433/5069da94-bcf2-4ee6-ada7-f494355b56e2-17870abb.png)
   4. On **Policy** drop-down, select the following:
      1. Policy.Read.AuthenticationMethod.
      2. Policy.ReadWrite.AuthenticationFlows.
         ![How to Configure Advanced User Sync in... - screenshot 9](/images/intercom/13607433/7e69b117-803b-4155-8094-2f53dcc86b60-4b510786.png)
   5. Click **Add Permissions.**
      The Permissions are listed on the API.
   6. Click **Grant admin consent for Oloid inc.**
      ![How to Configure Advanced User Sync in... - screenshot 10](/images/intercom/13607433/image-0df62394.png)
      The **API Permissions** are successfully created.
      ![How to Configure Advanced User Sync in... - screenshot 11](/images/intercom/13607433/image-a87e08e3.png)

### Create Client Secret

1. Go to **Certificates & secrets** > **Client Secrets > + New client secret**.
   ![How to Configure Advanced User Sync in... - screenshot 12](/images/intercom/13607433/f6ad3e20-d7ef-467e-aef6-ff25b63f6f99-ce5c2871.png)
   The **Add a client secret** screen is displayed.
2. Do the following:
   1. Enter **Description**.
   2. Select the **Expires** duration from the drop-down list.

      <Note>
        **Note:** Select 365 days (12 months).
      </Note>

   3. Click **Add**.
      ![How to Configure Advanced User Sync in... - screenshot 13](/images/intercom/13607433/a685fa2c-98c4-4dc7-b0a1-2d2fa871b2ab-4b0ec585.png)
      The **Client Secret** is added successfully and listed on **Client Secret** tab.

      <Note>
        **Note:** Click on the **Copy to Clipboard** icon next to the value field to copy the secret. This option is available only at the time of creation.
      </Note>

      ![How to Configure Advanced User Sync in... - screenshot 14](/images/intercom/13607433/8cb1df9b-80b0-4fbb-8188-f48cb035c4da-99cf9d13.png)
3. Go to **Overview** and copy the values of **Client ID** and **Directory** (**Tenant) ID**.
   ![How to Configure Advanced User Sync in... - screenshot 15](/images/intercom/13607433/image-b703961d.png)
   The application is configured successfully.

### Enable FIDO2 Authentication in Azure Portal

1. Go to **Tenant Overview > Manage > Security** in the vertical navigation menu.
   ![How to Configure Advanced User Sync in... - screenshot 16](https://downloads.intercomcdn.com/i/o/e4gi378c/2022187089/4a1186b0fa0f132c89f5148770e0/e342cb49-37f1-4542-a209-9fbbddc54292?expires=1790294400&signature=e1dd6a717dede2b5bb372af81042ce121ca7ea47553d8e953e2ea185a78ca7a1&req=diAlFMh2moFXUPMW3nq%2BgUivyTLcl1EIwBahxSm6hwP4IsIuWbwlh9RQuXEU%0AQVt6OZq7w4ZcAKYk0ermO6Oc2Ao%3D%0A)
2. Go to **Security > Manage > Authentication Methods**.
   ![How to Configure Advanced User Sync in... - screenshot 17](/images/intercom/13607433/577f9f41-2abe-46df-ae8c-a381532062dc-3a95a6e4.png)
   The Authentication page is displayed.
3. Go to **Manage > Policies**, select **Passkey (FIDO2)** in **Authentication method policies** table.
   ![How to Configure Advanced User Sync in... - screenshot 18](/images/intercom/13607433/274538f6-b12f-4c9e-b6c2-c96f294d0453-1d2d1d15.png)
   The Passkey (FIDO2) setting page is displayed.
4. Click **Enable and Target** tab and do the following:
   1. Enable the toggle.
   2. Select **All User** as Target.

      <Note>
        **Note:** If you want all users to use FIDO2 authentication.
      </Note>

   3. Click **Save**.
      ![How to Configure Advanced User Sync in... - screenshot 19](/images/intercom/13607433/image-422b8a70.png)
      The **Enable and Target** tab is configured successfully.
5. Click **Configure** tab and do the following:
   1. Select Allow Self-Service set up **Yes**.
   2. Select Enforce Attestation **No**.
   3. Select Enforce key restrictions **No**.
   4. Select Restrict specific key **Allow**.
   5. Click **Save**.
      ![How to Configure Advanced User Sync in... - screenshot 20](/images/intercom/13607433/image-1bc9893e.png)
      The Configure tab is configured successfully. FIDO2 is successfully configured.
