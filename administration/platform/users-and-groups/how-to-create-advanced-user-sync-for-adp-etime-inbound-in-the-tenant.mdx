## Introduction

The **Advanced User Sync** feature in the Tenant Admin Portal allows admin to create and manage user synchronization using supported agents such as ADP ETime - Inbound, ensuring accurate and consistent user data in the Oloid Tenant Admin Portal.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**.
   ![How to Create Advanced User Sync for... - screenshot 1](/images/intercom/14468948/image-a28bb49f.png)
   The Advanced User Sync page is displayed.
3. Click **Create User Sync**.
   ![How to Create Advanced User Sync for... - screenshot 2](/images/intercom/14468948/image-ccf77ce8.png)
   The **Create User Sync** pop-up box is displayed.
4. Do the following:
   1. Enter **User Sync Name**.
   2. Select **Agent**.

      <Note>
        **Note:** Select ADP ETime - Inbound as agent.
      </Note>

   3. Click **Create**.
      ![How to Create Advanced User Sync for... - screenshot 3](/images/intercom/14468948/image-e010ff11.png)
      The advanced user sync for ADP ETime - Inbound is created successfully.
      ![How to Create Advanced User Sync for... - screenshot 4](/images/intercom/14468948/image-6aaa7795.png)
