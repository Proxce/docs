## Introduction

The User Details section in the Tenant Admin Portal allows administrators to create, assign, manage and update user-credentials for all users in the connection(s).

## Prerequisites

- You must have a Tenant Admin access to Tenant Admin Portal.
- User must already exist in the Tenant Admin Portal.

## Steps to Configure User Details

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** icon on the left panel menu.
   ![How to Configure user details - screenshot 1](/images/intercom/8347344/image-967cb680.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![How to Configure user details - screenshot 2](/images/intercom/8347344/image-0948d039.png)
   The User details page is displayed.

Configure the following:

1. [Details tab](#configure-details-tab)
2. [Credentials tab](#configure-credentials-tab)
3. [Groups tab](#groups-tab)
4. [Transactions tab](#transactions-tab)
5. [Consent](#consent-tab)

The User details are configured.

### Configure Details Tab

![How to Configure user details - screenshot 3](/images/intercom/8347344/image-d065b922.png)

Do the following:

- Edit **Full Name**. (if required)
- Enter **User Email ID**. (optional)
- Enter **Badge ID/Secondary ID**. (optional)
- Enter **Wiegand Format.** (optional)
- Enter **External ID**. (optional)
- Enter **Phone**. (optional)
- Select **User Type** from the drop-down list. (optional)
- Enter **Supervisor Name**. (optional)
- Enter **Supervisor Email**.(optional)
- Enter **Other Identifiers** (optional)

### Configure Credentials Tab

You may enable one or more credentials based on your requirements.

![How to Configure user details - screenshot 5](/images/intercom/8347344/6568a3ef-f834-415f-8485-f986a38acabb-7901e56d.png)

#### Face Tab

To use face as credential, configure **Face** option. The Face tab allows you to add or invite user to add face for authentication.

<Note>
  **Note:** A user face cannot be onboarded if the user has not provided consent in the Oloid User Portal.
</Note>

![How to Configure user details - screenshot 6](/images/intercom/8347344/image-51fa99ed.png)

Do the following:

- **Upload Face:** This option allows you to upload the user's face. For further information, see **[How to onboard face of a single user](https://oloid.help/en/articles/8181773-how-to-onboard-face-of-a-single-user)**
- **Capture Face:** This option allows you to capture the user's face. For further information, see How to capture face of a single user **[Tenant Admin Portal - How to Add face using Capture Face](https://oloid.help/en/articles/13700750-tenant-admin-portal-how-to-add-face-using-capture-face)**
- **Invite to Add Face:** This option sends an email to the user with a link to upload their facial image. For further information, see**[How to invite to add face](https://oloid.help/en/articles/8398578-how-to-invite-to-add-face)**

#### QR Code Tab

To use QR Codeas credential, configure **QR code** option. The QR Code tab allows you to manage the user's QR code credentials.

![How to Configure user details - screenshot 7](/images/intercom/8347344/image-d9cd6c1f.png)

Do the following:

- **Create QR Code:** Select this option to create QR Code for the user. For further information, see **[How to create QR Code as credential for user](https://oloid.help/en/articles/8294162-how-to-create-qr-code-as-credential-for-user)**
- **Send QR Code on Email:** Select this option to send the QR code to the user's registered email ID. For further information, see **[How to send QR Code on Email](https://oloid.help/en/articles/9794751-how-to-send-qr-code-on-email)**
- **Send User Portal Link:** Select this option to send the user the User Portal Link via email, allowing them to manage their credentials, including viewing or downloading the QR code. For further information, see**[How to send QR Code credential to user using user portal link](https://oloid.help/en/articles/8850381-how-to-send-qr-code-credential-to-user-using-user-portal-link)**

#### Badge ID Tab

To use badgeas credential, configure **Badge ID** option. The Badge ID tab allows you to assign or enroll a user's badge for authentication.

![How to Configure user details - screenshot 8](/images/intercom/8347344/image-a8209a2c.png)

Do the following:

- **Assign Badge:** Select this option to manually assign a badge to the user. For further information, see **[How to assign Badge ID as credential to users](https://oloid.help/en/articles/8379462-how-to-assign-badge-id-as-credential-to-users)**
- **Scan Badge to Enroll:** Select this option to scan or enter badge ID to enroll a new badge for the user. For further information, see **[How to enroll users using badge scan in Oloid Portal](https://oloid.help/en/articles/8937141-how-to-enroll-users-using-badge-scan-in-oloid-portal)**

  <Note>
    **Note:** Changes here create temporary badges. Use 'Replace Badge' for permanent changes.
  </Note>

#### Windows Password Tab

To use Windows Passwordas credential, configure **Windows Password** option. The **Windows Passwords** tab allows the admin to create and manage the user's Windows login credentials.

![How to Configure user details - screenshot 9](/images/intercom/8347344/image-e024b657.png)

Do the following:

- **Create Password:** Select this option to generate a new Windows password for the user. For further information, see **[How to create Password for Windows Login](https://oloid.help/en/articles/8468581-how-to-create-password-for-windows-login)**
- **Add Windows Shared Password:** Select this option to add Windows shared credentials for Windows systems, which multiple users can access.For further information, see**[How to assign Shared Credentials to user](https://oloid.help/en/articles/8504427-how-to-assign-shared-credential-to-user)**
- **Invite to add password:** Select this option to Invite users to Add Windows password for Windows systems.For further information, see**[How to send invite to add Password to a user](https://oloid.help/en/articles/9929285-how-to-send-invite-to-add-password-to-a-user)**

#### Vault Passwords Tab

To use Vault Password credential, configure **Vault Passwords** option. The Vault Passwords tab allows you to manage the user's web password credentials.

![How to Configure user details - screenshot 10](/images/intercom/8347344/image-6e8bcf33.png)

Do the following:

**Create Password:** Select this option to create password for web (Chrome Vault) application. For further information, see **[How to create Vault Password for a user](https://oloid.help/en/articles/9936961-how-to-create-vault-password-for-a-user)**.

**Add Vault Shared Password:** Select this option to assign a shared password for web (Chrome Vault) application. Please refer: **[Chrome Vault: How to Add Vault Shared Password for a User in the Tenant Admin Portal](https://oloid.help/en/articles/13284463-chrome-vault-how-to-add-vault-shared-password-for-a-user-in-the-tenant-admin-portal)**

#### PIN Tab

To use PIN credential, configure **PIN** option. The PIN tab allows you to manage the user's PIN configuration.

![How to Configure user details - screenshot 13](/images/intercom/8347344/image-c3d8c0c9.png)

Do the following:

- **Add PIN:** Select this option to add PIN to the user. For further information, see**[How to add PIN as credential to users](https://oloid.help/en/articles/8385780-how-to-add-pin-as-credential-to-users).**
- **Send Reset PIN Email:** Select this option to allow users to Reset PIN. To add and configure PIN. For further information, see **[How to send invite to set Pin on Email to a user](https://oloid.help/en/articles/9937001-how-to-send-invite-to-set-pin-on-email-to-a-user)**.

- **Lock PIN:** Select this option to Lock the PIN and prevent the user from authenticating. For further information, see **[Tenant Admin Portal - How to Lock PIN Credential for a User](https://oloid.help/en/articles/14014193-tenant-admin-portal-how-to-lock-pin-credential-for-a-user)**

### Consent Tab

The **Consent** tab shows the user’s current consent status and their complete consent history.

<Note>
  **Note:** Consent Status are as follows:
</Note>

- Provided: User has provided consent for adding face
- Denied: User has rejected consent
- Pending: User has been sent the consent and user action is pending.
- Reconsent Pending: User had previously denied consent and was re-shared the consent and user action is pending.

Click the download icon to save consent file.

![How to Configure user details - screenshot 17](/images/intercom/8347344/image-3897bfd6.png)

Select Consent History tab to view past consents and their status.

![How to Configure user details - screenshot 18](/images/intercom/8347344/e968ca1f-f58c-4ee9-99fc-f9b961666e72-ccbe5158.png)
