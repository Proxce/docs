## Introduction

QR Code credentials can be configured with a specific validity period for user authentication. When the expiry date of QR Code credentials needs to be extended for multiple users, Tenant Admins can update the validity period in bulk

## Prerequisite

You must have Tenant admin access to the Tenant Admin Portal.

## Steps to extend QR Code expiry date in bulk

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Extend QR Code expiry date in... - screenshot 1](/images/intercom/8479750/image-73d3c46e.png)
   The **Users** page is displayed.
3. Select users.
4. Go to **Action** > **Extend QR Code Expiry Date**.
   ![How to Extend QR Code expiry date in... - screenshot 2](/images/intercom/8479750/image-f6ce6105.png)
   The **Extend QR Code** pop-up box is displayed.
5. On the pop-up box, do the following:
   1. Under **QR Code Validity** field adjust the date and time from the calendar icon.
   2. Under **Share Summary With** field enter the email ID(s) with whom you want to share the QR Code summary. (**optional**)
   3. Click **Assign**.
      ![How to Extend QR Code expiry date in... - screenshot 3](/images/intercom/8479750/image-3f3947ed.png)
      The QR Code credential is successfully extended for the selected users. The QR Code summary of these users is shared over email ID(s) and is available for download in the attachments.
      ![How to Extend QR Code expiry date in... - screenshot 4](/images/intercom/8479750/image-9f0b2444.png)
