## Introduction

The HR Picture Verification upload feature allows Admins to upload High Resolution facial images of users in bulk for identity verification.

## Pre-requisite

- You must have access to a Tenant Admin account.
- Ensure that the Image name is in the given format - "primaryID_username"

## Steps to Import faces

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left panel menu.
3. Click **HR Picture Verification**.
   ![How to Import Faces for HR Picture... - screenshot 1](/images/intercom/13524609/image-f900aad6.png)
   The HR Picture Verification page is displayed.
4. Click **Import Faces**.
   ![How to Import Faces for HR Picture... - screenshot 2](/images/intercom/13524609/image-1276e967.png)
   The **Import Faces** pop-up box is displayed.
5. Upload the image file of the users.
   ![How to Import Faces for HR Picture... - screenshot 3](/images/intercom/13524609/image-25536dcb.png)
6. Click **Import**.
   The images are uploaded and listed on **Import Faces** page.

   <Note>
     **Note:** 1. To check the status of HR Picture Verification file upload check **Upload Logs.**
   </Note>

Please ensure that the Image name is in the given format - "primaryID_username". Only one image per user is allowed. Images with duplicate file name will be overwritten by the latest uploaded file and name.
