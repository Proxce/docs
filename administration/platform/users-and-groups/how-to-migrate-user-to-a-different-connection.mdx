Steps to Migrate User to a different Connection:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/8379283/e51aa0d6-bdc5-4f8b-b177-a8b741da433e-f9fe2088.png)
   The **Users** page is displayed.
3. Click **Username** to edit.
   ![Image](/images/intercom/8379283/e8a1124b-4bc6-4318-a160-e06a07ba9600-10ad4e32.png)
   The User details page is displayed.
4. Go to **Action** > Select **Migrate User**.
   ![Image](/images/intercom/8379283/257affbf-d1d8-4577-82fa-0b217bc98f39-d2774319.png)
   The **Migrate User** pop-up box is displayed.
   ![How to migrate user to a different... - screenshot 1](/images/intercom/8379283/image-e2a6fcb5.png)
5. Select connection to map from **Connection** dropdown.
6. Click **Save**.

The user is migrated and mapped to the new connection.

![How to migrate user to a different... - screenshot 2](/images/intercom/8379283/image-dede26a1.png)

The updated connection for the user is displayed on the Users page.

![Image](/images/intercom/8379283/bcf81c1e-3fc4-49db-8410-7662e6a79da6-2bd56273.png)
