## Introduction

This document provides step-by-step instructions to add a **PIN credential** to a user in the Tenant Admin Portal. You can create a PIN for the user and share it with the user through their email address, phone number, or both, based on the configured PIN settings.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- The user must already be created in the Oloid Tenant Admin Portal. For more, refer to [Tenant Admin Portal - How to Create User](https://oloid.help/en/articles/8185048-tenant-admin-portal-how-to-create-user)
- PIN credential settings must be enabled and configured in Tenant Admin Portal.

## Steps to create PIN

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Directory** on the left menu panel.
   ![How to Add PIN Credential for User - screenshot 1](/images/intercom/8385780/image-fee2cfec.png)
   The **Users** page is displayed.
3. Click **user name** to edit.
   ![How to Add PIN Credential for User - screenshot 2](/images/intercom/8385780/image-8a860ed0.png)
   The user details page is displayed.
4. Do one of the following:
   1. Go to **Credentials** tab > **PIN** > **Add PIN**.
      ![How to Add PIN Credential for User - screenshot 3](/images/intercom/8385780/image-02cb4d7f.png)
   2. Go to **Assign Credential** > **Add PIN**.
      ![How to Add PIN Credential for User - screenshot 4](/images/intercom/8385780/image-82af9b54.png)
      The **Add PIN** pop-up box is displayed.
5. On the pop-up box, do the following:
   1. **Enter new PIN**.
   2. **Re-enter new PIN**.
   3. Under **Share PIN With,** select one or both available options to share the PIN with the user:
      1. In the **Email** field, enter the email address of the user with whom you want to share the PIN.
      2. In the **User Phone Number** field, enter the phone number of the user with whom you want to share the PIN.

         <Note>
           **Note:** If the **Share PIN With** option is not displayed in the **Add PIN** pop-up, an email notification will be sent to the user’s registered email address informing them of the PIN update. The new PIN will not be included in the email. For more, Contact [Oloid Support](mailto:support@oloid.ai)
         </Note>

   4. Click **Save**.
      ![How to Add PIN Credential for User - screenshot 5](/images/intercom/8385780/image-d8a77423.png)
      The PIN credential is created and listed on the **PIN** tab.
      ![How to Add PIN Credential for User - screenshot 6](/images/intercom/8385780/image-1f858481.png)
