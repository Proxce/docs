## Introduction

This document explains how to prepare the user upload template for bulk import in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Use the provided CSV template and do not change the column headers.
- Do not use commas (,) in field values.
- Ensure all values are in the correct format.
- Ensure the CSV file does not contain extra spaces or incorrect formatting.

## Steps to prepare the User Upload template

1. Log in to Tenant Admin Portal.
2. To download the template, go to **Directory** ![Tenant Admin Portal – How to Prepare... - screenshot 1](https://downloads.intercomcdn.com/i/o/e4gi378c/1397526130/4d9db810cd3d2736f5099b1dd775/image.png?expires=1790488800&signature=37b738bf63f50877cf51a1c7fe5cbe4a1d31f92fddd4f142ad9fecb58bc6162c&req=dSMuEcx8m4BcWfMW3nq%2BgRuRU3HtJLr%2FJ7LOiHI4cwUFg3a%2ByITSPZZv%2BcTs%0AX9kpfOKTnBcDc5tcGy9z6eh3Kcw%3D%0A) > **Import** > **Import Users**.
3. Open the downloaded template in Excel.
4. In the template, select rows **6 to 10**, right-click and click **Delete** to remove these rows.
5. Columns **A**, **B**, and **C** are mandatory fields required to successfully upload the user data. Keep any additional columns that requires updates as part of the User data. Rest of columns should be selected and deleted using the right click option.
   ![Tenant Admin Portal – How to Prepare... - screenshot 2](/images/intercom/10650742/image-3487134c.png)
6. Fill the remaining columns with the relevant user data and save the updated template with an appropriate file name.

**IMPORTANT TO NOTE:**

1. If you do not have the Primary ID (Employee ID) of a user and want to assign Oloid’s Default ID – known as “oloid”- then use `#&#123;&#123;oloid&#125;&#125;` in the primary ID field. Refer to the snapshot below for reference.
   ![Tenant Admin Portal – How to Prepare... - screenshot 3](/images/intercom/10650742/image-e5ce31c9.png)
2. To remove an existing user, set their **Status** field to **TERMINATED**.
3. If you want to add any custom fields, please add the custom header name and populate the column in the file. Do not add `#Oloid#_ `prefix with custom headers.
