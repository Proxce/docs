## Introduction

The Vault Passkey feature allows administrators to view and manage secure passkey credentials associated with a user in the Tenant Admin Portal.

## Prerequisite

You must have Tenant Admin account.

## Steps to View and Edit Vault Passkey

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/12889955/42812ab0-d4c9-4fc6-9fcd-e2cf4ddd66ce-78fec51b.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![Image](/images/intercom/12889955/b6ed1a54-d8ed-4082-a31f-757e7f2b0747-0964db7e.png)
   The **user details** page is displayed.
   ![How to View and Edit Vault Passkey... - screenshot 1](/images/intercom/12889955/image-495fe094.png)
4. Go to **Credentials** tab > **Vault Passkey**
   ![How to View and Edit Vault Passkey... - screenshot 2](/images/intercom/12889955/image-5cb31cab.png)
   The **Vault Passkey** is displayed.
5. Select the three-dot menu to open the options for viewing, editing, or deleting the passkey.
   ![How to View and Edit Vault Passkey... - screenshot 3](/images/intercom/12889955/image-9f8432d0.png)
6. Do the following:
   1. To View: Click **Three dots icon** > select **View Details**
      ![How to View and Edit Vault Passkey... - screenshot 4](/images/intercom/12889955/image-39cb1779.png)
   2. To Edit: Click **Three dots icon** > select **Edit** > **Change Display Name** > **Save**
      ![How to View and Edit Vault Passkey... - screenshot 5](/images/intercom/12889955/image-32c12974.png)
   3. To Delete: Click **Three dots icon** > select **Delete** > **Confirm**
      ![How to View and Edit Vault Passkey... - screenshot 6](/images/intercom/12889955/image-5f3c3983.png)

The Vault passkey is updated based on the changes made.
