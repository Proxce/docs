## Introduction

This document describes how to configure Advanced User Sync for ADP Vantage HCM - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- An **Advanced User Sync profile for ADP Vantage HCM - Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for ADP Vantage HCM - Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.
   ![Inbound in the Tenant Admin Portal - screenshot 1](/images/intercom/13843605/image-0b56f77e.png)
   The **Advanced User Sync** page is displayed.
3. Select the preferred **ADP Vantage HCM - Inbound** Advanced User Sync.
   ![Inbound in the Tenant Admin Portal - screenshot 2](/images/intercom/13843605/image-fd4a6fa7.png)
   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
5. Click **Activate**.
   ![Inbound in the Tenant Admin Portal - screenshot 3](/images/intercom/13843605/image-0522d842.png)
   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.
   ![Inbound in the Tenant Admin Portal - screenshot 4](/images/intercom/13843605/image-44665186.png)
   The Advanced User Sync is configured and activated successfully.
   ![Inbound in the Tenant Admin Portal - screenshot 5](/images/intercom/13843605/image-0e6d62df.png)
7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![Inbound in the Tenant Admin Portal - screenshot 6](/images/intercom/13843605/image-4e2dac47.png)
   The **Sync Now?** pop-up box is displayed.
8. Click **Confirm**.
   ![Inbound in the Tenant Admin Portal - screenshot 7](/images/intercom/13843605/image-4a69c1f4.png)
   The **Success** pop-up box is displayed.
   ![Inbound in the Tenant Admin Portal - screenshot 8](/images/intercom/13843605/image-2108f705.png)
   The Advanced User Sync for ADP Vantage HCM - Inbound is configured successfully.
   ![Inbound in the Tenant Admin Portal - screenshot 9](/images/intercom/13843605/image-d638c130.png)

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (if required).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.
   ![Inbound in the Tenant Admin Portal - screenshot 10](/images/intercom/13843605/image-20ac6dfa.png)
   The Details tab is configured successfully.

### Setup Configuration Tab

This tab is used to map user data from **ADP Vantage HCM - Inbound** to **Oloid**.

Do the following:

1. Select the **Data Mapper Table** from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. Select **Connection** from the drop-down.
3. Click **Save**.
   ![Inbound in the Tenant Admin Portal - screenshot 11](/images/intercom/13843605/image-9816fcf1.png)
   The Configuration tab is configured successfully.
   ![Inbound in the Tenant Admin Portal - screenshot 12](/images/intercom/13843605/image-1bcf4123.png)

### Configure Account Tab

This tab is used to add and configure the **ADP Vantage HCM - Inbound** account details required for inbound user synchronization with **Oloid**.

Do the following:

1. Enter **Account Name**.
2. Enter **Token Endpoint**.
3. Enter **Organization ID (OOID)**.
4. Enter **Read Credential Endpoint**.
5. Enter **API URL**.
6. Enter **Client ID**.
7. Enter **Client Secret**.

   <Note>
     **Note:** Contact Oloid support for **Organization ID, Client ID** and **Client Secret**.
   </Note>

   ![Inbound in the Tenant Admin Portal - screenshot 13](/images/intercom/13843605/image-440099d6.png)
   The Account tab is configured successfully.
8. Click **Test**.
   ![Inbound in the Tenant Admin Portal - screenshot 14](/images/intercom/13843605/image-5b46ede9.png)
   The **Success** pop-up box is displayed.

   ![Inbound in the Tenant Admin Portal - screenshot 15](/images/intercom/13843605/image-af95052f.png)

### Configure Schedule Tab

This tab is used to define when the **ADP Vantage HCM - Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![Inbound in the Tenant Admin Portal - screenshot 16](/images/intercom/13843605/image-ecb1a3e7.png)

The Schedule tab is configured successfully.

### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.
   ![Inbound in the Tenant Admin Portal - screenshot 17](/images/intercom/13843605/image-b3bdd618.png)
   The **Repeat Every** section is configured successfully.
   ![Inbound in the Tenant Admin Portal - screenshot 18](/images/intercom/13843605/image-dd2d566e.png)

### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![Inbound in the Tenant Admin Portal - screenshot 19](/images/intercom/13843605/image-ee972299.png)

The **Run Once When Activated** section is configured successfully.

![Inbound in the Tenant Admin Portal - screenshot 20](/images/intercom/13843605/image-11a9594d.png)
