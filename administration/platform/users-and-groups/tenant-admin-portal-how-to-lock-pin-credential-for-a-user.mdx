## Introduction

The **Lock PIN** feature allows the Tenant Admin to restrict the use of a user's PIN credential from the Tenant Admin Portal. Locking a PIN **prevents the user from authenticating with that credential** until it is unlocked or updated.

## Prerequisites

- You must have access to the **Tenant Admin Portal.**
- Ensure that the **PIN Lock** is enabled in the Tenant Settings. For further information, refer [PIN Lock Policy](https://oloid.help/en/articles/8407872-tenant-admin-portal-how-to-configure-pin#h_06934e4369:~:text=is%20setup%20successfully.-,Configure%20PIN%20Lock%20Policy,-The%20PIN%20Lock).

## Steps to Lock PIN of a User

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Directory** in the left navigation panel.
   ![How to Lock PIN Credential for a User - screenshot 1](/images/intercom/14014193/image-742762d6.png)
   The **Users** page is displayed.
3. Select the **user name** to edit.
   ![How to Lock PIN Credential for a User - screenshot 2](/images/intercom/14014193/image-0f02c3c6.png)
   The **User Details** page is displayed.
4. Go to **Credentials** > **PIN**.
   ![How to Lock PIN Credential for a User - screenshot 3](/images/intercom/14014193/image-bdd03e18.png)
   The **PIN** section is displayed.
5. Click **Lock PIN**.

   <Note>
     **Note:** The PIN Lock Policy is used to configure the settings for locking a PIN after consecutive failed authentication attempts and defining the unlock behavior. For further information, refer [PIN Lock](https://oloid.help/en/articles/8407872-tenant-admin-portal-how-to-configure-pin#h_06934e4369:~:text=is%20setup%20successfully.-,Configure%20PIN%20Lock%20Policy,-The%20PIN%20Lock).
   </Note>

   ![How to Lock PIN Credential for a User - screenshot 4](/images/intercom/14014193/image-c88e4554.png)
   The **Confirm PIN Lock** pop-up box is displayed.
6. Click **Lock PIN**.
   ![How to Lock PIN Credential for a User - screenshot 5](/images/intercom/14014193/image-5884fa2a.png)
   The PIN credential is locked successfully.
   ![How to Lock PIN Credential for a User - screenshot 6](/images/intercom/14014193/image-7c6c3867.png)
