## Introduction

The Create Vault Password feature enables an admin to securely create and store Vault password credentials for a user in the Tenant Admin Portal.

## Prerequisite

- You must have a Tenant Admin account.

## Steps to create Vault Password

1. Login to the Tenant Admin Portal.
2. On the homepage, click **Directory** from the left menu panel.
   ![Image](/images/intercom/9936961/081bd78d-7e0a-4865-9aa3-f1b09d506314-0c550230.png)
   The **Users** page is displayed.
3. Select **User** from the list.
   ![Image](/images/intercom/9936961/56d6fd3f-d2be-4c9f-af20-44e236758802-59c95f4f.png)
   The **User details** page is displayed.
   ![How to create Vault Password for a user - screenshot 1](/images/intercom/9936961/image-d001ee59.png)
4. Go to **Credential** tab > **Vault Passwords** > **+ Create Passwor**d.
   ![How to create Vault Password for a user - screenshot 2](/images/intercom/9936961/image-047004ce.png)
   The **Create Vault Password** pop-up screen is displayed.
5. On the screen, do the following
   1. Enter **Display Name**. (Optional)
   2. Select **Password Type** from the dropdown list.
   3. Click **Next**.
      ![How to create Vault Password for a user - screenshot 3](/images/intercom/9936961/image-6a325a6b.png)
   4. Enter **Web URL/Login UR**L.
   5. Enter **Username**.
   6. Enter **Password**.
   7. Click **Create**.
      ![How to create Vault Password for a user - screenshot 4](/images/intercom/9936961/image-162577d9.png)

The Vault Password is saved successfully.

![How to create Vault Password for a user - screenshot 5](/images/intercom/9936961/image-e2be87e2.png)
