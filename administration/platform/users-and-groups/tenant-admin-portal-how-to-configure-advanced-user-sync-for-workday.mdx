## Introduction

This document describes how to configure Advanced User Sync for Workday - Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- An **Advanced User Sync profile for Workday -Inbound** is created.
- A **Data Mapper Table** is created and available for user attribute mapping.

## Steps to Configure Advanced User Sync for Workday -Inbound

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents > Advanced User Sync**.
   ![How to Configure Advanced User Sync for... - screenshot 1](/images/intercom/13569620/image-0b56f77e.png)
   The **Advanced User Sync** page is displayed.
3. Select the preferred Workday Inbound Advanced User Sync.
   ![How to Configure Advanced User Sync for... - screenshot 2](/images/intercom/13569620/image-100ec660.png)
   The **Advanced User Sync** detail page is displayed.
4. Do the following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configuration Tab](#setup-configuration-tab)
   3. [Configure Account Tab](#configure-account-tab)
   4. [Configure Schedule Tab](#configure-schedule-tab)
5. Click **Activate**.
   ![How to Configure Advanced User Sync for... - screenshot 3](/images/intercom/13569620/image-310dba42.png)
   The **Confirm Activation** pop-up box is displayed.
6. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 4](/images/intercom/13569620/image-8decfbf2.png)
   The Advanced User Sync is configured and activated successfully.
   ![How to Configure Advanced User Sync for... - screenshot 5](/images/intercom/13569620/image-9a7c141c.png)
7. (Optional) Go to **Action > User Sync**.

   <Note>
     **Note:** Selecting **Sync Now** immediately triggers a manual synchronization.
   </Note>

   ![How to Configure Advanced User Sync for... - screenshot 6](/images/intercom/13569620/image-55775f05.png)
   The **Sync Now?** pop-up box is displayed.
8. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 7](/images/intercom/13569620/image-b566e6b5.png)
   The **Success** pop-up box is displayed.
   ![How to Configure Advanced User Sync for... - screenshot 8](/images/intercom/13569620/image-28c1dcf8.png)
   The Advanced User Sync for Workday - Inbound is configured successfully.
   ![How to Configure Advanced User Sync for... - screenshot 9](/images/intercom/13569620/image-b9fc6c54.png)

### Configure Details Tab

This tab is used to view and edit basic information about the Advanced User Sync.

Do the following:

1. Update the **User Sync Name** (if required).
2. Enter the **User Sync Description** (Optional).
3. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 10](/images/intercom/13569620/image-5fae6dfc.png)
   The Details tab is configured successfully.

### Setup Configuration Tab

This tab is used to map user data from **Workday** to **Oloid** and select the Oloid connection where users are added during the inbound user sync.

Do the following:

1. Select the data mapper table from the drop-down.

   <Note>
     **Note:** Click **View Tables** to review or create a data mapper table, if required.
   </Note>

2. On **Add Users to Selected Connection**, do one of the following:
   1. Select the **Connection** option, and then select the required **Connection** from the drop-down list.
      **Note: (Optional)** Select **Group** from the Groups drop-down to add users only to the selected groups.
      OR
   2. Select the **Data Filter Table** option, and then select the required **Data Filter Table** from the drop-down list.

      <Note>
        **Note:** Click **View Tables** to review or create a data filter table, if required.
      </Note>

3. On Update User, select **Sync Photos from Workday and add as Face credential**.
4. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 11](/images/intercom/13569620/9d8e5cca-941f-46c7-9019-346e25b6444f-27ec5d23.png)
   A **Confirm Update** pop-up box is displayed.
5. Click **Confirm**.
   ![How to Configure Advanced User Sync for... - screenshot 12](/images/intercom/13569620/image-30d117a2.png)
   The Configuration tab is configured successfully.
   ![How to Configure Advanced User Sync for... - screenshot 13](/images/intercom/13569620/image-a91bf240.png)

### Configure Schedule Tab

This tab is used to define when the **Workday - Inbound** user sync runs. You can configure the sync to run on a recurring schedule or run once when the sync is activated.

Do one of the following:

[Repeat Every](#repeat-every)

**OR**

[Run Once When Activated](#run-once-when-activated)

![How to Configure Advanced User Sync for... - screenshot 30](/images/intercom/13569620/image-3cf37c87.png)

The Schedule tab is configured successfully.

#### Repeat Every

The **Repeat Every** section is used torun the user sync on selected days and times.

Do the following:

1. Select **Repeat Every**.
2. Select the required day(s).

   <Note>
     **Note:** You can select multiple days (if needed).
   </Note>

3. Select the run time in the **Runs at** field.

   <Note>
     **Note:** You can add multiple execution time. To do, click **+Add** to configure additional run times, if required.
   </Note>

4. Select **Time Zone** from the drop-down.
5. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

6. Click **Save**.
   ![How to Configure Advanced User Sync for... - screenshot 31](/images/intercom/13569620/image-25d6ed0e.png)
   The **Repeat Every** section is configured successfully.
   ![How to Configure Advanced User Sync for... - screenshot 32](/images/intercom/13569620/image-b50d56ff.png)

#### Run Once When Activated

The **Run Once When Activated** section is used to run the sync only once.

Do the following:

1. Select **Run Once When Activated**.
2. Select the date and time in the **Select Date & Time** field.
3. Select **Time Zone** from the drop-down.
4. Enter email address(es) in the **Send failed job-run alerts to** field.

   <Note>
     **Note:** Separate multiple email addresses with commas.
   </Note>

5. Click **Save**.

![How to Configure Advanced User Sync for... - screenshot 33](/images/intercom/13569620/image-64f69d3e.png)

The **Run Once When Activated** section is configured successfully.
