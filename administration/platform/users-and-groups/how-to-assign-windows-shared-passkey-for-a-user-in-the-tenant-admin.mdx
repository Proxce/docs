## Introduction

The Assign Windows shared Passkey feature allows an admin to securely assign an existing shared passkey to a specific user.

## Prerequisites

- You must have a Tenant Admin account.
- Windows Passkey must already be created. For more information please refer: [Oloid Platform - How to create Windows Passkey as credential for users in Tenant Admin Portal](https://oloid.help/en/articles/11058549-oloid-platform-how-to-create-windows-passkey-as-credential-for-users-in-tenant-admin-portal)

## Steps to Assign Windows Shared Passkey

1. Login to the Tenant Admin Portal.
2. On the homepage, click **Directory** from the left menu panel.
   ![Image](/images/intercom/13305454/081bd78d-7e0a-4865-9aa3-f1b09d506314-0c550230.png)
   The **Users** page is displayed.
3. Click **username** to edit.
   ![Image](/images/intercom/13305454/56d6fd3f-d2be-4c9f-af20-44e236758802-59c95f4f.png)
   The **User details** page is displayed.
   ![How to Assign Windows shared Passkey... - screenshot 1](/images/intercom/13305454/image-d001ee59.png)
4. Go to **Credential** tab > **Windows Passkey** > **+ Windows Shared Passkey**.
   ![How to Assign Windows shared Passkey... - screenshot 2](/images/intercom/13305454/image-f732a107.png)
   Windows Shared Passkey pop-up is displayed
   ![How to Assign Windows shared Passkey... - screenshot 3](/images/intercom/13305454/image-7efa543a.png)
5. **Select** Windows Shared Passkey to Assign from the dropdown.
6. Click **Assign.**
   Windows Shared Passkey successfully added message is displayed.

   <Note>
     **Note:** More than one Windows Shared Passkey can be assigned for a user.
   </Note>

Windows Shared Passkey is assigned to user.
