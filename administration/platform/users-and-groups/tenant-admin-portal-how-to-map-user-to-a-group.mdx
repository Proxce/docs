## Introduction

This document provides instructions to map user to a group in the Tenant Admin Portal. You can add user by adding a group to a user or by adding user to a group.

## Prerequisites

- You must have admin access to the Tenant Admin Portal.
- Ensure that the required user(s) and group(s) is(are) available in the Tenant Admin Portal.

## Steps to Map User to a Group

You can map user to a group using either of the following methods:

- Add Group to a User
- Add a User(s) to a Group

### Steps to Add a Group to a User

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Directory** on the left menu panel.
   ![How to Map User to a Group - screenshot 1](/images/intercom/8267045/image-fced488f.png)
   The **Users** screen is displayed.
3. Click the preferred user name.
   ![How to Map User to a Group - screenshot 2](/images/intercom/8267045/image-5f4ce365.png)
   The **User Details** page is displayed.
   ![How to Map User to a Group - screenshot 3](/images/intercom/8267045/image-a334327f.png)
4. Click **Groups** > **+ Add Group**.
   ![How to Map User to a Group - screenshot 4](/images/intercom/8267045/image-4de592b9.png)
   The **Add Group** pop-up box is displayed.
5. Select the required group from the drop-down list and click **Add**.

   <Note>
     **Note:** If required, you can add a user to multiple groups.
   </Note>

   ![How to Map User to a Group - screenshot 5](/images/intercom/8267045/image-aa7247e3.png)
6. Click **Save**.
   The group is added and listed on the Groups tab.
   ![How to Map User to a Group - screenshot 6](/images/intercom/8267045/5686e16f-7206-43f4-87ea-27ca5b10c947-ea0002bc.png)

### Steps to Add User(s) to a Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Groups** on the left panel menu.
   ![How to Map User to a Group - screenshot 7](/images/intercom/8267045/image-56fb7f68.png)
   The **Groups** page is displayed.
3. Click the preferred group.
   ![How to Map User to a Group - screenshot 8](/images/intercom/8267045/image-7e75bf48.png)
   The **Group Details** page is displayed.
   ![How to Map User to a Group - screenshot 9](/images/intercom/8267045/image-1e4f1c34.png)
4. Click **Users** > **+ Add User**.
   ![How to Map User to a Group - screenshot 10](/images/intercom/8267045/image-1ddcb7e0.png)
   The **Add User** pop-up box is displayed.
5. Enter the **user’s Full Name, Primary ID, OloID,** or **Employee ID**, and click **Add**.

   <Note>
     **Note:** If needed, you can add multiple users to a Group.
   </Note>

   ![How to Map User to a Group - screenshot 11](/images/intercom/8267045/image-933efc57.png)
   The user is added successfully and listed on the **Group** tab.
   ![How to Map User to a Group - screenshot 12](/images/intercom/8267045/b51425f0-efba-4301-9de5-acbd0fbecbb5-83b675b9.png)

   <Note>
     **Note:** For instructions to map users to a group in bulk, see [How to map users to Group in bulk](https://oloid.help/en/articles/8272023-how-to-map-users-to-group-in-bulk).
   </Note>
