## Introduction

The Tenant Admin Portal allows the admin to manage user accounts, including adding, updating, and removing users as required. Removing a user ensures that their access to applications and resources linked to the Tenant Admin Portal is permanently revoked.

## Prerequisite

A User must be created. To create user refer [How to add Users in the Tenant Admin Portal](https://oloid.help/en/articles/8185048-how-to-add-users-in-the-tenant-admin-portal).

## Steps to remove user

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to remove user in the Tenant Admin... - screenshot 2](/images/intercom/8424129/image-31d60875.png)
   The **Users** page is displayed.
3. Click Username to edit.
   ![How to remove user in the Tenant Admin... - screenshot 3](/images/intercom/8424129/image-767d907e.png)
   The user details page is displayed.
4. On the top-right, go to **Action** > select **Delete User**.
   ![How to remove user in the Tenant Admin... - screenshot 4](/images/intercom/8424129/image-fe17d3a7.png)
   A confirmation pop-up box is displayed.
5. Click **Delete**.
   ![How to remove user in the Tenant Admin... - screenshot 5](/images/intercom/8424129/image-51bfedc3.png)
   The user is permanently deleted from the Tenant Admin Portal.
   ![How to remove user in the Tenant Admin... - screenshot 6](/images/intercom/8424129/image-94deef64.png)
