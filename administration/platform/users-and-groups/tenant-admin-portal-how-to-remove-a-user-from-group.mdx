## Introduction

This document provides instructions to remove one or more users from a group in the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Remove User from Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Groups** on the left panel menu.
   ![How to Remove a User from Group - screenshot 1](/images/intercom/8311847/image-4aca706d.png)
   The **Groups** page is displayed.
3. Click the preferred group.
   ![How to Remove a User from Group - screenshot 2](/images/intercom/8311847/image-857ad37a.png)
   The **Group Details** page is displayed.
   ![How to Remove a User from Group - screenshot 3](/images/intercom/8311847/image-e92b15dd.png)
4. Click **Users** tab and do the following:
   1. Select the preferred user(s).

      <Note>
        **Note:** If needed, you can select multiple users to delete from the group.
      </Note>

   2. Click **Delete** icon.
      ![How to Remove a User from Group - screenshot 4](/images/intercom/8311847/image-531f4005.png)
      The **Confirm Deletion** pop-up box is displayed.
   3. Click **Delete**.
      ![How to Remove a User from Group - screenshot 5](/images/intercom/8311847/image-8d6b8b72.png)
      The selected user is successfully removed from the group.
      ![How to Remove a User from Group - screenshot 6](/images/intercom/8311847/image-ad6ad47b.png)
