## Pre-requisite

Face should be added to the user.

Steps to find Face:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to find face - screenshot 1](/images/intercom/8355149/image-3b224d1d.png)
   The **Users** page is displayed.
3. Click User Name to edit.
   ![Image](/images/intercom/8355149/3278deee-0e7e-43b4-8228-df85a6303ce1-082d0682.png)
   You will see a preview of the tenant.
   The User details page is displayed.
4. Go to **Action** > Select **Find Face**.
   ![Image](/images/intercom/8355149/843bf11b-6912-4210-811f-2ccf79e245ad-f5d9c96e.png)
   The **Find Similar Faces** pop-up box is displayed.
   ![How to find face - screenshot 2](/images/intercom/8355149/image-d7bbea2e.png)
5. On the **Find Similar Faces** pop-up box, do the following:
   1. Enter **Confidence** level.

      <Note>
        **Note:** For best results, increase confidence level above default value.
      </Note>

   2. Select required connection(s) from the **Connection** drop down.
   3. Click **Search**.
      The **Results for Similar Faces** pop-up box is displayed.
      The search result shows confidence level face match.

      <Note>
        **Note:** This functionality is for Oloid internal use.
      </Note>
