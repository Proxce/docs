## Introduction

This document explains how to create a Token ID in the Okta Admin Console.
The Token ID is required to securely authenticate and authorize API access for Okta integrations.

## Prerequisite

You must have **admin access** to the Okta Admin Console.

## Steps to Create Token ID

1. Log in to the **Okta Admin Account**.
2. On the left menu panel, go to **Security** > **API.**
   ![How to Create a Token ID for Advanced... - screenshot 1](/images/intercom/13701658/image-322311eb.png)
   The **API** screen is displayed.
3. Click **Tokens**.
   ![How to Create a Token ID for Advanced... - screenshot 2](/images/intercom/13701658/image-a0cc5e9f.png)
   The API Token page is displayed.
4. Click **Create token**.
   ![How to Create a Token ID for Advanced... - screenshot 3](/images/intercom/13701658/image-b1fc8ba2.png)
   The **Create token** pop-up box is displayed.
5. Do the following:
   1. Enter **Token name**.
   2. Select the API calls from the drop-down.

      <Note>
        **Note:** Select **Any IP**.
      </Note>

   3. Click **Create token**.
      ![How to Create a Token ID for Advanced... - screenshot 4](/images/intercom/13701658/image-7ac95ed8.png)
      The **Verify your Password** screen is displayed.
6. Enter **OKTA Password** and click **Verify**.
   ![How to Create a Token ID for Advanced... - screenshot 5](/images/intercom/13701658/c5ddcbe1-fc78-4f1c-9792-47081b55ae5d-95e54e17.png)
   The Token ID is created successfully. You can use this Token ID in the Tenant Admin Portal when configuring Advanced User Sync for Okta – Inbound.
   ![How to Create a Token ID for Advanced... - screenshot 6](/images/intercom/13701658/40485b1d-20ac-4fe4-a3e6-8e489bc3c883-2969029b.png)
