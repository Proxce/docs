Steps to Activate or Deactivate User:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Directory** on the left panel menu.
   ![How to activate or deactivate user - screenshot 1](/images/intercom/8344346/image-3b224d1d.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![Image](/images/intercom/8344346/9b287eaa-1d3e-494b-bf86-b55995ed9091-b4ba12ec.png)
   The user details page is displayed.
   ![How to activate or deactivate user - screenshot 2](/images/intercom/8344346/image-cf4f1f4b.png)
4. Do one of the following on **Action** dropdown:
   1. Select **Deactivate**.
      ![Image](/images/intercom/8344346/682975be-c73d-4e6b-a689-d549d4419a2a-7aea8c96.png)

      <Note>
        **Note:**

        **Deactivate** button is visible for active users in the action dropdown.
      </Note>

      The **De-activate User** pop-up box is displayed.
      ![How to activate or deactivate user - screenshot 3](/images/intercom/8344346/image-1c92e337.png)
   2. Click **Confirm De-activate**.
      The user status is changed from active to inactive.
      ![Image](/images/intercom/8344346/06f4f758-64bc-4122-8343-16fdd52b1ca9-b103490a.png)
   3. Select **Activate**.
      ![Image](/images/intercom/8344346/348a0f4a-3e40-45ab-abee-a0666162a489-04f27800.png)
      The **Activate User** pop-up box is displayed.
      ![How to activate or deactivate user - screenshot 4](/images/intercom/8344346/image-3e9a6154.png)
   4. Click **Confirm Activate**.
      The user status is changed from inactive to active.
      ![Image](/images/intercom/8344346/2d162474-665b-4957-88ef-44adc2bd841f-4c685714.png)
