Steps to send QR code link:

1. Log in to **Oloid Portal.**
2. On the homepage, click **Directory** from the left menu panel.
   ![Image](/images/intercom/9716724/3958fc81-6eb8-4ae9-bf4d-1c8314db18f0-1ce19d36.png)
   The **Users** page is displayed.
   ![How to send QR code link using Oloid... - screenshot 1](/images/intercom/9716724/image-d18fe4e9.png)
3. Do one of the followings.
   1. Select user (s) and then click **Action** > **Send Email** > **Send QR code link.**
      ![How to send QR code link using Oloid... - screenshot 2](/images/intercom/9716724/image-8f3e617d.png)
      The QR code link is sent successfully.
      ![How to send QR code link using Oloid... - screenshot 3](/images/intercom/9716724/image-e3e1636c.png)
   2. Click user name to edit.
      ![How to send QR code link using Oloid... - screenshot 4](/images/intercom/9716724/image-3cbd944a.png)
      The User details page is displayed.
      - Go to **Credentials** tab > **QR Code** > select **Send User Portal Link**.
        ![Image](/images/intercom/9716724/395e8dd8-8908-40c3-b657-609fdbc8c272-7f5cb906.png)
        The link is send successfully.
        ![How to send QR code link using Oloid... - screenshot 5](/images/intercom/9716724/image-15d8e6df.png)
        An email with the user portal link is sent to the registered Email ID.
4. Click the link.
   ![Image](/images/intercom/9716724/4712bade-179b-40cd-a3b3-f251f9a4b146-c6fcb512.png)
   The **Assigned QR Code** page is displayed to view and scan the QR code.
   ![How to send QR code link using Oloid... - screenshot 6](/images/intercom/9716724/image-33d27687.png)
