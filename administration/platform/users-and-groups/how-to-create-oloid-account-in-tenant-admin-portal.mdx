**Introduction**

An Oloid account is a User's unique ID created within the Tenant Admin Portal, enabling users to access Oloid’s Applications.

**Pre-requisite:**

- You must provide your email address or phone number to create OloID Account.
- You must turn on **Enable OloID Account** toggle button on the Connection detail page. For more information, see**[How to Enable OloID account in Connection](https://oloid.help/en/articles/8488406-how-to-enable-oloid-account-in-a-connection)**.

**Steps to Create Oloid Account:**

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to create Oloid account in Tenant... - screenshot 1](/images/intercom/8347798/bc033b34-1390-4b77-8543-dabdccea0c43-f50273fb.png)
   The **Users** page is displayed.
   ![How to create Oloid account in Tenant... - screenshot 2](/images/intercom/8347798/image-9cbbd1be.png)
3. To create multiple user's Oloid account do the following:
   1. Select **User name(s**)> **Action** > **Create Oloid Account**.
      ![How to create Oloid account in Tenant... - screenshot 3](/images/intercom/8347798/image-60889055.png)
4. To create single user's Oloid account do the following:
   1. Click User Name to edit.
      ![How to create Oloid account in Tenant... - screenshot 4](/images/intercom/8347798/image-75d79ef8.png)
   2. Go to **Action** > **Create Oloid Account**.
      The User details page is displayed.
      ![How to create Oloid account in Tenant... - screenshot 5](/images/intercom/8347798/image-b3f37b07.png)
      An Oloid account is successfully created. The user can now log in to Oloid Cloudkey app using their registered email id.
