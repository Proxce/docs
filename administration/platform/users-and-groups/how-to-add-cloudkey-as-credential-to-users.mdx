## Steps to create CloudKey

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **Directory** on the left panel menu.
   ![How to add CloudKey as credential to... - screenshot 1](/images/intercom/8290091/image-2124a09a.png)
   The **Users** page is displayed.
3. Click **user name** to edit.
   ![How to add CloudKey as credential to... - screenshot 2](/images/intercom/8290091/image-8f8cc4fe.png)
   The user details page is displayed.
4. Do one of the following:
   1. Go to **Credentials** > **Cloud Key** > **+ Create CloudKey**.
      ![How to add CloudKey as credential to... - screenshot 3](/images/intercom/8290091/0c1df59f-b90e-46b7-9d03-74dc33538cab-bb3502b4.png)
   2. Go to **Assign Credential** > **Create CloudKey**.
      ![How to add CloudKey as credential to... - screenshot 4](/images/intercom/8290091/image-fcdceabb.png)
      The **Create CloudKey** pop-up box is displayed.
      ![How to add CloudKey as credential to... - screenshot 5](/images/intercom/8290091/image-c8bd6e2c.png)
5. Enter **Start Date / Time** and **End Date/Time.**

   <Note>
     **Note:** You can click **Now** to set the current date and time. The end date is automatically set to 1 year from the current date.
   </Note>

   You can also click **10 years from Now** to set the **End Date/Time** to 10 years from the current date/time.

Click **Create**.

The cloudkey is created and listed on the **Cloud Key** tab.

![How to add CloudKey as credential to... - screenshot 6](/images/intercom/8290091/image-7e4de845.png)
