## Introduction

The Windows Passkey feature in the Tenant Admin Portal allows admin to securely create and assign passkeys for users to access Windows Login application.

## Prerequisites

- You must have Tenant Admin account.
- Passkey must be enabled as a credential in the tenant settings. For further information please refer: [Oloid Platform - How to enable Passkey in Tenant Admin Portal](https://oloid.help/en/articles/11035277-oloid-platform-how-to-enable-passkey-in-tenant-admin-portal)

## Steps to create Windows Passkey

1. Log in to the Tenant Admin Portal.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/11058549/42812ab0-d4c9-4fc6-9fcd-e2cf4ddd66ce-78fec51b.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![Image](/images/intercom/11058549/b6ed1a54-d8ed-4082-a31f-757e7f2b0747-0964db7e.png)
   The **user details** page is displayed.
   ![How to create Windows Passkey as... - screenshot 1](/images/intercom/11058549/image-495fe094.png)
4. Go to **Credentials** tab > **Windows Passkey** > **+ Windows Passkey**.
   ![How to create Windows Passkey as... - screenshot 2](/images/intercom/11058549/image-fc3fd22b.png)
   The **Create Windows Passkey** pop-up box is displayed.
5. Do the following:
   ![How to create Windows Passkey as... - screenshot 3](/images/intercom/11058549/image-9d7d9206.png)
   1. Enter **Display Name**. (Required)
   2. Click **Next**.
   3. Enter **Domain Name** associated with the Windows account. (Required)
   4. Enter **Windows Username** for the user account. (Required)
   5. Select Preferred Machine from the **Preferred Machine** dropdown list. (Optional)
   6. Upload the **Certificate** file or drag it into the upload area. You may also type or paste the certificate contents manually in the text box. (Required)
   7. Upload the **Private Key** file or drag it into the upload area. You may also type or paste the key contents manually in the text box.
   8. Click **Create**.

The Windows Passkey is created successfully.
