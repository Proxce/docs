## Introduction

The Other Identifiers feature in the Oloid Portal allows administrators to associate external system identifiers—such as Duo, Okta, or Ping IDs—with a user profile.

## Prerequisite

1. You must have a Tenant Admin account.
2. The user must already have other Identifier IDs created in their respective external systems.

## Steps to Add Identifiers

1. Login to the Tenant Admin Portal.
2. Click **Directory** Icon > **Users** tab
   ![How to Add Other Identifiers - screenshot 1](/images/intercom/13009576/image-52e2b5d5.png)
   User list is displayed
3. Click user name to edit.
   User details is displayed
   ![How to Add Other Identifiers - screenshot 2](/images/intercom/13009576/image-c6a546d8.png)
4. Under the Other Identifiers section Click **+ Add Identifier**
   Add Identifier pop-up box is displayed
   ![How to Add Other Identifiers - screenshot 3](/images/intercom/13009576/image-cd41d879.png)
5. **Select** Identifier from dropdown:
   1. Duo ID
   2. Okta ID
   3. Ping ID
6. Click **Add**.
   ![How to Add Other Identifiers - screenshot 4](/images/intercom/13009576/image-abbb2310.png)
7. The selected Identifier type field will appear. Enter the **Identifier ID**
8. Click **Save**.

Other Identifier is successfully added.
