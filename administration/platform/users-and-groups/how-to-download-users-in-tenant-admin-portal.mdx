Steps to download users:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/11401401/e6056a2e-4572-4771-a94b-d4cb68396faf-d18e9ae1.png)
   The **Users** page is displayed.
3. Select **Export all users**![How to Download Users in Tenant Admin... - screenshot 1](https://downloads.intercomcdn.com/i/o/e4gi378c/1530328195/64053d31bcd12751e3b50c778c49/image.png?expires=1790488800&signature=58f179099c273b894ec1b6ac5be4e2b222eece474b60967b3d9fda926e1a7b94&req=dSUkFsp8lYBWXPMW3nq%2BgWwt1NJRpsNrmQA7%2Btr%2BCxsK%2F%2FHQ25nyI%2FPa%2B5jo%0Aa4DoDtWNkfwQrMK1%2Bz7gJM0UJEw%3D%0A) icon to download users from connection or group.
   ![How to Download Users in Tenant Admin... - screenshot 2](/images/intercom/11401401/b985f685-3f46-4b81-adf9-0e7bacfc1721-9001c139.png)
   The **Export to Excel** pop-up box is displayed.
   ![How to Download Users in Tenant Admin... - screenshot 3](/images/intercom/11401401/image-49a493ff.png)
4. Do the following:
   - **Connection**: Select this option to export users associated with a specific connection.
     - Select the desired connection from the **Connections** drop-down.
       ![How to Download Users in Tenant Admin... - screenshot 4](/images/intercom/11401401/image-122f84bc.png)
       The selected connection is added in the Connections field.
   - **Group**: Export users associated with a specific group.
     - Select the desired group from the **Groups** drop-down.
       ![How to Download Users in Tenant Admin... - screenshot 5](/images/intercom/11401401/image-de003bc6.png)
       The selected group is added in the Groups field.
5. Click **Download**.

Click **Save**.

The report file is downloaded to your local device.
