## Introduction

Groups provide a structured way to organize users, endpoints, and shared credentials. They help manage access and configurations more effectively by grouping related Users together.

## Prerequisites

- You must have access to a Tenant Admin account.
- Ensure that the Group is already created. For more information, please refer: **[How to create group](https://oloid.help/en/articles/8294358-how-to-create-group)**

## Steps to configure a Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Groups** on the left menu panel.
   ![Image](/images/intercom/8311585/73c40144-2e9d-431c-bd9d-9b11e1f91951-d1f0e807.png)
   The **Groups** page is displayed.
3. Click the **Group Name** to be configured from the listed groups.
   ![How to Configure Group - screenshot 1](/images/intercom/8311585/image-79e8000c.png)
   The **Group** details page is displayed.
   ![How to Configure Group - screenshot 2](/images/intercom/8311585/image-0522d407.png)
4. Do the following:
   [Configure Details tab](#configure-details-tab)
   [Configure Endpoint Tab](#configure-endpoint-tab)
   [Configure Users Tab](#configure-users-tab)
   [View Shared Credentials](#view-shared-credentials)

### Configure Details Tab

1. On the **Detail**s page, enter **Description** (Optional)**.**
2. Click **Save**.
   ![How to Configure Group - screenshot 3](/images/intercom/8311585/image-9a8a18c3.png)

### Configure Endpoint Tab

1. Click **Add Endpoint button** to add endpoint to the group. For more information, refer to [How to Add Endpoint to a group](https://oloid.help/en/articles/8315188-how-to-add-endpoint-to-a-group)

![How to Configure Group - screenshot 4](/images/intercom/8311585/image-8fa014fb.png)

### Configure Users Tab

Click **Add User** to add user to the group. For more information, [How to Map Users to a Group](https://oloid.help/en/articles/8267045-how-to-map-users-to-a-group)

![How to Configure Group - screenshot 5](/images/intercom/8311585/image-b7fde152.png)

### View Shared Credentials

The **Shared Credentials** tab within a group allows Tenant Admin to view all shared credentials assigned to that group.

<Note>
  **Note:** Shared Credentials tab only appears if any shared credential has been assigned to the group. For more information, refer: [How to Add a Group to Windows Shared Passwords](https://oloid.help/en/articles/13348724-how-to-add-a-group-to-windows-shared-passwords)
</Note>

Click **Shared Credentials** tab to view shared credentials assigned to the group.

![How to Configure Group - screenshot 6](/images/intercom/8311585/image-8facc7ba.png)

The Group is configured successfully.

![How to Configure Group - screenshot 7](/images/intercom/8311585/image-846faaaa.png)
