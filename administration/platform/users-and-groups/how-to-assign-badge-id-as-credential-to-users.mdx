#### Introduction

This document provides step-by-step instructions to assign Badge ID as a credential to users in the Tenant Admin Portal, including how to set the Wiegand format and link the Badge ID to a user’s profile.

#### Steps to assign Badge

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/8379462/42812ab0-d4c9-4fc6-9fcd-e2cf4ddd66ce-78fec51b.png)
   The **Users** page is displayed.
3. Click user name to edit.
   ![Image](/images/intercom/8379462/b6ed1a54-d8ed-4082-a31f-757e7f2b0747-0964db7e.png)
   The **user details** page is displayed.
   ![How to assign Badge ID as credential to... - screenshot 1](/images/intercom/8379462/image-495fe094.png)
4. Do one of the following:
   1. Go to **Credentials** tab > **Badge** > **+ Assign Badge**.
      ![Image](/images/intercom/8379462/f472e049-e86c-4d78-8473-dd3a59df3a4b-91acdab2.png)
   2. Go to **Assign Credential** > **Assign Badge**.
      ![Image](/images/intercom/8379462/69b35fdf-cb6d-442b-ba92-0151178428a2-0d929e6c.png)
      The **Assign Badge** pop-up box is displayed.
      ![How to assign Badge ID as credential to... - screenshot 2](/images/intercom/8379462/image-10b3b291.png)
5. Enter **Badge ID** and select **Wiegand Format**.
6. Click **Assign**.
   The badge ID is assigned and listed on the **Badge** tab.
   ![Image](/images/intercom/8379462/a8511e43-c519-4064-beae-28b481955ee4-38f58d8c.png)
