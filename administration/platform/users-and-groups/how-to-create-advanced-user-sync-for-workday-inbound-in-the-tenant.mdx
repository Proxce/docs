## Introduction

The **Advanced User Sync** feature in the Tenant Admin Portal allows admin to create and manage user synchronization using supported agents such as **Workday – Inbound**, ensuring accurate and consistent user data in the Oloid Tenant Admin Portal.

## Prerequisite

You must have **Admin access** to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**.
   ![Inbound in the Tenant Admin Portal - screenshot 1](/images/intercom/13559374/image-a28bb49f.png)
   The Advanced User Sync page is displayed.
3. Click **Create User Sync**.
   ![Inbound in the Tenant Admin Portal - screenshot 2](/images/intercom/13559374/image-ccf77ce8.png)
   The **Create User Sync** pop-up box is displayed.
4. Do the following:
   1. Enter **User Sync Name**.
   2. Select **Agent**.

      <Note>
        **Note:** Select **Workday - Inbound** as agents.
      </Note>

   3. Click **Create**.
      ![Inbound in the Tenant Admin Portal - screenshot 3](/images/intercom/13559374/image-f62412bc.png)
      The advanced user sync for Workday - Inbound is created successfully.
      ![Inbound in the Tenant Admin Portal - screenshot 4](/images/intercom/13559374/image-88013855.png)
