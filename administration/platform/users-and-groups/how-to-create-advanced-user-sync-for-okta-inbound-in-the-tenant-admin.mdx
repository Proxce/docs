## Introduction

The **Advanced User Sync** feature allows admin to create and manage user synchronization using supported agents such as **OKTA – Inbound**, ensuring accurate and consistent user data in the Tenant Admin Portal.

## Prerequisite

You must have **Admin access** to the Tenant Admin Portal.

## Steps to Create Advanced User Sync

1. Log in to the **Tenant Admin Portal**.
2. Go to **Agents** tab > **Advanced User Sync**.
   ![Inbound in the Tenant Admin Portal - screenshot 1](/images/intercom/13700439/image-a28bb49f.png)
   The Advanced User Sync page is displayed.
3. Click **Create User Sync**.
   ![Inbound in the Tenant Admin Portal - screenshot 2](/images/intercom/13700439/image-ccf77ce8.png)
   The **Create User Sync** pop-up box is displayed.
4. Do the following:
   1. Enter **User Sync Name**.
   2. Select **Okta - Inbound** as Agent.
   3. Click **Create**.
      ![Inbound in the Tenant Admin Portal - screenshot 3](/images/intercom/13700439/image-c5e86a5f.png)
      The advanced user sync for Okta - Inbound is created successfully.
      ![Inbound in the Tenant Admin Portal - screenshot 4](/images/intercom/13700439/image-56e5c6db.png)
