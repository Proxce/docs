## Introduction

This document provides step-by-step instructions to invite a user to add their face via email or SMS in the Tenant Admin Portal.

## Prerequisites

- You must have Tenant admin access to the Tenant Admin Portal.
- User must be created. For more, refer to[Tenant Admin Portal - How to Create User](https://oloid.help/en/articles/8185048-tenant-admin-portal-how-to-create-user)
- The registered email ID must be added to the user's profile on the Tenant Admin Portal.

This document comprises the following:

- [Invite to Add a Face via Email](#steps-to-send-an-invite-to-add-a-face-via-email)
- [Invite to Add a Face via SMS](#steps-to-send-an-invite-to-add-a-face-via-sms)

## Steps to Send an Invite to Add a Face via Email

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Invite to Add Face - screenshot 1](/images/intercom/8398578/image-dfd9789d.png)
   The **Users** page is displayed.
   ![Image](/images/intercom/8398578/97b7fe92-4793-4857-86a0-84b4bd021d43-ee9eae4e.png)
3. Click **username** to edit.
   ![Image](/images/intercom/8398578/81bc9c2a-f770-4ac1-98b0-cb2678ca6c59-119a32b2.png)
   The user details page is displayed.
   ![How to Invite to Add Face - screenshot 2](/images/intercom/8398578/image-5a7301a6.png)
4. Go to **Credentials** > **Face** > **Invite to Add Face.**
   ![How to Invite to Add Face - screenshot 3](/images/intercom/8398578/image-c977dbaa.png)
5. Select **Send via Email** optionfrom the dropdown list.
   ![How to Invite to Add Face - screenshot 4](/images/intercom/8398578/image-b00b37c4.png)
   The **Email Invitation Preview** pop-up box is displayed.
6. Do the following:
   ![How to Invite to Add Face - screenshot 5](/images/intercom/8398578/image-2a625eae.png)
   1. Enter the recipient's email ID(s) in the **Send Email to** field.
   2. Edit **Email Subject** field.(Optional)
   3. Edit **Email Body** field.(Optional)
   4. Click **Send**.
      An email with invite link is sent to user to upload their face.
      ![How to Invite to Add Face - screenshot 6](/images/intercom/8398578/image-4b158344.png)
      The user receives an email with an invite link. Clicking the link directs the user to the **self-service portal** to upload their face.
      ![How to Invite to Add Face - screenshot 7](/images/intercom/8398578/5ca1f9b1-f414-472a-a042-7d1d13b4dd04-54e5b8c7.png)
      To upload face using the invite link, see [How to add face using the invite link](https://oloid.help/en/articles/8472935-how-to-add-face-using-the-invite-link)

## Steps to Send an Invite to Add a Face via SMS

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Invite to Add Face - screenshot 8](/images/intercom/8398578/image-dfd9789d.png)
   The **Users** page is displayed.
   ![Image](/images/intercom/8398578/97b7fe92-4793-4857-86a0-84b4bd021d43-ee9eae4e.png)
3. Click **username** to edit.
   ![Image](/images/intercom/8398578/81bc9c2a-f770-4ac1-98b0-cb2678ca6c59-119a32b2.png)
   The user details page is displayed.
   ![How to Invite to Add Face - screenshot 9](/images/intercom/8398578/image-5a7301a6.png)
4. Go to **Credentials** > **Face** > **Invite to Add Face.**
   ![How to Invite to Add Face - screenshot 10](/images/intercom/8398578/image-6104d2aa.png)
5. Select **Send via SMS**.
   ![How to Invite to Add Face - screenshot 11](/images/intercom/8398578/image-2bf9fd9d.png)
   The **SMS Invitation Preview** pop-up box is displayed.
6. Do the following:
   ![How to Invite to Add Face - screenshot 12](/images/intercom/8398578/9ea5c617-2491-46f6-95ac-f7af64d63f17-b1b0b20f.png)
   1. Enter the **User's Phone Number** in the **Enter Phone Number** field.

      <Note>
        **Note:** Select the country icon to change the country code prefix.
      </Note>

   2. Click **Save**.
      An SMS with invite link is sent to the user to upload their face.
      ![How to Invite to Add Face - screenshot 13](/images/intercom/8398578/image-87ef8dbc.png)
      The user receives SMS with an invite link. Clicking the link directs the user to the **self-service portal** to upload their face.
      ![How to Invite to Add Face - screenshot 14](/images/intercom/8398578/image-b4a20a31.png)
