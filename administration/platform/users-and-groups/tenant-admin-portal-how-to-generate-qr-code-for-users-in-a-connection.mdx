## Introduction

This document provides instructions to generate and assign **QR Code credentials** to users in a selected Connection in the Tenant Admin Portal.

## Prerequisites

- You must have Tenant Admin Access.
- Connection must be created. For more, refer to[Tenant Admin Portal - How to Create Connection](https://oloid.help/en/articles/8294297-tenant-admin-portal-how-to-create-connection)

## Steps to Generate QR Code for a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Generate QR Code for Users in a... - screenshot 1](/images/intercom/8385745/image-50753e72.png)
   The **Users** page is displayed.
3. Go to **Action** > **Generate QR Code Credential**.
   ![How to Generate QR Code for Users in a... - screenshot 2](/images/intercom/8385745/image-f76775ff.png)
   The **Generate QR Code** pop-up box is displayed.
4. On the pop-up box, do the following:
   1. Select the connection from the **Connection** dropdown list.
   2. Under **QR Code Validity** field adjust the date and time from the calendar icon.
   3. Under **Share Summary With** field, enter the email ID(s) with whom you want to share the QR Code summary. (**optional**)
   4. Enable **Send QR Code** to get the generated QR codes with summary. (**optional**)
   5. Click **Assign**.
      ![How to Generate QR Code for Users in a... - screenshot 3](/images/intercom/8385745/image-b3349c71.png)
      The QR Code credentials are successfully assigned to users in the selected connection. The QR Code summary of these users is shared over email ID(s).
      ![How to Generate QR Code for Users in a... - screenshot 4](/images/intercom/8385745/image-de762b74.png)
