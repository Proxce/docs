Steps to delete QR Code Credential of Users in a Connection:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![Image](/images/intercom/8488468/9b73adc6-ba8f-49fc-85ba-aa6af6b7eb8c-716cd336.png)
   The **Users** page is displayed.
3. Go to **Action** > **Delete QR Code Credential**.
   ![Image](/images/intercom/8488468/e49fd567-05e9-475e-9b82-72d4f1454ffa-f278564a.png)
   The **Delete QR Code Credential** pop-up box is displayed.
   ![How to delete QR Code Credential of... - screenshot 1](/images/intercom/8488468/image-a10f0c24.png)
4. On the pop-up box, do the following:
   1. Select the connection from the **Connection** dropdown list.
   2. Under **Share Summary With** field enter the email ID(s) with whom you want to share the QR Code summary. (optional)
   3. Click **Delete**.
      The QR Code is successfully deleted for users in the selected connection. The QR Code summary of these users is shared over email ID(s).
      ![How to delete QR Code Credential of... - screenshot 2](/images/intercom/8488468/image-a8151c23.png)
