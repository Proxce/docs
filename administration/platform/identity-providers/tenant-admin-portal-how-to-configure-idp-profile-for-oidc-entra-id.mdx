## Introduction

This document helps to configure an **OIDC-** based **Entra ID Identity Provider (IdP) profile** in the Oloid Tenant Admin Portal.

## Prerequisites

- You must have access to **Tenant Admin Portal**.
- IDP profile for Entra ID must be created in Tenant Admin Portal. To know more, refer [How to Create IDP Profile for OIDC-Entra ID in Tenant Admin Portal](https://oloid.help/en/articles/13349621-how-to-create-idp-profile-for-oidc-entra-id-in-tenant-admin-portal).
- IDP Profile for Entra ID must be created and Configured in the Entra ID Admin Console. To know more, refer [Integrating Oloid as an External Method Authentication (EAM) with Microsoft Entra ID](https://oloid.help/en/articles/10299916-integrating-oloid-as-an-external-method-authentication-eam-with-microsoft-entra-id)

## Steps to Configure IDP Profile for OIDC - Entra ID

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security** > **Identity Provider**.
   ![How to Configure IDP Profile for... - screenshot 1](/images/intercom/13373994/image-f62754f4.png)
   The **Identity Provider Profiles** page is displayed.
3. Select an IDP Profile for Entra ID.
   ![How to Configure IDP Profile for... - screenshot 2](/images/intercom/13373994/image-7b1a9741.png)
   The IDP Profile details page is displayed.
4. Do the following:
   1. [Configure Details tab](#configure-details-tab)
   2. Integrate Metadata tab for Entra ID Settings
   3. [Configure IDP Settings tab](#configure-idp-settings-tab)
      The IDP Profile is configured.

### Configure Details Tab

1. Click **Details** tab and do the following:
   1. Edit the **IDP Name**. (if required)
   2. Enter **Description**. (Optional)
   3. Select the required WebKey application from the **Select WebKey Application** drop-down.
   4. Click **Save**.
      ![How to Configure IDP Profile for... - screenshot 3](/images/intercom/13373994/image-1f078f31.png)
   5. Click **Make Default** to set this IDP as default. (Optional)

      <Note>
        **Note:** If another IDP is currently set as default, it will be replaced upon confirmation.
      </Note>

      ![How to Configure IDP Profile for... - screenshot 4](/images/intercom/13373994/image-95256dbe.png)
      The confirmation box is displayed.
   6. Click **Set as Default** to designate the preferred IDP as default.
      ![How to Configure IDP Profile for... - screenshot 5](/images/intercom/13373994/fd786cd3-9105-4326-b0c0-d84a80db1990-abefadd5.png)
      The detail tab is configured successfully.

### Integrate Oloid Metadata tab for Entra ID Settings

This section provides Oloid Metadata information for Microsoft Entra ID settings.

Copy the **Authorization URL** and enter it in the Redirect URL field in the Microsoft Entra ID Admin Console.

![How to Configure IDP Profile for... - screenshot 6](/images/intercom/13373994/image-30d85921.png)

### Configure IDP Settings Tab

1. Click **IDP Settings** tab.
   The IDP Settings tab is displayed.
   ![How to Configure IDP Profile for... - screenshot 7](/images/intercom/13373994/c934f2ba-6a78-41df-959d-b111f2b8a937-24eff067.png)
2. Do the following:
   1. Enter **IDP ID**.
      ![How to Configure IDP Profile for... - screenshot 8](/images/intercom/13373994/image-dafcb435.png)

      <Note>
        **Note:** The Directory (tenant) ID is the IDP id. You can find this in the Entra ID Admin Console on the **Overview** tab.
      </Note>

      ![How to Configure IDP Profile for... - screenshot 9](/images/intercom/13373994/7a48fb47-2985-4d66-9cab-21dd5facbb93-f247f628.png)
   2. Enter **Application Client ID**.
      ![How to Configure IDP Profile for... - screenshot 10](/images/intercom/13373994/image-14abc23d.png)

      <Note>
        **Note:** You can find this in the Entra ID Admin Console on the **Overview** tab.
      </Note>

      ![How to Configure IDP Profile for... - screenshot 11](/images/intercom/13373994/image-d9ba2be2.png)
   3. Enter **Authorize URL**.
      ![How to Configure IDP Profile for... - screenshot 12](/images/intercom/13373994/image-af6f876d.png)

      <Note>
        **Note:** You can find this in the Entra ID Admin Console under **Overview > Endpoints > OpenID Connect metadata document**.
      </Note>

      ![How to Configure IDP Profile for... - screenshot 13](/images/intercom/13373994/f3ee1f62-bb74-4d30-b7e1-ff539e1b28fa-798d7a91.png)
   4. Enter **Redirect URL**.
      ![How to Configure IDP Profile for... - screenshot 14](/images/intercom/13373994/image-5b6e324d.png)

      <Note>
        **Note:** You can find this in the Tenant Admin Portal under **Metadata tab > Authorization Endpoint**.
      </Note>

      ![How to Configure IDP Profile for... - screenshot 15](/images/intercom/13373994/image-cecf0d39.png)
   5. Enter **Callback URL (Optional)**.
      ![How to Configure IDP Profile for... - screenshot 16](/images/intercom/13373994/image-82d2e43a.png)
   6. Enter **Secret**.
      ![How to Configure IDP Profile for... - screenshot 17](/images/intercom/13373994/image-4603a435.png)

      <Note>
        **Note:** You can find this in the Entra ID Admin Console under **Manage > Certificates and Secrets > Client secrets**.
      </Note>

      ![How to Configure IDP Profile for... - screenshot 18](/images/intercom/13373994/b8aaa1b5-8573-4bf8-b38e-9897cb6435f6-6fe0710e.png)
   7. **Home URL:** Enter the URL of the home page.
   8. **Home Label Button:** Enter the text displayed on the **Home** button.
      ![How to Configure IDP Profile for... - screenshot 19](/images/intercom/13373994/image-2b2ead6a.png)
   9. Click **Save**.
      ![How to Configure IDP Profile for... - screenshot 20](/images/intercom/13373994/6e183643-52f6-45e7-b0f1-29663f3488a3-5e5eb11f.png)
      The IDP settings tab is configured successfully.
