## Introduction

This document explains how to create a **SAML Identity Provider (IdP) profile** in the Oloid Portal to enable SAML-based authentication.

## Prerequisite

You must have Admin access to the Tenant Admin Portal.

## Steps to Create SAML IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security** > **Identity Provider**.
   ![How to Create IDP Profile for Security... - screenshot 1](/images/intercom/12808717/image-6c11c80a.png)
   The **Identity Provider Profiles** page is displayed.
3. Select **Create IDP** in the top right corner.
   ![How to Create IDP Profile for Security... - screenshot 2](/images/intercom/12808717/image-a3a9d91d.png)

   <Note>
     **Note:** You cannot create a new IDP unless a default IDP is already set. Please open an existing IDP and mark it as default before proceeding. For more details refer [How to make an IDP default](https://oloid.help/en/articles/11401191-how-to-link-multiple-webkey-applications-with-identity-provider-profile-idp#h_ba61702807).
   </Note>

   ![How to Create IDP Profile for Security... - screenshot 3](/images/intercom/12808717/image-faa58446.png)
   The **Create New IDP** pop-up box is displayed.
4. Do the following:
   1. Enter **IDP Name**.
   2. Select **SAML** asAuth Protocol.
   3. Click **Create**.
      ![How to Create IDP Profile for Security... - screenshot 4](/images/intercom/12808717/image-7f5bedc9.png)
      The IDP Profile for SAML is successfully created.
      ![How to Create IDP Profile for Security... - screenshot 5](/images/intercom/12808717/image-51745e38.png)
