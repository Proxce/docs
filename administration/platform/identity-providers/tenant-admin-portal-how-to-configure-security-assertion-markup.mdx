## Introduction

The SAML–Okta Identity Provider (IdP) Profile enables secure authentication between Okta and the Oloid Tenant Admin Portal. Configuring SAML allows users to sign in to Oloid applications using their Okta credentials.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure that the **SAML IDP** application is created. To create SAML application, refer [How to Create IDP Profile for Security Assertion Markup Language (SAML) in the Tenant Admin Portal](https://oloid.help/en/articles/12808717-how-to-create-idp-profile-for-security-assertion-markup-language-saml-in-the-tenant-admin-portal).
- Ensure that the required **Okta SAML parameters** are available or can be generated from the SAML Identity Provider configuration in the Okta Admin Console. To see the parameter, refer [How to Configure Security Assertion Markup Language (SAML) IDP in OKTA Admin Console](https://oloid.help/en/articles/12838654-how-to-configure-security-assertion-markup-language-saml-idp-in-okta-admin-console).
- Ensure that the Webkey application is created. To create Webkey application, refer [How to create and configure WebKey Application in Tenant Admin Portal](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application-in-tenant-admin-portal).

## Steps to Configure SAML-Okta IDP Profile

1. Log in to the **Oloid Tenant Admin Portal**.
2. On the **Applications** page, click **Auth Policies** > **Identity Provider**.
   ![How to Configure Security Assertion... - screenshot 1](/images/intercom/12840218/image-17a59e0b.png)
   The **Identity Provider Profiles** page is displayed.
3. Click preferred SAML-IDP application.
   ![How to Configure Security Assertion... - screenshot 2](/images/intercom/12840218/image-f461ca72.png)
   The IDP details page is displayed.
   ![How to Configure Security Assertion... - screenshot 3](/images/intercom/12840218/image-6a36c740.png)
4. Do the following:
   1. [Configure Details tab](https://oloid.help/en/articles/9215949-how-to-configure-oidc-okta-idp-profile#h_b9bb2a15fd)
   2. [Integrate Metadata tab for Okta Settings](https://oloid.help/en/articles/9215949-how-to-configure-oidc-okta-idp-profile#h_9da1653b28)
   3. [Configure IDP Settings tab](https://oloid.help/en/articles/9215949-how-to-configure-oidc-okta-idp-profile#h_18d3ee2df6)
   4. [Configure Claims tab](#configure-claims-tab-optional)
      The IDP Profile is configured successfully.

### Configure Metadata Tab

The Metadata tab is used to provide the required information to configure SAML settings and enable SAML-based authentication between the identity provider and the Tenant Admin Portal.

1. Click **Oloid Metadata** tab.
   The Oloid Metadata tab is displayed.

### Configure Claims Tab (Optional)

The **Claims** tab is used to configure custom claims that pass user attributes from Oloid to the SAML provider.

Do the following:

#### Add Additional Claims

Additional Claims allow the admin to map Oloid user attributes to SAML attributes.

Do the following:

1. In the **Additional Claims** section, click **Add Field**.
   ![How to Configure Security Assertion... - screenshot 25](/images/intercom/12840218/image-810274ca.png)
2. In the **SAML Claim** field, enter the claim name to be sent to the service provider.
3. Selectone of the following types.
   - **Basic:** Standard claim format.
   - **Unspecified:** No specific format defined.
   - **URI Reference:** Claim uses a URI-based format.
4. In the **Oloid Value** dropdown, select the corresponding Oloid attribute (for example, Oloid ID).

   <Note>
     **Note:** Click **Add Field** to add additional claim items.
   </Note>

5. Click **Save.**
   ![How to Configure Security Assertion... - screenshot 26](/images/intercom/12840218/image-8431ae5d.png)
   The Custom claims tab is configured.

#### Group Claims

The **Group Claims** section allows you to pass user group-related attributes from Oloid to the Service Provider during authentication.

1. In the **Group Claims** tab, expand the **Group Claims** section.
   The Group Claims section is displayed.
2. Click **Add Field**.
   ![How to Configure Security Assertion... - screenshot 27](/images/intercom/12840218/image-ad0015a8.png)
3. Enter the following details:
   1. **Attribute Name**: Enter the group attribute name to be sent to the Service Provider.
   2. **Type**: Select the claim format:
      1. **Basic**
      2. **Unspecified**
      3. **URI Reference**
   3. **Oloid Value**: Enter or select the group-related value.
   4. **Condition**: Select one of the following:
      1. **Contains**
      2. **Equal**
      3. **Starts With**
4. Click **Save**.
   ![How to Configure Security Assertion... - screenshot 28](/images/intercom/12840218/906fabe7-8c5d-498b-8e8a-9edd285867d3-ca254299.png)
   The **Group Claims** section is configured successfully.
   ![How to Configure Security Assertion... - screenshot 29](/images/intercom/12840218/image-8387edaa.png)
   The **SAML IDP** is successfully configured.
   ![How to Configure Security Assertion... - screenshot 30](/images/intercom/12840218/698e087f-a41c-4a85-b3f5-79d9a0e6d986-26d00f44.png)
