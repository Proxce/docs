## Introduction

Identity providers (IDP) help the system store and verify the user identity. Oloid acts as IDP for Passwordless SSO use cases.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create PingOne IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security** > **Identity Provider**.
   ![How to Create IDP Profile for... - screenshot 1](/images/intercom/10822772/image-c44e8028.png)
   The **Identity Provider Profiles** page is displayed.
3. Select **Create IDP** in the top right corner.
   ![How to Create IDP Profile for... - screenshot 2](/images/intercom/10822772/image-7d9c971d.png)

   <Note>
     **Note:** You cannot create a new IDP unless a default IDP is already set. Please open an existing IDP and mark it as default before proceeding. For more details refer [How to make an IDP default](https://oloid.help/en/articles/11401191-how-to-link-multiple-webkey-applications-with-identity-provider-profile-idp#h_ba61702807).
   </Note>

   ![How to Create IDP Profile for... - screenshot 3](/images/intercom/10822772/image-faa58446.png)
   The **Create New IDP** pop-up box is displayed.
4. Do the following:
   1. Enter **IDP Profile Name**.
   2. Select **OIDC** asAuth Protocol.
   3. Select **Next**.
   4. Select **PingOne** as IDP Provider for OIDC.
   5. Click **Create**.
      ![How to Create IDP Profile for... - screenshot 4](/images/intercom/10822772/image-14619411.png)
      The IDP Profile for OIDC-PingOne is successfully created.

![How to Create IDP Profile for... - screenshot 5](/images/intercom/10822772/image-673efb0e.png)
