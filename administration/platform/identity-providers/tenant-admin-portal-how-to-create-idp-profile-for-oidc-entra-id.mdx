## Introduction

Identity Providers (IDPs) are used to manage and verify user identities for authentication. This document explains how to create an **Entra ID Identity Provider (IDP) profile** in the Tenant Admin Portal using **OIDC authentication**.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Entra ID IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, select **Security** > **Identity Provider**.
   ![How to Create IDP Profile for... - screenshot 1](/images/intercom/13349621/image-d95e6ed3.png)
   The **Identity Provider Profiles** page is displayed.
3. Click **Create IDP** in the top right corner.
   ![How to Create IDP Profile for... - screenshot 2](/images/intercom/13349621/image-2da0d08b.png)

   <Note>
     **Note:** You cannot create a new IDP unless a default IDP is already set. Please open an existing IDP and mark it as default before proceeding. For more details refer [How to make an IDP default](https://oloid.help/en/articles/11401191-how-to-link-multiple-webkey-applications-with-identity-provider-profile-idp#h_ba61702807).
   </Note>

   ![How to Create IDP Profile for... - screenshot 3](/images/intercom/13349621/image-faa58446.png)
   The **Create New IDP Profile** pop-up box is displayed.
4. Do the following:
   1. Enter **IDP Name**.
   2. Select **OIDC** asAuth Protocol.
   3. Click **Next**.
   4. Select **Entra ID** as IDP Provider for OIDC.
   5. Click **Create**.
      ![How to Create IDP Profile for... - screenshot 4](/images/intercom/13349621/image-8bd921e9.png)
      The IDP Profile for OIDC Entra ID is created successfully.
      ![How to Create IDP Profile for... - screenshot 5](/images/intercom/13349621/image-c238c17e.png)
