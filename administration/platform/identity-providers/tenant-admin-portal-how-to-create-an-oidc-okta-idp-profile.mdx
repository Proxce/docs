## Introduction

This document provides instructions to create an Okta IdP profile in the Oloid Portal. An IdP profile enables passwordless SSO authentication using Okta.

## Prerequisites

You must have Admin access to the Tenant Admin Portal.

## Steps to Create an Okta Idp Profile

1. Log in to the **Tenant Admin Portal**.
2. On the home page, select **Security** > **Identity Provider**.
   ![How to Create an OIDC-Okta IDP Profile - screenshot 1](/images/intercom/9214537/image-2a18490b.png)
   The **Identity Provider Profiles** page is displayed.
3. Click **Create IDP**.
   ![How to Create an OIDC-Okta IDP Profile - screenshot 2](/images/intercom/9214537/143a12e6-834a-477a-920c-8efaacbe1c17-c3316782.png)

   <Note>
     **Note:** You cannot create a new Idp unless a default Idp is already set. Please open an existing Idp and mark it as default before proceeding. For more details refer [How to make an IDP default](https://oloid.help/en/articles/11401191-how-to-link-multiple-webkey-applications-with-identity-provider-profile-idp#h_ba61702807).
   </Note>

   ![How to Create an OIDC-Okta IDP Profile - screenshot 3](/images/intercom/9214537/image-faa58446.png)
   The **Create New IDP** pop-up box is displayed.
4. Do the following:
   1. Enter the **IDP Profile Name**.
   2. Select **OIDC** asanAuth Protocol.
   3. Click **Next**.
   4. Select **Okta** as the IDP Provider for OIDC.
   5. Click **Create**.
      ![How to Create an OIDC-Okta IDP Profile - screenshot 4](/images/intercom/9214537/image-657c1430.png)
      The Okta IdP profile is created successfully.
      ![How to Create an OIDC-Okta IDP Profile - screenshot 5](/images/intercom/9214537/image-c739087b.png)
