**Introduction**

This document provides step-by-step instructions on how Oloid's WebKey application integrates with PingOne as an external OpenID Connect (OIDC) Identity Provider (IdP).

1. Sign in to the Ping Identity Administrator Console with your PingOne account credentials
2. Select **Create Environment**, then select **Create a Customer Solution**.
   ![Integrating Oloid tenant to your... - screenshot 1](/images/intercom/10796370/image-26f01078.png)
   ![Integrating Oloid tenant to your... - screenshot 2](/images/intercom/10796370/image-7cf8bf37.png)
3. Go to the newly created environment and select **Manage Environment**.
   ![Integrating Oloid tenant to your... - screenshot 3](/images/intercom/10796370/4c4ba1e5-eb54-450f-9107-ed1724bdca3f-af92483c.png)
4. On the left menu panel, select **Integrations > External IdPs**.
   ![Integrating Oloid tenant to your... - screenshot 4](/images/intercom/10796370/8a5158f9-2f6b-461d-9fff-7da75f002bd4-0c2c21af.png)
   The Identity Providers page is displayed.
5. Select **+Add Provider**.
   ![Integrating Oloid tenant to your... - screenshot 5](/images/intercom/10796370/52b58014-749a-4425-91ec-12c322fc2b6f-6a60eaeb.png)
6. Select **OpenID Connect** under Custom.
   ![Integrating Oloid tenant to your... - screenshot 6](/images/intercom/10796370/2c519bd8-55a7-4735-b222-68e4dbff12d6-03da13d3.png)
7. Do the following:
   1. Enter a unique name for the Identity Provider profile in the **NAME** field.
   2. Enter a description to help identify the purpose of this profile in the **DESCRIPTION** field.
   3. Click **Continue**.
      ![Integrating Oloid tenant to your... - screenshot 7](/images/intercom/10796370/cc7c2e23-912f-45b2-99d9-f13dfa8a1cdf-19f7dffd.png)
      The Configure OpenID Connect Connection section is displayed.
   4. Enter **ClientID** and **Client Secret** provided by Oloid Admin.
      ![Integrating Oloid tenant to your... - screenshot 8](/images/intercom/10796370/d00bdbdc-da34-41a0-9824-a22ab164194f-a0fffb89.png)
   5. Enter **OpenID Configuration Endpoint** from Oloid Tenant Admin Portal in the **Discovery Document URI** field.

      <Note>
        **Note:** To find the **OpenID Configuration Endpoint** in the Oloid Tenant Admin Portal, go to **Auth Policies** > **Identity Provider** > select **IDP Profile** > **Meta Data** tab > **OpenID Configuration Endpoint**.
      </Note>

      ![Integrating Oloid tenant to your... - screenshot 9](/images/intercom/10796370/d5512f46-f368-4ee2-8b66-18d5bc27be0d-ea4a75c0.png)
      ![Integrating Oloid tenant to your... - screenshot 10](/images/intercom/10796370/b087c1e3-2a4c-46f9-8555-f40ca827477f-db57caab.png)
   6. Next, select **Use Discovery Document**.
      This auto-fills the remaining endpoints.
      ![Integrating Oloid tenant to your... - screenshot 11](/images/intercom/10796370/1ce1f7c5-036b-4648-baf9-00d6c5f29e78-ce8956b7.png)
   7. Select **Client Secret Basic** as **TOKEN ENDPOINT AUTHENTICATION METHOD**.
      ![Integrating Oloid tenant to your... - screenshot 12](/images/intercom/10796370/image-df809ed5.png)
   8. Click **Save and Continue**.
      ![Integrating Oloid tenant to your... - screenshot 13](/images/intercom/10796370/78eb6cd7-12b8-40c3-a3ec-f01aa26d9427-e4afe936.png)
      The Map Attributes section is displayed.
   9. Click **+ADD ATTRIBUTE**.
      ![Integrating Oloid tenant to your... - screenshot 14](/images/intercom/10796370/b92c083a-e7cb-4259-923b-6c974e61a68c-9208e91d.png)
   10. Select **Email Address** from **PINGONE USER PROFILE ATTRIBUTE** dropdown list.
       ![Integrating Oloid tenant to your... - screenshot 15](/images/intercom/10796370/image-6ca072d4.png)
   11. Set **providerAttributes.Email** in **OIDC ATTRIBUTE** field.
       ![Integrating Oloid tenant to your... - screenshot 16](/images/intercom/10796370/91efed97-dde6-4198-bcd0-0397c8fff6cf-99d0cee4.png)
   12. Select **Empty Only** from **UPDATE CONDITION** dropdown list.
       ![Integrating Oloid tenant to your... - screenshot 17](/images/intercom/10796370/f929c124-b7ac-41d5-84f5-407a2a29d180-81f1dc1b.png)
   13. Select **Save and Finish**.
       ![Integrating Oloid tenant to your... - screenshot 18](/images/intercom/10796370/78748a6d-cbf4-4674-9695-82cd3aa5ca27-791b5992.png)
8. Enable the newly created IDP from the External IdPs list.
   ![Integrating Oloid tenant to your... - screenshot 19](/images/intercom/10796370/eb0dda5a-3a0a-4c28-bf31-4664794d4651-95977573.png)
9. Go to the **Connection** tab, copy the **CALLBACK URL,** and paste it in the Oloid Tenant Admin Portal in **Callback URL** field.

   <Note>
     **Note:** To find the **Callback URL** field in the Oloid Tenant Admin Portal, go to **Auth Policies** > **Identity Provider** > select **IDP Profile** > **IDP Settings** tab > **Callback URL**.
   </Note>

   ![Integrating Oloid tenant to your... - screenshot 20](/images/intercom/10796370/94647849-25ad-4e3f-aabe-cafce7f496e2-b83cffe4.png)
   ![Integrating Oloid tenant to your... - screenshot 21](/images/intercom/10796370/53056d81-a7a1-42de-a90b-d8c264c7c9c1-cc0dc7f4.png)
10. Update the Authentication Policies to use the new IDP.
    1. On the left navigation menu panel, go to **Authentication** > **Policies** > **Authentication**.
       ![Integrating Oloid tenant to your... - screenshot 22](/images/intercom/10796370/c1268022-6ae3-4245-91cf-95c43d9d0850-546274cb.png)
       The Authentication Policies page is displayed.
    2. Select **+Add Policy** to create a new authentication policy.
       ![Integrating Oloid tenant to your... - screenshot 23](/images/intercom/10796370/951713c7-dc1e-4174-b9b7-60f37f10b044-1138da61.png)
       The Policy page is displayed.
    3. Enter policy name in the **POLICY NAME** field.
    4. Under **STEP TYPE,** select **External Identity Provider** from dropdown.
       ![Integrating Oloid tenant to your... - screenshot 24](/images/intercom/10796370/192e0ce1-ed0d-49b3-8f0c-562a2a58bf5d-e6348b93.png)
       The EXTERNAL IDENTITY PROVIDER section is displayed.
    5. Select the created external identity provider from the **EXTERNAL IDENTITY PROVIDER** section.
       ![Integrating Oloid tenant to your... - screenshot 25](/images/intercom/10796370/fc5804b1-db13-4cca-960a-9b5c4546771f-e34e56ea.png)
    6. Click **Save**.
       The policy is created successfully.
       ![Integrating Oloid tenant to your... - screenshot 26](/images/intercom/10796370/b695622e-abf8-4795-a37b-132479053dde-b159c81a.png)
11. Next, go to the left menu navigation panel and select **Applications** > **Applications**.
    ![Integrating Oloid tenant to your... - screenshot 27](/images/intercom/10796370/3cb60681-58fd-4d90-bee1-7b0cdf967c8a-faccdce6.png)
12. On the Application page, select **PingOne Application Portal** > copy the **Home Page URL**.
    ![Integrating Oloid tenant to your... - screenshot 28](/images/intercom/10796370/ce330d19-03eb-4f79-995a-fa2d92d5420d-b6441a86.png)
    ![Integrating Oloid tenant to your... - screenshot 29](/images/intercom/10796370/e5a6b37c-ef6c-4022-aed7-bd5bdae122ec-a3176b70.png)
13. Select **Applications** from the left menu, and click the Add ![Integrating Oloid tenant to your... - screenshot 30](https://downloads.intercomcdn.com/i/o/e4gi378c/1510083718/732161c5a054e654bfbc35893bc1/image.png?expires=1790488800&signature=a197e70bdbadf78bd1c8931185a4826527ac831f25aafe7f24caf5c3ef861637&req=dSUmFsl2noZeUfMW3nq%2BgQY%2Fqnx1Drz9Mo13H3%2BmVDn5srpUKnQC6r5SJyA5%0AGoEvJHrlAke4rmF2KHJUX%2BB88Rs%3D%0A) icon to add a new application.

    1. Enter **Application Name**, then select **OIDC Web App** from Application Type.
    2. Click **Save**.

15. Select the newly created application from the application list to edit.
    ![Integrating Oloid tenant to your... - screenshot 33](/images/intercom/10796370/503dd0fb-516c-4d7c-9bfd-9f851c8759aa-8207b61b.png)

    ![Integrating Oloid tenant to your... - screenshot 34](/images/intercom/10796370/c44a54c7-6faf-4dac-9f00-3f4dd3063692-2d2a2173.png)

    <Note>

    </Note>

    ![Integrating Oloid tenant to your... - screenshot 35](/images/intercom/10796370/bac122bd-a57e-4e92-b4ac-cd17ed9d5441-9170432f.png)

    ![Integrating Oloid tenant to your... - screenshot 36](/images/intercom/10796370/5a1c03ed-272e-48c1-aba5-a96afd467b84-da4d3673.png)

Under Access tab, click the edit![Integrating Oloid tenant to your... - screenshot 41](https://downloads.intercomcdn.com/i/o/e4gi378c/1493225132/22fe22458e3cf6adb8a4d3a38d11/image.png?expires=1790488800&signature=574697ee6a01452dd015b4eee1aa85b17b016ba5ac1ee375270521848eaec9e7&req=dSQuFct8mIBcW%2FMW3nq%2BgQpFExX7qbVUNf5N%2Fmrjs1uE0RBbhuWBn9Sp9HlX%0A9dUhYNyLeXZ3aTsHTUszRA4dgWE%3D%0A)icon.
