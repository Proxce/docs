## Introduction

This document explains how to configure an **OIDC PingOne Identity Provider (IDP) profile** in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- PingOne IDP profile must be created in Tenant Admin Portal. To create refer, [How to create IDP Profile for PingOne](https://oloid.help/en/articles/10822772-how-to-create-idp-profile-for-pingone).
- Ensure that the Webkey application is created. To create Webkey application, refer [How to create and configure WebKey Application in Tenant Admin Portal](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application-in-tenant-admin-portal).

## Steps to Configure OIDC-PingOne IDP Profile

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Security** > **Identity Provider**.
   ![How to Configure OIDC - PingOne IDP... - screenshot 1](/images/intercom/10826464/image-78ab3b26.png)
   The **Identity Provider Profiles** page is displayed.
3. Click PingOne-IDP application.
   ![How to Configure OIDC - PingOne IDP... - screenshot 2](/images/intercom/10826464/image-e950f2cd.png)
   The application details page is displayed.
4. Do the following:
   1. [Configure Details tab](#configure-details-tab)
   2. Integrate Metadata tab
   3. [Configure IDP Settings tab](#configure-idp-settings-tab)
   4. [Configure Claims tab](#configure-claims-tab-optional)
      The IDP Profile is configured.

### Configure Details Tab

The Details tab is used to view and manage the basic information such as IDP Name, IDP Description, etc. for the identity provider configured in the Tenant Admin Portal.

To configure the Details tab, do the following:

1. Edit the **IDP Name**. (Optional)
   ![How to Configure OIDC - PingOne IDP... - screenshot 3](/images/intercom/10826464/image-82d75074.png)
2. Enter **Description**. (Optional)
   ![How to Configure OIDC - PingOne IDP... - screenshot 4](/images/intercom/10826464/image-c254f086.png)
3. Do one of the following:
   1. Select the required WebKey application from the **Select WebKey Application** dropdown list.
      ![How to Configure OIDC - PingOne IDP... - screenshot 5](/images/intercom/10826464/237af1cd-9508-460c-8c25-623bf278eec6-d4c85528.png)
      (OR)
   2. Click **Make Default**.

      <Note>
        **Note:** The **Make Default** button is enabled only when more than one IDP is added in the Tenant Admin Portal.
      </Note>

      ![How to Configure OIDC - PingOne IDP... - screenshot 6](/images/intercom/10826464/569f5c44-81e6-4f88-81b7-7c265bf303a1-61dda655.png)
      The **Set this as Default IDP** pop-up box is displayed.
      - Select the **Webkey Application**.
      - Select **Set as Default**.
        ![How to Configure OIDC - PingOne IDP... - screenshot 7](/images/intercom/10826464/image-86896458.png)
        The WebKey application is set as the default, and the application is linked to this IDP.
        ![How to Configure OIDC - PingOne IDP... - screenshot 8](/images/intercom/10826464/image-46e37bd6.png)
4. Click **Save**.
   ![How to Configure OIDC - PingOne IDP... - screenshot 9](/images/intercom/10826464/image-7eb6942e.png)

<Note>
  **Note:** If another IDP is currently set as default, it will be replaced upon confirmation.
</Note>

- To make IDP as default, click **Make Default**. The confirmation pop-up box is displayed.
- Click **Set as Default** to designate the preferred IDP as default.

![How to Configure OIDC - PingOne IDP... - screenshot 10](/images/intercom/10826464/fd786cd3-9105-4326-b0c0-d84a80db1990-2324a93b.png)

Details tab is configured successfully.

### Configure Oloid Metadata Tab

The Metadata tab is used to provide the required information to configure PingOne settings and enable PingOne based authentication between the identity provider and the Tenant Admin Portal.

1. Click **Oloid Metadata**.
   The Oloid Metadata tab is displayed.
   ![How to Configure OIDC - PingOne IDP... - screenshot 11](/images/intercom/10826464/image-948ac544.png)
2. Click [Visit help page](https://oloid.help/en/articles/10796370-integrating-oloid-tenant-to-your-pingone-oidc-instance) for the document to configure PingOne settings for SSO login.
3. Do the following:
   1. **Download Oloid Metadata:** Download the certificate and upload it to the **IDP Signature Certificate** field.
   2. **OpenID Configuration Endpoint:** Copy the OpenID Configuration Endpoint URL and enter it in the **Discovery Endpoint URL** field in the PingOne Admin Console.
      ![How to Configure OIDC - PingOne IDP... - screenshot 12](/images/intercom/10826464/image-0257f77b.png)

      <Note>
        **Note:** You can find the **Discovery Endpoint URL** field in the PingOne Admin Console. For details, click **[here](https://oloid.help/en/articles/10796370-integrating-oloid-tenant-to-your-pingone-oidc-instance#:~:text=Next%2C%20select%20Use%20Discovery%20Document.)**.
      </Note>

      ![How to Configure OIDC - PingOne IDP... - screenshot 13](/images/intercom/10826464/image-8edeb50f.png)

### Configure IDP Settings Tab

The **IDP Settings** tab is used to configure and upload the required PingOne details to enable authentication between the identity provider and Tenant Admin Portal.

To configure the IDP settings tab, do the following:

1. Click the **IDP Settings** tab.
   The IDP Settings page is displayed.
2. Do the following to configure the IDP Settings tab.
   1. Enter **IDP ID**.
      ![How to Configure OIDC - PingOne IDP... - screenshot 14](/images/intercom/10826464/image-6099b735.png)

      <Note>
        **Note:** You can find the IDP ID from PingOne Admin Console under **Integrations** > **External IdPs** > select your configured IDP.
      </Note>

      ![How to Configure OIDC - PingOne IDP... - screenshot 15](/images/intercom/10826464/image-8cf64c7e.png)
   2. Enter **Callback URL**.
      ![How to Configure OIDC - PingOne IDP... - screenshot 16](/images/intercom/10826464/image-f06b1ba8.png)

      <Note>
        **Note:** You can find the Callback URL from PingOne Admin Console under **Integrations** > **External IdPs** > select your configured IDP >click **Connection** tab > **CALLBACK URL**.
      </Note>

      ![How to Configure OIDC - PingOne IDP... - screenshot 17](/images/intercom/10826464/image-70fae354.png)
   3. Enter **Redirect URL**.
      ![How to Configure OIDC - PingOne IDP... - screenshot 18](/images/intercom/10826464/image-e9658467.png)

      <Note>
        **Note:**

           - You can find the Redirect URL from PingOne Admin Console under **Applications** > **Applications** > **PingOne Application Portal** > **Configuration** tab > **General** section. To get the Redirect URLs, click [here](https://oloid.help/en/articles/10796370-integrating-oloid-tenant-to-your-pingone-oidc-instance#:~:text=Paste%20the%20copied%20URL%20in%20the%20Configuration%20tab%20%3E%20Redirect%20URL%20field%20of%20the%20created%20application.).
           - If you're using a custom domain, contact **Professional Services** for assistance.
        4. Enter **Application Client ID.**
           ![How to Configure OIDC - PingOne IDP... - screenshot 19](/images/intercom/10826464/image-171a05a6.png)
        5. Enter **Authorize URL.**
           ![How to Configure OIDC - PingOne IDP... - screenshot 20](/images/intercom/10826464/image-6a243573.png)
        6. Enter **Secret.**
           ![How to Configure OIDC - PingOne IDP... - screenshot 21](/images/intercom/10826464/image-15a7ddbc.png)
      </Note>

      <Note>
        **Note:** You can find the **Application Client ID, Authorize URL** and **Secret** from PingOne Admin Console. Navigate to **Applications** > **Applications** > **PingOne Application Portal** > **Overview** tab.
      </Note>

      ![How to Configure OIDC - PingOne IDP... - screenshot 22](/images/intercom/10826464/image-7946350b.png)
   7. **Enter Home URL:** Enter the URL of the home page.
   8. **Home Label Button:** Enter the text displayed on the **Home** button.
      ![How to Configure OIDC - PingOne IDP... - screenshot 23](/images/intercom/10826464/image-b1f4542f.png)
   9. Click **Save**.
      ![How to Configure OIDC - PingOne IDP... - screenshot 24](/images/intercom/10826464/image-a94d79dd.png)
      The IDP Profile is configured successfully.

### Configure Claims Tab (Optional)

The **Claims** tab is used to configure custom claims that pass user attributes from Oloid to the OIDC provider.

Do the following:

- [Custom Claims](#custom-claims)
- [Authentication Methods References (AMR) Claims](#authentication-methods-references-amr-claims)
  ![How to Configure OIDC - PingOne IDP... - screenshot 25](/images/intercom/10826464/image-981833ee.png)

#### Custom Claims

Custom Claims allow the admin to map Oloid user attributes to OIDC attributes.

Do the following:

1. In the **Custom Claims** tab, expand the **Custom Claims** section.
   The Custom Claims section is displayed.
   ![How to Configure OIDC - PingOne IDP... - screenshot 26](/images/intercom/10826464/image-f36b366d.png)
2. In the **Custom Claims** section, click **Add Field**.
3. In the **OIDC Attribute** field, enter the OIDC Attribute.
4. Select the Oloid Value from the **Oloid Value** dropdown.

   <Note>
     **Note:** Click **Add Field** to add additional claim.
   </Note>

5. Click **Save.**
   ![How to Configure OIDC - PingOne IDP... - screenshot 27](/images/intercom/10826464/image-aac44ac4.png)
   The Custom claims are configured successfully.
   ![How to Configure OIDC - PingOne IDP... - screenshot 28](/images/intercom/10826464/image-9209b6c1.png)

#### Authentication Methods References (AMR) Claims

**AMR Claims** indicate **how a user was authenticated** during the login process.

1. In the **AMR Claims** tab, expand the **AMR Claims** section.
   The AMR Claims section is displayed.
   ![How to Configure OIDC - PingOne IDP... - screenshot 29](/images/intercom/10826464/image-3eb5e68e.png)
2. In the **AMR Claims** section enter the authentication method value.
   ![How to Configure OIDC - PingOne IDP... - screenshot 30](/images/intercom/10826464/a6f55bf4-1c50-4ae8-bcf3-a7845ec37ddc-adbb90e3.png)

   <Note>
     **Note:** Click **Add** to add additional AMR claim items.
   </Note>

3. Click **Save.**
   ![How to Configure OIDC - PingOne IDP... - screenshot 31](/images/intercom/10826464/image-3fa2c755.png)
   The AMR section is configured successfully.
   ![How to Configure OIDC - PingOne IDP... - screenshot 32](/images/intercom/10826464/image-a3bfccb8.png)
   The PingOne IDP is configured successfully.
   ![How to Configure OIDC - PingOne IDP... - screenshot 33](/images/intercom/10826464/image-96234645.png)
