## Introduction

This document provides instructions to configure **Okta (OIDC)** as an Identity Provider for **Oloid Single Sign-On (SSO)**.

## Prerequisites

- You must have admin access to the **Okta Admin Console**
- Okta **OIDC (OpenID Connect)** support enabled.

## Steps to Add Identity Provider

1. On the home page of the Okta Admin Console, go to **Security** > **Identity Providers**.
   ![How to Create and Configure Okta (OIDC)... - screenshot 1](/images/intercom/9154143/image-54ed99eb.png)
2. Select **Add Identity Provider**.
   ![How to Create and Configure Okta (OIDC)... - screenshot 2](/images/intercom/9154143/image-260155c7.png)
   The identity provider list is displayed.
3. Select **OpenID Connect** and click **Next**.
   ![How to Create and Configure Okta (OIDC)... - screenshot 3](/images/intercom/9154143/image-e0f52264.png)
   The **Configure OpenID Connect IdP** dialog box is displayed.
4. Do the following
   1. Under **General settings** section:
      1. **Name:** Enter a namefor the Identity Provider configuration.
      2. **Scopes**: Leave the defaults. These scopes are included when Okta makes an OpenID Connect request to the Identity Provider.
         ![How to Create and Configure Okta (OIDC)... - screenshot 4](/images/intercom/9154143/image-c1a7fee8.png)
   2. Under **Client details** section:
      1. Enter **Client ID.**
      2. Enter **Client Secret**.
         ![How to Create and Configure Okta (OIDC)... - screenshot 5](/images/intercom/9154143/image-647a0f0c.png)

         <Note>
           **Note:** You can find the **Client ID** and **Client Secret** in your Oloid portal. On the Tenant Admin Portal, go to **Identity Provider > IDP Details > Meta Data** tab.
         </Note>

         ![How to Create and Configure Okta (OIDC)... - screenshot 6](/images/intercom/9154143/3441adda-02de-4e93-a491-510566510a08-77798ab2.png)
   3. Under **Endpoints section:**
      1. Enter **Issuer**.
      2. Enter **Authorization endpoint**.
      3. Enter **Token endpoint**.
      4. Enter **JWKS endpoint**.
         ![How to Create and Configure Okta (OIDC)... - screenshot 7](/images/intercom/9154143/image-827eb701.png)

         <Note>
           **Note:** You can find the **Issuer, Authorization Endpoint, Token Endpoint** and **JWKS Endpoint** in your Oloid Portal. On the Tenant Admin Portal, go to **Identity Provider > IDP Details > Meta Data** tab.
         </Note>

         ![How to Create and Configure Okta (OIDC)... - screenshot 8](/images/intercom/9154143/2ce0da7c-c5ce-4ea4-93a9-7f8cc55a252d-e22d6bb7.png)
5. Under **Authentication Settings** section,
   1. Select **Enable automatic linking** from **Account Link Policy**.
   2. If no match is found, select **Reject the authentication responses from IdP**.
      ![How to Create and Configure Okta (OIDC)... - screenshot 9](/images/intercom/9154143/d44ba6df-3832-4218-b7f8-058b1e2cae74-ed4e4b91.png)
6. Click **Finish**.
   The newly created IDP is listed under **Security** > **Identity Providers.**

   <Note>
     **Note:** In the search bar, you can search using identity provider name.
   </Note>

   ![How to Create and Configure Okta (OIDC)... - screenshot 10](/images/intercom/9154143/image-1944df21.png)
7. Go to IDP details and do the following:
   1. Copy **IDP ID** and enter it in **Tenant Admin Portal > Identity Provider > IDP Settings > IDP ID**.
   2. Copy **Redirect URl** and enter it in **Tenant Admin Portal > Identity Provider > IDP Settings** > **Callback URL**.
   3. Enter **[https://&#123;user-id&#125;.okta.com/](https://%7Buser-id%7D.okta.com/)** in the **Authorize URL** and **Redirect URL** fields under **Tenant Admin Portal > Identity Provider > IDP Settings**. For example, `https://dev-10453970.okta.com/`
      ![How to Create and Configure Okta (OIDC)... - screenshot 11](/images/intercom/9154143/image-72730472.png)
      ![How to Create and Configure Okta (OIDC)... - screenshot 12](/images/intercom/9154143/51ba2615-a338-408d-a202-6d971b6667c7-079d3ba5.png)

## Add Client Application

1. In the Okta Admin Console, go to **Applications** > **Applications**.
   ![How to Create and Configure Okta (OIDC)... - screenshot 13](/images/intercom/9154143/image-e5212b63.png)
2. Select **Create App Integration**.
   ![How to Create and Configure Okta (OIDC)... - screenshot 14](/images/intercom/9154143/image-809849f1.png)
   The **Create a new app integration** pop-up box is displayed.
   ![How to Create and Configure Okta (OIDC)... - screenshot 15](/images/intercom/9154143/image-56f7d543.png)
3. Do the following:
   1. Select **OIDC - OpenID Connect** as the **Sign-in method** and **Web Application** as **Application type**.
   2. Select **Next**.
      ![How to Create and Configure Okta (OIDC)... - screenshot 16](/images/intercom/9154143/image-e09e4721.png)
4. In the next screen, configure the application.
   1. Under **General Settings** section,
      1. Enter **App integration name**.
      2. Select **Authorization Code** as **Grant type** (If not already selected).
         ![How to Create and Configure Okta (OIDC)... - screenshot 17](/images/intercom/9154143/image-2d1d01d8.png)
   2. Enter **Sign-in redirect URIs.**

      <Note>
        **Note:** The Sign-in redirect URls must be set to **[https://&#123;yourOrg&#125;.okta.com](https://%7ByourOrg%7D.okta.com)**.
      </Note>

      ![How to Create and Configure Okta (OIDC)... - screenshot 18](/images/intercom/9154143/image-fc4d0288.png)
   3. Enter **Sign-out redirect URIs** (Optional)**.**

      <Note>
        **Note:** The Sign-out redirect URls must be set to **[https://&#123;yourOrg&#125;.okta.com](https://%7ByourOrg%7D.okta.com)**.
      </Note>

      ![How to Create and Configure Okta (OIDC)... - screenshot 19](/images/intercom/9154143/image-e1a003a8.png)
   4. Under **Assignments** section, select **Allow everyone in your organization to access**.
      ![How to Create and Configure Okta (OIDC)... - screenshot 20](/images/intercom/9154143/image-faa95807.png)
5. Click **Save**.
   Add the **ClientID** and **Client Secret** of the new app in **Tenant Admin Portal > Identity Provider > IDP Details > IDP Settings** tab**.**
   ![How to Create and Configure Okta (OIDC)... - screenshot 21](/images/intercom/9154143/image-3d1a549e.png)
   ![How to Create and Configure Okta (OIDC)... - screenshot 22](/images/intercom/9154143/image-0a235068.png)
6. Configure the IDP Profile in the Tenant Admin Portal:
   1. On the homepage of the portal, select the preferred IDP to edit.
   2. On the IDP details page, select the **WebKey** Application from **Select WebKey Application** dropdown.
      ![How to Create and Configure Okta (OIDC)... - screenshot 23](/images/intercom/9154143/dd5ab6de-29d3-4a19-85f3-3008d1101ffa-7615ab17.png)
7. Click **Save**.
8. On the top-right corner of the preferred WebKey application, select **Open login URL** to view the configured WebKey application in your browser.
