## Introduction

This document explains how to assign a Windows shared credential to users in the Tenant Admin Portal.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- The Shared Credential must be created in the Tenant Admin Portal. For more information, refer: [How to create shared Password for Windows login application in the Tenant Admin Portal](https://oloid.help/en/articles/8472794-how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal)

## Steps to assign Shared Credential

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to associate users with Window... - screenshot 1](/images/intercom/8543917/image-35d58b2d.png)
   The **Users** page is displayed.
3. Select **Shared Credentials > Windows Password** on the left menu panel.
   ![How to associate users with Window... - screenshot 2](/images/intercom/8543917/image-4b5da837.png)
   The **Windows Password** page is displayed.
   ![How to associate users with Window... - screenshot 3](/images/intercom/8543917/image-7289fe47.png)

Do one of the following:

[Assign Shared Password.](#assign-shared-password)

[Assign Shared Password to Multiple Users](#assign-shared-password)

The Windows shared password is successfully assigned to the selected users.

### Assign Shared Password.

1. Select credential name to assign.
   ![How to associate users with Window... - screenshot 4](/images/intercom/8543917/image-ea4d9507.png)
   The **Windows Shared Passwords** listpage is displayed.
2. Click **+ Assign Shared Passwords to Users.**
   ![How to associate users with Window... - screenshot 5](/images/intercom/8543917/image-336a9f16.png)
   The **Assign Shared Passwords to Users** pop-up box is displayed.
3. On the pop-up box, enter user name(s) in the **Users** dropdown list.
4. Click **Assign**.
   ![How to associate users with Window... - screenshot 6](/images/intercom/8543917/image-1377d98d.png)
   The Windows shared password is successfully assigned to the selected users.
   ![How to associate users with Window... - screenshot 7](/images/intercom/8543917/image-4be14f9e.png)
   The Users assigned to the shared password will be visible under the User Assigned section in the Windows shared password.
   ![How to associate users with Window... - screenshot 8](/images/intercom/8543917/image-236b2117.png)

### Assign Multiple Shared Password to User(s)

1. Select credential name checkbox to assign.

   <Note>
     **Note:** Multiple Shared Passwords can be assigned to users. To assign multiple passwords select the checkbox next to the required shared password(s) to assign them to users.
   </Note>

2. Click **+ Assign Passwords to Users.**
   ![How to associate users with Window... - screenshot 9](/images/intercom/8543917/image-18d1d59f.png)
   The **Assign Passwords to Users** pop-up box is displayed.
3. On the pop-up box, enter user name(s) in the **Users** dropdown list.
4. Click **Assign**.
   ![How to associate users with Window... - screenshot 10](/images/intercom/8543917/image-1beac4aa.png)

The Windows shared password is successfully assigned to the selected users.

![How to associate users with Window... - screenshot 11](/images/intercom/8543917/image-f744dfb0.png)

The Users assigned to the shared password will be visible under the User Assigned section in the Windows shared password.

![How to associate users with Window... - screenshot 12](/images/intercom/8543917/image-938e4840.png)
