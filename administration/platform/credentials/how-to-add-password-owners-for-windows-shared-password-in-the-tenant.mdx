## Introduction

The Tenant Admin Portal allows the admin to securely manage shared passwords across the organization. One of its key features is the ability to assign password owners, groups and users for Windows Shared Password.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- The Windows Shared Password must be created. To created Windows Shared Password refer [How to create shared Password for Windows login application in the Tenant Admin Portal](https://oloid.help/en/articles/8472794-how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal).

## Steps to add Password Owners

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to add password owners for Windows... - screenshot 1](/images/intercom/8544435/image-3b224d1d.png)
   The **Users** page is displayed.
3. Select **Shared Credentials > Windows Password** on the left menu panel.
   ![How to add password owners for Windows... - screenshot 2](/images/intercom/8544435/image-b1cada70.png)
   The **Windows Shared Password** page is displayed.
4. Select the preferred display name to edit.
   ![How to add password owners for Windows... - screenshot 3](/images/intercom/8544435/7e4cff9c-fc56-4f95-bea1-4c0923d48e38-9f2a5498.png)
5. Go to **Password Owners** tab > **+ Add Password Owners**.
   ![How to add password owners for Windows... - screenshot 4](/images/intercom/8544435/image-afc9d6ca.png)
   The **Add Password Owners** pop-up box is displayed.
6. On the pop-up box, enter user name(s) in the **Users** dropdown list.

   <Note>
     **Note:** Only users with Admin or Supervisor roles can be assigned as Password Owners.
   </Note>

7. Click **Assign**.

![How to add password owners for Windows... - screenshot 5](/images/intercom/8544435/image-fe4c9e87.png)

The password owners are successfully assigned.
