## Introduction

In the Tenant Admin Portal, admin can assign **Shared Password** to users. By assigning these credentials, multiple users can securely use the same login details without needing to create individual accounts, making it easier to manage shared systems.

## Prerequisites

- You must have admin access to Tenant Admin Portal.
- Shared Windows password must be created. To create a shared windows credential refer [How to create shared Password for Windows login application in the Tenant Admin Portal](https://oloid.help/en/articles/8472794-how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal).

## Steps to Assign Shared Password

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Assign Shared Password for... - screenshot 1](/images/intercom/8504427/image-e2b862e7.png)
   The **Users** page is displayed.
3. Click **User Name** to edit.
   ![Image](/images/intercom/8504427/3acb62b2-c00a-47b2-a74d-0a0247212ac2-ca2c7375.png)
   The **User details** page is displayed.
   ![How to Assign Shared Password for... - screenshot 2](/images/intercom/8504427/image-4dc304f4.png)
4. Go to **Credentials** >select **Windows Passwords** from left menu panel > **+ Add Windows Shared Password**.
   ![How to Assign Shared Password for... - screenshot 3](/images/intercom/8504427/image-9f7039eb.png)
   The **Add Windows Shared Password** pop-up box is displayed.
5. On the pop-up box, do the following:
   1. Select shared password(s) from **Select Shared Password** drop-down list.
   2. Click **Assign**.

![How to Assign Shared Password for... - screenshot 4](/images/intercom/8504427/image-71c453b7.png)

The shared credential is successfully assigned to the user.

![How to Assign Shared Password for... - screenshot 5](/images/intercom/8504427/image-fc39040f.png)
