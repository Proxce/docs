## Introduction

This document explains how Tenant Admin can send a user’s **PIN credential** through the Tenant Admin Portal. Admins can securely share the PIN with users via email or SMS, allowing them to use it for authentication without manual setup.

### Prerequisite

- You must have access to the Tenant Admin Portal
- The registered email ID must be added to the user's profile on the Tenant Admin Portal.

### Steps to send Pin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Directory**, from the left menu panel.
   ![How to Send PIN to User via email in... - screenshot 1](/images/intercom/14750432/image-f58db00b.png)
   The **Users** page is displayed.
3. Click **username** to edit.
   ![Image](/images/intercom/14750432/9c57efb9-2990-4bb6-9643-e121736a2c85-9e3c67ff.png)
   The **user details** page is displayed.
4. Go to **Credentials** tab > **PIN** > **Send PIN**.
   ![How to Send PIN to User via email in... - screenshot 2](/images/intercom/14750432/image-cb3ff806.png)
   ![How to Send PIN to User via email in... - screenshot 3](/images/intercom/14750432/image-c93282e8.png)
5. Do one the following:
   1. Via Email: The **Send PIN via Email** is displayed.
      1. Enter email ID(s) and select from the dropdown to whom you want to send the mail in **Send Email to** field.
      2. Click **Send**.
         The PIN is sent to Email successfully.
         ![How to Send PIN to User via email in... - screenshot 4](/images/intercom/14750432/image-25f92917.png)
   2. Via Phone Number: The **Send PIN via Phone Number** is displayed.
      1. Enter phone number of the user.
      2. Click **Send**.
         ![How to Send PIN to User via email in... - screenshot 5](/images/intercom/14750432/image-5befdeba.png)
         The PIN is sent to user via SMS successfully
         ![How to Send PIN to User via email in... - screenshot 6](/images/intercom/14750432/image-e71f146f.png)

The user can access the **PIN** from their Email.
