## Introduction

Shared passwords are passwords that can be used to access a local windows machine or domain. It is shared among users to which they are assigned to. For more details refer [How to assign shared credential with users](https://oloid.help/en/articles/8504427-how-to-assign-shared-credential-to-user).

This document comprises the following sections:

- [Create shared password for windows domain user](#steps-to-create-shared-password-for-windows-domain-user).
- [Create shared password for Windows local user](#steps-to-create-shared-password-for-windows-local-user).

### Steps to create shared password for windows domain user

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to create shared Password for... - screenshot 1](/images/intercom/8472794/image-e12c3b8d.png)
   The **Users** page is displayed.
3. Click **Shared Credentials > Windows Password** on the left menu panel.
   ![How to create shared Password for... - screenshot 2](/images/intercom/8472794/image-43f7e5b4.png)
   The **Windows Password** page is displayed.
4. On the top right, click **Create Password**.
   ![How to create shared Password for... - screenshot 3](/images/intercom/8472794/image-1b5b2c7a.png)
   The **Create Windows Shared Password** pop-up box is displayed.
5. Do the following:
   1. Enter **Display Name**.
   2. Select user type as **Domain User** from **User Type** dropdown.
   3. Enter user name then select **Password Owner(s)** from the dropdown list.
   4. Select **Next**.
      ![How to create shared Password for... - screenshot 4](/images/intercom/8472794/image-1e8967a5.png)
   5. Enter **Domain Name**.
   6. Select **Preferred Machine(s)**.
   7. Enter **Username** of your Windows Login.
   8. Enter **Password** of your Windows Login.
   9. Enter **External ID.**
   10. Click **Create.**
       ![How to create shared Password for... - screenshot 5](/images/intercom/8472794/852ee26e-f428-4024-9423-887bb580874e-f47379ee.png)
       The password is created and listed on the **Windows Shared Password** page.
       ![How to create shared Password for... - screenshot 6](/images/intercom/8472794/image-0b56f862.png)

### Steps to create shared password for windows local user

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to create shared Password for... - screenshot 7](/images/intercom/8472794/image-bfda71b6.png)
   The **Users** page is displayed.
3. Click **Shared Credentials > Windows Password** on the left menu panel.
   ![How to create shared Password for... - screenshot 8](/images/intercom/8472794/image-b2e7df3e.png)
   The **Windows Shared Password** page is displayed.
4. On the top right, click **Create Password**.
   ![How to create shared Password for... - screenshot 9](/images/intercom/8472794/image-f9edcd9a.png)
   The **Create Windows Shared Password** pop-up box is displayed.
5. On the pop-up box do the following:
   1. Enter **Display Name** that displays on the Windows Login page.
   2. Select user type as **Windows Local User** from **Password Type** dropdown.
   3. Enter an existing user name, then select **Password Owner** from the dropdown list.
   4. Select **Next**.
      ![How to create shared Password for... - screenshot 10](/images/intercom/8472794/image-20e4d7be.png)
   5. Enter **Machine Name**.

      <Note>
        **Note:** Enter your Windows device name.
      </Note>

   6. Enter **Username** of your Windows Login account.
   7. Enter **Password** of your Windows Login account.
   8. Enter **External ID.**
   9. Click **Create**.
      ![How to create shared Password for... - screenshot 11](/images/intercom/8472794/8aaaa857-a540-4be0-836c-bae39333f3ff-48df0604.png)
      The password is created and listed successfully on the **Windows Shared Password** page.
      ![How to create shared Password for... - screenshot 12](/images/intercom/8472794/image-f8591236.png)

<Note>
  **Note:** The domain shared password is also listed on the selected Endpoint details page.
</Note>
