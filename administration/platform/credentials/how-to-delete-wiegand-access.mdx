Steps to Delete Weigand Access:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, select **Weigand Access** on the left panel menu.
   ![How to delete Wiegand Access - screenshot 1](/images/intercom/8492278/cd1aa28b-9055-46bf-b090-d037db27c387-a412e454.png)
   The **Weigand Access** page is displayed.
3. Select the Weigand Name to delete.
   ![How to delete Wiegand Access - screenshot 2](/images/intercom/8492278/43613490-1765-4162-b987-02eb369c2a3b-c27bca0b.png)
   The **Weigand details** page is displayed.
4. Go to **Action** dropdown and select **Delete**.
   ![How to delete Wiegand Access - screenshot 3](/images/intercom/8492278/62aec8b0-eb8b-4315-816c-028f439e0fbc-ad588162.png)
   The confirmation pop-up box is displayed.
   ![How to delete Wiegand Access - screenshot 4](/images/intercom/8492278/image-35ed2e14.png)
5. Do the following:
   1. Enter Wiegand name in **Type the name of the Wiegand**.
   2. Enter the reason under **Please type the reason you are deleting the Wiegand**.
   3. Click **Delete**.
      The Weigand Access is permanently deleted.
      ![How to delete Wiegand Access - screenshot 5](/images/intercom/8492278/image-17b812be.png)
