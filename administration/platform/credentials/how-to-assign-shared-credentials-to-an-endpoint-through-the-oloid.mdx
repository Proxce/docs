## Pre-requisite

Shared credential must be already created. To create shared credential for domain user, read [How to create shared credential for domain users.](https://oloid.help/en/articles/8472794-how-to-create-shared-credentials-for-windows-login)

To assign shared credential to an endpoint:

1. Log in to the **Oloid Portal**.
2. On the Home page of the portal, click **Endpoints** on the left panel menu.
   ![How to assign shared credentials to an... - screenshot 1](/images/intercom/8717165/image-66735148.png)
   The Endpoints page is displayed.
3. Click on an endpoint name to edit from the listed endpoints.
   ![How to assign shared credentials to an... - screenshot 2](/images/intercom/8717165/image-51696599.png)
   The Endpoint details page is displayed.
   ![How to assign shared credentials to an... - screenshot 3](/images/intercom/8717165/image-918b9650.png)
4. Go to **Settings** tab> **Shared Credentials**> **+Assign Shared Credential**.
   ![How to assign shared credentials to an... - screenshot 4](/images/intercom/8717165/image-28212fe4.png)
   The **Assign Shared Credential** pop-up box is displayed.
5. On the pop-up box, select **Domain Shared Credential(s)** from the drop-down list.
   ![How to assign shared credentials to an... - screenshot 5](/images/intercom/8717165/image-467f5170.png)
6. Select **Assign**.
   The domain shared credential is successfully assigned to the endpoint.
   ![How to assign shared credentials to an... - screenshot 6](/images/intercom/8717165/image-387a7ef3.png)
