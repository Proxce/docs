## Introduction

Vault Shared Passwords allow the Tenant Admin to securely assign shared passwords to multiple users from the Tenant Admin Portal.

## Prerequisites

- You must have a Tenant Admin account.
- Vault shared password must be created. For more, refer: [Chrome Vault - How to Create Shared Password in the Tenant Admin Portal](https://oloid.help/en/articles/12275469-chrome-vault-how-to-create-shared-password-in-the-tenant-admin-portal)

## Steps to assign Vault Shared Passwords

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to assign Vault Shared Password to... - screenshot 1](/images/intercom/15053580/image-35d58b2d.png)
   The **Users** page is displayed.
3. Select **Shared Credentials > Vault Passwords** on the left menu panel.
   ![How to assign Vault Shared Password to... - screenshot 2](/images/intercom/15053580/image-be8513b3.png)
   The **Vault Passwords** page is displayed.
4. Select credential name to edit.

   <Note>
     **Note:** Multiple Shared Passwords can be assigned to users. To assign multiple passwords select the checkbox next to the required shared password(s) to assign them to users.
   </Note>

   ![How to assign Vault Shared Password to... - screenshot 3](/images/intercom/15053580/image-b4acdc1d.png)
   The **Vault Passwords Detail** page is displayed.
5. Click **User Assigned** > Click **+ Assign Shared Passwords to Users.**
   ![How to assign Vault Shared Password to... - screenshot 4](/images/intercom/15053580/image-b9244f46.png)
   The **Assign Passwords to Users** pop-up box is displayed.
6. On the pop-up box, enter user name(s) in the **Users** dropdown list.
7. Click **Assign**.

![How to assign Vault Shared Password to... - screenshot 5](/images/intercom/15053580/image-c66a0fc3.png)

The Vault shared password is successfully assigned to the selected users.

![How to assign Vault Shared Password to... - screenshot 6](/images/intercom/15053580/image-f3fa0deb.png)

The Users assigned to the shared password will be visible under the User Assigned section in the Vault shared password.

![How to assign Vault Shared Password to... - screenshot 7](/images/intercom/15053580/image-1f8958e2.png)
