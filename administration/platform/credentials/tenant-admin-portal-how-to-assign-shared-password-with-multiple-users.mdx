## Introduction

Tenant Admin Portal allows the Admin to assign shared credentials, such as Windows Passwords, to multiple users at once. This feature helps streamline access management by enabling several users to securely share the same credential for specific applications or systems.

## Prerequisites

- The Shared password must be created. To create shared password refer [How to create shared Password for Windows login application in the Tenant Admin Portal](https://oloid.help/en/articles/8472794-how-to-create-shared-password-for-windows-login-application-in-the-tenant-admin-portal).
- Users must be created. To create users refer [How to add Users in the Tenant Admin Portal](https://oloid.help/en/articles/8185048-how-to-add-users-in-the-tenant-admin-portal).

## Steps to assign Shared Credential

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Directory** on the left menu panel.
   ![How to Assign Shared Password with... - screenshot 1](/images/intercom/8504762/image-c1a48d96.png)
   The **Users** page is displayed.
3. Select **Shared Credentials >** select **Windows Password** on the left menu panel.
   ![How to Assign Shared Password with... - screenshot 2](/images/intercom/8504762/image-040d9625.png)
   The **Windows Shared Password** page is displayed.
   ![How to Assign Shared Password with... - screenshot 3](/images/intercom/8504762/image-d0baebad.png)
4. Select password name(s) to assign users.
5. Select **+ Assign Credentials to Users**.
   ![How to Assign Shared Password with... - screenshot 4](/images/intercom/8504762/image-c8558c94.png)
   The **Assign Users to Credentials** pop-up box is displayed.
6. On the pop-up box, enter user name(s) in the **Users** dropdown list.
7. Select **Assign**.
   ![How to Assign Shared Password with... - screenshot 5](/images/intercom/8504762/image-5fdd7689.png)
   The shared password is successfully assigned among the selected users.
   ![How to Assign Shared Password with... - screenshot 6](/images/intercom/8504762/image-f9bfeae7.png)
