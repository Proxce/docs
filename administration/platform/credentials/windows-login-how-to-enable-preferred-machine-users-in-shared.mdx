This feature of Windows login app lets you add a preferred machine to a shared domain credential, enabling login to those specific Windows systems.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure the endpoint is paired with the Windows Login application.
- Create Shared Credential of credential type as Domain User. Refer here [How to create shared credentials for Windows login](https://oloid.help/en/articles/9680203-supervisor-portal-how-to-create-shared-credentials-for-windows-login#h_14af33233d).

To enable preferred machine users:

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Endpoints** on the left panel menu.
   ![How to enable Preferred Machine Users... - screenshot 2](/images/intercom/8906511/image-86b2831e.png)
   The Endpoints page is displayed.
3. Select endpoint name from the listed endpoints.
   ![How to enable Preferred Machine Users... - screenshot 3](/images/intercom/8906511/1385b966-dabf-4300-88cb-9959a6f2dddf-e03d75b2.png)
   The endpoint detail page is displayed.
4. Go to **Configure** > **Endpoint Settings**.
   ![How to enable Preferred Machine Users... - screenshot 4](/images/intercom/8906511/fdb77052-93a1-47e0-8be5-d3b61e99cb19-93ddbb42.png)
5. Turn on **Enable only Preferred Machine Login**.
   ![How to enable Preferred Machine Users... - screenshot 5](/images/intercom/8906511/5fa51697-d94b-42fb-97bb-2b3512fe4a35-3ea560e3.png)
6. Click **Save**.
   Now, you can successfully log in to your Windows system.
