## Introduction

This document provides instructions to configure a **Wiegand** in the Tenant Admin Portal.

## Prerequisites

You must have admin access to the Tenant Admin Portal.

## Steps to Configure Weigand

1. Log in to the **Tenant Admin Portal**.
2. On the home page, select **Weigand Access** on the left menu panel.
   ![How to Configure Wiegand - screenshot 1](/images/intercom/8492442/image-4e6c776c.png)
   The **Weigand Access** page is displayed.
3. Select the Weigand Name to edit.
   ![How to Configure Wiegand - screenshot 2](/images/intercom/8492442/image-1862e6be.png)
   The **Weigand details** page is displayed.
   ![How to Configure Wiegand - screenshot 3](/images/intercom/8492442/image-680bb8f1.png)
4. Do the following:
   1. On **Details** tab, enter the Description (Optional).

      <Note>
        **Note:** You can describe the specific arrangement of your binary card data.
      </Note>

   2. Click **Configure** taband do the following:
      1. **Length**: Enter length of Wiegand Format.

         <Note>
           **Note:** Length is the number of bits in a badge binary.
         </Note>

      2. **Facility Code**: Enter the Facility Code of the card format.

         <Note>
           **Note:** This is a number that represents the facility or building that the card will be used in.
         </Note>

      3. **Facility Code Start**: Enter the start number of the Facility Code.

         <Note>
           **Note:** This is used to identify or represent each cardholder.
         </Note>

      4. **Facility Code Length**: Enter the facility code length.

         <Note>
           **Note:** Facility Code Length is the length (number of bits) available for storing facility code.
         </Note>

      5. **Encoded # Start**: Enter encoding start position.

         <Note>
           **Note:** Encoded Start represents the starting bit position from where card number will be stored.
         </Note>

      6. **Encoded # Length**: Enter encoded length.

         <Note>
           **Note:** Encoded length represents number of bits available to store the card number.
         </Note>

      7. Select the **Hot Stamp and encoded numbers default identical** checkbox.
         ![How to Configure Wiegand - screenshot 4](/images/intercom/8492442/image-f53a7cb1.png)
      8. Select **+ Add Parity Bit Definitions**
         The Parity Bit Definitions pop-up box is displayed.
         ![How to Configure Wiegand - screenshot 5](/images/intercom/8492442/image-36f3da1e.png)
      9. Enter values.

         <Note>
           **Note:** A parity bit is used as a very simple quality check for the accuracy of the transmitted binary data.
         </Note>

         ![How to Configure Wiegand - screenshot 6](/images/intercom/8492442/image-8f7a30fa.png)
5. Click **Save**.
   The Wiegand format is configured and listed on the **Wiegand Access** page.
   ![How to Configure Wiegand - screenshot 7](/images/intercom/8492442/image-6712ea9b.png)
