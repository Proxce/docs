## Introduction

A CloudKey endpoint represents a cloud-connected access point that links a CloudKey device to an application and, optionally, a workflow.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Ensure a CloudKey application is created. For more information, refer: [How to Create an Application](https://oloid.help/en/articles/8294483-tenant-admin-portal-how-to-create-an-application).

## Steps to create a CloudKey endpoint

1. Log in to the Tenant Admin Portal.
2. On the homepage of the portal, click **Endpoints** on the left menu panel.
   ![How to create a CloudKey endpoint - screenshot 1](/images/intercom/8263138/image-5e2a05ec.png)
   The **Endpoints** page is displayed.
3. Click **Add Endpoint** on the top right corner of the page.
   ![How to create a CloudKey endpoint - screenshot 2](/images/intercom/8263138/image-4eae0502.png)
   The **Create Endpoint** pop-up box is displayed.
4. Select **CloudKey** > click **Continue**.
   ![How to create a CloudKey endpoint - screenshot 3](/images/intercom/8263138/image-5585101e.png)
   The **CloudKey- Create a new Endpoint** pop-up box is displayed.
5. On the pop-up box, do the following:
   1. Enter **Endpoint name**.
   2. Select **Application** from the application list.
   3. Select **Workflow** from the workflow list (optional).
   4. Enter **CloudKey Url.**
   5. Enter **Door ID.**
   6. Enable **Wait for Response** (optional).
   7. Select **Location**. (Mandatory)
   8. Select **Building** (optional).
   9. Select **Area** (optional).
6. Click **Create**.

![How to create a CloudKey endpoint - screenshot 4](/images/intercom/8263138/image-9ff4ed6c.png)

The Endpoint is created and listed on the **Endpoints** page.

![How to create a CloudKey endpoint - screenshot 5](/images/intercom/8263138/image-acc29fad.png)
