## Pre-requisite

Location must be created on the Location Settings page.

For more information on creating location, see **[How to create a new location and add location details](https://oloid.help/en/articles/8227103-how-to-create-a-new-location-and-add-location-details)**.

### Steps to add location in bulk

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left panel menu.
   ![How to add location to endpoints in... - screenshot 1](/images/intercom/8227618/image-86b2831e.png)
   The endpoints page is displayed.
3. Select endpoints whose addresses are not updated.
   ![How to add location to endpoints in... - screenshot 2](/images/intercom/8227618/image-36a09bb9.png)
4. Go to **Action** dropdown and select **Add Location**.
   ![How to add location to endpoints in... - screenshot 3](/images/intercom/8227618/image-09dcf4fe.png)
   The **Add Location** pop-up box is displayed.
   ![How to add location to endpoints in... - screenshot 4](/images/intercom/8227618/image-367e2dbc.png)
5. Select appropriate location from **Select Location** dropdown.
6. Click **Save**.
   The location is successfully updated for the selected endpoints.
   ![How to add location to endpoints in... - screenshot 5](/images/intercom/8227618/image-857fb208.png)

   <Note>
     **Note:** To update the address of a specific endpoint, navigate to the endpoint details page and make the necessary change.
   </Note>
