Steps to create a new location through endpoint:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to create location using endpoint - screenshot 1](/images/intercom/8498777/image-86b2831e.png)
   The **Endpoints** page is displayed.
3. Select endpoint name(s) from the listed endpoints.
   ![How to create location using endpoint - screenshot 2](/images/intercom/8498777/image-18a26e0a.png)
4. Go to **Action** dropdown and select **Add Location**.
   ![How to create location using endpoint - screenshot 3](/images/intercom/8498777/image-eb26d414.png)
   The **Add Location** pop-up box is displayed.
   ![How to create location using endpoint - screenshot 4](/images/intercom/8498777/image-5f0d90e4.png)
5. On the pop-up box do the following:
   1. Click **Select Location** field.
      The search result lists existing locations.
      ![How to create location using endpoint - screenshot 5](/images/intercom/8498777/image-4cb32488.png)
   2. Click **Add New**.
      The **Create Location** pop-up box is displayed.
      ![How to create location using endpoint - screenshot 6](/images/intercom/8498777/image-f96eca37.png)
   3. Enter **Location Name**.
   4. Click **Create**.
      The location name is created and listed on the **Location Settings** page.
      ![How to create location using endpoint - screenshot 7](/images/intercom/8498777/image-b97cbe15.png)

You can now add location details, for instructions on adding location details, see **[How to add location details](https://oloid.help/en/articles/8498715-how-to-add-location-details)**.
