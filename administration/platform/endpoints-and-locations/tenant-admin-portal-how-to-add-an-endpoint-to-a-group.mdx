## Introduction

This document provides instructions to add an endpoint to an existing group in the Tenant Admin Portal.

<Note>
  **Note:** Adding Endpoint to a Group can be done in two ways. You can add group to an endpoint. For detailed instructions, see [How to add group to an endpoint](https://oloid.help/en/articles/8463479-how-to-add-group-to-endpoint).
</Note>

## Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- Ensure that the endpoint is already paired.
- Ensure that the group is already created.

## Steps to add Endpoint to a Group

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Groups** on the left menu panel.
   ![How to Add an Endpoint to a Group - screenshot 1](/images/intercom/8315188/image-39211325.png)
   The **Groups** page is displayed.
3. Click on a group name to edit from the listed groups.
   ![How to Add an Endpoint to a Group - screenshot 2](/images/intercom/8315188/image-e3dad145.png)
   The Group detail page is displayed.
   ![How to Add an Endpoint to a Group - screenshot 3](/images/intercom/8315188/image-ed33543a.png)
4. Go to **Endpoints** tab > Click **+ Add Endpoint**.
   ![How to Add an Endpoint to a Group - screenshot 4](/images/intercom/8315188/image-ccf988dd.png)
   The **Add Endpoint** pop-up box is displayed.
5. On the **Add Endpoint** pop-up box select endpoint from the **Select endpoints** dropdown list.

Click **Add**.

![How to Add an Endpoint to a Group - screenshot 5](/images/intercom/8315188/a02ccc1f-fbfe-468a-ab60-b2ad0760e026-c3d779d3.png)

The endpoint is added and listed on the **Endpoints** tab.

![How to Add an Endpoint to a Group - screenshot 6](/images/intercom/8315188/image-033d6e08.png)
