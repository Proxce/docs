Steps to configure Endpoint:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to configure Endpoint for... - screenshot 1](/images/intercom/8332796/image-86b2831e.png)
   The Endpoints page is displayed.
3. Click on an endpoint name to edit from the listed endpoints.
   ![How to configure Endpoint for... - screenshot 2](/images/intercom/8332796/image-18a26e0a.png)
   The Endpoint details page is displayed.
   ![How to configure Endpoint for... - screenshot 3](/images/intercom/8332796/image-1c299ef2.png)
4. Do the following:
   **Transaction** tab: You can view the transaction for the endpoint.
   **Settings** tab:
   1. **Endpoint Settings**:
      1. Edit **Endpoint Name** (optional).
      2. Enter **Endpoint Description** (optional).
      3. Enter time-zone from **Timezone** dropdown (optional).

         <Note>
           **Note:** If Endpoint time zone is not specified, by default the endpoint takes the time zone specified for the application.
         </Note>

      4. Enable **Capture Location** toggle button to activate the 'Location Capture' on the endpoint for each transaction.

         <Note>
           **Note:** The Endpoint device 'Location Permission' must be enabled.
         </Note>

      5. Click **Save**.
   2. **Groups:** Add Group to Endpoint.
   3. **Web Button**: Turn on **Enable Web Button** toggle button to view transactions.
   4. **Integration**: Enable Integrations to perform cloud-based actions.
   5. **Configure** tab: Enter integration in the **Integration Name** field and enter URL in the **Add URLs that needs to be monitored** field.
      **Health Response** tab: You can check the health status of the endpoint.
      **Insights**:
      You can view number of active users and endpoint transactions.
      ![How to configure Endpoint for... - screenshot 4](/images/intercom/8332796/image-3e6af229.png)
      **Health:**
      In this section, you can see the endpoint status, check health of the endpoint and configure health alert. For more information on health alert, see**[How to configure health alert for an endpoint](https://oloid.help/en/articles/8245679-how-to-add-health-alerts-in-the-endpoint)**.
      **Endpoint Location:**
      In this section, you can set endpoint location. For more information on adding location, see**[How to add location to the endpoint](https://oloid.help/en/articles/8223212-how-to-add-location-to-the-endpoint)**.
      The endpoint is configured.
