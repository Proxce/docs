## Create location using Transaction

Steps to create a new location through transaction:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Transactions** on the left menu panel.
   ![How to create a new location and add... - screenshot 1](/images/intercom/8227103/image-23099fe3.png)
   The **User Transaction Through Your Device** page is displayed.
3. Click **Location Settings** at the bottom of the left menu panel.
   ![How to create a new location and add... - screenshot 2](/images/intercom/8227103/image-062019a0.png)
   The **Location Settings** page is displayed.
4. Click **Create Location** on the right corner of the page.
   ![How to create a new location and add... - screenshot 3](/images/intercom/8227103/image-c4a7913d.png)
   The **Create Location** pop-up box is displayed.
   ![How to create a new location and add... - screenshot 4](/images/intercom/8227103/image-5487642c.png)
5. Enter **Location Name**.
6. Click **Create**.
   The location is created and listed on the **Location Settings** page.
   ![How to create a new location and add... - screenshot 5](/images/intercom/8227103/image-1c224934.png)

   <Note>
     **Note:** You can enable the toggle button for **Add Navigation Card.** This creates a card view on the right menu panel for that location.
   </Note>

## Create location using Endpoint

Steps to create a new location through endpoint:

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Endpoints** on the left menu panel.
   ![How to create a new location and add... - screenshot 6](/images/intercom/8227103/image-86b2831e.png)
   The **Endpoints** page is displayed.
3. Select endpoint name(s) from the listed endpoints.
   ![How to create a new location and add... - screenshot 7](/images/intercom/8227103/image-18a26e0a.png)
4. Go to **Action** dropdown and select **Add Location**.
   ![How to create a new location and add... - screenshot 8](/images/intercom/8227103/image-eb26d414.png)
   The **Add Location** pop-up box is displayed.
   ![How to create a new location and add... - screenshot 9](/images/intercom/8227103/image-5f0d90e4.png)
5. On the pop-up box do the following:
   1. Click **Select Location** field.
      The search result lists existing locations.
      ![How to create a new location and add... - screenshot 10](/images/intercom/8227103/image-4cb32488.png)
   2. Click **Add New**.
      The **Create Location** pop-up box is displayed.
      ![How to create a new location and add... - screenshot 11](/images/intercom/8227103/image-f96eca37.png)
   3. Enter **Location Name**.
   4. Click **Create**.
      The location name is created and listed on the **Location Settings** page.
      ![How to create a new location and add... - screenshot 12](/images/intercom/8227103/image-b97cbe15.png)

## Adding location details

1. Log in to the **Oloid Portal**.
2. On the home page of the portal, click **Transactions** on the left menu panel.
   ![How to create a new location and add... - screenshot 13](/images/intercom/8227103/image-23099fe3.png)
   The **User Transaction Through Your Device** page is displayed.
3. Click **Location Settings** at the bottom of the left menu panel.
   ![How to create a new location and add... - screenshot 14](/images/intercom/8227103/image-062019a0.png)
   The **Location Settings** page is displayed.
4. Select location name from the listed locations.
   ![How to create a new location and add... - screenshot 15](/images/intercom/8227103/image-b97cbe15.png)
   The Location detail page is displayed.
   ![How to create a new location and add... - screenshot 16](/images/intercom/8227103/image-34bd46c9.png)
5. Enter **Address**.
6. Enter **Description**.
7. Click **+ Add Building** to enter Building Name (optional).
8. Click **Save**.
   The location address is updated.
   ![How to create a new location and add... - screenshot 17](/images/intercom/8227103/image-b67608a0.png)
