## Introduction

This document provides instructions to add a group to an endpoint in the Tenant Admin Portal.

## Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- Ensure that the required group is already created in the Tenant Admin Portal.

## Steps to Add a Group to an Endpoint

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click **Endpoints** from the left navigation panel.
   ![How to Add a Group to an Endpoint - screenshot 1](/images/intercom/8463479/image-822d735e.png)
   The **Endpoints** page is displayed.
3. Select the required endpoint from the list.
   ![How to Add a Group to an Endpoint - screenshot 2](/images/intercom/8463479/image-1c62d06c.png)
   The endpoint detail page is displayed.
4. Click **Configure**.
   ![How to Add a Group to an Endpoint - screenshot 3](/images/intercom/8463479/image-f0a9aef0.png)
   The Configure screen is displayed.
5. Click **Groups** > **+ Add Group**.
   ![How to Add a Group to an Endpoint - screenshot 4](/images/intercom/8463479/image-899a9d59.png)
   The **Add Group** pop-up box is displayed.
6. Select a group name from the **Select Group** drop-down list and then click **Save**.
   ![How to Add a Group to an Endpoint - screenshot 5](/images/intercom/8463479/ca432dce-defa-4adf-95a9-e050ba230940-9f5fb7af.png)
   The selected group is added successfully
   ![How to Add a Group to an Endpoint - screenshot 6](/images/intercom/8463479/image-b053c499.png)
