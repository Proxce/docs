## Introduction

This document provides step-by-step instructions to configure Supervisor privileges in the Tenant Admin Portal.

### Prerequisites

- You must have Tenant Admin access to the Tenant Admin Portal.
- Ensure that the applicable user is assigned the Supervisor role.

## Steps to Configure Supervisor Privileges

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Configure Supervisor Privilege - screenshot 1](/images/intercom/9799715/image-edf44676.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Configure Supervisor Privilege - screenshot 2](/images/intercom/9799715/image-5622cece.png)
   The **Tenant Settings** page is displayed.
4. Go to **Advanced** Tab > **Supervisor Privileges**.
   ![How to Configure Supervisor Privilege - screenshot 3](/images/intercom/9799715/image-0c6c6677.png)
5. Do the following :
   1. Enable **Add/Delete Users** toggle button to allow the supervisor to add or remove users.
   2. Enable **Endpoint Pairing** toggle button to allow the supervisor to create or pair new endpoints.
      ![How to Configure Supervisor Privilege - screenshot 4](/images/intercom/9799715/image-3cfc3c86.png)
      The Supervisor Privileges are updated successfully.
      ![How to Configure Supervisor Privilege - screenshot 5](/images/intercom/9799715/image-385fb012.png)
