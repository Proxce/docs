**Introduction**

A Supervisor is a user with limited access to the Oloid Portal and all the Oloid connected devices.

For adding an existing user as Supervisor, see [How to invite a Supervisor](https://oloid.help/en/articles/8231811-how-to-invite-a-supervisor).

**Pre-requisite**

You must be a Tenant Admin to add a new user as a Supervisor.

**Steps to add and invite a new user as Supervisor:**

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left.
   ![How to add and invite a Supervisor - screenshot 1](/images/intercom/8262858/865f19ce-5b64-4d0f-9e53-462a550ca422-c112f248.png)
   The **user profile menu** is displayed.
3. Click **Tenant Settings**.
   ![Image](/images/intercom/8262858/4729a523-b525-41a6-bf8b-aaa6f3106c76-da55effe.png)
   The **Tenant Settings** page is displayed.
   ![How to add and invite a Supervisor - screenshot 2](/images/intercom/8262858/53821809-1ba9-466e-b2a9-8af59bab7dfd-f31100e3.png)
4. Do the following:
   1. Go to **Admin Controls** > **Supervisors** > **Invite Supervisors**.
      ![How to add and invite a Supervisor - screenshot 3](/images/intercom/8262858/a29123ed-c03c-4253-9804-7e6460dff529-15168348.png)
      OR
   2. Click **Action** > **Invite Supervisor**.
      ![How to add and invite a Supervisor - screenshot 4](/images/intercom/8262858/dd816b8f-e80c-4116-a6f2-680633d5f437-e776421a.png)
5. The **Invite Tenant Supervisor** pop-up box is displayed.
   ![How to add and invite a Supervisor - screenshot 5](/images/intercom/8262858/image-4ed3949c.png)
6. On the pop-up box, do the following:
   1. Enter the user name in the **Search By User or Primary ID** field.
      The search result lists down if there is any existing user.
   2. Click **Add user** to add a new user.
      ![How to add and invite a Supervisor - screenshot 6](/images/intercom/8262858/96ebe6a1-ea22-4cf8-a5d5-5e0c9f4e178c-b20e0b7e.png)
      The **Create Tenant Supervisor** pop-up box is displayed for the new user.
      ![How to add and invite a Supervisor - screenshot 7](/images/intercom/8262858/image-43c504bc.png)
   3. Edit **Full Name**. (if required).
   4. Enter **Primary ID** or select **Use OloID as Primary ID** to use OloID for your primary ID.
   5. Select connection from the **Connection** list.
   6. Enter **Supervisor Email.**
   7. Select **Read Only Mode** to restrict the Supervisor from performing any action. (Optional)
   8. Click **Create & Invite**.

The Tenant Supervisor is created and listed on the **Supervisors** tab.

<Note>
  **Note:** An email is sent to the user for verification.
</Note>
