## Introduction

The Activity Log is a detailed record of login events and actions performed by the Tenant Admin in the Tenant Admin Portal. It also shows time-specific log data that you select from the calendar option.

## Prerequisite

You must have access to Tenant Admin account.

## Steps to view Activity Log

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, do one of the following:
   1. Click **user profile icon** from the bottom left > select **Activity Log** from the menu.
      ![How to view Activity Log in Tenant... - screenshot 1](/images/intercom/10673538/0e491495-6497-40f9-8eb5-6cf187937eff-10d172d4.png)
   2. Select **Monitoring** > **Activity Log**.
      ![How to view Activity Log in Tenant... - screenshot 2](/images/intercom/10673538/image-e48516c7.png)
      The **Activity Log** page is displayed.
3. To select the desired date and time range for a specific time period, use the **calendar** option at the top left.
   ![How to view Activity Log in Tenant... - screenshot 3](/images/intercom/10673538/image-4c2ed295.png)
   The selected date and time range is displayed.
4. Click **OK.**
   The Activity Log data table is displayed for the selected timeline, allowing you to view the Log data.
   ![How to view Activity Log in Tenant... - screenshot 4](/images/intercom/10673538/image-95ef0ec0.png)
   The types of data you get to view in activity log are:
- **Event Type**- This column displays the actions performed on admin portal and also shows logs for endpoints (such as login to admin mode, repair the endpoint, etc.)
- **Target Type**- This column displays the name of the module on which the event occurred.
- **Action By**- This column displays the name and email ID of the Tenant Admin and Supervisor along with their browser and device details that are used to perform the event.
- **Action/Changes**- This column displays the status of the event/action that is performed.
- **Created Date**- This column displays the date on which the activity is performed.

### Activity Log – Add Filters

![How to view Activity Log in Tenant... - screenshot 5](/images/intercom/10673538/image-c36dc241.png)

1. On the Activity Log page click **+ Add** **Filter**.
2. Select the **filter type**. (see table below for filter type)
3. Select the **User, Application, Endpoint, Credential, Action By, or Group** to filter.
   The Activity Log data table is displayed for the selected filter.
   ![How to view Activity Log in Tenant... - screenshot 6](/images/intercom/10673538/image-745b932b.png)

Use the following filters to refine and to view specific activity records on the **Activity Log** page:

**Filter**

**Description**

**User**

Displays activity logs for the selected user, searchable by entering Name or ID.

**Application**

Displays activity logs for the selected application, searchable by entering Name or ID.

**Endpoint Name**

Displays activity logs for the selected endpoint device, searchable by entering Name or ID.

**Credential**

Displays activity logs based on the selected credential type used.

**Action By**

Displays activity logs based on the admin or user who performed the action, searchable by entering Name or ID.

**Group**

Displays activity logs for the selected user group, searchable by entering Name or ID.

<Note>
  **Note:** Each selected filter updates the Activity Log page to display only the records that match the applied criteria.
</Note>
