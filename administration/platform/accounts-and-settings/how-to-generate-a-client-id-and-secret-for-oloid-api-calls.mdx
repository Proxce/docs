This guide will walk you through the steps to generate a **Client ID** and **Client Secret** in the Oloid Portal. These credentials are essential for making API calls to integrate workflows and manage tenant configurations.

## Steps to generate a Client ID and Secret

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Generate a Client ID and Secret... - screenshot 1](/images/intercom/10458687/image-75c5736b.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   **Could not display content**
   The **Tenant Settings** page is displayed.
4. Go to **Security Tab** > **API Token** > **Admin Token**.
   ![How to Generate a Client ID and Secret... - screenshot 2](/images/intercom/10458687/42f29328-e595-40e1-a7ff-8e8c55affc8a-e2e4242f.png)
   The Generate Admin Credential section is displayed.
5. Click **Generate** to generate a new **Client ID** and **Client Secret**.
   ![How to Generate a Client ID and Secret... - screenshot 3](/images/intercom/10458687/4a827e00-ca1e-4bba-9f98-55e17e259541-bb3ae317.png)
   The Client ID and Client Secret are displayed.
   1. **Client ID**: This is a unique identifier for your tenant.
   2. **Client Secret**: This acts as a password and should be kept confidential.
   3. **Get Secret**: Click **Get Secret** to show the unmasked **Client Secret**.
      ![How to Generate a Client ID and Secret... - screenshot 4](/images/intercom/10458687/dd28c2f7-6b17-4846-9ca3-d8cdafd5d2f0-36431c4e.png)

![How to Generate a Client ID and Secret... - screenshot 5](/images/intercom/10458687/b645855a-19f5-44a0-ad32-8b4c31df4672-0d5e6837.png)

The generated **Client ID** and **Client Secret** can now be used as the username and password, respectively, in API calls.

## Deleting and Regenerating Credentials

If you need to revoke the current credentials:

1. Click the **Delete** button next to the existing Client ID and Secret.
   ![How to Generate a Client ID and Secret... - screenshot 6](/images/intercom/10458687/6fbcdf8c-f5cb-4d1b-9f56-1682484f41dd-549f5d8c.png)
2. Repeat the steps above to generate a new set of credentials.

## Security Best Practices

• Store the **Client Secret** in a secure location, such as a password manager.

• Avoid sharing these credentials publicly or with unauthorized personnel.

• If you suspect the credentials have been compromised, immediately delete them and regenerate a new set.

If you encounter any issues, please contact [Oloid Support](mailto:support@oloid.ai)
