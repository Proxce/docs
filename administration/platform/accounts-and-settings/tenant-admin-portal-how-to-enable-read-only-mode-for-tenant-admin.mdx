## Introduction

**Read-only Mode** allows Admin to view configurations, Activity Logs, and Transactions logs. Admin can download the Transaction reports.

## Prerequisites

- You must have Tenant Admin access to the **Tenant Admin Portal**.
- The user must be an existing Tenant Admin.

## Steps to enable Read-only Mode for existing Tenant Admin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to Enable Read-only Mode for Tenant... - screenshot 1](/images/intercom/10660395/image-edf44676.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Enable Read-only Mode for Tenant... - screenshot 2](/images/intercom/10660395/image-190743a7.png)
   The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** tab.
   ![How to Enable Read-only Mode for Tenant... - screenshot 3](/images/intercom/10660395/image-79a06434.png)
5. In the **Tenant Admins** tab, click **kebab menu** (three vertical dots) and select **Enable Read-Only Mode** for the particular Tenant Admin.
   ![How to Enable Read-only Mode for Tenant... - screenshot 4](/images/intercom/10660395/image-847670d5.png)
   The **Enable Read-only Mode** confirmation pop-up box is displayed.
6. Click **Enable**.
   ![How to Enable Read-only Mode for Tenant... - screenshot 5](/images/intercom/10660395/cd438e7a-b626-4dba-a1f0-2af6f5fa99fe-7fe9b42b.png)
   The Read-only Mode is enabled for the admin successfully.
   ![How to Enable Read-only Mode for Tenant... - screenshot 6](/images/intercom/10660395/image-1869b939.png)

<Note>
  **Note:** Once the Read-only mode is enabled, the admin cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![How to Enable Read-only Mode for Tenant... - screenshot 7](https://downloads.intercomcdn.com/i/o/e4gi378c/1466656287/1a4b9e536c985fcf46f76a38650d/image.png?expires=1790294400&signature=3b71f9faeb235d9b9ea7f7fc4406449c189f5a2346d51204b5ed551c230c57e4&req=dSQhEM97m4NXXvMW3nq%2Bge3K5rqJyy6bqAeBmZ2ZCnUtEmJLQiMhX1FrP3Ae%0A5EYA%2BdVssVKSd%2FIseLYH2CmFRKE%3D%0A)) is displayed next to the user name.
</Note>

## Steps to Enable Read-only Mode while inviting Tenant Admin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left.
   ![How to Enable Read-only Mode for Tenant... - screenshot 8](/images/intercom/10660395/b3614d5a-3344-4d95-ae8b-9ce21fc47f73-ed1d9dcc.png)
   The **user profile menu** is displayed.
3. Click **Invite Admin**.
   ![How to Enable Read-only Mode for Tenant... - screenshot 9](/images/intercom/10660395/image-1c8f7530.png)
   The **Invite Tenant Admin** pop-up box is displayed.
   ![How to Enable Read-only Mode for Tenant... - screenshot 10](/images/intercom/10660395/image-5ef4bbd0.png)
4. On the pop-up box, do the following:
   1. Enter **User name** or **Primary ID** of existing User in the search field.
   2. Select the accurate user name from the drop-down list.
   3. Select **Read Only Mode** to restrict the admin from performing any action in the Tenant Admin Portal.

Select **Invite.**

![How to Enable Read-only Mode for Tenant... - screenshot 11](/images/intercom/10660395/a30f9882-a2d4-44ee-856f-bf1772ed940f-7dc3ca7c.png)

---

4. The user is successfully invited as a Tenant Admin with Read-only Mode enabled.
   ![How to Enable Read-only Mode for Tenant... - screenshot 12](/images/intercom/10660395/image-65cc5b49.png)

   <Note>
     **Note:** Once the Read-only mode is enabled, the admin cannot perform any action.
