## Introduction

This document provides instructions to remove a user's Supervisor access in the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Remove a User as a Supervisor

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click the **user profile icon** on the bottom left.
   ![How to Remove a User from a Supervisor - screenshot 1](/images/intercom/8231496/6701d98d-3355-4e65-a49c-892085e9af30-2558d520.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Remove a User from a Supervisor - screenshot 2](/images/intercom/8231496/image-f474228d.png)
   The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** > **Supervisors**.
   ![How to Remove a User from a Supervisor - screenshot 3](/images/intercom/8231496/image-dd9e6391.png)
5. Click **kebab menu** (three vertical dots) for the applicable Supervisor and select **Delete Supervisor**.
   ![How to Remove a User from a Supervisor - screenshot 4](/images/intercom/8231496/image-c5f9aac1.png)
   The **Remove Tenant Supervisor** pop-up box is displayed.
6. Click **Delete**.
   ![How to Remove a User from a Supervisor - screenshot 5](/images/intercom/8231496/image-8387ce8f.png)
   The user's Supervisor access is successfully revoked.
   ![How to Remove a User from a Supervisor - screenshot 6](/images/intercom/8231496/image-f03ed6c7.png)
