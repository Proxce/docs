## Introduction

The Read-only Mode feature limits the Supervisor to viewing data in the Oloid Portal, restricting from performing any actions.

## Steps to enable Read-only Mode for existing Supervisor

1. Log in to the **Oloid Portal**.
2. On the homepage, go to **user profile icon** from the left panel > Select **Tenant Settings**.
   ![How to enable Read-only Mode for... - screenshot 1](/images/intercom/10650272/c4dffeac-08b1-4c64-85da-1e8fd23654e8-fc9273e1.png)
   The **Tenant Settings** page is displayed.
3. Go to **Admin Controls** > select **Supervisors**.
   ![How to enable Read-only Mode for... - screenshot 2](/images/intercom/10650272/Untitled4-dd1897fb.png)
4. Click **Kebab menu** (![How to enable Read-only Mode for... - screenshot 3](https://downloads.intercomcdn.com/i/o/e4gi378c/1468154915/b45a10a3ab00df9c779e675742dd/image.png?expires=1790488800&signature=d8f331a6ac186d1446406060e2a6ac0f81c8ba8578d1c47991c0ad43bc5b71a3&req=dSQhHsh7mYheXPMW3nq%2BgbryiCMmNtD4f309%2FVAsAfpqDaIcqLilFnypI1bU%0AQuG2iW%2FAxWfY7%2F%2Fbl8KeIocw%2B1o%3D%0A))> **Enable Read-only Mode**.
   ![How to enable Read-only Mode for... - screenshot 4](/images/intercom/10650272/Untitled8-0d8925ff.png)
   The **Enable Read-only Mode** confirmation pop-up box is displayed.
5. Click **Enable**.
   ![How to enable Read-only Mode for... - screenshot 5](/images/intercom/10650272/image-7d7c0fb5.png)

The Read-only Mode is enabled for the Supervisor.

![How to enable Read-only Mode for... - screenshot 6](/images/intercom/10650272/Untitled7-89d1e3b5.png)

<Note>
  **Note:** Once the Read-only Mode is enabled, the Supervisor cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![How to enable Read-only Mode for... - screenshot 7](https://downloads.intercomcdn.com/i/o/e4gi378c/1468171398/cb2cdd0a2c94e20a1b8fea79438a/image.png?expires=1790488800&signature=b9573511487caf54259e89708a746248231cf66890c71f91cc6e0b39c31375b2&req=dSQhHsh5nIJWUfMW3nq%2BgQBV3CqugOncyhUNWqRzbz%2BugdITIxjfMtHLzTo0%0AJFWjrpRTqZZUbjvHgsI4mq%2BqNzM%3D%0A)) is displayed next to the user name.
</Note>

## Steps to enable Read-only Mode while inviting a Supervisor

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **User profile icon** on the bottom left corner of the menu panel.
   ![How to enable Read-only Mode for... - screenshot 8](/images/intercom/10650272/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to enable Read-only Mode for... - screenshot 9](/images/intercom/10650272/5c250f53-9139-4dec-a6eb-44755142ea4e-9523b3e7.png)
   The **Tenant Settings** page is displayed.
4. On the **Tenant Settings** page, do one of the following:
   1. Go to **Admin Controls** > **Supervisors** tab > **Invite Supervisor**.
      ![How to enable Read-only Mode for... - screenshot 10](/images/intercom/10650272/image-741951e1.png)
   2. Click **Action** > **Invite Supervisor**.
      ![How to enable Read-only Mode for... - screenshot 11](/images/intercom/10650272/dd816b8f-e80c-4116-a6f2-680633d5f437-be382561.png)
      The **Invite Tenant Supervisor** pop-up box is displayed.
      ![How to enable Read-only Mode for... - screenshot 12](/images/intercom/10650272/image-db275238.png)
5. On the pop-up box, do the following:
   1. Enter **User name** or **Primary ID** of existing User in the search field.
   2. Select the accurate user name from the search list.
      ![How to enable Read-only Mode for... - screenshot 13](/images/intercom/10650272/Untitled8-fcdea97f.png)
   3. Select **Read Only Mode** to restrict the Supervisor from performing any action.
   4. Click **Invite**.
      The user is successfully invited as a Tenant Supervisor with Read-only Mode enabled.
      ![How to enable Read-only Mode for... - screenshot 14](/images/intercom/10650272/Untitled7-8f6f413c.png)

      <Note>
        **Note:** Once the Read-only Mode is enabled, the Supervisor cannot perform any action. A Read-only disclaimer is displayed at the top of every web page, and an editing disabled icon (![How to enable Read-only Mode for... - screenshot 15](https://downloads.intercomcdn.com/i/o/e4gi378c/1468171398/cb2cdd0a2c94e20a1b8fea79438a/image.png?expires=1790488800&signature=b9573511487caf54259e89708a746248231cf66890c71f91cc6e0b39c31375b2&req=dSQhHsh5nIJWUfMW3nq%2BgQBV3CqugOncyhUNWqRzbz%2BugdITIxjfMtHLzTo0%0AJFWjrpRTqZZUbjvHgsI4mq%2BqNzM%3D%0A)) is displayed next to the user name.
      </Note>
