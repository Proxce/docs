## Introduction

This document provides instructions to add or delete applications for a Supervisor in the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Assign Application to Supervisor

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left.
   ![How to Add or Delete Applications for a... - screenshot 1](/images/intercom/8442453/6701d98d-3355-4e65-a49c-892085e9af30-a7c41bda.png)
   The **user profile menu** is displayed.
3. Click **Tenant Settings.**
   ![How to Add or Delete Applications for a... - screenshot 2](/images/intercom/8442453/image-4313f631.png)
   The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** > **Supervisors**.
   ![How to Add or Delete Applications for a... - screenshot 3](/images/intercom/8442453/image-c9e5b346.png)
5. Go to **kebab menu** (three dots) of the selected Supervisor > click **Add/Delete Application.**
   ![How to Add or Delete Applications for a... - screenshot 4](/images/intercom/8442453/image-b2cc757e.png)
   The **Add/Delete Application** pop-up box is displayed.
6. Do the following:
   1. Select the Application from the drop-down.
   2. Click **Add**.
   3. Click **Save**
      ![How to Add or Delete Applications for a... - screenshot 5](/images/intercom/8442453/image-5a6eb6a3.png)

The application is assigned successfully to the Supervisor.

![How to Add or Delete Applications for a... - screenshot 6](/images/intercom/8442453/image-0769a1a7.png)

## Steps to Delete an Application

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left.
   ![How to Add or Delete Applications for a... - screenshot 7](/images/intercom/8442453/cd0bcd48-9415-4747-9601-b79b09347e5e-51c265b7.png)
   The **user profile menu** is displayed.
3. Click **Tenant Settings.**
   ![How to Add or Delete Applications for a... - screenshot 8](/images/intercom/8442453/image-deb34093.png)
   The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** > **Supervisors**.
   ![How to Add or Delete Applications for a... - screenshot 9](/images/intercom/8442453/image-d44109ab.png)
5. Go to **kebab menu** (three dots) of the selected Supervisor > click **Add/Delete Application.**
   ![How to Add or Delete Applications for a... - screenshot 10](/images/intercom/8442453/29ee2c99-f183-4f61-ab8f-def1961dc3e4-2cc4c3ff.png)
   The **Add/Delete Application** pop-up box is displayed.
6. Click Delete icon > click **Save**.
   ![How to Add or Delete Applications for a... - screenshot 11](/images/intercom/8442453/image-f54aaf34.png)

The application is removed from the Supervisor's access. The Supervisor can no longer view users associated with the application.

![How to Add or Delete Applications for a... - screenshot 12](/images/intercom/8442453/image-6b529680.png)
