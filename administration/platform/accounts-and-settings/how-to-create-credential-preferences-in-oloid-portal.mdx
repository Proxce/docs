**Introduction**

In the Oloid Portal, Tenant Admin can set preferred and primary credentials for specific use cases. After setup, the selected credentials will appear in the specified scenarios.

To set credential preferences, follow the below steps:

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to create credential preferences in... - screenshot 1](/images/intercom/10765097/7537dc26-1825-4a99-b451-dec0f8cfd374-870a84d9.png)
   The user profile menu is displayed.
3. Select **Tenant Settings**.
   ![How to create credential preferences in... - screenshot 2](/images/intercom/10765097/fa1c43c7-4144-406c-95f0-378a315842c7-4bed95f4.png)
   The **Tenant Settings** page is displayed.
4. Select **Preferences**.
   ![How to create credential preferences in... - screenshot 3](/images/intercom/10765097/image-c2f518e5.png)
   The **Let's customize the portal for you** pop-up box is displayed.
5. Do the following:
   1. Select the preferred **Credentials** you want to use.
   2. Click **Next**.
      ![How to create credential preferences in... - screenshot 4](/images/intercom/10765097/image-737a16ba.png)
   3. Select the **Primary Credentials**.
   4. Click **Save & Next**.
      ![How to create credential preferences in... - screenshot 5](/images/intercom/10765097/2beb0f5e-7c97-4287-b64b-101cc8b226b0-4925ec97.png)
   5. Select the **Use-cases** for which you intend to use the Oloid Portal.
   6. Click **Finish Setup**.
      ![How to create credential preferences in... - screenshot 6](/images/intercom/10765097/8eac6e9e-661c-460b-bbad-f9bea28b45cb-5672afb0.png)
      The selected credentials are visible in the respective use cases.
