**Introduction**

Enabling the Endpoint Pairing feature in the Tenant Admin Portal allows the Tenant Admin to grant access to Supervisors. Once enabled, supervisors can create or activate endpoints.

Steps to activate Endpoint Pairing action:

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **user profile icon**.
   ![How to activate Endpoint Pairing action... - screenshot 1](/images/intercom/10000759/cd53b515-96b8-44d4-9ad2-0c65bb2203fd-9f3eaf9c.png)
   The **user profile menu** is displayed.
3. Select **Tenant Settings**.
   ![How to activate Endpoint Pairing action... - screenshot 2](/images/intercom/10000759/image-9--f1e0f3f6.png)
   The **Tenant Settings** page is displayed.
4. Go to **Advanced** tab > **Supervisor privileges**.
   ![How to activate Endpoint Pairing action... - screenshot 3](/images/intercom/10000759/0164e32f-8ad2-441e-877f-512912e4a528-d15d9d62.png)
5. Enable **Endpoint Pairing** toggle to allow supervisors to create or pair endpoints.
   ![How to activate Endpoint Pairing action... - screenshot 4](/images/intercom/10000759/image-93fbeed5.png)
   Now, the Supervisor can create or pair a new endpoint.
   ![How to activate Endpoint Pairing action... - screenshot 5](/images/intercom/10000759/image-d23b9e2d.png)
