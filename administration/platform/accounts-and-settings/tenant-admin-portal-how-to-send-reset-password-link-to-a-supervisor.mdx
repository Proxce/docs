## Introduction

This document provides instructions to send a password reset link to a Supervisor from the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Send a Reset Password Link to a Supervisor

1. Log in to the **Tenant Admin Portal**.
2. On the home page, click the **user profile icon** on the bottom left.
   ![How to Send Reset Password Link to a... - screenshot 1](/images/intercom/8232355/6701d98d-3355-4e65-a49c-892085e9af30-2558d520.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Send Reset Password Link to a... - screenshot 2](/images/intercom/8232355/image-f474228d.png)
   The **Tenant Settings** page is displayed.
4. Go to **Admin Controls** > **Supervisors**.
   ![How to Send Reset Password Link to a... - screenshot 3](/images/intercom/8232355/image-dd9e6391.png)
5. Click **kebab menu** (three vertical dots) and select **Reset Password**.
   ![How to Send Reset Password Link to a... - screenshot 4](/images/intercom/8232355/image-81792f41.png)
   The **Reset password** pop-up box is displayed.
6. Click **Confirm**.
   ![How to Send Reset Password Link to a... - screenshot 5](/images/intercom/8232355/image-62d69e40.png)
   The user reset password link is successfully sent to the Supervisor's email ID.
   ![How to Send Reset Password Link to a... - screenshot 6](/images/intercom/8232355/image-443ffb5e.png)
