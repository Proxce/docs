## Introduction

This document provides instructions to reset the password for a Tenant Admin from the Tenant Admin Portal. When you reset the password, a password reset link is sent to the Tenant Admin's registered email address.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to reset password for Tenant Admin

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left of the menu panel.
   ![How to Send a Password Reset Link to a... - screenshot 1](/images/intercom/8237046/53565507-32a6-4d30-8fad-2ff095825483-c7518a4b.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Send a Password Reset Link to a... - screenshot 2](/images/intercom/8237046/image-4a733201.png)
   The **Tenant Settings** page is displayed.
   ![How to Send a Password Reset Link to a... - screenshot 3](/images/intercom/8237046/image-3fcb11d1.png)
4. Go to **Admin Controls** > **Tenant Admin.**
   ![How to Send a Password Reset Link to a... - screenshot 4](/images/intercom/8237046/2b14e75d-517b-4f67-a9f3-cc8331f8310a-132443e0.png)
5. Locate the Tenant Admin, and then select the **kebab menu** (three vertical dots) > **Reset Password**.
   ![How to Send a Password Reset Link to a... - screenshot 5](/images/intercom/8237046/7b2c61e6-edd0-424b-8eb5-0e73cc3fb433-8f95244e.png)
   The **Reset password** pop-up box is displayed.
6. Click **Confirm**.
   ![How to Send a Password Reset Link to a... - screenshot 6](/images/intercom/8237046/5fbd3698-239a-4749-ab79-b5300e201ffc-56c98587.png)
   The user reset password link is successfully sent to the Tenant Admin's email ID.
   ![How to Send a Password Reset Link to a... - screenshot 7](/images/intercom/8237046/image-8afe3d04.png)
