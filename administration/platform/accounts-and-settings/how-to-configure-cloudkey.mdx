## To configure CloudKey follow the below steps

1. Log in to the **Oloid Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![How to configure CloudKey? - screenshot 1](/images/intercom/8803628/image-ad0dfa51.png)
   The user profile menu is displayed.
3. Select **Settings**.
   The **Tenant Settings** page is displayed.
   ![How to configure CloudKey? - screenshot 2](/images/intercom/8803628/image-539cb5ba.png)
4. Go to **Advanced** tab.
   ![How to configure CloudKey? - screenshot 3](/images/intercom/8803628/image-957bb68e.png)
5. Under **Credentials** section select **CloudKey**.
   ![How to configure CloudKey? - screenshot 4](/images/intercom/8803628/image-580634f2.png)
6. On the **Cloudkey Settings** page, do the following:
   1. Turn on **Enable CloudKey Proximity check** to set **GPS Refresh Frequency** and **CloudKey Distance**.

      <Note>
        **Note:** Cloud key Proximity check if enabled will make only those CloudKey endpoints visible which are within the proximity range. If not enabled, all the endpoints will be visible.
      </Note>

      ![How to configure CloudKey? - screenshot 5](/images/intercom/8803628/image-4df9e94f.png)
   2. To set the GPS frequency, adjust the **GPS Refresh Frequency**.
   3. To adjust the distance setting, modify the **CloudKey Distance**.

      <Note>
        **Note:** Turn off the **Enable CloudKey Proximity check** to allow users to unlock doors without distance constraints.
      </Note>

   4. Click **Save**.
      The CloudKey is configured and is ready to be use.
