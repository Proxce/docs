This document provides an overview of the user roles—**Admin, Supervisor, Read-only Admin,** and **Read-only Supervisor**—along with their permissions in Oloid's Tenant Admin Portal.

Permissions are assigned based on roles, which determine the level of access users have to devices and settings within Oloid.

## Admin (Tenant)

An **Admin** has full access to the Oloid platform and all connected devices. Admins can create, update, and delete data.

To become a Tenant Admin, you must be an Oloid user.

An Admin can also grant admin rights to other users. For detailed instructions, refer to:

- [How to invite a Tenant Admin](https://oloid.help/en/articles/8236282-how-to-invite-a-tenant-admin)
- [How to add and invite a Tenant Admin](https://oloid.help/en/articles/8254907-how-to-add-and-invite-a-tenant-admin)

An Admin can:

- Add/invite Tenant Supervisors
- Activate Supervisor privileges
- Add or delete applications for Supervisors

For step-by-step instructions, see:

- [How to invite a Supervisor](https://oloid.help/en/articles/8231811-how-to-invite-a-supervisor)
- [How to add and invite a Supervisor](https://oloid.help/en/articles/8262858-how-to-add-and-invite-a-supervisor)
- [Adding/Deleting Applications for Supervisors](https://oloid.help/en/articles/8442453-adding-deleting-applications-for-supervisors)
- [How to activate Supervisor Privilege](https://oloid.help/en/articles/9799715-how-to-activate-supervisor-privilege)

Once you are an Admin, you can manage the Oloid Portal. For guidance on admin tasks, refer to the **Oloid Help Documents** on [Oloid Platform - Enterprise Features](https://oloid.help/en/collections/3797155-oloid-platform-enterprise-features)

## Read-only Admin (Tenant)

Read-only access restricts the Admin to create, update, and delete data . However, they have full read-only access to all the data .

## Supervisor

A **Supervisor** has limited access to the Oloid Portal and connected devices.

Supervisors can create, update, and delete data only if granted privileges by an Admin.

Once assigned a Supervisor role, you can perform tasks in the Oloid Portal and on connected devices based on your given privileges.

For more details on Supervisor tasks, refer to the **Oloid Help Documents** on [Supervisor Portal](https://oloid.help/en/collections/10092602-supervisor-portal)

## Read-only Supervisor

Read-only access restricts the Supervisor to create, update, and delete data . However, they have full read-only access to all the data .
