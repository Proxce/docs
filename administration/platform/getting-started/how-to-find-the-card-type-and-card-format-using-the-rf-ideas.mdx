**Overview**

This article explains how to identify the card type and card format using the RF IDeas Configurator Tool, which is essential for accurate card configuration and integration.

**Introduction**

RF IDeas Configurator Tool allows access cards to be used as digital identifier throughout the workplace.

**Pre-requisite:**

- Download the latest "rf IDEAS Configuration Utility" from the [RF IDEAS website](https://www.rfideas.com/support/tools/downloads).

To find the card type and card format:

1. Launch the rf IDEAS Configuration Utility app.
   ![How to find the Card Type and Card... - screenshot 1](/images/intercom/9720607/image-3d3c0386.png)
   The app opens.
   ![How to find the Card Type and Card... - screenshot 2](/images/intercom/9720607/image-dae91b28.png)
2. Make sure the card reader is connected to the system.
3. Select **Connect** from the left menu panel.
   ![How to find the Card Type and Card... - screenshot 3](/images/intercom/9720607/image-9aebdeec.png)
   The DEVICE LIST is configured and displayed.
   ![How to find the Card Type and Card... - screenshot 4](/images/intercom/9720607/5491a920-3fe3-4d8f-b4e4-2b1ea661bde8-3acadea7.png)
4. Select **Tools** from the left menu panel.
   ![How to find the Card Type and Card... - screenshot 5](/images/intercom/9720607/image-5b3ae544.png)
5. Go to **Card Analyzer** tab, and click **Start**.
   ![How to find the Card Type and Card... - screenshot 6](/images/intercom/9720607/image-e6b3fab7.png)
   The Welcome screen is displayed.
6. Select **Learn Card**.
   ![How to find the Card Type and Card... - screenshot 7](/images/intercom/9720607/image-6d3a3f83.png)
7. Place the card on the reader and leave it there, then click **Start Scan**.
   ![How to find the Card Type and Card... - screenshot 8](/images/intercom/9720607/image-7ce9daf6.png)
   As the scan runs, the Card Type and Supporting Readers are displayed. If it identifies a card type, it will beep and display the Card Type in the top box.
   ![How to find the Card Type and Card... - screenshot 9](/images/intercom/9720607/image-14c4478b.png)
8. Once the status scan is complete, if you want to configure the reader, then click **Auto Config**.
   ![How to find the Card Type and Card... - screenshot 10](/images/intercom/9720607/image-b84b1069.png)
   The Auto Config screen is displayed.
9. To identify the card, view the card type and the card format information.
   ![How to find the Card Type and Card... - screenshot 11](/images/intercom/9720607/image-ccdbfd4d.png)
10. Click **Exit**.
    ![How to find the Card Type and Card... - screenshot 12](/images/intercom/9720607/image-b96442b9.png)
