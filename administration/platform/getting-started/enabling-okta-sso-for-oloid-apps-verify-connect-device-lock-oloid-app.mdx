Follow these steps to add **Client Application** For **Oloid Applications:**

1. In the Admin Console, go to **Applications > Applications > Create App Integration.**
   ![Enabling Okta SSO for Oloid Apps (... - screenshot 1](/images/intercom/8159402/image-86175336.png)
2. Select **OIDC - OpenID** Connect as the **Sign-in method** and **Native Application** as **Application type.**
   ![Enabling Okta SSO for Oloid Apps (... - screenshot 2](/images/intercom/8159402/image-5263b271.png)
3. Do the following the next screen( General Settings) to configure the application:
   1. Enter a name for the application in the **App integration name** field..
   2. Select **Authorzation Code** as **Grant type**.
   3. Add the following as **Sign-in redirect URIs:**
      1. com.oloid.oloidapp:/callback
      2. com.oloid.OloID:/callback
   4. Select Allow everyone in your organization to access under **Assignments.**
      ![Enabling Okta SSO for Oloid Apps (... - screenshot 3](/images/intercom/8159402/image-6e5934de.png)
4. Click **Save.**
5. Share the **ClientID** and **Okta root domain** of the new app with Oloid.
   ![Enabling Okta SSO for Oloid Apps (... - screenshot 4](/images/intercom/8159402/image-f8724fa1.png)
