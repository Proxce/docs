## Introduction

This document provides instructions to create an application in the Oloid Tenant Admin Portal. Applications define the required product configurations and can be mapped to an Endpoint for use with Oloid products.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Create an application

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Create Application** in the top right corner.
   ![How to Create an Application - screenshot 1](/images/intercom/8294483/image-b81c0695.png)
   The **Create New Application** pop-up box is displayed.
3. Do the following:
   1. Enter **Application Name.**
   2. Selectapplicable **Application Type.**
   3. Click **Create**.
      ![How to Create an Application - screenshot 2](/images/intercom/8294483/image-fcb26f7a.png)
      An application is created based on the application type.
4. Add required details to configure the application and click **Save**.
   The application is configured and listed on the Application page.
   ![How to Create an Application - screenshot 3](/images/intercom/8294483/image-83f48d67.png)
   For detailed instructions to create and configure different application types, refer to below documents.
