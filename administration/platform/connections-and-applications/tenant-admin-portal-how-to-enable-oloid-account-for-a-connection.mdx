## Introduction

The Tenant Admin Portal allows admin to enable OloID accounts for a Connection, providing users with a unique identity across Oloid applications.

<Note>
  **Note:** Enable **OloID accounts** only for Connections used with Oloid Vault, Windows Login, the Tenant Admin Portal and the Oloid User Portal.
</Note>

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- A Connection must be created. To create connections, refer [Tenant Admin Portal - How to Create Connection](https://oloid.help/en/articles/8294297-tenant-admin-portal-how-to-create-connection)

## Steps to Enable OloID Account in a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel.
   ![How to Enable OloID Account for a... - screenshot 1](/images/intercom/8488406/image-40547b9d.png)
   The **Connections** page is displayed.
3. Select a connection name to edit.
   ![How to Enable OloID Account for a... - screenshot 2](/images/intercom/8488406/image-0edbc9da.png)
   The **Connection detail** page is displayed.
4. Go to **Configure** tab > **Settings** > turn on **Enable OloID Account** toggle.

Click **Save**.

![How to Enable OloID Account for a... - screenshot 3](/images/intercom/8488406/image-2eb5e90e.png)

The OloID account is enabled successfully for all the users in the Connection.

![How to Enable OloID Account for a... - screenshot 4](/images/intercom/8488406/image-204cea92.png)

<Note>
  **Note:** OloID account can be created for all OloID account enabled users. To create OloID account, see **[How to create OloID account](https://oloid.help/en/articles/8347798-how-to-create-oloid-account)**.
</Note>
