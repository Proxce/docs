## Introduction

This document provides instructions to create a Connection in the Tenant Admin Portal. A Connection is a logical group of users used to manage access within the Oloid platform. Each user belongs to one Connection. One or more Connections can be linked to one or more applications to grant user's access.

## Prerequisites

You must have an Admin access to the Tenant Admin Portal.

## Steps to Create a Connection

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left panel menu.
   ![How to Create Connection - screenshot 1](/images/intercom/8294297/image-86dcdd8e.png)
   The **Connections** page is displayed.
3. Click **Create Connection**.
   ![How to Create Connection - screenshot 2](/images/intercom/8294297/image-a229cef6.png)
   The **Create a new Connection** pop-up box is displayed.
4. Do the following.
   1. Enter **Connection Name**.

      <Note>
        **Note:** You can enable **PC/SC Badge Input** from the **Advanced Settings** section while creating a Connection for Windows Login Application. For more details refer [How to create PC/SC Badge Input enabled Connections in the Tenant Admin Portal](https://oloid.help/en/articles/11686694-how-to-create-pc-sc-badge-input-enabled-connections-in-the-tenant-admin-portal).
      </Note>

   2. Click **Create**.
      ![How to Create Connection - screenshot 3](/images/intercom/8294297/image-4479ef7b.png)
      A connection is created successfully and listed on the **Connections** page.
      ![How to Create Connection - screenshot 4](/images/intercom/8294297/image-cc0e03fc.png)
