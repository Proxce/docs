## Introduction

This section explains how to create a Windows Login passwordless application in the Tenant Admin Portal and configure the required settings to enable secure user authentication on Windows endpoints.

## Prerequisite

You must have Tenant Admin Access.

## Steps to create and configure Windows Login application

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click **Create Application** in the top right corner.
   ![How to create and configure Windows... - screenshot 1](/images/intercom/9352266/image-5da475bb.png)
   The **Create New Application** pop-up box is displayed.
3. Do the following:
   1. Enter **Application Name.**
   2. Select **Application Type** as **Passwordless**.
   3. Click **Next**.
      ![How to create and configure Windows... - screenshot 2](/images/intercom/9352266/image-8b24929c.png)
      The **Select Passwordless Use Case** page is displayed.
   4. Select **Windows Login** > click **Create**.
      ![How to create and configure Windows... - screenshot 3](/images/intercom/9352266/image-ac5156f7.png)
      The Passwordlessapplication of type **Windows Login** is created and the configuration page is displayed.
4. Configure the following:
   1. [Details tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_d6f1c16aee)
   2. [Authenticator tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_6e2751be8f)
   3. [Theme tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_77adabc23e)
   4. [Configure tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_ba84a9ee65)
   5. Health Setup tab
   6. [Connections tab](https://oloid.help/en/articles/8693859-how-to-create-and-configure-webkey-application#h_aec78abc12)

<Note>
  **Note:** These are one-time settings and all the default settings are recommended.
</Note>

## Configure Details Tab

1. Modify **Application Name** (if required).

   <Note>
     **Note:** Special characters are not allowed in Application Name.
   </Note>

2. Add **Description**. (Optional)

   <Note>
     **Note:** The description should be less than **140** characters.
   </Note>

3. Select your **Timezone** based on your country and region from dropdown list. (Coming Soon)
4. Select **Factor Sequence** from drop down list to activate Multi-Factor Authentication (MFA) for the Application's Endpoints. (Coming Soon)

## Configure Authenticator Tab

You may enable username and one or more credential options based on your requirements.

### Enable Username

**Emp ID/Primary ID:** Enable this option to prompt the user to enter their Employee ID or Primary ID before authentication.

- (Optional) In the **Custom Label** field, enter a label that appears on the login screen instead of **Emp ID / Primary ID**.

![How to create and configure Windows... - screenshot 5](/images/intercom/9352266/image-069f5d39.png)

Email: Enable this option to allow users to enter their email ID before authentication.

- Select the **Remember Username** checkbox to save the user after the first login. Next time, the app skips the ID entry screen and opens the authentication screen directly.

![How to create and configure Windows... - screenshot 6](/images/intercom/9352266/image-e242efd4.png)

## Configure Credentials

### Face

Do the following:

1. To use face as credential, enable **Face** option.
   The **Advanced Settings** page is displayed.
   1. Enable the **Take Re-consent During Transactions** Toggle.
   2. Take Re-consent During transactions: When enabled, shows the re-consent form to users with invalid consent during every face authentication until they re-sign.
2. Configure **Face Match Parameters**, and **Liveliness Check Parameters** on the Advanced Settings page. For more, refer to [How to configure Face credential for Windows Login Application in the Tenant Admin Portal](https://oloid.help/en/articles/11476775-how-to-configure-face-credential-for-windows-login-application-in-the-tenant-admin-portal)

### Configure Settings Tab

- **Enable Auto Launch Mode:** Select this option to auto-launch the Windows Login app in the login screen.
  - **Set Time-Out for Login Screen:** Select this option to allow users to configure the maximum time the system will wait on the login screen before timing out.
    ![How to create and configure Windows... - screenshot 17](/images/intercom/9352266/image-ed63d81f.png)
- **Use Groups for Authorization:** *Coming Soon*
- **Validate Windows Credential:** Select this option to ensure Oloid Agent checks the validity of the user’s Windows credentials before logging in.
  ![How to create and configure Windows... - screenshot 18](/images/intercom/9352266/eb2db23d-d635-4de9-9c1b-5339989e909d-6dff0f86.png)
- **Enable Passkey:** Turn on **Enable Passkeys** toggle button to allow users to log in using Passkey credential.
  ![How to create and configure Windows... - screenshot 19](/images/intercom/9352266/4ca57c09-bbde-4364-9747-4fb2b48a86a3-6446d918.png)
- **Allow Credential Updates and Enrollment:** Select this option to allow users to self-enroll or update their credentials.
  - Enable **Hide Option to Save Windows Credentials** toggle to hide the Save credentials option from the enrollment screen after Windows domain credentials are validated.
  - Select **Auto-save credentials on successful validation when the Save choice is hidden** checkbox to automatically save validated Windows credentials to the user’s Oloid account when the Save credentials option is hidden.
  - Enable **Allow Login Through Local Credentials** to allow users to log in to Windows using their local Windows credentials. For more, refer to [How to Configure Allow Login Through Local Credentials](https://oloid.help/en/articles/13615407-windows-login-how-to-configure-allow-login-through-local-credentials)
    ![How to create and configure Windows... - screenshot 20](/images/intercom/9352266/image-a09096cc.png)
- **Capture Windows User Events:** Select this option to capture Windows events for user logins, logouts, locks, unlocks, and credential provider details. All captured data is stored in the transaction tab.
  ![How to create and configure Windows... - screenshot 21](/images/intercom/9352266/8727ac67-5f34-4de8-8861-02ebc11aa335-c6a77e11.png)
- Enable **Auto-recover Endpoint** to automatically validate and sync the endpoint configuration during login module launch.
  ![How to create and configure Windows... - screenshot 22](/images/intercom/9352266/image-4b1bc976.png)
- **Enable Manual Capture Accessibility:** Turn on this option to allow users to manually capture their face during face authentication.
  ![How to create and configure Windows... - screenshot 23](/images/intercom/9352266/999da614-7e89-4423-8022-4e974504770d-b33ddb4b.png)
- **Enable Auto Authentication of Oloid Apps Using Oloid Session toggle.**
  Enabling this toggle will allow user to auto-authenticate the user using the Windows session, into Oloid apps after device login.
  ![How to create and configure Windows... - screenshot 24](/images/intercom/9352266/image-9421cdf7.png)
- **Enable Badge Out:** Select **Badge out using Windows Service** option to allow users to log out of their Windows system using their badge. For details, refer to [Windows Login - How to configure Enable Badge Out option](https://oloid.help/en/articles/10616183-windows-login-how-to-enable-badge-out-option)
  ![How to create and configure Windows... - screenshot 25](/images/intercom/9352266/image-6cf36057.png)
- **Master Admin override passcode:** Follow the onscreen instruction to create master admin override passcode. For details, refer [How to create device-admin passcode for Supervisor App](https://oloid.help/en/articles/9244629-how-to-create-device-admin-passcode-for-supervisor-app)
  ![How to create and configure Windows... - screenshot 26](/images/intercom/9352266/image-410f3bf9.png)
- **Apply Endpoint Template**: Select a Windows Login endpoint template that is applied during the endpoint pairing process.
  ![How to create and configure Windows... - screenshot 27](/images/intercom/9352266/image-d0974a45.png)
- **Enable Proxy Configuration** to configure proxy settings for secure network communication through a proxy server.
- Do the following:
  - Enter **Proxy URL**.
  - Enter **Port**.
  - Enter **Username**.
  - Enter **Password**.
- Click **Save**.

Auto update features keep all Windows Device Agents up to date without manual effort. It allows the tenant admin to install the latest version or select a specific version. They can also schedule updates to run at a set time, with options to retry if an update fails.

For more, refer to [How to configure Auto Update feature in Windows Login Application in Tenant Admin Portal](https://oloid.help/en/articles/11114161-how-to-configure-auto-update-feature-in-windows-login-application-in-tenant-admin-portal)
