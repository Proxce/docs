## Introduction

The Tenant Admin Portal allows the admin to Remove/ disable consent of a connection or Change the consent Template of a connection.

## Prerequisites

- You must create a Consent template. To create refer **[How to create a Consent Template](https://oloid.help/en/articles/8254979-how-to-create-a-consent-template)**.
- You must have access to the Tenant Admin Portal.

## Steps to add Consent

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel.
   ![How to Change Consent Template of a... - screenshot 1](/images/intercom/13407101/image-90bad06c.png)
   The **Connections** page is displayed.
3. Select a connection name to edit.
   ![How to Change Consent Template of a... - screenshot 2](/images/intercom/13407101/image-a7b92865.png)
   The Connection detail page is displayed.
   ![How to Change Consent Template of a... - screenshot 3](/images/intercom/13407101/image-e723d15a.png)
4. Go to **Configure Tab** > click **Consent.**
   ![How to Change Consent Template of a... - screenshot 4](/images/intercom/13407101/image-9aab2527.png)
5. Click **Disable / Change Consent.**

![How to Change Consent Template of a... - screenshot 5](/images/intercom/13407101/image-ff3642b3.png)

The Change consent Alert pop-up box is displayed.

Do one of the following:

1. To [Remove and Disable Consent Template](#remove-and-disable-consent-template)
2. To [Change Consent Template](#to-change-consent-template)

---

#### Remove and Disable Consent Template

1. Select **Remove and Disable Consent** > Select the **Consent template** from the dropdown list.
2. Click **Next.**
   ![How to Change Consent Template of a... - screenshot 6](/images/intercom/13407101/image-b4c479ea.png)
   The Consent Removal Alert pop-up box is displayed.
3. **Type** the reason for removal of Consent or **upload a supporting document.**
4. Click **Confirm.**

![How to Change Consent Template of a... - screenshot 7](/images/intercom/13407101/image-41bb7c67.png)

The Consent is successfully changed.

![How to Change Consent Template of a... - screenshot 8](/images/intercom/13407101/image-e26add3b.png)

---

#### To Change Consent Template

1. Select **Change Consent Template** > Select the **Consent template** from the dropdown list.

   <Note>
     **Note:** Only Published Consent Templates will appear in the dropdown list.
   </Note>

2. Click **Next.**
   ![How to Change Consent Template of a... - screenshot 9](/images/intercom/13407101/image-b124c7a2.png)
   The Applicable User Set pop-up box is displayed.
3. Select **New User Only** (or) **All User** > click **Next.**

   <Note>
     **Note:** Selecting *All users* updates the consent template for all existing and new users, while selecting *New users only* applies the updated template only to users created after the change.
   </Note>

   ![How to Change Consent Template of a... - screenshot 10](/images/intercom/13407101/image-e7f2c999.png)
   The Authentication Validity pop-up box is displayed.
4. Select **No End Date** (or) **Permit Authentication until the set date** > click **Confirm**.

   <Note>
     **Note:** Ensure that all users provide consent within the defined authentication validity period, if a validity date is configured.
   </Note>

![How to Change Consent Template of a... - screenshot 11](/images/intercom/13407101/image-ad340874.png)

The Consent Template for the connection is successfully changed.

![How to Change Consent Template of a... - screenshot 12](/images/intercom/13407101/image-282b4ecf.png)
