## Introduction

The **Language Version** option allows the Tenant Admin to create localized versions of an existing consent template. Multiple language versions can be added to a single consent document.

## Prerequisite

- You must have a Tenant Admin account.
- Consent Template must be created. Refer **[How to create and configure consent template](https://oloid.help/en/articles/8254979-how-to-create-and-configure-consent-template)**
- Legal Document must be created. Refer **[How to create Legal Document](https://oloid.help/en/articles/8329688-how-to-create-legal-document)**.

## To create a consent template

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Consent Documents** on the left menu panel.
   ![Image](/images/intercom/14459745/d0fc4d7a-0fa9-417b-828d-aa041b1c0198-79a08af9.png)
   The **Consent Documents** page is displayed.
3. Select the required **Consent Template** for which Language version needs to created.
   ![How to Create and Configure Language... - screenshot 1](/images/intercom/14459745/image-69c833c7.png)
   The template detail page is displayed.
4. On the top right, click **Language Version**.
   ![How to Create and Configure Language... - screenshot 2](/images/intercom/14459745/image-340d317c.png)
   The **Language Version** list page is displayed.
5. On the top right, click **Create Language Version.**
   ![How to Create and Configure Language... - screenshot 3](/images/intercom/14459745/image-f6c75f96.png)
   The Create language version pop-up box is displayed.
6. Select **Consent Language** from dropdown > click **Create Template**.

![How to Create and Configure Language... - screenshot 4](/images/intercom/14459745/image-6398c4b7.png)

The **Language Version** is successfully created.

![How to Create and Configure Language... - screenshot 5](/images/intercom/14459745/image-fb19bd5c.png)

<Note>
  **Note:** The created language version must be in published status, language version(s) in draft status will not appear in preferred language selection dropdown.
</Note>
