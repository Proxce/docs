## Introduction

The Tenant Admin Portal allows admins to configure a consent template to obtain user approval before capturing and storing facial data.

## Prerequisites

- You must create a Consent template. To create refer **[How to create a Consent Template](https://oloid.help/en/articles/8254979-how-to-create-a-consent-template)**.
- You must have a Tenant Admin Account.

## Steps to add Consent

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Connections** on the left menu panel.
   ![How to add a Consent Template to a... - screenshot 1](/images/intercom/8237994/image-90bad06c.png)
   The **Connections** page is displayed.
3. Select a connection name to edit.
   ![How to add a Consent Template to a... - screenshot 2](/images/intercom/8237994/image-a7b92865.png)
   The Connection detail page is displayed.
   ![How to add a Consent Template to a... - screenshot 3](/images/intercom/8237994/image-be69f451.png)
4. Click **Configure** tab then select **Consent** tab.
   ![How to add a Consent Template to a... - screenshot 4](/images/intercom/8237994/image-d4d1e4de.png)
5. Click **Enable Consent**.
   ![How to add a Consent Template to a... - screenshot 5](/images/intercom/8237994/image-8a31610d.png)
   Enable Consent popup-box is displayed.
6. Do the following:
   1. Select the applicable **Consent Template** from the dropdown list.

      <Note>
        **Note:** To create a consent template, refer [How to create a Consent Template](https://oloid.help/en/articles/8254979-how-to-create-a-consent-template).
      </Note>

   2. Click **Next**.
      ![How to add a Consent Template to a... - screenshot 6](/images/intercom/8237994/image-6c92450e.png)
      Applicable User Set screen is displayed.
   3. Select **All Users** > Click **Next**.
      ![How to add a Consent Template to a... - screenshot 7](/images/intercom/8237994/image-e3201482.png)
      Authentication validity pop-up box is displayed.
   4. Do one of the following:
      1. **No end-date:** Select this option to allow authentication without a defined end date. Face images and biometric data for all users in the connection whether they have already provided consent or have not yet provided will remain valid, and users will continue to authenticate using face biometrics after signing the re-consent document.
         OR
      2. **Permit authentication until the Set Date:** Select this option and enter the preferred date.

         <Note>
           **Note:** If consent is not provided by the selected date, the face data and associated biometric information will be deleted.
         </Note>

   5. Click **Confirm**.
      ![How to add a Consent Template to a... - screenshot 8](/images/intercom/8237994/image-00ff5624.png)
   6. **Consent Updated** popup box is displayed.
   7. Click **Okay**.
      ![How to add a Consent Template to a... - screenshot 9](/images/intercom/8237994/image-a0d5226c.png)
      Consent is enabled for the connection.
      ![How to add a Consent Template to a... - screenshot 10](/images/intercom/8237994/image-1d772d98.png)
