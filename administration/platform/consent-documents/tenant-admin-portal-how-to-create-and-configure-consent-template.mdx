## Introduction

Users need to provide consent to store and use their face for different applications within the workplace during face onboarding.

## Prerequisite

- You must have a Tenant Admin account
- Legal Document must be created. Refer **[How to create Legal Document](https://oloid.help/en/articles/8329688-how-to-create-legal-document)**.

## To create a consent template

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, click **Consent Documents** on the left menu panel.
   ![How to Create and Configure Consent... - screenshot 1](/images/intercom/8254979/image-17026ee9.png)
   The **Consent Documents** page is displayed.
3. On the top right, select **Create Consent Template**.
   ![How to Create and Configure Consent... - screenshot 2](/images/intercom/8254979/image-ce8ead92.png)
   The **Create Consent Template** pop-up dialog box is displayed.
4. On the pop-up dialog box, provide the **Template Name**.
5. Click **Create Template**.
   ![How to Create and Configure Consent... - screenshot 3](/images/intercom/8254979/image-ca34a13a.png)
   The template detail page is displayed.
   1. On the template detail page, do the following:
      1. Enter **Consent Document Heading**. (Required)
      2. Edit **Version** number. (Required)
      3. Edit **Section Heading**. (Required)
      4. Edit **Consent Description**. (Required)
      5. Select template status from **Status** dropdown.

         <Note>
           **Note:** The consent document can not be added to a connection unless it is in the published status. A Consent template in draft status cannot be added to connections.
         </Note>

      6. Select language from **Preferred Language** dropdown. (Optional)

         <Note>
           **Note:** The selected language will appear in consent documents across all apps during face onboarding. Language Version for the Consent Document can be created. Refer: [Tenant Admin Portal - How to Create and Configure Language version for Consent Template](https://oloid.help/en/articles/14459745-tenant-admin-portal-how-to-create-and-configure-language-version-for-consent-template)
         </Note>

      7. Change **Legal Document Heading**. (optional)
      8. Select legal document(s) from **Legal Document** dropdownlist. (Required)

         <Note>
           **Note:** If unavailable, click **Create Legal Document** to upload a new legal document. Refer **[How to create Legal Document](https://oloid.help/en/articles/8329688-how-to-create-legal-document)**.
         </Note>

      9. Enable **Show Scope** toggle.

         <Note>
           **Note:** Enabling this toggle displays the consent form's scope, indicating whether it applies to all applications or only the visitor application.
         </Note>

      10. Click **Save**.
          ![How to Create and Configure Consent... - screenshot 4](/images/intercom/8254979/image-1ab1f00f.png)

The Consent Template is configured successfully.
