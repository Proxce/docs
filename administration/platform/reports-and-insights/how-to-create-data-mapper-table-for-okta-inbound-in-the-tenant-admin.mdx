## Introduction

The Data Mapper Table in the Tenant Admin Portal allows admins to map employee data from external systems such as OKTA - Inbound to Oloid. This document provides instructions on how to create the Data Mapper table for OKTA - Inbound.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Create Data Mapper Table

1. Log in to Tenant Admin Portal.
2. Go to **Agents** tab > click **Data Tables**.
   ![Inbound in the Tenant Admin Portal - screenshot 1](/images/intercom/13696298/image-62bfe739.png)
   The Data Tables page is displayed.
3. Click **Create Table**.
   ![Inbound in the Tenant Admin Portal - screenshot 2](/images/intercom/13696298/image-9d7271ec.png)
   The **Create Data Table** pop-up box is displayed.
4. Do the following:
   1. Enter **Table Name**.
   2. Select **Data-mapper Table** in Type of Table.
   3. Click **Next**.
   4. Select **OKTA - Inbound** as a Category.
   5. Click **Create**.
      ![Inbound in the Tenant Admin Portal - screenshot 3](/images/intercom/13696298/image-36ddee25.png)
      The data mapper table is created successfully.
      ![Inbound in the Tenant Admin Portal - screenshot 4](/images/intercom/13696298/image-78f5c8b4.png)
