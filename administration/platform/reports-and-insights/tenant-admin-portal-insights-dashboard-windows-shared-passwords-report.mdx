## Introduction

The **Windows Shared Passwords Report** provides detailed information about shared credentials configured for Windows endpoints. This document walks you through the steps to access and download the report from the Insights Dashboard in the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Download Windows Shared Passwords Report

1. Log in to the **Tenant Admin Portal.** To login refer, [Tenant Admin Portal - How to Log in to the Tenant Admin Portal](https://oloid.help/en/articles/8462765-tenant-admin-portal-how-to-log-in-to-the-tenant-admin-portal).
2. From the left navigation menu, click **Insights**.
   The Insight dashboard screen is displayed.
   ![Insights Dashboard: Windows Shared... - screenshot 1](/images/intercom/13256535/jira-2-_1-80e53a19.png)
3. Select **Reports** tab > **Credentials** > **Windows Shared Passwords.**
   ![Insights Dashboard: Windows Shared... - screenshot 2](/images/intercom/13256535/jira-2-_2-b7266d5f.png)
   The Windows Shared Passwords page is displayed.
4. Click **Download Report**.
   ![Insights Dashboard: Windows Shared... - screenshot 3](/images/intercom/13256535/jira-3-_4-b43570eb.png)
   The Windows Shared Passwords Report is successfully downloaded.
   ![Insights Dashboard: Windows Shared... - screenshot 4](/images/intercom/13256535/jira-2-_3-7a258c8c.png)
