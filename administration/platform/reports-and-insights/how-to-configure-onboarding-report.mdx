## Introduction

The onboarding report can be configured to schedule the report generation frequency and send it to the customers through email.

## Pre-Requisite

You must have a Tenant Admin account.

## Steps to configure Onboarding Report

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Scheduled** on the left menu panel.
   ![Image](/images/intercom/8455465/99856871-33c6-4ecb-a397-757e0d40bce8-88dd241c.png)
   The **Scheduled Reports** page is displayed.
3. Select report name of onboarding report type to edit.
   ![Image](/images/intercom/8455465/11b30811-624c-4144-8ec3-f46430aebb0d-ab96dced.png)
   The report type detail page is displayed.
   ![How to configure Onboarding Report - screenshot 1](/images/intercom/8455465/image-9ffe8c4f.png)
4. On the **Settings** tab, do the following:
   1. Enter **Report Description**.
   2. Select **Connection**(s).
   3. Enter time unit for **Frequency**.
   4. Select the frequency for generating the report.: **Day**, **Hour**, **Minutes**.
   5. (Optional)Turn on **Enable onboarded users only** to allow those users' data in the report whose 'faces' have been onboarded.
   6. Enter **Recipient Emails**.
   7. Click **Save**.
      The onboarding report is configured.
5. On the **Scheduled Reports** page, turn on the **Status** option to send scheduled onboarding reports to the specified email address(es) of recipients.
   ![Image](/images/intercom/8455465/dd23c2b3-b3f2-469d-9e3d-6b6916f32c21-82bfbdd1.png)

   <Note>
     **Note:**

     - Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
     - The downloaded file format for reports is XLSX.
   </Note>
