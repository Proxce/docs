## Introduction

This report provides a list of users with Windows shared passwords.

## Prerequisite

- You must have Tenant Admin account.
- Shared credentials must be assigned to users.

## How to Access User Report

1. Log in to the Tenant Admin Portal.
2. From the left navigation menu, click **Insights** Icon.
3. Select the **Reports** tab > **Users** > **Users &lt;> Shared Cred**
   ![Insights Dashboard: Reports (Users... - screenshot 1](/images/intercom/13256388/image-345dfdd2.png)
   The **User Shared Cred Report** page is displayed.
4. Click **Add Filters** to narrow down the report based on specific criteria.
   ![Insights Dashboard: Reports (Users... - screenshot 2](/images/intercom/13256388/image-e11ae32f.png)
5. Select filter from dropdown.
   ![Insights Dashboard: Reports (Users... - screenshot 3](/images/intercom/13256388/image-1fb0f944.png)
6. Click **Download Report** to export the User Shared Cred Report.
7. Enter **Report Name** and select the required table columns.'
8. Click **Download**.
   ![Insights Dashboard: Reports (Users... - screenshot 4](/images/intercom/13256388/image-fc163a4a.png)
   The Report is successfully downloaded.

---

<Note>
  **Note:** Report Generation Details
</Note>

- The report runs **daily at 12:00 AM PST**.
- It displays data from the **last 30 days**.
- The **Last generated** date and time is shown at the top of the page.
- Use the pagination controls at the bottom of the page to navigate through multiple pages of users.
