## Introduction

This document provides instructions on how to configure a Data Mapper Table for ADP Workforce Now Inbound in the Tenant Admin Portal.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Data Mapper Table for ADP Workforce Now Inbound must be created. To create refer, [How to Create Data Mapper Table for ADP Workforce Now Inbound in the Tenant Admin Portal](https://oloid.help/en/articles/15174007-how-to-create-data-mapper-table-for-adp-workforce-now-inbound-in-the-tenant-admin-portal).

## Steps to Configure Data Mapper Table

1. Log in to the **Tenant Admin Portal**.
2. On the home page of the portal, go to **Agents > Data Tables**.
   ![How to Configure Data Mapper Table for... - screenshot 1](/images/intercom/15174524/image-8c032d90.png)
   The **Data Tables** page is displayed.
3. Click the ADP Workforce Now Inbound data table.
   ![How to Configure Data Mapper Table for... - screenshot 2](/images/intercom/15174524/image-71889e81.png)
   The data table details page is displayed.
4. Do the Following:
   1. [Configure Details Tab](#configure-details-tab)
   2. [Setup Configure Tab](#setup-configure-tab)
      ![How to Configure Data Mapper Table for... - screenshot 3](/images/intercom/15174524/image-217a97bc.png)
      After saving your changes, the Data Mapper Table for A**DP Workforce Now Inbound** is configured successfully.

### Configure Details Tab

This tab is used to view and edit basic information about the data mapper table.

Do the following:

1. Update the **Table Name** (Optional).
2. Enter **Description** (Optional).
3. Click **Save**.
   ![How to Configure Data Mapper Table for... - screenshot 4](/images/intercom/15174524/image-6ef0fbe4.png)
   The details tab is configured successfully.

### Setup Configure Tab

This tab is used to configure data field mappings between ADP Workforce Now Inbound and Oloid.

<Note>
  **Note:** The **FullName, DisplayName, PrimaryID, and Status** fields are mandatory and must be mapped to corresponding source fields or expressions before saving the configuration.
</Note>

Do one of the following:

- [Inline](#inline)
  **OR**
- [Upload File](#upload-file)
  ![How to Configure Data Mapper Table for... - screenshot 5](/images/intercom/15174524/image-21753a93.png)
  The Configure tab is set up successfully.

### Inline

In the **Inline** section, do the following:

1. **Source / Expression:** Enter the ADP field name or expression that provides the source value.
2. **Destination – Oloid Field:** Enter the Oloid field name to which the source value is mapped.
3. **Data Type:** Select the data type from the drop-down.
4. Click **Add field** to add more fields.

   <Note>
     **Note:** For mapping the table, refer **[Data mapper Table](#steps-to-configure-data-mapper-table)**.
   </Note>

5. Click **Save**.
   ![How to Configure Data Mapper Table for... - screenshot 6](/images/intercom/15174524/image-6395743e.png)
   The Inline section is configured successfully.

### Upload File

In the **Upload File** section, do the following:

1. Select **Upload File** and upload the mapping file.

   <Note>
     **Note:** The file format must be in **.XLSX** or **.CSV**.
   </Note>

2. Click **Save**.
   ![How to Configure Data Mapper Table for... - screenshot 7](/images/intercom/15174524/image-e69fc492.png)
   The Upload File section is configured successfully.
