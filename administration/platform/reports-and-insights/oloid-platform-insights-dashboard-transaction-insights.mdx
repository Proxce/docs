## Introduction

The **Transaction Insights** section under **Insights** provides admin with visibility into authentication across the organization.

## Prerequisite

- You must have Tenant Admin account.

## How to Access Transaction Insights

1. Log in to the **Tenant Admin Portal**.
2. From the left navigation menu, click **Insights**.
   ![Insights Dashboard: Transaction Insights - screenshot 1](/images/intercom/13228776/image-1fb15148.png)
3. Select the **Transaction Insights** tab.
   The Transaction Insights dashboard is displayed.
4. Do the Following:

### Transaction Status

This section displays the current status of transactions for the selected time period.

Available Time Filters:

- Yesterday
- Last 7 Days
- Last 30 Days

Click **Download** icon to export transaction status data.

![Insights Dashboard: Transaction Insights - screenshot 2](/images/intercom/13228776/image-f63f2cd6.png)

<Note>
  **Note:** If no transactions are available for the selected time range, a *“No data to show yet”* message is displayed.
</Note>

**Transaction Status Categories**

- **Success** – Transactions completed successfully.
- **Failed** – Transactions that did not complete successfully.
- **Pending** – Transactions that are in progress.
- **Others** – Transactions that do not fall into the above categories.

### Transaction Growth

![Insights Dashboard: Transaction Insights - screenshot 3](/images/intercom/13228776/image-00591ede.png)

Users can do the following:

- Compare growth percentage with the previous period (for example, vs last week).
- Switch between:
  - Last 7 Days
  - Last 30 Days

Click **Download**.

### User Activity Over Time

This section shows unique user activity based on **successful transactions** over a selected time period.

- **Last 7 Days**
- **Last 30 Days**

![Insights Dashboard: Transaction Insights - screenshot 4](/images/intercom/13228776/image-091ada99.png)

Click **Download**.

The report is successfully downloaded.
