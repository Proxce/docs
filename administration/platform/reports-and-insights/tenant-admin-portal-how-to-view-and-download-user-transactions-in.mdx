## Introduction

This document provides instructions to view and download user transactions report from the Tenant Admin Portal. A user transaction records a user's authentication activity, including details such as the transaction date and time, credential type, application, endpoint, and transaction status.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to View and Download User Transactions

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Transactions** on the left menu panel.
   ![How to View and Download User... - screenshot 1](/images/intercom/8223521/image-3a572d99.png)
   The **User Transactions** page is displayed.
3. Click **Export to excel** icon.
   ![How to View and Download User... - screenshot 2](/images/intercom/8223521/8c8a3baa-716c-43f9-95eb-8b592c0696f0-0db1701e.png)
   The **Export to Excel** pop-up box is displayed.
4. Do the following.
   1. Select the date and time from the calendar for **From Date & Time** and **To Date Time.**
   2. Select time-zone from **Time-zone** drop-down list.

      <Note>
        **Note:** Click the **Use Application Time** checkbox to show transactions based on the time-zone set in the application.
      </Note>

   3. Select transaction status from **Transaction Status** drop-down list.
   4. Select application names from **Application Names** drop-down list.
   5. Select endpoint names from **Endpoint Names** drop-down list.
   6. Enter **Primary ID**.
   7. Select Mode from **Mode** drop-down list.
   8. Select face match status from **Face Match Status** drop-down list.
   9. Click **Download.**

      <Note>
        **Note:** All filters are optional. If you do not apply any filters, the report includes transactions from the past seven days.
      </Note>

      ![How to View and Download User... - screenshot 3](/images/intercom/8223521/image-a377a93a.png)
      The **transaction report** is saved to the local device.

      <Note>
        **Note:** The downloaded file format for reports is XLSX.
      </Note>
