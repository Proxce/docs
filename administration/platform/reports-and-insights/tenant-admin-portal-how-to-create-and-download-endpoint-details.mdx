## Introduction

This document provides step-by-step instructions to create and download an Ad-Hoc Endpoint Details Report from the Tenant Admin Portal. The report provides endpoint details, including the associated application information.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

## Steps to Create and Download Endpoint Details Report

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Reports > Ad-Hoc** on the left menu panel.
   ![How to Create and Download Endpoint... - screenshot 1](/images/intercom/8450051/image-5c873bd6.png)
   The **Ad-Hoc Reports** page is displayed.
   ![How to Create and Download Endpoint... - screenshot 2](/images/intercom/8450051/image-b37e127f.png)
3. Do one of the following:
   1. Select **Endpoint Details Report** from the left menu panel, and then click **+ Create & Download Report**.
      ![How to Create and Download Endpoint... - screenshot 3](/images/intercom/8450051/image-fe29ee29.png)
      OR
   2. Click **Create Report** > **Endpoint Details Report**.
      ![How to Create and Download Endpoint... - screenshot 4](/images/intercom/8450051/image-3ea72025.png)
      The report is created and saved to your local device.

      <Note>
        **Note:** The downloaded file format for reports is XLSX.
      </Note>

      ![How to Create and Download Endpoint... - screenshot 5](/images/intercom/8450051/image-878390e9.png)
