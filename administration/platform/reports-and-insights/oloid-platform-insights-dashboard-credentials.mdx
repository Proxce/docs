## Introduction

The **Credentials** section under **Insights** provides admin with visibility into user credential enrollment across the organization.

## Prerequisite

- You must have Tenant Admin account.

## How to Access Credentials Insights

1. Log in to the **Tenant Admin Portal**.
2. From the left navigation menu, click **Insights**.
   ![Insights Dashboard : Credentials - screenshot 1](/images/intercom/13228799/image-4f9e4013.png)
3. Select the **Credentials** tab.
   The Credentials Insights dashboard is displayed.
4. Do one of the following:
   1. **Connection / Group**
      - Select **Connection** to filter users based on directory connections.
      - Select **Group** to filter users based on specific user groups.
        ![Insights Dashboard : Credentials - screenshot 2](/images/intercom/13228799/image-aa91c6fd.png)
5. **Select Credentials** from dropdown
   Filter insights by one or more credential types.
6. Click **Apply** after selecting filters to update the dashboard data.
   ![Insights Dashboard : Credentials - screenshot 3](/images/intercom/13228799/image-06199034.png)
7. Click **Download**.
   The report is successfully downloaded.

<Note>
  **Note:** The sum of users across credential types may be greater than the total number of users, as a user can be enrolled with multiple credential types.
</Note>

**User Categories**

- **Users with credentials** – Users enrolled with at least one credential.
- **Users without any credential** – Users who have not enrolled any credential.

The center of the pie chart displays the **Total Users** count.
