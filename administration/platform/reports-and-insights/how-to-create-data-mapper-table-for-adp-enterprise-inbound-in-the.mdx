## Introduction

The Data Mapper Table in the Tenant Admin Portal allows admins to map employee data from external systems such as ADP Enterprise Inbound to Oloid. This document provides instructions on how to create the Data Mapper table for ADP Enterprise Inbound.

## Prerequisite

You must have access to the **Tenant Admin Portal**.

## Steps to Create Data Mapper Table

1. Log in to **Tenant Admin Portal**.
2. Go to **Agents** tab > click **Data Tables**.
   ![How to Create Data Mapper Table for ADP... - screenshot 1](/images/intercom/13718403/image-62bfe739.png)
   The Data Tables page is displayed.
3. Click **Create Table**.
   ![How to Create Data Mapper Table for ADP... - screenshot 2](/images/intercom/13718403/image-9d7271ec.png)
   The **Create Data Table** pop-up box is displayed.
4. Do the following:
   1. Enter **Table Name**.
   2. Select **Data-mapper Table** in Type of Table.
   3. Click **Next**.
   4. Select **ADP Enterprise Inbound** as a Category.
   5. Click **Create**.
      ![How to Create Data Mapper Table for ADP... - screenshot 3](/images/intercom/13718403/image-b1878a8b.png)
      The data mapper table is created successfully.
      ![How to Create Data Mapper Table for ADP... - screenshot 4](/images/intercom/13718403/image-30d32cb4.png)
