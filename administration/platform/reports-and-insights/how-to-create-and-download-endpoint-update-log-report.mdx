## Introduction

An Endpoint Update Log provides details of all the updates made with the endpoints that are associated with the application, including details regarding last updated, Auto-update details etc.

## Pre-Requisite

You must have a Tenant Admin account.

## Steps to create & download Endpoint Update Log

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Ad-Hoc** on the left menu panel.
   ![How to create and download Endpoint... - screenshot 1](/images/intercom/12807264/image-88b73ed1.png)
   The **Ad-Hoc Reports** page is displayed.
   ![How to create and download Endpoint... - screenshot 2](/images/intercom/12807264/image-79ac7a95.png)
3. Use one of the following methods to download the report:
   1. On the top right, click **Create Report** > **Endpoint Update Log**
      ![How to create and download Endpoint... - screenshot 3](/images/intercom/12807264/image-7ebf7b54.png)
   2. Select Endpoint Update Log from the left menu panel then click **Create & Download Report.**
      ![How to create and download Endpoint... - screenshot 4](/images/intercom/12807264/image-70d070ac.png)

The **Endpoint Update Log** is saved to the local device and listed on the **Ad-Hoc Reports** page under the Endpoint Update Log tab.

![How to create and download Endpoint... - screenshot 5](/images/intercom/12807264/image-27fba71c.png)

<Note>
  **Note:**

  - Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
  - The downloaded file format for reports is XLSX.
</Note>
