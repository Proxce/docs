## Introduction

The **Endpoint Report** under **Insights > Reports** provides admin with a detailed view of Windows Login application endpoints in the organization.

## Prerequisite

- You must have Tenant Admin account.

## Steps to access Endpoint Report

1. Log in to the Tenant Admin Portal.
2. From the left navigation menu, click **Insights** Icon.
3. Select **Reports** > **Endpoints.**
   ![Insights Dashboard: Endpoints Report - screenshot 1](/images/intercom/13256453/image-de1eb095.png)
   The **Endpoints Report** page is displayed.

#### Filter Endpoints

4. ![Insights Dashboard: Endpoints Report - screenshot 2](/images/intercom/13256453/image-2c576b35.png)
   Use the **Add Filter** option to narrow down and view only the specific endpoints you want. This feature helps you quickly locate relevant endpoints from the list.
   1. Click **Add Filter**.
   2. Select the required filter from the dropdown.
   3. Enter the filter value to refine the endpoint results.

#### Download Endpoint Report

5. ![Insights Dashboard: Endpoints Report - screenshot 3](/images/intercom/13256453/image-b7d52a76.png)
   1. Select the **Endpoint Name** checkbox for the required endpoint(s).
   2. Click **Download**.
      ![Insights Dashboard: Endpoints Report - screenshot 4](/images/intercom/13256453/image-a707625a.png)

The **Download Custom Report** pop-up is displayed.

1. Enter the **Report Name** (required).
2. From the **Add Table Columns** dropdown, select the columns you want to include in the report.
3. Click **Download**.
   The endpoint report is downloaded successfully.
