The Oloid Tenant Admin Portal offers two key logging features to help administrators monitor system activity and user access. Each log provides visibility for auditing, troubleshooting, and compliance.

## 1. Activity Log

### Purpose

The **Activity Log** provides a detailed record of all administrative activities performed within the Oloid Portal. This includes changes made to user settings, configurations, and portal operations..

### What it covers

- Tracks user actions such as logins, profile updates, and configuration changes.
- Captures timestamps and user ( admin/supervisor) information associated with each activity.
- Enables search and filtering by date or keyword for quick access to specific events.

### How to view it

1. Log in to the Tenant Admin Portal/Supervisor Portal
2. Go to **Settings > Activity Log**
3. Use filters to view or search specific logs

## 2. User Transaction Log

### Purpose

The **User Transaction Log** captures entry and access-related transactions made by users across devices and entry points managed via Oloid systems..

### What it covers

- Displays all user access attempts, including successful and failed entries.
- Shows details like user name, access type (Face, QR, Badge etc.), time, location, and device.
- Supports exporting transaction data in Excel format for audits and reports.

### How to view/download

1. Log in to the Tenant Admin Portal
2. Click **Transactions** from the left menu
3. Apply filters by date, user, or type
4. Click **Export to Excel** to download the report

👉 [Full guide: How to view and download user transactions](https://oloid.help/en/articles/8223521-how-to-view-and-download-user-transaction-in-tenant-admin-portal)
