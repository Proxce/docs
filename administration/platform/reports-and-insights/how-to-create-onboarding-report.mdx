## Introduction

Onboarding Report contains the records of all the users onboarded to the Oloid Platform.

## Pre-Requisite

You must have a Tenant Admin account.

![How to create onboarding report - screenshot 1](/images/intercom/8450096/How-to-create-onboarding-report-9f81e00c.gif)

## Steps to create Onboarding Report

1. Log in to the **Oloid Portal**.
2. On the homepage, click **Reports > Scheduled** on the left menu panel.
   ![Image](/images/intercom/8450096/0101d443-0350-4cf2-abd5-f976fcbf4bc4-6fec02c1.png)
   The **Scheduled Reports** page is displayed.
3. On the top right, click **Create Report**.
   ![Image](/images/intercom/8450096/065fb0a0-c286-47ca-9c97-48526d1bc9d6-0a1cf19e.png)
   The **Create Report** pop-up box is displayed.
   ![How to create onboarding report - screenshot 2](/images/intercom/8450096/image-2c02edb6.png)
4. On the pop-up box, do the following:
   1. Enter **Report Name**.
   2. Select **Onboarding** report type.
   3. Click **Create**.
      The Onboarding report type is created and listed on the **Scheduled Reports** page.
      ![Image](/images/intercom/8450096/b8359810-f771-4dce-afab-350f2092b899-44c60343.png)

The onboarding report can be configured to schedule the report generation frequency and send it to the customers through email . For details see, **[How to configure onboarding report](https://oloid.help/en/articles/8455465-how-to-configure-onboarding-report).**

<Note>
  **Note:**

  - Ensure you have sufficient permissions as a **Tenant Admin** before attempting to create the report.
  - The downloaded file format for reports is XLSX.
</Note>
