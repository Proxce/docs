## Introduction

This document provides instructions to create a scheduled Transaction Report in the Tenant Admin Portal.

## Prerequisite

You must have admin access to the Tenant Admin Portal.

![How to Create a Scheduled Transaction... - screenshot 1](/images/intercom/8446424/How-to-create-a-scheduled-Transaction-Report-1337a33e.gif)

## Steps to Create Transaction Report

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, click **Reports > Scheduled** on the left menu panel.
   ![Image](/images/intercom/8446424/bfe829f7-5702-4694-b264-746551a07c97-9385d224.png)
   The **Scheduled Reports** page is displayed.
3. On the top right, click **Create Report**.
   ![Image](/images/intercom/8446424/4c8e0356-ea87-481f-8ff5-68bb0f253eb5-0483ea5d.png)
   The **Create Report** pop-up box is displayed.
4. Do the following:
   1. Enter **Report Name**.
   2. Select **Transaction** report type.
   3. Click **Create**.
      ![How to Create a Scheduled Transaction... - screenshot 2](/images/intercom/8446424/b41b3f60-d0b2-43cd-8758-073cc7e6479f-537cc7c9.png)
      The Transaction report type is created and listed on the **Scheduled Reports** page.
      ![How to Create a Scheduled Transaction... - screenshot 3](/images/intercom/8446424/image-9c9003c9.png)
      The Transaction report can be configured to schedule the report generation frequency and send it to the customers through email. For details see, [How to configure a scheduled transaction report](https://oloid.help/en/articles/8455213-how-to-configure-a-scheduled-transaction-report).
