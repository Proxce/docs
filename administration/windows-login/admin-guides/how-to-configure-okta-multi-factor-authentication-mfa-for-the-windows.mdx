OKTA provides the authentication and MFA capabilities that back the Oloid Windows Login application. Configuring OKTA lets an administrator create users, link them to an Oloid tenant, and enforce MFA at Windows sign-in.

This article covers three tasks across two roles:

| Task | Performed by | Where |
| --- | --- | --- |
| Create the user | Administrator | OKTA Admin Console |
| Link the OKTA ID | Administrator | Oloid Tenant Admin Portal |
| Enroll in OKTA Verify | End user | OKTA end-user dashboard + mobile device |

## Prerequisites

<Check>
  Administrator access to the **OKTA Administrator Console**.
</Check>

<Check>
  Administrator access to the **Oloid Tenant Admin Portal**.
</Check>

<Check>
  The OKTA Verify app installed on the end user's iOS or Android device.
</Check>

## Add a user in OKTA

<Steps>
  <Step title="Sign in to the OKTA Admin Console">
    The OKTA dashboard is displayed.

    ![OKTA Admin Console dashboard after sign-in](/images/intercom/13157388/image-a0dcb327.png)
  </Step>
  <Step title="Go to Directory > People > Add Person">
    The **Add Person** dialog is displayed.

    ![Add Person option under Directory, People in the OKTA Admin Console](/images/intercom/13157388/image-d77c97cc.png)
  </Step>
  <Step title="Complete the Add Person form">
    Enter the following details:

    | Field | Value |
    | --- | --- |
    | User Type | Select the applicable user type |
    | First name | The user's first name |
    | Last name | The user's last name |
    | Username | The user's OKTA username |
    | Email ID | The user's email address |
    | Groups | Optional |
    | Password | Select a password option |

    Select **Send user activation email now**.
  </Step>
  <Step title="Click Save">
    The user is created and the **People** list is displayed.

    ![Completed Add Person form with the Save button](/images/intercom/13157388/image-7ba7e1d5.png)
  </Step>
  <Step title="Open the new user record">
    Click the user's name. The user detail page is displayed.

    ![OKTA user detail page for the newly created user](/images/intercom/13157388/image-bd908653.png)
  </Step>
  <Step title="Copy the OKTA user ID from the address bar">
    The user ID is the segment that follows `/users/profile/` in the URL.

    ![Browser address bar showing the OKTA user ID in the profile URL](/images/intercom/13157388/image-5432773e.png)

    <Info>
      For example, in `https://your-domain-admin.okta.com/admin/user/profile/00u1abcdEFGHijkLM5d7` the user ID is `00u1abcdEFGHijkLM5d7`.
    </Info>
  </Step>
</Steps>

## Link the OKTA ID in the Tenant Admin Portal

<Steps>
  <Step title="Open the user in the Tenant Admin Portal">
    Go to **Directory > Users**, select the user, and expand the **Other Identifier** section.
  </Step>
  <Step title="Enter the OKTA ID">
    Paste the ID you copied into the **OKTA ID** field and save.

    ![OKTA ID field in the Other Identifier section of the Tenant Admin Portal](/images/intercom/13157388/cfcc87ae-e537-499a-b85c-1c2057d8ea20-f8963b7e.png)
  </Step>
</Steps>

## Activate the account and enroll in OKTA Verify

<Note>
  The remaining steps are performed by the end user on their own device.
</Note>

<Steps>
  <Step title="Activate the OKTA account">
    Open the OKTA activation email and click **Activate Okta Account**. The **Change password** screen is displayed.

    ![OKTA activation email with the Activate Okta Account button](/images/intercom/13157388/b0ac8bff-5ef3-4135-9032-9a389baafb71-23e8740c.png)
  </Step>
  <Step title="Set a new password">
    Enter the old password, then enter the new password in both the **New password** and **Repeat password** fields, and click **Change Password**.

    <Warning>
      The values in **New password** and **Repeat password** must match exactly.
    </Warning>

    ![OKTA Change password screen with old, new, and repeat password fields](/images/intercom/13157388/image-d6aadbe4.png)

    You are redirected to the OKTA user dashboard.
  </Step>
  <Step title="Open multifactor settings">
    Go to **User Profile > Settings**, then click **Set up** under multifactor authentication.

    ![Settings option in the OKTA user profile menu](/images/intercom/13157388/image-2294089f.png)

    ![Set up button on the OKTA multifactor authentication settings page](/images/intercom/13157388/image-757f1ec0.png)
  </Step>
  <Step title="Start OKTA Verify setup">
    Click **Setup**. The **Setup OKTA Verify** screen is displayed.

    ![Setup OKTA Verify option on the multifactor enrollment screen](/images/intercom/13157388/image-85fb928b.png)
  </Step>
  <Step title="Select the device type">
    Select **iPhone** or **Android**. The QR code screen is displayed.

    ![Device type selection showing iPhone and Android options](/images/intercom/13157388/image-95e8b738.png)
  </Step>
  <Step title="Scan the QR code">
    Open the OKTA Verify app on the device and scan the QR code.

    OKTA Verify is now enrolled, and the user can complete MFA at Windows sign-in.
  </Step>
</Steps>
