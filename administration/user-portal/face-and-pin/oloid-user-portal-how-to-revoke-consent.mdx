## Introduction

This document provides step-by-step instructions for revoking consent for face credentials in the Oloid User Portal. When consent is revoked, all previously enrolled face credentials are deleted, and users must provide consent again before adding a new face credential.

## Prerequisites

- You have access to the Oloid User Portal.
- Your face credential is already onboarded and consent is previously submitted. For more, refer to [How to Add a Face Using Invite Link in Oloid User Portal](https://oloid.help/en/articles/8472935-how-to-add-a-face-using-invite-link-in-oloid-user-portal)

## Steps to Revoke Consent

1. Log in to Oloid User Portal.
2. On the Credentials page of the portal, click on the **Faces**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to Revoke Consent - screenshot 1](/images/intercom/14685322/image-0fca07df.png)
   The **Face credential** page is displayed.
3. Click **Revoke Consent.**
   ![How to Revoke Consent - screenshot 2](/images/intercom/14685322/image-712ee344.png)
   The **Revoke Consent** Pop up is displayed.
4. Click **Yes, Revoke Consent** to revoke your consent.

![How to Revoke Consent - screenshot 3](/images/intercom/14685322/image-e134b00a.png)

The Consent is revoked successfully, and all previously enrolled face credentials are deleted.

<Note>
  **Note:** If consent is revoked, the **Add Face** option is disabled and cannot be selected. To add a face credential, consent must be provided.
</Note>

![How to Revoke Consent - screenshot 4](/images/intercom/14685322/image-62cf9cce.png)
