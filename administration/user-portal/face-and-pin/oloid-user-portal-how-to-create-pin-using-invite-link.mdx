## Introduction

This document provides step-by-step instructions to create a PIN in the Oloid User Portal using an invite link.

<Note>
  **Note:** The admin sends an email with an invite link. The link directs the user to the Oloid User Portal where the PIN can be create.
</Note>

## Prerequisite

- A valid invite link to Set PIN must be available in the user’s mailbox.

## Steps to set PIN using invite link

1. Click on the invite set PIN link.
   ![How to create PIN using invite link - screenshot 1](/images/intercom/9459704/image-bcba5427.png)
   The Oloid User Portal opens with PIN Credential page.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

2. Click **Add PIN**.
   ![How to create PIN using invite link - screenshot 2](/images/intercom/9459704/image-4ca6efe2.png)
   The screen to set PIN is displayed.
3. Enter new PIN.
4. Re-enter new PIN.
5. Click **Create**.
   The PIN is created successfully.
   ![How to create PIN using invite link - screenshot 3](/images/intercom/9459704/image-1486f3ec.png)

The PIN is created and assigned to you. The success message is displayed.

![How to create PIN using invite link - screenshot 4](/images/intercom/9459704/image-01a72a1d.png)
