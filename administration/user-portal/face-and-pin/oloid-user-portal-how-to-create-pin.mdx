## Introduction

This document provides step-by-step instructions for creating a PIN in the Oloid User Portal. Once created, the PIN is assigned to your account and can be used as a credential for authentication.

## Prerequisites

- You have the **login URL** provided to access the User portal.
- Your **Employee ID or Email ID** must be registered in the system.

## Steps to create PIN

1. Log in to **Oloid User Portal**.
2. On the credential home page, select **PIN**.
   ![How to Create PIN - screenshot 1](/images/intercom/9423743/image-f536b805.png)
   The **PIN Credential** page is displayed.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

3. Click **Add PIN**.
   ![How to Create PIN - screenshot 2](/images/intercom/9423743/image-4ca6efe2.png)
   The screen to set PIN is displayed.
4. Do the following:
   1. **Enter new PIN**.
   2. **Re-enter new PIN**.
   3. Click **Add PIN**.
      ![How to Create PIN - screenshot 3](/images/intercom/9423743/image-1486f3ec.png)
      The PIN is created and assigned to you. The success message is displayed.
      ![How to Create PIN - screenshot 4](/images/intercom/9423743/image-9e1c3786.png)
