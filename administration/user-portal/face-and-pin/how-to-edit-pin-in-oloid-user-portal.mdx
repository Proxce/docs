#### Introduction

This document provides step-by-step instructions to edit PIN in the Oloid User Portal.

#### Steps to edit PIN

1. Log in to the **Oloid User Portal**.
2. On the credential home page, select **PIN**.
   ![How to edit PIN in Oloid User Portal - screenshot 1](/images/intercom/9448187/b50573ec-08ba-4b4f-9659-0c2061af870e-d14c7e28.png)
   The **PIN Credential** page is displayed.
3. Select **Edit PIN**.
   ![How to edit PIN in Oloid User Portal - screenshot 2](/images/intercom/9448187/0bfd1aed-f6fe-4223-b98d-4005948c33b5-4703c9fc.png)
   The screen to reset PIN is displayed.
   ![How to edit PIN in Oloid User Portal - screenshot 3](/images/intercom/9448187/image-1d670309.png)
4. Do the following:
   1. **Enter new PIN**.
   2. **Re-enter new PIN**.
   3. Click **Update**.

The PIN is updated successfully.
