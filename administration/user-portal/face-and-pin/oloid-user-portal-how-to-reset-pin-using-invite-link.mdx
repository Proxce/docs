## Introduction

This document provides step-by-step instructions to reset PIN in the Oloid User Portal using an invite link.

<Note>
  **Note:** The admin sends an email with an invite link to reset the PIN. That link directs the user to the Oloid User Portal where user can reset the PIN.
</Note>

## Prerequisite

- A valid invite link to reset PIN must be available in the user’s mailbox.

## Steps to reset PIN using invite link

1. Click on the invite link for reset PIN.
   ![How to reset PIN using invite link - screenshot 1](/images/intercom/9489199/image-9b1dff90.png)
   The Oloid User Portal opens with PIN Credential screen.
2. Select **Edit PIN**.

   <Note>
     **Note:** You can select preferred display language from the **Language Dropdown Selector**. For more information, refer [Additional information section](#additional-information).
   </Note>

   ![How to reset PIN using invite link - screenshot 2](/images/intercom/9489199/image-fc512052.png)
   The Reset PIN page is displayed.
3. Do the following:
   1. Enter new PIN.
   2. Re-enter new PIN.
   3. Click **Update**.
      ![How to reset PIN using invite link - screenshot 3](/images/intercom/9489199/image-02e506a4.png)
      The PIN is updated successfully and a success message is displayed.

![How to reset PIN using invite link - screenshot 4](/images/intercom/9489199/image-daee45da.png)
