To enable **Google SSO Login** on Oloid User Portal, you need to raise a ticket with [Oloid Support.](mailto:Support@oloid.ai)

**Pre-requisite**

- You should be a user in the Tenant Admin Portal.
- You must enable SSO options in Tenant Admin Portal. For more details, refer to [How to configure Oloid User Portal in Tenant Admin Portal](https://oloid.help/en/articles/9969120-how-to-configure-oloid-user-portal-in-tenant-admin-portal) >[Configuring SSO options](https://oloid.help/en/articles/9969120-how-to-configure-oloid-user-portal-in-tenant-admin-portal#:~:text=Select%20SSO%20options%20to%20log%20in%20to%20the%20Oloid%20User%20Portal)

Steps to log in to Oloid User Portal using **Google SSO Login** option.

1. Launch your browser.
2. Enter the URL provided for you in the browser’s address bar. Then, press **Enter** on your keyboard.
   The **Oloid User Portal** page is displayed.
3. Click **Log in with SSO**.
   ![How to login Oloid User Portal with... - screenshot 1](/images/intercom/9514956/3d0371c3-488f-4c53-8fcb-e7148407ea6f-7f4ba4d0.png)
   The configured Login options are displayed.
4. Click **Continue with Google**.
   ![How to login Oloid User Portal with... - screenshot 2](/images/intercom/9514956/image-24cc9545.png)
   The **Sign in** screen is displayed.
   ![How to login Oloid User Portal with... - screenshot 3](/images/intercom/9514956/image-b65070bd.png)
5. On the screen, do the following.
   1. Enter **Email or phone** > click **Next**.
      The **Welcome** screen is displayed.
   2. Enter your **Password** > click **Next**.
      ![How to login Oloid User Portal with... - screenshot 4](/images/intercom/9514956/image-bbf41175.png)

You are logged in to the Oloid User Portal using Google SSO successfully.
