Steps to share feedback:

1. Login to the **Oloid User Portal**.
2. On the homepage, click menu panel ![How to share feedback using Oloid User... - screenshot 1](/images/intercom/9874142/image-bf4a32a2.png) icon on the top right corner.
3. Select **Profile**.
   ![Image](/images/intercom/9874142/54bc71a2-e074-4267-a7d4-7210256d8835-ae5578d0.png)
   The **Your Profile** page is displayed.
4. Click **Share app feedback**.
   ![Image](/images/intercom/9874142/b4447343-d8a5-4212-b033-bd032d32ed84-76866f5d.png)
   The **Share app feedback** page is displayed.
5. Do the following:
   1. Enter feedback in **Type here** field.
   2. Click **Submit**.
      ![How to share feedback using Oloid User... - screenshot 2](/images/intercom/9874142/image-c8dcdb73.png)
      The feedback is sent successfully.
      ![How to share feedback using Oloid User... - screenshot 3](/images/intercom/9874142/image-fe0da49d.png)
