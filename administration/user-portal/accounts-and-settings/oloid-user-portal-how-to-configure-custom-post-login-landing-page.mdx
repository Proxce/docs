## Introduction

The **Custom Post-Login Page** setting allows Tenant Admins to define the landing page users see after logging into the User Portal. By configuring this option in the Tenant Admin Portal, admins can control the default post-login experience and direct users to a specific page based on organizational requirements.

## Prerequisite

- You must have access to Tenant Admin account.
- Custom Post Login Landing page dropdown must be enabled by Oloid support.

## **Steps to configure** Custom Post-Login Landing page

1. Login to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **Profile icon** on the bottom left corner of the menu panel.
   ![How to Configure Custom Post-Login... - screenshot 1](/images/intercom/14321285/image-6aab28d0.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![How to Configure Custom Post-Login... - screenshot 2](/images/intercom/14321285/image-c6f28d5c.png)
   The **Tenant Settings** page is displayed.
4. Click **App Settings** tab > select **User Portal**.
   ![How to Configure Custom Post-Login... - screenshot 3](/images/intercom/14321285/image-a926ba38.png)
5. On the App settings Page section in the left menu panel select **User Portal** > click **Post-Login Page.**
   ![How to Configure Custom Post-Login... - screenshot 4](/images/intercom/14321285/image-5a4a4925.png)
6. Do the following:
   1. Turn on **Custom Post-Login Landing Page** toggle.
   2. Select landing page from **Dropdown**.

      <Note>
        **Note:** Landing page for the user-portal displays all the available pages enabled by Oloid support. If you need to enable pages not listed here, please contact [Oloid support](mailto:support@oloid.ai).
      </Note>

      ![How to Configure Custom Post-Login... - screenshot 5](/images/intercom/14321285/image-a5900486.png)
   3. Click **Deploy Changes**.
      ![How to Configure Custom Post-Login... - screenshot 6](/images/intercom/14321285/image-ef4d68df.png)
      Confirmation Pop-up is displayed.
   4. Click **Update**.

![How to Configure Custom Post-Login... - screenshot 7](/images/intercom/14321285/image-f1e1e90d.png)

The User Portal post-login landing page is configured.

![How to Configure Custom Post-Login... - screenshot 8](/images/intercom/14321285/image-642395f7.png)
