## Introduction

The User Portal allows users to create and register an Oloid passkey for authentication.

## Prerequisite

Oloid Passkey must be enabled in the App settings for User Portal from Tenant Admin portal.

## Steps to Generate Oloid Passkey

1. Log in to the **User Portal**.
2. On the credentials page of the portal, click **Oloid Passkey.**
   ![How to Generate Oloid Passkey in the... - screenshot 1](/images/intercom/13884380/image-ec76a362.png)
   The **Oloid Passkey** page is displayed.
3. Click **Generate**.
   ![How to Generate Oloid Passkey in the... - screenshot 2](/images/intercom/13884380/image-3cc3ffc5.png)
4. The Passkey registration screen is displayed.
   ![How to Generate Oloid Passkey in the... - screenshot 3](/images/intercom/13884380/image-be00c068.png)
   The Passkey is successfully generated.
   ![How to Generate Oloid Passkey in the... - screenshot 4](/images/intercom/13884380/image-d3760af0.png)
