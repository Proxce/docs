## Introduction

Oloid User Portal allows the user to create and assign passwords to themselves.

To create individual passwords:

1. Log in to the **Oloid User Portal**.
2. On the credential home page, select **Windows Passwords**.
   ![How to create individual password using... - screenshot 1](/images/intercom/9468372/image-fc02f527.png)
   The **Windows Passwords** page is displayed.
3. Select **Add** ![How to create individual password using... - screenshot 2](/images/intercom/9468372/image-1148b57e.png) icon to create an individual password.
   ![How to create individual password using... - screenshot 3](/images/intercom/9468372/aee98e6b-8fc9-4042-bd97-a71fe54a6d88-a01d0ea8.png)
   The **Windows Passwords** page is displayed to set Password.
4. Do the following:
   1. [Create password for domain user](#create-password-for-domain-user)
   2. [Create password for local user](#create-password-for-local-user)

### Create password for Domain User

1. Select user type as **Domain User** from **Windows User Type** dropdown.
   ![How to create individual password using... - screenshot 4](/images/intercom/9468372/60c396c8-9442-4007-a09a-b6ae4eb97143-c14e6db5.png)
2. Enter **Display Name**.
3. Enter **Domain Name**.
4. Select **Preferred Machine(s)**. (Optional)

   <Note>
     **Note:** You can select multiple machine name
   </Note>

5. Enter **User Name** of your Windows account.
6. Enter **Password** of your Windows account (Optional).
7. Click **Create**.
   The password credential is created and displayed for the domain user under the **Individual Passwords** section.
   ![How to create individual password using... - screenshot 5](/images/intercom/9468372/3d0a43be-65de-41a2-905c-5b41ea872a78-e333a078.png)

### Create password for Local User

1. Select user type as **Local User** from **Windows User Type** dropdown.
   ![How to create individual password using... - screenshot 6](/images/intercom/9468372/75c85b8e-cded-4f81-86dd-c6bd84d6048e-35b709d3.png)
2. Enter **Display Name**.
3. Select **Machine Name**.

   <Note>
     **Note:** You can select only single machine name.
   </Note>

4. Enter **User Name**.
5. Enter **Password** (Optional).
6. Click **Create**.
   The password credential is created and displayed for the local user under the **Individual Passwords** section.
   ![How to create individual password using... - screenshot 7](/images/intercom/9468372/e7fd3fe5-311f-4f6a-aa8e-36a8cd6202b3-05c07360.png)
