## Introduction

This document describes the steps to create a **Vault Password** in the Oloid User Portal. The process allows authorized users to securely store and manage credentials for applications or services.

## Prerequisites

- You are a registered user in the **Tenant Admin Portal** with the Admin role.
- User must have required information for the web application, including **URL/App ID**, **User Name**, and **Password**.
- The Vault Password feature must be enabled in the User Portal. To enable this feature, refer to the **Configure Setting Section** of [How to Configure Oloid User Portal in Tenant Admin Portal](https://oloid.help/en/articles/9969120-how-to-configure-oloid-user-portal-in-tenant-admin-portal#h_f0b7436728).

## Steps to Create Vault Password

1. Log in to the **Oloid User Portal**.
2. On the homepage, click **Vault Passwords**.
   ![How to Create Vault Password using... - screenshot 1](/images/intercom/9880892/image-e415cffd.png)
   Vault Passwords page is displayed.
3. Click **+ ADD** from the top right corner.

   <Note>
     **Note:** You cannot add Shared Credentials.
   </Note>

   ![How to Create Vault Password using... - screenshot 2](/images/intercom/9880892/image-b9cea987.png)
   The page to create **Vault Passwords** is displayed.
4. Do the following:
   1. Select **Web** from the **Vault Password Type** drop-down list.
   2. Enter **Display Name**. (Optional)
   3. Enter **URL/App ID**.
   4. Enter **User Name**.
   5. Enter **Password**.
   6. Click **Create**.
      ![How to Create Vault Password using... - screenshot 3](/images/intercom/9880892/image-3fbc22f5.png)

The vault password is successfully created.

![How to Create Vault Password using... - screenshot 4](/images/intercom/9880892/image-16cfd59b.png)

The vault password is listed in the Individual Passwords section.

![How to Create Vault Password using... - screenshot 5](/images/intercom/9880892/image-525e8ff7.png)
