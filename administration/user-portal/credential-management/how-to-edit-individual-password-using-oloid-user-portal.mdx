To edit individual passwords:

1. Log in to the **Oloid User Portal**.
2. On the Credential home page, select **Windows Passwords**.
   ![How to edit individual password using... - screenshot 1](/images/intercom/9468926/image-4ced2d74.png)
   The **Windows Passwords** page is displayed.
3. Select password (Domain User/Local User) and click **edit** ![How to edit individual password using... - screenshot 2](/images/intercom/9468926/image-956c268a.png) icon.
   ![How to edit individual password using... - screenshot 3](/images/intercom/9468926/f0ac8ad0-3c26-4bdd-8d23-0fbd666be8a2-7586026f.png)
   The page is displayed to edit password.
   ![How to edit individual password using... - screenshot 4](/images/intercom/9468926/image-e816040a.png)
4. Do the following:
   1. [View and Edit Domain User](#view-and-edit-domain-user)
   2. [View and Edit Local User](#view-and-edit-local-user)

## View and Edit Domain User

![How to edit individual password using... - screenshot 5](/images/intercom/9468926/image-8607b19c.png)

1. Edit **Display Name**.
2. Edit **Domain Name**.
3. Select **Preferred Machine** from the **Preferred Machine(s)** list. (Optional)
4. Edit **User Name**.
5. Enter **Password** (Optional).
6. Click **Save**.
   The Windows Password for domain user is updated successfully.
   ![How to edit individual password using... - screenshot 6](/images/intercom/9468926/image-7dd4b5e9.png)

## View and Edit Local User

![How to edit individual password using... - screenshot 7](/images/intercom/9468926/image-f51e67e6.png)

1. Edit **Display Name**.
2. Select **Machine** from the **Machine Name** dropdown list.
3. Edit **User Name**.
4. Enter **Password**. (Optional)
5. Click **Save**.

The Windows Password for local user is updated successfully.

![How to edit individual password using... - screenshot 8](/images/intercom/9468926/image-6136defb.png)
