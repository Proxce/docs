## Introduction

This document provides step-by-step instructions for replacing an existing NFC credential through the Oloid User Portal. Users can replace an NFC credential when the existing NFC card is lost or not working.

## Prerequisites

- You have the **login URL** provided to access the User portal.
- Your **Employee ID or Email ID** must be registered in the system.
- Ensure You have a Valid NFC card and Reader.
- NFC must already be assigned to the user, for the NFC Replacement.

## To Replace and Assign NFC

1. Log in to the **Oloid User Portal**.
2. On the credential page of the Oloid User Portal, select **NFC**.

   <Note>
     **Note:** If configured in the Tenant Admin Portal, You can select preferred display language from the **Language Dropdown Selector**.
   </Note>

   ![How to replace and assign NFC - screenshot 1](/images/intercom/9459621/image-57e2fe9f.png)
   The **NFC Credential** page is displayed.
3. Select **Replace NFC**.
   ![How to replace and assign NFC - screenshot 2](/images/intercom/9459621/image-df788e50.png)
4. On the confirmation pop-up box do the following:
   1. Select **Report lost NFC Tag**. (Optional)
   2. Select **NFC Tag not working**. (Optional)
   3. Select **Replace NFC**.
      ![How to replace and assign NFC - screenshot 3](/images/intercom/9459621/image-bb3438c7.png)
      The confirmation pop-up to ensure that the NFC Tag reader is connected to your device is displayed.
5. Click **Okay**.
   ![How to replace and assign NFC - screenshot 4](/images/intercom/9459621/image-6a1f56ed.png)
   The **Scan your NFC Tag** page is displayed.
6. Do any of the following:
   1. Enter the NFC number.
   2. Click on the **Scan or Type Data** textbox area. Tap the **NFC card** on the **Card Reader** to scan it.

      <Note>
        **Note:** If you do not click on the Scan or Type Data textbox area, you will not see the data in the text field.
      </Note>

   3. Click **Submit**.
      ![How to replace and assign NFC - screenshot 5](/images/intercom/9459621/image-56b88408.png)
      You successfully assigned a new NFC credential.

![How to replace and assign NFC - screenshot 6](/images/intercom/9459621/image-61481618.png)
