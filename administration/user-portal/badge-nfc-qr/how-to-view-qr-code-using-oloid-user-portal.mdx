Steps to view QR code:

1. Log in to the **Oloid User Portal**.
2. On the homepage, click **QR Code**.
   ![Image](/images/intercom/9901402/b1e6a936-9b74-41a1-8b81-f629a7677dad-6a0906ee.png)
   The **Assign QR Code** page is displayed and you can view the QR Code on the page.
   ![How to view QR Code using Oloid User... - screenshot 1](/images/intercom/9901402/33117bec-6da5-49cc-926f-d02bc8935c49-e39d9387.png)

   <Note>
     **Note:** You can also download the QR Code.
