## Introduction

This document provides step-by-step instructions for enrolling an **NFC credential** through the Oloid User Portal. Once enrolled, the NFC credential can be used for NFC-based authentication.

## Prerequisites

- You have the **login URL** provided to access the User portal.
- Your **Employee ID or Email ID** must be registered in the system.
- Ensure You have a Valid NFC card and Reader.

## To Enroll NFC

1. Log in to the **Oloid User Portal**.
   The **Your Credentials** page is displayed.
2. Click **NFC**.

   <Note>
     **Note:** If configured in the Tenant Admin Portal, You can select preferred display language from the **Language Dropdown Selector**.
   </Note>

   ![How to enroll for NFC Login - screenshot 1](/images/intercom/9459595/image-f1da7d65.png)
   The **NFC Credential** page is displayed.
3. Click **Enroll for NFC Login**.
   ![How to enroll for NFC Login - screenshot 2](/images/intercom/9459595/image-ee4510f9.png)
   The **Scan your NFC Tag** page is displayed.
   The confirmation pop-up to ensure that the NFC Tag reader is connected to your device is displayed.
4. Click **Okay**.
   ![How to enroll for NFC Login - screenshot 3](/images/intercom/9459595/image-07dcecf2.png)
5. Do any of the following:
   1. Enter the NFC number.
   2. **Click on the NFC Tag ID** textbox area. Tap the **NFC card** on the **Card Reader** to scan it.

      <Note>
        **Note:** If you do not click on the Scan or Type Data textbox area, you will not see the data in the text field.
      </Note>

   3. Click **Submit**.
      ![How to enroll for NFC Login - screenshot 4](/images/intercom/9459595/image-3832c123.png)
      You are successfully assigned an NFC credential.
      ![How to enroll for NFC Login - screenshot 5](/images/intercom/9459595/image-c9316a80.png)
