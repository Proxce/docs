Steps to download the files:

1. Log in to the **Supervisor Portal**.
2. On the homepage of the portal, click **User profile icon** on the bottom left corner of the menu panel.
   ![How to download file using file sharing... - screenshot 1](/images/intercom/9690938/image-c847243b.png)
   The user profile menu is displayed.
   ![How to download file using file sharing... - screenshot 2](/images/intercom/9690938/image-5157047b.png)
3. Select **File Sharing**.
   ![How to download file using file sharing... - screenshot 3](/images/intercom/9690938/image-78b8e038.png)
   The **File Sharing** page is displayed.
   ![How to download file using file sharing... - screenshot 4](/images/intercom/9690938/image-07d29582.png)
4. Select the preferred file to download.
   ![Image](/images/intercom/9690938/15198fa9-c5fa-4e78-869e-744e537697ec-3ed30628.png)
   The file is downloaded.
