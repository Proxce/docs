Steps to add a Windows Login endpoint:

1. Log in to the **Supervisor Portal**.
2. On the homepage of the portal, click **Endpoints** on the left panel menu.
   ![How to create Windows Login endpoint in... - screenshot 1](/images/intercom/11494143/d2704221-5a53-46dc-9827-9956d34ff7f2-a91ef2ae.png)
   The **Endpoints** page is displayed.
3. Click **Add Endpoint** on the top right corner of the page.
   ![How to create Windows Login endpoint in... - screenshot 2](/images/intercom/11494143/765196a4-e294-405d-8cf7-481d521ae7e8-59b9f79d.png)
   The **Create Endpoint** pop-up box is displayed.
   ![How to create Windows Login endpoint in... - screenshot 3](/images/intercom/11494143/image-b35f85a6.png)
4. Select **Windows Login** and select **Continue**.
   The **Create Windows Login Endpoint** pop-up box is displayed.
   ![How to create Windows Login endpoint in... - screenshot 4](/images/intercom/11494143/image-0015dc01.png)
5. On the pop-up box, do the following:
   1. Enter **Endpoint Name**.
   2. Select **Application** from the application list**.**
   3. Select **Template** (optional).
   4. Click **Create**.
      The endpoint is created and listed on the **Endpoints** page.
      ![How to create Windows Login endpoint in... - screenshot 5](/images/intercom/11494143/image-553d9b92.png)
