Steps to assign Shared Credential:

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
   ![How to associate users with shared... - screenshot 1](/images/intercom/9684906/image-995c1139.png)
2. Click **Shared Credentials** > **Windows Passwords** on the left menu panel.
   ![Image](/images/intercom/9684906/1df080b1-7cde-4a2e-8b41-83416f7058d5-2a6a7986.png)
   The Windows Passwords page is displayed.
   ![How to associate users with shared... - screenshot 2](/images/intercom/9684906/image-e54a413a.png)
3. Select credential name to edit.
   ![Image](/images/intercom/9684906/f9258aee-f703-4a01-b14c-6d19ea1767de-59c31753.png)
   The credential details page is displayed.
   ![Image](/images/intercom/9684906/31a13acd-52c4-4113-9717-55833477e392-b79f49d2.png)
4. Select **User Assigned** tab **> + Assign Shared Password to Users**.
   ![Image](/images/intercom/9684906/0fc5f754-51eb-462e-aaa0-1e2ab4a71065-e8ee5a23.png)
   The **Assign Shared Password to Users** pop-up box is displayed.
   ![How to associate users with shared... - screenshot 3](/images/intercom/9684906/image-569b5227.png)
5. On the pop-up box, enter user name(s) in the **Users** dropdown list.
6. Select **Assign**.
   The shared password is successfully assigned and listed on the credential details page.
   ![How to associate users with shared... - screenshot 4](/images/intercom/9684906/image-b7da8255.png)
   ![Image](/images/intercom/9684906/e5ccbe47-49bd-48ee-867c-7f1df2b3a417-c0973eb0.png)
