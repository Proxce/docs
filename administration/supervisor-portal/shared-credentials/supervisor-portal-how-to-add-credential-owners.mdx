Steps to add Credential Owners:

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
   ![How to add credential owners - screenshot 1](/images/intercom/9684955/image-995c1139.png)
2. Click **Shared Credentials** > **Windows Passwords**.
   ![Image](/images/intercom/9684955/1df080b1-7cde-4a2e-8b41-83416f7058d5-2a6a7986.png)
   The Windows Passwords page is displayed.
3. Select credential name to edit.
   ![Image](/images/intercom/9684955/f9258aee-f703-4a01-b14c-6d19ea1767de-59c31753.png)
4. Select **Credential Owners** tab > **+ Add Credential Owners**.
   ![Image](/images/intercom/9684955/fefb9102-c06f-4266-af6e-b89bfa430939-327a4768.png)
   The **Add Credential Owners** pop-up box is displayed.
   ![How to add credential owners - screenshot 2](/images/intercom/9684955/image-e7830ab3.png)
5. On the pop-up box, enter user name(s) or primary ID(s) in the **Users** dropdown list.
6. Select **Assign**.
   The credential owners are successfully assigned.
   ![Image](/images/intercom/9684955/33269edb-e06d-45e6-9f7c-1b5f980a60e1-2fdf508a.png)
