Steps to assign Shared Credential:

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
   ![How to assign shared credential to... - screenshot 1](/images/intercom/9684697/image-995c1139.png)
2. Click **Shared Credentials > Windows Passwords** on the left menu panel.
   ![Image](/images/intercom/9684697/1df080b1-7cde-4a2e-8b41-83416f7058d5-2a6a7986.png)
   The **Windows Password** page is displayed.
   ![How to assign shared credential to... - screenshot 2](/images/intercom/9684697/image-c3bf98c3.png)
3. Select credential name(s) to assign users.
   ![How to assign shared credential to... - screenshot 3](/images/intercom/9684697/image-2d6a22c2.png)
4. Select **+ Assign Credentials to Users**.
   ![Image](/images/intercom/9684697/10602bfc-df9f-4f27-9ec0-b71c71a8065f-a97f92bb.png)
   The **Assign Credentials to Users** pop-up box is displayed.
   ![How to assign shared credential to... - screenshot 4](/images/intercom/9684697/image-1044c815.png)
5. On the pop-up box, select username(s) in the **Select Users** dropdown list.

Select **Assign**.

The shared password is successfully assigned among the selected users.

![How to assign shared credential to... - screenshot 5](/images/intercom/9684697/image-887d4a53.png)
