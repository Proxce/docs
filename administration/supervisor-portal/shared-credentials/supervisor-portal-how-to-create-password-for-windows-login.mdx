## Create Password for local windows machine

To create Password:

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
2. Click **username** to edit.
   ![How to create Password for Windows Login - screenshot 1](/images/intercom/9674358/image-a3c33ae5.png)
   The User details page is displayed.
   ![How to create Password for Windows Login - screenshot 2](/images/intercom/9674358/image-03b3778d.png)
3. Go to **Credentials** > **Windows Password** tab > **+ Create Password**.
   ![Image](/images/intercom/9674358/fed3188f-78a5-454d-8464-3815fe9262ed-13fbd941.png)
   The **Create Windows Password** pop-up box is displayed.
   ![How to create Password for Windows Login - screenshot 3](/images/intercom/9674358/image-7bb698ea.png)
4. Do the following:
   1. Enter **Display Name** that displays on the Windows Login page.
   2. Select **Windows Local User** type from **Credential Type** dropdown list.
   3. Click **Next.**
      ![How to create Password for Windows Login - screenshot 4](/images/intercom/9674358/image-a30d36b1.png)
   4. Enter **Machine Name**.

      <Note>
        **Note:** Enter your Windows device name.
      </Note>

   5. Enter **Username** of your Windows Login.

      <Note>
        **Note:** Windows account name.
      </Note>

   6. Enter **Password** of your Windows Login.
   7. Click **Save**.

![Image](/images/intercom/9674358/6a0e1ceb-44f5-4418-9416-128193bc2041-7922ae4e.png)

The password is created and listed in the **Password** tab.

## Create Password for domain

1. Log in to the **Supervisor Portal.**
   The **Users** page is displayed.
2. Click **username** to edit.
   ![How to create Password for Windows Login - screenshot 5](/images/intercom/9674358/image-a3c33ae5.png)
   The User details page is displayed.
   ![How to create Password for Windows Login - screenshot 6](/images/intercom/9674358/image-03b3778d.png)
3. Go to **Credentials** > **Passwords** tab > **Create Password**.
   ![Image](/images/intercom/9674358/fed3188f-78a5-454d-8464-3815fe9262ed-13fbd941.png)
   The **Create Windows Password** pop-up box is displayed.
   ![How to create Password for Windows Login - screenshot 7](/images/intercom/9674358/image-7bb698ea.png)
4. Do the following:
   1. Enter **Display Name** that displays on the Windows Login page.
   2. Select **Windows Domain User** type from **Credential Type** dropdown list.
   3. Click **Next.**
      ![How to create Password for Windows Login - screenshot 8](/images/intercom/9674358/image-ccdd1686.png)
   4. Enter **Domain Name**.
   5. Select **Preferred Machine** from the **Preferred Machine(s)** list.
   6. Enter **Username** of your Windows Login.

      <Note>
        **Note:** Windows account name.
      </Note>

   7. Enter **Password** of your Windows Login.
   8. Click **Save**.
      ![Image](/images/intercom/9674358/6ba6a2fa-6949-4868-8aa6-ebeb8d52c22d-c4ad3468.png)
      The password is created and listed in the **Password** tab.
