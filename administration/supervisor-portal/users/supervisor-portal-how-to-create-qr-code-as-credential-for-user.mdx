Steps to create QR code:

1. Log in to the **Supervisor Portal.**
   The **Users** page is displayed.
2. Click **username** to edit.
   ![How to create QR code as credential for... - screenshot 1](/images/intercom/9669597/image-97765975.png)
   The User Details page is displayed
   ![How to create QR code as credential for... - screenshot 2](/images/intercom/9669597/image-7b36130b.png)
3. Do one of the following:
   1. Go to **Credentials** tab > **QR Code** > select **+ Create QR Code**.
      ![Image](/images/intercom/9669597/569a25e7-0412-4061-865c-fa3fdbea145d-ae461dc1.png)
   2. Go to **Assign Credential** > **Create QR Code**.
      ![Image](/images/intercom/9669597/52010179-df24-4fb5-97eb-b93a38b245db-448eaeaa.png)
      The **Create QR Code** pop-up window is displayed.
      ![How to create QR code as credential for... - screenshot 3](/images/intercom/9669597/image-74c24a44.png)
4. On the pop-up box, do the following:
   1. Select **QR Code Validity** from the calendar.
   2. Enter recipient's **email ID** to share the QR code.
   3. Click **Assign**.
      The QR code is created and listed in the **QR Code** tab. The QR code is sent to the recipient's (user's) email id.
      ![Image](/images/intercom/9669597/754939d5-0484-4aa8-9878-bb5239df6e91-efa8f891.png)
