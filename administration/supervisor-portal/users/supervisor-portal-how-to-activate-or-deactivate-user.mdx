Steps to Activate or Deactivate User:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
2. Click username to edit.
   ![How to activate or deactivate user - screenshot 1](/images/intercom/9673602/image-30bf4673.png)
   The user details page is displayed.
   ![How to activate or deactivate user - screenshot 2](/images/intercom/9673602/image-7b36130b.png)
3. Do one of the following on **Action** dropdown:
   1. Select **Deactivate**.
      ![How to activate or deactivate user - screenshot 3](/images/intercom/9673602/image-2dd1b0db.png)

      <Note>
        **Note:**

        **Deactivate** button is visible for active users in the action dropdown.
      </Note>

      The **De-activate User** pop-up box is displayed.
      1. Click **Confirm De-activate**.
         ![How to activate or deactivate user - screenshot 4](/images/intercom/9673602/image-6ff9cee9.png)
         The user status is changed from active to inactive.
         ![How to activate or deactivate user - screenshot 5](/images/intercom/9673602/image-39067055.png)
   2. Select **Activate**.
      ![How to activate or deactivate user - screenshot 6](/images/intercom/9673602/image-a0dc55ce.png)
      The **Activate User** pop-up box is displayed.
      1. Click **Confirm Activate**.
         ![How to activate or deactivate user - screenshot 7](/images/intercom/9673602/image-081defa0.png)
         The user status is changed from inactive to active.
         ![How to activate or deactivate user - screenshot 8](/images/intercom/9673602/image-c7cb1992.png)
