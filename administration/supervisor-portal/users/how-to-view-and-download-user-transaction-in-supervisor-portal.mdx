**Introduction**

A user transaction is a record of a user's activity that captures important details such as the date and time of the action, the type of credential used (e.g., NFC, QR code, batch, pin), the name of the application accessed, and the endpoint involved. These transactions help track and analyse user interactions.

**Steps to view and download user transaction report:**

1. Log in to the **Supervisor Portal .**
2. On the home page of the portal, click **Transactions** on the left menu panel.
   ![How to View and Download User... - screenshot 1](/images/intercom/11401404/400176fb-25cc-49d7-8445-6547737269fe-2ed9211a.png)
   The **User Transactions** page is displayed.
3. Click **Export to excel icon**.
   ![How to View and Download User... - screenshot 2](/images/intercom/11401404/666f6a02-a6cd-4c0a-b735-b0b3da3bc2c2-da1f13b4.png)
   The **Export to Excel** pop-up box is displayed.
   ![How to View and Download User... - screenshot 3](/images/intercom/11401404/5885ecfb-efdd-4798-97a1-c63abf62ec8a-35f014ae.png)
4. (Optional) **Customize the report** by configuring the following options:
   1. **From Date & Time**: Select the start date and time.
   2. **To Date & Time**: Select the end date and time.
   3. **Time Zone**: Select a time zone.

**Use Application Time Zone**: Enable to apply the application's configured time zone.

<Note>
  **Note:** This option only works if a time zone is set in the application. If different time zones are selected for the application and export, the application's time zone takes priority when this option is enabled.
</Note>

```
To set time zone in the preferred application, go to home page > select the Application > Details tab > Time Zone.
```

5. **Transaction Status**: Select one or more statuses.
6. **Application Names**: Select the relevant application(s).
7. **Endpoint Names**: Select the desired endpoint(s).
8. **User’s Primary ID**: Enter the User's **Primary ID**.
9. **Mode**: Select the transaction mode.
10. **Face Match Status**: Filter by face match status.
5. Click **Download** to export the report.
   The **user transaction report is downloaded** to your device in Excel format.
