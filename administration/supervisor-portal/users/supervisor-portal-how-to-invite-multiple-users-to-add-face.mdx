Steps to invite multiple users to add Face

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
2. Select user(s).
   ![How to invite multiple users to add face - screenshot 2](/images/intercom/9674132/image-3f24bcc2.png)
3. On top right, Click **Action** > **Send email** > **Invite to add face**.
   ![How to invite multiple users to add face - screenshot 3](/images/intercom/9674132/image-92c83cb7.png)
   An email invite link is sent to the users to upload their face.
   ![How to invite multiple users to add face - screenshot 4](/images/intercom/9674132/image-a96c5651.png)

To upload face using the invite link, see [How to add face using the invite link](https://oloid.help/en/articles/8472935-how-to-add-face-using-the-invite-link-in-oloid-user-portal).
