Steps to Assign Badge:

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
2. Click **username** to edit.
   ![Image](/images/intercom/9679401/ae7366d1-2e72-47da-95c5-543894f81c0e-8277e0d2.png)
   The User details page is displayed.
   ![How to assign Badge ID as credential to... - screenshot 1](/images/intercom/9679401/image-b485b978.png)
3. Do one of the following:
   1. Go to **Credentials** > **Badge** > **+ Assign Badge**.
      ![Image](/images/intercom/9679401/c1b7b9d0-a2dc-456d-8c4c-8d751b56a402-82162488.png)
   2. Go to **Assign Credential** > **Assign Badge**.
      ![Image](/images/intercom/9679401/157d9f52-cb4a-4bfc-a4ac-747a72b62dd0-40d43bad.png)
      The **Assign Badge** pop-up box is displayed.
4. On the pop up box, enter **Badge ID** or **Secondary ID**, then select **Wiegand Format**.
   ![How to assign Badge ID as credential to... - screenshot 2](/images/intercom/9679401/image-606d726f.png)

Click **Assign**.

The badge ID is assigned and listed on the **Badge** tab.

![Image](/images/intercom/9679401/64847153-3505-4bdb-a401-07e7546e8b51-b469ef7d.png)
