Steps to Invite to Add Face:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
2. Click **username** to edit.
   ![Image](/images/intercom/9673759/7046f59b-7e08-4971-9372-8bd19055bc69-aea17ab3.png)
   The user details page is displayed.

Go to **Credentials** > **Face** > **Invite to Add Face**.

![How to invite to add face - screenshot 1](/images/intercom/9673759/image-dc434fa9.png)

An email invite link is sent to user to upload their face.

To upload face using the invite link, see **[How to add face using the invite link](https://oloid.help/en/articles/8472935-how-to-add-face-using-the-invite-link-in-oloid-user-portal)**[.](https://oloid.help/en/articles/8472935-how-to-add-face-using-the-invite-link-in-oloid-user-portal)
