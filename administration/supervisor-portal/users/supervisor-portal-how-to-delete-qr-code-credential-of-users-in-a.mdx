Steps to delete QR Code Credential of Users in a Connection:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
   ![How to delete QR Code Credential of... - screenshot 1](/images/intercom/9674159/image-28c47ea2.png)
2. Go to **Action** > **Delete QR Code Credential**.
   ![How to delete QR Code Credential of... - screenshot 2](/images/intercom/9674159/image-18bdd665.png)
   The **Delete QR Code Credential** pop-up box is displayed.
   ![How to delete QR Code Credential of... - screenshot 3](/images/intercom/9674159/image-a08929f2.png)
3. On the pop-up box, do the following:
   1. Select connection from **Connection** dropdown list to delete QR Code for users in the selected connection.
   2. On **Share Summary With** field enter the email ID(s) with whom you want to share the QR Code summary.
   3. Click **Delete**.
      The QR Code is successfully deleted for the selected users and summary details are shared with respective email IDs.
