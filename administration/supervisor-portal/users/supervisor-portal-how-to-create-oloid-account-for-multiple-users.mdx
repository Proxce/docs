Steps to create Oloid Account:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
2. Select user(s) to create Oloid Account.
   ![How to create Oloid Account for... - screenshot 1](/images/intercom/9711943/image-d1ec3e03.png)
3. Go to **Action > Create Oloid Account**.
   ![How to create Oloid Account for... - screenshot 2](/images/intercom/9711943/image-14c1f5a4.png)
   The Oloid account is created for the selected users.
   ![How to create Oloid Account for... - screenshot 3](/images/intercom/9711943/image-1786273d.png)
