Steps to create CloudKey:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
2. Click **username** to edit.
   ![How to add CloudKey as credential to... - screenshot 1](/images/intercom/9673835/image-6054030a.png)
   The user details page is displayed.
   ![How to add CloudKey as credential to... - screenshot 2](/images/intercom/9673835/image-f0e7511d.png)
3. Do one of the following:
   1. Go to **Credentials** > **Cloud Key** > **+ Create CloudKey**
      ![Image](/images/intercom/9673835/871f484c-95bf-497a-ac3a-501c5e7d806f-a7b8cbfb.png)
   2. Go to **Assign Credential** > **Create CloudKey**.
      ![Image](/images/intercom/9673835/ef2b1aa8-4f5f-4364-8c3f-e5a468f4a212-b7ea0b84.png)
      The **Create CloudKey** pop-up box is displayed.
      ![How to add CloudKey as credential to... - screenshot 3](/images/intercom/9673835/image-4c9ec5f8.png)
4. Enter **Start Date / Time** and **End Date/Time.**

   <Note>
     **Note:** You can click **Now** to set the current date and time. The end date is automatically set to 1 year from the current date.
   </Note>

   You can also click **10 years from Now** to set the **End Date/Time** to 10 years from the current date/time.
5. Click **Create**.
   The Cloudkey is created and listed on the **CloudKey** tab.
   ![Image](/images/intercom/9673835/4ab597b6-ce48-499e-9e62-825de58df294-3db2f101.png)
