**Introduction**

An Oloid account is a User's unique ID created within the Supervisor Portal, enabling users to access Oloid’s applications.

**Pre-requisite:**

- You must provide your email address or phone number to create OloID Account.
- You must turn on **Enable OloID Account** toggle button on the Connection detail page. For more information, see**[How to Enable OloID account in Connection](https://oloid.help/en/articles/8488406-how-to-enable-oloid-account-in-a-connection)**.

**Steps to Create Oloid Account:**

1. Log in to the **Supervisor Portal**.
2. On the home page of the portal, click User Name to edit.
   ![How to create Oloid Account in... - screenshot 1](/images/intercom/11401882/image-fc64b1dd.png)
   The User details page is displayed.
3. Go to **Action** > **Create Oloid Account**.
   ![How to create Oloid Account in... - screenshot 2](/images/intercom/11401882/image-00158e54.png)
   An Oloid account is created successfully.
