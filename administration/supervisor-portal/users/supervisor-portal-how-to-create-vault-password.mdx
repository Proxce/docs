Steps to create Vault Password:

1. Log in to the **Supervisor Portal.**
   The **Users** page is displayed.
2. Click the **username** to edit.
   ![Image](/images/intercom/10304522/7046f59b-7e08-4971-9372-8bd19055bc69-aea17ab3.png)
   The user details page is displayed.
3. Go to **Credentials** > **Vault Passwords** tab > **+ Create Password**.
   ![Supervisor Portal- How to create Vault... - screenshot 1](/images/intercom/10304522/image-d46a3c6e.png)
   The **Create Vault Password** pop-up box is displayed.
   ![Supervisor Portal- How to create Vault... - screenshot 2](/images/intercom/10304522/image-1705ed0c.png)
4. Do the following:
   1. Enter **Display Name** that helps you identify this password. (Optional)
   2. Select **Web** type from **Password Type** dropdown list.
   3. Click **Next.**
      ![Supervisor Portal- How to create Vault... - screenshot 3](/images/intercom/10304522/image-a70a095c.png)
   4. Enter **Web URL**.
   5. Enter **Username**.
   6. Enter **Password**.
   7. Click **Save.**
      The password is created and listed in the **Vault Passwords** tab.
      ![Supervisor Portal- How to create Vault... - screenshot 4](/images/intercom/10304522/image-c4df2b82.png)
