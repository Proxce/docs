The tenant admin must grant the supervisor permission to add or delete users.

![How to remove user - screenshot 1](/images/intercom/9674187/How-to-remove-user-in-the-supervisor-portal-93eb2910.gif)

Steps to remove user:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
2. Click username to edit.
   ![How to remove user - screenshot 2](/images/intercom/9674187/image-30bf4673.png)
   The user details page is displayed.
3. On the top-right, go to **Action** > **Delete User**.
   ![How to remove user - screenshot 3](/images/intercom/9674187/image-d7a05fca.png)
   A confirmation pop-up box is displayed.
   ![How to remove user - screenshot 4](/images/intercom/9674187/image-d3968a2e.png)
4. Click **Delete**.
   The user is permanently deleted from the Supervisor Portal.
