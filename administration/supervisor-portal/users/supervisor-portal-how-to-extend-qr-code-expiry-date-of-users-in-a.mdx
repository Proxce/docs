Steps to extend QR Code expiry date for a Connection:

1. Log in to the **Supervisor Portal**.
   The **Users** page is displayed.
   ![How to extend QR Code expiry date of... - screenshot 1](/images/intercom/9673773/image-52812e79.png)
2. Go to **Action** > **Extend QR Code Expiry Date**.
   ![How to extend QR Code expiry date of... - screenshot 2](/images/intercom/9673773/image-d5e4f8dd.png)
   The **Extend QR Code** pop-up box is displayed.
   ![How to extend QR Code expiry date of... - screenshot 3](/images/intercom/9673773/image-2eee782b.png)
3. On the pop-up box, do the following:
   1. Select a preferred connection from the **Connection** dropdown list.
   2. Under **QR Code Validity** field adjust the date and time from the calendar icon.
   3. Under **Share Summary With** field enter the email ID(s) with whom you want to share the QR Code summary.
   4. Click **Assign**.
      The QR Code is successfully extended for users in the selected connection. The QR Code summary of these users is shared over email ID(s).
