### Pre-requisite

Face should be added to the user.

### Steps to find Face

1. Log in to the **Supervisor Portal.**
   The Users page is displayed.
2. Click **username** to edit.
   ![How to find face - screenshot 1](/images/intercom/9669611/image-30bf4673.png)
   The User details page is displayed.
   ![How to find face - screenshot 2](/images/intercom/9669611/image-23ab078e.png)
3. Go to **Action** > Select **Find Face**.
   ![How to find face - screenshot 3](/images/intercom/9669611/image-502bb903.png)
   The **Find Similar Faces** pop-up box is displayed.
   ![How to find face - screenshot 4](/images/intercom/9669611/image-d7bbea2e.png)
4. On the **Find Similar Faces** pop-up box, do the following:
   1. Enter **Confidence level**.

      <Note>
        **Note:** For best results, increase confidence level above default value.
      </Note>

   2. Select required connection(s) from the **Connection** drop-down list.
   3. Click **Search**.
      The **Results for Similar Faces** pop-up box is displayed.
      The search result shows confidence level face match.

      <Note>
        **Note:** This functionality is for Oloid internal use.
      </Note>
