## Configure users in Oloid Admin Portal

A tenant needs to be created by Oloid Admin to configure users in the Tenant Admin Portal.

1. Log into your **Tenant Admin Portal**.

2. Import **Users**. See, [Onboarding Users Using Import Template](https://login.oloid.help?returnurl=https://oloid.help/en/articles/7120185-onboarding-users-using-import-template).

<Note>
  **Note:** Once users are imported, BadgeBinary is generated. Bluetooth token needs to be generated for Oloid App to function.
</Note>

To generate Bluetooth token, see [How to create Bluetooth ID](https://login.oloid.help?returnurl=https://oloid.help/en/articles/7129819-how-to-create-bluetooth-id)

To generate Bluetooth token in bulk, see [How to generate BLE token in bulk](https://login.oloid.help?returnurl=https://oloid.help/en/articles/7129885-how-to-generate-ble-token-in-bulk)
