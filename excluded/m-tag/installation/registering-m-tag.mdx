Registering M-Tag is performed by the customer once they receive the device. This activity must be done before the end user can use the M-Tag to access a door.

**Prerequisite for this activity:** Customer should have an active Online Account as a Tenant (This is created by Oloid).

Registering the M-Tag can be done through Oloid's M-Tag Admin App.

Steps to Register M-Tag (endpoint):

1. Log in to the **Tenant Admin App** with Admin credentials.

2. Upon successful login, the user is asked to register the endpoint.

3. Once the endpoint is successfully registered, you can use your endpoint (M-tag) to open the door.

For more information see, [How to register M-Tag in M-Tag Admin App](https://oloid.help/en/articles/6972238-how-to-register-m-tag).
