1. Launch the **M-Tag Admin** App.
2. Log in to the App.
   The M-Tag screen is displayed with the list of the available M-Tags.
   ![Unregister M-Tag - screenshot 1](/images/intercom/6984762/image-7a297adf.png)
3. Select the **M- Tag** to unregister.
   ![Unregister M-Tag - screenshot 2](/images/intercom/6984762/image-c318b598.png)
   The M-tag detail screen is displayed.
   ![Unregister M-Tag - screenshot 3](/images/intercom/6984762/image-3d35b997.png)
4. Click **Un-Register**.
   A pop-up box is displayed to confirm de-registration.
   ![Unregister M-Tag - screenshot 4](/images/intercom/6984762/image-961e442f.png)
5. Click **Ok**.
   The M-Tag is unregistered. You can verify it in the M-Tag list screen.
   ![Unregister M-Tag - screenshot 5](/images/intercom/6984762/image-c1259177.png)
