## Terms

## Definitions

## A

### Access Control

Oloid Access control allows restricted access at workplace based on multi modal authentication such as BLE, facial recognition, QR code, and badge.

### Activate User

To enable user to use the Oloid platform for various transactions.

### Activity Log

The Activity log is the detailed user record of all the activities or events performed in the platform.

### Add Users

This feature of Oloid allows the user in tenant admin mode within the Oloid Connect or Oloid Verify App to add new users to the connection.

### Ad-Hoc Reports

Reports created on need basis. These are generally one time reports.

### Admin Mode

A section of the Oloid Connect or Oloid Verify App, which is accessible only by a Tenant Admin.

### Administrator

A super user who has access and control over the platform with highest level of permission to perform all actions available within the platform.

### Application

An application is a set of configurations depending on the product (FR, Thermal, QR, BLE, etc or a combination of any of these) the customer is subscribed to.

### Application Type

Application type helps to identify the product used by the customer.Oloid Platform comprises of three application types: M-Tag, Oloid Connect, Oloid Verify.

### Authentication Type

The methods used to verify a user's identity such as Face, Bluetooth Token, QR Code, and Badge.

## B

### Badge

Badge is physical access card used to gain entry to an area having automated access control entry points.

## C

### Connection

Connections are a collection of users of the application.

### Consent Template

Consent is a permission to use face as a credential to authenticate a user in the platform.
This has to be in accordance with the legal terms and conditions of that company/state/ region/ country.
Consent template has privacy policy and legal terms and conditions attached to it.

### Credentials

A unique identifier to authenticate a user like Face, QR Code, Badge, Bluetooth Token.

## E

### Encoded start

Encoded Start represents the starting bit position from where card number will be stored.

### Endpoint

Endpoints are the devices like M-Tag, iPad, Android Phone, iPhone, etc. that allows customers to authenticate employees or visitors in their company premises.

### Endpoint ID

It is an autogenerated id associated with a particular endpoint.

### Endpoint Report

A report detailing endpoint settings and configurations.

### Endpoint Type

Devices like iPad, Android Phone, iPhone, M-Tag etc.

### Exception Actions

These are post identification actions which are trigged in case any exception occurs during that transaction e.g. temperature check fails

## F

### Face Onboarding

Adding face as a credential for a user to Oloid platform.

### Face Quality Check

Face quality check refers to measure of the quality of a face image parameters (e.g. Eyes Visible, Full face visible, etc.) used in automatic face recognition.

### Faces

Digital image of a person which shows the front of the head, from the top of the forehead to the bottom of the chin.

### Facial Recognition

Facial recognition is a way of identifying or confirming an individual's identity using their face.

### Facial Recognition Model

A set of algorithms which are the underlying component of any facial detection and recognition system.

### Facial Transaction

A transaction based on facial authentication method.

### Facility Code

This is a number that represents the facility or building that the card will be used in.

### Facility Code Length

Facility Code Length is the length (number of bits) available for storing facility code.

### Facility Code Start

Facility code start represents the bit position from where the facility code will be stored.

## G

### Group Name

Groups are used to restrict access for a selection of users to a particular endpoint. If groups is enabled in endpoint then only users belonging to the same groups and connection that the endpoint belongs to can do access through the endpoint.

## H

### Health Response

Response received from the health check . It will have the status of all the health parameters queried in the health check.

### Health Set-up

Health setup enables to check health of the endpoint e.g. battery level of M-Tag, internet connectivity of oloid verify. It also helps to receive health alerts of the endpoints to the configured emails to view their health status.

## I

### Identity Confidence

It is the threshold value which describes the accuracy of a face match in facial recognition.

### Identity QR authentication

The process of authenticating a user using a QR code.

### Improve Faces

Functionality to improve the quality of reference images by using the latest high quality images from transactions

### Integrations

Integration is linking of two separate systems which can exchange information.

## L

### Legal Documents

A legal document outlines an agreement between two or more parties that has been signed by mutual assent

## M

### Min Confidence

Minimum confidence value is the minimum threshold value which is considered to take accuracy of a face match.

### M-Tag

M-Tag is a retrofit hardware device that enables communication between card readers and Mobile App by translating Bluetooth signals to RF card signal.

## O

### OloID

It is a mobile app for access control using BLE module.

### OloID Account

User account created for users to access the OloID app.

### Oloid Connect

Oloid Connect is a contactless authentication application for time and attendance clocking, payroll compliance and workplace access. It includes workflow temperature checks and self-attestation checks using gesture and voice-based technology.

### Oloid Thermal

Oloid Thermal is a feature of Oloid Connect Application that allows temperature checks.

### Oloid Thermal Kit

This kit contains the Oloid iPad with thermal camera assembled with it.

### Oloid Verify

Oloid Verify is a contactless authentication application for time and attendance, clocking, and payroll compliance using facial recognition.

### Onboarding

Onboarding refers to adding users and their credentials to Oloid platform.

## P

### Platform

A user interface which can be accessed only by a tenant admin to perform various functionalities like onboarding users, configuring application and endpoint settings, etc.

### Power Source

It is a source of power , for example an electrical outlet.

### Preview Mode

The section of the Oloid Connect or Oloid Verify App, which captures the users face for authentication

### Primary ID

Employee ID of the user who is onboarded on the platform.

### Punch attendance

The process of capturing attendance using Facial Authentication method or Identity QR as a mode.

## Q

### QR Code

A quick response (QR) code is a type of barcode that stores information and can be read by a digital device, such as a cell phone. It is used to establish identity of a user.

## R

### Reference Image

Reference image is the face uploaded by the Tenant Admin for a user. This face is used as a reference point for face match against the captured image during daily transactions.

## S

### Secondary ID

It is the badge Id or employee ID of the Oloid user.

### Secret

Secret is an encryption key which can be used to encrypt and decrypt an information encoded within that key.

## T

### Tenant Admin

Tenant admin can perform a set of tasks like onboarding users and credentials, configuring application and endpoints, etc.

### Thermal Check

This feature of Oloid Connect app enables to scan human skin temperature for wellness check before entering the workplace.

### Topics

Definition

### Transaction Report

A report detailing Transaction details.

### Transactions

A set of operations performed to authenticate the user for punch attendance, temperature check and/ or access control.

## U

### User Group

Groups are used to create collection of users who can be provided common access rights or common access policy can be applied to them.

### Users

User is a person who ultimately uses or is intended to ultimately use a product.

## W

### Wellness Attestation

The wellness attestation form requires employees, staff and visitors to confirm health information such as that they do not feel sick, do not have a fever, have not come in contact with anyone who is sick, or have been cleared by a doctor after becoming ill.

### Wellness Check

Wellness check is the process of capturing and administering the responses of a symptoms questionnaire at different points of entry at workplace

### Wiegand

In access control applications, wiegand is the technology used by card readers to communicate with controler.

### Wiegand Format

In access control applications, wiegand format is access card data encoding that is sent from card readers with controler.
