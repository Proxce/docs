## Introduction

This document provides instructions to install the Oloid Vault extension in Google Chrome from the Chrome Web Store.

## Prerequisites

- Google Chrome is installed on the device.
- You have an active internet connection.
- You have permission to install browser extensions.

## Steps to Add Oloid Vault Extension in Google Chrome.

1. Open the Google Chrome browser.
   The Google Chrome browser is displayed.
   ![How to Add the Oloid Vault Extension... - screenshot 1](/images/intercom/16105372/image-0064bbe9.png)
2. Click the **Menu (three dots)** icon > **Extensions > Manage Extensions**.

   <Note>
     **Note:** You can also click **Visit Chrome Web Store** to open the Chrome Web Store and skip **Step 3**.
   </Note>

   ![How to Add the Oloid Vault Extension... - screenshot 2](/images/intercom/16105372/image-17478dbb.png)
   The Extensions screen is displayed.
3. Click **Chrome Web Store**.
   ![How to Add the Oloid Vault Extension... - screenshot 3](/images/intercom/16105372/image-6d77361d.png)
   The Chrome Web store screen is displayed.
4. In the search bar, enter **Oloid Vault**.
   ![How to Add the Oloid Vault Extension... - screenshot 4](/images/intercom/16105372/image-ea71ac67.png)
   The **Oloid Vault Extension** screen is displayed.
5. Click **Oloid Vault**.
   ![How to Add the Oloid Vault Extension... - screenshot 5](/images/intercom/16105372/image-e3e6f722.png)
   The Oloid Vault Extension screen is displayed.
6. Click **Add to Chrome**.
   ![How to Add the Oloid Vault Extension... - screenshot 6](/images/intercom/16105372/image-9f6ff319.png)
   The **Add "Oloid Vault"** pop-up box is displayed.
7. Click **Add extension**.
   ![How to Add the Oloid Vault Extension... - screenshot 7](/images/intercom/16105372/image-70cc46b5.png)
   The Oloid Vault extension is successfully added to Google Chrome.
   ![How to Add the Oloid Vault Extension... - screenshot 8](/images/intercom/16105372/image-4b0ab73c.png)
