## Introduction

This document provides instructions to add the Oloid Vault extension to Google Chrome using the Tenant Admin Portal.

## Prerequisite

You must have access to the Tenant Admin Portal.

## Steps to Add Oloid Vault Extension

1. Log in to **Tenant Admin Portal**.
2. On the homepage of the portal, click **User profile icon** at the bottom-left corner of the menu panel.
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![Oloid Vault (Chrome/Chromium) – How to... - screenshot 1](/images/intercom/16145298/image-923827f3.png)
   The **Tenant Settings** screen is displayed.
   ![Oloid Vault (Chrome/Chromium) – How to... - screenshot 2](/images/intercom/16145298/image-1c391802.png)
4. Go to **Oloid Apps** tab **>** Click **View in Chrome Web Store**.

   <Note>
     **Note:** To install the Oloid Vault extension in Microsoft Edge, copy the **View in Chrome Web Store** URL, paste it into the Microsoft Edge browser, and follow steps 5 and 6.
   </Note>

   ![Oloid Vault (Chrome/Chromium) – How to... - screenshot 3](/images/intercom/16145298/image-72d8dcb9.png)
   The Oloid Vault Extension page is displayed.
5. Click **Add to Chrome**.
   ![Oloid Vault (Chrome/Chromium) – How to... - screenshot 4](/images/intercom/16145298/image-9f6ff319.png)
   The **Add Oloid Vault** pop-up box is displayed.
6. Click **Add extension**.
   ![Oloid Vault (Chrome/Chromium) – How to... - screenshot 5](/images/intercom/16145298/image-70cc46b5.png)
   The Oloid Vault extension is successfully added to the Google Chrome.
   ![Oloid Vault (Chrome/Chromium) – How to... - screenshot 6](/images/intercom/16145298/image-17280ab5.png)
