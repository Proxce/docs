## Introduction

The Endpoint Template in the Tenant Admin Portal allows Tenant Admin to configure and manage settings for endpoints used in the Oloid Vault (Chrome / Chromium) application.

## Prerequisites

You must create Endpoint Template. To create refer, [How to create Endpoint Template for Chrome Vault application in the Tenant Admin Portal](https://oloid.help/en/articles/12606069-how-to-create-endpoint-template-for-chrome-vault-application-in-the-tenant-admin-portal).

## Steps to configure Endpoint Templates

1. Log in to the **Tenant Admin Portal**.
2. On the homepage, select **Endpoint** from the left menu panel.
   ![How Configure Endpoint Templates in the... - screenshot 1](/images/intercom/12636504/image-ac445d0a.png)
   The **Endpoints** page is displayed.
3. Click **Endpoint Template** from the top right.
   ![How Configure Endpoint Templates in the... - screenshot 2](/images/intercom/12636504/image-05f84921.png)
   The **Endpoint Template** page is displayed.
4. Select the preferred Endpoint Template to edit.
   ![How Configure Endpoint Templates in the... - screenshot 3](/images/intercom/12636504/image-8ccf2316.png)
   The Endpoint Template details page is displayed.
5. Do the following:
   1. Edit **Template Name**.
   2. Add **Template Description**.
   3. Select the **Time Zone** from the dropdown list.
   4. Add **Endpoint Name**.
   5. Click **Save**.
      ![How Configure Endpoint Templates in the... - screenshot 4](/images/intercom/12636504/image-e82cd966.png)
6. Go to Configure tab and do the following:
   1. Turn on **Generate Debug Logs** toggle to activate generation of logs for the endpoint until disabled.
   2. Click **Save**.
      ![How Configure Endpoint Templates in the... - screenshot 5](/images/intercom/12636504/image-722dd6b6.png)
      The Endpoint Settings is configured successfully.
   3. Select **Groups** from the left menu panel > select **Add Groups**.
      ![How Configure Endpoint Templates in the... - screenshot 6](/images/intercom/12636504/image-b3fdf7ae.png)
      The **Add Group** pop-up box is displayed.
   4. Do the following on the pop-up box:
      1. Select Groups from the **Groups** dropdown list.
      2. Click **Add**.

![How Configure Endpoint Templates in the... - screenshot 7](/images/intercom/12636504/image-06ac4883.png)

The Endpoint Template for DeviceLock Application is configured successfully.

![How Configure Endpoint Templates in the... - screenshot 8](/images/intercom/12636504/image-592e18c7.png)
