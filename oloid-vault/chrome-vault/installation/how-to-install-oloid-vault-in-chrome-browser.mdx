## Introduction

This document provides instructions to install **Oloid Vault** as a browser extension. The installation steps in this document apply to **Google Chrome** browser. After installation, Oloid Vault enables users to securely manage credentials directly within supported web applications.

## Prerequisites

- The **Oloid Vault installer package** (ZIP file) is available.

  <Note>
    **Note:** Contact [Oloid Support](mailto:Support@oloid.ai) to obtain the Oloid Vault installer package
  </Note>

- The installer package includes:
  - **Oloid_Vault.crx file**
  - **Registry file(s).**

    <Note>
      **Note:** Restart **Chrome Browser** to apply the registry changes
    </Note>

## Steps to Install Oloid Vault Application

1. Download the **Oloid Vault installer ZIP file** on your system.

   <Note>
     **Note:** Ensure theinstaller file must contain **Oloid_Vault.crx** and **Registry** files.
   </Note>

2. Right-click the zip file and select **Extract All**.

   <Note>
     **Note:** The extracted files are saved in the same folder as the original ZIP file.
   </Note>

3. Install **Registry** file.

   <Note>
     **Note:** First-time users must install the required registry file before using the Oloid Vault application.
   </Note>

4. Open **Google Chrome** browser.
5. Go to **Extensions** > **Manage Extensions**.
   ![How to Install Oloid Vault in Chrome... - screenshot 1](/images/intercom/13724911/image-41291e03.png)
   The **Extensions** page is displayed.
6. Enable **Developer Mode** toggle.
   ![How to Install Oloid Vault in Chrome... - screenshot 2](/images/intercom/13724911/image-e4c34eb5.png)
   The **Developer mode** is enabled successfully.
7. Drag and drop the **Oloid_Vault.crx file** onto the **Chrome Extensions** page.

   <Note>
     **Note:** Ensure that **Developer mode** is enabled before dragging and dropping the Oloid_Vault.crx file.
   </Note>

   The **Add Oloid Vault** pop-up box is displayed.
   ![How to Install Oloid Vault in Chrome... - screenshot 3](/images/intercom/13724911/image-c4562a71.png)
8. Select **Add extension**.
   ![How to Install Oloid Vault in Chrome... - screenshot 4](/images/intercom/13724911/440e2329-e638-4e6b-95f7-1f2aff3ad637-77cdfe05.png)
   The **Oloid Vault** is added successfully.
9. Click **Details**.
   ![How to Install Oloid Vault in Chrome... - screenshot 5](/images/intercom/13724911/image-c165aa83.png)
   The **Details** page is displayed.
10. Do the following:
    1. Enable **Pin to toolbar** toggle.
    2. Enable **Allow in Incognito** toggle.
       ![How to Install Oloid Vault in Chrome... - screenshot 6](/images/intercom/13724911/image-816a916f.png)
       The **Oloid Vault** extension is successfully installed. You can now view **Oloid Vault** icon on the toolbar.
       ![How to Install Oloid Vault in Chrome... - screenshot 7](/images/intercom/13724911/image-654c027a.png)
