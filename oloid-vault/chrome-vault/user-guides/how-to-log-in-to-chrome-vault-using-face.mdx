## Introduction

Chrome Vault allows users to log in securely using Facial authentication. When Face authentication is enabled for the application, user can sign in by showing his face on the device camera. This method eliminates the need for manual credential entry, providing a faster and more secure login experience.

## Prerequisite

Your device must have a **working camera** with permission to access the browser.

## Steps to Log in to Chrome Vault using Face

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar.
   ![How to log in to Chrome Vault using Face - screenshot 1](/images/intercom/9612252/image-57ce4432.png)
   The **Welcome** screen is displayed.
2. Select **Login with Face**.

   <Note>
     **Note:** The authentication methods (Face, NFC and Badge) will be visible on the Welcome screen, only if they are enabled for the application. The button names may vary based on the application’s configuration and customization. If you do not see any authentication method available, please contact your [support](mailto:support@oloid.ai) team for assistance.
   </Note>

   ![How to log in to Chrome Vault using Face - screenshot 2](/images/intercom/9612252/29f86f0f-80eb-4858-bafa-ceaaf0a74315-01816966.png)
   The Camera Permission pop-up box is displayed.
3. Select **Allow while visiting the site** to open the camera.
   ![How to log in to Chrome Vault using Face - screenshot 3](/images/intercom/9612252/image-a4ea8f0a.png)
   The image capture pop-up box is displayed.
4. Do one of the following:
   - Position yourself to face the camera for automatic capture.
     or
   - Position yourself to face the camera > click capture button.
     ![How to log in to Chrome Vault using Face - screenshot 4](/images/intercom/9612252/9d2f3b60-a714-470c-ae32-86b634b8c297-8f78f53d.png)
     You are successfully signed in to Chrome Vault.
