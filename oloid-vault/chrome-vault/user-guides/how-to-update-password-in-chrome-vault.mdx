**Pre-requisite**

You have saved credentials in the Chrome Vault application. For more information, see [How to save password in Chrome Vault](https://oloid.help/en/articles/9618391-how-to-save-password-in-chrome-vault)

To update password:

1. Go to a website that you need to log in.
2. Click on the password field.
   The Chrome Vault icon is displayed.
3. Edit the password field > **Update Password**.
   ![How to update password in Chrome Vault - screenshot 1](/images/intercom/9819006/image-6dff3790.png)
   The Chrome Vault pop-up is displayed.
   ![How to update password in Chrome Vault - screenshot 2](/images/intercom/9819006/image-78ecb192.png)
4. Click **Update Password**.
   The password is updated successfully and you can log in to the website.
   ![How to update password in Chrome Vault - screenshot 3](/images/intercom/9819006/image-a62b5e42.png)
