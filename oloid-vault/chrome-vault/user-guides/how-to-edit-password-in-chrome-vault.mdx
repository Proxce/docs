## Introduction

Chrome Vault lets you securely manage saved passwords in your browser. This document shows you how to update a saved password to keep your credentials current and avoid login issues.

## Prerequisite

The password must be saved in Chrome Vault. To save password refer [How to save password in Chrome Vault](https://oloid.help/en/articles/9618391-how-to-save-password-in-chrome-vault).

## Steps to edit password

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar.
   ![How to edit password in Chrome Vault - screenshot 1](/images/intercom/9795116/image-57ce4432.png)
   The **Chrome Vault** pop-up box is displayed.
2. Click **More options menu** (![How to edit password in Chrome Vault - screenshot 2](https://downloads.intercomcdn.com/i/o/e4gi378c/1726122252/fc0ccc96e39ecbaabc5cb67cbd50/image.png?expires=1790488800&signature=ecbe7172768d39710a31d2f8026c0d66d46535bcf86f764f4c23b390cf0fe22d&req=dSclEMh8n4NaW%2FMW3nq%2BgQh5yD2j3xGs6B1O7KMBfDR8uY%2BP%2FD%2F6O%2B7s7QRo%0ApzNhVdSpM9lxWByqbCtvyyb1uRo%3D%0A)) on the preferred saved profile to edit it.
   ![How to edit password in Chrome Vault - screenshot 3](/images/intercom/9795116/image-94c27a47.png)
   The **Chrome Vault** page in edit mode is displayed.
3. Do the following:
   1. Edit the website **URL** (optional).
   2. Edit **username** (optional).
   3. Edit **password**.
   4. Click **Save Password**.
      ![How to edit password in Chrome Vault - screenshot 4](/images/intercom/9795116/5abd4953-db36-476f-8251-3bd8bfd7e778-771182a2.png)
      The password is updated successfully.
      ![How to edit password in Chrome Vault - screenshot 5](/images/intercom/9795116/image-f6820f50.png)

      <Note>
        **Note:** You can also edit and update your password using the Update Password option. For details, see [How to update password in Chrome Vault](https://oloid.help/en/articles/9819006-how-to-update-password-in-chrome-vault).
      </Note>
