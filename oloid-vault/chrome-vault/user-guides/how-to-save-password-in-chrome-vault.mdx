## Introduction

The Chrome Vault application securely stores and manages your website passwords in the browser. It lets you quickly access saved credentials without remembering multiple usernames and passwords. You can save passwords either while logging in through the browser or by using the add option in the Chrome Vault extension.

## Prerequisites

The Chrome Vault application must be installed. To install refer [How to install Chrome Vault application](https://oloid.help/en/articles/9610642-how-to-install-chrome-vault-application).

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar.

2. Log in to **Chrome Vault** application by selecting an authentication method. For more details refer [How to log in to Chrome Vault](https://oloid.help/en/articles/12289985-how-to-log-in-to-chrome-vault).

   You are logged in to Chrome Vault.

3. You can add website password using the following ways:

### Using Browser

1. Go to a website that you need to log in.
   ![How to save password in Chrome Vault - screenshot 4](/images/intercom/9618391/image-bfe21d9d.png)
2. Click on any credential field .
   The **Chrome Vault** icon is displayed.
3. Click Chrome Vault icon (![How to save password in Chrome Vault - screenshot 5](/images/intercom/9618391/image-b898cfdb.png)) > **Save in Chrome Vault**.
   ![How to save password in Chrome Vault - screenshot 6](/images/intercom/9618391/image-fa67daa0.png)
   The Chrome Vault pop-up box is displayed.
4. Do the following:
   1. **Website URL:** The application auto-fills the URL field.
   2. **Username**: Enter **Username**.
   3. **Password**: Enter **Password**.
   4. Click **Save Password**.
