## Introduction

The Chrome Vault application provides a secure and passwordless way for users to access their accounts using Face, Badge, or NFC/ID authentication. This ensures a faster login experience while maintaining high security standards.

## Prerequisites

Authentication method (Face, Badge, or NFC/ID) must be enabled. To enable refer [How to create and configure Chrome Vault application](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application#h_205e28ce64).

## Steps to login

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar.
   ![How to log in to Chrome Vault - screenshot 1](/images/intercom/12289985/image-0c211771.png)
   The Welcome screen is displayed.
2. Do one of the following:
   1. Select **Login with Face**
      To login with Face refer[How to log in to Chrome Vault using Face](https://oloid.help/en/articles/9612252-how-to-log-in-to-chrome-vault-using-face).
   2. Select **Login with Badge**
      To login with Badge refer [How to log in to Chrome Vault using Badge](https://oloid.help/en/articles/9751929-how-to-log-in-to-chrome-vault-using-badge).
   3. Select **Login with NFC/ID**
      To login with NFC/ID refer [How to log in to Chrome Vault using NFC](https://oloid.help/en/articles/9740334-how-to-log-in-to-chrome-vault-using-nfc).
      ![How to log in to Chrome Vault - screenshot 2](/images/intercom/12289985/image-9c6676c9.png)
