## Introduction

This document provides instructions for logging in to **Admin Mode** in Oloid Vault (Chrome/Chromium) to manage settings and configure features.

## Prerequisite

You must install and setup the Oloid Vault. For more details, refer [Oloid Vault - How to Set Up and Use](https://oloid.help/en/articles/9822629-oloid-vault-how-to-set-up-and-use)

## Steps to Log in to Admin Mode

1. Open **Google Chrome** browser and click **Oloid Vault** icon.
   ![How to Log in to Admin Mode - screenshot 1](/images/intercom/9651553/image-b381a68a.png)
   The welcome screen is displayed.
2. Click **More** option icon (![How to Log in to Admin Mode - screenshot 2](/images/intercom/9651553/image-416117ef.png)) > select **Admin Mode**.
   ![How to Log in to Admin Mode - screenshot 3](/images/intercom/9651553/image-b735116f.png)
   The **Login as supervisor** screen is displayed.
3. Do the following:
   1. Enter **Supervisor username** or **email ID**.
   2. Enter **Password**.
   3. Click **Login**.
      ![How to Log in to Admin Mode - screenshot 4](/images/intercom/9651553/image-81e2c6b5.png)
      You are successfully logged in to the admin mode.
      ![How to Log in to Admin Mode - screenshot 5](/images/intercom/9651553/image-ac0aa7e9.png)
