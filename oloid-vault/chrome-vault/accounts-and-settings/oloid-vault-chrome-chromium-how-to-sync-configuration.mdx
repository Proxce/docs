## Introduction

This document provides instructions for syncing the configuration in Oloid Vault (Chrome/Chromium) to update the application with the latest settings and configuration.

## Prerequisites

- Oloid Vault (Chrome/Chromium) must be installed and set up on your device. For more information, refer to [Setting up and using Chrome Vault](https://oloid.help/en/articles/9822629-setting-up-and-using-chrome-vault).
- To sync the configuration from **Admin Mode**, you must have valid admin credentials.

## Steps to Sync Configuration

You can sync configuration in Chrome Vault using the following options:

- [Sync Config on Welcome Screen](#sync-config-on-welcome-screen)
- [Sync Config in Admin Mode](#sync-config-in-admin-mode)

### Sync Config on Welcome Screen

1. Open **Google Chrome** browser and click **Chrome Vault** icon located on the toolbar.
   ![How to Sync Configuration - screenshot 1](/images/intercom/9842062/image-e82ffc79.png)
   The **Welcome** screen is displayed.
2. Go to **More** option (![How to Sync Configuration - screenshot 2](/images/intercom/9842062/image-62e5cbc8.png)) icon > **Sync Config**.
   ![How to Sync Configuration - screenshot 3](/images/intercom/9842062/image-76882ba4.png)

The Syncing Configuration is initiated.

![How to Sync Configuration - screenshot 4](/images/intercom/9842062/image-316eeadd.png)

The Oloid Vault configuration is updated successfully.

![How to Sync Configuration - screenshot 5](/images/intercom/9842062/image-5b1687ff.png)

### Sync Config in Admin Mode

1. Log in to Admin Mode in Oloid Vault. For more details refer [Oloid Vault (Chrome / Chromium) - How to Log in to Admin Mode](https://oloid.help/en/articles/9651553-oloid-vault-chrome-chromium-how-to-log-in-to-admin-mode)
2. On the configuration screen, click **Sync Config**.
   ![How to Sync Configuration - screenshot 6](/images/intercom/9842062/image-8b536727.png)
3. The Syncing Configuration is initiated.

![How to Sync Configuration - screenshot 7](/images/intercom/9842062/image-3a8a2078.png)

The Oloid Vault configuration is updated successfully.

![How to Sync Configuration - screenshot 8](/images/intercom/9842062/image-e96208c5.png)
