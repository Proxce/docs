## Introduction

This document explains how to lock the browser using the Oloid Vault (Chrome / Chromium) app. The Browser Lock feature secures all active browser tabs and requires reauthentication to unlock them.

## Prerequisites

- Ensure that the **Browser Lock** feature is enabled in the Tenant Admin Portal. For more information, refer [Lock Browser](https://oloid.help/en/articles/9586885-how-to-create-and-configure-chrome-vault-application-in-the-tenant-admin-portal#h_2a0d8a36d8:~:text=Customize%20Buttons%20tab-,Configure%20Settings%20tab,-Vault%20Behaviour).
- You must login to the Chrome Vault. To log in refer [How to log in to Chrome Vault](https://oloid.help/en/articles/12289985-how-to-log-in-to-chrome-vault).

## Steps to Lock the Browser

1. Open **Chrome Vault** application.
2. Click **Lock Browser**.
   ![How to Lock the Browser - screenshot 1](/images/intercom/14075018/image-11e2d118.png)
   The Browser is locked successfully.

   <Note>
     **Note:** All browser tabs are locked automatically. Reauthenticate from any tab to unlock the browser. Once authentication is completed, all tabs are unlocked.
   </Note>
