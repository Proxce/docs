## Introduction

This document provides instructions for unpairing an endpoint from Oloid Vault (Chrome/Chromium) when the endpoint is no longer in use or needs to be removed from the system.

## Prerequisites

- The endpoint you want to unpair must be paired with Oloid Vault (Chrome/Chromium).
- You must have valid Oloid Vault admin credentials to access Admin Mode.

## Steps to unpair an Endpoint

1. Open **Google Chrome** browser and click **Oloid Vault** icon located on the toolbar.
   ![How to unpair an Endpoint - screenshot 1](/images/intercom/9651603/image-79614510.png)
   The **Welcome** screen is displayed.
2. Go to **More** option (![How to unpair an Endpoint - screenshot 2](/images/intercom/9651603/image-416117ef.png)) icon > **Admin Mode**.
   ![How to unpair an Endpoint - screenshot 3](/images/intercom/9651603/image-46ea0067.png)
   The **Login as supervisor** screen is displayed.
3. Do the following:
   1. Enter your **Username** or **Email ID**.
   2. Enter **Password**.
   3. Click **Login**.
      ![How to unpair an Endpoint - screenshot 4](/images/intercom/9651603/image-adebca27.png)
      The Endpoint pair screen is displayed.
4. Select **Unpair Endpoint**.
   ![How to unpair an Endpoint - screenshot 5](/images/intercom/9651603/image-2d397a0c.png)
   The **Confirm Unpair** screen is displayed.
5. Select **Confirm Unpair**.
   ![How to unpair an Endpoint - screenshot 6](/images/intercom/9651603/image-219f4260.png)
   The device is unpaired successfully.
   ![How to unpair an Endpoint - screenshot 7](/images/intercom/9651603/image-fc71077a.png)
