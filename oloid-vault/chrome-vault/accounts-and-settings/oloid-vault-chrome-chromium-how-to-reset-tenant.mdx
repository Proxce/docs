## Introduction

This document provides instructions for resetting a tenant in Oloid Vault (Chrome/Chromium) to remove the existing tenant configuration and restore the application to its default state.

## Prerequisite

You must have valid Tenant Admin credentials to access **Admin Mode** in Oloid Vault.

## Steps to Reset Tenant

1. Open **Google Chrome** browser and click **Oloid Vault** icon located on the toolbar.
   ![How to Reset Tenant - screenshot 1](/images/intercom/9667131/image-faa596ce.png)
   The **Welcome** screen is displayed.
2. Go to **More** option (![How to Reset Tenant - screenshot 2](/images/intercom/9667131/image-416117ef.png)) icon > **Admin Mode**.
   ![How to Reset Tenant - screenshot 3](/images/intercom/9667131/image-73ef5e4a.png)
   The **Login as supervisor** screen is displayed.
3. Do the following:
   1. Enter your **Username** or **Email ID**.
   2. Enter **Password**.
   3. Click **Login**.
      ![How to Reset Tenant - screenshot 4](/images/intercom/9667131/8e93436f-4c9b-4f0c-b140-cd72a98e88f5-5aad6919.png)
      The Endpoint pair screen is displayed.
4. Select **More** (![How to Reset Tenant - screenshot 5](/images/intercom/9667131/image-05a6cc89.png)) icon > **Reset Tenant**.
   ![How to Reset Tenant - screenshot 6](/images/intercom/9667131/image-e297b9fe.png)
   The **Confirm Tenant Reset** page is displayed.
5. Select **Reset Tenant**.
   ![How to Reset Tenant - screenshot 7](/images/intercom/9667131/image-4880dd7c.png)
   The tenant has been reset successfully.
   ![How to Reset Tenant - screenshot 8](/images/intercom/9667131/image-ca247ec6.png)
