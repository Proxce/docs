## Introduction

The Add Vault Shared Password feature allows an admin to securely assign an existing shared password from the Vault to a specific user.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- Vault Shared Password must already be created. For more information, refer [How to create Vault Password for a user](https://oloid.help/en/articles/9936961-how-to-create-vault-password-for-a-user)

## Steps to Assign Vault Password

1. Log in to the Tenant Admin Portal.
2. On the homepage, click **Directory** from the left menu panel.
   ![Image](/images/intercom/13284463/081bd78d-7e0a-4865-9aa3-f1b09d506314-0c550230.png)
   The **Users** page is displayed.
3. Select preferred **User** from the list.
   ![Image](/images/intercom/13284463/56d6fd3f-d2be-4c9f-af20-44e236758802-59c95f4f.png)
   The **User details** page is displayed.
   ![How to Add Vault Shared Password for a... - screenshot 1](/images/intercom/13284463/image-d001ee59.png)
4. Go to **Credential** tab > **Vault Passwords** > **+ Add Vault Shared Password**.
   ![How to Add Vault Shared Password for a... - screenshot 2](/images/intercom/13284463/image-1f8cbe84.png)
   The Vault Shared password pop-up is displayed.
5. **Select** Vault Shared password to Assign from the dropdown.

   <Note>
     **Note:** More than one Vault shared password can be assigned for a user.
   </Note>

6. Click **Assign.**
   ![How to Add Vault Shared Password for a... - screenshot 3](/images/intercom/13284463/image-1b5e9886.png)
   Vault shared password is assigned to user.
