## Introduction

The **Auto-Pair Config File** feature in the **Oloid Tenant Admin Portal** allows admin to generate configuration files used for automatically pairing endpoints with specific applications.

## Prerequisite

You must have access to the **Tenant Admin Portal**.

## Steps to Generate and Download Auto-pair Config File

1. Log in to the **Tenant Admin Portal**.
2. On the homepage of the portal, click **user profile icon** on the bottom left corner of the menu panel.
   ![Oloid Vault (Chrome / Chromium)- How to... - screenshot 1](/images/intercom/15202831/image-83a78116.png)
   The user profile menu is displayed.
3. Click **Tenant Settings**.
   ![Oloid Vault (Chrome / Chromium)- How to... - screenshot 2](/images/intercom/15202831/image-466c99a1.png)
   The **Tenant Settings** page is displayed.
4. Go to **Security** tab > **API Token** > **API Key**.
   ![Oloid Vault (Chrome / Chromium)- How to... - screenshot 3](/images/intercom/15202831/45633202-6454-4d3a-9836-b22ac299a1b2-fe15e691.png)
5. In the **Generate Temporary Access Token** section, do the following:
   1. In the **Generate Temporary Access Token** section, select the **Start Date/Time** field.
      - To set the start date and time, click the date picker or select **Now**.
   2. Select the **End Date/Time** field.
      - Click the date picker, choose when the token will expire, and then click **OK**.
   3. Specify **Number of Endpoints** that can be created using the auto-config file. (Optional)
   4. Click **Generate**.
      ![Oloid Vault (Chrome / Chromium)- How to... - screenshot 4](/images/intercom/15202831/b700b191-2b42-4aa7-9bfe-0d5c41b866f3-0401d10e.png)
      The auto-pair config file is generated.
6. Click **Auto-pair config file**.
   ![Oloid Vault (Chrome / Chromium)- How to... - screenshot 5](/images/intercom/15202831/ca6e65c5-4747-4b0a-89f6-2f2f2e20d16e-c6095aa9.png)
   The Auto-pair config file pop-up box is displayed.
7. Do the following:
   1. Select **Application** as **Passwordless - OloidVault** from **Application Type** dropdown list.
   2. From the **Select Application** dropdown list, select the application that you want the endpoints to pair with.
   3. Under **Download file format**, select one of the following:
      - **JSON** – Download the configuration file in JSON format.
      - **TEXT** – Download the configuration file in text format.
   4. Select **Skip user confirmation for pairing** option to auto-pair endpoints without requiring user confirmation (optional but recommended).
      - **If selected:** When the configuration file is uploaded to the endpoint, the system will pair automatically without prompting the user for confirmation.
      - **If not selected:** The system will display a confirmation pop-up to the user before completing the pairing process.
   5. Click **Copy Config Text** to copy the configuration details to your device (Optional).
   6. Click **Download**.
      ![Oloid Vault (Chrome / Chromium)- How to... - screenshot 6](/images/intercom/15202831/image-36745354.png)

The AutopairConfig file is downloaded to the local device.
