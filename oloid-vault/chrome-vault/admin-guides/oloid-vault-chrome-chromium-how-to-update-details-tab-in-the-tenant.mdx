## Introduction

The **Details** tab for Oloid Vault (Chrome / Chromium) application in the Tenant Admin Portal allows the admin to update the application name, description, set the time zone, etc.

## Prerequisites

- You must have access to the **Tenant Admin Portal**.
- Ensure that **Oloid Vault (Chrome / Chromium)** application is created. To create refer [Oloid Vault (Chrome / Chromium) - How to Create and Configure Oloid Vault Application in the Tenant Admin Portal](https://oloid.help/en/articles/9586885-oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal).

## Steps to Update Details Tab

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click on the preferred Oloid Vault application.
   ![How to Update Details tab in the Tenant... - screenshot 1](/images/intercom/12457063/image-ef381b5f.png)
   The application detail page is displayed.
3. Do the following:
   1. Update the **Application Name** (If needed).
   2. Add the **Description** (Optional).

      <Note>
        **Note:** The description should be less than 140 characters.
      </Note>

   3. Select the **Time Zone** from the dropdown menu.

      <Note>
        **Note:** If the endpoint time zone is not set, it will automatically use the application’s time zone.
      </Note>

   4. Click **Save.**
      ![How to Update Details tab in the Tenant... - screenshot 2](/images/intercom/12457063/image-f675b1bb.png)
      The details tab is updated successfully.
      ![How to Update Details tab in the Tenant... - screenshot 3](/images/intercom/12457063/image-bb2b2935.png)
