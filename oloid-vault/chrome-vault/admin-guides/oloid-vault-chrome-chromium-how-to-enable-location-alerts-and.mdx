## Introduction

This document explains how to enable the **Location Alerts** feature and configure **Geo-Fencing Radius** for the Oloid Vault (Chrome / Chromium) application.

### Prerequisites

- You must have Admin access to the Tenant Admin Portal.
- You must create and configure Oloid Vault (Chrome / Chromium) application in the Tenant Admin Portal. For more, refer to [Oloid Vault (Chrome / Chromium) - How to Create and Configure Oloid Vault Application in the Tenant Admin Portal](https://oloid.help/en/articles/9586885-oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal)

## Steps to Enable Location Alerts

1. Log in to the **Tenant Admin Portal**.
2. On the **Applications** page, click on the Chrome Vault application.
   ![How to Enable Location Alerts and... - screenshot 1](/images/intercom/15699935/image-b5a0c3c0.png)
   The application **details** page is displayed.
   ![How to Enable Location Alerts and... - screenshot 2](/images/intercom/15699935/image-49576c79.png)
3. Go to **Configure** tab > **Settings.**
   ![How to Enable Location Alerts and... - screenshot 3](/images/intercom/15699935/image-fbcdf9d2.png)
   The settings page is displayed.
4. **Enable Location Alerts** toggle to generate an alert transaction when a user's authentication occurs outside the configured geo-fencing radius.

   <Note>
     **Note:** When enabled, users must grant device location access before authentication.
   </Note>

5. In the **Geo-fencing Radius** section, configure the allowed authentication distance:
   - **Miles** – Enter the allowed radius in miles.
   - **Feet** – Enter the allowed radius in feet.

     <Note>
       **Note:** To receive a **Windows Alert** each time a location violation occurs, enable **Browser Tracking** and configure the **Push Browser-data to transaction every** interval. For more, refer to [How to Enable and Configure Browser Tracking.](https://oloid.help/en/articles/9586885-oloid-vault-chrome-chromium-how-to-create-and-configure-oloid-vault-application-in-the-tenant-admin-portal#h_2a0d8a36d8:~:text=Enable%20Browser%20Tracking)
     </Note>

Click **Save.**

![How to Enable Location Alerts and... - screenshot 4](/images/intercom/15699935/image-c4230a0a.png)

The Location Alerts is configured successfully.

![How to Enable Location Alerts and... - screenshot 5](/images/intercom/15699935/image-0f87abc1.png)
