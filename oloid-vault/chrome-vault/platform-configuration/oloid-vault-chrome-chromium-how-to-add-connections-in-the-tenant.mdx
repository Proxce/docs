## Introduction

The **Connections** tab in the Oloid Vault (Chrome / Chromium) application allows admin to link predefined connections to the application. By adding connections, you enable the application to communicate with supported endpoints for secure authentication and access.

## Prerequisites

- You must have access to the Tenant Admin Portal.
- You must create a Oloid Vault (Chrome / Chromium) application in the Tenant Admin Portal. To create refer [How to Create and Configure Oloid Vault (Chrome / Chromium) Application in the Tenant Admin Portal](https://oloid.help/en/articles/9586885-how-to-create-and-configure-oloid-vault-chrome-chromium-application-in-the-tenant-admin-portal).
- You must create Connections. To create Connections. To more information, refer [How to create Connections in the Tenant Admin Portal](https://oloid.help/en/articles/8294297-how-to-create-connections-in-the-tenant-admin-portal).

## Steps to add Connections

1. Log in to the **Tenant Admin Portal**.
2. On the Home page of the portal, click on the preferred Oloid Vault application.
   ![How to Add Connections in the Tenant... - screenshot 1](/images/intercom/12442012/image-df79047a.png)
   The application detail page is displayed.
3. Go to **Connections** tab > select **Add Connections**.
   ![How to Add Connections in the Tenant... - screenshot 2](/images/intercom/12442012/image-4f5ea1bf.png)
   The Add Connection pop-up box is displayed.
4. Do the following:
   1. Select **Connection**(s) from Connection drop down list.
   2. Click **Add**.

      <Note>
        **Note:** An application can have up to 5 connections, and all must be either PC/SC-enabled or non-PC/SC. Combining different connection types is not allowed.
      </Note>

      ![How to Add Connections in the Tenant... - screenshot 3](/images/intercom/12442012/image-7bb695c2.png)

The Connection is successfully added to the application and listed in the connections list.
