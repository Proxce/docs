## Introduction

This document explains how to deploy **Oloid Vault for Chrome/Chromium** using **Microsoft Intune (MDM)**. It covers importing the required ADMX administrative template, creating a configuration profile, configuring the Oloid Vault extension settings, applying the managed configuration (Autopair key), and assigning the profile to target devices.

## Prerequisites

- You must have admin access to the Microsoft Intune Admin Center.
- You must have **ADMX** and **ADML** template files.

  <Note>
    **Note:** Contact [Oloid Support](mailto:support@oloid.ai) to get ADMX and ADML files.
  </Note>

- You must download/copy the **AutoPairConfig.txt** file from the Tenant Admin Portal. For more information, refer [Oloid Vault (Chrome / Chromium)- How to Generate and Download Auto-Pair Config File in the Tenant Admin Portal](https://oloid.help/en/articles/15202831-oloid-vault-chrome-chromium-how-to-generate-and-download-auto-pair-config-file-in-the-tenant-admin-portal).

## Steps to Deploy Oloid Vault (Chrome/Chromium) via Microsoft Intune

1. [Import ADMX Template](#import-admx-template)
2. [Create Configuration Profile](#create-configuration-profile)

### Import ADMX Template

1. Log in to **Microsoft Intune Admin Account**.
   The Microsoft Intune home page is displayed.
2. Select **Devices**.
   ![How to Deploy Oloid Vault using... - screenshot 1](/images/intercom/15689334/image-7f0f7339.png)
   The **Devices** page is displayed.
3. Click **Windows**.
   ![How to Deploy Oloid Vault using... - screenshot 2](/images/intercom/15689334/image-12381169.png)
   The **Windows devices** screen is displayed.
4. Go to **Manage devices** >click **Configuration**.
   ![How to Deploy Oloid Vault using... - screenshot 3](/images/intercom/15689334/image-3aeaeb4d.png)
   The **Configuration** screen is displayed.
5. Click **Import ADMX**.
   ![How to Deploy Oloid Vault using... - screenshot 4](/images/intercom/15689334/image-a45deb6b.png)
   The **Import ADMX** screen is displayed.
6. Click **+Import**.
   ![How to Deploy Oloid Vault using... - screenshot 5](/images/intercom/15689334/abfe47b6-9a29-4fa0-919f-7de75eae7ef0-853a91e7.png)
   The Import settings screen is displayed.
7. On **ADMX file upload** tab, do the following:
   1. Select **ADMX file**.
   2. Select **ADML file for the default language**.

      <Note>
        **Note:** Contact [Oloid Support](mailto:support@oloid.ai) to get the ADML and ADML files.
      </Note>

   3. Click **Next**.
      ![How to Deploy Oloid Vault using... - screenshot 6](/images/intercom/15689334/image-26f738d1.png)
      The **Review + create** tab is displayed.
8. On **Review + create** tab, click **Create**.
   ![How to Deploy Oloid Vault using... - screenshot 7](/images/intercom/15689334/image-3057c6bf.png)
   The ADMX file is created and added in the Import ADMX list.

### Create Configuration Profile

1. Navigate to **Devices > Windows > Manage devices > Configuration**.
   The Configuration page is displayed.
2. Click **Create** > **New Policy**.
   ![How to Deploy Oloid Vault using... - screenshot 8](/images/intercom/15689334/image-f1e62acb.png)
   The **Create a profile** screen is displayed.
3. Do the following:
   1. Select **Windows 10 and later** as Platform.
   2. Select **Templates** as Profile type.
   3. Select **Imported Administrative templates** as Template.
   4. Click **Create**.
      ![How to Deploy Oloid Vault using... - screenshot 9](/images/intercom/15689334/image-77b8cf7d.png)
      The **Create Profile** screen is displayed.
4. On **Basics** tab, do the following:
   1. Enter **Name**.
   2. Enter **Description** (Optional).
   3. Click **Next**.
      ![How to Deploy Oloid Vault using... - screenshot 10](/images/intercom/15689334/image-e7f89d48.png)
      The **Configuration settings** tab is displayed.
5. On **Configuration settings** tab, do the following:
   1. Select **Computer Configuration** > **Oloid Vault**.
      ![How to Deploy Oloid Vault using... - screenshot 11](/images/intercom/15689334/image-841d89e5.png)
   2. Select **Google Chrome** > **Settings**.

      <Note>
        **Note:** To deploy Oloid Vault for **Microsoft Edge**, select **Microsoft Edge**.
      </Note>

      ![How to Deploy Oloid Vault using... - screenshot 12](/images/intercom/15689334/image-57dc1547.png)
   3. Configure both the settings as follows:
      1. Click **AutoPair Configuration**.

         <Note>
           **Note:** This setting is used to automatically pair Oloid Vault with the Oloid tenant during deployment.
         </Note>

         The **AutoPair Configuration** pop-up box is displayed.
         1. Select one of the following:
            1. Enabled

               <Note>
                 **Note:** If enabled is selected, in the **Configuration (base64)** field, enter the Base64-encoded AutoPair configuration key. To generate and download the Auto-Pair configuration key, refer to [Oloid Vault (Chrome / Chromium)- How to Generate and Download Auto-Pair Config File in the Tenant Admin Portal](https://oloid.help/en/articles/15202831-oloid-vault-chrome-chromium-how-to-generate-and-download-auto-pair-config-file-in-the-tenant-admin-portal).
               </Note>

            2. Disabled
            3. Not configured

               <Note>
                 **Note:** If you select **Disabled** or **Not Configured**, you must manually pair the Oloid Vault application after installation.
               </Note>

            4. Click **OK**.
               ![How to Deploy Oloid Vault using... - screenshot 13](/images/intercom/15689334/image-00b3073c.png)
      2. Click **Extension**.

         <Note>
           **Note:** This setting is used to automatically install and pin the Oloid Vault extension in Google Chrome/Chromium during deployment.
         </Note>

         The **Extension** pop-up box is displayed.
         1. Select one of the following:
            1. Enabled
            2. Disabled
            3. Not configured
            4. Click **OK**.
               ![How to Deploy Oloid Vault using... - screenshot 14](/images/intercom/15689334/image-235c9823.png)
   4. Click **Next**.
      ![How to Deploy Oloid Vault using... - screenshot 15](/images/intercom/15689334/image-81772a63.png)
      The **Scope tags** tab is displayed.
6. On **Scope tags**, click **Next**.
   ![How to Deploy Oloid Vault using... - screenshot 16](/images/intercom/15689334/image-4f971981.png)
   The **Assignments** tab is displayed.
7. On **Assignments** tab, do the following.
   1. Click **Add groups** to assign this profile to your target device groups.

      <Note>
        **Note:** Click **+ Add all devices** to apply to all enrolled devices.
      </Note>

      ![How to Deploy Oloid Vault using... - screenshot 17](/images/intercom/15689334/image-d0109b34.png)
      The **Select groups to include** pop-up box is displayed.
   2. Do the following.
      1. Select the **group(s**) from the list.

         <Note>
           **Note:** You can select multiple groups.
         </Note>

      2. Click **Select**.
         ![How to Deploy Oloid Vault using... - screenshot 18](/images/intercom/15689334/a9038bce-eb0f-4dc5-8b61-88df7d7a4174-f168bb65.png)
         The **Group** is added in the list.
   3. Click **Next**.
      ![How to Deploy Oloid Vault using... - screenshot 19](/images/intercom/15689334/image-926ff4b0.png)
      The Assignment tab is configured successfully and Review + create tab is displayed.
8. On the Review + create tab, review the summary and confirm the following:
   1. **Force-install and pin settings (Google Chrome)** is Enabled.
   2. **Managed configuration (Google Chrome)** is Enabled.
   3. Correct group is assigned.
9. Click **Create**.
   ![How to Deploy Oloid Vault using... - screenshot 20](/images/intercom/15689334/image-50f03697.png)
   The Configuration profile is created successfully.
