## Oloid Vault Location Alerts and Geo-fencing Feature

The Location Alerts feature in Oloid Vault(Chrome / Chromium) enables organizations to monitor whether user authentication occurs within an approved geographical area.

Admin can define an allowed authentication radius in miles and feet. When a user authenticates outside the configured geo-fencing radius, Oloid Vault generates a location violation transaction.

When Location Alerts toggle is enabled, users must grant location access to their device or browser before authentication. The system checks whether the authentication occurred in the allowed location.

Admin can also configure **Browser Tracking** to **send browser activity at configured intervals** to transactions.

## How to Enable the **Location Alerts**

Tenant Admin can enable Location Alerts and configure the geo-fencing radius from the Oloid Vault (Chrome / Chromium) application settings in the Tenant Admin Portal.

Do the following:

1. Enable **Location Alerts**.
2. Configure the allowed authentication Geo fencing radius in miles and feet.
3. Enable **Browser Tracking** and configure the browser-data transaction interval to generate Windows Alerts for location violations.
4. Save the configuration.
   For detailed configuration instructions, refer to [Oloid Vault (Chrome / Chromium) - How to Enable Location Alerts and Configure Geo-fencing Radius](https://oloid.help/en/articles/15699935-oloid-vault-chrome-chromium-how-to-enable-location-alerts-and-configure-geo-fencing-radius)
