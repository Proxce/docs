## Introduction

This document provides step-by-step instructions to install, configure and auto-pair the Oloid Vault chromium-based extension on managed Windows endpoints using ManageEngine Endpoint Central.

## Prerequisites

- You must have admin access to the ManageEngine Endpoint Central console.
- You must download the **AutoPairConfig.txt** file from the Tenant Admin Portal. For more information, refer to [Oloid Vault (Chrome / Chromium)- How to Generate Auto-Pair Config File in the Tenant Admin Portal](https://oloid.help/en/articles/15202831-oloid-vault-chrome-chromium-how-to-generate-auto-pair-config-file-in-the-tenant-admin-portal)

  <Note>
    **Note:** Download the AutoPairConfig file in `.txt` format only.
  </Note>

## Steps to Deploy Oloid Vault (Chrome/Chromium) via ManageEngine Endpoint Central

1. [Configure Chrome Extension Policy for Oloid Vault](#configure-chrome-extension-policy-for-oloid-vault)
2. [Configure Auto-pair for Oloid Vault](#configure-auto-pair-for-oloid-vault)
3. [Configure Target and Deploy the Oloid Vault App](#configure-target-and-deploy-the-oloid-vault-app)
   The Chrome Vault is deployed successfully.

### Configure Chrome Extension Policy for Oloid Vault

1. Log in to the ManageEngine Endpoint Central.
   The ManageEngine Endpoint Central home screen is displayed.
2. Go to **Configurations** > **Create Configuration** > **Windows.**
   ![How to Deploy Oloid Vault using... - screenshot 1](/images/intercom/15189497/eb64d429-3981-4ba7-8669-aec84595ec0d-ee84c7ac.png)
   The **Windows Configuration** screen is displayed.
3. Click **Registry > Computer Configuration**.
   ![How to Deploy Oloid Vault using... - screenshot 2](/images/intercom/15189497/image-1afb9cd1.png)
   The Registry configuration screen is displayed.
4. In the **Name and Description** section, do the following:
   1. Enter the configuration name.
   2. Click **Add Description** and then enter the description in the displayed text box. (Optional)
5. Ensure **Manually** is selected under **Registry Configuration**.
6. Ensure **Write Value** is selected under **Action**.
7. Ensure **HKEY_LOCAL_MACHINE** is selected under **Header Key**.
8. In the **Sub-Key** field, enter `SOFTWARE\Policies\Google\Chrome` as the registry sub-key path.
9. Ensure **REG_SZ** is selected under **Data Type**.
10. In the **Value Name** field, enter `ExtensionSettings` as the value name.
11. In the **Value Data** field, enter the appropriate registry value for your browser:.

Google Chrome

```
{ "peeofnhcbenipokkdfpiocdbbapphnje": { "installation_mode": "force_installed", "toolbar_pin": "force_pinned", "update_url": "https://clients2.google.com/service/update2/crx", "override_update_url": true } }
```

Microsoft Edge

```
{"gbicnkgpdfjpgeledfgfkkalheafcjpd":{"installation_mode":"force_installed","update_url":"https://edge.microsoft.com/extensionwebstorebase/v1/crx","toolbar_state":"force_shown"}}
```

### Configure Auto-pair for Oloid Vault

1. Click **Add More Registry Settings**.
   The Registry Entry screen is displayed.
2. In the **Name and Description** section, do the following:
   1. Enter the configuration name.
   2. Click **Add Description** and then enter the description in the displayed text box. (Optional)
3. Ensure **Manually** is selected under **Registry Configuration**.
4. Ensure **Write Value** is selected under **Action**.
5. Ensure **HKEY_LOCAL_MACHINE** is selected under **Header Key**.
6. In the **Sub-Key** field, enter the registry sub-key path for your browser:

Google Chrome

```
SOFTWARE\Policies\Google\Chrome\3rdparty\extensions\peeofnhcbenipokkdfpiocdbbapphnje\policy.
```

Microsoft Edge

```
SOFTWARE\Policies\Microsoft\Edge\3rdparty\extensions\gbicnkgpdfjpgeledfgfkkalheafcjpd
```

7. Ensure **REG_SZ** is selected under **Data Type**.
8. In the **Value Name** field, enter `Config` as the value name.
9. In the **Value Data** field, paste the auto-pair config. plain text from the downloaded file.

   <Note>
     **Note:** You can download the auto-pair config. plain text from your Oloid Portal.
   </Note>

   ![How to Deploy Oloid Vault using... - screenshot 4](/images/intercom/15189497/image-ec991a15.png)
   The auto-pair is configured successfully. Scroll down to configure and deploy the Oloid Vault extension.

### Configure Target and Deploy the Oloid Vault App

1. Under **Define Target**, configure **Target 1**:
   1. Select the required **Target Type** from the drop-down.
   2. Configure the **Target settings**.
      ![How to Deploy Oloid Vault using... - screenshot 5](/images/intercom/15189497/image-3fe9ad11.png)

      <Note>
        **Note:** The **Execution Settings** section is preconfigured with the recommended default settings. Do not change any options in this section.
      </Note>

Click **Deploy.**

<Note>
  **Note:** Changes may take a few minutes to apply. To deploy the changes immediately, click **Deploy Immediately**.
</Note>

![How to Deploy Oloid Vault using... - screenshot 6](/images/intercom/15189497/image-e7d8cdba.png)

The deployment is initiated and the configuration is pushed to target machines.
