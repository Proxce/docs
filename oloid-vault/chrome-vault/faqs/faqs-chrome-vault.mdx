## 1. How to share logs ?

You have to be an Admin/Supervisor to share logs with the developers.

1. Open **Chrome Vault app**.
2. Go to more option icon ![FAQs Chrome Vault - screenshot 1](/images/intercom/9973398/image-1133bdf8.png) > **Admin mode** tab.
3. Log in to the **Chrome Vault**.
4. Click **Share logs**.
   The logs are shared.

## 2. How to view application details?

You have to be an Admin/Supervisor to view the application details.

1. Go to **Admin mode** tab.
2. Log in to the **Chrome Vault**.
3. Go to more option icon ![FAQs Chrome Vault - screenshot 2](/images/intercom/9973398/image-9c922367.png) > **Application Details**.
   The Application details page is displayed.

## 3. How to exit admin mode?

To exit admin mode, close the tab where the admin mode is opened.
