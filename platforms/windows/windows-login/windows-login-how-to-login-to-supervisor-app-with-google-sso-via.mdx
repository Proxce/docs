## Introduction

This document provides step-by-step instructions for logging in to the Supervisor App using Google SSO. When SSO is enabled, users can authenticate using their Google account credentials to securely access the Supervisor App.

## Prerequisites

- You must have an Admin or Supervisor account access.
- Windows Login Application must be created in the Tenant Admin Portal. For more information, refer: [How to create and configure Windows Login application in the Tenant Admin Portal](/platforms/windows/windows-login/windows-login-how-to-create-and-configure-windows-login-application)
- Ensure the endpoint is paired with the Windows Login application. refer [Windows Login - How to Manually Pair the Supervisor App](/platforms/windows/supervisor-app/windows-login-how-to-manually-pair-the-supervisor-app)
- Ensure User has a Valid Google account.
- Ensure SSO is enabled in the Tenant Admin Portal. For more information, refer: [Tenant Admin Portal - How to Enable GSuite SSO in Tenant Admin Portal](/more/sso-and-mfa/tenant-admin-portal-how-to-enable-gsuite-sso-in-tenant-admin-portal)

## Step to Login with Google

1. Double-click on the **Supervisor App** to start.

   ![Double-click on the Supervisor App to start.](/images/intercom/9727729/image-78170438.png)

   The Login screen is displayed.
2. Click **Login with SSO.**

   ![Click Login with SSO.](/images/intercom/9727729/image-a6dd338f.png)

   The **Login with SSO** page is displayed.
3. Select **Login with Google.**

   ![Select Login with Google.](/images/intercom/9727729/image-87dd5e97.png)

   The **Sign in** page is displayed.

   ![The Sign in page is displayed.](/images/intercom/9727729/image-d42b266a.png)

4. Enter **Email or phone.**
5. Click **Next.**
   The **Welcome** page is displayed.

   ![The Welcome page is displayed.](/images/intercom/9727729/7f6e7469-d76f-454e-963d-5949c9e88cbe-d627a2c0.png)

6. Enter **Password.**
7. Click **Next.**
   You are logged into the Supervisor app.

   ![You are logged into the Supervisor app.](/images/intercom/9727729/image-6e846f4d.png)
