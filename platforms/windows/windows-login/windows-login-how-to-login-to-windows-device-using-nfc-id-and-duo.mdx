## Introduction

This document explains how to sign in to a Windows device using an NFC tag and Duo authentication in the Windows Login app. This passwordless, multi-factor login combines NFC verification with Duo two-factor authentication, so it’s faster and more secure than signing in with a password.

## Prerequisites

- An NFC ID must be assigned to you. For more information, refer [Windows Login - How to enroll NFC](/platforms/windows/windows-login/windows-login-how-to-enroll-nfc-tag-from-the-windows-lock-screen)
- Duo must be enabled as the second factor in the **Authenticator** tab of the Windows Login application in the Tenant Admin Portal.
- You must have access to your registered mobile device.
- Your External Username or Duo ID must be added as an identifier on the **User Details** page and registered in the Duo app.

  <Note>
    **Note:** If you don’t see the login option, contact [Oloid Support](mailto:support@oloid.ai).
  </Note>

## Steps to login to Windows Device

1. On the Windows lock screen, do the following:
   1. Click **Sign-in options**.

      ![Click Sign-in options.](/images/intercom/12421965/6faa7742-4e4a-41ec-9b56-58697982d959-d911507d.png)

      The Windows login app is displayed.
   2. Select **Windows login app**.

      ![Select Windows login app.](/images/intercom/12421965/284c288c-36be-4d5e-aeb4-42a6d04de7bc-1cac1b11.png)

   3. Select **Login with OLOID**.

      ![Select Login with OLOID.](/images/intercom/12421965/3027aaf5-4fc3-4869-8b25-95ecc7748ce0-47fb83d7.png)

      The **Tap NFC Tag at the device** screen is displayed.
2. Tap the **NFC Tag** on the **Reader** to scan it.

   ![Tap the NFC Tag on the Reader to scan it.](/images/intercom/12421965/image-6a2b5884.png)

   The **Choose Your Account** pop-up box is displayed.

   <Note>
     **Note:** If the user has multiple passwords configured in the Oloid Portal, they can select a specific account to sign in. If the user has only one account configured, **Choose Your Account** pop-up box will not be displayed.
   </Note>

3. Select the account to sign in.

   ![Select the account to sign in.](/images/intercom/12421965/image-87004acc.png)

   The message “Please check your mobile device for a Duo push notification and approve the authentication request” is displayed.

   ![The message “Please check your mobile device for a Duo push notification and approve the authentication](/images/intercom/12421965/103-0134bd8e.png)

   The **Duo Security** pop-up box is displayed.

   ![The Duo Security pop-up box is displayed.](/images/intercom/12421965/af48985f-2cd5-4ff1-900d-8ab639e9a3eb-a0b47310.png)

4. Select the user’s phone number from the **Device** dropdown in the **User Details** section.

   <Note>
     **Note:** The **Device** dropdown displays multiple phone numbers only if the user has more than one phone number configured in the system.
   </Note>

5. Do one of the following:
   1. **Duo Push**:
      1. Select **Send push** to send a notification to the registered mobile number.

         ![Select Send push to send a notification to the registered mobile number.](/images/intercom/12421965/2ccff0c7-0104-490a-80b3-184f2f928b3d-6752a5c8.png)

         The Push notification is displayed in your registered device.
      2. Tap **Approve**.

         ![Tap Approve.](/images/intercom/12421965/image-31--476becd6.png)

         OR
   2. **Passcode:**
      1. Select **Enter a Passcode** to send a Passcode to the registered mobile number.

         ![Select Enter a Passcode to send a Passcode to the registered mobile number.](/images/intercom/12421965/87ae0b42-5918-49ae-81a5-1043917800c2-8228a0f3.png)

         A Passcode is displayed on the Duo mobile application.

         ![A Passcode is displayed on the Duo mobile application.](/images/intercom/12421965/image-27ef1319.png)

      2. Enter the passcode in the passcode field and click **Log In**.

         ![Enter the passcode in the passcode field and click Log In.](/images/intercom/12421965/image-1acee688.png)

         The **Validating Duo** screen is displayed.

         ![The Validating Duo screen is displayed.](/images/intercom/12421965/104-19cea9ea.png)

         After authentication succeeds, the **Authentication Success** screen is displayed.

         ![After authentication succeeds, the Authentication Success screen is displayed.](/images/intercom/12421965/105-26bdce67.png)
