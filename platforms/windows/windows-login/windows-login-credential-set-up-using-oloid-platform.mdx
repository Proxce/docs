This is based on client requirements. Oloid's Windows login functions with a single factor (like Face, Badge, NFC tags, and Pin) or a combination of factors ( **Badge +PIN** and **NFC +PIN**).

Set up the following based on your need:

- Onboard User Faces. Refer [Face Onboarding](/more/passwordless-authenticator/face-onboarding) guide.
- Create Badges and assign it to users. Refer [Badge Onboarding](/more/passwordless-authenticator/badge-onboarding) guide.
- Create NFC and assign it to users. Refer [NFC Onboarding](/more/passwordless-authenticator/nfc-onboarding) guide.
- Create Pin and assign it to users. Refer [Pin Onboarding](/more/passwordless-authenticator/pin-onboarding) guide.
- Create Passwords ( Individual Domain and Individual Local). Refer [How to create Password for Windows Login](/platform/tenant-admin-portal/how-to-create-password-for-windows-login) guide
- Create Shared Credentials (Shared Domain and Shared Local) and assign it to users. Refer [How to create Shared credentials and assign it to users](/drafts/unassigned/intercom/how-to-create-shared-credentials-and-assign-it-to-users) guide.

The credential setup is also done using the Supervisor App. Refer to [Credential Management - Supervisor App](https://oloid.help/en/collections/8743863-credential-management-supervisor-app)
