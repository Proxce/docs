## Introduction

This document lists the **domain URLs that must be whitelisted** in the customer network to allow Oloid products to function correctly.

Whitelisting these URLs ensures proper connectivity for the **Oloid platform.**

Allow **outbound HTTPS traffic (Port 443)** to the domains listed below.

---

## Product Information

| Field | Value |
| --- | --- |
| Product Name | Windows Authenticator App 2.0 |
| Protocol | HTTPS |
| Port | 443 |
| Direction | Outbound |

---

Use the following table for URL whitelisting.

| Service | PROD (US) | Description | Whitelisting Requirement |
| --- | --- | --- | --- |
| Cloud URL | gateway.oloid.cloud | Provides access to Oloid cloud services through path-based routing, including Admin API, User API, Downloads, Cache and Documents. | **Mandatory** |
| Windows Login cache service | oloidcache.oloid.cloud | Windows Login cache service URL used for device authentication. | **Mandatory** |
| Tenant S3 bucket | &lt;tenantname>&lt;tenantid>.s3.us-east-1.amazonaws.com | Tenant S3 bucket URL used to download the Customer Logo. | **Mandatory** |
| Oloid download service | download.oloid.cloud | Oloid download service URL used to download oloid software. | **Conditional:** Required when you use On-device FR mode, Presence Detection, Epic and Launcher during installation. |
| Oloid document bucket | oloiddocument-prod.s3.us-east-1.amazonaws.com | Oloid document bucket URL is used for Consent document. | **Conditional:** Required when you use FR mode. |
| Admin API | api.oloid.cloud | Admin API used for Authentication. | **Conditional:** Required when you use the Oloid Admin Portal on the Windows device. |
| Tenant User API | api.myoloid.com | The Tenant User API used for Enrollment | **Conditional:** Required when you use the Oloid User Portal on the Windows device. |

---

##### Additional Information

- Replace **&lt;tenantname>** and **&lt;tenantid>** with your organization's Tenant name and Tenant ID.
- Enter the **&lt;tenantname>** and **&lt;tenantid>** values in lowercase only.
- Contact [Oloid Support](mailto:support@oloid.ai), if you do not have the **&lt;tenantname>** and **&lt;tenantid>** details.
