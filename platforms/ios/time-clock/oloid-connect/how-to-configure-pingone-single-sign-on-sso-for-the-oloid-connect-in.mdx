## Introduction

This document provides instructions to configure PingOne Single Sign-On (SSO) for the DeviceLock App in the PingOne Admin Console.

## Prerequisite

You must have **administrator access** to the PingOne Admin Console.

## Steps to Configure PingOne SSO

[Create Environment](/more/sso-and-mfa/how-to-configure-pingone-single-sign-on-sso-for-the-oloid-portal-in)

[Create and Configure Applications](/more/sso-and-mfa/how-to-configure-pingone-single-sign-on-sso-for-the-oloid-portal-in)

### Steps to Create an Environment

<Note>
  **Note:** If an environment already exists, skip this section.
</Note>

1. Sign in to the Ping Identity Administrator Console with your PingOne account credentials.
2. Click **Create Environment**

   ![Click Create Environment](/images/intercom/16779341/image-55816dee.png)

   The Create Environment screen is displayed.
3. Select **Customer Solution** and then click **Next**.

   ![Select Customer Solution and then click Next.](/images/intercom/16779341/image-c3cfcb6e.png)

4. Click **Next**.

   ![Click Next.](/images/intercom/16779341/image-76265e66.png)

5. Do the following:
   1. Enter **Trial Environment Name**.
   2. Enter **Description (Optional)**
   3. Select **Environment ID**.
   4. Select a **Region**.
   5. Select a **Licence**.
   6. Click **Finish**.

      ![Click Finish.](/images/intercom/16779341/image-f2818bfb.png)

      The environment is created successfully.

### Steps to Create and Configure Application

1. Go to the newly created environment, select **Applications > Applications**.

   ![Go to the newly created environment, select Applications &gt; Applications.](/images/intercom/16779341/image-b9f2584b.png)

   The Applications page is displayed.
2. Click Add icon (<img src="https://downloads.intercomcdn.com/i/o/e4gi378c/1315355866/00d82bfa56619275fd638dfe1eae/image.png?expires=1795154400&amp;signature=d9809bc89eb77b85ef04f2f849075c589e5ed37b7f8f3adf768f78e0926bc2f1&amp;req=dSMmE8p7mIlZX%2FMW3nq%2BgeSv0FFIna5XyUIqowgVWWL0R6hTAKNBurRLhHb4%0AugYxXnx3KV4S2mHP8aZZxIp416A%3D%0A" alt="Icon" className="oloid-icon" noZoom />).

   ![Click Add icon ( ).](/images/intercom/16779341/image-43ab0fde.png)

   The **Add Application** page is displayed.
3. Do the following:
   1. Enter **Application Name**.
   2. Enter **Description** (Optional).
   3. Select **Native** as **Application Type**.
   4. Click **Save**.

      ![Click Save.](/images/intercom/16779341/image-e7e37f21.png)

      The application is created successfully.
4. Select the newly created application.

   ![Select the newly created application.](/images/intercom/16779341/image-e46640eb.png)

   The Application detail page is displayed.
5. On the application **Profile** page, enable the app using the toggle button next to the application name.

   ![On the application Profile page, enable the app using the toggle button next to the application name.](/images/intercom/16779341/image-6969b0be.png)

   The app is enabled successfully.
6. Select **Overview** > **OpenID Connect.**

   ![Select Overview &gt; OpenID Connect.](/images/intercom/16779341/image-bfc43c48.png)

   The **Edit Configuration** screen is displayed.
7. Do the following:
   1. Enter `com.connect.oloid://callback` in the **Redirect URIs** field.

      <Note>
        **Note:** Click **+ Add** to add additional redirect URIs, if required (Optional).
      </Note>

   2. Ensure that **None** is selected as the **Token Endpoint Authentication Method**.
   3. Click **Save**.

      ![Click Save. (2)](/images/intercom/16779341/image-a4a6ed22.png)

8. In the application overview, click **Resources >** Allowed Scopes **Edit icon.**

   ![In the application overview, click Resources &gt; Allowed Scopes Edit icon.](/images/intercom/16779341/image-13be02e6.png)

   The **Edit Resources** page is displayed.
9. Select **email >** click **Save**.

   ![Select email &gt; click Save.](/images/intercom/16779341/image-31e5be94.png)

   The Email is added in the allowed scopes list.

   ![The Email is added in the allowed scopes list.](/images/intercom/16779341/image-910a2490.png)

   The PingOne SSO for Oloid Connect is configured successfully.
