## Introduction

This document provides instructions to log in to the **Oloid Connect** application using **Google Single Sign On (SSO)**.

## Prerequisite

- You must create and configure the **Oloid Connect** application in the **Tenant Admin Portal**. For more, refer to [How to create and configure Oloid Connect Application in Tenant Admin Portal](/platforms/ios/time-clock/oloid-connect/oloid-connect-how-to-create-and-configure-application-in-tenant-admin)
- You must install the **Oloid Connect** app from the App Store. For more, refer to [How to Download and Install the Oloid Connect App on iPhone](/platforms/ios/time-clock/oloid-connect/oloid-connect-how-to-download-and-install-on-iphone)

## Steps to Log in with Google SSO

1. Launch the **Oloid Connect** <img src="/images/intercom/13595983/image-6def886f.png" alt="Oloid Connect icon" className="oloid-icon" noZoom /> app.

   ![Launch the Oloid Connect app.](/images/intercom/13595983/image-02ba2845.png)

   The **Welcome** screen is displayed.
2. Tap **Pair as Supervisor.**

   ![Tap Pair as Supervisor.](/images/intercom/13595983/d77a4a4e-7ec2-412c-8aa8-bb42212fafdb-449c6e31.png)

   The Welcome screen is displayed.
3. Enter **Tenant Name**, then tap **Next**.

   ![Enter Tenant Name, then tap Next.](/images/intercom/13595983/fe90a5f2-9be5-4c65-803b-128174c6d20a-7c997912.png)

   TheLogin page is displayed.
4. Tap **Login with SSO**.

   ![Tap Login with SSO.](/images/intercom/13595983/ca239fcd-407e-4a7a-a949-0802d1c9d140-b243e7c0.png)

   The screen with **SSO options** is displayed.
5. Tap **Continue with Google**.

   ![Tap Continue with Google.](/images/intercom/13595983/image-cb99f25a.png)

   The confirmation pop-up is displayed.
6. Tap **Continue**.

   ![Tap Continue.](/images/intercom/13595983/image-5b361f52.png)

   The **Sign in** screen is displayed.
7. Do the following:
   1. Enter **Email ID**.
   2. Tap **Next**.

      ![Tap Next.](/images/intercom/13595983/image-e788652e.png)

      The **Welcome** screen is displayed.
8. Do the following:
   1. Enter **Password**.
   2. Tap **Next**.

      ![Tap Next. (2)](/images/intercom/13595983/288000da-9bc1-485a-91c8-af362d86d174-4ef2d722.png)

      You are successfully logged in to Oloid Connect Admin Mode.

![You are successfully logged in to Oloid Connect Admin Mode.](/images/intercom/13595983/image-8d10dc4d.png)
