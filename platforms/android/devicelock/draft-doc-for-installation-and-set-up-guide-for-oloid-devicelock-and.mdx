## Introduction

This guide provides detailed instructions to install and set up the Oloid Device Lock and Oloid Vault applications on Android devices through SOTI MobiControl. It also includes a set of basic regression test cases with expected outcomes to ensure that, with every new build release, all core use cases function as intended and no regressions occur.

## Prerequisites

- The device is already enrolled in **SOTI MobiControl**.
- A stable internet connection is available.
- A valid **Microsoft account** is available for the user.

## Installation of Oloid DeviceLock and Oloid Vault

1. Launch the **SOTI MobiControl** app on the device.

   ![Launch the SOTI MobiControl app on the device.](/images/intercom/12148494/image-8a5e9cc2.png)

   The app opens successfully.

   ![The app opens successfully.](/images/intercom/12148494/image-45c50263.png)

2. Tap the **Menu** option on the top-left side of the screen.

   ![Tap the Menu option on the top-left side of the screen.](/images/intercom/12148494/image-0e7c9b7f.png)

3. Tap **App Catalog** menu.

   ![Tap App Catalog menu.](/images/intercom/12148494/image-c4fd6d56.png)

   The App Catalog screen is displayed.

   ![The App Catalog screen is displayed.](/images/intercom/12148494/image-f90eb505.png)

4. Go to **In-House Apps** tab and do the following:
   1. Tap install **Oloid Device Lock**.
   2. Tap install **Oloid Vault**.

      ![Tap install Oloid Vault.](/images/intercom/12148494/image-763ef0ea.png)

      Both applications are installed successfully.

      ![Both applications are installed successfully.](/images/intercom/12148494/d86c8463-4c2e-4b90-819a-8a655e7251f1-eab1ec38.png)

### Enable Oloid Vault Accessibility

1. Open **Oloid Vault app.**

   ![Open Oloid Vault app.](/images/intercom/12148494/4bfabc35-194c-496a-8382-59ca8988ba4c-dd23f9d8.png)

2. Select **Oloid Vault**.

   ![Select Oloid Vault.](/images/intercom/12148494/d5ab58a1-0935-4096-a69c-d888f189e883-4c727b0d.png)

3. Enable Use Oloid Vault toggle.

   ![Enable Use Oloid Vault toggle.](/images/intercom/12148494/image-416c7565.png)

   The Allow Oloid Vault control access pop-up box is displayed.
4. Select **Allow**.

   ![Select Allow.](/images/intercom/12148494/image-6dd33852.png)

   The Oloid Vault Accessibility is enabled successfully.

   ![The Oloid Vault Accessibility is enabled successfully.](/images/intercom/12148494/image-e48c22a2.png)

### Enable Autofill option for Oloid Vault

1. Open **settings** on you Android Device.

   ![Open settings on you Android Device.](/images/intercom/12148494/image-e63a53ea.png)

2. Enter **Autofill** in the search bar text field.

   ![Enter Autofill in the search bar text field.](/images/intercom/12148494/image-25d3b963.png)

3. Tap the option under Autofill.

   ![Tap the option under Autofill.](/images/intercom/12148494/image-2d295f9b.png)

4. Tap **Oloid Vault** option under Autofill service.

   ![Tap Oloid Vault option under Autofill service.](/images/intercom/12148494/image-f96ebd3e.png)

   The **Make Sure** pop-up box is displayed.
5. Tap **OK**.

   ![Tap OK.](/images/intercom/12148494/image-2f4581fd.png)

   The **Autofill service** for Oloid Vault is enable successfully.

   ![The Autofill service for Oloid Vault is enable successfully.](/images/intercom/12148494/image-28b0e320.png)

3. Enable **Use Oloid Accessibility Service** toggle.

   ![Enable Use Oloid Accessibility Service toggle.](/images/intercom/12148494/12891967-f2d3-47b6-b6c9-a0cac4996d43-48f85e73.png)

4. Tap **allow** when prompted.

![Tap allow when prompted.](/images/intercom/12148494/dff0d65a-86d1-4c74-b581-2f2ee6012e7d-e7ace98c.png)

![The Oloid Accessibility Service is enabled successfully.](/images/intercom/12148494/image-533ee573.png)

  **Note:** While enabling the accessibility, if you get the restricted settings, then you can enable restricted setting. For more details refer this section [Allow Restricted Setting](/platforms/android/devicelock/installation-setup-and-regression-test-case-guide-for-oloid-device).

### Allow Restricted Setting

1. Go to the Android device Home Screen.
2. Long tap the **Oloid Device Lock** app > Tap **App Info**.

   ![Long tap the Oloid Device Lock app &gt; Tap App Info.](/images/intercom/12148494/image-8f0e1667.png)

   The App info screen is displayed.
3. Tap the **three-dot menu** on the right-top side of the screen.

   ![Tap the three-dot menu on the right-top side of the screen.](/images/intercom/12148494/image-4cd32a96.png)

4. Select **Allow Restricted Settings**.

   ![Select Allow Restricted Settings.](/images/intercom/12148494/image-9325cdf1.png)

   Restricted settings are enabled successfully for Oloid DeviceLock app
5. Launch **Oloid DeviceLock App** and allow **accessibility service** for DeviceLock App.
   For more details refer this section [Allow Accessibility service for DeviceLock App](/platforms/android/devicelock/installation-setup-and-regression-test-case-guide-for-oloid-device).

### Login with SSO

3. Select **Login with SSO**.

   ![Select Login with SSO.](/images/intercom/12148494/image-5c5b1024.png)

4. Choose **Continue with Microsoft**.

   ![Choose Continue with Microsoft.](/images/intercom/12148494/image-942b0147.png)

5. Enter your Microsoft **Email ID > Select Next**.

   ![Enter your Microsoft Email ID &gt; Select Next.](/images/intercom/12148494/image-564a8e4d.png)

6. Enter Password > Tap **Sign In**.

   ![Enter Password &gt; Tap Sign In.](/images/intercom/12148494/image-e2dc9318.png)

   You have logged in with SSO successfully.

   ![You have logged in with SSO successfully.](/images/intercom/12148494/image-af36c981.png)

### Enroll User credentials

1. Enroll Face. To enroll face refer [How to enroll face for users in the DeviceLock App](/platforms/android/devicelock/oloid-devicelock-app-how-to-add-face-for-users-in-the-devicelock-app).
2. Enroll PIN. To enroll PIN refer [How to enroll PIN for users in the DeviceLock App](/platforms/android/devicelock/devicelock-app-how-to-assign-a-pin-for-users-in-the-devicelock-app).
3. Enroll NFC/ID. To enroll NFC/ID refer [How to enroll NFC/ID for users in the DeviceLock App](/platforms/android/devicelock/devicelock-app-how-to-assign-nfc-id-for-users-in-the-devicelock-app).

   <Note>
     **Note:** Once the Credentials are enrolled for the user, Log out of Admin Mode and Initial Screen of device lock with configured Auth methods will be displayed
   </Note>

### Authentication Flow

1. Authenticate using **Device Lock** (Face + PIN or NFC + PIN).

   ![Authenticate using Device Lock (Face + PIN or NFC + PIN).](/images/intercom/12148494/image-d048c852.png)

   The **web view** screen is displayed.
2. Enter your Microsoft account **password** > Tap **sign-in.**

   <Note>
     **Note:** If it is first-time login, you need to manually enter your credentials.
   </Note>

   ![Enter your Microsoft account password &gt; Tap sign-in.](/images/intercom/12148494/image-c42e6246.png)

   The Username and Password prompt box is displayed.
3. Select **Save**.

   ![Select Save.](/images/intercom/12148494/cc148b33-65cf-4847-8cd8-66f89db93e3d-f5578166.png)

   .
   The **pre-login screen** is displayed.

   ![The pre-login screen is displayed.](/images/intercom/12148494/image-9b9213bb.png)

   <Note>
     **Note:** Using Accessibility, **auto-login** is attempted into SOTI.
   </Note>

4. If auto-login does not occur, tap the **Login button** manually.
   The SOTI dash board screen is appeared.

   ![The SOTI dash board screen is appeared.](/images/intercom/12148494/image-7f3a70d6.png)

5. Once logged in, you can access the customer **apps** like - Blank slate, Spring shot, Aero, etc.
6. For all future app logins, **auto-login will occur automatically**.

## Summary

By following the above steps, the **Oloid Device Lock** and **Oloid Vault** applications will be fully installed, configured, and ready for use.

- Administrators can log in using **Microsoft SSO for** enrolling with **Face, NFC, and PIN** credentials
- **Oloid Vault** enables **Autofill**, allowing seamless access and auto-login to Microsoft and non-Microsoft applications.
